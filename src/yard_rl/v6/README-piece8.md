### 범위 밖 · 남은 구멍 (조각 8 이 끝나도 남는 것)

- **시장 이식** (약 915줄: market 168 + seller 165 + buyer 122 + resolver 109 + offer 77 + bridge 274,
  + time_sell 132) — 없으면 연구가 재는 메커니즘(공간 판매·시간 이연)이 학습 대상에서 빠진다.
  이식하면 `gpu/cands3.py` 의 '이름 순위 = 행 번호' 위험이 **즉시 살아난다**(이송이 동점을 만든다).
- **고정 화물(`CargoTerminal`) 갈래** — 연구선의 유일한 실행 경로. 전역 큐 4단 키 ·
  `V3Announcer.resolve_entry` · 원격 본선 인계 · 끝의 재고 등식 · `cargo_moves.move_dependent`.
- **증거 배선** — v5 형식 체크포인트(옵티마이저·난수 상태)·날별 장부·완주 게이트 6종·코드 도장이 없다.
  `.npz` + `report.json` 뿐이라 v5 평가·재개 도구가 읽지 못한다. 프로세스를 넘겨 이어 돌릴 수도 없다
  (`--e0>0` 은 이제 **거절한다** — 전에는 조용히 새 세계를 만들고 '완료' 로 적었다).
- **작업량 정형화(workload shaping) 보상** 미이식 → 세 팔 중 workload 팔 불가 (`shaping_reward` 는 0 고정).
- **결정 칸** — 배수 구간(7,200초)에는 검토 경계가 없어 한 구간에 결정 140건이 쌓인다. `cmax` 기본 256 은
  그 실측값 + 여유이고 (21블록·구간당 20.7MB · 60구간 = 1.24GB), **넘치면 이제 크게 실패한다**
  (`PR.raise_on_flags` — 전에는 비트만 켜고 지나가 잘린 테이프로 학습하고도 '완료' 였다).
  정공법은 배수 구간에도 검토 경계를 넣어 `cmax` 를 격자 값(≤39)으로 되돌리는 것이다.
- **GPU 의 `gamma ** dt`** — 실제로 나올 수 있는 dt 전부(정수 1~130 + 이진분수 + 1441)를 CPU 에서 비트
  일치로 단언하고, GPU 에서 1 ulp 갈리는 dt 는 **재서 찍는다**(밑 0.95 · dt 24·121·1441 실측).
