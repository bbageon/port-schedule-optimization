# v3 — 통합 아키텍처 코드

> 설계 정본: [`.claude/docs/architecture/README.md`](../../../.claude/docs/architecture/README.md)
> 문서가 **to-be** 이고 코드가 여기에 맞춘다.

## 이 폴더의 규칙 (사용자 지시 2026-08-20)

1. **v1·v2 코드를 수정하지 않는다.** 읽는 것은 자유, 고쳐야 하면 여기에 새로 짠다.
2. **v3 는 v3 것만 갖는다.** v1/v2 에서 import 하지 않는다 — 식이 같아도 사본을
   따로 둔다. 세대를 얼리기 위한 **의도된 중복**이다.
3. **무대만 공유한다** — `integrated/`(엔진·비용·레이아웃·배정기)는 복제하지
   않는다. 판정이 **짝비교**라 세 세대가 같은 무대를 받아야 비교가 성립한다.
4. **한 번에 한 축씩** 넣고 축마다 판정한다.

기계 검사: `tests/v3/test_v3_isolation.py` 가 1·2 를 강제한다.

## 무엇을 세대 폴더에, 무엇을 무대에 두나

가르는 기준은 **"세대가 바뀌면 이게 달라져야 하나"** 하나다.

| | 어디 | 왜 |
|---|---|---|
| **판정에 쓰는 것** — 평가 잣대 Φ · 규칙 팔 · 에피소드 실행 · 시뮬레이터 | `integrated/` | **같아야 비교가 성립한다.** 판정이 짝비교라 세 세대가 같은 무대·같은 자를 받아야 한다 |
| **학습에 쓰는 것** — 특징 · 보상 라벨 · 정책망 · 학습 루프 | `v1/` `v2/` `v3/` | **달라지는 게 세대다.** 세대마다 사본을 갖는다 |

`shared/` 같은 중간 계층은 두지 않는다 — 만들면 결국 거기로 다 모인다
(사용자 지시 2026-08-20). 기계 검사: `tests/v3/test_v3_isolation.py`

## 무엇을 어디에 두나

**`schema/`** 오더 레코드 규격과 시각 셋(통지·예정·실현)의 분리. 지금 구현은
셋이 한 값이라 예약 준수 축이 없다 → 여기서 갈라 놓는다.

**`reward/`** 그 거래만 취소한 세계를 H=1시간 굴려 총비용 차이를 재는 교사.
**학습에서만** 불린다 — 배포 경로에서 부르면 하드가드 위반이다.

**`actors/`** 채점망을 파는 쪽(Seller)·사는 쪽(Buyer) 둘로 나눈다. 배정기가
`Seller(src) − Buyer(dst) − ΔC_route` 로 조립한다.

**`features/`** 경계 안쪽인데 안 주던 정보를 넣는다. 넣기 전에 **잡음 하한을
먼저 재서** 값어치를 확인한다(학습 불필요).

## 아직 비어 있다

착수 순서는 설계 정본의 리팩토링 순서를 따른다. 지금 가능한 것은 1~4단계이고
5~8단계는 **performance 게이트 해소 전 착수 금지**다.
