# 선택 계약을 지키는 교사: 고정 합성 환경 재학습 사전등록

등록일 2026-11-09. YR-332-ab/c. 결과를 보기 전에 코드와 함께 커밋한다.

## 질문과 범위

실행 우선순위를 우회한 대안을 가르치는 문제가 관측되었다. 이 계약만 고쳤을 때
같은 신경망의 주문 체류시간이 줄어드는지 검증한다. 실제 터미널 효과 확증은 아니다.
외생 주문은 모두 유지, 양하 하한은 chain-v3-discharge-bound. 운반차 3대/470초 고정.
예약 시각과 실도착 차이, 실제 운반차 운영 보정은 미확정이며 현실성 게이트를 열지 않는다.
정책 입력 10개(feasible/STORE/clipped), 은닉층 64×64, 실작업 우선, 기존 비용식 고정.
후보 제한 없음, 기존 공통계산·계획 재사용 설정은 모든 군에서 동일하게 켠다.

## 교사 군

- legacy_force: 기존 크레인별 작업 강제(tier=-1). 비교용이며 채택하지 않는다.
- reachable: 대안의 float32 입력 점수만 최상위로 바꾸고 같은 입력에는 같은 점수 적용.
  필수/실작업 등급은 유지하고 기존 resolver가 선택한 경우만 비교한다.
  같은 표본 결정에서 정해진 순서로 대안을 탐색한다. 새 결정을 더 모으지 않는다.
  표본된 크레인에서만 탐색하며, 선택된 작업과 같은 입력은 쌍별 차이 학습이 불가능해 제외한다.
  공동 배정 전체를 증거로 저장하고 분기 첫 배정과 완전 일치해야 라벨로 사용한다.
  단일 점수 개입의 탐색 범위이므로 전체 도달 가능성의 완전 탐색이라고 주장하지 않는다.

## 학습 예산

- 모델 초기값: 9914701, 9914702, 9914703. 군별 초기 가중치 동일.
- 6회 갱신: 하루 3500, 7500, 15000건을 두 차례, 회차마다 새로운 입력.
- 학습 입력 seed = 9914800 + 100×모델순번 + 10×회차(0부터).
- 각 회차 행동 정책은 해당 초기 모델로 고정한다. 두 군의 실제 결정 열이 일치해야 한다.
  이는 공통 행동 자료로 비교하는 통제 재학습이다. 온라인 정책 반복 개선과 구분한다.
- 각 군 회차당 최대 24개 표본 결정, 미래 10800초, coverage 표본 방식.
- 같은 초기 모델에서 각 군을 따로 6회 누적 학습. pairwise 손실, 기존 Adam/학습률.
- 회차당 최적화 50회(기존 steps_coef=1.0, 최대 48개 행이면 기존 하한 50회), 검증 분리는 결정 단위.
- 라벨 2쌍 미만·사실 재생 불일치·새 교사 대안 재생 불일치·예외 발생 시 중단하고 기록.
  성공 쌍 수 차이도 교사 수정의 결과로 보고하며 추가 수집으로 보충하지 않는다.

## 독립 평가

- 학습에 쓰지 않은 3일×3부하: seed=9915900+100×날순번+10×부하순번.
- 각 초기값의 초기 모델, 3회 후 모델, 6회 후 모델을 같은 입력에서 평가한다.
- 채택 판정은 미리 정한 6회 후 모델만 사용한다. 시험 성적을 보고 가중치를 고르지 않는다.
- 기존 고전 규칙 7개도 동일 입력/후보/환경으로 평가한다.
- 24시간 체류시간(미완료는 창 끝까지 포함), 24/26시간 미완료·접수 누락·본선 완료/대기,
  비용 원값·예외·결정 재현을 함께 보고한다. 완료 차량만 평균 내서 미완료를 숨기지 않는다.
- 독립 단위는 입력일이다. 초기 모델 셋을 독립 항만 관측으로 세지 않는다.
- 학습 전/기존 교사/각 규칙 대비 차이를 모두 공개한다. SF-SPT가 사전 주 비교 규칙이다.
- 개선 주장: 최종 체류시간이 초기/기존교사/SF-SPT보다 낮고, 접수 누락=0,
  미완료 수·본선 보호가 악화하지 않아야 한다. 표본이 작으면 진단으로만 해석한다.
- 정식 성능 게이트는 기존 비용 신뢰구간·완주·잔여·본선 가드를 그대로 사용한다.
  비용 차이는 각 입력의 SF-SPT 대비 백분율로 계산하며 최소개선 0, 관심효과 1%로 고정한다.
  초기값 3개 평균을 낸 입력 9개가 통계 단위이고, 부하별 결과도 따로 공개한다.
  통과하지 못하면 연속 30일 확증으로 넘어가지 않는다.
