# 합성 하루 학습량·후보 맥락망 진단 실행 설정

2026-11-16 · YR-323-d/as. 사용자 네 단계 실행 요청의 3·4단계다.
앞 단계의 실제 분별 모형 실패와 보정은 별도 기록하며, 그 정책 결과로 이 설정을 고르지 않는다.

## 새 비교 정답 수집

- 최종 합성 입력: 기존 24지점 하루 곡선 + 같은 부모의 반출 비율 + ar에서 검증한 수식 도착.
- 학습: train 곡선0~5, 물량3,500/7,500/15,000을 두 번 순환. 입력 시드9940100~9940105.
- 선택용 검사: selection 곡선0~2, 세 물량 각각 하나, 시드9940200~9940202.
- 각 하루 최대48개 교사 질문, coverage 표본, reachable 대안, 미래비용 창10,800초.
- 행동 정책은 기존 초기 MLP(seed9917101)로 모두 고정. 여러 망이 정확히 같은 정답을 받는다.
- 10개 현재 특징을 실행 가능한 후보 전체에서 저장. 비교 정답은 두 선택, 맥락은 후보 전체다.
- 원래 실행/대안 일치 실패0, 교사 오류0, 모든 오더 접수, 후보 특징과 비교 쌍 특징 일치 필수.
- 실행은 부모3개×분기 작업자3개(부모 포함 최대12프로세스), 연산 스레드1로 고정한다.
  결과는 결정 키 순서로 정렬한다. 동시 실행 메모리를 확인하며 과거 상한16프로세스를 넘지 않는다.

## 같은 정보·자료 비교

초기값9917101/102/103. 학습률0.0003, SmoothL1 비교 비용차 손실, 기울기 한계1.
MLP64×64, 맥락망 후보32→결합64→출력1. 매개변수 수 차이도 보고한다.
여섯 회차를 모두 사용하고 종료 시점은 고정한다. 선택용 성과로 가장 좋은 회차를 뽑지 않는다.

| 팔 | 자료 | 회차당 갱신 | 목적 |
|---|---|---:|---|
| point_current | 현재 회차 전체 | 50 | 현재 학습 방식 대조 |
| point_replay | 현재까지 전체 누적 | 50 | 이전 자료 재사용 효과 |
| point_half | 각 회차의 절반을 누적 | 50 | 새 정답 수 효과 |
| point_steps | 현재까지 전체 누적 | 200 | 같은 자료 반복량 효과 |
| mean_context | 현재까지 전체 누적 | 50 | 후보 전체 접근의 효과 |
| star_attention | 현재까지 전체 누적 | 50 | 동일 정보에서 집계 구조 효과 |

매 갱신 미니배치는 결정 쌍128개로 고정하고 복원 추출한다. 자료가 적어도 갱신당 표본 수는 같게 한다.
모든 팔의 샘플 순서는 같은 난수 시드로 고정한다. 과거 aq의 `min(128,자료 수)`와 다른 새 진단 설정이다.
절반 자료는 입력 시드별 고정 무작위 순서의 앞 절반이며, 전체 자료에 포함된다.
공통 정규화 눈금은 학습용 절반 자료의 원화 비용 차이 절댓값 중앙값(기존 하한1,000원)을 사용한다.
선택용·최종 평가 자료는 눈금에 쓰지 않는다. 원래 aq 회차별 정규화와 다른 새 진단 조건임을 명시한다.
학습 손실·순위·선택용 결과·시간을 모두 기록하고, 맥락망의 평가에는 전체 후보를 동일하게 제공한다.

## 운영 평가

- 미사용 합성 holdout 곡선0/1/2 × 각각 물량3,500/7,500/15,000, 시드9940300/301/302.
  세 물량에 날짜 하나씩이므로 일반화의 확증이 아니라 고정 조건 진단이다.
- 여섯 학습 팔 + 학습 전 MLP × 초기값3 × 입력3 =63회.
- SF_SPT/FIFO/LWKR × 입력3 =9회, 합72회.
- 대표 MLP·Attention 조건 각1회 반복하여 결정·사건·장부와 결과 동일성을 확인한다.
- 첫 초기값의 여섯 학습 팔을 반복하여 최종 가중치가 정확히 재현되는지 확인한다.
- 트럭은 오더당 게이트 진입→작업 완료, 24시간 경계에서 미완료 경과시간을 포함한다.
  본선은 스트림 시작→해당 야드 작업 완료. 24/26시간 미완료를 함께 보고한다.
- 원자료 전체를 저장·다시 계산한다. 성능 악화·혼잡·미완료를 이유로 입력을 제외하지 않는다.
- 후보 전부 평가, 후보 순서 일관성, 전체 결정 소요시간도 기록한다.
- 평균 개선만으로 채택하지 않는다. 모든 초기값·입력의 변화와 본선 보호·미완료를 확인한다.

## 범위

고정된 제한적 합성 환경에서 입력·학습·구조를 분리한 비교다. PPO 구현이나 현장 성능 증명이 아니다.
공동 배정기·물리·원화 비용·완료 기준은 그대로다. 관계망은 자원 경쟁의 별 그래프이며 방문 선후관계까지 포함하지 않는다.
외부 운반·대기열 근거 미확보는 유지한다. 사용자 요청 진단과 자동 채택 게이트를 구분한다.
