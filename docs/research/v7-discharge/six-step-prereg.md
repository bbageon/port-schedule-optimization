2026-11-05. 사용자 명시 지시: 제안한 6단계를 순서대로 실험한다.
기준 코드 `2eff03e1`. 단계별 구현·검사를 마친 깨끗한 커밋에서 각 실험을 실행한다.

## 순서·분리

1. YR-332-n: 같은 후보·선택·결과를 유지하는 후보 계산 보정.
2. YR-332-o: 기본 12칸과 전체 후보 대조. 후보 누락과 모델 선택 변화·운영 결과 기록.
3. YR-332-g: 8번째 입력을 해당 크레인의 실행 가능한 실작업 수로 수정.
4. YR-332-p: 같은 표본의 개별 회귀와 비용 차이 학습 비교.
5. YR-332-q: 같은 최대 비교 예산에서 크레인·작업 종류별 대안 추출 개선.
6. YR-332-r: STORE/RETRIEVE 여부 한 입력만 추가해 기존 본선 여부와 함께 네 흐름 구분.

효과가 없거나 악화하면 해당 변경은 채택하지 않는다. 다음 단계의 사전 지정 대조는 진단으로
실행할 수 있으나, 이전 변경이 검증됐다고 전제하지 않는다. 단계별 결과와 조건을 분리한다.
후보·물리 정합 실패는 즉시 중단하고 고친 후 재등록한다. 손실이 줄었다고 운영 개선으로 판정하지 않는다.
이번에는 대형 그래프망·PPO 전환·비용식 변경·재배정 추가를 동시에 하지 않는다.

- 전체/후보 생성/선택 시간, 결정의 중앙·느린 5%·최대, 메모리를 모두 보고한다.
- 전체 평균과 부하별 변화·반복 변동을 함께 판단한다. 특정 입력 개선만으로 채택하지 않는다.

### 1단계 구현 확정 (주 비교 실행 전)

기준 프로파일에서 `_plan` 2,380,008회, `find_slot` 4,133,129회가 관측됐다.
`find_slot` 누적 126.78초, 전체 물리 상태 대조는 8.65초(계측 포함)였다.
세대 번호 추적보다 먼저 **기존 물리 상태 대조 아래 동일한 재취급 슬롯 탐색을 재사용**한다.
반입 슬롯에 이미 적용한 같은 인자 계약을 재취급에 확장하며, 물리 검사와 후보 범위는 유지한다.
직접 상태 수정·예약 변경·외부 선택 함수·복제/직렬화와 혼합 작업 검사를 포함한 101건이 통과했다.
`reuse_rehandle_slots`는 기본 꺼짐이며, 비교 결과를 보고 채택 여부를 별도로 판정한다.

### 1단계 대안 추가 (대안 코드의 속도 측정 전)

초기 슬롯 재사용 대조의 앞 7쌍은 결과가 같고 속도 차이는 대체로 ±2%였다.
기준 계측에서 실행 가능성 존재 확인(`_decision_cranes`)이 전체 목록을 계산하며
`candidates_for` 누적 141.62초를 쓰는 별도 병목도 확인했다. 초기 12쌍은 끝까지 보존한다.
대안은 존재 확인을 첫 **계획·예약 검사까지 통과한 작업**에서 끝내는 것뿐이다.
정책이 받는 전체 후보 생성·점수·순서는 바꾸지 않는다. 외부 선택 함수가 있으면 기존 전체 탐색을 쓴다.
슬롯 재사용과 결합하지 않는다. 기본 꺼짐으로 비교하고 결과가 보존돼야 한다.
3500/9913490, 7500/9913491, 15000/9913492의 3쌍을 각각 두 번 반복한다(추가 12실행).
각 부하에서 두 쌍 모두 같은 작업 결과와 시간 감소가 확인돼야 계산 경로 채택을 검토한다.
이는 3개 입력의 계산 진단이며 정책 성능이나 다른 항만의 속도 보장은 아니다.

## 4·5·6단계 학습 진단

- 초기 모델 시드 9913501/9913502/9913503. 학습 입력은 9913600대, 최종 평가는 9913900대.
- 모델별 3회 갱신(3,500→7,500→15,000건), 회차당 최대 24개 비교·각 3시간·가지 2개.
  짧은 원인 분리 진단이다. 수렴·논문 확증이나 24개가 충분한 표본이라는 주장이 아니다.
- 최대 예산·실제 유효 비교 수·반사실 세계 수·제로 차이·강제 실패를 모두 보고한다.
- 최초 비교(4단계)는 똑같이 저장한 학습 표본·초기 모델·갱신 횟수로 손실만 변경한다.
  이후 정책별로 자료를 모으는 폐루프 학습 효과와 구분한다.
- 손실: 기존 개별 SmoothL1과 점수 차이 SmoothL1. 비용 눈금은 동일 라벨의 동일 통계를 사용한다.
  표본 수 차이로 갱신 강도가 변하지 않도록 단계별 업데이트 예산을 명시한다.
- 5단계는 크레인/작업 종류의 비교 표본을 넓힌다. 대표 표본을 유지하고 무작위 선택은 전용 고정 시드 사용.
- 6단계는 STORE 여부 1칸만 추가한다. 첫 9칸 가중치는 동일하게 복사하고 새 칸 가중치는 0에서 시작해
  학습 전 행동이 동일함을 확인한다. 추가 정보 효과와 초기 모델 차이를 분리한다.
- 학습/검증은 같은 결정의 두 후보를 묶어서 나눈다. 최종 평가일은 학습·모델 선택에 쓰지 않는다.
- 마지막 모델을 평가한다. 최종 평가 성적을 보고 최고 회차를 고르지 않는다.
- 각 모델은 부하 3종의 같은 평가일에서 학습 전·기존 손실·차이 손실·표본 개선·정보 추가와 비교한다.
  기존 규칙도 같은 후보·같은 물리 조건에서 평가한다. 제한 12의 원래 규칙 결과를 별도 보존한다.
- 턴타임 개선이 있어도 본선 완료/미완료를 악화시키면 운영 채택은 미통과다.
- 3초기값·각 부하 1평가일은 진단이다. 모든 결정 수를 독립 반복 표본으로 세지 않는다.
- 학습시간·유효 표본·추가 재생 수를 함께 보고한다. 동일 표본 비교와 동일 시간 비교는 구별한다.

### 학습 비교의 데이터 통제 확정 (라벨 수집 전)

- 4단계는 기존 개별 손실 정책을 공통 자료 수집 정책으로 삼는다. 매 회차 수집 직전 모델을
  보관하고, 같은 라벨로 개별 손실과 차이 손실의 학습기를 각각 갱신한다.
- 5단계는 4단계의 **동일 회차 수집 직전 모델·입력**을 재사용하되 비교 표본 선택만 바꾼다.
  차이 손실 학습기는 같은 초기값에서 다시 시작한다. 실제 하루 경로가 같아야 한다.
  표본 시각·간격은 유지한다. 그때 가능한 크레인 중 덜 비교한 크레인을 고르고, 절반은 정책의
  차선 후보, 나머지는 덜 비교한 작업 유형 쌍을 고른다. 동률은 고정 시드 해시로 해소한다.
  미래 비용을 보고 표본을 고르지 않는다. 하루 전체 시간대 편중을 해결했다고 주장하지 않는다.
- 6단계는 5단계의 동일 라벨에 결정 당시 기록한 STORE 여부만 붙여 학습한다.
  입력 추가 효과를 위해 분기 자료·목표·눈금·갱신 수를 다시 바꾸지 않는다.
- 따라서 이는 공통 수집 정책에 대한 **통제된 학습 비교**다. 차이 손실·표본 개선·추가 입력을
  각자 정책으로 되먹임하는 장기 학습의 효과까지 검증한 것으로 해석하지 않는다.
- 학습 시드: `9913600 + 초기값번호(0~2)*100 + 회차(0~2)*10`.
  평가 시드: 부하 순서대로 `9913900/9913910/9913920`, 모든 모델에 같은 세 날 적용.
- 3단계 의미 감사는 부하 3종·시드 9913420에서 기존 입력으로 실제 실행하고, 같은 상태·후보의
  수정 입력/상한 도달 비율과 최고 순위 변화만 별도 계산한다. 수정 입력의 성능은 재학습 후 평가한다.
- 표본을 뽑지 않는 결정의 대안 점수 계산은 생략하되, 표본 시각·후보 선택 규칙은 유지한다.
  분기 결과 정렬은 시간·블록·크레인 전체 키를 써서 병렬 완료 순서에 의존하지 않게 한다.
  두 수정은 공통 수집 경로의 재현성 검사 대상으로 두며 손실식 성능 이득으로 계산하지 않는다.
