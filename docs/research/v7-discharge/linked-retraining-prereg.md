# 보정 환경 재학습 진단 (사용자 요청) — 2026-11-14

## 질문

사용자 요청: "모든 사항 진행하고 학습 다시 해서 감소율 알려줘."
ag 학습 뒤 환경을 네 번 고쳤다: 작업 비율·시간대(aj), 시간대 안 방문 몰림(ak), 여러 컨테이너 방문 연결(al),
명단 보조 시각(an, 결과 불변). **학습 방법은 그대로 두고 환경만 바꿔** 다시 학습하면,
학습 전·짧은 실작업 우선 규칙·이전 모델 대비 트럭 시간 감소율이 어떻게 되는지 진단한다.

## 경계

- 현재 게이트는 현실성 FAIL·성능 미확정이다. 이 실행은 사용자 지시 진단이며 성능 확증·채택이 아니다.
  운반(i)·대기열 정의(f)·날짜 간 변동(ao)·고물량 몰림 근거(ap)는 남아 있다.
- 보정 근거는 이미 본 개발용 13일이다. 평가 입력은 새 합성 시드이며 실자료 독립 기간이 아니다.

## 환경

- `outputs/reports/yr332_visit_links/demand-profiles.json`의 `observed_visit_links`
  (aj 반출 비율·24시간 비중 + ak 실제 분당 방문 형판 + al 방문 연결). 예약 보정 파일은 ag와 같다.
- 물리·운반 3대·470초 가정, 21블록·42크레인, 24시간 관측·26시간 실행, 후보 수 제한 없음, 재배정 끔.
- al 사전등록대로 7,500·15,000건의 방문 몰림은 관측 범위 밖 민감도 조건이다.

## 학습 — ag와 동일

- 초기 시드 9917101·9917102·9917103. 초기 가중치가 ag와 같은지 먼저 검사한다.
- 6회: 3,500 → 7,500 → 15,000 → 3,500 → 7,500 → 15,000. 학습 입력 시드 `9923200 + 100×모델 + 10×회차`.
- 회차마다 결정 최대 24개를 골라, 실제 고른 작업과 실행 가능한 차점자 작업의 3시간 뒤 비용을 두 세계로 굴려 잰다.
  두 점수의 차이가 비용 차이를 따르도록 50회 갱신한다(쌍 비교 손실). 질문 생성 정책은 초기 정책으로 고정한다.
- 마지막(6회차) 가중치만 평가한다. 결과를 본 뒤 학습량·회차·시드를 바꾸지 않는다.

## 평가

- 새 입력 9개: `9923600 + 100×날짜 + 10×물량번호`(물량별 3개).
- 정책 16개: 고전 규칙 7개(SF_SPT·FIFO·LIFO·SPT·NEAREST·LWKR·RANDOM), 학습 전 3개, 재학습 3개,
  이전 모델 3개(ag 학습 후 가중치, 연결 없는 보정 전 입력으로 학습). 144회 + 반복 2회 = 146회.
- 주 지표: 오더별 게이트 진입→그 작업 완료 평균(24시간 검열, 미완료 포함). 반입·반출·양하·적하별.
  방문별 진입→마지막 완료와 진입→출차는 보조 지표다.
- 감소율 = (기준 − 비교 정책)÷기준×100. 양수면 짧아진 것이다. 기준은 같은 모델의 학습 전, SF_SPT, 이전 모델.
  모델 3개를 같은 입력에서 함께 평균하고, 모델·물량별 값도 모두 공개한다(좋은 모델만 고르지 않는다).
- 총비용(재학습 − SF_SPT)의 입력 9개 단위 짝 재표집 95% 구간(10,000회)을 보고한다.
  성능 판정은 ag와 같은 규칙(최소 개선 1%, 전건 완료·미완료 0·본선 보호·물리 가드)으로 기록만 한다.
- 검산: 저장 라벨로 가중치 18개 정확 재학습, 트럭·전체 작업 행 재계산, 방문 정차·출차 엔진 검사, 반복 2회 비트 일치.

## 해석 규칙

- 이전 모델과 재학습 모델은 같은 입력에서 비교하므로, 차이는 학습 입력 분포를 바꾼 효과로만 읽는다.
- 물량별 입력 3개, 모델 3개다. 입력 단위 구간이 0을 걸치면 방향 미확정으로 보고한다.
