# YR-332-ay: 남은 비용 예측의 학습 눈금만 바꾸는 비교

등록일: 2026-11-17. 정책 결과를 보기 전에 설정과 코드를 동결한다.
사용자 요청: “응 이거 진행해봐 음수신호가 필요한지도 모르겠네”.
합성 환경의 진단 실행을 승인한 것으로 기록한다. 현실성 통과를 대신하지 않는다.
이전 검사 도구의 현실성 선결 거절은 `authorization.json`에 원문 보존한다.

## 가설과 변경 한 축

- 가설: 남은 비용을 예측하는 학습의 큰 오차·규모 차이가 정책 갱신을 불안정하게 한다.
- 대조군: 기존 PPO(선택 확률을 조금씩 고치는 강화학습)의 가치 학습 그대로.
- 변경군: PopArt(학습 눈금을 조정하면서 원래 단위 예측은 보존)의 단일 전역 정규화.
- 보상·총비용 목적·고정 눈금 368293633.7020551·24시간 관측·26시간 실행은 그대로다.
- Transformer 32너비/4헤드/2층, 후보 10개 특징, 가변 전체 후보, 물리 제약은 그대로다.
- 날짜·물량별로 보상이나 우선순위를 다시 가중하지 않는다. 미래 진실을 입력에 추가하지 않는다.
- 음수 학습 신호는 제거하지 않는다. `실현 보상 합 − 사전 가치 예측`을 계산하고,
  기존과 같이 두 날짜에서 고른 전체 2,048개를 함께 평균·표준편차로 조정한다.
  음수는 상대적으로 확률을 낮추는 신호이며, 특정 날에 음수가 많다는 사실만으로 오류는 아니다.

## 정확한 정규화·최적화 계약

- 한 정책 갱신에서 새로 선택한 2,048개 표적을 **한 번만** 통계에 넣는다.
- 과거 표적도 포함한 누적 모집단 평균 μ와 표준편차 σ를 float64로 계산한다.
  반복 학습 4회 때문에 같은 표적을 통계에 네 번 넣지 않는다. 평가 자료는 통계에 넣지 않는다.
- 초기 μ=0, σ=1, 누적수=0. 수치적 바닥 σ=0.0001; 발동 여부를 기록한다.
- 정규화 표적은 `(Y−μ)/σ`, 원래 눈금의 예측은 `V=σg+μ`이다.
- 통계 변경 시 마지막 선형층은 `W'=σ_old/σ_new·W`,
  `b'=(σ_old·b+μ_old−μ_new)/σ_new`로 바꾼다. 실제 선택 점수는 바꾸지 않는다.
- 새 경험 전체에서 통계 변경 전후 가치 오차 ≤0.00002, 선택 점수 차이 0을 검사한다.
- 가치 손실만 정규화된 표적과 예측의 제곱오차로 계산한다. 행동 학습 신호는 복원한 V를 쓴다.
- Adam의 모든 누적 상태는 **그대로 유지**하며 초기화·재척도화하지 않는다.
  이는 명시적인 구현 선택이다. 예측 보존과 Adam 갱신 궤적의 불변성은 다른 것이며 후자는 주장하지 않는다.
- 학습률 .0003, PPO 비율 제한 .2, 가치 계수 .5, 엔트로피 계수 .01,
  전체 기울기 상한 1, 4회 반복, 묶음 64를 두 군 모두 유지한다.
  내부 눈금 변화가 가치 손실의 유효 크기를 바꾸는 것이 이번 개입이며,
  계수를 같게 썼다고 행동/가치 기울기 비율까지 고정된 것은 아니다.

## 같은 출발·같은 예산

- Transformer 초기값 9951101·9951102·9951103의 세 쌍. 각 쌍은 모든 초기 파라미터가 같다.
- 양쪽 모두 새 Adam으로 다시 시작한다. 옛 파일에 Adam 상태가 없으므로 이어학습이라 부르지 않는다.
- 모델당 6회 갱신 × 새로운 2일 = 12일. 갱신당 최대 2,048결정 × 4회 반복 = 128최적화 단계.
- 저장 모델: 초기, 갱신 0~5, 최종. **최종은 언제나 갱신 5**이며 최고 모델을 고르지 않는다.
- 새 체크포인트에는 모델·정규화 통계·Adam·Torch 난수·갱신 번호를 보존한다.
- 경험을 만드는 선택은 확률 추첨이다. 두 군은 같은 입력·난수 시작점을 쓰지만
  정책이 달라진 뒤 방문하는 상태·결정 수까지 강제로 같게 만들지는 않는다.
- 날짜 추첨·샘플 선택·미니배치 순서의 난수는 코드에 별도로 고정한다.

## 합성 입력과 분리

- 기존 24개 주기적 삼각 기저, 개발일 모수의 두 점 보간, 같은 반출 비율 보간,
  분 단위 상관 모형, 트럭 방문 연결, 초기 적재 유지 설정을 그대로 쓴다.
- 기존 개발 집계에서 새 곡선 bank seed=9954000으로 train13/selection3/holdout3을 만든다.
- train0~11은 학습, train12는 동작 시험 전용이다. 이전 36곡선과 중복이 없어야 한다.
- 학습 입력 seed=9954200~9954211, 물량은 3500/7500/15000의 네 순환이다.
- 검증 selection0/1/2에 물량 3500/7500/15000을 대응하고 seed=9954300/1/2를 쓴다.
- 시험 holdout0/1/2 각각에 세 물량을 교차한다. seed=9954400/1/2, 총 9입력이다.
- 모든 입력은 정책 실행 전에 공급·예약·방문·반입/반출 보존을 검사한다.
  실패하면 중단·원인 공개한다. 성능을 보고 곡선이나 입력 난수를 버리지 않는다.
- 새 합성 추첨이지 독립 실측 날짜가 아니다. 같은 보정 모수와 같은 물리 모형을 공유한다.

## 평가·판정

- 검증 3입력: 초기 3모델, 두 군의 갱신2·최종 6모델을 고정 최고점 선택으로 평가한다(45회).
- 최종 6모델의 비용 예측은 같은 검증 입력에서 별도 확률 추첨으로 평가한다(18회).
  가치망이 예측하는 확률 정책과 최고점 실행 정책의 차이를 섞지 않는다.
- 시험 9입력: 최종 6모델과 SF_SPT(실제로 짧게 끝나는 작업 우선 규칙)를 평가한다(63회).
- 본 평가 126회 + 두 군 각 1회 결정적 재실행. 통계 갱신이나 추가 학습에 평가를 사용하지 않는다.
- 학습 전후 같은 경험의 오차, 새 검증 경험의 오차, 물량·6시간 구간별 신호 부호를 분리한다.
- 같은 상태에서 선택 분포·최고점 변화도 측정한다. 확률 변화와 실제 결정 변화는 따로 적는다.
- 1차 결과는 24시간 터미널 총비용. 함께 게이트진입→작업완료 시간,
  반입·반출·양하·적하, 24/26시간 미완료 수, 본선 지연을 제시한다.
- 일별 평균을 각 입력에 같은 무게로 합친다. 모델 세 초기값을 독립 반복으로 보고,
  개별 트럭 수를 독립 실험 반복 수처럼 세지 않는다. 미완료 오더도 관측 종료까지의 시간을
  평균에 포함하고 미완료 수를 병기한다. 끝까지 걸린 실제 평균 시간과 구별한다.
- 세 초기값 모두 시험 평균 비용이 줄고, 평균 트럭 시간·본선 지연·미완료가
  함께 악화하지 않아야 일관된 개선 후보로 본다. 한 초기값이나 가치 오차만 좋아지면 채택하지 않는다.
- 규칙 대비 성능·전건 완료와 현실성은 별도 게이트다. 비용 예측 개선만으로 통과시키지 않는다.
- 작은 3초기값·3곡선 진단이므로 통계적 확증이나 실제 항만 개선 주장을 하지 않는다.
