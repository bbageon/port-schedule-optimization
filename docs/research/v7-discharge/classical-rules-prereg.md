# 고전 규칙 7종 대비 저장 학습 정책 — 실행 전 고정 조건

2026-11-06, YR-332-v. 실행 전 커밋 후 이 문서는 변경하지 않는다.

## 질문과 범위

현재 고정 시뮬레이션에서 학습 정책이 도착순·효율·본선 보호 규칙보다 나은가?
재학습하지 않는다. 정책·비용·물리·입력은 고정하고 규칙 비교 정의만 확장한다.
현장 TOS 순서 재현이나 실제 항만 성능 주장은 하지 않는다.

## 규칙 정의

공통: 실행 가능한 후보, 필수 작업과 안전 제약, 실작업 우선 유지.
공통 동률은 작업 ID. WAIT와 준비 작업의 순위 층은 기존 RuleBase와 같다.
문헌의 모든 세부 규칙을 복제한 것이 아니라 같은 행동 공간 위에 적용한 변형이다.

1. FCFS_ARRIVAL: 외부 트럭 BLOCK_ARRIVAL, 적하 JOB_RELEASED, 양하 VESSEL_RELEASED의
   관측된 실제 사건 시각. 준비는 공개 통지순. 직전 평가 구현 유지.
2. SPT: 계획된 전체 작업시간 최소. 이동·취급·재취급을 포함한다.
3. NEAREST: 현재 크레인 위치에서 계획의 첫 취급 bay까지 거리 최소.
   moves가 없으면 end_bay를 사용한다. 점유구간(corridor)과 목표 위치를 구분한다.
4. VESSEL_FCFS: 실작업 중 본선 양하·적하 우선, 같은 종류 안에서는 FCFS.
5. VESSEL_NEAREST: 실작업 중 본선 양하·적하 우선, 같은 종류 안에서는 NEAREST.
6. UNIDIRECTIONAL: 현재 방향의 후보 우선 후 거리 최소. 없으면 반대 방향 가장 가까운 후보.
   시작 방향은 bay 증가 방향. 실제 완료 위치가 바뀌면 그 이동 방향을 기록한다.
   위치가 같으면 방향 유지. 블록·크레인·복제 세계 간 상태 공유 금지.
7. DISTANCE_WAIT: 접근 이동시간 − 대기열 진입 후 대기시간이 최소인 후보.
   접근시간은 현재 bay에서 첫 취급 bay까지 거리/장비 속도. 준비 후보의 대기는 0.
   모든 작업 종류에 같은 초 단위를 쓴다. 가중치 탐색 없음.

기존 SF_SPT는 별도 이력 기준이다. SPT와 동률 해소가 달라 동일성을 가정하지 않는다.
본선 우선은 안전 제약·필수 작업·실작업 우선보다 앞서지 않는다.
미도착 오더의 실현 도착이나 실행 결과는 선택 입력에 넣지 않는다.
공개 정보의 범위는 공통이나 표현은 다르다. 학습 정책은 거리·시간·대기에 상한을 적용하며,
본선 대기열 진입 시각과 단방향의 방향 기억을 그대로 입력받지는 않는다.
따라서 결과는 전체 선택 방식의 비교이며 입력 표현까지 동일한 학습기만의 비교가 아니다.

## 고정 입력·모델·횟수

- 21블록·42크레인, 초기 적재율 0.65, 관측 24시간 + 정리 2시간.
- 물량/입력시드: 3500/9913900, 7500/9913910, 15000/9913920.
- 후보 수 무제한, 재배정 없음, decision_probe_shortcircuit=True,
  reuse_rehandle_slots=False, 기존 기본 실행 설정과 원화 비용 그대로.
- 초기화: 9913501, 9913502, 9913503.
- 모델: initial.pt 및 pointwise/pairwise/coverage/flow의 마지막 *-2.pt 전부.
- 최신(flow)을 주 설명 대상으로 하되 네 학습 방식을 모두 공개한다.
- 21규칙 + 45모델 + 3기존 SF_SPT + NEAREST/UNIDIRECTIONAL의 3500 반복 각 1회 = 71회.
- 새 실행 모두 CPU 1스레드. 최대 6개 독립 프로세스, 프로세스별 세계·모델 생성.
- 기존 결과: 45모델 + SF_SPT 3회는 six_steps, FCFS 3회는 arrival_eval과 정확 재현 대조.
- 반복 2회는 후보·선택·사건·작업·트럭 장부·결과 해시가 같아야 한다.
- 모든 기존 모델/원자료 해시와 실행 전후 원천 파일 해시를 확인한다.

## 지표와 해석

- 기존 공식 값: 24시간 종료까지 게이트 진입 후 체류 평균·90/99분위, 미완료, 비용 네 항.
- 미투입은 입력−admitted로 별도 보고. 체류 평균에 미투입을 0시간으로 넣지 않는다.
- 26시간 최종 시점에 트럭 잔여와 양하/적하 야드 완료를 별도 기록한다.
- 본선 완료 지연은 선박별 마지막 작업의 계획시각과 실제 완료시각으로 계산한다.
  끝나지 않은 본선은 26시간까지만 계산하고 미완료 척수를 함께 적는다.
  이것은 계획 작업 완료 대비 지연이며 ETD 출항 지연이 아니다.
- 안벽 크레인 대기는 선박별 스트림 수로 나눈 기존 vessel_idle_of 정의도 따로 기록한다.
- 같은 입력의 정책/규칙 변화율을 먼저 계산하고, 날짜·모델에 같은 비중으로 평균한다.
- 같은 초기 모델 대비 학습 전후 차이는 규칙 대비 성능과 따로 산출한다.
- 비용·체류 감소와 함께 투입 감소/미완료 증가/본선 완료 감소/본선 지연 증가를 검사한다.
  하나라도 있으면 모든 운영 조건 통과라고 하지 않는다. 임의 허용 손실은 만들지 않는다.
- 물리·정보 시점·실행 예외는 0이어야 한다. 가드가 미수집되면 채택 판정은 미통과다.
- 3날짜는 기존 입력이며 독립 9일도 새 잠금평가도 아니다. 확증용 신뢰구간을 붙이지 않는다.
- 결과를 보고 추가 학습·규칙 선택·비용 재조정·표본 확대를 하지 않는다.
