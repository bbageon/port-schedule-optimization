# YR-332-s — 초기 모델 재현 비교의 분석 정정

2026-11-07. 본 평가 59회가 끝난 뒤의 분석 정정이다. 성능 비교 조건은 바꾸지 않았다.

## 발견한 문제

사전등록은 기존 설정의 학습 전/후 18회 모두 과거 평가와 정확히 같을 것으로 예상했다.
하지만 과거 학습 전 모델은 9입력이고 이번 학습 전 모델은 10입력이다.
추가 입력의 가중치가 0이라도 컴퓨터의 소수점 계산 순서까지 같아지는 것은 아니다.
기존 학습 후 모델은 이미 10입력이다. 이번 세 변환의 학습 전후도 모두 10입력이다.

과거 초기 모델과 비교한 9건 중 8건은 정확 재현했다.
모델 9913501·15,000건에서는 평균 체류가 11,677.123643초에서 11,676.856086초로,
약 0.268초 달랐고, 24시간 미출차는 3,195대에서 3,194대로 달랐다.
이 차이를 숨기거나 과거와 정확히 같다고 간주하지 않는다.

## 원인 조사

별도 추적으로 같은 상태에서 두 모델의 선택이 갈리는 지점을 확인했다.
70,733.674737초, Y13 블록 YC-W 크레인의 D-07330과 D-08489다.
공유 가중치·첫 9개 입력은 정확히 같고 추가 가중치는 0이었다.
단정밀도(평소 신경망 계산 정밀도)에서 두 점수의 약 0.0000001 차이가 순위를 뒤집었다.
같은 계산을 더 높은 정밀도로 하면 두 모델의 점수 차이는 최대 2.23×10⁻¹⁶이었다.

근거: `outputs/reports/yr332_count_transform/initial-replay-diagnosis.json`.
진단 코드: `scripts/v7/diagnose_initial_count_replay.py`.
진단은 원인을 확인하는 별도 추적이다. 평가 정책의 정밀도·동점 처리·행동은 바꾸지 않았다.

## 정정한 검증 범위

- 원본 사전등록·분석 코드·실행 코드·모델·59개 평가 결과는 수정하지 않는다.
- 원본 분석은 첫 불일치에서 중단됐다. 그 실패와 원본 분석 해시를 추가 실행 계획에 보존한다.
- 모든 실행 소스와 입력 해시는 원본 실행 명세와 계속 정확히 대조한다.
- 과거 9입력 대 현재 10입력의 9건은 별도의 구조 간 비교로 공개한다.
- 해당 10입력 초기 모델 한 건을 동일 조건에서 추가 반복하고 결과·전체 궤적의 정확 일치를 요구한다.
- 학습 후 기존 모델 9건·SPT(예상 작업시간이 짧은 작업 우선) 3건의 과거 결과 대조는 유지한다.
- 기존 linear/log1p 반복 2건도 유지한다. 추가 1건은 성능 표본이나 모델 선택에 넣지 않는다.
- 주 비교·보조 비교·종료 시점·모델 선택·보호 조건·집계식은 바꾸지 않는다.
- 학습 전후 효과는 원래 계획대로 이번에 실행한 동일 10입력 구조끼리 비교한다.

전체 실행은 원래 후보 수 복원 9회, 사전 지정 평가 59회, 추가 반복 1회다.
별도 부분 추적을 제외하면 하루 환경 재생은 총 69회다.
3가지 입력 변환×3초기 모델×3회차 학습 27회는 그대로다.

원본 `report_count_transform.py`를 보존한 채 `report_count_transform_analysis.py`로 분석한다.
`analysis-revision.json`에 원본/정정 분석·본 문서·원인 조사·추가 반복 계획의 해시를 기록한다.
독립 감사는 원본 실행 소스와 정정 분석 근거를 모두 확인한다.
