# K 비교 표의 감소율 표시 보완

2026-11-10. 고정 계획과 실행 조건은 `horizon-sweep-prereg.md`를 따른다.
K1·2·6의 성능을 종합하기 전, 기존 K3의 63회 재현 평가를 모두 확인한 시점의 표시 보완이다.

## 바꾸는 것

평균 시간과 같은 칸에 쓰는 괄호 감소율은 **그 평균 시간끼리 계산한 비율**로 표시한다.
계산식은 `100 × (학습 전 평균 − 해당 K 평균) / 학습 전 평균`이다.
평균은 기존과 같이 모델 셋을 먼저 평균한 뒤 입력 아홉을 같은 비중으로 평균한다.

## 그대로 보존하는 주 분석

사전등록한 **입력별 감소율의 평균과 95% 구간**은 비교 표와 JSON의 `reduction_percent`에 보존한다.
새 표시용 값은 별도 필드 `reduction_of_mean_percent`다. 어느 값이 더 유리한지로 선택하지 않는다.
모든 트럭을 건수로 가중한 누적시간 비율도 기존 계획대로 별도 저장한다.
SF-SPT 대비 비용의 짝비교, 표본 수, 모델·시드·학습량·관측 종료·채택 조건은 변경하지 않는다.

## 이유와 실제 예

기존 K3의 전체 트럭 평균은 95.894824분에서 91.702635분으로 줄었다.
이 평균끼리 계산하면 4.371653% 감소이며, 입력별 감소율을 평균하면 4.548676% 감소다.
반입은 53.949642분에서 48.761571분으로 줄어 평균 시간 기준 9.616507% 감소다.
같은 반입 자료의 입력별 감소율 평균은 5.025880%다.
서로 다른 집계법을 한 칸에 섞으면 표시된 평균값으로 감소율을 검산할 수 없게 된다.
이는 원자료 수정이 아니라 서로 다른 통계를 분리해 표시하는 보완이다.

보고서 숫자는 반올림 전 원값으로 계산하고, 표의 평균과 감소율을 따로 기계 대조한다.

## 보고서 계산 속도 보완

최종 집계에서 기존 통계 함수가 같은 확률·자유도의 값을 반복 계산했다.
보고서 안에서 그 함수의 반환값을 그대로 저장해 재사용한다. 공식·정밀도·표본·신뢰수준은 유지한다.
서로 다른 12개 입력과 같은 입력의 재호출 12개가 원래 함수와 정확히 일치했다.
보고서 검사 2건도 다시 통과했다. 첫 집계 프로세스는 중단 후 다시 실행했고 학습·평가 자료는 유지했다.
