# 실제 오더 분포 보정의 고정 정책 진단 — 2026-11-12

## 질문과 적용 범위

실자료와 합성 입력의 차이가 기존 정책 비교에 미치는 영향을 분리한다.
학습 효과 확증·터미널 전체 재현·현장 성능을 주장하는 실험이 아니다.
자료 대조는 `outputs/reports/yr332_order_representativeness/input-audit.json`에 저장했다.
현재 13일 자료는 모두 개발용이며 최종 평가용 기간으로 재사용하지 않는다.

## 결과를 보기 전에 고정한 세 조건

1. `original`: 기존 반출 확률 0.6과 합성 도착곡선.
2. `observed_mix`: 반출 확률만 실제 진입 18,439 / 34,304로 변경.
3. `observed_mix_hours`: 2번에서 시간대별 도착 비중만 실제 24칸 비율로 변경.

1→2는 작업 비율, 2→3은 시간대 도착곡선 한 축만 다르다.
13일의 진입 오더를 전부 센다. 예약 보정 포함군으로 물리 오더를 제한하지 않는다.
시간대 비중은 오더 수 가중 합계다. 일별 물량은 터미널 전체라고 확인되지 않아 보정하지 않는다.
도착 분포의 누적 비율을 따라 기존과 같은 층화 난수로 시각을 만든다.
시간대 안에서는 균등하며 **실제 분 단위 몰림과 날짜 변동은 아직 재현하지 않는다**.
반입/반출의 시간대별 결합분포·실제 블록 배치·본선 자원은 이번에 함께 바꾸지 않는다.
본선 atw의 사건 단계가 미확정이므로 이를 크레인 서비스시간이나 준비시각으로 대입하지 않는다.

## 입력·정책·실행 예산

- 새로운 입력 시드: 물량 3,500 → 9921100, 7,500 → 9921110, 15,000 → 9921120.
- 각 물량에서 같은 시드로 세 조건을 만들며, 모든 정책에 동일한 조건별 명단을 준다.
- 학습 당시 저장한 3모델의 학습 전·후 가중치 6개를 모두 고정해 평가한다.
- 기존 작업 규칙 7개: SF_SPT, FIFO, LIFO, SPT, NEAREST, LWKR, RANDOM.
- 3조건 × 3물량 × 13정책 = 117회. 7,500건 조건의 3회는 정확 재현을 추가 확인한다.
- 추가 재현: 원본/SF_SPT, 비율 보정/첫 학습 후 모델, 시간대 보정/SF_SPT.
- 물량별 신규 시드가 하나이므로 통계적 유의성·일반적 우위를 주장하지 않는다.
- 학습·후보 제한·보상·물리 처리·본선 계획·예약 오차 보정값을 변경하지 않는다.
- 기록 창 24시간, 엔진 26시간. 후보 전체, 기존 계획 재사용·정밀 접수 경로 유지.
- 독립 실행 최대 12개. 각 실행 계산 스레드 1개. 실패·부분 기록을 덮어쓰지 않는다.

## 입력과 결과의 검증

- 기본 경로와 확률 0.6 명시 경로의 입력·작업 궤적 일치를 확인한다.
- 비율 변경 시 도착·블록·규격·주행·초기 야드·본선 유지, 시간대 변경 시 유형·대상 유지.
- 반출 대상 고갈로 유형이 바뀌는 건수 0, 오더 보존, 정확 접수, 사건시각 순서를 확인한다.
- 입력 명단과 가중치 해시를 정책별로 대조하고, 반복 실행의 사건·선택·비용이 같아야 한다.
- 저장한 오더별 시각에서 평균·미완료 수를 별도로 다시 계산한다.
- 트럭은 진입→작업 완료, 본선은 스트림 계획 시작→야드 완료. 물리 체류와 혼동하지 않는다.
- 미완료는 제거하지 않고 창 끝까지 관측된 시간을 포함한다. 26시간 결과도 따로 보고한다.
- 반입·반출·양하·적하, 물량별, 모델별 결과를 모두 보존한다.
- 합계 평균은 오더 수 가중이며 15,000건 조건이 평균을 지배하는 정도를 명시한다.

## 판단과 다음 조건

분포 수정 전후의 같은 정책 성적 변화와, 각 조건 안의 정책 간 차이를 구분한다.
환경이 쉬워져 시간이 줄어든 것을 학습 성능 향상으로 부르지 않는다.
형태가 비슷해져도 누락된 몰림·상관관계·물리 보정까지 현실성 통과로 승계하지 않는다.
자료 대조와 제한된 입력 보정의 완료 여부를 판정하며 기존 i/f의 미확정은 유지한다.
추가 학습은 학습 자료/순위 진단과 환경 근거를 확인한 뒤 기존 323-d에서 한 축씩 수행한다.
새 기간의 독립 검증은 323-e에 남기며, 미확보 자료를 합성 시드로 대체했다고 주장하지 않는다.
