# 후보 수 입력 상한의 단일축 비교 — YR-332-s

2026-11-07. 사용자는 정책 개선 기법 설명 후 “응 진행해줘”라고 지시했다.
확인된 실패 기제인 8번째 입력의 18개 상한부터 분리해 학습·평가한다.
이는 현재 합성 환경의 제한된 진단이며, 현장 타당성이나 운영 채택 판정의 우회가 아니다.
기존 전역 게이트의 scenario 재계산 실패와 t/m/f/i 미해결은 그대로 기록한다.

## 고정할 것

- 원본 코드 기준 `600fe01b`, 기존 6단계의 최신 flow 설정(10입력·비용 차이 손실).
- 21블록·42크레인, 초기 적재율 0.65, 후보 제한 없음, 재배정 없음.
- 작업 종류·후보 생성·물리·안전·보상·3시간 비교·대안 하나 선택을 바꾸지 않는다.
- 기존 stage 5의 동일 선택 쌍·비용·정규화 목표에 STORE 입력을 붙여 stage 6을 재현한다.

## 유일한 처리 축

8번째 입력을 다음 세 가지로 비교한다. N은 해당 크레인의 실행 가능한 SERVE 후보 수다.

| 이름 | 입력값 | 역할 |
|---|---|---|
| clipped | min(N/18, 1) | 현재 설정의 정확 재현 |
| linear | N/18 | 기존 눈금을 유지하고 상한만 제거, 주 비교 |
| log1p | log(1+N)/log(19) | 큰 개수도 구분하는 완만한 표현, 보조 비교 |

18은 기존 코드와 동일한 고정 기준이다. 최적 수용량이나 실측 적정 부하를 뜻하지 않는다.
평가 자료에서 눈금을 추정하거나 결과를 보고 변환식을 고르지 않는다.
모든 후보를 원래대로 평가한다. 입력값 1을 넘는 것은 허용하며 후보 수를 제한하지 않는다.
모델 설정에 변환식을 저장한다. 옛 모델은 clipped로 복원한다. 기본값 변경은 별도 채택 판단이다.

## 동일 자료의 원래 후보 수 복원

기존 라벨에는 상한 적용 전 개수가 없다. 18 이상을 역산하거나 추정하지 않는다.
각 회차의 저장된 공통 행동 모델로 같은 입력일을 교사 없이 다시 실행한다(총 9회).
기존 라벨의 시각·블록·크레인·작업 ID에서 원래 개수만 읽는다.
모든 기존 입력 9개, 실제 선택, 하루 전체 선택 해시, 공식 비용 네 항·체류·투입·미완료가
저장 학습 실행과 같아야 한다. 하나라도 다르면 중단한다. 원래 선택 쌍·미래 비용은 재사용한다.
복원한 개수와 원자료 sha256을 보존하고 두 후보의 개수가 같은지도 확인한다.

## 학습과 평가

- 3변환×3초기 모델×3회차 = 27회 학습. 같은 회차의 자료·갱신 예산은 같다.
- clipped의 매 회차 가중치가 기존 flow 체크포인트와 정확히 같아야 한다.
- 모든 변환의 학습 전·마지막 모델을 평가한다. 좋은 중간 회차를 사후 선택하지 않는다.
- 같은 기존 평가 3일: 물량 3500/7500/15000, seed 9913900/9913910/9913920.
- 3변환×3모델×2시점×3일 = 54회, linear/log1p의 3500 첫 모델 최종 평가를 각 1회 반복.
- 최단 작업 SPT를 같은 3일에서 새로 실행한다. 총 새 평가 59회, 복원 포함 68회.
- clipped 학습 전/후 18회와 SPT 3회는 기존 후보·선택·사건·완료·장부·공식 결과와 정확 대조.
- 7개 규칙과 기존 pairwise 모델 결과는 이전 고정 자료를 명시적으로 재사용하며 해시를 검사한다.
- 이 3일은 이미 본 진단 입력이다. 미사용 날짜의 확증이나 9개 독립 날짜로 해석하지 않는다.

## 판정과 원자료

주 비교는 linear 학습 후 대 clipped 학습 후다. log1p는 사전 지정 보조 비교로 전부 공개한다.
날짜별 변화율을 계산해 모델·날짜를 같은 비중으로 평균한다. 부하별 결과와 9쌍 전부 보존한다.
같은 변환의 학습 전후 비교를 별도 공개해 표현 변경과 학습 효과를 혼동하지 않는다.
체류·비용·오래 기다린 트럭·24시간 미출차·26시간 야드 잔여·양하/적하 완료·본선 대기를 본다.
입력 평균이 좋아져도 투입 감소, 미완료 증가, 본선 완료 감소가 하나라도 있으면 채택하지 않는다.
성능 향상 후보는 체류와 비용 평균이 둘 다 감소하고 위 보호 조건이 전 쌍에서 통과해야 한다.
후보도 3대 연구 게이트의 성능 PASS나 현장 적용으로 자동 승격하지 않는다.
26시간 출차 잔여는 수집하지 않는다. 공식 24시간 출차 장부와 26시간 야드 완료를 구분한다.
본선 마감이 평가창 밖인 한 최종 출항 지연 개선을 주장하지 않는다.

기존 교사 비용의 외부 근거·정책별 투입 차이·예약 오차·양하 보정은 미해결이다.
