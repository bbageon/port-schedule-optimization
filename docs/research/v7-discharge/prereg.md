## 모형

미완 양하 수 = 본선에서 인출했지만 야드 적재 완료 전인 상자 수.
같은 블록의 미완 양하 수 합 ≤ 실행 프로파일의 운반차 대수.
기존 이송 모형과 적하 흐름은 유지하고, 운반차 대수 자체를 튜닝하지 않는다.
하루/월별 기본 크레인 경로 ON, 비교용 OFF를 명시적으로 제공한다.

유한 순환 물량의 집계 근사다. 차량 식별자별 왕복 궤적이나 실측 용량 모델은 아니다.
3대 기본값은 현재 코드값이며 문서의 6대와 다른 문제는 별도 보정 과제로 기록한다.

## 검사

- 같은 양하 입력에서 OFF/ON 및 야드 처리 지연을 비교한다.
- 1/3/6 용량을 진단한다. 이 결과로 최적 용량을 선택하지 않는다.
- 공유 용량·다른 선박 재개·완료 전 용량 미반환·복제/초기화·비용 적립을 검사한다.
- 기존 크레인 교사·하루/연속 실행 관련 시험을 실행한다.

## 지연 측정

- 현재 공유 신경망 9→64→64→1, CPU 1 thread, 난수 seed 9,903,320.
- 준비된 입력의 개별/일괄/분할 일괄 추론: 후보 12/100/1,000/10,000, 각 30회.
- 실제 후보 생성부터 특징·추론·충돌 해소까지: 12/100/1,000 오더, 각 10회.
- 준비 실행 3회. 최초 호출과 준비 후 중앙·95백분위(느린 쪽 5% 경계) 구분.
- 원시 시간, 실제 후보 수, 계산 환경, 점수 오차와 선택 일치를 저장한다.

- 실제 통신·TOS·새 집합 인코더·실시간 제어 마감은 미검증이다.
