# 날짜 모양 생성기 1차 입력 검증 — YR-332-ao

2026-11-15. 사용자 구현 승인. 정책·학습 변경 없이 입력 모양만 검사한다.

## 입력만 보고 고정하는 계약

- 이미 본 13일의 **오더**별 게이트 진입을 날짜×24시간 집계한다. 방문 수와 구분한다.
- 기존 식의 24시간 균등 기저와 세 봉우리(10시/1.5시간, 15시/2.5시간, 21시/1시간)를 유지한다.
  각 성분은 0~24시간 안에서 적분하여 정규화한다. 하루별 네 비중만 합이 1이 되게 적합한다.
  봉우리 위치·폭까지 한꺼번에 추정하지 않는다. 점심 감소·피크 이동 잔차는 숨기지 않는다.
- 날짜별 정규화 시간대 비중과의 제곱 오차를 최소화한다. 일별 총량은 곡선 가중치가 아니다.
  4성분의 모든 활성 집합을 탐색하는 제약 최소제곱으로 전역 최소를 구한다.
- 새 곡선: 서로 다른 개발 날짜의 적합 계수 둘을 균등 선택하고, 0~1 균등 혼합계수로 보간한다.
  이는 관측 범위를 벗어나지 않는 **합성 조건 설계 가정**이며 실제 날짜의 확률법칙 추정이 아니다.
  보간은 산포를 줄이므로 생성·관측 산포를 함께 보고한다. 관측 일별 벡터 자체는 재생하지 않는다.
- 학습용 곡선 24개, 선택용 6개, 잠금용 6개를 분리된 난수 이름공간에서 만든다.
  수량은 이번 입력 검사용 예산이며 학습에 충분하다고 주장하지 않는다.
  고정 대조 곡선은 학습용 24개 곡선의 점별 평균이다. 다른 분할은 평균에 쓰지 않는다.
- 시드: 곡선 은행 9934000, 실제 하루 9934100 + 100×분할번호 + 곡선번호.
  입력 검사: 학습 첫 3개와 고정 평균 × 3,500/7,500/15,000건. 반복 1개.
  동일 부하·곡선번호의 고정/변동 입력은 같은 사건 시드를 쓴다.
- 반출 확률, 시간대 안 형판, 방문 연결, 선박·초기 재고·정보 오차·학습은 기존 설정을 유지한다.
  다른 시각대로 옮겨진 오더의 방문 묶음은 기존 시간대별 연결 알고리즘에 따라 달라질 수 있다.
  이 차이를 숨기지 않고 방문 수·유형별 비중을 검사한다.

## 검사와 판정

- 같은 설정·시드의 곡선/입력 동일, 분할 간 곡선·시드 중복 없음, 고정 곡선=학습 곡선 평균.
- 확률 합 1·음수 없음·총 오더 보존, 반입/반출·블록·컨테이너·선박·재고 속성 보존.
- 예약 전건 존재, 공개 통지≤실제 도착, 완료 시각 미주입, 방문 용량·반입 우선 제약.
- 날짜별 적합 오차, 경계 계수, 날짜 하나 제외 시 범위/평균 변화, 생성 산포를 공개한다.
- 입력 적합성 기준: 각 개발 날짜의 곡선 잔차가 같은 총량의 표본잡음 95% 범위 안인지 검사한다.
  표본잡음 기준은 그 날짜의 적합 곡선에서 다항분포 1,000회 생성한 거리로 구한다.
  13일을 모두 충족해야 '현재 곡선 가족으로 날짜 모양을 표현했다'고 판정한다.
  통계적 확증·미사용 자료 검증을 뜻하지 않는다. 실패하면 입력 가족 수정이 다음 작업이다.
- 이 기준이 실패하면 정책 민감도·재학습을 진행해 채택 결론을 만들지 않는다.
  생성기는 진단 후보로 보존하고, 실패한 잔차를 ao에서 먼저 해결한다.
- 통과한 경우 고정 정책 민감도는 별도 실행 명세로 잠근 뒤 진행한다.
  이 단계는 신경망 성능 향상을 판정하지 않는다. 전체 현실성 미통과도 유지한다.

근거: [합성 설계](synthetic-demand-design.md), [선행연구](synthetic-demand-literature.md).

## 입력 결과에 따른 수정 1 — 같은 날, 정책 실행 전

최초 4성분 적합은 13일 모두 표현 기준 미달(잔차 4.34~13.49%p).
점심 감소·날짜별 피크 변화가 고정 세 봉우리로 표현되지 않았다. 실패 결과는 원형 그대로 보존한다.
입력만 보는 탐색에서 주기적 선형 곡선을 6/8/12/24개 시간 지점으로 비교했다.
통과 날짜는 0/0/3/13일이었다. 이에 **1시간 간격 24지점**을 후보 생성기로 동결한다.
로그 Fourier 1~8차 탐색도 했으나 최대 9/13일로 잔차 기준을 만족하지 못했다.
이 곡선 선택은 입력 자료를 본 뒤 한 수정이며, 처음부터 정한 사전 가설처럼 보고하지 않는다.

- 하루가 끝날 때 이어지는 삼각형 기저의 비중을 제약 최소제곱으로 적합한다.
  시간대별 평균은 곡선을 적분해 만든다. 양수·총량 보존·자정 연속성이 수식으로 보장된다.
- 시간대 안 실제 도착은 기존 ak 형판을 계속 쓴다. 연속 곡선이 분별 도착까지 대체한 것이 아니다.
- 두 날짜의 계수 보간·분할·고정 대조군 정의는 유지한다. 24개 곡선 계수는 정책의 입력 수와 무관하다.
- 24개 시간대 자료에 유연한 24계수를 맞췄으므로 좋은 잔차는 **표현 가능성** 근거다.
  실제 날짜 확률분포 추정·예측 타당성·새 날짜 일반화의 통과로 취급하지 않는다.
  보간에 따른 산포 감소와 작은 13일 표본의 한계를 별도 공개한다.
- 최초 입력 검사에서 반출 크기를 오더의 무작위 반입용 필드로 읽은 감사 코드 오류를 발견했다.
  반출은 실제 대상 컨테이너 크기로 검사하도록 고쳤다. 환경·오더 생성·방문 연결은 변경하지 않았다.

## 입력 결과에 따른 수정 2 — 새 배경 시드의 공급 부족

시드 9934102·15,000건은 원래 반출 요청 44건을 반입으로 바꿨다(기존 생성기의 fallback).
곡선 변경 전에도 발생하며 곡선 문제는 아니다. 이 상태로 작업 비율 보존을 주장할 수 없다.
전역 재고 생성기 수정은 at로 분리한다. 이번 은행은 아래 **재고가 성립하는 조건부 합성 상황**으로 제한한다.

- 36개 곡선을 모두 유지한다. 정책 실행 전에 각 배경 시드를 3개 물량 모두에서 확인한다.
- 반출 대상 부족으로 작업 종류가 바뀐 경우에만 배경 시드를 `요청 시드+1000×재시도 번호`로 다시 뽑는다.
  최대 20회다. 고정/변동 대조군과 모든 부하가 같은 최종 시드를 공유한다. 분할 간 중복을 금지한다.
- 모든 거절 시드·물량·블록·건수와 최종 시드를 저장한다. 유효하지만 혼잡하거나 느린 입력은 제외하지 않는다.
- 자료의 숨은 보정이 아니라 입력 도메인을 조건부로 제한한 것이다. 거절률과 이 선택의 한계를 공개한다.
  '모든 임의 시드에서 공급이 맞는다'거나 '고물량 실제 터미널을 대표한다'고 주장하지 않는다.
- 최초 검사 실패와 변경 이력을 보존한다. 정책 성능을 보고 시드나 곡선을 고른 적은 없다.
