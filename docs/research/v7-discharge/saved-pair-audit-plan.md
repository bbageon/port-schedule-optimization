# 저장된 비교 정답·체크포인트의 읽기 전용 재집계

2026-11-16. YR-323-d 명세가 허용한 저장 자료 진단. 새 학습·환경 실행·가중치 변경 없음.
ao의 고정 정책 실행과 별개로, 이미 저장된 aq 모델과 정답을 다시 읽는다.
이전 보고에서 정답 283쌍·현재 회차만 학습·마지막 회차 12~16학습 쌍을 알고 있다.

## 질문과 고정 계산

1. 각 회차의 결정 단위 분할을 원래 input_seed와 torch.randperm으로 복원한다.
   저장된 학습/검증 건수와 학습 직후 검증 정확도가 일치해야 한다.
2. 각 정답 쌍을 초기·그 회차 학습 직후·마지막 모델에 넣어 비용 차이의 부호가 맞는지 비교한다.
   원래 검증 기준과 같은 float32 및 |정답 차이|>1e-9를 사용한다. 동률 예측은 정답으로 세지 않는다.
3. 앞의 5회차 학습 자료에서 “직후 맞음→최종 틀림”, 반대 방향, 유지 수를 각각 센다.
   마지막 회차는 직후=최종이므로 망각 집계에서 제외한다.
4. 두 후보의 float32 입력이 완전히 같은데 비용 차이가 있는 쌍의 수를 센다.
   이런 쌍은 같은 입력만 보는 결정론적 점수망으로 구별할 수 없다. 대략 비슷한 입력을 같은 것으로 취급하지 않는다.
5. 반입/반출 등 후보 유형 조합별 정답 수와 순위 오류를 별도로 저장한다.

## 해석 제한

- 학습 자료의 순위 정확도는 터미널 운영 성능이 아니다.
- 회차 사이 정답 재사용이 없다는 코드 확인과, 실제 순위 변경 측정을 구분한다.
  이전 답을 잊은 사례가 있더라도 전체 재학습 성능 하락의 원인으로 확정하지 않는다.
- 검증 분할도 적은 저장 표본이며 최종 독립 날짜 평가가 아니다.
- 자료/최적화 횟수/신경망 크기를 늘리지 않는다. GAT나 PPO 우월성을 이 재집계로 주장하지 않는다.
- 모든 모델·정답·분할 코드의 해시, 개별 쌍 결과와 모델별 집계를 남긴다.
  결론에 따라 후속 실험은 기존 323-d의 한 축 비교로 설계한다.
