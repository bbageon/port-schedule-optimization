# 트럭 작업 완료 기준 — 2026-11-10 사용자 결정

주 지표와 보상의 트럭 시간은 **실제 게이트 진입→작업 완료**다.
작업이 끝난 후 출차를 늦추는 시간은 크레인 정책의 손실로 더하지 않는다.

| 사건 | 기록 | 의미 |
|---|---|---|
| 게이트 진입 A | `gate_in_s` | 트럭이 실제로 터미널에 들어옴 |
| 작업 완료 C | `job_done_s` | 해당 반입·반출 작업이 끝남 |
| 게이트 진출 O | `gate_out_s` | 트럭이 실제로 터미널을 나감 |

예를 들어 09:00 진입, 09:30 작업 완료, 10:00 출차이면 주 지표는 30분이다.
완료 후 출차까지 30분, 전체 게이트 체류 60분을 별도로 기록한다.
블록 도착과 작업 시작도 내부 사건으로 유지하므로 진입 주행·줄서기·작업 시간을 분해할 수 있다.

## 계산

- 관측 종료 T까지의 작업 처리시간: `max(0, min(C,T)-A)`. C가 없으면 T를 사용한다.
- 아직 진입하지 않은 오더는 그 시점의 평균 분모와 비용에서 제외한다.
- 작업 중인 오더도 T까지의 시간으로 포함하며, 이를 완전한 완료시간 평균이라고 부르지 않는다.
- 작업이 끝난 오더는 출차 기록이 없더라도 비용 증가를 멈춘다.
- 완료→출차: `max(0, min(O,T)-C)`. O가 없으면 T를 사용한다.
- 전체 게이트 체류 = 작업 처리시간 + 완료 후 체류. 합계는 동일 진입 집단에서 일치해야 한다.

| 출력 | 분모/뜻 |
|---|---|
| `mean_gate_to_job_done_s` | T까지 진입한 전건. 미완료도 관측분을 포함 |
| `n_job_censored` | T까지 진입했지만 작업이 안 끝난 건수 |
| `n_job_done` | T까지 작업이 끝난 건수 |
| `mean_job_done_to_gate_out_s` | T까지 작업이 끝난 건수. 미출차는 관측분 포함 |
| `n_exit_pending` | 작업은 끝났지만 출차하지 않은 건수 |
| `mean_turn_time_s` / `n_censored` | 기존 출차 기준 체류 / 미출차. 과거 열의 뜻을 바꾸지 않음 |

## 학습과 과거 결과

원화 평가·미래 비용 교사의 트럭 항과 통화 없는 PPO의 `truck_s` 모두 C에서 멈춘다.
기존 시간가치·할증 계수와 다른 비용 항은 유지한다. 이 수식은 실제 청구서를 재현하지 않는다.
PPO의 고정 정규화 눈금도 유지하고, **눈금의 원자료는 과거 출차 기준**임을 계약에 기록한다.
따라서 이번에 새 목적함수의 표준편차를 다시 추정한 것은 아니다. 정규화 변경을 동시에 하지 않는다.
크레인 교사의 두 대안 비용 차이 정규화는 기존 절차로 새 완료 기준 비용에서 계산된다.

계약 표식은 `gate-in-to-job-done-v1`이다. 과거 라벨·학습 재개와 혼합하지 않는다.
과거 동결 모델은 새 지표로 재평가할 수 있지만 새 목적함수로 학습했다고 표시할 수 없다.
과거 K 비교·예약 비교 산출물은 출차 기준 그대로 남긴다. 정의 변경으로 감소한 수치는 성능 개선이 아니다.

본선 양하·적하는 트럭 게이트 사건을 갖지 않는다. 기존 본선 작업 흐름·유휴 비용을 유지한다.
이 결정은 현장 도착·운반 시간의 실측 보정, 정책의 규칙 대비 우위를 증명하지 않는다.
