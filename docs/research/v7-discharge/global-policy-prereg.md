# YR-332-bc — 전역 대기 정보의 정책 효과 탐색 계약

2026-11-19. 사용자가 예측 오차 악화와 무관하게 같은 예산으로 정책 비교를 끝까지 진행하도록 명시했다.
이번 계약은 새 코드·입력·정책 실행 전에 고정한다. az의 이전 계약과 미통과 결과는 수정하지 않는다.

## 목적·허용 범위

전역 대기 정보가 비용 예측망을 통해 PPO(선택 결과에 따라 행동 확률을 갱신하는 강화학습)의 실제 정책 성능을 바꾸는지 확인한다.
예측 오차는 물량·시간대별로 기록하되 진입·중단 조건으로 쓰지 않는다. 비용·시간 악화도 그대로 보고하며 예산을 늘리지 않는다.
공통 진행 검사는 현실성 선결 미통과로 거절했다. 사용자 요청에 따른 제한된 합성환경 탐색으로 실행하고 거절·지시를 함께 보존한다.
운반 단계 i·대기 정의 f·고물량 자료 ap의 미확인 상태를 유지하며 실제 항만 효과나 정책 채택을 자동 주장하지 않는다.
물리·정보시점·장부 제약 또는 비정상 수치 오류는 계속 실패 처리한다. 유효하지 않은 실행을 성능 수치로 채택하지 않는다.

## 비교하는 한 축

- 두 조건은 `zero`(전역 입력 0)와 `global`(21개 블록의 작업 시작 대기 트럭 오더 합계)이다.
- 같은 확장 비용망을 사용한다. 추가 입력은 `log1p(total)/log1p(210)`이며 상한을 자르지 않는다.
- 동기화 시각의 스냅샷만 사용하며 각 결정 시각보다 늦은 정보는 금지한다. 전역값은 작업 선택망에 직접 넣지 않는다.
- 시작 모델은 ay 최종 PopArt 모델 9951101/9951102/9951103이다. 각 모델을 두 조건으로 복제하고 새 입력 열은 0으로 시작한다.
- 기존 정규화 누적 통계는 승계하고 Adam(가중치를 갱신하는 계산기)은 새로 만든다. 완전한 중단 재개 학습으로 부르지 않는다.
- Transformer 입력 10칸·너비32·헤드4·층2, 후보 무제한, 제약·비용·보상·작업완료 지표·시뮬레이터는 유지한다.
- 공유 표현과 선택망도 PPO로 함께 갱신한다. 비용 예측 손실을 통해 공유 표현이 바뀔 수 있다.
- 양쪽 모두 기존 PopArt 수식과 PPO 계수를 사용하며 부가 보상·교사·다른 규칙을 붙이지 않는다.

- 관측24시간·실행26시간, 초기 재고 보존, 재배정 없음, 후보·계획 재사용 옵션 유지.

- 매 갱신 당시 정책으로 모은 결정 중2,048개를 비복원 추출하고 4회 반복, 묶음64개로 학습한다.

- 학습률0.0003, PPO 비율 범위0.8~1.2, 비용망 손실계수0.5, 엔트로피계수0.01, 기울기 상한1, 할인1.

## 평가 시점·180개 고정 실행

1. 개발에서 초기 공통 모델3개×3입력=9회. 두 조건의 초기 가중치·출력 일치를 별도 확인한다.
2. 2·4·6번째 갱신에서 각6모델×3입력=54회. 6번째를 최종 모델로 사용하고 중간 최고점을 고르지 않는다.
3. 최종시험에서 최종6모델×9입력=54회, 학습 시작 모델3개×9입력=27회, 짧은 실작업 우선 규칙9회.
4. 예측 진단은 개발3입력에서 초기3모델·최종6모델을 확률 선택으로 각각 실행한다(27회).
   이 결과는 최고점 선택의 운영 성능표에 합치지 않는다. 정책마다 방문 상태가 달라 예측 차이를 순수 정보 효과로 단정하지 않는다.

합계180회. 운영 성능은 최고점 선택, 예측 진단은 확률 선택이다. 최종시험은 모든6모델 학습 종료 뒤에만 연다.
규칙은 새 입력에서 재실행한다. 주 비교는 최종 global 대 zero, 시작 모델 및 규칙과의 비교도 같은 입력에서 제시한다.
최종시험 첫 모델·첫 곡선·7,500건을 각 조건에서 한 번씩 더 실행한다(2회). 입력·후보·선택·사건·오더·장부 해시가 같아야 한다.

## 지표·집계·진단

- 1차 지표: 날짜·물량·시작 모델에 동일 비중을 둔 터미널 총비용. global−zero 짝 차이와 변화율을 보고한다.
- 작업별 반입·반출은 게이트 진입→작업완료, 양하·적하는 본선 작업 묶음의 계획 시작→개별 야드 작업완료다.
  본선 시간은 선박 전체 재항시간이 아니다. 트럭 전체·본선 전체도 함께 표시한다.
- 24시간까지 시작 기준 시각이 도래한 고정 오더 집단을 사용하고, 미완료는24시간까지의 경과시간을 포함한다.
- 선박 지연비용·24/26시간 미완료 건수를 함께 보고한다. 주 표는 날짜 평균이고 오더 수 가중 평균은 별도 보조값이다.
- 모델별·물량별 결과와 학습 시작→2→4→6회 추이를 공개한다. 성능 악화와 미완료를 숨기지 않는다.
- 예측 오차는 학습 표본의 갱신 전후 및 확률 선택 개발 평가에서 물량/6시간대별로 기록한다. 보상을 음수라는 이유로 없애지 않는다.
- 보조 불확실성: 물량을 먼저 평균한3곡선×3모델 짝 차이 표에서 두 축을 각각 복원 추출한다.
  시드10089900·10,000회, 2.5/97.5백분위. 이는 작은 합성 표본의 탐색 구간이며 현장 확증이 아니다.
- 채택용 공통 성능 판정은 규칙 대비 총비용과 본선·미완료·물리 조건을 별도로 검사한다. 탐색 완주와 성공을 구분한다.
