# 전역 대기 정보의 비용 예측 설명력과 조건부 정책 비교

등록일: 2026-11-18. YR-332-az 실행 설정이며 결과 관측 전에 코드와 함께 커밋한다.
사용자 요청: “이거 한번 검토해서 진행해볼래?” — 제시된 두 단계 합성 진단을 실행한다.

## 질문과 한 축

- Transformer 32너비·4헤드·2층, 후보별 10입력, 전체 후보, 작업 제약과 총비용을 유지한다.
- 비용 예측 입력에만 `log1p(전체 대기 외부트럭 오더)/log1p(21 * 10)` 한 칸을 더한다.
  분모는 `log(211)`이며 상한 절단은 없다.
- zero/global 두 군 모두 66→64→1 비용망을 쓴다. 추가 입력은 각각0/실측 스냅샷 요약이다.
- 기존65열 가중치를 복사하고 새 열은0으로 초기화한다. 선택망 입력은 늘리지 않는다.
- 선택망과 비용망의 공유 표현은 정책 학습에서는 기존처럼 함께 갱신된다.
  따라서 선택망이 전역값을 직접 읽지 않는 것과 비용 손실이 선택 학습에 영향을 주는 것은 다르다.
- 보상 단위368293633.7020551, 24시간 총비용, 26시간 물리 실행, PopArt 식·계수는 양 군 동일하다.
- 음수 상대평가 신호, 모든 비용 항과 단가를 유지한다. 본선·반출 보호 조건을 완화하지 않는다.

## 관측과 호환 계약

- 초기0 및 기존 review에서 공개 접수·원장 갱신 후 `kpis.waiting_count()`를 블록별로 저장한다.
- 활성 블록 시각 일치와 미래 시각 부재를 검사한다. 다른 블록 객체를 결정 도중 합산하지 않는다.
- 블록별 대기 수·합계·시각을 불변으로 보존하고 결정 때 마지막 관측만 사용한다.
- 대기는 블록 도착 후 서비스 시작 전 외부 트럭 **오더**이며 본선 대기·차량 방문 수는 아니다.
- 결정 블록은 동일 프로파일의 block_id가 아니라 실제 terminal의 simulator→block 대응으로 식별한다.
- 24시간 뒤 review는 기존처럼 생략한다. 배수 구간은 마지막24시간 관측을 유지하며 지연을 별도 집계한다.
- 학습 표본은 결정시각<24시간만 사용한다. 미래 도착·하루 총물량·최종비용은 입력으로 제공하지 않는다.
- 신규 경험 형식 v2는 원래 상태, 신경망 입력값, 관측 근거를 모두 보존한다. 누락·합계 오류는 실패한다.
- 구형 모델과 상태의 기본 경로는 유지하며 과거 실험의 소스 검사는 과거 커밋에서만 수행한다.

## 새 입력과 초기 모델

- 기존24시간 주기 합성곡선·일별 혼합·분 단위 몰림·방문 연결·초기 재고 보존 생성법은 유지한다.
- 새 곡선 bank seed=9964000, train13/selection3/holdout3. 이전두bank와 곡선 중복0을 검사한다.
- train0~11: 3500/7500/15000오더를 네 번 순환. 입력 seed=9964200+i.
- train12: 동작 시험 전용3500오더, seed9964212. 판정 표본에 넣지 않는다.
- selection0~2: 각 곡선을 세 물량에 교차해9입력. seed=9964300+i.
- holdout0~2: 각 곡선을 세 물량에 교차해9입력. seed=9964400+i.
- 모든 날짜는 독립 초기화한 합성 하루다. 12일 연속 운영이나 독립 실측 기간으로 부르지 않는다.
- 시작 모델: ay PopArt 최종 모델9951101/9951102/9951103의 가중치·정규화 통계.
  새 Adam을 사용하므로 완전 이어학습은 아니다. 양 군은 각각 동일한 시작 파일을 복제한다.
- 공통 경험 행동 정책은 첫 번호9951101의 ay PopArt 최종 모델로 고정한다.
  여러 모델을 비교해 행동 정책을 고르는 절차는 없다. 이 한 행동 분포에서의 설명력으로 한정한다.

## 1단계: 고정 정책의 공통 경험으로 비용 예측만 비교

- 12학습일+9검증입력을 고정 정책의 확률 추첨으로 실행한다. 행동seed=9965000+입력seed.
- 각 학습일1024개, 검증일2048개를 중복 없이 고정 난수로 뽑는다(seed=9966000+입력seed).
  부족하면 전부 사용하고 실제 수를 공개한다. 표본 수 때문에 날짜를 탈락시키지 않는다.
- 같은 경험과 같은 목표값을 두 군이 공유한다. 목표는 기존 -(최종비용−직전동기화비용)/고정눈금이다.
- 각 시작 모델의 선택망·공유 표현을 고정하고, 비용망만 학습한다. 표현을 미리 계산해 재사용한다.
- 학습 목표만으로 PopArt 통계를 한 번 갱신한다. 기존 학습 통계는 양 군 동일하게 승계한다.
  검증 목표·전역값으로 눈금을 맞추거나 재학습하지 않는다.
- 모델별 새 Adam lr0.0003, 묶음128, 200회 전수 반복, 기울기 상한1.
  섞기seed=모델seed+9967000, 양 군 같은 순서. 0/20/50/100/200회 오차를 기록하되200회만 판정한다.
- 1차 오차는 원래 보상 단위의 RMSE(큰 예측 오차를 더 크게 반영한 평균 오차)다.
  날짜별 MSE에 같은 무게를 준 뒤 평균·제곱근, 모델 세 개에도 같은 무게를 준다.
- 물량별·6시간 구간별 오차와 편향, 각 날짜·각 모델 차이를 모두 공개한다.
- **정책 실험으로 넘어갈 조건**: 전체 RMSE 5% 이상 감소, 모델3쌍 각각 감소,
  물량별 평균 오차 증가2% 이하, 6시간 구간별 증가5% 이하, 관측·고정 선택망 검증 모두 통과.
  이는 추가 정책 실험을 할 실용적 기준이지 문헌의 보장값·통계적 유의수준이 아니다.
- 기준 미달이면 이번 범위는 예측 진단으로 종료한다. 표본·학습량·임계값을 결과를 보고 늘리지 않는다.
- 예측 성공을 운영 성능 성공으로 해석하지 않는다. 이 검증 입력을 최종 정책 시험에 재사용하지 않는다.

## 2단계: 1단계 통과 때만 수행하는 PPO 비교

- 비용망 사전 진단에서 학습한 가중치를 사용하지 않는다. 두 군 모두 위 ay 모델에서 다시 시작한다.
- 초기값3쌍, 모델마다12학습일·6갱신, 갱신당 두 하루의 새 경험에서2048표본·4회 반복·묶음64.
- Adam lr0.0003, PPOclip0.2, 비용망 손실계수0.5, 엔트로피0.01, 기울기 상한1.
- 행동seed=모델seed+1000+day, 표본seed=모델seed+2000+갱신, 학습seed=모델seed+3000+갱신.
- 양 군 모두 동일 PopArt. 새 경험과 반환값은 각 정책의 실행 결과이므로 이후 달라질 수 있다.
- 전체 모델·Adam·정규화·난수 상태를 갱신 경계마다 저장한다. 마지막6번째 갱신만 최종 모델로 쓴다.
- selection9입력: 초기모델3개 및 최종모델6개, 최고점 선택. 중간 모델 선택은 하지 않는다.
- holdout9입력: 최종모델6개+SF_SPT 규칙, 총63회. 두 군 각1회 결정·장부 재실행을 추가한다.
- 주 지표는 날짜·모델 동일 가중 총비용. 같은 계산법으로 트럭·본선 평균과4종 작업 시간을 낸다.
- 미완료도 관측 종료까지 경과시간을 포함한다. 24/26시간 미완료·본선 지연비용·오더 가중 평균을 병기한다.
- 개선 후보는 모델3쌍 비용 감소와 전체 평균 트럭·반출·본선 평균·본선비용·미완료 비악화를 요구한다.
- 규칙 대비 비용·트럭·본선과 전건완료도 확인한다. 작은 합성 진단을 확증이나 현장 개선으로 부르지 않는다.

## 재현과 판정

- 기록만 추가한 동작 시험과 기존 경로의 후보·행동·사건·비용·난수 상태가 일치해야 한다.
- 고정 가중치에서 전역값만 바꾸면 선택 점수·확률은 그대로이고 비용 예측만 달라질 수 있어야 한다.
- 표본 원장·시간·전체 대기 합계·목표 비용을 다시 검산한다. 학습 가중치 재실행도 검증한다.
- 실행 코드·설정·입력·모델·결과 해시를 저장하고 Dashboard·보고서와 대조한다.
- Windows의 검증된 yr331-env torch2.14 CPU 사용, 병렬 최대6작업·각1스레드.
  조사 시 가용 메모리 약70GB이며3GB/작업 가정의6작업은 그80%보다 작다.
- 연구 게이트의 현실성 선결 거절을 authorization.json에 보존한다.
  이번 명시 요청으로 합성 진단만 실행하며 운반i/대기열f 미확인을 PASS로 바꾸지 않는다.
