# K=1·2·3·6시간 교사 비교 사전등록

2026-11-10. 사용자 요청: 시뮬레이션 시간 K 1·2·3·6 비교와 전체/업무별 체류시간 감소율.
작업 YR-323. 기존 환경의 하루 길이를 바꾸는 것이 아니라 **선택 이후 비용을 비교하는 교사 창**을 바꾼다.

## 범위와 승인

- 사용자가 직전 설명의 미래 비교 창을 네 값으로 직접 지정했다. 이 요청을 고정 합성 환경의 진단 실행 승인으로 기록한다.
- 현실성 보정 미통과는 유지한다. 이번 요청은 실항만 효과 확증이나 30일 잠금평가 승인이 아니다.
- research-gates의 일반적인 현실성 선행 순서를 이번 명시적 K 진단에 적용해 재승인을 요구하지 않는다.
- 정책 구조·환경·보상·후보·작업 배정·학습량은 바꾸지 않는다. 어떤 K도 결과를 보기 전에 채택하지 않는다.

## 통제 조건

- 모델 초기값 9914701·9914702·9914703, 10칸 입력·64×64 은닉층, pairwise SmoothL1·Adam.
- 각 K와 초기값마다 6회 갱신, 회당 50번 최적화. 부하 3500·7500·15000을 두 번 반복한다.
- 학습 입력 `9914800 + 100*초기값순번 + 10*갱신순번`.
- 행동 자료를 모으는 정책은 처음 가중치로 고정한다. K별 같은 결정·후보·개입을 비교한다.
- coverage 표집 최대 24결정/회. reachable 계약(실제 선택기로 고를 수 있는 대안)을 사용한다.
- 후보 상한 없음, 작업 계획 재사용·존재 검사 단축·외생 주문 보존 켬. 거래·재배정 끔.
- K는 3600·7200·10800·21600초. 실제 종료는 `min(결정시각+K, 93600)`.
- 끝부분에서 짧아진 창의 수·길이를 따로 보고한다. 창 뒤의 비용을 청구하거나 미래 가치를 추가하지 않는다.
- 비용 차이의 정규화는 기존 학습기와 같다. 표본별 비용 크기가 K에 따라 바뀌는 효과도 K의 영향이다.
- K=3은 독립 재검증된 기존 18개 자료·가중치를 파일 지문 확인 후 재사용한다.
- 새 K=1·2·6 학습은 모두 실제 재실행한다. 모든 72개 갱신 가중치는 원자료로 다시 학습해 정확히 대조한다.

## 평가

- 최종 6번째 가중치를 사전에 선택한다. 중간 성적을 보고 가중치나 K를 고르지 않는다.
- 평가 입력 3일×3부하, `9915900 + 100*일순번 + 10*부하순번`; 학습 입력과 다르다.
- 기존 연구에서 사용한 입력이므로 새로운 잠금 검증 자료라고 주장하지 않는다.
- K 네 값×모델 셋×입력 아홉 = 108회. 학습 전 27회·SF-SPT 규칙 9회 추가: 총 144회.
- 유형별 새 측정기를 달아 144회 모두 다시 실행한다. 이전 학습 전/K3/규칙 63회는 기존 결과·선택·사건 해시와 대조한다.
- K=1·2·6 각각 첫 모델·첫날·15000건은 새 프로세스로 한 번 더 실행한다(총 147회, 독립 표본 증가 아님).
- 평균은 모델 셋을 먼저 평균한 뒤 9개 입력을 동일 비중으로 평균한다. 부하별 값도 별도 보고한다.
- 감소율 기본은 `(학습 전 − 해당 K)/학습 전 × 100`. 양수는 개선, 음수는 악화다.
- 입력별 감소율의 평균·95% 구간과 전체 누적시간 비율을 함께 저장한다. 네 K 탐색 결과는 탐색적 진단이다.
- SF-SPT(실행 가능한 실작업 중 예상 작업시간이 짧은 작업 우선), 기존 K=3과의 차이도 계산한다.

## 시간 정의와 미완료

- 트럭 전체·반입·반출: 실제 게이트 진입→출차. 기본 관측 종료는 24시간, 26시간은 보조 확인.
- 양하·적하: **해당 본선 작업 시작 예정시각→개별 야드 작업 완료**. 배 한 척의 항만 체류시간이 아니다.
- 같은 본선 묶음의 모든 주문은 같은 시작점을 쓴다. 처리되지 않아 아직 야드에 안 온 양하도 분모에 남는다.
- 양하의 `release_time`은 실제 해제 시각이 아니므로 주 지표의 시작점으로 쓰지 않는다.
- 실제 야드 도착/해제→야드 완료는 보조 통계다. 도착한 오더 수가 정책별 달라질 수 있어 이것만으로 우위를 판정하지 않는다.
- 미완료 주문은 관측 종료까지 쌓인 시간을 포함하고, 업무별 미완료·미도착 수를 같이 보고한다.
- 모든 주문의 평균도 업무별 합계를 주문 수로 가중해 저장한다. 서로 다른 시작점의 혼합 지표임을 표시한다.
- 주 보고는 기존 연구와 같은 트럭 전체 평균과 네 유형별 평균/감소율이다. 혼합 평균을 트럭 체류시간이라 부르지 않는다.

## 검증·판정

- 시간 경계·미도착 양하·가중평균·잘못된 시각의 실패 테스트, 작은 별도 입력의 실제 실행.
- 표집 키·선택·특징·대안은 K=3과 정확히 같아야 한다. 실제로 관측한 종료시각 이후 비용이 없어야 한다.
- 주문 전수·입력 해시·시각 순서·원자료 집계, 가중치 72개 재학습, 재현 실행 3회.
- 성능 판정은 기존 규약대로 SF-SPT 대비 터미널 총비용과 완주·잔여·본선 보호·물리 가드를 함께 본다.
- 현실성 미확정과 해당 K의 채택 가능성은 분리 보고한다. 원자료·실패·불리한 결과를 삭제하지 않는다.
- 실행 코드/설정 clean commit, 모든 원자료 sha256, Dashboard/spec·원격 기록을 맞춘 뒤 완료한다.
