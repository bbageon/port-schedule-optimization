## 한 축의 수정

1. GateIn TSS/VBS 요청에서 `(컨테이너, 차량, 방향, gateInTime)`을 연결한다. 방향1/FR은 반출,2/TO는 반입이다.
2. CSV의 진입 시각과 같은 원본 `gateInTime`이 있으면 확인된 시각이다. 다른 메시지의 명시 시각도 인정한다.
3. 원본 `gateInTime`은 없고 로그 시각만 맞으면 `log_only`로 분리한다. 다른 시각의 실제 진입을 끌어와 덮어쓰지 않는다.
4. 원본·CSV의 깨진 시각/식별키 충돌은 실패로 처리한다. 원본 요청 자체가 없으면 미확인으로 분리한다.
5. `error=true`만으로 제거하거나 `error=false`만으로 실제 진입을 인정하지 않는다.
6. 미확인 방문 행은 `outputs/private/yr332_gate_time_provenance/`에 보존한다. git에는 익명 집계만 올린다.
7. 새 예약·통지 profile은 기존 v1 형식에 출처 계약을 추가한다. 기존 profile을 덮어쓰지 않는다.
