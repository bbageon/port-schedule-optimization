# 합성 입력과 학습 구조의 네 단계 비교

2026-11-16. 사용자 요청: 다음 순서 1~4를 모두 실행한다. 각 축은 따로 판정한다.
현장 채택·PPO 전환이 아니라 사용자 요청에 따른 합성 환경의 진단 실험이다.
기본 정책과 과거 산출물은 보존하고 새 경로를 명시적으로 선택한다.

## 1. 날짜별 반출 비율 (YR-332-ao)

- 기존 13일 집계의 날짜별 반출 비율을 사용한다. 새로운 원본 기간은 열지 않는다.
- 하루 곡선을 만든 두 부모 날짜와 동일한 혼합계수로 반출 비율도 보간한다.
  시간대 모양과 작업 비율의 관측 연관성을 임의로 끊지 않는 조건 설계다.
- 고정 대조 비율은 학습용 24개 비율의 평균. 기존 53.75%와의 평균 차이는 따로 보고한다.
- 학습/선택/평가 24/6/6개 × 3,500/7,500/15,000건의 입력 계약을 확인한다.
- 첫 학습 곡선 3개 × 세 물량 × 고정/변동 비율 × SF_SPT/FIFO/LWKR = 54회.
- 두 팔은 하루 곡선·시드·분별 생성법·물리·정책이 같다. 비율 변경에 따른 재고 배치·방문 구성 변화는 기록한다.
- 총 오더·요청 작업 종류·공급·차대 용량·선후관계·예약 사건 순서 위반은 0이어야 한다.

## 2. 수식 기반 분별 방문 도착 (YR-332-ar)

- 하루 곡선·작업 비율·시간대 방문 수는 고정하고 시간대 안 시각만 바꾼다.
- 후보: 독립 균등 도착, 대칭 Dirichlet 분별 비중에서 뽑는 조건부 도착.
  후자는 60개 Gamma 난수를 정규화한 분별 비중에 고정 방문 수를 배분한다.
  실제 분별 배열은 보정 통계 계산에만 쓰며 생성기 설정에 내장하지 않는다.
- 집중 매개변수는 날짜×시간의 방문 수 n과 분별 수에서 구한 이차 모멘트로 추정한다.
  E[Σ c(c−1)/(n(n−1))]=(α+1)/(60α+1). 독립 모형은 α→∞.
- 개발 자료의 날짜×시간 방문 수를 그대로 둔 합성 반복 100개로 1분/10분 산포와 인접 분 상관을 검사한다.
  모형 선택 기준: 산포 절대 오차 각각 ≤0.10/0.15, 인접 분 상관 절대 오차 ≤0.05.
  독립 모형이 모두 통과하면 우선 채택, 아니면 Dirichlet 후보. 둘 다 실패하면 실패를 기록한다.
- 조건부 고정 건수이므로 무조건부 Poisson 과정이라고 부르지 않는다. 고물량 외삽 한계는 남긴다.
- 첫 세 곡선·세 물량에서 기존/선택 모형 × SF_SPT/FIFO = 36회. 입력 전체 보존·재현 및 원자료 시간 검산.
- 공개 합성 설정에는 집계 매개변수와 출처를 기록한다. 보정에 실제 통계를 쓴 사실은 숨기지 않는다.

## 3. 학습 방식 진단 (YR-323-d)

- 먼저 저장된 aq 자료의 원래 분할·초기값을 고정하고 현재 회차 50회 / 누적 자료 50회 /
  현재 회차 200회를 각각 비교한다. 이전 자료 재사용과 반복 횟수 효과를 분리한다.
- 학습/검증 분할은 원래 회차의 결정 단위로 고정하며 검증 쌍을 누적 학습에 넣지 않는다.
- 새 합성 입력에서 후보 전체의 현재 10개 특징을 저장한 비교 정답을 추가 수집한다.
  행동 정책은 고정 MLP, 미래 비용 창 3시간, 실행 가능한 대안, 보상·물리 동일.
- 새 자료 예산·입력·초기값·분할·갱신 횟수는 수집 전에 별도 실행 설정으로 고정한다.
- 정답 수와 갱신 수를 각각 따로 비교한다. 최종 평가 결과를 보고 설정이나 예산을 늘리지 않는다.
- 순위 정확도·정규화 회귀오차·앞 회차 유지와 실제 운영 결과를 구분한다.

## 4. 같은 정보의 신경망 비교 (YR-332-as)

- 기존 후보별 MLP → 후보 집합의 평균 정보를 함께 읽는 작은 망 → 자원 중심 Attention 관계망.
- 두 맥락망은 동일한 후보 전체의 현재 10개 특징·같은 정답·같은 분할·같은 갱신 예산을 받는다.
  후보별 MLP 대 맥락망은 정보 접근 효과가 섞이므로 구조 우열의 주 비교로 쓰지 않는다.
- 관계는 같은 크레인에 작업을 요청하는 후보→자원 중심→후보인 별 모양이다.
  방문 선후관계까지 표현한 이종 그래프나 원 논문 GAT 전체 재현으로 부르지 않는다.
- 후보 제한 없음, 후보 순서에 대한 일관성·다른 결정 간 정보 혼입 금지·저장/복원·실행 배선을 검사한다.
- 모든 후보 쌍을 연결하는 제곱 계산 대신 후보 수에 비례하는 자원 중심 집계를 사용한다.
- 세 초기값·고정된 새 합성 평가일에서 기존 규칙, 학습 전/후, 맥락망을 비교한다.
  손실만으로 채택하지 않고 4종 작업 시간·미완료·본선·후보 보존·전체 결정 지연을 보고한다.

## 판정과 근거

입력과 코드·원자료 정합, 합성 조건 안의 성능, 현장 현실성을 분리한다.
운반·대기열 등 외부 근거 미확인은 계속 유지한다. 자동 게이트 결과는 변경·완화하지 않는다.
3·4는 사용자의 명시적 네 단계 실행 요청에 따른 제한된 진단이며 현장 성능 주장 근거가 아니다.
단일 시드 최고 성과를 채택하거나 최종 평가를 재학습 입력으로 돌려 쓰지 않는다.

- [기존 합성 입력 근거](synthetic-demand-literature.md)
- [Deep Sets](https://arxiv.org/abs/1703.06114): 순서에 의존하지 않는 집합 표현.
- [Graph Attention Networks](https://arxiv.org/abs/1710.10903): 이웃의 중요도를 학습하는 집계.
- [NumPy Dirichlet 문서](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.dirichlet.html):
  Gamma 난수의 정규화로 구성하는 확률 벡터. 항만의 수치 근거는 별도 개발 통계다.
