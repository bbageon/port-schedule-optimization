# YR-332-i — 양하 완료 하한 보정의 비교 계약

2026-11-09. 시간 관계 감사 `48e8feb2` 뒤, 보정 실행 전에 고정한다.

## 확인한 오류

현재 3대·470초, 안벽 작업 간격 3600/27.5초에서 1·2·3박스는
130.909·261.818·392.727초에 본선 인출을 마친다. 기존 하한은 각각
156.667·313.333·470초여서 실제 가능한 완료보다 늦다. 회귀 시험 3건에서 재현됐다.
평균 운반 공급 간격을 처음부터 적용해, 첫 차량들의 동시 가용성을 무시한 결과다.

## 수정 범위

양하 본선 완료는 마지막 안벽 인출이다. 마지막 상자의 야드 적재 완료와 구분한다.
버퍼·공유 인계 상태를 받지 않는 기존 하한 함수에서는 양하에 안벽 작업 간격 하한만 쓴다.
이 하한은 필요조건이며 달성 가능한 계획의 보증이 아니다. 더 강한 자원 하한은 실제 인계 계약 후다.
적하 추정식·물리 처리시간·운반 대수·공유 인계 상한·정책·보상은 바꾸지 않는다.

## 검증

1. 앞선 7조건과 반복 1회를 동일하게 실행한다. 단일 블록·1개 야드크레인 시험 무대이며
   운반차는 H-21의 3대·470초, 안벽 간격은 3600/27.5초다. 실터미널 대표 표본이 아니다.
2. 새 양하 하한이 실제 완료를 넘는 반례는 0이어야 한다.
3. 사건·작업 시각·완료·유휴·적재 수지는 보정 전과 정확히 같아야 한다.
4. 기존 하루 입력 3,500/7,500/15,000건(시드 9913900/9913910/9913920)의
   주문·물리 입력·계획 마감·출항 시각이 같아야 한다. 하한 진단값과 버전 표기만 분리한다.
5. 짧은 작업 반례·공유 차량·야드 정지·복사 세계·주문 보존 회귀를 실행한다.

운반시간을 실측 보정하거나 새 학습을 수행하는 실험이 아니다.
실제 투입 대수·주행·인수/귀환 시간 자료가 없는 한 현실성 전체 통과는 보류한다.
