# 실제 트럭 방문 단위와 시간대 안 도착 몰림의 고정 정책 진단 — 2026-11-13

## 질문과 범위

aj는 작업 비율과 24시간 비중을 맞췄지만 시간대 안에서는 오더를 고르게 배치했다.
ak는 먼저 원자료의 방문·오더 단위를 확정하고, 그다음 **시간대 안 도착 간격 한 축만** 바꾼다.
학습 효과 확증·터미널 전체 재현·현장 성능을 주장하는 실험이 아니다.
2026-10-28~11-09의 13일은 이미 열람한 개발용 자료다. 같은 자료로 만든 입력을 독립 검증으로 부르지 않는다.

## 결과를 보기 전에 고정한 정의

원자료 읽기 전용 감사(`outputs/reports/yr332_visit_arrivals/visit-unit-audit.json`)로 정했다.

- `visit_id`는 오더 키다. 진입 기록 34,304건 모두 `진입 시각_트럭 앞 8자리_컨테이너_방향`이다.
- 게이트 기록 = 같은 트럭·같은 진입 시각의 행 묶음(28,265개).
- 재처리 기록 = 블록 진입·작업 완료·출차가 하나도 없고, 30분 안에 같은 트럭의 다음 진입이 있는 기록.
  850개(같은 컨테이너 716개)이며 원자료 행은 지우지 않는다.
  30분은 간격 분포의 꺾임이다(1분 373, 5분 723, 10분 801, 30분 850). 10분·60분 기준의 방문 수도 함께 보고한다.
- 실제 방문 = 재처리 기록을 뒤 기록에 붙인 묶음(27,415번). 도착 시각은 실제로 들어간 기록의 진입 시각이다.
  같은 트럭의 방문끼리 터미널 체류가 겹치는 경우는 3건뿐이다.
- 여러 오더 방문은 5,492번이다. 출차 시각이 같은 묶음이 4,944개이고, 다른 106개도 차이가 281초 이하다.
- 방문 안 작업 순서는 관측값으로만 적는다. 같은 블록 반입+반출은 반입 완료가 먼저인 경우가 1,716 대 21이다.
  이 순서를 선후 제약으로 구현하지 않는다.
- 진입 후 취소 210건(0.6%)은 원자료에 남긴다. 물리 취소는 구현하지 않는다.
- 트럭 지표는 그대로 오더별 진입→그 작업 완료다. 방문 전체 완료 지표로 바꾸지 않는다.
- 합성 무대의 오더 1건 = 트럭 1대 계약은 그대로다. 여러 오더 방문의 연결은 별도 연결 계약 과제로 남긴다.
- 재처리 기록 제거가 aj의 반출 비중·시간대 비중에 주는 변화는 0.21%p 이하이므로 aj 보정값을 유지한다.

합성 트럭 한 대는 실제 방문 한 번에 대응시킨다. 따라서 몰림 기준은 오더가 아니라 **실제 방문**이다.
실제 오더 단위의 큰 몰림(1분 지수 1.772)에는 한 트럭의 여러 컨테이너가 같은 시각에 찍힌 효과가 들어 있다.
이 차이는 연결 계약 없이 재현하지 않는다.

## 고정한 세 조건

1. `observed_mix_hours`: aj 최종 입력. 시간대 안에서 고르게 배치한다.
2. `observed_hours_poisson`: 각 시간대의 건수는 같고 시간대 안에서는 서로 독립인 균등 시각이다.
3. `observed_hours_visit_minutes`: 같은 시각대의 실제 날짜별 분당 방문 수를 무작위 날짜 순서로 통째로 쌓는다.
   마지막 날짜만 필요한 수만큼 뽑고, 분 안에서는 균등 시각을 쓴다.

1→2는 고른 간격에서 무작위 간격으로, 2→3은 무작위에서 실제 몰림으로 바뀐다.
시간대별 건수, 오더 순서, 유형·블록·반출 대상·규격·주행, 예약 보정, 물리, 정책은 같다.
난수는 `h21d:within:<방법>:<입력 시드>:<시각>`로 고정한다.

물량이 실제보다 많으면 같은 시각대의 실제 날짜를 여러 개 겹친다.
따라서 날짜마다 공통인 시간대 안 패턴은 물량과 함께 커진다고 가정한다.
3,500건만 관측된 시간당 방문 수 범위 안이다. 7,500·15,000건은 이 가정에 따른 외삽이다.
등록 전에 입력 통계만 시험했고 정책은 실행하지 않았다.
시험값의 1분 지수는 3,500건 약 1.28, 7,500건 약 1.76, 15,000건 약 2.17이었다.

## 입력 대조 기준 — 정책 실행 전에 판정

실제 방문 기준값: 1분 지수 1.266, 10분 지수 1.182, 정규화 도착 간격 변동계수 1.176.
지수는 각 날짜·시각 안 같은 폭 구간 건수의 분산/평균이며 aj와 같은 정의다.

- 3,500건 조건 3은 세 값의 차이가 각각 0.10, 0.15, 0.10 이하여야 한다.
- 미달하면 정책을 실행하기 전에 방법을 고치고, 고친 경위를 남긴다.
- 7,500·15,000건은 같은 통계를 보고만 한다. 관측 근거가 없으므로 합격 기준을 두지 않는다.
- 반입·반출 동시 유입(1분·10분 구간 건수 상관)은 실제 0.336·0.285와 나란히 보고한다.
  실제 값에는 한 트럭의 반입+반출이 들어 있어 이번 축으로 맞추지 않는다.
- 공통 검사: 오더 보존, 유형·대상·블록 동일, 시간대별 건수 동일, 반출 대상 고갈 0,
  통지 ≤ 도착, 시각 순서 유지, 실제 날짜 재사용 0. aj 입력은 저장 지문과 같아야 한다.

## 정책·실행 예산

- 입력 시드는 aj와 같다: 3,500 → 9921100, 7,500 → 9921110, 15,000 → 9921120.
- 정책 13개: 규칙 7개(SF_SPT·FIFO·LIFO·SPT·NEAREST·LWKR·RANDOM)와 저장 3모델의 학습 전·후 가중치.
- 3조건 × 3물량 × 13정책 = 117회에 반복 3회를 더해 총 120회다.
- 반복 대상은 조건 2 SF_SPT, 조건 3 SF_SPT, 조건 3 첫 학습 후 모델이며 모두 7,500건이다.
- 조건 1의 39회는 aj 저장 결과와 비트 단위로 같아야 한다. 이것이 코드 변경 전후의 동일성 검사다.
- 기록 창 24시간, 엔진 26시간, 후보 전체. 학습·보상·물리·예약 오차 보정값은 바꾸지 않는다.
- 독립 실행 최대 12개, 실행당 계산 스레드 1개. 실패·부분 기록을 덮어쓰지 않는다.

## 보고와 해석 규칙

- 트럭 진입→작업 완료(24시간 검열, 미완료 포함), 반입·반출·양하·적하, 물량별, 모델별, 미완료 수, 26시간 결과.
- 같은 정책의 조건 간 변화(환경이 바뀐 효과)와 같은 조건 안의 정책 간 차이를 구분한다.
- 핵심 비교: 조건마다 학습 후 모델 대 SF_SPT, 학습 전 대 학습 후의 차이가 어떻게 바뀌는가.
- 몰림 때문에 시간이 늘어난 것을 학습 성능 저하로 읽지 않는다. 기존 채택 판정은 바꾸지 않는다.
- 평균은 오더 수 가중이다. 15,000건이 평균을 지배하는 정도와 물량별 결과를 함께 적는다.
- 물량별 입력이 하나이므로 통계적 유의성·일반적 우위를 주장하지 않는다.
- 성능 게이트는 새 학습이 없는 환경 민감도 진단이므로 INCONCLUSIVE로 둔다.
- 현실성은 시간대 안 도착 간격 한 축의 보정 여부만 판정한다.
  방문 연결·날짜 간 변동·반입/반출 시간대 결합·본선 운반(i)·대기열 정의(f)는 남는다.

## 정정 — 입력 판정 뒤, 정책 실행 전 (2026-11-13)

첫 방법(날짜를 무작위 순서로 쌓기, `283eaa26`)의 3,500건 입력 판정 결과는 다음과 같다.
1분 지수 1.309(통과), 10분 지수 1.184(통과), 도착 간격 변동계수 1.073으로 기준 1.176과 0.103 차이다(미달).
원자료는 [첫 판정](../../../outputs/reports/yr332_visit_arrivals/input-preflight-draft-random-order.json)에 보존했다.

- 원인: 합성 3,500건 하루는 관측된 어느 날보다 트럭이 많다(실제 방문 최대 2,884번/일).
  가장 바쁜 날짜를 써도 24개 시각대 중 22개는 두 날짜 이상을 겹쳐야 한다.
  겹치면 절대 시간의 몰림은 유지되지만, 평균 간격에 대한 상대적 몰림(변동계수)은 묽어진다.
  무작위 순서는 주말처럼 한가한 날짜까지 섞어 겹치는 날짜 수를 더 늘렸다.
- 위 '3,500건만 관측 범위 안'이라는 문장은 틀렸다. 시각대별로는 2개만 한 날짜로 채울 수 있다.
- 수정(원칙으로 결정, 한 번만 재판정): 그 시각대에 방문이 가장 많은 날짜부터 쌓는다(`busiest_first`).
  물량이 가장 비슷한 실제 날짜를 쓰고 겹치는 날짜 수를 최소로 한다. 동률은 고정 난수 순서로 정한다.
  기준값·허용폭·다른 조건·정책·실행 수는 바꾸지 않는다.
- 재판정에서도 미달하면 그 사실을 공개하고 진행한다.
  이 경우 결과 해석에 '짧은 간격의 상대적 몰림은 실제보다 약하다'는 한계를 적는다.
