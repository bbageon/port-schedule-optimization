# 적하 최소 완료시각의 내부 계산 검증

2026-11-21 · YR-332-i(본선 운반 시간·용량 보정)의 미검증 적하 계산 범위.

## 목적과 범위

현재 `phys_min_completion_s`가 실제로 실행 가능한 완료시각보다 늦게 나오는지 검사한다.
최소 완료시각은 그보다 빨리 끝낼 수 없다는 **하한**이며 달성 가능한 마감의 보증이 아니다.
양하 하한은 11/09에 보정했지만 적하의 유한 차량 수 계산은 아직 검증하지 않았다.
외부 자료가 없어도 내부 사건 순서와 산술은 확인할 수 있다.

3대·470초를 실측값으로 바꾸거나 정책·보상·도착곡선을 조정하지 않는다.
실제 투입량·인계·귀환 정의와 대기열·고물량 자료의 외부 대기는 유지한다.
학습과 정책 성능 비교는 이번 범위 밖이다.

## 결과를 보기 전에 고정하는 검사

- 기존 단일 크레인 시험 프로파일, 재취급 없는 적하 상자, 시드 0.
- 운반 지연 470초, 본선 처리 간격 3600/27.5초.
- 단일 본선: 차량 1/3대 × 작업 1/2/3/4/8/32개 = 12조건.
- 공유 운반: 본선 2개 × 각 8작업, 차량 1/3대 × 야드 정지 0/1200초 = 4조건.
- 시각 이동: 시작 600초, 3대, 작업 1/3개 = 2조건.
- 총 18조건과 마지막 조건의 정확 반복 1회. 평가창 32000초, 모든 작업 완료 확인.
- 적하 작업의 공개 시점은 생성기와 같이 본선 시작 + 작업 순번 × 본선 처리 간격이다.
- 매 조건에서 대상 목록을 준 하한과 대상 미제공 하한을 모두 실제 완료시각과 비교한다.
- 작업 완료·운반 도착·본선 처리 기록, 자원/장부 불변식, 반복 일치 여부를 저장한다.
- 실제 완료가 하한보다 1e-8초 이상 빠르면 산술 반례로 기록한다. 반례를 삭제하지 않는다.

## 반례가 발견되면

유한 차량의 동시 운반을 고려한 보수적인 하한으로 계산 한 곳만 수정한다.
같은 조건을 재실행해 물리 사건·작업 완료·비용이 변하지 않는지 비교한다.
차량 공급과 본선 처리의 독립적인 이산 사건 계산으로 보정식을 추가 검증한다.
기존 본선 하한·운반·발생기 관련 회귀검사를 수행한다.
최신 정책 비교에서 사용한 9개 합성 입력의 물리 설정·작업·마감·출항시각 영향을 확인한다.
마감이 달라지는 입력이 있으면 과거 성능과 직접 비교하지 않으며 영향 범위를 보고한다.

하한 보정의 성공과 운반 모델의 외부타당성은 별개다. 후자는 실제 자료 없이 통과 처리하지 않는다.
