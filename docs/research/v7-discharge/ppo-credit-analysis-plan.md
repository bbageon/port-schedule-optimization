## 범위와 권한

- 사용자 요청: 물량·시각별 비용 예측 오차, 같은 상태의 작업 순위·확률, 긴 대기의 입력 상한을 확인한다.
- 이전 실행 e5e24f2236b58f33ddefb8ab2bfb4908fd0cafc1의 저장 파일만 읽는다.
- 두 구조(MLP, Transformer), 초기값 9951101/9951102/9951103, 각각 6회 갱신의 2,048표본 전수:
  총 36개 자료 묶음·73,728개 결정 상태다. 같은 12개 입력을 여러 모델이 경험한 것이며 독립 72일이 아니다.
- 새 시뮬레이션·학습·보상/정책 수정·잠금 평가를 하지 않는다. 검사기의 현실성 선결 거절을 보존한다.
  이번 읽기 전용 진단은 현재 사용자의 명시 요청 범위다. 기존 성능·현실성 판정을 승격하지 않는다.

## 측정 정의

1. 원래 선택의 로그확률과 가치 예측을 갱신 직전 모델에서 재계산한다.
   일별 최종 비용과 기록된 과거 비용으로 목표 `-(최종-과거)/고정눈금`도 검산한다.
2. 목표에서 당시 예측을 뺀 값과 학습에 실제 쓰인 표준화 신호를 복구한다.
   원래 구현처럼 두 날 2,048표본을 함께 표준화하며 순열·float32 계산도 재현한다.
   구조/초기값/갱신/물량/6시간 구간별 오차·양수 신호 비율을 낸다.
   같은 갱신의 두 날 평균 차이가 설명하는 신호 분산과, 6시간 구간을 나눈 뒤의 비율을 함께 낸다.
   후자는 시간대를 일부 구분한 기술 통계이며 행동 인과 효과의 추정이 아니다.
3. 같은 저장 상태에서 갱신 직전→직후, 최초→최종 모델을 비교한다.
   주 분석은 **첫 번째로 선택지가 둘 이상인 단계**다. 앞선 강제 선택의 경로는 동일하다.
   뒤 단계의 마스크는 원래 행동에 의존하므로 새 공동 배정으로 오인하지 않는다.
   작업 종류별 확률 합, 원래 선택의 확률·동률 중간 순위, 최상위 작업 변화,
   반입/반출이 함께 가능한 상태의 반입 조건부 확률을 측정한다.
4. 그 단계의 실행 가능한 외부 트럭 실작업에서 대기 입력 2시간에 붙은 후보를 센다.
   후보 비중과 상태 비중을 구별하고 물량/시간대/종류별로 나눈다.
   상한에 붙은 후보와 나머지가 함께 있을 때 선택 확률 변화를 측정한다.
   원래 2시간 초과 대기·작업 ID는 저장되지 않았으므로 상한 제거의 성능 효과는 측정할 수 없다.
5. 각 갱신 첫 미니배치의 행동·가치·탐색 손실 기울기를 6모델 모두에서 분리한다(36배치).
   가중치를 갱신하지 않는다. Transformer 공통 부분도 별도 측정한다.
   첫 배치는 전체 최적화 과정의 대리물이 아니며 Adam 이후 실제 이동량과도 다르다.

- 후속 수정은 가장 일관된 관측 하나를 겨냥한 작업으로 등록한다. 이번에 실행하지 않는다.
