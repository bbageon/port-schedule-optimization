# 공용 외부 장치장 연구 — 실험 설계와 판정 기준

> [연구 설계안](../../../busan_port_buffer_rl_experiment_design.md)의 상세 제안.
> 비용·제약·정보 경계: [문제 정식화](01-problem-formulation.md). 아래 항목은 수행 결과가 아니다.

## 1. 효과를 구분하는 비교 구조

장치장 이용이라는 물류 운영방식, 강화학습 알고리즘, 사전정보의 효과를 각각 식별한다. 모든 비교에서 외생 화물 수요·초기 상태·터미널 내부 작업 규칙은 동일하게 유지한다.

| 질문 | 대비 | 해석 |
|---|---|---|
| 장치장 이용의 효과 | 규칙 기반 장치장 정책 − 직접 반입 | 추가 시설·운송을 포함한 운영방식의 순효과 |
| 강화학습의 추가 효과 | RL − 동일 정보의 강한 비학습 정책 | 같은 권한·정보에서 학습 의사결정이 제공하는 가치 |
| 차량 사전정보의 효과 | RL 현재 관측+통지 도착정보 − RL 현재 관측 | 정보 추가의 효과. 알고리즘·자원은 고정 |
| 본선 계획정보의 효과 | RL 차량 사전정보+본선 계획 − RL 차량 사전정보 | 본선 정보만 추가한 효과 |
| 용량·오차에 대한 강건성 | 같은 정책군을 사전 지정 조건별로 비교 | 어떤 조건까지 비용·서비스 기준이 유지되는가 |

비용 차이가 음수면 앞 정책이 유리하다. 규칙과 RL의 정보가 다르면 **정보 차이와 학습 효과가 섞이므로** 강화학습의 우월성을 판정하지 않는다.

## 2. 완결된 비교 정책

| 정책 | 최초 경로 선택 | 장치장 출고 |
|---|---|---|
| 직접 반입 | 지정 터미널 직접 반입만 허용 | 해당 없음 |
| 장치율 임계 정책 | 목적 터미널 장치율이 설정 문턱 이상일 때 경유 | 장치율이 출고 문턱 이하일 때 실행 가능한 화물을 마감 순서로 출고 |
| 대기시간 임계 정책 | 현재 관측에서 추정한 터미널 대기가 문턱 이상일 때 경유 | 예상 대기가 출고 문턱 이하일 때 마감 순서로 출고 |
| 예측 기반 비용 비교 정책 | 직접 반입과 경유의 예상 증분 시스템 비용을 비교 | 계속 장치와 즉시 출고의 예상 증분비용을 비교 |
| 강화학습 정책 | 실행 가능한 두 경로의 장기 비용을 학습하여 선택 | 동일 후보·자원 제약에서 계속 장치 또는 출고 대상 선택 |

마감 순서는 납기일 우선 규칙(earliest due date, EDD: 여기서는 반입 마감이 가까운 화물부터 처리)으로 정의하고, 동률이면 최초 통지순·식별자순을 적용한다. 이는 **출고 순서 규칙**이지 경로 선택 알고리즘의 이름이 아니다.

대기시간 임계 정책을 “최단 대기열(shortest queue)”로 부르지 않는다. 목적 터미널은 고정돼 있고 터미널과 장치장의 처리능력도 달라서, 대기 대수만 비교하는 최단 대기열 배정과 다른 정책이다.

임계값·출고 검토주기·예측기간은 학습·검증 자료로 정한 뒤 고정한다. 장치율 90%는 조사 없이 공통 기준으로 확정하지 않는다. 별도 안전 처리를 두면 그 규칙과 비용을 모든 정책에 동일하게 적용한다.

비용 비교 정책은 현재 상태만 사용하는 판과 차량 사전정보까지 사용하는 판을 따로 둔다. 각 RL 정책과 **동일한 관측 집합**으로 비교한다. 자체 설계한 비용 휴리스틱은 그 계산식·예측기간을 공개하고 문헌 표준 알고리즘인 것처럼 명명하지 않는다.

주비교 상대는 검증 자료에서 고른 강한 비학습 정책으로 고정한다. 최종 평가 결과를 보고 가장 약한 상대를 골라 보고하지 않는다. 계산량이 다른 정책은 의사결정 시간과 사용 자원도 함께 기록한다.

완벽한 미래를 보는 참조 정책은 현실적인 경쟁 상대에서 제외한다. 최적성이 증명되지 않은 탐색 결과를 “최적해” 또는 엄밀한 성능 상한이라고 부르지 않는다.

## 3. 시나리오와 민감도

| 축 | 설계 조건 | 필요한 관측 |
|---|---|---|
| 유입 부하 | 여유·혼잡·지속 과부하 | 외생 발생률, 실제 완료율, 재고·미완료 물량의 증가율 |
| 수요 집중 | 단일 터미널 집중·복수 터미널 동시 집중 | 터미널별 대기·처리량과 장치장 경합 |
| 본선 일정 | 작업 분산·집중 | 야드 자원 경합과 실현된 본선 영향 |
| 시설 능력 | 장치용량·입출고 장비·셔틀 대수를 각각 변화 | 공간 병목과 처리·운송 병목의 분리 |
| 정보 품질 | 도착예측 편향·분산·통지 누락·갱신 지연 | 실제 도착과 공개 예측 사이의 오차 |
| 외생 장애 | 게이트 처리 저하·장비 고장·이동시간 증가 | 장애 발생·공개·복구시각과 추가 미완료 |
| 규모 | 소규모 모형과 다중 터미널 모형 | 계산시간, 공유 장치장 경합, 물량당 성능 |

표의 축은 모든 조합을 즉시 실행하는 일정이 아니다. 단일축의 원인을 구분하는 설계 조건이며 실행 순서는 §9의 Dashboard 조건을 따른다.

용량은 500·1,000·2,000·5,000 TEU 같은 예시를 근거 없이 고정하지 않는다. 초기재고·일별 유입량·공간별 규격 제약에 맞춘 범위를 사용하고 절대 용량과 수요 대비 비율을 병기한다. 장치용량 0은 직접 반입과 같아지는지 확인하는 경계조건이다.

예측오차는 “±20%”만으로 정의하지 않는다. 예를 들어 도착예정시각 오차는 분 단위, 수요량 오차는 비율·건수 단위로 정의하고, 편향·분산·시간적 상관·꼬리·결측률을 명시한다. 실제 운영 범위가 없으면 가정 기반 민감도 분석으로 표기한다.

주분석은 같은 외생 수요 조건에서 수행한다. 정책 실행 뒤 달라진 혼잡 수준을 기준으로 좋은 에피소드만 재분류·선택하지 않는다. 실현 혼잡 등급은 진단으로만 병기한다.

도로 이동시간을 외생값으로 주는 모형은 추가 주행거리·이동시간을 평가할 수 있다. **정책으로 인한 도로 대기열 전파**까지 주장하려면 도로 용량과 교통류 상호작용을 별도로 모형화해야 한다.

## 4. 학습·검증·평가 분리

- **학습 자료:** 정책 가중치·예측기·정규화 계수 적합.
- **검증 자료:** 정책 선택, 임계값·학습 설정 결정, 독립 예측 오차 확인.
- **최종 평가 자료:** 선택된 정책의 비용·서비스 판정. 설정 변경에 재사용하지 않음.

분리 단위는 독립적인 시나리오 또는 운영 기간이다. 시간적으로 이어진 화물·동일 운항편·같은 반사실 결정 쌍을 행 단위로 무작위 분할해 학습과 평가에 나누지 않는다. 실자료는 시간 순서와 운영 주기를 고려하고, 합성 자료는 중복되지 않는 난수 대역을 사용한다.

난수 시드(random seed: 같은 무작위 조건을 다시 만드는 시작값)는 **환경 생성용**과 **학습 초기화·탐색용**을 구분한다. 여러 초기화에서 학습한 정책을 동일 평가 시나리오에 적용해 학습 변동과 환경 변동을 모두 보고한다.

최종 판정은 학습 손실이 아니라 미학습 시나리오에서의 정책 비용으로 한다. 예측형 학습 목표를 사용하면 검증 오차가 실제 행동 간 비용 차이를 구별할 수 있는지도 진단한다. [기존 학습 진단](../../../.claude/docs/dashboard-task-specs/YR-218-training-loop.md) · [검증 분리 근거](../../../.claude/docs/dashboard-task-specs/YR-222-sample-expansion.md).

반사실 교사나 사후 미래정보를 학습에 사용하더라도 평가 입력은 공개 관측으로 제한한다. 이런 학습 방법의 투입은 기본 정책 성능을 확인한 뒤 별도 단일축으로 관리한다.

## 5. 통계 분석과 판정

### 5.1 짝비교와 독립 표본

공통난수법(common random numbers: 정책마다 같은 외생 상황을 겪게 하는 비교 방법)을 적용한다. 정책에 따라 사건 수가 달라져도 외생 수요가 바뀌지 않도록 수요·작업·이동의 난수 흐름을 분리하고 객체·구간 기준으로 재현한다. 같은 정수 시드만 넣는 것으로 충분하다고 가정하지 않는다.

독립 시나리오 \(d\)에서 비교 정책과 기준 정책의 비용 차이를 다음처럼 계산한다.

$$
D_d=C_d^{\mathrm{candidate}}-C_d^{\mathrm{reference}}.
$$

주효과는 \(\bar D\)와 95% 신뢰구간(confidence interval, CI: 반복 표본 추론에서 사용하는 평균 차이의 불확실성 범위)으로 보고한다. 독립 표본 수는 시나리오 수이며 하루의 차량 수·터미널 수를 곱해 늘리지 않는다.

같은 날이 연속되거나 여러 정책이 같은 시나리오를 공유하면 그 의존성을 유지한다. 여러 학습 초기화의 평균 정책효과를 평가할 경우, **학습 초기화와 평가 시나리오 두 축을 반영한 재표집**을 사용하고 모든 초기화×시나리오 결과를 독립 표본처럼 처리하지 않는다.

### 5.2 추론 방법과 표본 수

주추론 방법은 사전등록한다. 고정 정책의 독립 시나리오 짝비교에서는 시나리오 단위 짝 부트스트랩(짝을 유지한 재표집) 신뢰구간을 사용할 수 있다. 차이값의 분포와 표본 규모가 적절하면 대응표본 t 추론을 사용한다. 대응표본 t 통계는 [NIST의 짝비교 정의](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/t_test.htm)를 따른다.

검정법을 결과가 유리해질 때까지 바꾸지 않는다. Wilcoxon 부호순위검정을 사용할 경우 차이 분포의 대칭성 등 조건과 검정 대상이 평균비용 차이와 같지 않음을 명시한다. 여러 대비의 확증 판단에는 사전 지정한 다중비교 보정을 적용하거나 주대비와 탐색 분석을 분리한다.

“최소 30개 시드면 충분”으로 정하지 않는다. 독립 예비 표본으로 분산·최소 의미 개선량·목표 검정력 또는 허용 신뢰구간 폭을 정해 평가 표본 수를 고정한다. 평가 결과의 부호를 보고 시드를 추가하거나 학습을 재선택하지 않는다.

표준화 효과크기는 필요하면 **짝 차이의 표준편차를 사용하는 \(d_z=\bar D/s_D\)**로 보고한다. 원/컨테이너, 분/차량 등 실제 크기를 우선 제시한다. 독립 두 집단용 효과크기를 짝비교에 그대로 적용하지 않는다.

### 5.3 채택 기준

총비용의 최소 의미 개선량을 \(\delta_C>0\)로 사전 고정한다. 후보−기준 비용 차이 신뢰구간의 상한이 \(-\delta_C\)보다 작고 서비스·물리 기준도 충족할 때 개선으로 판정한다. 여러 주대비가 있으면 보정된 추론 기준을 적용한다.

비용 신뢰구간이 개선 문턱과 겹치면 판단을 유보한다. 물리 제약 위반은 실패로 기록한다. 마감 위반율·95백분위수·처리량의 허용 악화폭도 사전 지정하고 비열등성 기준으로 따로 검사한다. “유의하게 나빠지지 않았다”만으로 서비스가 유지됐다고 판단하지 않는다.

고정 물량 실험은 같은 화물을 끝까지 처리했는지 확인한다. 지속운영은 유입·완료율과 미완료 물량 증가율을 보고, 처리량이 줄어 비용이 낮아진 것을 개선으로 해석하지 않는다. 완료한 화물만 분모로 둔 비용을 주지표로 삼지 않는다.

## 6. 지표와 결과 도표

| 지표군 | 보고 내용 |
|---|---|
| 주목적 | 동일 경계의 시스템 총비용, 외생 대상 물량당 비용, 정책 간 짝 차이·신뢰구간 |
| 차량 | 총 구속시간, 외부 대기, 터미널 내 체류·방문시간의 평균·95백분위수 |
| 화물 | 반입 소요시간·장치장 체류, 마감 위반율, 선적 실패, 종료시점 미완료 |
| 시설·운송 | 터미널·장치장 재고·대기열, 임계 초과 지속시간, 셔틀 가동·빈차 거리 |
| 계산 | 의사결정 소요시간의 중앙값·95백분위수, 학습시간·환경 상호작용 수 |

평균 장치율은 터미널 용량을 고려한 가중 평균과 터미널별 값을 함께 제시한다. 터미널 간 장치율 분산은 보조 지표다. 분산 감소만으로 서로 다른 목적지 물량의 처리 효율이 좋아졌다고 판단하지 않는다.

권장 도표는 비용 차이와 신뢰구간, 비용 항별 누적 막대, 대기·재고의 시간 변화, 체류시간 누적분포, 용량별 한계효과, 예측오차별 성능이다. 사례 시간축은 사전 기준으로 선택하거나 전체 분포와 함께 제시해 성공 사례만 고르지 않는다.

초안의 개선율·장치장 이용률 예시값은 결과에 쓰지 않는다. 사용률이 높다는 이유만으로 과사용을 단정하지 않고, 추가 취급·운송·미완료·서비스 악화까지 포함한 순효과로 판단한다.

학습 보상 가중치의 민감도에서는 **공통 평가 비용**을 고정한다. 경제적 단가 자체를 바꾸는 분석은 모든 정책을 같은 새 단가로 재평가하고, 다른 단가 조건의 총액을 직접 비교해 개선율로 삼지 않는다.

## 7. 재현성과 검증 기록

설정·코드 커밋·의존성 버전·학습 및 환경 시드·자료 분할·비교군·원자료·비용 단가·선택된 모델을 저장한다. 파일 해시(내용 변경 여부를 확인하는 값)를 기록하고 보고서 수치를 원자료에서 재계산할 수 있게 한다.

검증에는 물량·차량 보존, 장치공간의 예약 포함 용량, 비용의 구간별 합계, 입력 공개시점, 장치장 용량 0에서 직접 반입과의 일치, 마감 실패·미완료 기록을 포함한다. 비용이 싸진 원인이 기록 누락이 아닌지 먼저 확인한다.

실험 완료 뒤에는 저장소의 [연구 진행 3대 게이트](../../../.claude/skills/research-gates.md)에 따라 성능 개선, Dashboard·코드·증거 정합, 시나리오 현실성을 각각 판정한다. 새 목적함수에 맞는 검증을 정식 등록하기 전 기존 터미널용 검사 결과를 공용 장치장 실험의 통과 증거로 재사용하지 않는다.

## 8. 논문 구성과 주장 제한

논문은 서론·관련연구, 문제 정식화, 학습 방법, 시뮬레이션과 자료, 실험 설계, 결과, 논의·한계 순서로 구성한다. 관련연구에서는 트럭 예약, 외부 장치장, 반입 조절, 강화학습 제어를 구분하여 본 문제의 차이를 설명한다.

논문의 주장은 실제 판정에 따라 달라진다. 장치장 이용만 유효하면 물류 메커니즘의 결과로 보고하고, RL이 강한 동일 정보 기준선을 넘었을 때만 학습의 추가 가치를 주장한다. 실제 비용·자료·도로·본선 범위가 확인되지 않으면 그 부분의 현장 개선율을 제시하지 않는다.

## 9. 실행 조건과 Dashboard 연결

**YR-225(문서 개정 작업)**는 본 설계 작성·문서 검증으로 끝난다. **YR-226(공용 장치장 확장 연구 성립조건 검토)**는 물류 흐름·자료·비용 경계를 확인하는 조건부 후속이다. 외부 장치·셔틀 비용 때문에 기존 내부 재배치 결과를 바로 승계할 수 없다는 점이 등록 이유다.

소규모 모형에서 물리·비용 검증, 최소 정보 정책 비교, 차량 사전정보 추가, 본선 정보 추가, 규모·강건성 평가라는 설계 의존관계를 둔다. 이는 현재 연구를 건너뛰는 실행 우선순위가 아니다. YR-226 검토와 기존 연구 착수 조건을 충족한 뒤 실제 실험별 row·상세 명세·사전등록을 먼저 만든다. [후속 명세](../../../.claude/docs/dashboard-task-specs/YR-226-buffer-extension-feasibility.md).
