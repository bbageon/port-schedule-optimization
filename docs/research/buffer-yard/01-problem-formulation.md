# 공용 외부 장치장 연구 — 문제 정식화와 비용 모형

> [연구 설계안](../../../busan_port_buffer_rl_experiment_design.md)의 상세 제안. 구현된 모형의 명세로 간주하지 않는다.
> 검증 절차: [실험 설계](02-experimental-design.md).

## 1. 물류 네트워크와 기록 단위

터미널 집합을 \(\mathcal J=\{1,\ldots,N\}\), 공용 장치장을 \(B\), 컨테이너 집합을 \(\mathcal I\)로 둔다. 컨테이너 \(i\)의 목적 터미널 \(d_i\)는 고정한다. 경로는 직접 반입 또는 장치장 경유의 두 가지다.

| 객체 | 필수 자료 |
|---|---|
| 터미널 \(j\) | 사용 가능한 장치용량, 초기 재고, 게이트·야드 자원, 작업시간 분포, 접수시간 |
| 컨테이너 \(i\) | 불변 식별자, 규격, 목적 터미널, 선적 대상, 반입 개시·마감, 통지·발생시각 |
| 외부 운송차량 | 컨테이너와의 연결, 경로·위치, 대기·주행·작업·회송 상태, 업무 종료시각 |
| 장치장 \(B\) | 장치용량, 초기 재고, 입출고 장비, 작업시간, 도착 예정 예약량 |
| 셔틀 차량 | 차량·운전자 수, 가용시각, 적재능력, 출발·도착·복귀 기록 |
| 본선 작업 | 계획 작업량·시간, 터미널 자원과의 경합, 지연·유휴를 산출할 사건 기록 |

컨테이너 식별자와 차량 식별자는 분리한다. 하차 뒤 컨테이너가 셔틀로 옮겨 실려도 컨테이너 기록은 이어지며, 두 차량의 시간을 한 차량의 체류시간처럼 연결하지 않는다.

기본 모형에서는 셔틀 1회에 컨테이너 1개를 운송한다. 20피트 컨테이너 2개 동시 운송 등은 별도 적재 계약이 확인될 때만 허용한다. 재고는 TEU(20피트 환산량), 작업은 취급 건수, 운송은 차량 대수로 각각 집계한다.

터미널 야드에는 초기 장치 화물과 선적·반출에 의한 재고 감소가 있어야 한다. 외부 반입만 생성해 모든 야드가 결국 포화되는 모형으로 정상 운영을 평가하지 않는다. 본선 처리율도 무한대로 두지 않는다.

## 2. 관측과 정보 공개시점

의사결정 시각을 \(t_k\), 실제 환경 상태를 \(x_k\), 정책 관측을 \(o_k\)로 구분한다. 부분적인 관측만으로 실제 상태가 완전히 결정된다고 가정하지 않는다.

| 정보 단계 | 입력 | 통제 사항 |
|---|---|---|
| 기본 관측 | 현재 시각, 목적 터미널·규격, 반입 개시·마감까지 남은 시간, 현재 대기·재고, 예약 용량, 장비·차량 가용상태 | 과거·현재 관측과 이미 공개된 계약 정보만 사용 |
| 차량 사전정보 추가 | 통지된 차량의 도착예정시각과 예정 반입량 | 통지시각 이전에는 존재·수량·예정시각 모두 비공개 |
| 본선 계획 추가 | 공개된 하역작업 계획과 예정 자원 점유 | 실제 미래 작업완료·지연은 비공개 |
| 오차 민감도 | 사전에 정한 예측 편향·분산·결측·갱신지연 | 실제 사건과 정책이 보는 예측값을 분리 |

위 단계는 입력을 순차적으로 검증하기 위한 구분이다. 기본 관측에서도 알려진 마감·시설 제약은 제거하지 않는다. “현재 정보만”은 미래 도착 수요 예측을 제외한다는 뜻이다.

공개 시각 \(p_i\)를 갖는 정보는 \(p_i\le t_k\)일 때만 사용한다. 입력 정규화 계수와 예측모형은 학습 자료로만 적합한다. 검증·평가 기간의 실제 도착값으로 미리 보정하지 않는다.

차량 도착예정시각은 외생 입력으로 취급한다. 별도 예측모형의 정확도 개선을 본 연구의 성과에 포함하지 않는다. 기존 연구의 [정보 경계 원칙](../../../.claude/docs/architecture/05-정보경계.md)을 적용한다.

## 3. 결정 시점과 행동 집합

물류는 사건 기반으로 진행하고, 정책은 **경로 변경이 가능한 최초 시점** 및 **장치장 입고·장비 가용·출고 검토 시점**에 호출한다. 통지만 받고 실행 준비가 되지 않은 컨테이너를 즉시 이동시키지 않는다.

| 대상의 현재 상태 | 실행 가능한 행동 |
|---|---|
| 최초 운송 결정 대기 | 직접 반입 또는 장치장 경유 |
| 장치 완료·출고 대기 | 계속 장치 또는 지정 터미널로 출고 |
| 운송·취급 중 | 해당 작업의 완료를 기다림. 중복 배차·순간 경로 전환 금지 |
| 목적 터미널 반입 완료 | 장치장 경로 결정 대상에서 제외 |

“계속 장치”도 유효한 행동이다. 출고 검토에는 다음 검토시각을 두어 영구 정지를 방지하고, 검토 주기를 모든 정책에서 동일하게 고정한다. 같은 시각의 사건 처리·동률 해소 순서도 사전 고정한다.

한 시각에 여러 출고 요청이 있으면 정책이 실행 가능한 컨테이너 후보를 선택한다. 선택할 때마다 자원을 예약·갱신하고, 남은 후보를 재검사한다. 진입과 출고는 **하나의 정책에서 단계별 실행 가능 행동으로 표현**하며, 별도 교섭시장이나 다중 에이전트 계층을 기본 설계에 추가하지 않는다.

정책을 적용할 실제 상태가 충분히 관측되지 않으므로 **부분관측 순차 의사결정 문제**로 기술한다. 결정 간격이 변한다면 준마르코프 의사결정 모형(semi-Markov decision model: 행동마다 경과시간이 다른 모형)에 맞춰 시간·비용을 처리한다. 관측 벡터만 보고 완전관측 마르코프성이 성립한다고 단정하지 않는다.

정책 함수근사 방식은 행동 집합과 학습 예산을 확정한 뒤 사전등록한다. 특정 신경망이나 학습 알고리즘의 우월성을 설계 단계에서 선언하지 않는다.

## 4. 실행 가능성 제약

장치장 현재 재고를 \(x_B(t)\), 이미 장치장행으로 확정됐으나 도착 전인 예약량을 \(b_B(t)\), 용량을 \(K_B\)라고 하면 다음을 지킨다.

$$
0\le x_B(t)+b_B(t)\le K_B.
$$

장치장으로 출발한 컨테이너의 공간까지 확보하므로, 동시 요청을 각각 허용해 도착 시 초과하는 문제를 막는다. 터미널도 같은 방식으로 접수·장치 가능성을 검사한다. TEU 총량 검사는 규격별 적치 가능 공간 검사와 함께 수행한다.

- **자원 제약:** 차량·장비의 중복 사용 금지, 이동·작업시간의 양수 보장, 셔틀 복귀 전 재사용 금지.
- **반입 제약:** 화물 취급 적합성, 반입 개시시각, 접수·작업 용량, 선적별 마감.
- **체류 제약:** 최대 장치 허용시간은 운영 근거로 정하고, 임의의 6시간을 확정값으로 쓰지 않는다.
- **보존 제약:** 발생·초기 물량은 이동 중·장치 중·처리완료·미완료 기록으로 모두 설명돼야 한다.

부적합 행동은 행동 마스킹(action masking: 실행할 수 없는 선택을 후보에서 제거하는 절차)으로 제외하고, 실행 직전 다시 검사한다. 조건부 예약 취소도 기록해 공간·차량이 사라지지 않게 한다.

출고 후보의 마감 여유는 다음과 같이 추정한다.

$$
s_i(t)=d_i^{\mathrm{cut}}-
\left[t+\widehat{\tau}_{\mathrm{load},i}
+\widehat{\tau}_{B,d_i}
+\widehat{\tau}_{\mathrm{gate},i}
+\widehat{\tau}_{\mathrm{accept},i}\right].
$$

\(d_i^{\mathrm{cut}}\)은 반입 마감, 각 \(\widehat{\tau}\)는 상차·주행·게이트 대기·접수 완료까지의 예상 소요시간이다. 일정 여유를 두고 실행 가능성을 판단하되 **예측에 의한 후보 제한은 실제 마감 준수를 보증하지 않는다**. 실현 위반은 별도 기록한다.

불확실성으로 마감·최대 체류를 넘긴 화물도 삭제하지 않는다. 물리 제약은 유지하면서 공통 비상 처리 규칙으로 운송을 마치고, 서비스 실패·추가비용을 기록한다. 직접 반입과 장치장 진입이 모두 불가능하면 상류 대기열에 남기며 그 대기도 계산한다. 이 강제 대기는 임의의 도착 지연을 선택하는 별도 정책 행동과 구분한다.

## 5. 시스템 비용의 자원별 정의

정책 비교의 시작 경계는 **운송 경로를 처음 선택할 수 있는 동일한 지점**이다. 목적 터미널 안에서의 시간만 측정하면 경유·외부 대기를 누락하므로 다음 항목을 함께 계산한다.

| 항목 | 원화 환산식·정의 | 중복 방지 |
|---|---|---|
| 차량·기사 시간 \(C_{\mathrm{truck}}\) | 차량별 시간가치 × 운송·대기·취급·회송으로 구속된 시간 | 장치 후 떠난 기사의 시간은 더하지 않음 |
| 생산적 취급 \(C_{\mathrm{handling}}\) | 터미널·장치장의 필수 하차·상차 등 작업 횟수 × 해당 자원 단가 | 운전기사 시간과 구분하고 재취급 작업은 제외 |
| 장치·보관 \(C_{\mathrm{storage}}\) | 시설별 고정 운영비 + TEU·시간 재고 적분 × 보관 단가 | 직접 반입과 경유 모두 같은 범위 적용 |
| 비시간 운송비 \(C_{\mathrm{transport}}\) | 적재·빈차 주행의 연료·통행료 등 직접 비용 | 기사·차량 시간은 첫 항에서만 계산 |
| 재취급 \(C_{\mathrm{rehandling}}\) | 접근 방해 컨테이너의 추가 이동 횟수 × 단가 | 필수 상하차와 사건 식별자를 공유하지 않음 |
| 본선 영향 \(C_{\mathrm{vessel}}\) | 모형에서 실현된 본선 유휴 또는 지연 × 사전 지정 단가 | 마감 근접도를 선박 지연으로 대체하지 않음 |
| 마감 위반 \(C_{\mathrm{late}}\) | 실제 반입 지각·선적 실패에 대한 사전 지정 서비스 손실 | 본선 항과 같은 손해를 이중 계상하지 않음 |

이 표는 **서로 다른 자원의 비용을 한 번씩 계산하기 위한 분류**다. 계약 요금에 여러 자원비가 묶여 있다면 묶음 요금을 쓰거나 구성 원가를 쓰는 방식 중 하나를 택한다. 운영주체 간 동일 요금의 지불·수취를 시스템 비용으로 두 번 더하지 않는다.

차량 시간비용은 차량·기사의 실제 구속 구간을 적분한다. 경유 화물의 추가 셔틀·빈차 회송뿐 아니라 확보한 셔틀 차량의 유급 대기 등도 운영계약에 맞게 포함한다. 두 경로의 업무 종료·복귀 지점은 비교 전에 동일한 기준으로 정의한다.

보관비는 장치장에만 부과해 터미널 보관을 무료로 두지 않는다. 시설 \(f\)의 재고 \(x_f(t)\), 단가 \(c_f^{\mathrm{store}}\), 평가 구간 \([t_0,T]\)의 고정 운영비 \(F_f\)에 대해 다음으로 계산한다. 시설 운영 여부와 고정비 부담은 정책 비교 전에 정하며, 단가에 배분된 같은 고정비를 다시 더하지 않는다.

$$
C_{\mathrm{storage}}
=\sum_f\left[F_f+c_f^{\mathrm{store}}\int_{t_0}^{T}x_f(t)\,dt\right].
$$

시간 단위를 시간으로 쓰면 단가는 원/(TEU·시간)이다. 장치율을 낮췄더라도 전체 보관시간과 운송비가 늘 수 있으므로 총비용을 함께 확인한다.

기존 구현의 [원화 환산 비용 함수](../../../src/yard_rl/v3/reward/krw.py)에는 트럭 시간가치와 장시간 체류 할증 등이 있다. 이는 **기존 터미널 내부 평가 계약**이다. 확장 모형에 그대로 적용하지 않고 시간 경계·할증 사유·단가의 적용 범위를 다시 명시한다. 고시 인용이나 실제 요금 적용이 필요하면 원출처와 적용시점을 별도로 검증한다.

야드·본선 자원 경합을 모형화했다면 본선 영향도 평가한다. 집계 처리율만 주어진 축약 모형에서는 반입 마감 준수까지만 주장하고 본선 비용을 실측 효과처럼 산출하지 않는다. 마감 위반 벌점은 안전·용량 제약을 비용으로 사는 수단이 아니다.

## 6. 학습 보상과 목적함수 정렬

\(\Phi(t)\)를 시작 이후 발생한 누적 시스템 비용, \(Z_T\)를 종료시점 미완료 부담의 처리비용이라고 한다. 정책은 다음 값을 최소화한다.

$$
J(\pi)=\mathbb E_\pi\left[\Phi(T)+Z_T\right],
\qquad
r_k=-\frac{\Phi(t_{k+1})-\Phi(t_k)}{c_{\mathrm{scale}}}.
$$

\(c_{\mathrm{scale}}>0\)는 학습 수치를 안정화하기 위한 **고정 공통 배율**이다. 보고 비용은 원 단위를 유지하고, 마지막 보상에는 \(Z_T\)를 한 번만 반영한다. 그러면 할인하지 않은 보상 합은 총비용 최소화와 일치한다.

유한 평가 구간의 총비용을 목표로 하면 기본 할인계수는 1로 둔다. 다른 할인율을 사용하면 미래 비용의 중요도가 바뀌므로 시간 단위·근거·평가 목적과의 차이를 명시한다. 사건 간격이 다른데 사건 수만으로 할인하지 않는다.

기존 반사실 학습(같은 상황에서 다른 행동을 했을 때의 비용 차이를 학습하는 방법)을 사용하려면 기본 정책의 효과 검증 뒤 별도 축으로 평가한다. 여러 행동의 대안 비용을 실제 발생 비용에 합산하지 않고, 예측 오차와 행동 간 비용 차이를 비교해 학습 신호가 구별되는지 확인한다.

## 7. 평가 종료와 지속운영

유한 물량 실험에서는 종료시점에 남은 화물을 숨기지 않도록, **모든 정책에 동일한 후속 처리 규칙**을 적용해 배송·차량 복귀를 마치는 비용을 \(Z_T\)로 계산한다. 종료 전 비용과 종료 후 비용은 구간을 나눠 중복 없이 기록한다. 잔여비용을 추정으로 대체할 때는 실제 후속 처리와의 오차를 검증한다.

지속운영 실험은 예열 구간 뒤 고정 측정창을 두고 창 끝까지 외생 도착을 유지한다. 대기·재고 비용은 시간 적분으로 계산하고, 미완료 수·재고 증가율·처리량을 함께 보고한다. 유한 물량을 비운 결과만으로 정상상태 혼잡 완화를 주장하지 않는다.

완료 차량만으로 계산한 체류 평균·분위수에는 미완료 표본이 제외되는 편향이 생긴다. 미완료 비율을 함께 제시하고, 코호트 추적(측정창에 들어온 대상을 종료 뒤에도 따라가는 방법)으로 완료까지 관측한다. 실패 실험을 통계에서 제외해 비용이 낮아 보이게 하지 않는다.

공용 장치장은 공간·시간을 재배분할 뿐 지속적인 처리능력 부족을 자동으로 해결하지 않는다. 의도된 과부하는 정상상태 가정의 검증과 나눠 보고한다.
