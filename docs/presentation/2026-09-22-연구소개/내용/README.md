# 발표 내용 (2026-09-22 연구 소개)

여기 있는 것은 그 그림 위에 올릴 문장과 발표할 때 입으로 덧붙일 말이다.

## 각 장의 짜임

장마다 네 칸이 같은 순서로 있다.

1. **한 줄로 말하면** — 그 장에서 청중이 가져갈 문장 하나. 슬라이드 제목과 같다.
2. **슬라이드에 넣을 글** — 화면에 띄울 짧은 문장들.
3. **말로 덧붙일 것** — 화면에는 안 쓰고 입으로 할 설명.
4. **숫자와 출처 · 나올 만한 질문** — 어디서 나온 값인지, 질문이 오면 무엇을 답할지.

## 쓸 때 지키는 것

- **한 장에 메시지 하나.** 제목이 곧 결론이고 나머지는 근거다.
- **숫자는 장당 두세 개**만. 표를 길게 넣지 않는다.
- **한계를 같이 말한다.** 이 연구의 결과는 아직 "확정"이 아니라 "재현되는 방향"이다.
- 여기 적힌 숫자는 전부 **측정한 값**이다. 출처 없는 값은 쓰지 않는다.

## 이 연구를 한 문장으로

> 터미널에 오는 트럭의 **예약 시각과 갈 블록**을 학습된 정책이 다시 조정하면
> 터미널 전체 비용이 줄어드는지를, 시뮬레이터 위에서 검증한다.

목표는 실제 터미널에 바로 적용하는 것이 **아니다.** 강화학습이라는 방법이 이 문제에서
효과가 있는지 없는지를 가리는 것이다. 그래서 "안 된다"는 결과도 결과로 쓴다.
