## 한 줄 주장

> **컨테이너 터미널에서 트럭의 배정 블록을 서로 사고파는 재배치 시장을 얹으면,
> 밑에 깔린 배차 방식이 무엇이든 트럭 1대당 약 2.6분의 대기가 줄어든다.**

## 왜 이 주장이 강한가

같은 이득이 **성질이 전혀 다른 두 배차 정책 위에서 거의 같은 크기**로 나온다.

| 밑에 깔린 배차 | 재배치를 얹었을 때 |
|---|---|
| 현행 규칙 (SF-SPT) | **−158.13** 비용시간 (t=−11.90) |
| 학습된 크레인 정책 | **−166.69** 비용시간 (t=−8.80) |

"우리가 만든 정책이 마침 나빠서 개선 여지가 컸다"로 설명되지 않는다.
**메커니즘 자체의 성질**이다.
