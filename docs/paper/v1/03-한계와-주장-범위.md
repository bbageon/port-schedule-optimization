# 03 — 한계와 주장 범위

> 아래 다섯은 **본문에 둔다.** 각주로 밀지 않는다.

## 1. 시뮬레이션이다 — 실제 항만 기록이 아니다

무대는 공개 스펙과 문헌으로 **보정한** 시뮬레이터다. 실제 터미널 운영 로그는
이 연구에 **한 건도 쓰이지 않았다.**

허용되는 주장은 **"문헌 보정 시뮬레이션의 방법론 결과"** 까지다.

- ❌ "실제 부산항에서 대당 2.6분이 준다"
- ⭕ "문헌 보정 시뮬레이션의 21블록 무대에서 대당 2.6분이 준다"

"학습에 안 쓴 날"이라는 말도 **시뮬레이터의 다른 난수 시드**를 뜻하지, 실제
다른 날을 뜻하지 않는다.

## 2. 학습 부족이 원인은 아니었다 (2026-08-19 갱신)

초판에서 이 절은 "동결 예산의 25%에서 멈춰 미해결"이라고 적었다. 그 뒤 두 가지가
확인되어 **이 한계는 다른 형태로 바뀌었다.**

**① 학습량은 원인이 아니다.** 학습 구조를 바꾼 판(YR-189)에서 **동결 예산 16회차를
완주**했고, 모델 정확도는 단조 개선했다(RMSE 0.069 → 0.019). 그런데도 규칙을
넘지 못했다 — `q − greedy` = **+211.41** [+167.79, +255.02], **16일 전부 규칙 승**.

**② 남은 것은 "학습을 어떻게 쓰는가"다.** 실패 지점이 특정됐다. 결정 규칙
`Q < 0` 에는 **예측 오차에 대한 안전 여유가 없다.** 모델 오차가 신호의 82%인
상황에서 이 문턱은 참값이 0 근처인 건들을 오차의 부호로 판다. 결과적으로 학습
정책은 규칙보다 **2.26배 많이 팔았고**(일평균 2,167 vs 957건) 그래서 졌다.

규칙의 `gain_margin`(κ_T 1σ)이 정확히 그 안전 여유다. 문헌도 "최고 후보 하나만
쓰면 채점 잡음에 민감"하다고 경고했고, 사전등록에 그 위험을 적어두고도 대비를
넣지 않았다.

따라서 이 초안의 negative result 는 **"강화학습은 원리적으로 안 된다"가 아니라
"학습된 비용 모형을 딱딱한 0 문턱으로 쓰면 규칙을 넘지 못한다"** 이다.
문턱을 모델 잔차에서 유도하는 것이 다음 단일축 실험이다(YR-195).

**부수적으로 확인된 것**: 구조 결함 3종(critic 붕괴 · 보상 0 이 91% · 값매김 자가
두 개)은 실제로 사라졌다. 라벨이 붙은 표본이 9% → **99.3%** 로 올랐고, 두 축의
비용 격차도 정확히 학습했다(라벨 +0.2480 vs 모델 +0.2546). **결함이 사라져도
성능이 따라오지 않았다**는 것이 이 판의 핵심 결과다.

## 3. 밑에 깔린 크레인 정책이 이 무대에서 규칙보다 비싸다

`A − R` = **+59.97** (신뢰구간 [7.25, 112.69], 대당 +1.00분).

이 정책은 **구 2블록 무대에서 학습된 것을 얼려 쓴 것**이다. 21블록 24시간
무대에서 재학습한 적이 없고, 학습 중에도 가중치가 고정돼 있다.

그래서 이 연구가 원래 목표로 삼았던 **"차량·본선·장비를 처음부터 하나의
정책으로 다루는 단일 통합정책"은 학습·평가된 적이 없다.** 학습되는 것은
재배치 층 하나뿐이고, 나머지는 동결이거나 계산식이다.

**본 주장은 이 한계의 영향을 받지 않는다** — 재배치 이득이 규칙 배차 위에서도
같은 크기로 나오기 때문이다. 오히려 그것이 이 대비를 넣은 이유다.

## 4. 최적화 대상과 배포 대상이 어긋나 있다 (구 PPO 판 — 해소됨)

> **2026-08-19 갱신**: 아래는 PPO 판의 한계다. Q 채점 전환(YR-189)에는 추첨
> 정책이 없어 이 어긋남이 **구조적으로 사라졌다.** 그럼에도 성능은 규칙을 넘지
> 못했으므로(§2), 이 불일치는 **주된 원인이 아니었다.** 기록으로 보존한다.

같은 가중치가 두 방식에서 **반대로** 움직인다.

| | 최선 고르기 | 확률 추첨 |
|---|---|---|
| 병목 교정 전 | −73.43 | +14.62 |
| 병목 교정 후 | **−129.15** (개선) | **+39.47** (악화) |

PPO 가 최적화하는 것은 **추첨 정책의 기대수익**이고, 배포에 쓰려는 것은
**최선 고르기**다. 교정이 후자만 개선했다.

이 불일치의 기전은 규명하지 못했다. 엔트로피 보너스가 정책을 계속 흐트러뜨리는
것과 관련될 수 있으나 확인하지 않았다. **미해결로 남긴다.**

## 5. 고정 +15분 시간축과 현 비용계약 아래의 값이다

- **시간 이연은 +15분 한 칸 고정**이다. 30분 슬롯 48칸으로 넓힌 실험은
  **유의하게 더 나빴다**(+33.0, t=+3.31).
- **같은 시간 칸에 트럭이 몰리는 것을 막는 용량 검사가 없다.** 현 거래량에서는
  드러나지 않았으나(하루 186건이 18~20칸에 분산) 구조적 구멍이다. 이를 넣으면
  행동이 바뀌므로 **재측정이 필요하다.**
- 기사가 정문 밖에서 기다리는 시간을 터미널 안 대기와 **같은 단가**로 센다.
  이 가정이 시간 이연을 구조적으로 불리하게 만든다. 다른 단가를 쓰면 시간 축의
  결론이 달라질 수 있다.

## 6. 그 밖에 명시할 것

| | |
|---|---|
| 본선 작업 | 크레인의 작업 순서 결정에는 **포함**되나 재배치 대상은 **아니다**(위치가 선박에 묶임) |
| 구조 일반화 | 21블록 수평 공유형 하나만 검증했다. 수직 역할분리형 구조는 미실행 |
| 견적 신경망 | 검증 3종 중 **단조성 실패**. 본 주장에 쓰이지 않으므로 영향 없으나, 이를 "검증된 견적기"로 부르지 않는다 |
| 비용 항별 분해 | 평가가 총액만 기록해, 이득이 트럭 체류에서 왔는지 본선에서 왔는지 **가르지 못했다** |

## 7. 재현성

| | |
|---|---|
| 실행 트리 | 판정 실행은 전부 깨끗한 커밋에서 수행하고 결과에 박제했다 |
| 결과 파일 | 해시를 파일 밖 sidecar 에 남겨 자기검증이 성립한다 |
| 가중치 | 현 무대가 참조하는 학습 가중치는 버전관리에 편입했고, 미편입분은 경로·해시 원장으로 남겼다 |
| 남은 위험 | 학습은 확률적이고 torch 판 차이에 민감해 **비트 단위 재현은 보장되지 않는다** |
