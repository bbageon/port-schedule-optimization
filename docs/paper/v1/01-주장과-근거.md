# 01 — 주장과 근거

## 1. 문제

컨테이너 터미널에서 외부 트럭은 도착 전에 **어느 블록으로 갈지**가 이미 정해져
있다. 그런데 그 블록이 마침 붐비면 트럭은 기다린다. 옆 블록이 한산해도 그렇다.

이 초안이 다루는 것은 **그 배정을 도착 전에 바꿀 수 있게 하면 얼마나 좋아지는가**
이다. 두 가지 바꿈을 허용한다.

| 축 | 무엇 |
|---|---|
| **공간** | 다른 블록으로 보낸다 |
| **시간** | 같은 블록에 조금 늦게 오게 한다 (고정 +15분) |

블록들이 서로 "이 트럭을 넘길까"를 제안하고, 중앙 조정기가 전체 비용이 가장
적은 조합을 고른다. 모든 대안이 지금보다 나쁘면 아무것도 바꾸지 않는다.

## 2. 무대

**문헌·공개자료로 보정한 시뮬레이션**이다. 실제 터미널 운영 기록이 아니다.

| | |
|---|---|
| 구조 | 21블록, 블록당 크레인 2기 |
| 시간 | 24시간, 이중 피크 |
| 부하 | 고정 재공량 — 나간 만큼 채워 넣는다 |
| 하루 트럭 | **3,600대** |
| 평균 체류 | 31~33분 |
| 본선 | 12 프로세스 × 120 무브 (계획 작업률 앵커 안) |

비용은 **비용시간** 단위다. 트럭 체류시간 + 약속시간 초과 벌금 + 본선 지연으로
구성되고, 기준선 분해는 트럭선형 81.8% · 트럭벌금 10.7% · 본선지연 7.5% 다.
트럭 1대가 1시간 머물면 비용 1 이므로, **비용 1 ≈ 트럭 1시간**이다.

## 3. 실험 설계 (사전등록)

**결과를 보기 전에** 팔·평가일·판정축·통계·하드가드를 전부 동결하고 커밋했다.

| 팔 | 크레인 배차 | 재배치 |
|---|---|---|
| `R` | **현행 규칙 (SF-SPT)** | 없음 |
| `R_S` | 현행 규칙 | 규칙 기반 재배치 |
| `A` | 학습된 크레인 정책 | 없음 |
| `A_S` | 학습된 크레인 정책 | 규칙 기반 재배치 |
| `A_P` | 학습된 크레인 정책 | **학습된** 재배치 |

- 새 난수 대역 **16일**, 다른 어떤 실험과도 겹치지 않는다.
- **같은 날끼리 짝지어** 비교하고, 독립단위는 **날**(n=16)이다.
- 주판정은 **총비용과 실제 gate-in→gate-out 두 축 공동**이다. 하나만 좋아지는
  것은 이득으로 치지 않는다.
- **신뢰구간이 0을 배제할 때만** 방향을 선언한다. 아니면 "판단 불가"로 적는다.
- 표본 확장은 오차 폭이 기준을 넘을 때만, **폭만 보고** 정한다(부호 미열람).

## 4. 전체 성적표

| 팔 | 총비용 Φ | 체류 평균 | 꼬리 P95 | 공간·시간 거래/일 |
|---|---|---|---|---|
| R | 2358.80 | 32.64분 | 70.81분 | 0 · 0 |
| **R_S** | **2200.67** | **30.24분** | 65.95분 | 678.2 · 280.3 |
| A | 2418.77 | 32.70분 | 75.88분 | 0 · 0 |
| A_S | 2252.08 | 30.00분 | 70.39분 | 680.8 · 277.6 |
| A_P | 2350.02 | 31.18분 | 73.07분 | 218.7 · 338.6 |

하드 가드 4종 전항 통과(투입 3,600 전건·정책 예외 0·결정론·깨끗한 트리).
최대 신뢰구간 반폭 56.05로 사전 지정 한계(60) 안이라 표본 확장은 하지 않았다.

## 5. 판정

| 대비 | 총비용 | 체류시간 | 판정 |
|---|---|---|---|
| **`R_S − R`** | **−158.13** (t=−11.90) | **−143.78초** (t=−19.52) | **좋아짐** |
| **`A_S − A`** | **−166.69** (t=−8.80) | **−161.82초** (t=−15.17) | **좋아짐** |
| `A_S − R` | −106.72 (t=−4.06) | −157.89초 (t=−11.46) | 좋아짐 |
| `A − R` | +59.97 [7.25, 112.69] | +3.93초 | **나빠짐** (비용) |
| `A_P − A_S` | +97.94 (t=+5.60) | +70.78초 (t=+7.26) | **나빠짐** |

### 5-1. 본 주장 — 재배치는 배차 방식과 무관하게 이득이다

`R_S − R`(**−158.13**)과 `A_S − A`(**−166.69**)가 **거의 같다.**

성질이 전혀 다른 두 배차 정책 위에서 같은 크기의 이득이 나온다. 규칙 배차는
서비스 우선·짧은 작업 우선의 결정론적 규칙이고, 학습 정책은 신경망에 롤아웃
가드를 붙인 것이다. 공통점이 없다. 그런데 재배치를 얹으면 둘 다 같은 만큼
좋아진다.

**두 지표가 같은 방향으로 강하게 유의**한 것도 중요하다. 비용만 줄고 체류가
늘었다면 비용 함수가 다른 항으로 이득을 낸 것이지 트럭 기사에게 좋아진 게
아니다. 여기서는 둘 다 줄었다.

### 5-2. 대당 환산

트럭 3,600대 기준이다.

| | 비용시간 | 대당 |
|---|---|---|
| 재배치 (규칙 배차 위) | −158.13 | **−2.64분** |
| 재배치 (학습 정책 위) | −166.69 | **−2.78분** |
| 전체 vs 현행 규칙 | −106.72 | −1.78분 |
| 학습 크레인 정책 단독 | +59.97 | +1.00분 (손해) |

평균 체류 31~33분 대비 **8~9%** 다.

### 5-3. 이득의 정체는 "공간을 많이 판다"

성적이 공간 거래량을 거의 그대로 따라간다.

| 구성 | 공간 거래/일 | 안 팔기 대비 |
|---|---|---|
| 규칙 재배치 | 678.2 | −158.13 |
| 학습 재배치 | 218.7 | −97.94 대비 열세 |

시간 이연은 이 계약에서 **1건당 +14.28분 손해**로 확정돼 있다. 기사가 정문
밖에서 기다리는 시간을 터미널 안 대기와 같은 값으로 세기 때문에, 고정 +15분
이연은 구조적으로 "아낀 것 − 15분"이다. 이득은 **공간 축 하나에서** 나온다.

### 5-4. 부수 — 학습된 크레인 정책은 이 무대에서 규칙보다 비싸다

`A − R` = **+59.97** (신뢰구간 [7.25, 112.69], 대당 +1.00분). 연구 최초 측정이다.

평균 체류는 차이가 없고(+3.93초, 판단 불가) **꼬리가 나쁘다** — P95 75.88 vs
70.81, **+5.07분**. 벌금이 약속시간 초과분에 붙는 구조라 꼬리가 곧 비용이다.
다만 비용 항별 분해를 기록하지 않아 **확증은 아니다**.

이 정책은 **구 2블록 무대에서 학습된 것을 얼려 쓴 것**이며 현 무대에서 재학습한
적이 없다([03](03-한계와-주장-범위.md) 참조).

## 6. 사후 관찰 (판정 아님)

사전등록에 없던 대비다. **판정으로 인용하지 않는다.**

`A_S − R_S` = +51.40 → 다섯 구성 중 가장 싼 것은 **`R_S`(현행 규칙 배차 +
규칙 기반 재배치) Φ 2200.67** 이고, 여기에는 **학습이 한 군데도 들어가지
않는다.**
