## 결과 검증

새 산출물은 해시를 **파일 밖**에 남긴다.

```bash
sha256sum outputs/reports/yr185_retrain/eval_fix.json
cat       outputs/reports/yr185_retrain/eval_fix.json.sha256
```

파일 안에 자기 해시를 적으면 적는 순간 내용이 바뀌어 검증이 성립하지 않는다.
구 산출물에는 sidecar 가 없으며, 그 경우 검증 결과는 "위반"이 아니라
"미상"으로 표기된다.
