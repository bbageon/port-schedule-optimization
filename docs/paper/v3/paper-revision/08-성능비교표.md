# 성능 비교표: 요청 보존 후 10일 진단과 기존 논문

2026-09-16 갱신. **요청을 버리지 않도록 보정한 세 정책의 10일 실행이 10:30 KST에 모두 끝났다.**
새 진단 결과를 맨 위에 추가하고, 보정 전 실행과 기존 논문 결과를 아래에 보존한다. 추가학습·독립 시드 성능 평가는 아직 하지 않았다.

## 1. 요청 보존 후 최종 결과 — 9/16 종료

고정 소스 `2e4caef`, 기존 최종 가중치, 같은 시드 9,500,000의 연속 10일이다.
합성 도착곡선과 원래 물량을 유지했다. 각 정책에 트럭 69,000건·본선 44,322건을 전부 접수했으며 미투입·미추적은 0건이다.

| 정책 | 총비용(억 원) | 기준 대비 절감률 | 트럭 완료(대) | 트럭 미완료(대) | 본선 야드 잔여(건) |
|---|---:|---:|---:|---:|---:|
| 배정 변경 없음 | 51.777 | 기준 | 69,000 | 0 | 1,681 |
| 전체 모형 | 43.624 | 15.75% | 68,819 | 181 | 1,817 |
| 수락 거절 기능 제거 | 48.628 | 6.08% | 68,762 | 238 | 1,560 |

전체 모형은 기준보다 8.153억 원, 거절 기능 제거보다 5.004억 원(10.29%) 낮았다.
그러나 전체 모형과 거절 기능 제거에는 반출 대상이 부족해 끝나지 않은 트럭이 남았다. 기준 정책도 본선 작업을 전부 마치지는 못했다.
**15.75%는 이 진단의 관측 절감률이며, 모든 요청을 완료하는 정책의 성능이나 독립 반복의 확증 결과가 아니다.**
거절 기능 제거에도 후보 정렬용 수락망 점수가 남으므로 수락망 전체의 기여를 분리한 실험으로 부르지 않는다.

| 비용 항목(백만 원) | 배정 변경 없음 | 전체 모형 | 수락 거절 기능 제거 |
|---|---:|---:|---:|
| 트럭 체류·장시간 벌점 | 4,972.823 | 4,173.948 | 4,668.979 |
| 크레인 추가 이동 | 7.210 | 7.355 | 7.393 |
| 컨테이너 재조작 | 116.780 | 118.668 | 119.524 |
| 본선 유휴 | 80.916 | 62.467 | 66.909 |

기존 비용식을 그대로 적용했다. 종료 시점까지의 미완료 트럭 비용은 포함하지만, 그 뒤 완료까지의 비용이나 게이트 밖 일정 변경 부담까지 계산한 것은 아니다.
전체 모형에서 원래 요청보다 늦어진 진입은 32,681대·합계 33,370.25시간이다. 이 시간차는 실제 외부 대기의 측정값이 아니다.
요청·비용 기록 대조 6개 항목과 정책별 종료 장부 검사가 모두 통과했다. 접수 보존과 전건 완료는 구분한다.

## 2. 보정 전 10일 진단 — 9/15 결과 보존

세 정책 모두 시드(상황을 재현하는 난수 시작값) 9,500,000의 같은 기본 트럭 요청 69,000건·본선 작업 44,322회로 시작했다.
10일 전체의 확정 일별 비용을 합산했다. 트럭은 종료 뒤 2시간까지 추적한다. 아래 본선 수는 투입 수이며 완료 수가 아니다.

| 정책 | 총비용(억 원) | 기준 대비 절감률 | 트럭 완료(대) | 트럭 미투입(대) | 본선 투입(회) |
|---|---:|---:|---:|---:|---:|
| 배정 변경 없음 | 46.533 | 기준 | 68,830 | 170 | 43,394 |
| 전체 모형 | 38.494 | 17.28% | 68,820 | 180 | 43,295 |
| 수락 거절 기능 제거 | 39.432 | 15.26% | 68,864 | 136 | 43,267 |

절감률 = (배정 변경 없음의 총비용 − 해당 정책 총비용) / 배정 변경 없음의 총비용 × 100. 원 단위 원값으로 계산한 뒤 표시만 반올림했다.
이 실행에서 전체 모형은 거절 기능 제거보다 0.938억 원(2.38%) 낮고, 기준 대비 절감률 차이는 2.02%포인트다.
다만 트럭 완료 수는 전체 모형이 44대 적고 본선 투입 수는 28회 많다. 이 비용 차이 전부를 수락 기능의 효과로 분리할 수 없다.
수락 거절 기능 제거는 수락망의 거절 권한만 끈 비교다. 후보 정렬에는 수락망 점수가 남아 있어 수락망 전체 제거 실험으로 부르지 않는다.

### 비용 항목별 비교

단위: 백만 원. 크레인 추가 이동과 컨테이너 재조작 비용도 총비용에 포함한다.

| 비용 항목 | 배정 변경 없음 | 전체 모형 | 수락 거절 기능 제거 |
|---|---:|---:|---:|
| 트럭 체류·장시간 벌점 | 4,449.909 | 3,659.525 | 3,756.629 |
| 크레인 추가 이동 | 7.204 | 7.361 | 7.374 |
| 컨테이너 재조작 | 117.728 | 119.066 | 119.206 |
| 본선 유휴 | 78.427 | 63.448 | 60.019 |

전체 모형의 기준 대비 순절감액 중 98.32%가 트럭 체류 비용 차이에서 나온다. 이는 비용 항목의 분해이며 시간 조정 행동의 기여율과 같지 않다.
전체 모형은 기준보다 이동·재조작 비용이 높다. 거절 기능 제거와 비교하면 본선 유휴 비용도 더 높아 모든 항목이 함께 개선된 결과는 아니다.

## 3. 기존 논문에 사용된 28일 결과

원래 30일 실행의 가운데 28일(날짜 번호 1–28)이며 위 10일 진단과 평가 상황·기간이 다르다. 두 표의 절감률을 학습 전후 성능 변화로 비교하지 않는다.

| 정책 | 총비용(억 원) | 기준 대비 절감률 |
|---|---:|---:|
| 배정 변경 없음 | 99.958 | 기준 |
| 전체 모형 | 85.244 | 14.72% |
| 시간 조정만 | 86.522 | 13.44% |
| 블록 조정만 | 101.265 | -1.31% |

음수 절감률은 비용 증가다. 전체 모형과 시간 조정만의 차이는 약 1.28%포인트이며, 블록 조정만은 전체 기간 비용이 증가했다.
한가할 때의 블록 효과와 혼잡할 때의 시간 효과는 [기존 부하별 표](01-독립반복-부하별효과.md)에서 별도로 확인한다. 이번 10일에는 시간만·블록만 정책을 실행하지 않았다.

## 4. 해석 범위와 리뷰 대응

- 리뷰 1-4: 수락 거절 기능 비교의 관측 비용을 공개했다. 요청 처리 차이를 해결하고 수락망 전체 제거와 비교해야 별도 기여를 검증할 수 있다.
- 리뷰 1-1·1-5·리뷰 2: 이번 표는 재사용한 시드 한 번의 진단이다. 독립 반복·통계적 유의성·다른 환경 검증을 대신하지 않는다.
- 리뷰 1-2: 보정 후 미투입은 없지만 게이트 밖 대기·일정 변경 비용은 여전히 포함하지 않는다. 15.75%를 현실 제약과 외부 부담을 적용한 절감률로 쓰지 않는다.
- 보정 전후 차이에는 요청 보존과 대상 지정 시점의 영향이 함께 있다. 새 학습의 개선 효과로 비교하지 않는다.

다음은 YR-317-g(요청 처리 계약 검증)에서 블록별 공급 계획과 반출 컨테이너의 연결을 확인하는 작업이다. 비용이 낮아도 필요한 컨테이너가 없어 작업이 남는 문제를 직접 다루기 위해 필요하다.
