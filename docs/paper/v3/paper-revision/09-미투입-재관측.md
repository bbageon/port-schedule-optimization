## 진행하는 이유

기존 10일 비용표에서 전체 모형은 기준보다 17.28% 낮았지만, 트럭 170/180/136대가 정책별로 다르게 미투입됐다.
본선 요청 44,322회도 모두 투입되지 않았다. 리뷰 1-1의 독립 반복과 1-4의 구성요소 비교를 해석하려면 이 차이가 생긴 상태를 확인해야 한다.
새 기록을 켠 실행으로 실패 순간의 재고·예약과 본선 완료를 관측한다. 이 단계에서 누락의 현실 비용이나 새 제약을 임의로 추가하지 않는다.

## 확인할 결과

- 실제 재고가 없는 경우와 재고가 모두 다른 작업에 지정된 경우를 구분한다.
- 실제 공간 부족과 미도착 작업·예약분에 따른 투입 제한을 구분한다.
- 본선 원 요청 = 미투입 + 투입, 투입 = 완료 + 잔여 + 미추적 수를 대조한다.
- 트럭 요청별 사건·기존 비용식을 독립된 분석 코드로 재계산한다.
- 세 정책의 비용표와 기존 10일 실행 대비 날짜별 비용·행동·처리 수 차이를 남긴다.
