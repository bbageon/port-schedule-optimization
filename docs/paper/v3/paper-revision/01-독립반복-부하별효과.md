# 독립 반복·공간/시간 기여·민감도 설계

대상: 리뷰 1-1·1-4·1-5, 리뷰 2의 단일 실행 문제. **아래 새 실험 수는 실행 전 확정할 설계안이며 실행 결과가 아니다.**

## 1. 마지막 원고의 결과 검산

원자료: [주실험](../../../../outputs/v3/judge-30d/arms), [재계산값·파일 지문](source-audit.json).
30일 중 앞뒤 하루를 제외한 28일의 총비용 절감률은 전체 14.7204%, 시간만 13.4416%, 공간만 −1.3070%다.
전체가 시간만보다 더 절감한 값은 기준 비용 대비 **1.2788%포인트**이며, 시간만의 절감액이 전체 절감액의 91.31%다.

다음은 §5.2·그림 2의 같은 부하 날짜들을 합친 값이다. 단위는 **백만 원**, 양수는 배정 변경 없음 대비 절감, 음수는 비용 증가다.

| 하루 트럭 수 | 해당 일수 | 전체 | 시간만 | 공간만 | 전체의 추가 절감: 전체−시간만 |
|---:|---:|---:|---:|---:|---:|
| 3,500 | 12 | 47.221 | −12.608 | 57.073 | 59.828 |
| 5,000 | 8 | 59.832 | 29.414 | 67.213 | 30.419 |
| 7,500 | 4 | 32.004 | 7.527 | 0.384 | 24.477 |
| 12,500 | 2 | 610.751 | 572.650 | −14.242 | 38.102 |
| 15,000 | 2 | 721.616 | 746.614 | −241.072 | −24.998 |

해석: 한가한 두 구간에서 공간만이 전체 모형보다도 좋다. 가장 혼잡한 구간에서는 시간만이 전체 모형보다 좋다.
공간 조정이 낮은 부하에서 도움이 된다는 사용자 설명은 맞지만, 현재 선택 정책이 각 조건에서 최선으로 작동한다는 근거는 아니다.
일수가 다르므로 합계 막대의 높이로 부하 간 평균 효과를 비교하지 않는다. 개정 그림은 일평균·트럭당 값도 함께 보여준다.

혼잡 빈도를 바꾼 기존 추가 실험도 재계산했다. 비용은 가운데 28일, 행동 비중은 원고 검산기가 사용한 전체 30일 기준이다.

| 기존 환경 | 혼잡일 수/28일 | 전체 절감액, 백만 원 | 시간만 절감/전체 절감 | 공간 행동 비중, 30일 |
|---|---:|---:|---:|---:|
| quiet | 2 | 822.783 | 66.53% | 32.04% |
| mixed | 6 | 2,550.783 | 78.61% | 21.52% |
| heavy | 14 | 5,047.200 | 81.49% | 11.88% |

해석: 혼잡일이 많을수록 시간 조정의 역할이 커지는 경향은 이미 있다. 그러나 이 세 조건은 같은 단일 시드 9,900,980에 기반한다.
주실험의 혼잡 4일 점은 다른 시드 9,900,950이므로 네 점 모두를 동일 시드 통제 실험으로 설명하지 않는다.
행동 비중을 28일로 맞추면 위 세 조건은 각각 31.60%, 20.77%, 11.16%다. 개정에서는 기간을 통일하고 변경 사실을 명시한다.
주실험의 일별 행동 기록은 해당 arm 파일에 없으므로 28일 값을 추정해서 채우지 않는다.

## 2. 독립 반복과 통계 단위

1. 기본 제안은 **독립적인 30일 실행 20개**다. 각 실행 안에서 상태를 계속 이어가고 동일한 앞뒤 제외 규칙으로 평가한다.
2. 같은 실행 시드와 외생 작업 목록을 모든 정책에 공통 적용한다. 정책 차이 때문에 처리량이 바뀌어도 요청 목록 자체는 바뀌지 않아야 한다.
3. 비용 차이는 `D_r = 기준 정책의 28일 비용 − 비교 정책의 28일 비용`으로 계산한다. 독립 표본은 날짜가 아니라 실행 `r`이다.
4. 주지표는 실행별 비용 차이의 평균과 95% 신뢰구간이다. 신뢰구간은 **실행 전체를 20,000번 재표집**해 만들고 시드별 점도 공개한다.
5. 유의성 검정이 필요하면 실행별 대응 차이로 계산한다. 여러 우위 주장은 주비교를 미리 정하고 Holm 보정(여러 검정의 우연한 양성 판정을 줄이는 방법)을 적용한다.
6. 20개라는 수는 실행 전 정밀도·계산량을 검토할 계획값이다. 기존 진단 분산과 최소 의미 있는 차이로 최종 수를 동결하고 결과를 본 뒤 유의해질 때까지 늘리지 않는다.
7. 현재 원고의 일별 부호검정·Wilcoxon 검정·일별 층화 재표집은 독립 확증 근거에서 제외한다. 기존 28일 도표는 한 실행의 기술 통계로 남긴다.
8. “전체 날짜보다 혼잡일을 늘리면 된다”는 식의 권고는 수정한다. 자연스러운 혼잡 빈도를 사전에 정하고 독립 실행을 늘리는 것이 기본이다.

시드 주의: 현재 월 생성기는 날짜별 시드를 파생한다. 월 시작 시드만 다르게 썼더라도 1,000씩 이동하면 날짜 시드가 겹칠 수 있다.
학습·후보 진단·확증에서 **실제 파생 난수열 식별자까지** 대조해 겹치지 않는 목록을 저장한다. 정책 간 공통 난수는 의도된 대응 설계다.
대조 정책 때문에 난수 소비 순서가 달라지지 않도록 외생 도착·작업 속성은 사건별 고정 목록으로 재생하고 대조한다.

## 3. 공간과 수락망을 구별하는 비교

핵심 비교 8개 정책 × 20개 실행 = **160개 정책-월**이 기본 예산안이다. 먼저 기존 환경에서 아래 비교를 잠근다.

| 비교 정책 | 무엇을 확인하는가 |
|---|---|
| 배정 변경 없음 / 전체 모형 | 제안한 정책의 총비용 효과 |
| 시간만 / 공간만 | 동일한 동결 모형에서 행동 축을 제한했을 때의 기여 |
| 거절만 제거, 기존 `RL_NOVETO` | 수락 거절 기능의 효과. 수락망 점수를 이용한 정렬은 남아 있음 |
| 수락망 완전 제거, 신규 대조군 | 거절과 점수 기반 우선순서를 모두 제거하고 기존 작업 순서로 확정. 별도 수락망 전체의 효과 |
| 공간·시간 규칙 정책 | 같은 정보와 후보 범위를 사용하는 비학습 대조 |
| 시간 규칙 정책 | 시간만 모형의 효과가 단순 시간 이동 기능 때문인지 확인 |

주비교는 전체 대 시간만, 전체 대 배정 변경 없음, 전체 대 수락망 완전 제거다. 거절만 제거는 기능 분해용이다.
완전 제거 시에도 기존의 물리적 수용 가능 여부 확인은 유지한다. 동일한 용량 확인까지 없애면 학습망 효과와 실행 가능성이 섞인다.
실제로 자원 경합이 드물다면 수락망 순서의 차이도 작을 수 있다. 경합 횟수와 확정된 작업 집합의 차이를 함께 보고한다.
행동 제한은 “현재 동결 모형에서의 기여”다. 각 제한 정책을 따로 최적화한 것처럼 표현하지 않는다.
독립 학습의 안정성까지 주장하려면 초기·최종 가중치를 함께 저장한 복수 학습 시드가 별도로 필요하다. 기존 첫 반복 가중치를 미학습 모형으로 부르지 않는다.

## 4. 부하별 효과를 확증하는 방법

- 외생 일 물량 다섯 단계는 기존 3,500/5,000/7,500/12,500/15,000을 유지한다. 각 실행의 같은 물량 날짜를 대응시킨다.
- 주결과는 전체 비용이고 부하별 차이는 사전 지정한 보조 결과다. 3,500·5,000은 낮은 물량, 12,500·15,000은 높은 물량으로 미리 묶되 다섯 단계 표도 공개한다.
- 부하별 `전체−시간만`, `공간만−변경 없음`의 절감 차이를 일평균·트럭당 값과 월 단위 재표집 구간으로 제시한다.
- 비용뿐 아니라 공간/시간 행동 수, 시간 이동량, 대기열 최고값, 블록별 부하 차이, 주행·재조작·본선 비용을 함께 보여준다.
- 같은 외생 물량이라도 전날 잔여 작업 때문에 혼잡도가 달라질 수 있다. 결정 직전 대기열·재고는 기전 설명용으로 기록한다.
- 정책이 바꾼 대기열로 날짜를 다시 분류한 뒤 이를 외생적인 조건 효과처럼 해석하지 않는다.
- “한가하면 블록, 혼잡하면 시간”이라는 수기 전환 규칙을 추가하지 않는다. 학습 정책이 이 선택을 잘하는지가 연구 질문이다.

판정: 전체의 추가 이득이 낮은 부하에서 반복되고 높은 부하에서 사라진다면 기여를 조건부로 좁힌다.
전체가 시간만보다 나쁜 구간이 반복되면 후보 선택·수락 진단으로 원인을 밝히고 불리한 결과도 보고한다.

## 5. 90.5% 집중에 필요한 보완

| 축 | 구체적인 비교 | 4번만으로 해결되지 않는 이유 |
|---|---|---|
| 혼잡 빈도 | 기존 2/6/14일 조건을 독립 월들로 반복; 주실험은 별도 기준 조건 | 단일 달의 피크 발생 우연성을 제거해야 함 |
| 혼잡 연속성 | 같은 총물량·혼잡일 수에서 분산 배치와 연속 배치를 비교 | 전날 상태가 다음 날에 미치는 누적 효과가 다름 |
| 수요 파형 | 필요 시 같은 일 물량에서 집중 도착 폭·본선 작업 겹침을 한 축씩 변경 | 하루 총량만으로 분 단위 혼잡을 설명할 수 없음 |
| 기존 비용 가정 | 대기·재조작·본선·이동 네 계수를 각각 0.5/1/2배로 재합산 | 특정 비용 항의 큰 가중치가 절감률을 지배할 수 있음 |
| 운영 길이 | 30일 대 연속 90일, 첫 30일의 외생 입력은 일치 | 끝난 뒤로 작업을 미룬 효과와 누적 불안정성을 확인해야 함 |

빈도·연속성·기간의 확인은 기본 4정책(변경 없음/전체/시간만/공간만)으로 하고 모든 변형에 8정책을 곱하지 않는다.
각 축의 시드 수와 설정은 실행 전에 고정한다. 최종 원고 분량·계산량에 따라 추가 파형은 후속으로 남길 수 있다.
계수 재합산은 동결 정책 궤적의 비용 민감도다. 새 비용에서 다시 학습한 최적 성능으로 해석하지 않는다. 일정 변경 비용 신설은 이번 범위 밖이다.
90일 비교는 일당·트럭당 비용과 종료 시 잔여 작업, 동일한 잔여 작업 평가 규칙을 함께 제시한다. 30일마다 상태를 초기화하지 않는다.
피크일 제외와 실행 하나씩 제외한 계산은 민감도 설명용이다. 좋은 결과가 나오도록 피크일을 빼거나 주평가 표본을 바꾸지 않는다.

## 6. 서로 다른 세 가지 시간

- **60초**: 온라인 정책이 결정을 검토하는 주기.
- **3시간**: 학습 라벨을 만들 때 행동의 뒤따르는 비용을 관찰하는 길이.
- **30/90일**: 정책의 운영 성능을 누적 평가하는 기간.

리뷰의 운영기간 문제는 우선 세 번째를 비교한다. 라벨 관찰 길이를 3시간에서 6시간으로 바꾸면 학습 조건도 바뀌므로 별도 한 축 실험으로 취급한다.

## 7. 실제 처리시간과 재현성

온라인 검토 전체의 경과 시간을 잰다: 상태·후보 구성 → 특징 계산 → 제안·수락망 계산 → 경합 처리·배정 확정.
중앙값, 95번째·99번째 백분위수(100번 중 각각 느린 5번·1번이 시작되는 시간), 최대값, 60초 초과 비율을 보고한다.
빈 검토 주기와 실제 제안이 있는 주기, 낮은·높은 물량을 나눈다. 예열, CPU·스레드, 후보 수와 온라인 반사실 호출 0회도 기록한다.
전체 시뮬레이션 실행 시간이나 학습 18시간을 온라인 응답 시간으로 대신하지 않는다. 중첩 계측 구간을 더해 시간을 중복 계산하지 않는다.
모형 지문·소스 커밋·의존성·입력 특징·실제 초기 장치율·시드·실행 명령·원자료·표 재생성 명령을 함께 공개한다.
