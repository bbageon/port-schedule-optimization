## 무엇을 했나

같은 학습 시드(9,950,000, 7일)를 기존 공유형(수평)과 수직 끝단형에 각각 넣어 **시간정책 가중치를 환경별로 따로** 학습했다.
두 학습은 같은 초기 가중치·같은 예산(라벨 389건, 망 갱신 2,496회)이었고 소요는 수평 3.4시간, 수직 6.3시간이었다.
그다음 같은 평가 시드(30,300,000, 7일)로 각 환경에서 **자기 모델 vs 기준정책(재배정 없음)**을 비교했다. 마지막 날 체크포인트만 썼다.
평가 7일 물량: 7,500 · **5,000 · 15,000 · 3,500 · 12,500 · 7,500** · 5,000 (굵은 5일이 측정, 앞뒤 하루는 연결용).

## 해석

- **각 환경에서 배운 시간정책은 각 환경에서 이긴다.** 수평 6/7일, 수직 7/7일. [YR-317-h](27-수직형-단일시드-보완실험.md)의 전이 사례(수평 모델을 수직에 옮김, 28일 −0.77%, 미완료 증가)와 달리, 수직에서 직접 배운 모델은 물량 수준 전부에서 비용이 낮다. "수직형에서 이득이 없다"는 모델 탓이었지 환경 탓만은 아니었다는 뜻이다.
- **수직형에서는 여전히 처리량이 나빠진다.** 못 끝낸 트럭 246대·본선 잔여 25건 증가. 비용 감소를 운영 개선으로 자동 채택하지 않는다는 사전등록 원칙대로 두 수치를 함께 보고한다. 수직형은 기준정책부터 56,000대 중 2,505대를 7일 안에 못 끝내는 과부하 환경이다.
- **7일 학습은 30일 학습보다 이득이 작다.** 수평 −2.2%는 30일 학습 모델의 독립 시드 중앙값(약 −13%)보다 훨씬 작고, 시간 변경도 6.5%로 30일 모델(58%)보다 훨씬 소극적이다. 학습 일수가 짧아 정책이 보수적으로 수렴했다. 수직 모델은 74%를 바꾸며 공격적인데, 붐비는 환경에서 "미루면 비용이 준다"는 신호가 강하기 때문으로 보인다.
- **두 환경의 절대 비용(48억 vs 362억)을 방향 효과로 읽지 않는다.** 운반 차량 3대 제한·양하 정원·크레인 역할이 함께 바뀐 다른 환경이고, 학습 시드 1·평가 시드 1의 서술 사례다.
- 물량별 표는 한가 1일·보통 2일·혼잡 2일이라 방향만 본다. 수평 한가한 날 −2.2%(더 비쌈)는 하루 값이다.

"A vertical end-transfer layout was implemented; with the horizontal model transferred unchanged, time-only saved 0.77% on one 30-day seed while unfinished trucks increased. When separate time-only weights were trained inside each layout for the same 7-day seed and evaluated on one shared 7-day seed, the layout-specific policy was cheaper on 6/7 (horizontal, −2.2% over the five measurement days) and 7/7 days (vertical, −4.6%), while the vertical environment remained overloaded (2,505→2,751 unfinished trucks). These are single-seed descriptive cases, not a layout comparison."
