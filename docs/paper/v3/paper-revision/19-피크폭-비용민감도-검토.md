# 도착 피크 폭에 따른 일별 비용 비교 검토

결론: 비교할 필요가 있다. 다만 별도의 하루 초기화 실험을 추가하기보다, 폭을 바꾼 연속 월 실행에서 일별 자료와 월 전체 결과를 함께 분석한다.
이는 Reviewer #1의 서로 다른 수요 패턴에 대한 요구를 보완한다. 현재는 계획 검토이며 실제 비용 변화는 아직 계산하지 않았다.

## 1. 확인할 질문 두 가지

1. 같은 하루 물량에서 도착이 집중될수록 비용·대기·미완료가 어떻게 변하는가?
2. 그때 전체/시간만 모델의 기준 정책 대비 이득이 유지되는가? 전체가 시간만보다 추가로 도움이 되는가?

전체 모델의 비용만 보면 환경이 어려워진 효과와 정책 효과를 구별할 수 없다.
각 폭에서 재배정 없는 기준 정책·전체·시간만을 같은 입력으로 비교한다.
블록만의 독립적인 효과까지 주장하려면 공간만 정책을 추가해야 하며, 전체−시간만은 현재 전체 모델에서 공간 후보를 더 허용한 추가 효과다.

| 폭 조건 | 고정할 것 | 비교 결과 |
|---|---|---|
| 완만/기존/급격 | 일 물량·날짜 순서·트럭 속성·선박 계획·초기 상태·장비·비용·정책 가중치 | 정책별 비용·대기열·잔여·턴타임과 정책 간 차이 |

폭별 초기 상태는 월 시작에만 동일하게 둔다. 이후 잔여가 달라지는 것은 집중 도착의 누적 효과이므로 초기화로 지우지 않는다.
따라서 일별 비용 차이는 당일 피크와 이전 날짜의 누적 영향을 함께 포함한다. 순수한 당일 직접 효과라고 부르지 않는다.
같은 하루 시작 상태에서 갈라놓는 별도 진단은 기전이 불분명할 때 추가할 수 있지만 기본 반복의 필수 조건은 아니다.

## 2. 저장과 통계

- d2의 일별 기록을 그대로 쓴다. 최초 요청 물량, 하루 시작 잔여, 실제·블록별 대기열, 남은 야드 작업, 평균/90백분위 턴타임, 공간/시간 행동 비율, 비용 네 항을 보존한다.
- 그림: 가로축 폭 배수, 세로축 트럭당 비용 또는 하루 평균 비용. 정책별 선을 나누고 시드별 점/월 단위 불확실성을 표시한다.
- 표: 각 폭에서 기준·전체·시간만의 절대 비용, 기준 대비 절감액/절감률, 전체 대 시간만 차이, 완료율·종료 잔여.
- 물량 구간별 보조 표는 동일한 물량 날짜끼리 합산한다. 구간마다 날짜 수가 다르므로 단순 합계 높이로 효과 크기를 비교하지 않는다.
- 폭별 비용 변화는 같은 정책끼리, 정책 효과는 같은 폭끼리 짝비교한다. 독립 단위는 날짜가 아니라 월 전체다.
- 시간 조정으로 날짜가 바뀌어도 원래 요청일 비용 집합을 유지한다. 일별 비용은 트럭 항의 요청일 귀속과 나머지 항의 달력 날짜 귀속을 구분해 해석한다.
- 비용이 줄어도 미완료를 늘렸다면 운영 개선으로 인정하지 않는다. 날별 물량만으로 실제 혼잡을 확정하지 않는다.

## 3. 현재 곡선에 대한 중요한 확인

기존 코드는 24시간 균등 성분 38%와 세 정규분포 성분을 더한다. 성분 중심은 10/15/21시, 폭은 1.5/2.5/1.0시간이다.
피크 성분 상대 가중치는 0.317/0.633/0.050이다. [실제 함수](../../../../src/yard_rl/v3/world/integrated/terminal_stream.py).

15초 간격으로 합성 밀도의 국소 최대를 계산한 결과:

| 폭 배수 | 구성 성분 수 | 합성곡선의 눈에 보이는 봉우리 수 |
|---:|---:|---:|
| 1.50 | 3 | 1 |
| 1.20 | 3 | 2 |
| 1.10 | 3 | 2 |
| 1.05 | 3 | 3 |
| 1.00 | 3 | 3 |
| 0.60 | 3 | 3 |

즉 1.5배를 쓰면 “세 피크 성분의 중심과 가중치 유지”라고 써야 한다. 보이는 피크 수까지 보존한다는 설명은 맞지 않는다.
보이는 봉우리 3개가 필수라면 완만한 쪽의 배수를 더 좁게 잡아야 한다. 1.05배는 이번 계산에서 3개지만 변화 폭이 작아 약한 민감도 조건이라는 한계가 있다.
성분 중심을 고정해도 겹침 때문에 합성곡선의 실제 최대 시각은 달라질 수 있다.

또한 현재 함수는 0~24시간 전체를 한 번 정규화한다. 저녁 피크 등의 꼬리가 잘리는 양이 폭마다 달라져 실제 성분 비중도 조금 변한다.
균등 성분의 실제 비중은 기존 약 38.004%, 1.5배 약 38.150%다. 입력 파라미터의 w 고정과 기간 안의 실제 물량 비중 고정을 구분한다.
실제 비중까지 엄밀하게 유지하려면 성분별 24시간 질량을 보존하는 보정을 설계하되, 1.0배가 기존 입력을 정확히 재현하는지도 검사해야 한다.
[산술 검산](../../../../outputs/reports/yr317_v3_peak_width/curve-inspection.json) · [재현 스크립트](../../../../scripts/v3/inspect_arrival_peak_width.py). 시뮬레이션 실행 0회, 비용 결과가 아니다.

## 4. 계산 예산과 주장 범위

- 독립 반복 d의 기본 20개월×3정책을 우선한다. 전체 20개월에 세 폭을 곱하면 180개 정책-월이며 기본 60개 외에 120개가 추가된다.
- 4일 마감에 맞춰 폭 검증은 실행시간을 보고 사전에 고정한 시드 부분집합으로 제한할 수 있다. 시드는 결과를 보기 전에 고르고 유리한 시드로 교체하지 않는다.
- 기존 폭 1.0은 입력·계측·정책·평가 계약이 동일할 때만 기본 반복 결과를 재사용한다. 따라서 별도 하루 실험을 중복 실행할 필요가 없다.
- 기존 가중치로 폭 변화에 대한 민감도를 먼저 본다. 폭별 재학습까지 섞으면 새 학습 효과와 강건성을 구분하기 어렵다.
- 이 실험은 예약 슬롯 정원·시간 변경 비용을 추가하지 않는다. 제약을 넣어도 시간 조정이 유리하다는 주장은 별도 비교가 있어야 한다.
