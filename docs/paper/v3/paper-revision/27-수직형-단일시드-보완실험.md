# 수직형 단일 시드 보완 실험

2026-09-19. 담당: [기본 배치 검증 작업](../../../../.claude/docs/dashboard-task-specs/YR-317-h-v3-review-basic-layouts.md).

## 이번 결정

사용자는 기존 독립 실험의 적절한 기준을 수직형에 가져와 계산 시간을 줄이고, 두 정책을 병렬 실행하도록 요청했다.
수평형을 새로 구현하고 네 실행을 모두 다시 만드는 대신, 기존 환경 결과 두 개를 재사용하고 수직형 두 개만 추가한다.
이는 기존 공유형과 수직 끝단형에서 각각 시간 조정의 효과를 확인하는 사례다. 정교한 수평·수직 배치의 순수 인과 비교는 아니다.

## 재사용 기준

| 항목 | 고정 내용 | 해석 |
|---|---|---|
| 시드 | 원래 명단 첫 번째 20,000,000 | 이득이 큰 시드를 고르지 않음 |
| 입력 | 합성곡선·물량·초기 재고·보정 선박 계획 | 원본 지문을 기존 평가와 대조 |
| 정책 | 기준정책·시간정책, 기존 모델 고정 | 새 학습 없음 |
| 기간 | 30일 연속+2시간 잔여 처리 | 중간 28일 주 분석·30일 보조 분석 |
| 비용 | 기존 네 비용 항·단가·귀속 방식 | 새 일정 변경 비용 검증은 아님 |
| 관측 | 300초 간격·요청·장부·일별 비용과 상태 | 미완료와 손실도 함께 보존 |

수직형 도로 이동시간은 구조에 맞게 파생한다. 원본 입력이 같다는 것과 실행용 이동시간까지 두 환경이 같다는 것은 다르다.
수직형 두 정책끼리는 원본과 파생 입력이 모두 같아야 한다.

## 기존 전량 완료 검사와 구분

기존 독립 실험은 기록 오류와 종료 잔여를 나눠 판정한다. 수직형 초기 자격 검사는 전량 완료를 다음 정책의 시작 조건으로 두었다.
초기 실패는 그대로 보존하고, 이번 운영 사례의 기록 검사에는 원래 독립 평가의 기준을 적용한다.
요청 누락·물리 연결·비용 장부 오류는 중단 사유다. 남은 작업과 마감 초과는 결과로 저장하며 운영 개선 판정에 함께 사용한다.
단순 비용 감소만으로 전량 완료·안정 운영·일반적 우위를 선언하지 않는다.

## 실행과 해석

- 별도 진단 시드의 두 정책 연결 검사 후 수직형 본 실행 두 개를 CPU 18·19에서 병렬로 실행한다.
- 기존 실험과 모델·입력·감독 프로세스를 유지한다. 새 실행은 별도 고정 소스와 출력 경로를 쓴다.
- 기존 공유형의 같은 시드 두 결과는 완료·감사를 확인한 뒤 재사용한다. 완료 속도에 따라 시드를 바꾸지 않는다.
- 내부 운반시간·양하 정원·크레인 역할·후보 보존 규칙 차이를 공개한다. 각 환경의 기준정책 대비 시간정책 차이를 본다.
- 한 시드의 날짜들은 독립 반복이 아니다. 결과는 구조 변경에 대한 제한적인 적용 사례로 제시한다.

실행 전 상세 조건: [고정 계약](../../../../outputs/reports/yr317_v3_vertical_transfer/prereg.md).
현재 단계는 실행기 준비다. 실제 시작은 별도 시작 기록과 프로세스 확인으로 보고한다.
