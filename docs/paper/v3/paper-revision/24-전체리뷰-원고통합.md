# 전체 리뷰 답변서·원고 통합 결과

2026-09-18 · YR-317-i(전체 리뷰 문서 통합). **12쪽 통합 초안을 만들었다. 독립 실험의 최종 결과가 없는 제출 전 작업본이다.**

## 진행사항

- [통합 원고 PDF](main-integrated.pdf) · [원고 소스](main-integrated.tex) · [전체 영문 답변서](23-review-response-draft.md).
- 기존 11정책 성능표와 그림 3개를 보존했다. 성능표는 PDF 8쪽, 부하별 효과는 9쪽이다.
- 일별 검정과 일별 재표집 구간을 독립 반복의 확증으로 제시하던 문장을 제거했다.
- 20개 독립 월, 같은 입력의 네 정책, 고정 가중치, 요청 보존·공급 보정, 미완료 작업 공개를 실제 실행 계약에 맞췄다.
- 원래 세 정책의 두 주비교와 나중에 추가된 Block-only 비교를 구분했다. 각각 97.5% 구간이며 네 비교 전체의 한 묶음 보장으로 설명하지 않는다.
- 후보 점수의 조건부 정당성, 수락망의 거절 기능과 정렬 기능, 현실 제약·외부 비용의 누락, 운영자 업무 흐름을 한 원고에 통합했다.
- 실제 코드에 맞춰 Full의 후보가 블록 또는 시간 한 축을 바꾼다고 정정했다. 초기 장치율은 월 생성기의 45%로 맞추고, 합성곡선은 통지 시각이 아닌 요청 도착 시각의 분포라고 명시했다.
- 기존 `main.tex/pdf`와 9/15 부분 개정 `main-revised.tex/pdf`는 보존했다. 실행 코드·모델·사전등록·진행 중 실험은 변경하지 않았다.

## 검증과 재현

- [변경 기록](integrated-revision.json), [원고 차이](integrated-revision.patch), [자동 검증](integrated-validation.json).
- 문서 검사 28개 통과, 산출물 커밋 `3082402` 원격 반영 확인. [작업표·명세·증거 감사](dashboard-integrated-audit.json)에서 i·b·f의 문서 범위 완료가 일치한다.
- PDF를 두 번 컴파일하고 12쪽 전체를 이미지로 확인했다. 표·그림·수식의 잘림과 겹침이 없고, 기존 글꼴·본문 폭을 유지했다.
- 참고문헌 22개와 상호참조, 원본·그림 지문, 기존 절감률, 답변서의 근거 링크를 검사했다. 알려진 문서 클래스 경고 외 넘침·미정의 참조는 없다.
- 답변서의 페이지는 해당 절의 시작 페이지다. 최종 실험 표가 들어가면 다시 확인해야 한다.
- 아래 명령은 문서 생성·검사만 수행한다. 시뮬레이션이나 학습을 시작하지 않는다. `pdflatex`와 Python의 `pymupdf`가 필요하다.

## 예정사항

- YR-317-d(독립 반복 비교): 진행 중인 네 정책의 실행과 검사를 마친 뒤 비용·미완료 작업·월 단위 구간을 원고와 답변서에 넣는다. 이것이 일관된 성능에 관한 핵심 근거다.
- YR-317-c(후보 선택 검증): 같은 상태의 후보를 실제 비용으로 비교해 점수 순위가 유효한지 확인한다. 설명만으로 남은 방법론 질문을 해결할 수 없다.
- YR-317-e(온라인 시간 측정): 전체 의사결정에 걸리는 시간을 재어 실제 사용 가능성을 판단한다. 월 시뮬레이션 소요시간과는 다른 지표다.
- YR-317-d3·h(피크 폭·두 기본 구조): 등록된 범위의 추가 검증 대상으로 유지한다. 이번 문서 통합이 이 실험들의 완료를 뜻하지 않는다.

전체 묶음 YR-317은 미완료다. 독립 결과를 확인하기 전에는 `14.72%`를 새 환경에서도 재현한 수치로 사용하거나, 낮은 부하에서는 블록·높은 부하에서는 시간이라는 일반 규칙으로 확정하지 않는다.
