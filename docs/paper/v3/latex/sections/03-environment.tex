\section{실험환경}

\subsection{문헌 기반 합성환경}
제안한 재배치 아키텍처의 성능은 수치 실험으로 확인한다. 실험을 되도록 현실에 가까운
조건에서 수행하기 위해, 기존 컨테이너 터미널 연구가 보고한 규모와 운영 범위를 가능한
범위에서 사용했다. 따라서 실험 대상은 특정 터미널의 운영자료를 복제한 환경이 아니라
\emph{문헌 기반 합성환경}이다. 선행연구의 값을 그대로 사용한 경우와 그 범위 안에서
본 연구가 정한 값을 표~\ref{tab:env}처럼 구분한다.

따라서 21블록, 정확한 수요량과 도착곡선 계수는 본 연구의 실험 설계값이다. 인용은
선택한 규모와 변동 구조가 기존 연구의 모형 범위에 놓인다는 근거이며, 특정 항만의
운영자료를 뜻하지 않는다.

\subsection{터미널과 시간 설정}
야드는 21블록이고 블록마다 야드 크레인 2기를 두어 모두 42기다. 블록 용량은 1,440
슬롯이며 시작 점유율은 65\%다. 게이트와 안벽은 반대쪽에 있는 1차원 수평 배치이고,
정책 결정 간격은 60초다. 운영은 30일 연속이며 첫날과 마지막날을 제외한 가운데 28일을
비교한다. 크레인 작업순서는 실제 작업을 우선하고 그 안에서 예상 처리시간이 짧은
작업을 먼저 수행하는 규칙이다.

하루는 터미널이 자정에 멈춘다는 뜻이 아니라 비용과 중간 결과를 나누는 절단면이다.
야드 재고, 대기열, 크레인 상태와 미완료 작업은 다음 날로 이어진다. 첫날은 초기 상태와
연속 흐름을 연결하고, 마지막날은 앞선 작업의 잔여 효과를 보존한다.

\subsection{외부 트럭 수요와 도착 과정}
$d$일의 일일 수요 $D_d$ 는 $\{3{,}500,\,5{,}000,\,7{,}500,\,12{,}500,\,15{,}000\}$
대 위의 이산분포에서 확률 $\{0.30,\,0.30,\,0.25,\,0.10,\,0.05\}$ 로 뽑았다. 앞의 셋은
원활·보통·높은 수요, 뒤의 둘은 혼잡·초혼잡 조건이다. 하루 안에서 각 작업의 통지
시각은 시간대별 도착밀도 $f(t)$ 에서 뽑았으며, 이는 24시간 균등 바닥과 정규분포
봉우리의 혼합이다.

\begin{equation}
f(t)=0.38\,U(0,24)+0.62\sum_{m=1}^{3}w_m
\mathcal N_{[0,24)}(t;\mu_m,\sigma_m^2),
\end{equation}
\begin{equation}
(\mu_m,\sigma_m,w_m)\in
\{(10,1.5,0.317),(15,2.5,0.633),(21,1.0,0.050)\}.
\end{equation}

시간 단위는 시(hour)이고 절단된 밀도는 하루 합이 1이 되도록 다시 정규화한다.
시간대별 도착확률 모형과 도착 패턴의 체류시간 영향은~\cite{ref19,ref20}을 따른 문제
설정이며, 혼합비와 중심시각은 수요수준별 혼잡 민감도를 비교할 수 있도록 정한 연구
설계값으로, 특정 터미널에 적합시킨 추정값이라고 주장하지 않는다.
그림~\ref{fig:arrival}이 이 곡선을 보여 준다. 균등 바닥이 야간에도 도착을 0 으로
두지 않으므로, 날 경계를 넘어 이어지는 야드 상태가 빈 밤의 산물이 아니라는 점에
유의한다.

\subsection{선박과 안벽 작업}
선박은 세 등급으로 나누고 기항 작업량은 선박 용량의 일정 비율로 생성했다
(표~\ref{tab:vessel}). 매개변수는 다음처럼 생성했다. 용량 $C$ TEU 인 선박의 기항
작업량은 $u\sim U[0.15,0.30]$ 에 대해 $C\cdot u$ 로 뽑았다. 하루 구성은 소형 2척과
중형 1척이며 대형 1척을 30\% 확률로 더했다. STS 1기의 처리율은
\SI{27.5}{move/h}로 두며 이는 문헌의 24·30·36 \si{move/h} 실험 범위 안에
있다~\cite{ref17}. 여러 STS의 막힘은 합산한 뒤 배정 대수로 나누어 선박 단위
유휴시간으로 환산한다.

\subsection{야드 크레인 능력의 단위}
크레인 1기의 기준 서비스시간은 \SI{180}{\second}/move다. 이론상 총 이동능력은
다음과 같다.

\begin{equation}
\mu_{YC}=21\times2\times\frac{3600}{180}=840\ \text{move/h}.
\end{equation}

\si{move/h}는 컨테이너 이동 횟수이며 \si{truck/h}와 다르다. 트럭 한 건은 이동과
재취급을 여러 번 요구할 수 있고 실제 서비스시간도 위치와 작업 종류에 따라 변한다.
장비 성능을 해석할 때 이동 종류, 자동화 지연과 연계 차량 조건을 함께 적어야 한다는
지침을 따른다~\cite{ref6}.

\subsection{비용함수}
날짜 구간 $[d,d+1)$의 총비용은 네 항의 합으로 정의한다.

\begin{equation}
\Phi_d=C_{wait,d}+C_{move,d}+C_{rehandle,d}+C_{vessel,d}.
\end{equation}

트럭 체류는 시간당 40,000원이며 1시간 초과분에 같은 단가를 더한다. 안전운임을
화폐 기준점으로 사용하고 시간 환산은 연구값이다~\cite{ref12}. 추가 크레인 이동은
작업시간당 60,000원, 재취급은 회당 2,000원으로 두며 둘 다 연구 설계값이다. 선박
유휴는 \SI{2.99}{\won/GT\per hour}로, 접안 초과요율 29.9원/10GT·시간을
환산했다~\cite{ref22}.

트럭 $i$의 터미널 체류시간을 $h_i$, 추가 크레인 작업시간을 $m$, 재취급 횟수를 $R$,
선박 $v$의 정책 관련 유휴시간을 $T_v$라 하면 다음처럼 계산한다.

\begin{equation}
C_{wait}=\sum_i 40{,}000\{h_i+\max(0,h_i-1)\},\quad
C_{move}=60{,}000\,m,\quad C_{rehandle}=2{,}000\,R,
\end{equation}
\begin{equation}
C_{vessel}=\sum_v 2.99\,GT_v\,T_v.
\end{equation}

접이안과 검역처럼 재배치 정책이 바꾸지 않는 구조적 선박 시간은 진단값으로 분리한다.
네 비용 항은 같은 날짜 경계의 누적값 차이로 계산한다.
