## 작업본(`../latex-en`)과 무엇이 다른가

내용을 **줄인 판**이다. 21쪽 → 12쪽. 수치·주장은 같고(같은 진단 대역 시드
9,900,950), 같은 정보를 본문·표·그림·캡션에서 여러 번 말하던 부분을 한 번만
말하도록 합쳤다.

| | 작업본 | 제출본 |
|---|---|---|
| 그림 | 7개 | **3개** — 아키텍처 · 수요수준별 분해 · 학습곡선 |
| 표 | 4개 | **2개** — 설정 통합표 · 주비교 통합표 |
| 관련연구 | 논문별 소개 | **연구흐름 3문단** |
| 실험환경 | 설정을 본문에 서술 | **설정 통합표 + 평가 프로토콜을 이 절로** |
| 결과 | 6개 절 | **3개 절** |

빠진 그림: 개념도(아키텍처 그림이 포함) · MLP 구조(21→64→64→1 한 문장으로) ·
수요 분포(설정표의 수요 행) · 날짜별 짝비교(통합표의 승수와 p, 예외 이틀은 캡션에).

빠진 표: 선박 등급(설정표에 흡수) · 수요수준별 분해(그림 2와 같은 값이었다.
시각만 1.344 · 블록만 −0.131 · 상호작용 0.258 = 합계 1.471 십억원을 본문에 남겨
91.3% 의 근거가 사라지지 않게 했다).

## 작업본과 달라진 서술 두 곳

- **`First-iteration model`** — 작업본의 "학습 전 모형"은 틀린 이름이다. 판정 실행이
  쓴 `--ckpt-early` 는 `ckpt_000.pt` 이고, 이 파일은 **1회차 갱신 뒤** 저장된다
  (`train/loop.py` 의 `TrainState.save` 가 `on_day` 끝에서 불린다). 그래서 제출본은
  "30회차 중 첫 회차 이후 모형" 으로 적는다.
- **시간 축 비교의 두 검정** — 시간만 비교하면 규칙이 더 많은 날 이기지만(8/28,
  부호검정 p=0.036) 부호순위는 차이를 못 찾고(p=0.399) 총액은 학습 정책이 10.0억원
  낮다. 작업본은 승수만 적었는데, 제출본은 세 값을 같이 적어 "자주 이기는 것과 크게
  이기는 것은 다르다" 를 그 자리에서 보인다.
