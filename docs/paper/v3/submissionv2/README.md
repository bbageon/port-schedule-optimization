# submissionv2 — 혼잡 빈도 민감도를 반영한 판

`submission/` 을 그대로 복사한 뒤, **혼잡 빈도 민감도 실험**(env-quiet /
env-mixed / env-heavy)의 결과를 반영한 판이다. `submission/` 은 손대지 않았다.

**빌드**: `pdflatex main.tex` 를 두 번.
**검증**: `python scripts/v3/verify_submission.py docs/paper/v3/submissionv2`

## 왜 만들었나

§5.4 의 행동 분해가 대역 사이에서 **부호까지 뒤집혔다** — 시각의 몫 91.3% ↔ 53.8%,
블록만 항 −0.131 ↔ +0.394 (십억원). 원인 후보는 **혼잡일 빈도**였다(진단 4일 vs
판정 6일). 시드를 9,900,980 으로 고정하고 혼잡 파도 모양도 통일한 채
**혼잡일 빈도만 2 / 6 / 14 일**로 바꿔 다시 쟀다.

## 무엇이 드러났나 (모두 원자료에서 재계산)

| | 한산(2일) | 적당(6일) | 혼잡(14일) |
|---|---|---|---|
| 전체 감소 | 0.82 bn (12.9%) | 2.55 bn (18.1%) | 5.05 bn (17.0%) |
| 시각만 몫 | 67% | 79% | 81% |
| **블록만** | **+0.23 bn** | **−2.40 bn** | **+1.17 bn** |
| 학습 몫 | 0.18 bn | 1.51 bn | 1.60 bn |
| **학습 중앙값/일** | +0.8 M | −0.1 M | **+9.7 M** |
| 학습 부호검정 | 17/28 p=0.345 | 14/28 p=1.000 | **22/28 p=0.004** |
| 무재배치 대비 | 27/28 | 27/28 | 28/28 |
| **공간 행동 비중** | **32.0%** | **21.5%** | **11.9%** |

**흔들린 것**: 행동 분해. 블록만 항은 부호가 뒤집히고, 적당 환경에서는
15,000대 하루가 음(−)의 대부분을 만든다 — 28일로는 추정되지 않는 양이다.

**흔들리지 않은 것 넷**: ①공간→시간 전환이 **단조**(2→4→6→14일에 대해
32.0 → **25.7** → 21.5 → 11.9%, 가운데 25.7% 가 본편 실행이다) ②시각이 어디서나
최대 요소 ③핵심 주장은 모든 환경에서 성립 ④학습 효과는 혼잡할 때만 잡힌다.

## submission/ 과 무엇이 다른가

| 자리 | submission | submissionv2 |
|---|---|---|
| 초록 | *"Arrival-time adjustments accounted for **91.3%**"* | 그 수치를 빼고 **단조 전환**(32%→12%)과 *학습은 가장 혼잡한 환경에서만 통계적으로 잡힌다* 로 대체 |
| §5.4 | *"therefore explains 91.3%"* + 대역 한정 두 문장 | *"not stably estimated at 28 days"* + 세 환경 수치 + **단조 전환** |
| §5.6 | *"or **45.9%** of the total reduction"* | 비율 삭제 — 절대액 셋과 **중앙값** 셋, 부호검정 p 셋으로 대체 |
| 결론 | *"carry no estimate of variation across realisations"* | 민감도 결과로 교체 — 집계 결과와 전환은 유지되지만 분해는 28일로 안 잡힌다 |
| 그림 2 캡션 | — | *"specific to this demand mix"* 한 줄 추가 |

**왜 91.3% 와 45.9% 를 뺐나**: 91.3% 는 다섯 자료 중 **가장 바깥값**이고
(67 · 79 · 81 · 53.8 · 91.3), 45.9% 는 분모(전체 감소)가 환경마다 두 배씩 달라
학습 몫이 거의 같아도(1.51 vs 1.60 bn) 59% vs 32% 로 갈린다.
