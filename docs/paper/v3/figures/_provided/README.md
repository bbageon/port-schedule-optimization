# 원본 이미지 (논문에 쓰는 그림의 출처)

사용자가 만든 이미지 두 장의 **자르지 않은 원본**이다. 논문에 실리는 것은 이 원본에서
여백(과 MLP 의 그림 안 제목)만 잘라낸 사본이다.

| 원본 | 논문에 실리는 파일 | 자른 내용 |
|---|---|---|
| `MLP.png` | `../fig-mlp.png` | 그림 안의 "MLP" 제목 + 여백 (제목은 LaTeX `\caption` 이 맡는다) |
| `System Architecture.png` | `../fig-system.png` | 여백만 |

## ⚠️ 아직 남은 표기 두 곳 — 구현과 다르다

논문 본문에는 **코드가 맞는 값**을 적어 두었으므로, 지금은 그림과 본문이 서로 다르다.
이미지를 고칠 때 아래 둘을 함께 바로잡아야 한다.

| 그림 | 그림에 적힌 것 | 실제 구현 |
|---|---|---|
| MLP | 활성함수 **GELU** | **ReLU** — `src/yard_rl/v3/actors/nets.py` 의 `nn.ReLU()` |
| System Architecture | 학습목표 `y = (Φ₁ − (Φ₂+Φ₃)/2) / 10⁵` | 정책마다 **짝을 지어** `base = ½(Φ_사실 + Φ_대안)` 를 빼고 표본을 둘 만든다 — `src/yard_rl/v3/train/labels.py` |

두 번째가 더 무겁다. 그림대로 읽으면 두 망이 세 세계를 함께 쓰는 것 같지만, 구현에서
**제안망은 `Φ_수락반대` 를, 수락망은 `Φ_제안반대` 를 보지 않는다.** 각 망은 자기
반사실하고만 짝을 이룬다.

## 참고 — 쓰지 않는 대체본

위 `fig-mlp.png` 를 덮어쓰지 않는다.
