# 제공받은 원본 그림 (현재 논문에는 쓰지 않음)

사용자가 준 이미지 두 장이다. **논문에는 쓰지 않는다** — 둘 다 구현과 어긋나는
표기가 있는데 래스터라 고칠 수 없어서, 같은 내용을 코드에 맞게 다시 그린 벡터
그림으로 대체했다.

| 파일 | 그림에 적힌 것 | 실제 구현 | 대체본 |
|---|---|---|---|
| `MLP.png` | 활성함수 **GELU** | **ReLU** (`src/yard_rl/v3/actors/nets.py`) | `../fig-mlp.pdf` (`scripts/v3/fig_mlp.py`) |
| `System Architecture.png` | 학습목표 `y = (Φ₁ − (Φ₂+Φ₃)/2) / 10⁵` | 정책마다 **짝을 지어** `base = ½(Φ_사실 + Φ_대안)` 를 빼고 표본을 둘 만든다 (`src/yard_rl/v3/train/labels.py`) | `../fig-arch.pdf` (`scripts/v3/fig_arch.py`) |

두 번째가 특히 중요하다. 그림대로면 제안망과 수락망이 세 세계를 함께 쓰는 것으로
읽히지만, 구현에서 **제안망은 `Φ_수락반대` 를, 수락망은 `Φ_제안반대` 를 보지 않는다.**
각 망은 자기 반사실하고만 짝을 이룬다.

원본을 지우지 않고 여기 남겨 둔 이유는, 나중에 이미지를 직접 고쳐 쓰기로 결정할 수
있기 때문이다. 그때는 위 두 표기를 바로잡아야 한다.
