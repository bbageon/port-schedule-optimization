# 제공받은 원본 그림 (현재 논문에는 쓰지 않음)

사용자가 준 이미지와 조판용으로 다듬은 래스터 초안이다. **논문에는 쓰지 않는다** —
아래 두 표기가 실제 구현과 어긋나서, 같은 내용을 코드에 맞게 다시 그린 벡터 그림으로
대체했다.

| 파일 | 그림에 적힌 것 | 실제 구현 | 대체본 |
|---|---|---|---|
| `MLP.png`, `MLP-draft.png` | 활성함수 **GELU** | **ReLU** (`src/yard_rl/v3/actors/nets.py`) | `../fig-mlp.pdf` (`scripts/v3/fig_mlp.py`) |
| `System Architecture.png`, `fig-system-draft.png` | 학습목표 `y = (Φ₁ − (Φ₂+Φ₃)/2) / 10⁵` | 정책마다 **짝을 지어** `base = ½(Φ_사실 + Φ_대안)` 를 빼고 표본을 둘 만든다 (`src/yard_rl/v3/train/labels.py`) | `../fig-arch.pdf` (`scripts/v3/fig_arch.py`) |

두 번째가 특히 중요하다. 그림대로면 제안망과 수락망이 세 세계를 함께 쓰는 것으로
읽히지만, 구현에서 **제안망은 `Φ_수락반대`를, 수락망은 `Φ_제안반대`를 보지 않는다.**
각 망은 자기 반사실하고만 짝을 이룬다.

원본을 남겨 둔 이유는 시각 참고와 변경 이력을 보존하기 위해서다. 출판본은 PDF를 쓰고,
SVG는 편집 원본, PNG는 빠른 미리보기로 둔다.
