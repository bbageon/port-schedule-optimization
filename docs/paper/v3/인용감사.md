### ⚠ [18] PEMA — 이미 한 번 정정한 인용

내부 감사([[YR-238]])에서 **PEMA IP15가 `2~3분/사이클`을 직접 제시하지 않음**을 확인했다.
현재 본문은 수치 근거가 아니라 **보고 지침**으로만 쓰고 있어 정정된 상태다. 180초의
수치 근거는 [9]로 옮겨져 있다. **본문을 고칠 필요는 없으나, 이 이력을 아는 사람이
검토해야 한다.**

### ✔ [20] Kim et al. 2020 — 원문 확인

가우시안을 쓴 근거가 정규성 검정이 아니라 **평균 주변의 개인차를 만드는 합성 가정**임을
원문에서 확인했다.

> *"the parameters **were randomly generated** as follows. … the mean of the desired
> illuminance … **was selected uniformly** from the interval [500, 700] … Then
> l\*ᵢ,ₙ **was sampled from a Gaussian distribution** with mean l̄\*ᵢ and variance 10²"*

실측(조도·온도 공개 데이터셋)과 합성(선호 매개변수)을 나눠 쓰되 합성 쪽은 정당화 없이
선언한다. 우리 §3.1의 "문헌 근거 / 설계값" 표가 같은 처리다.

### ◻ 나머지 23편 — **원문 미확인**

이 원고의 인용은 앞선 작업에서 붙은 것이고 **이번 감사에서 원문을 열어 대조하지
않았다.** 특히 아래 넷은 **수치를 직접 받치므로 원문 확인이 필요하다.**

| 확인해야 할 것 | 어디에 쓰이나 |
|---|---|
| [9]의 삼각분포 범위가 실제로 180초를 포함하는가 | 크레인 기준 서비스시간 |
| [16]이 실제로 24·30·36 move/h를 쓰는가 | STS 처리율 27.5 |
| [15]가 16블록, [16]이 20블록인가 | 21블록의 "인접 규모" 근거 |
| [24]의 안전운임에서 40,000원/시간이 어떻게 나오는가 | Φ의 93.5%를 차지하는 항 |

## 3. 근거 없는 설계값 — 인용을 붙여야 할 것

아래는 현재 **"연구 설계값"으로만 적혀 있고 문헌 근거가 없는** 값이다.
후보 문헌은 이번에 찾은 것이며 **본문에 넣기 전 원문 확인이 필요하다.**

| 값 | 현재 서술 | 후보 근거 |
|---|---|---|
| **블록 초기 점유율 65%** | 근거 없음 | 업계 자료가 **60–65%를 전통적 운영 밀도 상한**으로 보고하고, 70% 초과 시 재취급이 늘어난다고 설명한다 |
| **검토 창 30분** | 근거 없음 | 트럭 예약제 문헌·현업이 **15–30분 창**을 표준으로 쓴다. APM Terminals는 2024년 30분 슬롯으로 확대했고 HIT는 30분 단위로 정원을 둔다 |
| **이연 격자 15분** | 근거 없음 | 위와 같은 근거 (1세대 예약제가 15–30분 창) |
| **추가 크레인 이동 60,000원/시간** | "연구 설계값" | **찾지 못함** — 국내 장비 운영비 공개자료 필요 |
| **재취급 2,000원/회** | "연구 설계값" | **찾지 못함** — 재취급 비용은 대개 시간·이동 수로 환산되고 단가 공개가 드물다 |
| **반사실 지평 3시간** | 근거 없음 | 내부 예산식(창 30분 + 이연 120분 + 도착압력 30분)에서 유도 — **문헌이 아니라 설계 유도**임을 본문에 밝히면 된다 |
| **결정 간격 60초** | 근거 없음 | 실시간 배차 연구의 결정 주기와 대조 필요 ([19] 확인) |
| **부호검정 사용** | 근거 없음 | 비모수 짝비교 표준 — 통계 교재 1편이면 충분 |
| **선박 하루 구성(소 2·중 1·대 0.3)** | 근거 없음 | [23] 기항량 연구에서 근거를 뽑을 수 있는지 확인 필요 |

### 권고

1. **65% · 30분 · 15분** 셋은 근거를 붙일 수 있다 — 후보를 확인해 각주로 넣는다.
2. **60,000원 · 2,000원** 둘은 근거를 못 찾았다. **[20]의 방식**을 따라
   *"연구 설계값이며 문헌에서 가져오지 않았다"* 를 명시하는 것이 정직하다.
   지금 본문이 이미 "연구 설계값"이라고 적고 있으므로 **표현은 충분하다.**
3. **3시간 지평**은 문헌이 아니라 **설계 유도**임을 한 문장으로 밝힌다.
4. 위 §2의 **수치를 직접 받치는 넷**은 원문을 열어 확인한다.
