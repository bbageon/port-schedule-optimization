## 이 폴더가 v2 와 다른 점

[v2](../v2/README.md)는 절을 주제별로 나눈 **작업 문서**다. 여기 v3 는 그 내용을
제출 원고의 순서대로 **한 편으로 조립한 것**이다. 내용은 v2 와 같고, 절 번호와
연결 문장만 원고 흐름에 맞췄다. 수치가 갱신되면 v2 를 먼저 고치고 여기에 반영한다.

한 파일이 200줄을 넘지 않도록 절 단위로 나눴다. 아래 순서대로 읽으면 한 편이 된다.

## 초록

스마트항만은 자동화 장비와 디지털 정보를 결합해 한정된 공간, 장비와 차량 흐름을
효율적으로 조정하는 방향으로 발전하고 있다. 선행연구는 스마트 기술의 효과가 운영
조건과 적용 방식에 따라 달라지므로, 관측 정보를 실제 자원 배치와 운영 판단으로
연결하는 정책이 중요하다고 설명한다 ([1]–[3]).

본 연구는 이미 통지된 외부 트럭 작업의 야드 블록과 도착시각을 실시간 혼잡에 따라
함께 재검토하는 강화학습 아키텍처를 제안한다. 재배치를 요청하는 정책과 이를 받을
블록 또는 시간대의 수락 정책을 독립적으로 구성하고, 양쪽이 동의한 후보만 중앙 절차가
자원 제약 아래에서 확정한다. 각 정책은 동일한 상태에서 현재 행동만 바꾼 이산사건
시뮬레이션의 비용 차이를 학습하며, 운영 단계에서는 학습된 신경망만 사용한다. 이 구조는
분산 예약 협상과 반사실 기준선 연구를 시공간 재배치 문제에 연결한다
([5], [6], [10], [11]).

아키텍처는 선행연구의 터미널 규모, 시간대별 트럭 도착, 복수 야드 크레인과 선박
기항량 범위를 반영한 연속 합성환경에서 평가했다. 학습에 사용하지 않은 난수 조건에서
재배치 없음, 규칙 기반 정책과 학습 전 모형을 함께 비교했다. 그 결과 제안–수락–확정–
실행으로 이어지는 의사결정 경로가 연속 운영 중 안정적으로 작동했고, 비용 감소 방향은
혼잡한 조건의 도착시각 조정에서 뚜렷하게 관찰됐다. 행동 범위를 맞춘 규칙 정책과의
비교에서도 학습된 모형이 낮은 비용 방향을 보였으며, 학습 전 모형 대비로도 같은 방향이
관찰됐다.

본 연구의 기여는 특정 성능값보다 **실시간 혼잡 관측, 독립된 제안과 수락, 상호 동의,
반사실 비용 학습, 빠른 운영 추론을 하나의 실행 구조로 제시한 것**에 있다. 현 실험은
이 아키텍처가 항만의 시공간 배치를 다루는 강화학습 정책으로 발전할 가능성을 보여 준다.

**주제어** — 스마트항만, 컨테이너 터미널, 트럭 도착 관리, 야드 블록 재배치,
반사실 학습, 강화학습

## 해석 범위

이 원고의 중심 주장은 특정 개선율의 현장 일반화가 아니라, 제안·수락·확정·실행과
반사실 학습을 연결한 **정책 아키텍처의 작동 가능성**이다. 모든 수치는 문헌 기반
합성환경의 **진단 난수 대역** 결과이며, 판정 대역 1회 평가와 학습 기여의 통계적
확증은 남아 있다. 구체적 조건은 [5 실험결과](5-실험결과.md) §1 에 적었다.
