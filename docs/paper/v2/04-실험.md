# 04 — 실험

## 1. 실험 목적

실험은 제안 아키텍처가 연속 운영 중 의사결정을 끝까지 실행하는지, 재배치 행동이
비용에 어떤 방향으로 연결되는지, 학습된 비용 모형이 행동 선택에 기여할 가능성이
있는지를 단계적으로 살펴본다. 재현에 필요한 수치와 통계값은 이 장의 소분류에 모았다.

## 2. 실험 구성

| 소분류 | 내용 |
|---|---|
| [04a 실험환경](04a-실험환경.md) | 문헌 근거, 터미널·도착·선박 설정, 장비 단위와 비용함수 |
| [04b 정책과 학습](04b-정책과-학습.md) | 상태·행동 수식, 합의 제약, 의사코드, 반사실 비용 회귀 |

## 3. 전체 실험 흐름

```text
문헌 기반 합성환경 구성
        ↓
연속 운영 궤적 생성
        ↓
일부 결정의 반사실 비용 라벨 생성
        ↓
독립 제안·수락 비용모형 학습
        ↓
가중치 고정·탐색 중지
        ↓
같은 난수를 공유하는 정책별 연속 실행
        ↓
전체 비용·혼잡 수준·행동 유형·학습 전후 비교
```

## 4. 비교 단위와 통계

시뮬레이션은 30일을 연속으로 진행한다. 첫날과 마지막날은 날짜 경계의 상태를 연결하는
구간으로 쓰고, 가운데 28일을 비교한다. 정책들은 같은 날짜의 수요와 난수를 공유한다.
날짜별 비용 차이에는 양측 부호검정을 적용한다. 부호검정의 `p`값은 실제 정책 차이가
없다고 가정했을 때 현재와 같은 승패 쏠림이 우연히 나타날 확률이다. 공통 난수를 이용한
짝비교는 정책 차이의 잡음을 줄이는 실험설계와 맞닿아 있다
([9](03-관련연구.md#ref-9)).

## 5. 해석 순서

1. **실행 가능성** — 제안, 수락, 확정과 실행이 정보·합의·용량 규칙을 지키는지 본다.
2. **운영 가능성** — 평가 중 반사실 분기 없이 학습된 모형만으로 판단하는지 본다.
3. **비용 방향** — 재배치 없음과 규칙 기반 정책보다 비용이 어느 방향으로 변하는지 본다.
4. **기여 분해** — 블록 재배치, 도착시각 조정과 학습 전후를 따로 비교한다.
5. **적용 범위** — 혼잡 수준, 예약 정원과 평가구간 조건을 함께 제시한다.
