# 06 — 관련연구와 참고문헌

## 1. 관련연구의 범위

선행연구는 제안 아키텍처와 직접 연결되는 다섯 주제로 한정한다. 외부 문헌은 문제 설정과
방법 선택의 근거이며, 본 연구의 비용 차이는 합성 시뮬레이션에서 별도로 평가한다.

| 주제 | 외부 근거 | 본 연구와의 연결 |
|---|---|---|
| 스마트항만 운영 효율화 | R14–R16 | 실시간 정보와 자동화가 자원 배치·운영 조정으로 이어져야 한다는 연구 배경 |
| 트럭 예약과 도착시각 조정 | R1–R3·R11 | 시간대별 수요 분산과 터미널·운송사 간 분산 의사결정의 근거 |
| 야드 크레인 운영 | R4–R6·R10·R13 | 블록 혼잡, 작업순서와 장비 성능 가정의 범위 |
| 다중 정책의 반사실 기준선 | R7–R8 | 한쪽 행동만 바꿔 제안·수락 정책의 비용 신호를 분리하는 근거 |
| 짝비교 시뮬레이션 | R9 | 같은 난수를 공유하는 날짜별 정책 비교의 근거 |

## 2. 스마트항만 연구에서 본 연구의 위치

스마트항만 연구는 자동화, 지능화와 환경 설계를 운영 효율과 연결한다. 그러나 주요 항만
20곳을 분석한 연구에서는 각 요소의 영향이 달랐고, 모든 스마트 기술이 자동으로 긍정적
성과를 만들지는 않았다(R14). 따라서 기술 도입 여부뿐 아니라 정보가 어떤 운영 결정으로
이어졌는지를 함께 평가해야 한다.

실제 항만의 추진 사례도 관측과 의사결정의 연결을 강조한다. 부산항 디지털 트윈은 장비
투입 시나리오, 컨테이너·장비 위치와 트럭 정보를 이용해 운영과 혼잡 분산을 지원한다
(R15). 싱가포르 투아스항은 자동 야드 크레인과 무인운반차를 원격 운영체계와 결합해
생산성 향상을 추진한다(R16). 본 연구는 스마트항만 플랫폼 전체가 아니라, 이런 실시간
정보가 주어졌을 때 **트럭 작업을 어디에 언제 배치할지 판단하는 정책 계층**에 초점을
둔다.

## 3. 트럭 예약·야드 운영과의 차이

트럭 예약 연구는 시간창으로 게이트 도착을 분산하거나(R1), 터미널과 운송사가 각자
비용을 가진 채 도착시각을 협상하는 문제를 다뤘다(R2–R3). 부산항의 차량 예약 시범도
시간 조정의 현장 가능성을 보여 준다(R11). 본 연구는 예약 시각만 새로 정하는 문제가
아니라, 이미 통지된 작업의 블록과 도착시각을 실시간 혼잡에 따라 함께 재검토한다.

야드 크레인 연구는 단일 크레인의 작업순서 최적화(R4)와 다중 자동화 크레인의 간섭을
반영한 실시간 계획(R5)을 다룬다. 본 연구의 규칙 기반 비교 정책은 이러한 최적화 방법을
대체하는 최강 대조군이 아니라, 제안 아키텍처의 작동 가능성을 비교하기 위한 해석 가능한
기준선이다. 또한 장비 처리능력은 작업 종류와 간섭 조건에 따라 달라지므로 단일 숫자를
현장 전체 처리량으로 해석하지 않는다(R6·R13).

## 4. 반사실 학습과 평가설계

한 재배치는 다른 트럭과 크레인의 뒤 행동을 바꾼다. 차이 보상(R7)과 다중 행위자
반사실 기준선(R8)은 다른 행동을 유지하거나 소거한 기준선과 비교해 개별 행동의 책임을
분리한다. 본 연구는 이 발상을 중앙 가치함수나 정책경사로 구현하지 않고, 같은 난수의
이산사건 시뮬레이션에서 행동 하나만 바꿔 원화 비용 차이를 만든다.

정책 비교에서는 같은 날짜의 정책들이 같은 난수를 사용한다. 공통 난수에 의한 짝비교는
시뮬레이션 결과 차이의 잡음을 줄이는 전통적인 실험설계다(R9). 다만 짝비교가 행동 범위의
차이나 부족한 혼잡 표본까지 해결하는 것은 아니므로, 학습 전 모형과 같은 행동을 쓰는
규칙 기반 정책을 별도로 비교한다.
