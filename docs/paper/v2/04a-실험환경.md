# 04a — 실험환경

## 1. 문헌 기반 합성환경

실험 대상은 특정 터미널의 운영자료를 복제한 환경이 아니라, 기존 컨테이너 터미널
연구가 사용한 규모와 운영 범위를 조합한 **문헌 기반 합성환경**이다. 선행연구의 값을
그대로 사용한 경우와 그 범위 안에서 본 연구가 정한 값을 다음처럼 구분한다.

| 구성요소 | 선행연구의 근거 | 본 연구의 사용 방식 |
|---|---|---|
| 다중 블록 | 국내 시뮬레이션은 16블록, 동적 배차 연구는 20블록을 사용([10](03-관련연구.md#ref-10), [17](03-관련연구.md#ref-17)) | 인접 규모인 21블록을 실험값으로 설정 |
| 복수 야드 크레인 | 블록별 복수 크레인과 간섭을 다루는 연구가 존재([5](03-관련연구.md#ref-5), [18](03-관련연구.md#ref-18)) | 모든 블록에 2기를 두는 동질 구조로 설정 |
| 장기 이산사건 운영 | 여러 주의 개별 컨테이너 흐름을 연속 모의한 연구([13](03-관련연구.md#ref-13)) | 날짜 경계에서 상태를 유지하는 30일 환경으로 구성 |
| 시간대별 트럭 도착 | 도착확률이 시간대와 작업 특성에 따라 달라지고, 도착 패턴이 체류시간에 영향([19](03-관련연구.md#ref-19), [20](03-관련연구.md#ref-20)) | 24시간 바닥과 세 개 봉우리를 결합한 실험 곡선 사용 |
| 선박 등급·기항량 | 세 선박 등급과 서로 다른 기항 작업량을 사용한 시뮬레이션([17](03-관련연구.md#ref-17)); 큰 기항량은 야드·게이트 피크를 형성([21](03-관련연구.md#ref-21)) | 소·중·대형 선박과 용량 비례 기항량을 설정 |
| 크레인 서비스시간 | 크레인 취급시간의 삼각분포 범위가 보고됨([13](03-관련연구.md#ref-13)) | 해당 범위 안의 180초를 기준 이동시간으로 설정 |

따라서 21블록, 정확한 수요량과 도착곡선 계수는 본 연구의 실험 설계값이다. 인용은
선택한 규모와 변동 구조가 기존 연구의 모형 범위에 놓인다는 근거이며, 특정 항만의
운영자료를 뜻하지 않는다.

## 2. 터미널과 시간 설정

| 항목 | 설정값 |
|---|---|
| 야드 | 21블록, 블록당 야드 크레인 2기, 총 42기 |
| 블록 용량·초기 적재 | 블록당 1,440 슬롯, 시작 점유율 65% |
| 배치 | 게이트와 안벽이 반대쪽에 있는 1차원 수평 배치 |
| 정책 결정 간격 | 60초 |
| 운영 기간 | 30일 연속 |
| 비교 기간 | 첫날·마지막날을 제외한 가운데 28일 |
| 크레인 작업순서 | 실제 작업 우선 후 예상 처리시간이 짧은 작업 우선 |

하루는 터미널이 자정에 멈춘다는 뜻이 아니라 비용과 중간 결과를 나누는 절단면이다.
야드 재고, 대기열, 크레인 상태와 미완료 작업은 다음 날로 이어진다. 첫날은 초기 상태와
연속 흐름을 연결하고, 마지막날은 앞선 작업의 잔여 효과를 보존한다.

## 3. 외부 트럭 수요와 도착 과정

| 일일 수요 | 추첨 확률 | 역할 |
|---:|---:|---|
| 3,500대 | 30% | 원활 조건 |
| 5,000대 | 30% | 보통 조건 |
| 7,500대 | 25% | 높은 수요 조건 |
| 12,500대 | 10% | 혼잡 조건 |
| 15,000대 | 5% | 초혼잡 조건 |

시간대별 도착밀도 (f(t))는 24시간 균등 바닥과 정규분포 봉우리의 혼합으로 정의한다.

\[
f(t)=0.38\,U(0,24)+0.62\sum_{m=1}^{3}w_m
\mathcal N_{[0,24)}(t;\mu_m,\sigma_m^2),
\]

\[
(\mu_m,\sigma_m,w_m)\in
\{(10,1.5,0.317),(15,2.5,0.633),(21,1.0,0.050)\}.
\]

여기서 시간 단위는 시(hour)이고 절단된 밀도는 하루 합이 1이 되도록 다시 정규화한다.
시간대별 도착확률 모형과 도착 패턴의 체류시간 영향은 [19](03-관련연구.md#ref-19)와
[20](03-관련연구.md#ref-20)을 따른 문제 설정이며, 위 혼합비와 중심시각은 혼잡
민감도를 비교하기 위한 연구 설계값이다.

## 4. 선박과 안벽 작업

선박은 세 등급으로 나누고, 기항 작업량은 선박 용량의 일정 비율로 생성한다. 세 등급과
서로 다른 기항량을 함께 쓰는 구성은 [17](03-관련연구.md#ref-17), 기항량이 터미널
하위 시스템에 피크를 만든다는 근거는 [21](03-관련연구.md#ref-21)을 참고했다.

| 등급 | GT | TEU | 기항 작업량 | 배정 STS | 선박 유휴비용/시간 |
|---|---:|---:|---:|---:|---:|
| 소형 | 50,000 | 3,000 | 450~900 move | 2기 | 149,500원 |
| 중형 | 100,000 | 7,500 | 1,125~2,250 move | 4기 | 299,000원 |
| 대형 | 150,000 | 14,000 | 2,100~4,200 move | 6기 | 448,500원 |

기항 작업량은 `TEU × U(0.15, 0.30)`으로 생성한다. 하루 기본 구성은 소형 2척과
중형 1척이며 대형 1척을 30% 확률로 추가한다. STS 1기의 처리율은 27.5 move/h로
두며, 이는 문헌의 24·30·36 move/h 실험 범위 안에 있다
([17](03-관련연구.md#ref-17)). 여러 STS의 막힘은 합산한 뒤 배정 대수로 나누어
선박 단위 유휴시간으로 환산한다.

## 5. 야드 크레인 능력의 단위

크레인 1기의 기준 서비스시간은 180초/move다. 이론상 총 이동능력은 다음과 같다.

\[
\mu_{YC}=21\times2\times\frac{3600}{180}=840\ \text{move/h}.
\]

`move/h`는 컨테이너 이동 횟수이며 `truck/h`와 다르다. 트럭 한 건은 이동과 재취급을
여러 번 요구할 수 있고 실제 서비스시간도 위치와 작업 종류에 따라 변한다. 장비 성능을
해석할 때 이동 종류, 자동화 지연과 연계 차량 조건을 함께 적어야 한다는 지침은
[6](03-관련연구.md#ref-6)을 따른다.

## 6. 비용함수

날짜 구간 ([d,d+1))의 총비용은 네 항의 합으로 정의한다.

\[
\Phi_d=C_{wait,d}+C_{move,d}+C_{rehandle,d}+C_{vessel,d}.
\]

| 항 | 계산과 단가 | 출처 구분 |
|---|---|---|
| 트럭 체류 | 40,000원/트럭·시간, 1시간 초과분에 같은 단가 추가 | 안전운임을 화폐 기준점으로 사용하고 시간 환산은 연구값([12](03-관련연구.md#ref-12)) |
| 추가 크레인 이동 | 추가 작업시간당 60,000원 | 연구 설계값 |
| 재취급 | 2,000원/회 | 연구 설계값 |
| 선박 유휴 | 2.99원/GT·시간 | 외항선 접안 초과요율 29.9원/10GT·시간을 환산([22](03-관련연구.md#ref-22)) |

트럭 \(i\)의 터미널 체류시간을 \(h_i\), 추가 크레인 작업시간을 \(m\), 재취급 횟수를
\(R\), 선박 \(v\)의 정책 관련 유휴시간을 \(T_v\)라 하면 다음처럼 계산한다.

\[
C_{wait}=\sum_i40{,}000\{h_i+\max(0,h_i-1)\},\quad
C_{move}=60{,}000m,\quad C_{rehandle}=2{,}000R,
\]

\[
C_{vessel}=\sum_v2.99\,GT_vT_v.
\]

접이안과 검역처럼 재배치 정책이 바꾸지 않는 구조적 선박 시간은 진단값으로 분리한다.
네 비용 항은 같은 날짜 경계의 누적값 차이로 계산한다.
