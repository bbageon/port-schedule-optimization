# 논문 작업초고 v2 — 시공간 재배치를 위한 강화학습 아키텍처

> 이 초고는 실시간 혼잡에 따라 트럭 작업의 블록과 도착시각을 함께 조정하는
> 강화학습 아키텍처를 제안하고, 문헌 기반 합성환경에서 그 발전 가능성을 살펴본다.

## 한 줄 주장

> 독립된 재배치 제안 정책과 수락 정책, 상호 동의를 확인하는 중앙 확정 절차,
> 반사실 비용 학습을 결합하면 항만의 관측 정보를 실행 가능한 시공간 배치 결정으로
> 연결할 수 있다.

## 서술 원칙

- 재현에 필요한 설정값, 비용, 표본 수, 통계값과 적용 조건은 **실험**에 모은다.
- 초록·서론·관련 연구·결론은 수치 나열보다 연구 방향과 아키텍처의 의미를 설명한다.
- 실험환경은 특정 터미널의 복제가 아니라 **선행연구의 범위를 근거로 구성한 합성환경**으로 쓴다.
- 문헌이 직접 제시한 값과 본 연구가 그 범위 안에서 정한 설계값을 구분한다.
- 결과는 가능성과 개선 방향을 중심으로 쓰되 관찰값과 통계적 확실성은 그대로 보존한다.
- 내부 작업 번호, 코드 약칭과 개발 과정의 은유는 제출 본문에 넣지 않는다.

## 논문의 초점

1. 재배치 제안과 수락을 독립 정책으로 구성하는 방법
2. 양쪽 동의와 자원 제약을 함께 확인하는 확정 절차
3. 한 행동만 바꾼 시뮬레이션으로 비용 학습 신호를 만드는 방법
4. 계산량이 큰 학습과 빠른 운영 판단을 분리하는 방법
5. 블록과 도착시각을 하나의 시공간 행동 범위로 다루는 방법

## 용어 원칙

- 역할은 **재배치 제안 정책**, **수락 정책**, **중앙 확정 절차**로 쓴다.
- 행동은 **블록 재배치**, **도착시각 조정**, **원배정 유지**로 쓴다.
- 학습값은 **반사실 비용 차이**, 실행 조건은 **문헌 기반 연속 합성환경**으로 쓴다.
- 현행 모형은 시간차 학습이 아니라 행동별 비용 회귀이므로 **반사실 비용 회귀**로 설명한다.

## 해석 범위

이 원고의 중심 주장은 특정 개선율의 현장 일반화가 아니라, 제안·수락·확정·실행과
반사실 학습을 연결한 정책 아키텍처의 작동 가능성이다. 구체적인 수치는
[실험 결과](04c-실험결과.md)에서 실험 조건과 함께 제시한다.
