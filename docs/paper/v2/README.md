## 한 줄 결론

> 앞선 3,600대 합성 시나리오에서는 규칙 기반 재배치의 가치가 확인됐고, 현행
> 구현에서는 독립 제안·수락 정책과 반사실 학습 절차가 검증됐다. 그러나 **30일 연속
> 시나리오의 학습 효과는 미학습 모형과 구분되지 않았고, 미사용 난수시드 30일 평가가
> 끝나지 않았으므로 미확정이다.**

제안 정책은 작업의 블록이나 도착시각 변경을 요청하고, 수락 정책은 목적 블록 또는
예약 시간대에서 그 요청을 받을지 판단한다. 반사실 학습은 “변경했을 때”와 “원배정을
유지했을 때”의 시뮬레이션 비용 차이를 작은 신경망에 학습시키는 방식이다.

## 이 버전이 필요한 이유

[이전 초고](../v1/README.md)는 2026-08-18에 끝난 3,600대 합성 시나리오의 결과를
정확히 보존한다. 현행 구현에는 다음이 새로 생겼다.

- 하루 총비용을 네 가지 원화 비용 항목으로 통일
- 독립 제안·수락 정책과 상호 동의 기반 중앙 매칭
- 학습 때만 쓰는 3시간 반사실 비용 라벨 생성
- 소형·중형·대형 본선과 기항 물량
- 규칙 기반 재배치·크레인 작업순서 비교와 재배치 유형별 분석
- 야간에도 도착이 이어지는 24시간 도착분포와 다섯 수요수준
- 자정에 초기화하지 않는 30일 연속 환경, 가운데 28일 학습과 별도 고정정책 평가

반대로 예비 일중 시나리오에서 얻은 성능 수치는 현행 연속 시나리오에 그대로 옮길 수
없다. 이 초고는 좋은 수치만 합치는 대신 **어느 실험 조건에서 무엇을 확인했는지**를
분리한다.

## 논문 용어와 코드 식별자의 대응

아래 오른쪽 열은 저장소 코드를 찾기 위한 식별자이며 제출 원고에서는 사용하지 않는다.

## 인용을 읽는 법

- `[R번호]`는 외부 문헌이 **문제 설정이나 방법 선택이 연구적으로 가능한지**를 뒷받침한다.
- `YR-번호`와 원자료는 **우리 코드와 실험에서 실제로 무엇이 일어났는지**를 뒷받침한다.
- 외부 항만의 개선율과 장비 수치를 본 연구의 성능 결과로 옮겨 쓰지 않는다.
