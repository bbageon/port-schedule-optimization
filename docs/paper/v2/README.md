# 논문 작업초고 v2 — 시공간 재배치를 위한 강화학습 아키텍처

> 이 문서는 특정 성능 수치의 성공 보고서가 아니라, 독립 제안·수락 정책과 반사실
> 비용 학습을 결합한 아키텍처를 설명하고 그 가능성을 평가하는 작업초고다.

## 한 줄 주장

> 실시간 혼잡에 따라 트럭 작업의 블록과 도착시각을 재검토하는 **독립 제안·수락
> 강화학습 아키텍처**를 제시했다. 연속 합성 환경에서 실행과 비용 감소 가능성을
> 관찰했지만, 학습된 모형은 학습 전 모형과 통계적으로 구분되지 않았다. 따라서 현재
> 결론은 **성공 확증이 아니라 후속 최적화를 진행할 가능성이 확인됐다**는 것이다.

## 논문의 초점

이 초고는 다음 네 가지에 집중한다.

1. 재배치 제안 정책과 수락 정책을 독립적으로 구성하는 방법
2. 상호 동의와 용량 제약을 보장하는 중앙 확정 절차
3. 반사실 이산사건 시뮬레이션으로 행동별 비용 신호를 만드는 방법
4. 느린 학습과 빠른 운영 추론을 분리하는 방법

28일 비용 차이와 재배치 유형 분해는 이 아키텍처의 가능성과 한계를 판단하는
진단 증거다. 과거 실험의 모든 시행착오, 사용하지 않은 신경망 후보와 이전 환경의
성능은 본문 주장이 아니므로 제외한다.

## 현재 증거의 해석

| 관찰 | 논문에서의 해석 |
|---|---|
| 재배치 없음보다 26/28일 비용이 낮음 | 아키텍처가 비용 감소 가능성을 보인 예비 증거 |
| 총비용 차이 14.7% | 합성 진단 환경의 결과이며 실제 항만 개선율이 아님 |
| 이득의 90.5%가 혼잡한 나흘에 집중 | 혼잡 대응 정책으로 발전할 가능성과 표본 부족을 동시에 뜻함 |
| 이득의 91.4%가 도착시각 조정에서 발생 | 정책 행동 범위가 중요하며 같은 행동을 쓰는 대조군이 필요함 |
| 학습 전 모형 대비 18/28일·p=0.18 | 반사실 학습 자체의 기여는 아직 확정할 수 없음 |

## 용어 원칙

제출 원고는 일반 학술 용어만 사용한다.

- 정책의 역할은 **재배치 제안 정책**, **수락 정책**, **중앙 확정 절차**로 쓴다.
- 행동은 **블록 재배치**, **도착시각 조정**, **원배정 유지**로 쓴다.
- 학습 자료는 **반사실 시뮬레이션 비용 차이**, 실행 조건은 **연속 합성 환경**으로 쓴다.
- 내부 작업 번호, 코드의 약칭과 개발 과정의 은유는 제출 본문에 넣지 않는다.

## 주장 경계

| 사용할 수 있는 문장 | 사용하지 않는 문장 |
|---|---|
| 제안 아키텍처가 연속 합성 환경에서 실행됐다. | 실제 부산항에서 14.7% 개선됐다. |
| 비용 감소 가능성이 진단 평가에서 관찰됐다. | 강화학습 정책의 우수성이 입증됐다. |
| 효과는 혼잡한 날의 도착시각 조정에 집중됐다. | 블록 재배치는 일반적으로 해롭다. |
| 학습 효과는 아직 통계적으로 확정되지 않았다. | 학습이 전체 이득의 45%를 만들었다. |
