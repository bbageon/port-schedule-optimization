# 논문 작업초고 v2 — 시공간 재배치의 반사실 학습

> 작성 기준일 2026-08-26 · YR-236 · **결과가 모두 끝난 완성 논문이 아니라 현재 증거를 정리한 작업초고**

## 한 줄 결론

> 예전 3,600대 무대에서는 규칙 재배치의 가치가 확정됐고, 현재 v3에서는 독립
> Seller·Buyer와 반사실 학습 절차가 구현·검증됐다. 그러나 **6차 무대의 최종 성능은
> 아직 재학습과 새 시드 평가 전이므로 결론을 내릴 수 없다.**

Seller는 작업을 다른 블록이나 시간으로 내놓는 행위자, Buyer는 그 제안을 받을지
판단하는 행위자다. 반사실 학습은 “했을 때”와 “하지 않았을 때”의 시뮬레이션 비용
차이를 정답으로 만들어 작은 신경망에 가르치는 방식이다.

## 이 버전이 필요한 이유

[v1](../v1/README.md)은 2026-08-18에 끝난 옛 3,600대 무대의 결과를 정확히 보존한다.
그 뒤 v3에는 다음이 새로 생겼다.

- 하루 총비용을 원화 네 항으로 통일
- 독립 Seller·Buyer와 상호 동의 Resolver
- 학습 때만 쓰는 3시간 반사실 교사
- 소형·중형·대형 본선과 기항 물량
- 고전 규칙 5종과 공간·시간 축 분해
- 24시간 연속 도착을 나타내는 6차 도착곡선과 다섯 부하

반대로 5차 무대에서 얻은 성능 수치는 6차 무대에 그대로 옮길 수 없게 됐다. 이
초고는 좋은 수치만 합치는 대신 **어느 무대에서 무엇을 확인했는지**를 분리한다.

## 증거 표시

| 표시 | 뜻 | 논문에서의 사용 |
|---|---|---|
| **확정** | 사전등록 판정 또는 기계 검증 통과 | 범위를 붙여 결과로 사용 |
| **진단** | 비판정 시드의 원인 측정 | 다음 설계의 근거로만 사용 |
| **무효화** | 옛 무대에서는 사실이나 현재 성능으로 이전 불가 | 역사 결과로만 보존 |
| **진행 중** | 코드 수정·재학습·최종평가 미완료 | 결과를 비워 둠 |
