# 04b — 정책과 학습

## 1. 기호와 결정 단위

결정 간격을 \(\delta=60\)초, 야드 블록 집합을 \(\mathcal B\), 도착시각 이연 후보를
\(\mathcal D\)라 한다. 작업 \(i\)의 현재 배정은 \(z_i=(b_i,\tau_i)\)이며, \(b_i\)는
블록, \(\tau_i\)는 통지된 도착예정시각이다. 재배치 행동은 다음과 같다.

\[
a_i=(b'_i,\Delta_i)\in\mathcal A_i(t),\qquad
z_i(a_i)=(b'_i,\tau_i+\Delta_i).
\]

`원배정 유지`는 \(a_i^0=(b_i,0)\), `블록 재배치`는 \(b'_i\ne b_i\), `도착시각
조정`은 \(\Delta_i>0\)이다. 두 값이 함께 바뀌는 후보도 허용한다. 반출 작업은 꺼낼
컨테이너 위치가 정해져 있으므로 블록 재배치 후보에서 제외한다.

작업의 통지시각을 \(n_i\), 게이트 진입시각을 \(g_i\), 최초 검토 여부를 \(r_i\)라 하면
시점 \(t\)에 새로 검토하는 집합은 다음과 같다.

\[
\mathcal E_t=\{i\mid n_i\le t<n_i+\delta,\ g_i>t,\ r_i=0\}.
\]

즉 아직 도착하지 않은 작업을 통지가 자격 창에 처음 들어온 한 시점에서만 검토한다.

## 2. 독립된 제안 정책과 수락 정책

제안 정책은 자기 블록 상태와 작업·행동 특징 \(o_i^P\)를 이용해 예상 비용이 가장 낮은
행동을 고른다.

\[
\hat a_i=\arg\min_{a\in\mathcal A_i(t)}
\hat c_{\theta}^{P}(o_i^P,a),\qquad
p_i=\mathbf 1[\hat a_i\ne a_i^0].
\]

제안이 있으면 목적 블록 또는 목표 시간대가 수락 주체가 된다. 수락 정책은 제안 메시지와
자기 상태 \(o_i^A\)를 보고 수락과 거절의 예상 비용을 비교한다.

\[
q_i=\mathbf 1\!\left[
\hat c_{\psi}^{A}(o_i^A,\hat a_i,\mathrm{accept})
\le
\hat c_{\psi}^{A}(o_i^A,\hat a_i,\mathrm{reject})
\right].
\]

목표 자원의 남은 용량이 0이면 신경망 판단 전에 거절한다. 두 정책이 함께 동의한
후보 집합은 \(\mathcal J_t=\{i\in\mathcal E_t\mid p_iq_i=1\}\)이다. 독립된 두 주체가
제한된 정보를 바탕으로 도착시각을 협의하는 문제 구조는
[2](03-관련연구.md#ref-2)와 [3](03-관련연구.md#ref-3)을 참고했다.

## 3. 중앙 확정 제약

중앙 절차는 새 후보를 만들지 않고 \(\mathcal J_t\) 안에서만 확정한다. 동의 후보를
수락 정책의 예측비용 오름차순으로 정렬하고, 동점은 작업·좌표의 사전순으로 처리한다.
후보 \(i\)의 확정 여부를 \(x_i\in\{0,1\}\), 목적 블록의 남은 슬롯을 \(F_b(t)\),
예약 시간대 \(k\)의 남은 정원을 \(K_k(t)\)라 하면 다음 제약을 만족한다.

\[
x_i\le p_iq_i,\qquad
\sum_{i\in\mathcal J_t}x_i\mathbf1[b'_i=b]\le F_b(t)
\quad(\forall b\in\mathcal B),
\]

\[
\sum_{i\in\mathcal J_t}x_i\mathbf1[k(i)=k]\le K_k(t)
\quad(\forall k),\qquad
\sum_{t\in\mathcal T}\mathbf1[i\in\mathcal E_t]\le1\quad(\forall i).
\]

현행 실험에서 블록 용량 제약은 활성화돼 있다. 시간대 정원 자료가 없는 조건은
\(K_k(t)=\infty\)로 두며, 이 조건의 효과는 시간 조정 가능성의 범위로 해석한다.

확정 직전 배정을 \(z_i^-=(b_i,\tau_i)\), 선택한 새 배정을
\(\hat z_i=z_i(\hat a_i)\)라 한다. 원배정 장부 \(L_t\)와 확정 뒤 상태는 다음과 같다.

\[
L_t=\{(i,z_i^-):x_i=1\},\qquad
z_i^+=
\begin{cases}
\hat z_i,&x_i=1,\\
z_i^-,&x_i=0,
\end{cases}
\quad r_i^+=1\quad(\forall i\in\mathcal E_t).
\]

모든 \(z_i^+\)는 같은 시점에 일괄 반영한다. 따라서 먼저 확정된 작업이 같은 결정
시점의 뒤 후보가 보는 상태를 바꾸지 않는다.

## 4. 재배치 확정 의사코드

```text
Algorithm 1  독립 제안·수락 기반 시공간 재배치
Input: 시점 t, 작업 장부 O, 야드 상태 S, 제안모형 cP, 수락모형 cA
Output: 확정 재배치 집합 M_t

1: E_t ← 이번 60초 구간에 처음 자격을 얻었고 게이트에 들어오지 않은 작업
2: Offers ← ∅
3: for i ∈ sort(E_t) do
4:     A_i(t) ← {원배정 유지, 가능한 목적 블록, 가능한 이연 시간대}
5:     â_i ← argmin_{a ∈ A_i(t)} cP(o_i^P, a)
6:     if â_i ≠ 원배정 유지 then Offers ← Offers ∪ {(i, â_i)}
7:     else i를 원배정 유지로 확정
8: end for
9: Responses ← ∅
10: for (i, â_i) ∈ Offers do
11:     if 목표 자원의 남은 용량 = 0 then q_i ← 거절
12:     else q_i ← argmin_{u ∈ {수락, 거절}} cA(o_i^A, â_i, u)
13:     Responses ← Responses ∪ {(i, â_i, q_i)}
14: end for
15: J_t ← Responses 중 q_i = 수락인 후보
16: J_t를 (수락 예상비용, 작업 ID, 목적 좌표) 오름차순으로 정렬
17: M_t ← ∅
18: for i ∈ J_t do
19:     if 작업 소유권·블록 용량·시간대 정원 제약을 만족 then
20:         M_t ← M_t ∪ {i}; 가상 남은 용량을 1 감소
21:     else i를 원배정 유지로 확정
22: end for
23: M_t의 원래 블록·시각을 기록하고 새 배정을 일괄 반영
24: E_t의 모든 작업을 검토 완료로 잠금
25: return M_t
```

이 의사코드는 “제안과 수락이 모두 있는 후보만 확정한다”는 합의 조건과, 한 작업을
한 번만 검토하는 소유권 조건을 함께 보여 준다.

## 5. 정책모형과 입력

두 정책은 고정 길이 특징을 후보별로 평가하는 다층퍼셉트론(MLP, 완전연결 신경망)이다.
모든 블록이 같은 가중치 한 벌을 공유한다.

| 구분 | 제안 정책 | 수락 정책 |
|---|---:|---:|
| 입력 차원 | 21 | 16 |
| 입력 묶음 | 자기 블록·작업·행동 특징 | 자기 블록·작업·제안 메시지 |
| 은닉층 | 64–ReLU–64–ReLU | 64–ReLU–64–ReLU |
| 출력 | 후보별 예상 비용 1개 | 수락·거절 행별 예상 비용 1개 |
| 선택 | 모든 후보 중 `argmin` | 수락·거절 중 `argmin` |

입력은 현재 대기·재고·크레인 잔여, 공개 도착예정시각, 경로 차이와 목표 시각 주변의
통지 물량으로 구성한다. 아직 실현되지 않은 실제 도착·완료시각과 다른 수락 주체의
동시 응답은 입력에서 제외한다. MLP를 사용한 이유는 현재 입력이 고정 길이 표이며 각
후보를 독립 채점하기 때문이다. 그래프나 긴 순서 의존성을 직접 입력하는 단계가 되면
GNN 또는 순차 모형을 별도 비교할 수 있다.

## 6. 반사실 비용 라벨

표본 결정마다 분기 직전 상태와 난수를 복제하고 최대 세 세계를 3시간 실행한다.

\[
\phi_i^F=\Phi_H(\text{관측 행동}),\quad
\phi_i^P=\Phi_H(\text{제안 행동만 반대}),\quad
\phi_i^A=\Phi_H(\text{수락 행동만 반대}),\quad H=10{,}800\text{s}.
\]

수락 제안이 없는 결정은 제안 비교만 만든다. 각 정책의 두 행동은 같은 평균을 빼고
100,000원으로 나누어 학습한다. 제안 정책의 예는 다음과 같다.

\[
\bar\phi_i^P=\frac{\phi_i^F+\phi_i^P}{2},\qquad
y_{i,F}^P=\frac{\phi_i^F-\bar\phi_i^P}{100{,}000},\qquad
y_{i,P}^P=\frac{\phi_i^P-\bar\phi_i^P}{100{,}000}.
\]

수락 정책도 \((\phi_i^F,\phi_i^A)\)에 같은 중심화를 적용한다. 평균 차감은 두 행동의
순서를 바꾸지 않으면서 공통 비용을 제거한다. 한 행위만 바꾼 기준선은 차이 보상과
다중 행위자 반사실 기준선 연구에 닿아 있다
([7](03-관련연구.md#ref-7), [8](03-관련연구.md#ref-8)).

## 7. 학습 설정과 운영 분리

| 항목 | 설정 |
|---|---:|
| 학습일당 표본 상한 | 64개 결정 |
| 탐색 확률 | 0.50에서 0.05까지 선형 감소 |
| 학습·검증 분리 | 결정 단위 80%·20% |
| 최적화 | Adam, 학습률 `3×10⁻⁴` |
| 손실 | Huber, `β=1.0` |
| 미니배치 | 최대 256행 |
| 갱신 횟수 | `max(50, min(600, 4×학습행 수))` |
| 기울기 제한 | 1.0 |

반사실 분기는 CPU 여러 코어에서 병렬 실행하고 그날 생성한 라벨은 당일 갱신 뒤
교체한다. 운영 평가에서는 가중치를 고정하고 탐색을 끄며 반사실 분기를 호출하지 않는다.
RUDDER처럼 전체 궤적의 보상을 재분배하는 순차 모형([23](03-관련연구.md#ref-23))은
현행 학습기에 포함하지 않고 장기 기여를 확장하는 비교 대상으로 둔다.
