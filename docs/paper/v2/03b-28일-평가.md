# 03b — 효과 분해와 연구질문

[03 — 아키텍처 작동과 예비 성능](03-결과.md)의 추가 분석이다. 이 장은 전체 비용
차이를 재배치 유형과 학습 여부로 나누어, 제안 아키텍처의 어느 부분에서 가능성이
나타났는지 살펴본다.

## 1. 블록 재배치와 도착시각 조정의 기여

같은 28일에서 두 행동 중 하나만 허용한 조건을 재배치 없음과 비교했다. 양수는 비용
감소, 음수는 비용 증가를 뜻한다.

| 일일 트럭 수요 | 일수 | 두 행동 모두 | **도착시각 조정만** | **블록 재배치만** | 학습 전 모형 |
|---:|---:|---:|---:|---:|---:|
| 3,500 | 12 | 0.47억 | −0.13억 | **0.57억** | −0.09억 |

도착시각 조정은 혼잡한 나흘에서 13.2억원을 줄여 전체 비용 차이의 91.4%를 만들었다.
반면 블록 재배치만 허용하면 한산한 날에는 소폭 개선됐지만, 초혼잡 조건의 손해가 더
커서 28일 합계는 재배치 없음보다 1.31억원 높았다.

이 결과는 “학습 정책이 규칙보다 우수하다”는 주장보다, **정책에 어떤 행동을 허용하는지가
중요하다**는 설계 시사점을 준다. 기존 규칙 기반 비교 정책은 블록만 바꾸므로 도착시각
조정까지 허용한 제안 정책과 행동 범위가 다르다. 같은 행동 범위를 사용하는 규칙 기반
대조군의 평가가 끝나기 전에는 정책 선택 품질의 우위를 주장하지 않는다.

## 2. 아키텍처 관점의 해석

독립 제안·수락 구조는 블록과 시간이라는 서로 다른 운영 자원을 같은 의사결정 절차에서
다룰 수 있었다. 또한 행동을 한쪽씩 제한해 비용 차이의 출처를 분해할 수 있었다. 이는
제안 아키텍처가 단순히 하나의 성능 수치를 내는 모형이 아니라, **행동 설계와 학습
효과를 따로 검증할 수 있는 연구 틀**로 쓰일 수 있음을 뜻한다.

다만 현재 도착시각 조정에는 실제 예약 시간대별 정원이 입력되지 않았다. 혼잡한 작업을
미래 시간대로 옮기는 선택이 물리적 수용 한도 없이 허용됐으므로, 관찰된 비용 차이는
현장 적용 성과가 아니라 시간 조정 기능의 가능성을 보여 주는 상한에 가깝다.

## 4. 다음 검증에서 필요한 증거

아키텍처의 가능성을 강화학습 정책의 효과로 발전시키려면 다음 네 조건이 필요하다.

1. 도착시각 조정을 사용하는 규칙 기반 대조군과 행동 범위를 맞춘 비교
2. 실제 예약 시간대별 정원을 반영한 재평가
3. 혼잡 조건의 날짜 수를 늘린 학습 전·후 비교
4. 결과를 보지 않은 별도 난수시드 대역의 잠금평가

이 조건을 통과하기 전 논문의 결론은 **제안 아키텍처가 유망한 실행 가능성을 보였다**는
수준으로 제한한다.
