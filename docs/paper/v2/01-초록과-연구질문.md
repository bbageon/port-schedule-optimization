# 01 — 초록과 연구질문

## 가제

**연속 운영 컨테이너 터미널의 시공간 재배치: 독립 Seller–Buyer 반사실 학습과
검증 중심 시뮬레이션**

## 초록

컨테이너 터미널의 외부 트럭은 도착 전에 작업 블록과 시간이 정해지지만, 실제
도착 시점의 블록 혼잡은 그 계획과 다를 수 있다. 본 연구는 이미 배정된 트럭 작업을
다른 블록으로 옮기는 **공간 재배치**와 도착을 늦추는 **시간 재배치**를 함께 다룬다.
21개 블록과 블록당 야드 크레인 2기를 가진 합성 터미널에서 트럭과 본선 작업이
같은 크레인 자원을 공유하도록 이산사건 시뮬레이션을 구성했다.

제안 구조는 작업을 내놓는 Seller와 제안을 받는 Buyer가 각각 작은 다층퍼셉트론
(MLP, 기본적인 완전연결 신경망)으로 비용 차이를 예측하고, 중앙 Resolver가 양쪽이
동의한 거래만 확정한다. 학습 때에는 같은 상태에서 행동 하나만 바꾼 평행세계를
3시간 굴려 SELL−KEEP과 BUY−REJECT의 원화 비용 차이를 만든다. 운영과 평가 때에는
이 느린 반사실 시뮬레이션을 호출하지 않는다.

연구는 결과의 세대를 분리한다. 옛 3,600대 무대의 사전등록 평가에서는 규칙 기반
재배치가 규칙 크레인 배차와 학습 크레인 배차 위에서 각각 트럭 1대당 2.64분과
2.78분을 줄였다. 현재 v3에서는 독립 행위자, 원화 네 항 비용, 선급 3종, 반사실
교사와 고전 규칙 대조군의 구현을 검증했다. 동시에 3시간 라벨이 5차 도착곡선의
오전 효과를 놓쳐 거래량 가중 21.1%에서 하루 끝 부호와 달랐고, 순차 기여도 모델
RUDDER도 시간 순서를 쓰지 못해 사전 관문에서 기각됐다.

5차 무대의 진단에서는 시간 재배치가 이득의 대부분을 만들고 공간 재배치는 손해인
현상이 나타났으나, 24시간 도착곡선과 부하가 6차로 바뀌면서 이 성능 수치는 현재
결론으로 이전할 수 없다. 따라서 본 작업초고의 현재 결론은 **재배치 가능성과 v3
측정 방법은 검증됐지만, v3 정책의 최종 우세는 아직 미확정**이라는 것이다.

## 연구질문

### RQ1. 재배치 메커니즘 자체에 가치가 있는가?

학습 정책의 우수성과 별개로, 블록·시간 재배치를 허용하는 것만으로 터미널 비용과
트럭 체류시간이 줄어드는지 묻는다. 옛 3,600대 무대의 사전등록 결과가 이 질문의
1차 답이다.

### RQ2. 독립 Seller·Buyer를 실제 운영 가능한 형태로 학습시킬 수 있는가?

학습 중에는 미래 시뮬레이션을 쓰되, 평가에서는 현재 공개 정보와 두 신경망만으로
결정할 수 있는지 묻는다. 상호 동의 없는 거래 0건과 평가 중 반사실 호출 0건이
필수 조건이다.

### RQ3. 짧은 반사실 창이 장기 혼잡 효과를 올바르게 가르치는가?

현재 결정은 뒤 트럭의 대기와 이후 재배치 결정을 바꾼다. 3시간 비용 차이가 하루
끝 효과와 같은 부호·크기를 갖는지, 틀린다면 어느 시간대와 부하에서 틀리는지 묻는다.

### RQ4. v3는 고전 재배치 규칙보다 비용을 줄이는가?

No Reallocation, FCFS, SPT, Least Slack, Nearest, NetGain과 비교한다. 다만 6차
도착곡선의 정책 재학습과 새 시드 최종평가가 끝나지 않아 **현재 답은 미확정**이다.

## 기여

1. **행위자 분리** — 내보내는 쪽과 받는 쪽을 따로 학습하고, 상호 동의만 중앙에서
   원자적으로 확정하는 구조를 제시한다.
2. **학습·운영 분리** — 느린 평행세계 계산은 교사로만 쓰고, 운영은 작은 MLP 두 개로
   끝낸다.
3. **실패를 검증하는 절차** — 지평, 표본 크기, 시간 순서, 평가 판정력을 각각 분리해
   무엇이 학습 실패처럼 보였는지 수치로 확인한다.
4. **주장 보존 규약** — 무대가 바뀌면 옛 성능을 삭제하거나 승계하지 않고, 확정·진단·
   무효화·진행 중으로 분리한다.

## 용어 주의

이 연구는 넓은 뜻에서 강화학습 정책 연구지만, v3의 학생 학습 자체는 벨만 방정식이나
시간차 갱신을 쓰지 않는다. 시뮬레이터가 만든 행동별 비용을 맞히는 **문맥 비용 회귀**에
가깝다. 따라서 본문에서는 알고리즘을 단순히 “Q-learning”이라고 부르지 않는다.
