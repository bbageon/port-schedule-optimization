# v5 졸업논문 서론 과제

- 제출 범위: **서론 17장과 참고문헌 2장**, 총 19장.
- 가제: 컨테이너 터미널의 작업 재배정과 야드크레인 배정을 위한 통합 강화학습.
- 흐름: 스마트항만 운영 배경, 야드 작업, 혼잡, 결정의 상호작용, 기존 연구,
  문제 정의, 통합 정책·PPO의 필요성, 연구 목표·질문, 범위, 기대 기여.
- 내용 원본: [페이지별 데이터·발표 노트](slides.json).
- 제출 파일: [서론 PPT](v5_졸업논문_서론.pptx).
- 문장으로 읽는 자료: [서론 문장형 초안](서론_문장형_초안.md).
- 기존 [v3 서론](../../v3/1-서론.md)은 배경 자료로만 사용했다. 원본은 수정하지 않았다.

## v5에 맞춘 구분

- 제안·수락·크레인 선택은 역할을 나누지만 하나의 정책망을 공유한다.
- 반사실 교사 대신 본 실행 경험과 비용 증가분으로 PPO를 학습한다.
- 공간 재배정은 트럭 반입만 허용한다. 수락 거절은 원 주문 등록 거절이 아니다.
- 60초는 비용·경험 기록 경계이며 크레인의 무조건적인 재결정 주기가 아니다.
- 새 비선형 본선 마감 비용과 6시간 통지창은 구현된 것으로 적지 않았다.
- 규칙 대비 비용 절감, 학습 효과, 실제 항만 적용 성과를 확정된 결과로 쓰지 않았다.
- 기존 연구에도 통합 최적화와 공유 정책 PPO가 있으므로 최초성을 주장하지 않았다.

## 문헌

확인한 논문 7편의 제목·DOI 또는 원문 링크를 관련 슬라이드와 발표 노트에 담는다.
문헌은 서론의 배경과 방법 선택을 뒷받침하며 v5의 성능을 입증하지 않는다.
출판사 공개 초록·본문 미리보기와 PPO 원문 소개를 근거로 하며, 유료 원문 전체를
읽은 것으로 표시하지 않는다. 참고문헌 상세는 `slides.json`의 `references`에 있다.

## 제출 전

교과목에서 요구하는 이름·학번 표기는 확인 후 표지에 추가할 수 있다.
알려지지 않은 개인 정보는 임의로 채우지 않았다.
