# 본선 작업 턴타임 기준 모델 재학습 성적

공통 완주 입력 9/9개. 학습과 시험 날짜를 분리하고, 같은 트럭·본선 작업 명단으로 세 방식을 평가했다.

## 같은 입력의 비용과 시간

입력마다 모델 세 개의 평균을 먼저 낸 뒤 각 날짜와 물량에 같은 비중을 줬다. 비용은 하루에 들어온 물량 기준이다.

| 배정 방식 | 총비용(억원) | 본선 턴타임(시간/척) | 트럭 턴타임(분/건) | 자정 미완료 트럭(건) |
|---|---:|---:|---:|---:|
| 짧은 작업 우선 | 10.12 | 27.51 | 57.66 | 718.2 |
| 기존 모델 | 13.11 | 30.26 | 73.96 | 1188.4 |
| 재학습 모델 | 12.98 | 29.91 | 72.71 | 1146.0 |

양수는 비교 대상보다 재학습 모델의 비용 또는 시간이 늘었다는 뜻이다.

- 기존 모델 대비 총비용 -1.02%, 본선 -1.14%, 트럭 -1.69%. 비용이 더 낮은 입력 6/9개. 날짜와 시작 모델을 짝지어 다시 뽑은 비용 변화의 95% 범위는 -6.38~+3.72%다.
- 짧은 작업 우선 대비 총비용 +28.20%, 본선 +8.73%, 트럭 +26.10%. 비용이 더 낮은 입력 0/9개. 날짜와 시작 모델을 짝지어 다시 뽑은 비용 변화의 95% 범위는 +20.87~+37.78%다.

### 물량별 총비용

| 하루 트럭 오더 | 공통 완주 날짜 | 짧은 작업 우선(억원) | 기존 모델(억원) | 재학습 모델(억원) |
|---:|---:|---:|---:|---:|
| 3,500 | 3/3 | 2.00 | 2.28 | 2.22 |
| 7,500 | 3/3 | 3.75 | 4.24 | 4.34 |
| 15,000 | 3/3 | 24.61 | 32.81 | 32.36 |

3,500건은 실측 도착률 범위에 든 입력이고, 7,500건과 15,000건은 혼잡이 심해졌을 때의 부담 시험이다.

### 비용 항목

| 배정 방식 | 트럭 시간(만원) | 장비 빈 이동(만원) | 재조작(만원) | 본선 시간(만원) |
|---|---:|---:|---:|---:|
| 짧은 작업 우선 | 79,318.6 | 70.9 | 1,473.1 | 20,358.6 |
| 기존 모델 | 107,035.5 | 90.7 | 1,690.0 | 22,277.1 |
| 재학습 모델 | 105,961.3 | 83.9 | 1,669.2 | 22,046.2 |

본선은 하역 가능 시각부터 마지막 안벽 적하·양하까지, 총톤수 1톤당 시간당 35.88원으로 한 척에 한 번 계산했다.
트럭은 게이트 진입부터 야드 작업 완료까지다. 자정에 미완료면 그때까지의 시간으로 평균과 비용을 계산한다.
본선 항목의 효과를 분리하기 위해 트럭은 기존 식을 유지했다. 시간당 4만원에 1시간 초과분 시간당 4만원을 더한다.
빈 이동은 시간당 6만원, 재조작은 건당 2천원이다. 이 두 항목도 종전 24시간을 집계했다. 총비용은 네 항목의 모형 추정액이다.

세계은행의 항만 지표도 화물작업 시작·종료와 선석 출발을 따로 기록한다. 여기서는 첫 작업을 미루는 선택에도 비용이 생기도록 시작을 사전에 주어진 하역 가능 시각으로 고정했다. [세계은행 항만성과 지표 산정법](https://thedocs.worldbank.org/en/doc/aac122f6df85534428d66a7b9af4b7f6-0400012026/original/CPPI-Methodology-Note.pdf)
미국교통연구소의 트럭 체류 연구는 직접비와 운행 기회 손실을 따로 산정한다. 국내 트럭이 한 시간 이후 겪는 추가 비용의 곡선은 이번 비교에서 실측 보정하지 않았다. [미국교통연구소 체류비용 연구](https://truckingresearch.org/2024/09/new-research-documents-substantial-financial-and-safety-impacts-from-truck-driver-detention/)

## 완료 여부와 학습 범위

| 배정 방식 | 모든 배가 끝난 실행/전체 | 끝난 배/전체 | 144시간에 남은 안벽 작업(개, 전체 실행 합계) |
|---|---:|---:|---:|
| 짧은 작업 우선 | 9/9 | 27/27 | 0 |
| 기존 모델 | 27/27 | 81/81 | 0 |
| 재학습 모델 | 27/27 | 81/81 | 0 |

학습은 매번 같은 날짜 12개를 모두 실행했다. 모든 배가 끝난 날의 선택에는 자정 이후 마지막 배까지 남은 비용을 연결했다.
144시간에도 작업이 남으면 최종비용을 알 수 없어 그날을 가중치 갱신에서 제외했다.

| 시작 모델 | 완료한 학습일 | 실제 가중치 갱신/예정 | 완료일의 자정 이후 선택(회) |
|---|---:|---:|---:|
| 9951101 | 7/12 | 5/6 | 21,967 |
| 9951102 | 6/12 | 4/6 | 20,358 |
| 9951103 | 9/12 | 6/6 | 31,325 |

같은 정책 학습 알고리즘과 모델 구조를 사용했다. 세 비교 방식 모두 새 산정식으로 채점했다.
기존 모델과 재학습 모델의 성적 차이에는 추가 학습의 효과도 포함된다. 산정식 변경만의 효과를 분리하려면 기존 식으로 같은 기간 추가 학습한 대조군이 필요하다.
별도 동작확인 날짜에는 가장 유리하게 계산해도 지정 블록에 양하 최소 123개를 놓을 수 없었다.
시험은 기존 합성 날짜 세 개를 다시 썼다. 자정 이후 신규 유입 없이 당일 배를 마무리했으며, 실제 항만의 연속운영 절감액은 검증 대상 밖이다.
