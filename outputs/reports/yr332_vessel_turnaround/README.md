# 본선 작업 턴타임 기준 재학습과 성능 비교

**진행 중.** 세 시작 모델로 같은 합성 입력을 사용해 재학습하고 있다. 성능표는 최종 가중치 평가가 끝난 뒤 확정한다.

## 첫 갱신 시점

첫 번째 시작 모델과 첫 시험일 3,500건의 중간 측정이다. 세 방식 모두 같은 선박 세 척의 마지막 하역까지 완료했다.

| 배정 방식 | 총비용(억원) | 평균 본선 작업(시간/척) | 평균 트럭 진입→완료(분/건) |
|---|---:|---:|---:|
| 짧은 작업 우선 | 1.8240 | 17.96 | 14.49 |
| 기존 모델 | 2.0758 | 20.56 | 15.95 |
| 첫 갱신 모델 | 2.0614 | 19.36 | 17.36 |

기존 모델보다 본선 비용이 812만원 줄고 트럭 비용이 687만원 늘어 총비용은 144만원(0.69%) 줄었다.
규칙에 비해서는 13.02% 높다. 별도 개발 날짜는 세 방식 모두 144시간에도 작업이 남아 최종비용 비교에서 제외한다.
중간 가중치는 최종 모델 선정에 쓰지 않는다. [중간 가중치 시험](development/first-update-holdout-0-3500.json)
세 모델의 학습 일정이 절반에 이르면 같은 첫 시험일 3,500건을 한 번씩 재어 초기값에 따른 차이도 기록한다.
이 중간 점검은 같은 날의 변화만 보고하며, 12일 학습 일정과 최종 시험 조건은 그대로 적용한다.

## 산정과 비교

- 본선은 한 기항의 하역 가능 시각부터 마지막 안벽 적하·양하까지 시간을 잰다. 완료까지 자정을 넘어간 비용도 당일 선택의 학습 목표에 들어간다.
- 트럭은 게이트 진입부터 야드 작업 완료까지이고 24시간 시점에 미완료인 오더는 그때까지의 경과시간을 센다.
- 세 정책 모두 같은 입력과 비용을 사용한다. 트럭·빈 이동·재조작 세 항목의 관측창과 단가는 이전 계약을 유지한다.
- 학습일 12개와 시험용 합성 날짜 3개는 분리했다. 시험은 날짜마다 트럭 3,500·7,500·15,000건을 각각 평가한다.
- 24시간 이후에는 다음 날의 신규 물량을 넣지 않고 같은 정책으로 당일 기항을 마무리한다. 실제 연속운영 성능은 별도 검증이 필요하다.

## 완료 관측 검사

- 학습·시험·동작확인 입력 22개 모두 선박별 배정 물량이 원래 적하·양하 총량과 일치했다.
- 별도 동작확인 날짜의 4척 중 3척은 두 방식 모두 완료했다. 대형선 1척에 144시간 뒤 규칙은 양하 484개, 기존 모델의 확률 선택은 499개가 남았다.
- 입고 트럭을 하나도 받지 않고 반출을 모두 허용하는 유리한 조건으로 계산해도 그 날짜 지정 블록의 양하 최소 123개는 수용할 수 없다.
- 최초 학습 날짜의 규칙 재생에서는 36시간부터 144시간까지 같은 83개가 남았다. 전체 용량만으로 규격별 적치 가능성까지 보장할 수 없다.
- 미완료 기항은 완료시간을 추정해 채우지 않는다. 전체의 완주율·잔량을 공개하고, 모든 비교 정책이 완료한 같은 입력에서만 최종 비용·소요시간을 비교한다.
