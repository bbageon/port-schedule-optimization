  미추적 v4 스크립트 두 개도 사본에 포함했다. 원본 세대와 `claude.md`는 무수정이다.

- 크레인 충돌 후보는 선택 전에 가린다. 선택 후 규칙의 강제 대체는 없다.

## 짧은 실제 실행

[train.json](train.json): 진단 시드 9,900,302, 하루 트럭 300대, 21블록,
시뮬레이션 12시간. 실제 실행 구간 측정 5.54초(프로세스 시작·모듈 적재 시간 제외).
이는 저부하 배선 검사이며 장기 학습 소요시간이나 v4 대비 속도비가 아니다.

| 확인 항목 | 실측 |
|---|---:|
| 정책 갱신 | 6회 |
| 판매 / 구매 / 크레인 선택 | 118 / 107 / 1,267건 |
| 크레인 작업 / 대기 / 위치이동 / 선행 재조작 | 642 / 533 / 83 / 9건 |
| 공간 이동 / 시간 이연 확정 | 23 / 34건 |

| 누적비용 | 3,883,410.871950724원 |
| 전체 구간 보상 합계 | −3.883410871950722 |

즉 네 종류의 크레인 행동과 양쪽 거래가 실제 엔진까지 이어졌으며,
`−보상 합계 × 100만원 = 누적비용`이 반올림 오차 안에서 일치한다.
본선 유휴비용도 424,383.4265원 발생해 트럭만 움직인 빈 검사가 아님을 확인했다.

[replay.json](replay.json): 저장한 가중치를 다시 읽어 12시간 실행, 갱신·반사실 0회.
최대확률 선택에서는 판매가 모두 KEEP이라 거래 0건이었다. 짧은 갱신만으로
판매·구매 판단 품질이 확보됐다는 뜻은 아니며 학습 성공·성능 우위로 해석하지 않는다.

  --output outputs/v5/new-debug

  --seconds 43200 --output outputs/v5/new-replay
