# 실제 오더 분포 보정 후 고정 정책 비교

비율·시간대 보정 뒤에도 반입 우선 성향이 남았다. 학습 후 모델의 트럭 평균은 학습 전보다 14.21% 짧지만, 반출은 7.97% 길다. 짧은 실작업 우선 규칙보다 전체 평균이 17.93% 길어 채택 근거가 아니다.

작업 비율과 시간대 분포를 한 축씩 보정했다. 학습 가중치는 고정했으므로 환경 변경의 영향과 기존 모델의 성향을 보는 진단이다.
트럭 지표는 오더별 게이트 진입→작업 완료이며, 24시간 안에 끝나지 않은 오더도 창 끝까지의 시간을 포함한다.

## 기존 규칙 7개와의 비교

| 규칙 | 기존 입력(분) | 작업 비율 보정(분) | 비율+시간대 보정(분) |
|---|---:|---:|---:|
| SF_SPT | 97.575 | 89.736 | 80.396 |
| FIFO | 137.509 | 129.995 | 113.776 |
| LIFO | 140.293 | 134.121 | 118.449 |
| SPT | 97.575 | 89.736 | 80.228 |
| NEAREST | 122.328 | 114.275 | 100.133 |
| LWKR | 136.858 | 129.803 | 113.449 |
| RANDOM | 136.451 | 130.580 | 112.319 |
| initial | 131.357 | 123.757 | 110.520 |
| trained | 115.878 | 107.054 | 94.811 |

SF_SPT=실작업 중 짧은 작업 우선, FIFO=먼저 통지된 작업, LIFO=나중 통지된 작업, SPT=짧은 작업, NEAREST=가까운 작업, LWKR=오래 기다린 트럭 작업, RANDOM=무작위 기준이다.
여기서 FIFO는 실제 블록 도착순인 FCFS_ARRIVAL과 다르다. 기존 ag와 같은 일곱 규칙을 고정한 비교다.
사전 기준인 SF_SPT 대비 최종 조건의 학습 후 모형 비용은 19.72% 높다. 실제 원화 지출을 예측한 수치는 아니다.
규칙마다 같은 실행 가능 후보와 입력을 사용했다. 모델 3개는 같은 오더를 보며 독립된 평가일 3개로 세지 않는다.

## 저장된 학습 자료의 순위 진단

- 기존 비교 297쌍 중 반입·반출을 직접 비교한 것은 70쌍이다.
- 시뮬레이션 비용 비교는 반입 48쌍, 반출 22쌍을 선호했다.
- 최종 모델은 같은 입력의 67쌍에서 반입에 우선 점수를 줬고, 반출이 유리했던 22쌍 중 21쌍에서도 반입을 우선했다.
- 저장된 비교 입력에 대한 점수 검사다. 실제 실행 선택 비율이나 새로운 자료에서의 예측 정확도와 다르다.
- 자료 구성·특징 구분·회차별 학습과 이전 사례 유지 문제를 먼저 구분해야 한다. 반복 횟수만 늘리면 해결된다고 확정하지 않는다.

## 검증과 한계

- 본 비교 120회(고유 117회·반복 3회), 기본 경로 과거 재현 2회, 관련 검사 72건 통과.
- 트럭 장부 1,036,500행, 전체 작업 1,446,708행을 저장 시각에서 별도로 검산했다.
- 실행 코드 `35400a24`, 코드·설정·가중치 206개 해시 확인.
- 물량별 신규 입력 시드가 하나다. 통계적 확증·최적성 증명·실제 터미널 성능을 주장하지 않는다.
- 실제 오더/차량 단위와 수집 범위, 분 단위 몰림·유형별 시간대 결합, 순수 작업·운반 시간이 남아 있다.
- 원본 13일은 이미 개발에 사용했다. 새 기간은 미확보이므로 독립 최종 평가는 수행하지 않았다.
- 보정은 CPU 하루 실행의 명시적 옵션이다. 연속 월·배열 경로의 검증으로 승계하지 않는다.
