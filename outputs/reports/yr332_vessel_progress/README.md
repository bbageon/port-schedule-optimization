# 양적하 진척 숫자 확인 (bo, 학습 없음)

합성 환경 진단이다. 고정한 시작 모델로 학습 월을 4번 굴리며 결정마다 '그 블록이 일부를 맡은 미완료 기항의 남은 안벽 작업 시간'(기항마다 가장 많이 남은 몫 기준)을 기록했다. 가중치 갱신은 없다.

**판정(실행 전 기준): 두 기준 모두 통과 — bn에 이 숫자를 넣는다.**

## 1. 배가 끝나기까지 남은 시간을 더 잘 맞히나

그 블록이 일부를 맡은 미완료 기항이 끝나기까지 남은 시간(평가 결정의 표준편차 46.66시간)을 비용 예측부 머리만 새로 맞춰 예측했다. 2개 월로 맞추고 다른 2개 월로 평가했다.

- 숫자 없이: 오차 39.17시간, 설명력 29.5%, 시간대 비율 30.0%
- 숫자를 넣고: 오차 27.36시간, 설명력 65.6%, 시간대 비율 46.2%
- 오차 감소 30.1% (기준 30% 이상) — 통과

결과를 본 뒤 추가 확인([난수별 결과](seed-sensitivity.json)): 같은 자료에서 예측부 맞춤 난수만 10가지로 바꾸면 오차 감소가 29.2~30.8%(중앙 30.0%)였고 5/10번이 기준 이상이었다. 개선 크기는 일정하지만 기준과 거의 같아 통과는 경계선이다. 등록된 판정은 바꾸지 않는다.

## 2. 블록의 양적하 진척이 숫자에 드러나나

블록 몫이 가장 늦게 끝나 기항 완료를 좌우한 결정 12,705개를 봤다.

- 결정 순간 그 블록 몫이 가장 많이 남아 있던 비율: 77.3% (기준 50% 이상) — 통과. 이때는 그 블록의 30분 양적하가 숫자를 줄인다.
- 비교: 지금 입력(여유 시간, ±2시간 상한)에서 30분 진척이 드러날 수 있던 비율은 11.9%였다.
- 30분 안에 그 기항의 남은 작업이 실제로 줄어든 비율: 65.2% (참고)

## 참고

- 숫자가 0보다 큰지와 실제로 열린 기항이 있는지가 일치한 비율 100.00%. 0보다 클 때 중앙값 15.2시간.
- 남은 작업 시간은 남은 안벽 작업 수 × 안벽 크레인 작업 간격이다. 막힘으로 늦어지는 시간은 들어 있지 않다.
- 같은 학습 월을 맞춤과 평가에 썼다. 모델 하나의 기록이다.
