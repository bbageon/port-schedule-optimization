# 100만원 보상 눈금 교체 — 실행 결과

2026-09-28 · YR-331-d · [문헌·새 수식](../../../docs/research/v6-workload-reward/normalization.md)

**100만원 고정 기본값을 제거했다.** 별도 기준 규칙의 할인 누적 비용 표준편차(변동 크기)로 나눈다.
자료에서 나온 이번 눈금은 **37,620,956.31원**이다. 합성 운전의 통계값이며 실제 비용 단가나 공통 권장값이 아니다.

```text
기준 운전: z_t = 0.999^(Δt/60초) × z_(t−1) − 증가비용
비용 보상 = −증가비용 / 기준 구간 z의 표준편차
```

기준 자료는 학습 전에 고정하며 평균을 빼거나 큰 손해를 잘라내지 않는다.
원화 네 단가의 타당성은 별도 문제로 남는다. 부하 보조 점수도 기본 설정에서 켜지 않는다.

보상에 기준 눈금을 곱하면 같은 비용이 복원된다. 이 비용 수치는 성능 비교나 개선율이 아니다.
해당 시점까지 1,377건 접수·누락 0, 물리 제약 검사를 통과했다. 6시간에 끊은 실행을 전건 완료로 해석하지 않는다.

기준 실행 소스는 `bfae72a3`, 새 학습 실행 소스는 `e2485204`이며 모두 변경 없는 별도 작업 폴더에서 실행했다.

기존 시험 6개가 100만원을 가정해 처음에는 실패했다. 시험의 비용 복원 식을 실제 설정값으로 고친 뒤 전체 78개가 통과했다.
실패 기록도 보존했다. 배열의 추가 13개 검사와 패키지 검사는 별도로 통과했다.
원본 실행 기록의 `generation=v5`·첫날 `phase=warmup`은 복사된 공통 기록기의 과거 표기다.
실제 실행 코드는 v6이고, 실행 설정의 `training_during_first_day=true` 및 360개 학습 구간·6회 갱신이 실질 기록이다. 원본을 사후 수정하지 않았다.
