## 해석의 범위

- 후보 보존율은 각 결정에서 제한 전 생성된 실행 가능 행동 중 남겨진 비율이다.
  같은 작업이 여러 시점에 반복 집계된다. 모든 잠재 오더의 보존율이나 최적 행동 보장은 아니다.
- 학습 비교는 초기 모델 3개·각 3회 갱신이며, 같은 평가일 세 개에서 비교한다.
  장기 수렴·통계적 확증을 뜻하지 않는다. 초기 모델마다 같은 평가일을 다시 사용한다.
  세 반복의 학습 입력도 다르므로 반복 간 차이는 초기 가중치와 학습 자료의 변동을 함께 포함한다.
- 비교 방법을 분리하기 위해 공통 정책이 수집한 자료로 학습한다.
  각 개선 정책이 자기 행동으로 자료를 다시 모으는 장기 학습의 검증은 아니다.
  학습 중 자동 검사는 분기 시작의 원래 선택과 대안 적용을 대조한다.
  모든 학습 분기의 3시간 전체 궤적을 본 실행과 대조한 것은 아니다.
- 예약 오차·양하 용량 등 현실 보정은 미완료다. 실제 항만에서의 비용 절감 주장을 하지 않는다.
- 체류시간, 비용, 투입, 관측 종료 시 미완료, 본선 완료를 함께 본다.
  관측창은 24시간, 추가 처리 후 본선 완료 집계는 26시간으로 서로 구분한다.
  미완료 트럭도 24시간 종료 시점까지의 체류시간으로 평균에 포함한다.
  그 이후의 추가 대기는 이 평균에 없고, 미투입 트럭은 별도 집계한다.

## 재현 자료

- 단계별 `campaign*.json`: 실행 커밋, 코드 해시, 설정, 입력, 완료 기록.
- 단계별 `.json.gz`: 입력/모델 식별값, 선택·사건·결과 해시와 원래 수치.
- 학습 `model-*/`: 초기/회차별 모델, 공통 수집 모델, 원래 비용을 포함한 학습 자료.
- [구현 검증](prepared-verification.json): 수정 후 고유 160개 항목 통과. 초기 실패 기록도 보존.
- [최초 승인 판정](authorization.json): 이전 현실성 게이트의 실패를 보존한다.
  최신 사용자 지시에 따른 제한된 진단 실행이며 기존 실패를 통과로 바꾸지 않는다.

집계 명령은 `scripts/v7/summarize_six_steps.py candidates <단계 폴더>`와
`scripts/v7/summarize_six_steps.py learning outputs/reports/yr332_six_steps/learning`이다.
