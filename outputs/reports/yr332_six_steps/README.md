# 후보 생성·학습 구조 6단계 진단

2026-11-05 사용자 지시에 따른 6단계 진단을 순서대로 모두 완료했다.
[사전등록](../../../docs/research/v7-discharge/six-step-prereg.md)의 입력·예산·판정 범위를 유지한다.
계산 시간과 후보 보존은 개선했지만, 이번 짧은 학습에서 기존 작업 규칙보다 좋은 정책은 얻지 못했다.

## 진행사항

| 단계 | 바꾼 것 | 상태·결과 | 증거 |
|---|---|---|---|
| 1 | 후보 계산 | 완료. 결과 동일, 존재 확인 단축으로 전체 시간 20~28% 감소. 자리 재사용 미채택 | [결과](stage1-existence.md) |
| 2 | 후보 12칸/전체 | 완료. 후보 보존 100%, 학습 전 체류 평균은 악화 | [결과](stage2/report.md) |
| 3 | 8번째 입력의 의미 | 완료. 의미 수정 확인, 18개 상한의 정보 손실은 남음 | [결과](stage3/report.md) |
| 4 | 개별 값/비용 차이 학습 | 완료. 차이 학습 비용 -0.62%, 같은 후보 규칙 대비 +11.88%·채택 미통과 | [결과](learning/stage4-report.md) |
| 5 | 비교 표본 선정 | 완료. 앞 단계 대비 비용 +8.19%·체류 +9.05%, 미채택 | [결과](learning/stage5-report.md) |
| 6 | 작업 방향 정보 한 칸 | 완료. 앞 단계 대비 비용 -0.40%이나 혼잡일 악화·본선 보호 미통과 | [결과](learning/stage6-report.md) |

4단계의 -0.62%는 개별 값 학습 대비, 5단계의 +8.19%는 비용 차이 학습 대비,
6단계의 -0.40%는 표본 변경 학습 대비다. 음수는 비용 감소, 양수는 비용 증가다.

## 운영 성능 판정

| 학습 방법 | 같은 전체 후보 규칙 대비 비용 | 체류 | 원래 12개 선별 규칙 대비 비용 |
|---|---:|---:|---:|
| 개별 값 학습 | +12.68% | +9.97% | +24.43% |
| 두 작업 비용 차이 학습 | +11.88% | +8.78% | +23.54% |
| 비교 표본 변경 | +20.71% | +17.94% | +33.39% |
| 작업 방향 추가 | +20.21% | +16.99% | +32.69% |

규칙은 실작업을 먼저 처리하고 그 안에서 예상 소요시간이 짧은 작업을 우선한다.
같은 후보의 규칙은 학습 방식 비교 기준이고, 원래 규칙은 기존 시스템 대비 차이를 확인하는 기준이다.
학습 정책 모두 같은 후보 규칙 대비 본선 완료가 9/9회 줄어 이번 운영 채택은 미통과다.
원래 12개 설정은 별도 점수로 후보를 사전 선별하므로 후보 범위의 차이도 결과에 포함된다.
각 변화율은 같은 입력의 짝별 비율을 낸 뒤 세 물량·세 학습 반복을 같은 비중으로 평균했다.

4단계는 같은 자료에서 손실, 5단계는 같은 수집 정책에서 표본, 6단계는 같은 자료에서 입력만 변경했다.
앞 단계가 채택됐다고 전제하고 합친 성공 사례가 아니다.
계산 단축은 후속 진단에 적용했고 `decision_probe_shortcircuit=True`로 재현한다.
자리 재사용, 표본 변경, 입력 한 칸 추가를 운영 성능 개선으로 채택하지 않았다.

## 검증

- 구현 검사 고유 160건 통과. 시험 대상 코드 182개 파일이 실행 중 바뀌지 않았음을 확인했다.
- 저장 자료로 36개 갱신을 다시 학습해 가중치가 모두 정확히 같았다: [재학습 대조](learning/fit-replay-verification.json).
- 자료·모델·입력·수집 경로 대조 958건 통과: [최종 검사](verification-final.json).
- 여섯 작업의 Dashboard·명세·코드·원자료 일치 확인: [최종 대조](final-dashboard-audits.json).
- 학습 자료 생성은 4·5단계 각각 198쌍·396미래 실행이다. 6단계는 5단계 자료를 재사용했다.
  별도 운영 평가는 규칙 포함 51회다. 독립된 날짜 51개라는 뜻은 아니다.
- 자료 생성 합계 약 57.24분, 가중치 갱신 합계 약 1.02초다. 프로그램 시작·평가 시간은 별도다.

재현 검사는 저장 자료에서의 학습을 반복한 것이며 모든 환경 수집을 다시 실행한 것은 아니다.
연구 게이트는 운영 성능 미통과·기록 정합 통과·현실성 미해소다: [최종 판정](final-verdict.json).

## 해석의 범위

- 후보 보존율은 각 결정에서 제한 전 생성된 실행 가능 행동 중 남겨진 비율이다.
  같은 작업이 여러 시점에 반복 집계된다. 모든 잠재 오더의 보존율이나 최적 행동 보장은 아니다.
- 학습 비교는 초기 모델 3개·각 3회 갱신이며, 같은 평가일 세 개에서 비교한다.
  장기 수렴·통계적 확증을 뜻하지 않는다. 초기 모델마다 같은 평가일을 다시 사용한다.
  세 반복의 학습 입력도 다르므로 반복 간 차이는 초기 가중치와 학습 자료의 변동을 함께 포함한다.
- 비교 방법을 분리하기 위해 공통 정책이 수집한 자료로 학습한다.
  각 개선 정책이 자기 행동으로 자료를 다시 모으는 장기 학습의 검증은 아니다.
  학습 중 자동 검사는 분기 시작의 원래 선택과 대안 적용을 대조한다.
  모든 학습 분기의 3시간 전체 궤적을 본 실행과 대조한 것은 아니다.
- 예약 오차·양하 용량 등 현실 보정은 미완료다. 실제 항만에서의 비용 절감 주장을 하지 않는다.
- 체류시간, 비용, 투입, 관측 종료 시 미완료, 본선 완료를 함께 본다.
  관측창은 24시간, 추가 처리 후 본선 완료 집계는 26시간으로 서로 구분한다.
  미완료 트럭도 24시간 종료 시점까지의 체류시간으로 평균에 포함한다.
  그 이후의 추가 대기는 이 평균에 없고, 미투입 트럭은 별도 집계한다.

  최신 사용자 지시에 따른 제한된 진단 실행이며 기존 실패를 통과로 바꾸지 않는다.
