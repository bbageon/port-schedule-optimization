# YR-116 — 새 판정 전 후보·리뷰창 계약 완결

## 발견 경위

YR-105-b 착수 감사에서 YR-112-b의 “1 bay 탈출 후보 종단 검증”과 다중블록의
gate-in review 창을 다시 따라갔다. 새 평가 대역을 쓰기 전에 공통 후보집합과 결정시점이
완전한지 확인하는 것이 목적이다.

## 결과를 보기 전에 확인한 결함

1. `_escape_bays()`는 통로 `(17,19)`와 크레인 위치 `16`에서 목표 `15`를 계산했다.
   그러나 최종 `_reposition()`의 일반 미세이동 필터 `거리 ≤ 1 bay`가 다시 삭제했다.
   기존 테스트는 중간 목표 집합까지만 검사해 “종단 검증”이 아니었다.
2. `MultiBlockTerminal._schedule_review_epochs()`가 `0 < actual_gate_in`만 허용했다.
   평가창 시작과 동시에 들어온 반입은 합법적인 `[gate-in, block-in)` 창이 있는데도
   재배정 검토에서 영구 제외됐다. YR-113 원자료에는 선택 40건·확증 77건이 있었다.

## 수정 계약

- 일반 선제 위치조정의 `≤1 bay` 하한은 유지한다.
- `interference_deadlock_corridors()`가 직접 만든 탈출 목표만 하한에서 면제한다.
- gate-in review 범위는 `0 ≤ actual_gate_in ≤ evaluation_end`로 고친다.
- 두 변경 모두 정책 점수·혼잡식·이송 임계·비용함수는 바꾸지 않는다.

## 검증

- 1 bay 목표가 중간 계산뿐 아니라 최종 `REPOSITION` 후보로 남고 실행 가능함을 검사한다.
- t=0 epoch가 양 블록에 예약되고 전역 장부가 gate-in 0을 보존함을 검사한다.
- epoch가 있어도 이송 0이면 기존 사건흐름·비용이 같은 회귀를 유지한다.
- YR-112·다중블록 브리지 표적 테스트: **35 passed**.
- 전체 회귀: **604 passed / 1 failed / 3 skipped**. 실패 1건은 이번 변경 전부터
  등록된 YR-111 잔차망 수렴 테스트와 동일하다.

## 기존 결론에 대한 적용 범위

두 변경은 공통 환경 계약을 넓히므로 과거 YR-113의 독립 확증을 새 결과로 대체하지 않는다.
같은 확증 대역을 재사용한 계약 민감도 검사는 방향 보존만 확인한다. 결과는 아래에 append한다.

## 실행 결과

2026-07-28, 추적 파일 변경이 없는 clean commit에서 기존 YR-113 확증 대역과
**같은 106쌍**을 재실행했다(정확한 SHA는 결과 JSON의 재현 스탬프가 원본이다).
이 검사는 새 독립 확증이 아니라 공통 계약 변경에 대한 집계 민감도 검사다.

| 채널 (`NOTRANSFER−BASE`) | 구 계약 | 새 계약 |
|---|---:|---:|
| truck (1차) | `+3.347 [2.395,4.299]` | `+3.365 [2.416,4.315]` |
| vessel (탐색) | `+5.286 [2.566,8.005]` | `+5.562 [2.858,8.266]` |
| move (탐색) | `−0.572 [−0.633,−0.512]` | `−0.573 [−0.633,−0.512]` |
| total (탐색) | `+8.060 [5.234,10.886]` | `+8.355 [5.558,11.151]` |

- guard 전부 통과, 구·신 대역 digest 동일, 실행 시 추적 파일 변경 없음.
- 트럭 1차 지표의 집계 방향과 유의성은 유지됐다. 따라서 YR-105-b가 전제로 삼는
  “현행 0.10 이송이 이송 0보다 트럭 비용을 낮춘다”는 방향은 보존됐다.
- 이는 **106개 개별 시드가 모두 같은 방향**이었다는 뜻이 아니다. 총비용이 달라진 행은
  5/106이고 트럭 부호가 바뀐 시드도 1개 있었다. 계약 무해성·동등성을 별도 확증한 것도 아니다.
- vessel·total은 원래 탐색 채널이므로 이번 재사용으로 확증 지위가 올라가지 않는다.

결론: 두 누락 계약을 고친 뒤에도 YR-113의 **106쌍 집계 결론은 유지**된다. YR-116을
종결하고, 새 대역에서 YR-105-b 임계 최적화를 진행할 수 있다.
