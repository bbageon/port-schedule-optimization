# 일별 운영 기록 계측 검증 — 실행 전 계약

- 목적: 사용자가 요청한 일별 혼잡·행동 기록을 추가하되 정책 궤적·비용 불변을 확인한다.
- 진단 시드 9,900,720, 연속 2일, 하루 60대. 독립 20개월의 성능 표본을 사용하지 않는다.
- 기준/전체/시간만 세 정책을 각각 관측 끔/켬으로 비교한다. 기존 month-02/ckpt_029.pt 고정, 새 학습 없음.
- 원래 공급계획, PRESERVE 요청 접수, 물리적 공급 연결 검사 켬. 계측 외의 인자를 동일하게 둔다.
- 일정 간격 300초, 2일과 마지막 경계까지 577개 상태 기록. 새 요청·시장 결정 이전 관측이다.
- 기존 일별 결과 필드·요청 입력 지문·요청 결과·컨테이너 연결 결과가 전부 같아야 한다.
- 같은 자정의 전날 끝 상태와 다음 날 시작 상태가 일치해야 한다. 기록 완전성 검사 모두 통과해야 한다.
- 실제 30일 실행 성능·예약 정원·변경 비용의 검증으로 해석하지 않는다.
- 소스는 실행 전 commit 후 깨끗한 별도 checkout에서 실행한다. 테스트 실행과 이 검증을 구별한다.
- 자원: 기존 실험 외 CPU 4에 1개 프로세스, Torch 1스레드. 20코어 사용자 상한 이내.
