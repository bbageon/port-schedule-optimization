# 실제 도착순 대비 v7 학습 정책 재평가

2026-11-06. 도착순 대비 학습 정책의 평균 트럭 체류시간은 줄었다. 다만 짧은 작업 우선 규칙에는
여전히 못 미쳤고, 일부 실행의 투입·본선 보호 조건도 충족하지 못했다. 재학습은 하지 않았다.

## 진행사항

비교 기준은 해당 크레인의 실행 가능한 후보 중 **실제로 작업 대기열에 들어온 순서**다.
트럭은 블록 도착, 적하는 작업 해제, 양하는 야드 인계 사건을 쓴다. 안전·필수 작업·공동 예약
제약과 실작업 우선은 공통이다. 사전 준비는 실작업 뒤에서 공개 통지순으로 평가한다.
기존 코드의 통지순 FIFO와 구분했으며, 특정 부산항 터미널의 실운영 규칙이라고 주장하지 않는다.

### 도착순 대비 전체 비교

| 방식 | 트럭 체류시간 변화 | 비용 변화 | 체류시간이 짧았던 비교 |
|---|---:|---:|---:|
| 학습 전 모델 | -4.35% | -2.09% | 5/9 |
| 기존 학습 | -13.62% | -12.69% | 8/9 |
| 비용 차이 학습 | -14.66% | -13.37% | 8/9 |
| 비교 표본 확대 | -7.14% | -6.27% | 6/9 |
| 작업 방향 추가(최신) | -8.20% | -6.97% | 7/9 |
| 짧은 작업 우선 | -20.80% | -21.99% | 3/3 |

음수는 감소다. 같은 입력의 변화율을 낸 후 세 물량·세 모델에 같은 비중을 두었다.
짧은 작업 우선은 모델 없는 규칙이라 세 입력만 있다. 9쌍은 독립된 9일이 아니라 **같은 세 날짜 × 모델 셋**이다.
비용은 기존 원화 네 항을 유지한 값이며 현장 금전 절감으로 해석하지 않는다.

| 하루 트럭 오더 | 도착순 | 최신 모델 3개 평균 | 변화 |
|---|---:|---:|---:|
| 3,500건 | 26.79분 | 25.86분 | -3.49% |
| 7,500건 | 52.31분 | 47.86분 | -8.50% |
| 15,000건 | 230.85분 | 201.76분 | -12.60% |

도착순보다 세 물량의 평균은 짧다. 다만 개별 모델 결과가 모두 개선된 것은 아니다.
체류는 게이트 진입 이후이며, 관측 24시간 끝에 남은 트럭은 종료 시점까지의 시간으로 포함한다.
미투입 차량과 24시간 이후 추가 대기는 이 평균에 포함되지 않는다.

### 함께 봐야 할 손해와 잔여

| 학습 방식 | 투입 감소 | 24시간 미완료 증가 | 26시간 본선 완료 감소 |
|---|---:|---:|---:|
| 기존 학습 | 3/9 | 0/9 | 1/9 |
| 비용 차이 학습 | 3/9 | 0/9 | 1/9 |
| 비교 표본 확대 | 3/9 | 3/9 | 4/9 |
| 작업 방향 추가(최신) | 3/9 | 2/9 | 3/9 |

숫자는 도착순보다 나빠진 비교의 수다. 평균 개선만으로 모든 조건을 통과했다고 보지 않는다.
혼잡일 도착순은 15,000건 중 14,439건이 투입됐고, 최신 모델은 평균 12.33건 덜 투입됐다.
같은 날 최신 모델의 미완료는 평균 941건 줄고 본선 완료는 평균 57건 늘었으나,
투입 차이의 원인을 아직 구분하지 못해 순수한 처리 효율 개선으로 확정하지 않는다.

## 해석

1. “도착순보다 나은가”에는 평균 개선이 관측됐다. “짧은 작업 우선도 넘는가”에는 아직 아니다.
   최신 모델은 짧은 작업 우선 대비 체류 +16.99%, 비용 +20.21%다.
2. 학습 전 모델도 도착순보다 체류가 평균 4.35% 짧다. 도착순 대비 차이 전체를 학습만의 효과로 귀속하지 않는다.
   같은 초기 모델 대비 최신 모델의 직접 짝비교는 체류 -3.35%, 비용 -4.20%다.
3. 네 학습 방식을 전부 보고했으며 이번 결과로 모델을 다시 고르지 않았다. 각 모델은 3회 갱신한 짧은 진단이다.
4. 세 날짜는 앞 실험에서 이미 본 입력이다. 실제 도착 오차·운반 용량·작업시간·비용 단가의 현실 보정은 미완료다.
5. 이번 도착순 규칙은 네 작업 흐름의 실제 대기열 진입을 합친 연구용 정의다. 실제 터미널의 본선 우선순위와 같다는 보장은 없다.

## 검증과 재현

- 새 실행 12회: 도착순 3조건+반복 1회, 기존 결과 정확 재현 대조 8회.
- 재현 대조 8회에서 후보·선택·사건·작업·트럭 장부·결과가 이전과 정확히 같았다. 도착순 반복도 같다.
- 기존 원자료 51개·저장 모델 15개(학습 12+초기 3)의 해시를 전수 확인했다. 공통 소스 변경은 새 배차 규칙 파일뿐이다.
- 구현 관련 검사 40건 통과. 저장 결과로 각 비교의 변화율·입력 동일성을 독립 재계산했다.
- 설정과 코드·입력·산출물 연결 검사는 통과했다. 현실성 게이트의 기존 실패는 그대로 남았다.
- 평가 CPU 1스레드·최대 두 실행 동시 진행. 시간은 실행 기록이며 속도 성과로 비교하지 않는다.
- 실행 커밋: `694606611174b43e3b5d85c21331a5d03dbef045`. 실험 중 원천 파일 184개의 해시 불변을 확인했다.
