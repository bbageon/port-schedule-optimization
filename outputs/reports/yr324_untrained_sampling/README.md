# YR-324 단계 0 — 학습 전 가중치 + 추첨 (2026-09-22)

2×2 의 마지막 빈 칸을 채웠다. 코드 `adaa5f2` · 체크포인트 `initial.pt`(학습 0회) ·
시드 9900306 · 같은 30일 명단 · 추첨 · 갱신 없음. [[YR-319]] 와 **체크포인트만** 다르다.

**결과: 30일 완주. 규칙의 1.47배. 못 나간 트럭 8대.**

## 두 가지가 각각 확정된다

**① 최고점 선택이 망친다.** 가중치가 무엇이든 무너진다. 학습을 **한 번도 안 한** 망도
159배다. 172배 중 학습이 더한 몫은 8%뿐이다.

**② 학습이 정책을 나쁘게 만들었다.** 추첨으로 조건을 맞추면 학습 전은 30일을
1.10~1.47배로 완주하고 학습 후는 7일차에 4.04배로 죽는다. 사전등록한 해석 그대로다.

## ★그리고 "학습 중에는 잘 됐다" 도 착각이었다

학습하며 굴린 30일(138억·72.3분·미출차 48)보다 **학습을 안 한 망이 더 낫다**
(133억·71.3분·미출차 8). 즉 그 실행이 버틴 것은 **온라인 갱신 덕이 아니라 추첨 덕**이다.
672회의 갱신은 성능을 올리지 못했다.

## 날짜별 턴타임 (규칙 대비)

30일 내내 **1.10 ~ 1.47배**. 발산하지 않는다. 가장 나쁜 날이 3일차 1.47배이고
마지막 날이 1.25배다. 같은 기간 학습 후 가중치는 1.39 → 4.04배로 벌어졌다.
