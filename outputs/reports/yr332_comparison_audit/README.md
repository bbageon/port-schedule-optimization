# 비교 기준·비용 수치 타당성 감사

2026-11-07 · YR-332-t. 새 학습 없이 7규칙 비교(YR-332-v)의 69회를 다시 실행했다. 비용 숫자를
원래 단위(시간·횟수)로 풀고, 근거가 문서로 남은 다른 단가로 바꿔도 판정이 유지되는지 확인했다.

## 결론 먼저

- **학습 정책이 최단 작업 규칙보다 못하다는 판정은 단가 탓이 아니다.** 최신 학습은 비용 +20.21%·체류 +16.99%이고, 문서 근거가 있는 다른 단가 7가지로 바꿔도(+17.04~+23.24%), 다섯 단가를 각각 0~10배로 움직여도 뒤집히지 않았다. 비용 차이 중 +16.08%p가 트럭 대기(블록 앞 줄서기), +3.80%p가 본선 유휴다.
- **학습 전보다 나아졌다는 판정도 유지된다.** 최신 방식 -4.20%(9쌍 중 6쌍), 비용 차이 학습 -10.16%(8쌍). 네 방식 모두 어떤 대안에서도 평균은 개선이다. 단 비교 표본 확대 방식은 본선 단가를 옛 값으로 바꾸면 개선 쌍이 5쌍→4쌍이 된다.
- **판정이 바뀌는 비교는 9쌍이 4~5쌍으로 갈려 있던 것뿐이다.** 44개 비교 중 6개이고, 평균의 방향까지 바뀐 것은 최신 학습 vs 단방향(기준 +0.17%) 1개다. 나머지는 개선 쌍 수가 4↔5로 한 쌍 바뀐 경우다.
- **숫자는 이 시뮬레이터 안의 값이다.** 수치 33개 중 법정 근거 1개(트럭 단가, 2차 확인)·시장·문헌 6개·실측 표본 1개·설계값 22개·미확정 2개다. 현실 운영 비용으로 읽을 수 없다.
- **새로 찾은 문제:** ① 학습 정책의 ‘배 여유’ 입력이 한가한 날 100.0%, 붐비는 날 84.5% 상한에 걸려 배의 급함을 거의 못 본다 ② 본선 비용에 운반 장비 설정이 만든 바닥이 크다 ③ ‘크레인 빈 이동’ 비용 정의가 문서와 다르다 ④ 모든 배가 평가창 안에 일을 못 끝내 출항 지연을 비교할 수 없다.

## ② 해석 — 네 가지를 나눠 판정

1. **학습 전후 개선**: 이 시뮬레이터 안에서 관측된 개선은 단가 선택과 무관하게 유지된다. 다만 이미 본 3일·
   초기값 3개의 9쌍이라 독립 9일이 아니며, 수렴이나 확증의 증거가 아니다.
2. **규칙 대비 우열**: 최단 작업 규칙에 못 미친다는 판정은 단가와 평가창 검열을 따져도 유지된다. 검열은 오히려
   학습 정책에 유리하게 작용한다. 도착순보다 낫다는 판정도 유지된다. 최근접·단방향과는 박빙이다.
   같은 작업시간 정보를 받으면서도 짧은 일 먼저 고르기로는 조금만 움직였다(한가한 날 일치율 26.4%→34.7%, 최단 작업 84.9%).
3. **운영 채택**: 미통과 그대로다. 이번 감사는 투입·미완료·본선 보호 조건을 다시 판정하지 않았고 새 채택 근거도 없다.
4. **현실 타당성**: 미확보다. 트럭 단가만 법정 근거가 있고, 본선 단가는 용선료 대리값, 빈 이동·재조작은
   근거 없는 설계값이다. 작업시간은 오차 없이 계획대로 끝나고(규칙이 시간을 정확히 안다), 본선 유휴는 운반 장비
   설정의 바닥에 크게 좌우되며, 배의 완료가 평가창 밖이다. 현장 비용·성능을 주장할 근거가 아니다.
