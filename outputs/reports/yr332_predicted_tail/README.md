# 30분 실제 + 예측값 학습: 2단계 흔들림 측정 (bn)

합성 환경 진단이다. 예측부 입력을 넓힌 시작 모델로 학습 월을 4번 굴려 새 학습 신호의 흔들림을 쟀다. 가중치 갱신은 없다.

**판정(실행 전 기준): 재학습하지 않고 닫는다.** 시간대 비율은 0.9%로 통과했지만, 흔들림이 결정당 145,758 가중 분이라 선택 하나의 효과(24.75)의 5,890배다. 신호가 보이려면 갱신 한 번에 결정 34,690,304개가 필요한데 한 물결에 모은 결정은 970,632개다.

## 측정

- 학습 월 4번 모두 트럭 241,000건·본선 101척을 끝냈다(각 85~86분).
- 월 0·1의 결정 32,768개로 예측부를 '월말까지 실제 남은 블록 시간'에 맞추고, 월 2·3의 결정 32,768개에서 쟀다.
- 새 신호의 흔들림 145,758, 월말까지 실제 값을 쓴 경우 962,805 가중 분. 예측값으로 이어 약 6.6분의 1로 줄었다.
- 시간대 비율 0.94%(우연 기대값 0.39%). bl의 시각 쏠림(79~83%)은 사라졌다.

## 왜 흔들리나 (결과를 본 뒤 추가 진단, 판정 불변)

- 한 달 실현 기록 안에서 새 신호는 정확히 '30분 뒤 결정에서의 예측 오차 − 지금 결정에서의 예측 오차'다(검산 차이 9.3e-10).
- 예측부가 맞히는 값은 월말까지 남은 블록 시간이라 오차가 결정당 약 962,983 가중 분이다. 두 시점의 오차는 98.9% 같이 움직이지만, 남는 차이가 결정당 145,758 가중 분이다.
- 실제로 센 30분 부분은 평균 5,893, 표준편차 3,755로 작다. 흔들림의 중앙값도 60,522 가중 분이라 몇몇 극단값 탓이 아니다.
- 결정한 블록(21개 중 하나)을 예측부에 알려 주면 월말 예측 오차는 980,763 → 290,097로 줄지만, 새 신호의 흔들림은 157,398 → 108,761에 그친다. 필요한 결정은 여전히 약 19백만 개다.

## 한계

- 예측부는 시작 모델의 표현 위에 머리만 맞췄다. 학습이 진행되며 달라질 수 있지만, 첫 갱신부터 신호가 흔들림에 묻힌다.
- 학습 월 하나, 모델 하나의 기록이다. 이 달은 시험 월보다 훨씬 붐빈다.
