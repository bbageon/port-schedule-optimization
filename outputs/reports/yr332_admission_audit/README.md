24시간 미완료 노출과 26시간까지의 추가 대기를 분리했다. 관측창 이후의 최종 체류는 여전히 미확정이다.
이번 감사는 단일 날짜의 과부하가 정상인지, 본선 용량·시간 값이 현실적인지 승인하지 않는다.
