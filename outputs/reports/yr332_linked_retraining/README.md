# 보정 환경 재학습 진단 (YR-332-aq, 사용자 요청)

## 결론

같은 학습 방법으로 보정된 환경(실제 작업 비율·시간대, 방문 몰림, 여러 컨테이너 방문 연결)에서 다시 학습했다.
재학습 모델의 트럭 시간은 **학습 전보다 +4.17% 감소**에 그쳤다. 모델 3개의 결과가 −21.42%~+21.12%로 크게 엇갈렸다.
짧은 실작업 우선 규칙(SF_SPT)보다는 **−27.07%**(27% 더 김), 이전 모델(ag 학습 후)보다도 **−8.29%**(8% 더 김)다.
감소율은 (기준 − 재학습)÷기준이며 양수가 짧아진 것이다. 보정 환경에서 다시 학습해도 나아지지 않았다.

## 학습은 지금 이렇게 한다

- **무엇을 배우나**: 크레인이 "다음에 어떤 작업을 할지" 고르는 점수다. 작은 신경망(입력 10칸, 중간층 64칸)이
  실행 가능한 작업마다 점수를 매기고, 기존 배정 규칙(해결기)이 그 점수로 작업을 정한다. 재배정·게이트 운영은 학습하지 않는다.
- **망이 보는 10칸**: 본선 작업인가, 실제 작업인가, 그 트럭이 기다린 시간, 배 마감 여유, 크레인 이동 시간, 작업 시간,
  위 박스 파내기 시간, 그 크레인이 고를 수 있는 작업 수, 블록에 줄 선 트럭 수, 쌓는(반입·양하) 작업인가.
- **정답 만드는 법(반사실 교사)**: 하루를 시뮬레이션하다가 크레인이 고르는 순간 24번을 골라 세계를 둘로 복제한다.
  한쪽은 실제로 고른 작업, 다른 쪽은 실행 가능한 차점자 작업을 하고 3시간 앞까지 굴린다.
  두 세계의 비용(트럭 진입→작업 완료 시간 비용 + 크레인 추가 이동 + 파내기 + 본선 지연) 차이가 정답이다.
  차점자가 실제 배정 규칙으로 선택될 수 없는 순간은 버린다. 그래서 회차당 8~19쌍만 남는다.
- **갱신**: 두 작업의 점수 차이가 실제 비용 차이를 따르도록 50번 갱신한다(쌍 비교 손실).
- **회차**: 3,500 → 7,500 → 15,000건 하루를 두 번, 6회. 질문을 만드는 행동 정책은 학습 전 정책으로 고정한다.
  모델 3개(초기값 3개)를 따로 학습하고 6회차 가중치만 평가한다.
- **PPO 같은 일반 강화학습이 아니다**: 보상을 쌓아 정책을 밀어 올리는 방식이 아니라, 시뮬레이터로 두 선택을 직접
  비교해 만든 정답으로 한 걸음 개선하는 방식(시뮬레이션 비교 기반 지도학습)이다.
- **규모**: 하루 크레인 결정 약 5,600~14,300번 중 24번만 질문한다. 모델당 학습 쌍은 6회 합쳐 86~105쌍, 세 모델 283쌍이다.

- 평가: 새 합성 입력 9개(물량별 3개) × 정책 16개 = 144회 + 반복 2회. 평가 입력은 학습에 쓰지 않았다.

## 해석

- **환경을 실제에 가깝게 고쳐도 같은 학습 방법은 규칙을 따라잡지 못했다.** 규칙과의 격차는 오히려 커졌다.
- **학습 결과가 초기값에 크게 좌우된다.** 한 모델은 학습 전보다 21% 나빠졌고 다른 모델은 21% 좋아졌다.
  회차당 8~19쌍, 검증 1~3쌍으로 6번만 갱신하므로 신호가 작고 흔들린다. 평균 4.17%는 안정된 개선으로 읽지 않는다.
- **이전 모델이 재학습 모델보다 나았다.** 학습 입력을 실제에 가깝게 바꾸는 것만으로는 도움이 되지 않았다는 뜻이다.
  두 모델 모두 같은 소량 학습이라, 차이는 학습 입력보다 학습의 불안정성으로 설명하는 편이 자연스럽다(원인 확정은 아님).
- **반입은 줄었지만 반출은 줄지 않았다.** 재학습 모델은 학습 전보다 반입을 16.77% 줄였지만 반출은 −0.32%로 그대로다.
  ag 때의 "반입 개선·반출 정체" 양상이 반복됐다.
- 다음 단계는 새 가설이 아니라 학습 진단이다. 자료가 부족한지(질문 수), 주어진 자료도 못 맞추는지(갱신·초기값),
  학습 전 정책으로만 질문을 만든 탓인지를 나눠 보는 YR-323-d가 이 결과를 직접 겨냥한다.

## 검증

- 저장 라벨로 가중치 18개를 다시 학습해 비트 단위로 같았다. 학습 쌍 283개 모두 사실 분기 불일치 0.
- 트럭 1,263,000행·전체 작업 1,908,164행을 시각에서 다시 계산했다. 방문 208,606개의 정차 도착 430,658건,
  끝난 방문 175,294개의 단일 출차를 확인했고 늦은 도착·출차는 0건이다. 반복 2회 비트 일치.
- 실행 코드 `3f1caa0b`, 동결 `720e43c0`(첫 동결 `071b1ce6`은 al 기록 결함 수정으로 1회차 뒤 폐기). 시험 188건.

## 한계

- 사용자 지시 진단이다. 하네스는 현실성 미통과로 새 학습을 허용하지 않았고, 거절 기록을 남겼다. 성능 확증·채택이 아니다.
- 운반 3대·470초 가정(i), 대기 수가 오더 기준(f), 날짜 간 변동 없음(ao), 7,500·15,000건 몰림의 근거 부족(ap)이 남는다.
- 평가 입력은 새 합성 시드이며 실자료 독립 기간이 아니다. 물량별 입력 3개·모델 3개로 표본이 작다.
- ag 결과(학습 전 132.961→학습 후 117.471분)는 보정 전 환경의 값이라 이번 수치와 한 곡선으로 잇지 않는다.
