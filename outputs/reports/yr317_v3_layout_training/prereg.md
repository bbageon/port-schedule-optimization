# 구조별 7일 학습·같은 시드 평가 — 실행 전 고정

2026-09-20 사용자 지시: "7일로 진행해서 동일한 시드 데이터로 수직 학습 따로 수평 학습 따로 해서
동일한 테스트 데이터로 수평 테스트, 수직 테스트 진행". 담당: [YR-317-h2](../../../.claude/docs/dashboard-task-specs/YR-317-h2-v3-layout-specific-training.md).

## 목적과 허용 주장

- 기존 공유형(수평)과 수직 끝단형 각각에서 **같은 코드·같은 예산으로 별도 가중치**를 학습하고,
  각 모델을 **자기 환경**에서 같은 평가 시드로 기준정책(재배정 없음)과 비교한다.
- 답하려는 질문: "그 구조 안에서 배운 시간정책이 그 구조에서 이득을 내는가". 수평 모델을 수직에
  옮긴 [YR-317-h](../yr317_v3_vertical_transfer/prereg.md)의 전이 진단과 구분한다.
- 학습 시드 하나·평가 시드 하나의 서술 사례다. 독립 반복 확증·유의성 검정·배치 방향의 인과효과·
  현장 성능은 주장하지 않는다. 두 환경의 원비용 차이를 방향 효과로 읽지 않는다.

## 고정 설계

| 항목 | 값 | 이유 |
|---|---|---|
| 학습 정책 | 시간만 조정(`RL_TIME`) | 수직 경로가 시간 행동만 지원하고, 독립 반복에서 살아남은 정책이 시간정책이다 |
| 학습 시드 | **9,950,000** (진단 대역, 7일) | 측정 5일이 한가(3,500)·보통(5,000)·혼잡(12,500)을 모두 포함. 이전 학습 시드·일 시드(9,900,700 계열)와 겹치지 않음 |
| 평가 시드 | **30,300,000** (새 대역, 7일) | 규칙: 30,000,000부터 100,000씩 올리며 측정 5일이 한가·보통·혼잡 세 묶음을 모두 포함하는 **첫** 시드. 결과를 보고 고르지 않았다 |
| 일수 | 7일 (측정 2~6일차 5일, 1·7일차는 연결용) + 기존 2시간 잔여 처리 | 사용자 지시 7일. 학습은 라벨 있는 모든 날에 한다 |
| 망 초기값 시드 | 9,950,001 (두 환경 동일) | 두 모델이 같은 가중치에서 출발 |
| 라벨 예산 | 하루 64건, 반사실 창 3시간, ε 0.50→0.05 (7일 선형) | 기존 v3 학습 예산 유지 |
| 요청·공급 계약 | 요청 보존(PRESERVE) + 공급 보정(COUNT_BALANCED), 두 환경·학습·평가 모두 | 수직 경로 요구 조건이며, 환경 하나만 바꾸기 위해 수평도 같은 계약 |
| 체크포인트 | **마지막 날(7일차) 체크포인트만** 평가 | 평가 결과로 회차를 고르지 않는다 |
| 평가 | 환경별 기준정책 vs 그 환경 모델, 가중치 고정·탐색 0·반사실 분기 0 | 기존 독립 평가 기록 검사 그대로 |
| 비용 | 트럭 대기·크레인 이동·재조작·본선 네 항, 요청일 귀속, 측정 5일 주분석·7일 보조 | 기존과 동일. 새 정원·변경 비용 없음 |
| 관측 | 300초 운영 상태·요청 장부·컨테이너 연결·일별 관측 저장 | 미완료·미결·본선 잔여를 비용과 함께 공개 |

## 코드 변경 범위

- 수직 환경 경로의 "고정 모델 평가만 허용" 가드에 **명시적 옵트인**(`layout_training=True`)을 추가한다.
  옵트인 없이는 이전과 같이 학습을 거절하고, 옵트인은 시간정책·요청 보존·공급 보정에서만 허용한다.
- 학습 루프와 진입점에 후보 폭·공급 계약·환경 명세 인자를 추가한다. 기본값은 기존과 같다.
- 기존 30일 고정 평가·수직 전이 실행기·진행 중 실험의 코드·입력·가중치는 바꾸지 않는다.

## 연결 검사와 본 실행

- 본 실행 전 별도 시드(학습 9,949,000 · 평가 99,194,002)의 3일·60대 입력으로 두 환경의
  학습→평가 전체 경로를 병렬로 검사한다. 라벨·망 갱신·기록·연결·지문 검사가 통과해야 본 실행을 시작한다.
- 학습 표본 0인 측정일·요청 누락·이중 반출·물리 제약·비용 장부·입력 불일치는 오류로 남기고 중단한다.
  작업 잔여·마감 초과는 결과로 저장하며 시드를 바꾸지 않는다.
- 한 환경이 실패해도 다른 환경의 결과는 끝까지 보존한다. 자동 재시작·시드 교체·체크포인트 선택은 없다.

## 자원

- 학습: 환경당 CPU 8개(본 프로세스 1 + 분기 작업자 7), 두 환경 병렬. 평가: 실행당 CPU 1개, 4개 병렬.
- 기존 실험(독립 반복 잔여 3건·v5)을 중지하지 않고, 총 사용을 사용자 허용 20코어 안에서 관리한다.
- 예상 소요는 사전에 못 박지 않는다(수직형은 고정 평가만으로도 하루 21분, 학습은 분기 세계가 얹힌다).

## 보고

- 환경별로 기준정책 vs 자기 모델의 측정 5일 비용·네 항·시간 변경 건수·미완료·미결·본선 잔여·턴타임·
  학습 라벨 수·갱신 횟수를 함께 보고한다. 비용이 줄어도 처리량 악화가 있으면 운영 개선으로 자동 채택하지 않는다.
- 실제 소스·설정·입력·체크포인트 지문과 시작·완료·실패를 기록한다.
