# YR-306 — 현재 코드의 세 정책 참고 비교

## ① 진행사항

- 2026-09-14 사용자 예외 승인을 [기록](authorization.json)했다.
- [사전등록](../../../.claude/docs/dashboard-task-specs/YR-306-reference-comparison.md):
  같은 30일 명단에서 final/initial/KEEP+SF-SPT, 최고점 선택, 학습 0회.
- 새 실행기만 추가한다. 정책·환경·비용식·대기 동작과 원 실행 파일은 바꾸지 않는다.
- 비용 차이 부호·잘못된 비교 차단·규칙 연결·모델 불변·대기열 검사와 기존 종료창 검사로 실행기를 검증한다.
- CPU 1개 순차 실행. 다른 v4 작업이 끝난 뒤 단기 검사→30일 비교 순으로 자동 진행할 예정이다.

## ② 해석

- 아직 비교 결과가 없다. 기존 학습 비용은 절감액으로 쓰지 않는다.
- 사용자 승인은 진행 순서의 예외이지, 기존 신뢰성·현실성·성능 검사를 통과했다는 뜻이 아니다.
- 같은 학습 명단 재사용·한 달·현재 WAIT 및 비용 한계가 있는 참고 비교다.

## ③ 예정사항

- 같은 YR-306: 실행기 검사 → 깨끗한 코드 고정 → 대기열 등록 → 단기 동일성 검사 → 세 팔 비교.
- 원 실행과 비교 결과는 `outputs/v5/`의 서로 다른 폴더에 보존한다.
