# YR-317-g 요청 보존 계약 — 실행 전 고정

2026-09-16. 사용자 후속 진행·필요시 학습·CPU 20개 승인. 기존 합성곡선 유지.

## 무엇을 확인하는가

기존 10일 진단에서 트럭 미투입 170/180/136건과 선박 요청 축소가 관찰됐다.
통지 시점의 재고·예약 여유 부족이 요청 소실로 이어지는 경로를 직접 보정한다.
정책 성능 확증이나 재학습 결과로 해석하지 않는다.

## 수정 계약

- `admission_mode=PRESERVE`를 별도 명시한다. 기존 `LEGACY` 실행도 재현 가능하게 둔다.
- 원래 트럭 명단·도착곡선·날짜별 물량·흐름·블록·리드타임·본선 계획은 그대로다.
- 통지 시점에 반출 대상이 없으면 요청을 접수하고, 실제 블록 도착 이후 가용 재고가 생길 때 대상을 지정한다.
- 반입 요청을 미래 예약의 합계만으로 삭제하지 않는다. 트럭은 원래 도착시각으로 들어와 기다리며 기존 게이트 진입 이후 비용에 잡힌다.
- 물리 적재·재조작 공간·장비 간격·작업 소유권 검사는 그대로다. 요청 접수가 실제 적재 허가를 뜻하지 않는다.
- 선박 적하는 최초 요청 수를 그대로 등록한다. 아직 해제되지 않은 적하 작업이 하루 시작에 재고 전체를 선점하지 않도록 실제 해제시각 이후 대상을 지정한다.
- 이미 지정된 대상은 빼앗지 않는다. 미지정 작업은 해제시각·작업 ID 순서, 실제 가용 재고 중 고정 난수로 선택한다. 미래 재고나 접근하기 쉬운 상자를 선택하지 않는다.
- 미완료 트럭은 원래 진입시각부터 종료까지 비용을 유지하고, 미완료 본선 작업은 잔여로 남긴다. 오류·기말 잔여를 삭제하거나 완료로 바꾸지 않는다.
- 대기 공간의 실측 정원이나 외부 일정 변경 비용은 새로 도입하지 않는다. 무한 대기 공간을 가진 기존 합성 모형 범위이며 현장 실행 가능성 주장은 하지 않는다.
- 학습용 짧은 분기에서도 동일 계약을 사용한다. 분기 관찰 종료 뒤 도착하는 통지 요청은 등록 상태로 남고 관찰창 안의 비용만 센다.
- 미지정 대상 연결은 마지막 날 이후 기존 2시간 배수 구간에도 같은 60초 격자로 계속한다. 원래 도착 명단이나 배수 길이는 바꾸지 않는다.

## 실행 순서와 고정 조건

1. 코드 검사: 재고 선점, 예약 여유 부족, 본선 요청 축소, 분기 복사, 관찰창 절단, 시간 오류, 중복 대상 지정 사례.
2. 실제 연결 검사: 시드 9,900,700·하루 300대, 세 정책 각 1회. 요청·본선 전건 완료 및 기록 대조가 통과해야 다음 실행을 한다.
3. 알려진 실패 재검증: 시드 9,500,000 원래 30일의 앞 10일, 정책별 연속 실행 각 1회. 트럭 69,000건, 본선 요청 44,322건은 기존과 같아야 한다.
4. 정책: 변경 없음 `NO_REALLOC`, 전체 `RL`, 거절 기능 제거 `RL_NOVETO`. 마지막 정책에도 구매 점수 정렬은 남아 있으므로 수락망 완전 제거라 부르지 않는다.
5. 가중치: `outputs/v3/month-02/ckpt_029.pt`를 고정한다. 행동·가중치·비용식을 동시에 바꾸지 않는다.
6. 기본 자원: 정책 3개를 CPU 0/1/2에서 병렬 실행. 한 정책의 날짜는 분리하지 않는다. 사용자 상한 20개, v5 CPU 23 유지. 많은 코어가 필요한 학습은 별도 예산으로 연결한다.
7. 깨끗한 별도 실행 소스와 commit·설정·가중치 지문, 날짜별 진행, 요청별 사건, 본선 장부, 늦은 대상 지정 내역을 저장한다.

## 통과·보류 기준

- 요청 보존: 정책 간 원래 요청 지문 일치, 트럭 미투입·미처리 0, 본선 미투입 0, 요청=완료+미완료.
- 물리·장부: 기존 물리 검사 켜짐, 작업 이중 소유 0, 비용 원자료 대조, 예외 0, 평가 중 교사 호출 0.
- 전체 물리 완주·잔여 0 여부는 위 접수 검사와 별도로 판단한다. 접수만 통과했다고 현실성 전체 통과라 하지 않는다.
- 실제 도착·물량을 바꿔 가드를 맞추거나 특정 시드를 제거하지 않는다. 실패 시 그대로 기록하고 같은 원인을 직접 보정한다.
- 기존 10일 결과와의 비용 차이는 환경 계약 변화의 진단이다. 독립 반복의 통계 검정·학습 성공 주장은 금지한다.
- 재학습이 필요하면 YR-317-d에서 보정 환경에 맞춘 학습/평가 계약을 실행 전에 고정한다. 현재 실행기는 자동 학습하지 않는다.

## 코드 검사 기록

- 기존 월·관측 검사 39개 통과. 첫 추가 검사에서는 시험용 요청의 필수 주행 필드가 빠져 3개 실패했고, 시험 입력을 완성한 뒤 새 검사 7개 모두 통과했다.
