# 판정 파일의 원격 바이트 확인

2026-11-18 최종 push 후 로컬·원격 파일 해시를 대조했다.
첫 판정 발행 `f23f082c`에서 공통 저장 함수는 Windows 줄바꿈(CRLF)을 쓰고 git은 LF로 저장했다.
JSON 값과 판정은 같았으나, 로컬 파일로 계산한 체크섬이 원격 파일의 바이트와 달랐다.
해당 커밋은 이력에 보존하고, 이번 발행기에서 처음부터 LF로 저장·해시하도록 고쳤다.

코드 변경을 먼저 commit·push한 뒤 같은 판정을 다시 발행한다.
재검증 대상은 `current-gates.json`과 `dashboard-audit.json`의 로컬 파일·git blob·체크섬 일치다.
표본·보정값·입력 검사·성능 해석에는 변경이 없다.
