# 남은 비용 예측의 학습 안정화 비교

**총비용과 트럭 시간은 줄었지만 사전 보호 조건을 모두 만족하지 못했다.**
기존 학습 대비 트럭 시간 -8.74%, 총비용 -7.55%다. 짧은 실작업 우선 규칙 대비 트럭 시간은 +28.07%다.
음수 학습 신호는 유지했다. 새로 학습한 여섯 모델을 같은 입력에서 비교한 결과다.

## ① 진행사항

- 같은 초기값 3쌍, 모델당 새 합성 12일·6갱신·12,288개 선택 경험·768최적화 단계.
- 기존 방식과 PopArt(비용 예측의 학습 눈금을 바꾸되 원래 단위 예측을 보존)를 비교했다.
- 새로 생성한 19곡선을 학습12·동작시험1·검증3·최종시험3으로 분리했다.
- 최종시험은 3곡선×3물량의 9입력이다. 검증·시험 본 평가126회와 결정적 재실행2회를 했다.
- 총비용·24시간 보상·26시간 실행·정책 입력·학습량·행동 학습 식을 그대로 유지했다.

| 최종 시험 | 평균 트럭 작업시간(분) | 총비용 변화: 기존 대비 | 26시간 후 미완료 오더: 회당 |
|---|---:|---:|---:|
| 기존 가치 학습 | 87.178 | +0.00% | 4151.56 |
| 가치 목표 정규화 | 79.562 | -7.55% | 4093.00 |
| 짧은 실작업 우선 규칙 | 62.125 | -30.72% | 2715.33 |

변화의 **−는 감소, +는 증가**다. 트럭 시간은 오더당 게이트 진입→작업완료이며 출차까지가 아니다.
미완료 건도 24시간 종료까지 관측한 경과시간을 평균에 포함한다. 최종 완료시간을 모두 관측한 평균은 아니다.
사전등록대로 입력 날짜와 모델에 같은 무게를 줬다. 과거 물량 가중 평균과 직접 비교하지 않는다.
오더 수로 가중한 보조 평균은 기존 124.636분, 정규화 114.542분, 규칙 87.876분이다.

본선 지연 비용 변화는 +0.74%, 전체 미완료는 회당 -58.56건이다.

### 비용 예측 자체는 나아졌나

| 하루 오더 | 기존 예측 오차 | 정규화 예측 오차 |
|---:|---:|---:|
| 3,500 | 1.6995 | 2.2341 |
| 7,500 | 1.8075 | 2.0410 |
| 15,000 | 3.9629 | 3.9357 |

오차는 새 검증 경험에서 실제 남은 비용과 예측의 차이를 제곱평균한 뒤 제곱근을 취한 값이다.
양쪽 모두 원래 고정 보상 눈금으로 복원해서 잰다. 각 정책이 확률 추첨으로 만든 경험이므로 방문 상태는 다를 수 있다.
학습에 사용한 경험의 오차와 새 검증 오차는 분리했다. 정규화된 학습 손실 숫자를 서로 직접 비교하지 않는다.

- 기존 가치 학습: 학습자료 예측 오차 3.6318→1.4802; 고물량 오전 양수 행동 신호 0/5,537; 첫 묶음의 가치/행동 기울기 크기 비율 중앙값 85.59배.
- 가치 목표 정규화: 학습자료 예측 오차 3.6381→1.4803; 고물량 오전 양수 행동 신호 0/5,291; 첫 묶음의 가치/행동 기울기 크기 비율 중앙값 23.54배.

기울기 비율은 갱신 첫 묶음만 측정했다. Adam을 거친 실제 파라미터 이동량이나 전체 학습의 원인 비율이 아니다.

| 9951101 | 9,264 | 6.802% | 48.88% |

|---:|---:|---:|---:|
| 9951101 | 4,764 | 58.11%→65.06% | 82.28%→100.00% |
| 9951102 | 4,745 | 54.71%→60.13% | 2.23%→82.72% |
| 9951103 | 4,782 | 55.94%→59.68% | 51.55%→89.67% |

양쪽 정책에서 저장한 검증 상태를 합쳐 같은 합법 후보에 두 모델을 적용했다.
표는 크레인 하나가 고르는 상황만 따로 센다. 여러 크레인에 대한 선택 순서 변화와 실작업 우선순위 변화를 섞지 않기 위해서다.
확률 분포 차이는 바뀐 확률 질량이다. 작은 확률 차이라도 최고점 후보가 바뀔 수 있다. 이 표는 선택 결과의 인과 효과를 재현한 실험이 아니다.

## ② 해석

- 총비용과 트럭 시간은 줄었지만 사전 보호 조건을 모두 만족하지 못했다.
- 미충족 보호 조건: 본선 지연비용 비악화. 총비용 감소와 본선 보호 조건의 충족은 구별한다.
- 작업별 변화는 반입 -45.30%, 반출 +1.98%다. 같은 상태의 선택에서도 반입 우선이 강해졌다. 개별 결정의 인과 효과까지 분리한 결과는 아니다.
- 새 비용 예측 오차가 커진 물량: 3,500건, 7,500건. 예측 정확도와 정책 성능의 개선을 같은 뜻으로 읽지 않는다.
- 보상을 ‘−비용’으로 두는 것은 비용 최소화를 보상 최대화로 표현하는 방법이다. 비용이 발생했다는 사실과 특정 선택이 상대적으로 나빴다는 평가는 구별한다.
- 행동 신호의 음수는 “예상보다 나빴으니 선택 확률을 낮추라”는 뜻이다. 예를 들어 예측 비용10·실제8이면 상대 신호+2, 실제12이면−2다.
- 현재 구현은 이 상대 신호를 두 날짜 전체에서 한 번 더 표준화한다. 고물량 날짜의 음수 편중만으로 잘못된 행동이라고 단정할 수 없다.
- 이번 비교에서는 음수 신호를 삭제하지 않았다. 삭제 실험을 하지 않았으므로 음수 제거의 효과를 입증한 것도 아니다.
- 음수값 자체가 모든 강화학습의 필수 조건이라는 뜻은 아니다. 현재 PPO에서 음수 상대 신호를 0으로 지우면 학습식이 달라지므로 별도 비교가 필요하다.
- 학습은 확률 추첨, 주 평가는 최고점 선택이다. 그 차이를 유지한 비교이며 두 실행 방식이 같다고 주장하지 않는다.
- 모든 학습 쌍은 새로 시작했다. 기존 체크포인트에서 완전하게 이어 학습한 결과가 아니다.
- 학습 날짜12개는 매번 환경을 새로 만드는 하루 사례다. 12일 연속 운영이 아니다.
- 정규화의 Adam 누적값은 보존했다. 출력 보존은 검사했지만 최적화 궤적의 좌표 불변성은 주장하지 않는다.
- 이번 판정은 누적 전역 통계를 쓴 PopArt와 고정된 학습 예산에 한정한다. 모든 정규화 방법이나 충분히 오래 학습한 경우의 성능을 판정한 것은 아니다.
- 사전 지정 채택 수치 조건: 미충족. 작은 합성 진단이므로 수치 조건 충족도 현장 개선 확증은 아니다. 기록·코드·검산은 별도 확인하며 현실성은 미통과를 유지한다.
- 동일한 합성 생성기의 새 추첨이다. 독립 실측 기간·운반 흐름·현장 대기열을 검증한 결과가 아니다. 기본 정책은 바꾸지 않았다.

## ③ 예정사항

- 운반 흐름 확인(YR-332-i): 차량 투입·주행·인계 기록으로 양하 연결을 검증한다. 실제 환경의 성능을 말하기 전에 필요한 외부 자료가 남아 있다.
- 대기열 정의 확인(YR-332-f): 현장의 줄과 모델의 대기 상태가 같은 뜻인지 확인한다. 자료가 도착하면 현실성 게이트를 다시 판정한다.
