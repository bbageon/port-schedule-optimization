  `ckpt_000.pt`는 기존처럼 첫날 종료 시점이며 학습 전으로 읽지 않는다.

- YR-296 spec 상태를 기존 완료 row와 맞췄고, 실행 완료와 독립 확증을 구분하는 해석 정정을 덧붙였다.
