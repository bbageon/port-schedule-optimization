# 교사 선택 계약 수정·동일 구조 재학습 결과

초기값 3개×교사 2종×6회 갱신. 독립 입력 9개, 평가 208회.
주문 장부 1,809,000건 대조·저장 가중치 36개 재학습 재현·회귀 165건 통과.

학습 후 평균 체류시간은 학습 전보다 짧아졌지만, 수정 교사는 기존 교사와 주 비교 규칙보다 평균 성적이 나빴다.
초기값에 따른 악화도 관측됐으며, 미완료·본선 보호 조건을 통과하지 못했다. 이번 수정의 성능 우위와 정책 채택은 성립하지 않는다.

## 해석 범위

현재 표의 차이는 고정 합성 환경에서 교사 계약을 바꾼 효과다. 입력·신경망 구조·비용식은 같다.
모든 자료는 같은 초기 행동 정책에서 수집했다. 학습 후 정책으로 다시 수집하는 온라인 반복 실험은 아니다.
단일 공유 입력 점수 개입의 선택 증거이며, 가능한 모든 신경망 순서를 전수 탐색한 결과가 아니다.
선택기의 운영 제약을 통과했다는 증거이며, 현재 신경망이 모든 목표 점수를 동시에 표현할 수 있다는 증명은 아니다.
운반차 3대/470초, 예약 정확성, 적하 시간 추정은 실측 확정되지 않았다.
교사 비용은 환경 종료까지 최대 3시간이다. 환경 밖 비용을 계산하던 첫 실행은 중단·보존하고 두 군을 새로 학습했다.
6회 최종 가중치를 미리 정했고 시험 성적에 따라 좋은 중간 가중치를 선택하지 않았다.
초기 시험 2건의 실패는 모든 작업 입력이 같은 시험 자료 때문이었다. 대기시간이 다른 작업으로 시험을 고쳤다.
