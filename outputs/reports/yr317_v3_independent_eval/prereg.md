# YR-317-d — 독립 20개월·고정 모델 비교

2026-09-16 사용자 지시: 공급·요청 검증 종료 뒤 기존 모델로 20개 독립 환경의 기준·전체·시간만 비교까지 진행한다.
이 문서는 독립 성능 결과를 보기 전에 고정한다. 이번 묶음에 추가학습·피크 폭 변경·새 비용·예약 정원은 넣지 않는다.

## 실행 계약

- 기존 입력 20개월: 20,000,000부터 100,000 간격으로 21,900,000까지. 교체·추가·성능별 제외 없음.
- 정책: `NO_REALLOC`(재조정 없음), `RL`(전체), `RL_TIME`(시간만). 60개 정책-월을 모두 보존한다.
- 가중치: `outputs/v3/month-02/ckpt_029.pt`, SHA-256 `50f2da2e8b3070dbba48273f0de5debdf5514fe96f0fa1f5a8f25b8a830cba99`.
- 매 실행 별도 프로세스·새 엔진. 한 실행은 30일 연속+기존 2시간 종료 구간이며 날짜마다 초기화하지 않는다.
- 모델 업데이트·탐색·학습용 분기 없음. 평가 전후 가중치와 체크포인트 지문이 같은지 검사한다.
- 원래 합성곡선·하루 물량·트럭 명단·초기 재고를 유지한다. 선박 계획은 g에서 고정한 `COUNT_BALANCED`, 접수는 `PRESERVE`다.
- 원본 입력과 보정 선박 파일 지문을 기록한다. 실제 엔진 초기화 직전 요청·초기 재고·선박 계획 지문을 다시 대조한다.
- 기존 학습 환경과 접수·공급 계약이 달라졌음을 보고한다. 이번 결과는 보정 환경에서 기존 모델을 고정한 평가이며 재학습 효과가 아니다.
- 일별 기록: 물량·시작 잔여·실제/블록별 대기열·야드 작업·평균/상위 10% 경계 턴타임·공간/시간 실행 비율·네 비용 항.
- 300초 상태 표본·확정 일별 파일·요청별 사건·컨테이너 연결·선박 완료 장부를 보존하고 재검산한다.

## 선행 검사와 자동 연결

- 먼저 독립 평가 대역 밖 9,900,722에서 2일×60대, 세 정책의 실행·저장·원자료 검사를 한다. 성능 표본에 포함하지 않는다.
- 기존 g의 세 조건 30일 실행과 감독 프로세스가 모두 끝날 때까지 본 평가를 시작하지 않는다.
- 종료 코드·원자료 사건·요청 전건 접수·선박 전건 접수·동일 입력·컨테이너 이중 반출/미래 공급·물리 재고·보정 수량을 재검산한다.
- 기록·물리 연결·입력 보존 오류가 있으면 실패 자료를 남기고 본 평가를 중단한다. 조용한 재실행·시드 교체 없음.
- 종료 잔여가 기록된 경우 완료 처리와 구분해 저장한다. 작업 잔여·정책 열위 자체로 독립 시드를 버리거나 성능 비교를 숨기지 않는다.
- 이 시작 조건은 기록과 물리 연결 확인이다. 지속운영 가능성·전건 완료·정책 우위·실제 터미널 적용성 통과와 다르다.
- 현재 게이트의 현실성 직접 보정으로 같은 계약의 독립 실행·작업 잔여를 관측한다. 순위 검사·재학습을 새 필수 선행으로 넣지 않는다.

## 통계와 결과

- 독립 표본은 월 하나이며 n=20이다. 일별 비용은 원래 요청일 트럭 항과 달력 날짜의 나머지 항이라는 기존 귀속을 유지한다.
- 주 분석은 기존 논문과 같은 2~29일의 28일 비용. 보조 분석은 전체 30일 비용. 두 값 모두 같은 30일 실행에서 계산한다.
- 주 비교 둘: 기준−전체, 시간만−전체. 양수는 전체의 절감액이다. 시간만 대 기준은 보조 비교다.
- 월 단위 짝 차이의 평균, 월별 절감률 평균, 비용 합계의 비율, 승/패/동률을 모두 보고한다.
- 동일 월 묶음을 20,000회 재표집한다. 통계 난수 9,900,721. 두 주 비교는 각각 97.5% 구간으로 묶음 오류를 보수적으로 조정한다. 보조 비교는 95% 기술 구간이다.
- 결과를 보고 표본을 늘리지 않는다. 60개 자료가 모두 있고 짝의 입력이 같아야 최종 구간을 계산한다.
- 비용표 옆에 완료율·미완료 트럭·선박 잔여·대상 미지정 건수를 둔다. 미완료가 있으면 비용 감소만으로 운영 개선을 확증하지 않는다.
- 부하별·날짜별 자료는 기전 설명용이다. 600일을 독립 표본 600개로 취급하지 않는다.
- Full−Time-only는 같은 모델에서 공간 후보 허용의 추가 효과다. 별도로 최적화한 공간 정책의 우월성이나 학습 시드 반복 안정성을 주장하지 않는다.

## 자원·재현

- CPU 상한 20개(0~19), 기존 다른 작업의 CPU 23은 건드리지 않는다. 한 실행은 CPU 하나와 Torch 한 스레드.
- 동시 실행은 최대 16개이며 시작 시 가용 메모리의 80% / 실행당 3GiB로 더 줄인다. 한 실행 내부 날짜는 병렬로 나누지 않는다.
