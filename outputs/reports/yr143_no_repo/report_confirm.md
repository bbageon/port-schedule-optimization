# YR-143 확증 판정 — C0(위치조정 없음) vs C1(결속 PREPOSITION): 양군 하드 가드 실격 → 미확정 (제거도 유지도 불가)

- 프로토콜: 착수·확증 사전등록 동결(`b6628e2`·`8b95123`) — 공통 R 계약·유일 차이
  PREPOSITION·신규 초기화 8쌍(221000~228000)·신규 44판(910100+·파일럿 지문 제외)·
  Δ=C0−C1·δ(가정) v2 1.0/본선 3.0분/v1 2.0·4분류+민감도·top-up 금지.
- **동결 분류기 출력**: "C0_GUARD_FAIL(C1 유지)" (δ×0.5·×1.5 동일). **단 동결 규칙의
  사각 정직 박제**: 분류기는 C0 실격을 먼저 검사하는데 **C1 도 실격**이다(양군 동시
  실격 케이스가 4분류에 미정의). 따라서 실질 결론은 **"양군 가드 실격 — PREPOSITION
  제거도 유지도 확정 불가(INCONCLUSIVE 계열)"** 이며 "C1 유지" 함의는 채택하지 않는다.

## 이 결과가 갱신하는 것

1. **완주 견고성이 PREPOSITION 논쟁보다 선결이다**: 신규 초기화 8쌍·352판 규모에서는
   R 계약(순위손실 포함)도 양군 모두 미완주를 남긴다 — YR-147 판정(3초기화·96판 전판
   완주)의 관찰이 초기화 표본을 넓히면 유지되지 않음(해당 결론의 적용 범위 축소 정정).
2. 미완주가 특정 초기화·특정 시나리오에 집중 — 학습 초기화 복권(lottery) 성격.
3. **YR-146(배포 안전장치 — 정책 무관 종단 정지 0 보장)의 필요 근거가 실측으로 강화**
   — 정책 학습만으로는 완주 0건 보장이 안 된다는 spec §3(YR-147 결정이력)의 예측 재확인.
