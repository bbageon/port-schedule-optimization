# YR-153 — 연구 진행 3대 게이트 하네스 보고

## ① 진행사항

앞으로 모든 판정 실험에 공통으로 붙일 세 게이트를 구현했다.

- **성능**: 후보−규칙의 반올림 전 신뢰구간, 검정력, 완주·본선 보호 가드를 함께 판정한다.
- **신뢰성**: 실행 commit·시드·설정·파일 hash를 남기고, 완료 후 Dashboard·spec·각 증거 파일이
  실제 원격 commit에 들어 있는지 다시 대조한다.
- **현실성**: 물리·정보누출·장부와 지속 유입 흐름, 실제자료 등급을 분리한다.
- **진행 통제**: 미통과가 있으면 관련 보정만, 전부 통과하면 목표 확증만 허용한다.

코드 감사에서 기존 공용 평가기가 표시용 3자리 신뢰구간으로 판정하던 결함도 찾아 원정밀도로
수정했다. YR-149의 row·spec·코드 경로·원격 commit은 일치했지만, 실행 원자료에
`git_dirty=true`, 전체 설정 `{}`, 사전등록 파일 경로 누락이 남아 있어 **신뢰성 전체는 실패**로 판정했다.

## ② 해석

현재 세 항목의 답은 다음과 같다.

| 질문 | 현재 판정 | 쉬운 뜻 |
|---|---|---|
| 성능이 증가했나 | **미확정** | 사전 이동을 빼는 개선은 확인했지만, 최종 정책 전체가 지속 운영에서 SF-SPT보다 싼지는 아직 안 재봄 |
| Dashboard와 코드가 맞나 | **실패** | 완료 기록의 경로·commit은 맞지만 실행 시점 코드가 dirty였고 전체 설정이 빠짐 |
| 시드가 실제 가능한가 | **미확정** | 유한 물량 시드는 내부적으로 가능하지만, 계속 들어오는 정상 운영과 실제 운영자료 대조가 아직 없음 |

따라서 현재는 성능 개선을 주장할 수 없다. YR-149 숫자는 자격 진단 참고로 보존하되, 다음
판정런은 clean commit·전체 설정·시드·파일 hash를 새로 남겨야 한다. 또한 50·75·100·125·150을 곧바로 실제 항만의
양호·보통·혼잡 등급이라고 부를 수도 없다. 지금 확정된 것은 문헌 보정 시뮬레이션에서 부하
불균형을 만들 수 있다는 것까지다.

## ③ 예정사항

현재 바로 허용되는 작업은 **YR-151 0A 하나뿐**이다. 각 통과 뒤 다음 단계가 차례로 열린다.

1. **YR-151 0A — 기술계약 검사**: 30분 후보, 미래정보 누출, 게이트 진입 전 원자 재배정이 맞는지
   clean commit과 전체 재현 스탬프로 확인한다. 새 정책을 학습하지 않는 저비용 신뢰성 보정이다.
2. **0A가 신뢰성 PASS인 경우에만 YR-150 — 지속 유입 환경 자격시험**: 트럭이 평가창 끝까지 계속 들어오는 환경에서 도착률,
   완료율, 재공량과 backlog 기울기가 실현 상태 분류와 맞는지 확인한다. 시드 현실성 미확정을 닫는다.
3. **YR-150이 현실성 PASS인 경우에만 YR-151 0B — SELL 정책 성능 판정**: 자격을 통과한 같은 환경에서 SF-SPT·계산 기준선·PPO SELL을
   비교한다. 최종 터미널 비용 개선 미확정을 닫는다.

둘이 통과하면 새 가설을 더 만들지 않고 신규 시드 잠금평가로 바로 간다. 실패하면 관측된 실패
기제를 직접 고치는 단일축만 한 번 허용한다.
