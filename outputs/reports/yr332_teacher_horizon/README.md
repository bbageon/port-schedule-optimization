# 교사 환경 종료와 비용 종료 일치

환경이 끝난 뒤의 미진행 시간에 비용을 더 계산하던 경로를 수정했다.
수정 코드 `78fc06ff`. 기존/수정 교사, 단일/병렬과 일반 창을 포함해 실제 실행 5회·비교 11개 검증 통과.

- 비용 종료 = min(결정 시각 + 요청 관측 길이, 원래 환경 종료).
- 환경 종료 전 창은 그대로 두고, 끝이 잘린 창의 실제 길이를 저장한다.
- 짧은 시험의 환경 끝은 9,000초다. 요청 10,800초 창은 두 분기 모두 9,000초까지만 계산했다.
- 일반 1,800초 창은 원래 길이를 유지했다.
- 두 교사 각각 직렬/병렬 결과가 같았고, 5회 주 궤적과 원래 비용도 같았다.
- 시험용 짧은 환경이며 본 학습·평가의 24시간 관측 + 2시간 종료 구간은 바꾸지 않았다.

첫 ab 실행은 8개 수집 자료에서 종료를 넘는 비교 4개를 발견하고 중단했다.
최대 요청 끝 96,826.088초 대비 환경 끝 93,600초였다. 그 부분 모델·라벨은 새 비교에 쓰지 않는다.
두 교사를 공통 보정 환경에서 처음부터 다시 수집하고 학습한다.
운반차·예약 실측 보정은 여전히 미확정이다.
