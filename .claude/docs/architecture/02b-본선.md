야드 크레인은 트럭만 상대하지 않는다 — **본선 작업(양하·선적)이 같은 크레인을
나눠 쓴다.** 그래서 본선 구성이 무대 부하의 절반을 정한다.

```contract
vessel_classes_target = 3
```

## 1. 선급 3종 (사용자 결정 2026-08-20)

단가·요율(2.99원/GT·시간)은 [04](04-비용과-보상.md) §1-2. 여기서는 **무대 구성**만.

```
moves_v ~ TEU_v × U(0.15, 0.30)        시드에서 미리 추출 (재현성)
```

| 급 | GT | TEU | 기항 moves (최소~평균~최대) | 현행 120 대비 |
|---|---|---|---|---|
| 소형 | 50,000 | 3,000 | 450 ~ **675** ~ 900 | ×5.6 |
| 중형 | 100,000 | 7,500 | 1,125 ~ **1,687** ~ 2,250 | ×14.1 |
| 대형 | 150,000 | 14,000 | 2,100 ~ **3,150** ~ 4,200 | **×26.2** |

### 그래서 척수를 크게 줄인다

척당 물량이 최대 26배가 되므로 **현행 12척은 무대가 안 선다.**

| 구성 | 본선 moves(평균) | 트럭 7,500 합산 가동률 |
|---|---|---|
| 소6 / 중4 / 대2 | 17,100 | **122%** ← 불가능 |
| 소3 / 중2 / 대1 | 8,550 | 80% |
| 소2 / 중1 / 대1 | 6,187 | 68% |

하루 YC 능력 = 21블록 × 2대 × (3600÷180초) × 24h = **20,160 moves**.

### 대형선 희소성은 '척수'가 아니라 '출현 확률'

하루 3척 안팎이라 비율로는 희소성을 못 만든다. **오는 날과 안 오는 날**로 나눈다.

```
소형 2척 (항상)  ·  중형 1척 (항상)  ·  대형 1척 (확률 30%)
```

| | 본선 moves | 트럭 7,500 합산 |
|---|---|---|
| 대형 없는 날 (70%) | 약 3,037 | 52% |
| **대형 오는 날 (30%)** | 약 6,188 | **68%** |
| 평균 | 3,982 | 57% |

**학습에도 이쪽이 낫다** — "오늘 대형선이 있다"가 하루의 성격을 바꾸므로 정책이
배울 변동이 생긴다. 매일 똑같으면 배울 게 없다(리드타임과 같은 논리 — [02](02-무대.md) §4).

**본선 구성은 판정 축이 아니라 시드별 변동**이다. 판정 축은 트럭 물량 3수준([02](02-무대.md) §2-1)
뿐이고 본선은 그 안에서 날마다 흔들린다 — 축을 둘로 만들면 셀 수가 곱으로 는다.

**⚠️ 앞선 7,500 실측([02](02-무대.md) §2-1)은 본선 1,440 기준이라 다시 재야 한다** → [[YR-212]]
