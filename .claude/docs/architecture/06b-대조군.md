# 06b — 대조군 (v3 설계 · 무엇과 비교하나)

> **성격**: to-be 설계. 코드가 여기에 맞춰진다. → [index](README.md)
> **판정 규약**은 [06](06-학습과-판정.md) · **결정층 구조**는 [03](03-결정층.md)

**"RL 이 무엇을 이겼나"가 논문의 전부**다. 상대를 잘못 세우면 이겨도 의미가 없고,
져도 원인을 모른다. 축이 **둘**이라 대조군도 둘이다 — **재배치**(학습 대상)와
**배차**(무대의 크레인 정책).

## 1. 재배치 축 — 고전 배차 규칙을 번역해 쓴다 ([[YR-211]])

비교 상대가 `greedy`(`UnifiedNetGain`) 하나였는데 그건 **우리 비용식에서 직접 유도한
자체 휴리스틱**이라 순환적이고 문헌에 이름이 없다.

| 팔 | 누구를 옮기나 | 어디로 |
|---|---|---|
| **No Reallocation** | — (최초 배정 유지) | — |
| **FCFS** | 먼저 통지된 트럭 | Least-Loaded |
| **SPT** | 예상 작업시간 짧은 트럭 | Least-Loaded |
| **EDD / Least Slack** | SLA 여유 최소 트럭 | Least-Loaded |
| **Nearest** | 트리거된 전건 | 주행 증가 최소 |
| `NetGain` (현행) | 순이득 최대 | 순이득 최대 목적지 |
| **Proposed RL** | 학습 | 학습 |

**번역이 필요한 이유**: 고전 규칙은 *"다음에 어느 작업을"*(sequencing)인데 우리 축은
*"어디로·언제"*(assignment)이고, 결정이 **둘**(누구를 + 어디로)이라 목적지 규칙을
짝지어야 한 팔이 된다.

**공통 트리거를 고정한다**(출발 블록 공개 예상 대기 상위 `k`%, **전 팔 동일**) — 고전
규칙에는 "안 옮긴다"가 없어 트리거가 없으면 무차별 재배치로 실제보다 나빠 보인다.
**전 팔이 공개 정보만 쓴다**([[YR-107]] 누출 반복 금지). **부하별로 갈리면** 세 수치를
다 적고 "어느 구간에서 유효한가"로 쓴다.

## 2. 배차 축 — 규칙 · 계획법 · 얼린 망 ([[YR-213]])

배차를 규칙 하나로 두면 **"계획법 품질을 학습 속도로"**([[YR-088]] 채택 목표)를 잴
수단이 없다. 규칙은 계산을 안 하고 계획법은 느리다 — RL 은 그 사이를 노린다.

| 배차 팔 | 무엇 | 역할 |
|---|---|---|
| `SF-SPT` | 규칙 | 현장 관행 바닥 (어느 논문에나 있다) |
| **`JointRolloutGreedy`** | 계획법 | **진짜 경쟁 상대** — 채택 망의 **증류 원본** |
| 얼린 망 | 채택 PPO | 이력 — 규칙보다 **+59.97** 나쁘다([[YR-180]]) |

**오라클은 팔이 아니라 진단 열**이다 — 정보·계산 반칙이라 넘을 대상이 아니다
([03](03-결정층.md) §2).

## 3. ⚠️ 완전교차하면 셀이 터진다

부하 3 × 배차 3 × 재배치 7팔 × 16일 = **1,008 런**(약 10일). **부분요인**으로 나눈다.

| 무엇을 재나 | 설계 | 런 |
|---|---|---|
| **주판정** — 재배치 팔 서열 | 재배치 7팔 × **배차 1종(계획법)** × 부하 3 × 16일 | 336 |
| **일반성** — "배차 무관" | 재배치 **2팔**(안팔기·최선) × 배차 3 × 부하 3 × 16일 | 288 |

합 **624 런**(완전교차의 62%). 대부분이 **학습 없는 팔**이라 병렬로 돈다.

**일반성 확인이 핵심**이다 — [[YR-180]] 이 재배치 이득을 규칙 위(−158.13)·얼린 망
위(−166.69)에서 거의 같게 쟀다. 계획법 위에서도 같으면 **세 배차로 확증**된다.

## 4. 오라클은 팔이 아니다

우리 오라클은 **정보 반칙**(완벽 ETA)과 **계산 반칙**(BEAM wide)으로 만든
**진단용 상한**이다([03](03-결정층.md) §2 · [[YR-070]]). 실제로 도달할 수 없으므로
**판정표에 넣지 않고** 헤드룸 보고용 열로만 둔다.

문헌 표준도 같다 — 규칙 · **메타휴리스틱**(GA·GA-TS·Tabu) · 소규모 **B&B 최적성
격차**가 비교군이고, 완벽정보 상한은 진단이다. 상세·출처 → [[YR-213]] spec.
