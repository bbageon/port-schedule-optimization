## 1. Φ — 평가 잣대 (v3 유지)

```
Φ(t) = Σ블록 (트럭 비용 + 본선 비용) + 주행/3600 + 기사 외부 대기/3600

트럭:  J_T(Ô) = (Ô − A)/3600 + (κ_T/3600)·softplus((Ô − D_T)/κ_T)
                 └ 체류 시간     └ SLA 초과 **확률** × 벌점
```

**계단이 아니라 softplus 인 이유**: 마감 직전인 작업은 이미 "넘길 위험"을 안고
있는데 `max(0, x)` 는 그걸 결정 시점에 안 보여준다. 그리고 **미분 가능**하다.

**본선**: `J_V(F̂) = (10·κ_V/3600)·softplus((F̂−P)/κ_V)` — **트럭의 10배**(ρ=10).
κ 는 0단계 적합 후 `kappa_fit.json` 동결, 판정런 내 조정 금지.

### 단위 — v3 에서 비용시간에서 원화로 ([[YR-207]])

지금은 **비용시간(cost-hour)** 이고 `ρ=10` 은 임의 가중치다. v3 는 **기준재를
법정 고시값으로 바꾼다.**

```
2026년 화물자동차 안전운임 고시 (국토교통부 제2026-402호, 2026-08-01 시행)
  항만부두 대기 1시간 초과분: 30분당 20,000원
  → v_truck = 40,000원 / (트럭·시간)          VAT 별도
```

**트럭 항의 구간도 바뀐다** — `B→C`(블록 도착→작업 완료) 상대비용에서
**`A→O`(게이트인→게이트아웃) 전체**로. 미완료 트럭은 평가 종료 `T` 에서 검열해
`T−A` 를 물린다(에피소드 끝에 남은 트럭이 비용을 피하지 못하게).

**법정 청구서 재현이 아니다.** 고시의 첫 1시간 면제·30분 반올림을 따르지 않고
**시간가치만 가져와** 연속 목적함수로 쓴다. 법정 재현값은 진단열로만 둔다.
왜 중요한가 — **임의 가중치가 사라지면 "얼마나 좋아졌나"를 원으로 말할 수 있다.**

## 2. 빠져 있는 비용 항목

범용 항만 비용 5항목과 대조(2026-08-19): 차량 대기 ✅ · 작업 지연 ✅(softplus 라
제안보다 정교) · 본선 대기 ✅(ρ=10) · **장비 이동 ⚠️**(트럭 주행만, 크레인 이동
없음) · **재조작 ❌**(엔진에 동작은 있으나 비용항 없음).

**야드 배치 품질이 목적함수에 안 들어간다** — 3단 밑에 깔아놔도 비용이 같다.

**v3 에서 어디까지 해결되나**: 재조작·크레인 이동은 **1시간 안에 일어나면**
반사실이 지연으로 잡는다([04b](04b-학습-잣대.md) §3). **밖이면 안 잡힌다** — 며칠 뒤 꺼낼 때의 재취급은
비용항을 새로 만들어야 한다. 그게 [[YR-202]] `C_future` 이고 **위험이 크다**:
목적함수는 정확해지지만 **라벨이 시끄러워져 학습이 더 어려워질 수 있다.**
그래서 [[YR-202]] 도 **넣기 전에 잡음 하한을 먼저 잰다.**
