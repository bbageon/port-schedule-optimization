## 1. Φ — 네 항으로 단순화 (사용자 설계 2026-08-20)

```
Φ = C_wait + C_move + C_rehandle + C_vessel        [원]
```

구 Φ 는 "비용시간(cost-hour)" 단위였고 블록별 합·주행·기사 외부 대기가 흩어져
있었다. **네 항·원화로 통일**한다.

### 항 1 — 트럭 대기 `C_wait`

```
C_wait = c_w · Σ TT_j          +  c_over · Σ max(0, TT_j − 1시간)
         └ 기본요금 (전 구간) ┘     └ 초과 할증 ┘

TT_j = O_j − A_j               ★턴타임 — 게이트인부터 게이트아웃까지
```

**`TT_j` 는 턴타임으로 못박는다**(사용자 결정 2026-08-20). 블록 체류(`C−B`)나
순수 줄서기(`S−B`)가 아니라 **기사가 실제로 겪는 총 시간**이다 —
[00 라이프사이클](00-라이프사이클.md)의 ②게이트 진입 ~ ⑤게이트 아웃.

미완료 트럭은 평가 종료 `T` 에서 검열해 `T − A_j` 를 물린다. 그래야 에피소드
끝에 남은 트럭이 비용을 피하지 못한다.

### 항 2 — YC 추가 이동 `C_move`

```
C_move = c_move · Σ (추가 이동 시간)
```

**★생산 사이클은 세지 않는다.** 트럭을 서비스하는 시간까지 비용에 넣으면
**"아무것도 안 하기"가 최적**이 된다. 재배치·재취급으로 **생긴** 빈 주행만 센다.

거리(`ΣD`) 대신 **시간** 기준이다 — 같은 100m 라도 상황에 따라 걸리는 시간이
다르고, 우리 엔진은 시간을 직접 안다.

### 항 3 — 재취급 `C_rehandle`

```
C_rehandle = c_r · N_rehandle          건당
```

**야드 배치 품질이 목적함수에 들어오는 유일한 통로**다. 지금은 3단 밑에 깔아놔도
비용이 같다.

### 항 4 — 본선/STS 대기 `C_vessel`

```
C_vessel = Σ_v  2.99 · GT_v · T_idle,v          [원]   (T 는 시간 단위)
```

야드 공급이 늦어 안벽 크레인이 멈춘 시간. **선박 톤수에 비례**한다
(사용자 결정 2026-08-20) — 큰 배를 세우면 그만큼 더 비싸다.

## 1-1. 단가 — 하나만 법정 근거가 있다

| 항 | 단가 | 근거 |
|---|---|---|
| `c_w` 트럭 | **40,000원 / 트럭·시간** | **2026 안전운임 고시**(국토부 제2026-402호) 항만부두 대기료 30분당 20,000원 |
| `c_over` 초과 할증 | **40,000원 / 트럭·시간** (기본과 동률 → 1시간 넘으면 **한계요율 2배**) | 설계 — 고시가 1시간 초과분부터 청구한다는 것을 "그 지점부터 실제 비용" 으로 읽음 |
| `c_move` YC 이동 | 60,000원/시간 (1,000원/분) | 설계 — 전력·정비·운영 환산 |
| `c_r` 재취급 | 2,000원/회 | 설계 — 추가 lift 2분 × YC 분당 단가 |
| `c_v` 본선 | **2.99원 / GT·시간** | 설계 (선급 3종 — §1-2) |

**`c_w` 만 인용 가능한 법정값**이고 나머지는 **동결 대상 설계 파라미터**다.
판정 시작 전에 동결하고 런 중 조정 금지 — 결과를 보고 바꾸면 판정이 무효다.

## 1-2. ★본선은 톤수에 비례한다 — 선급 3종

```contract
vessel_classes_target = 3
```

| 급 | GT | TEU | `c_v` 원/시간 | 원/분 | **트럭 대비 ρ** | GT/TEU |
|---|---|---|---|---|---|---|
| 소형 | 50,000 | 3,000 | 149,500 | 2,492 | **3.74** | 16.7 |
| 중형 | 100,000 | 7,500 | 299,000 | 4,983 | **7.47** | 13.3 |
| 대형 | 150,000 | 14,000 | 448,500 | 7,475 | **11.21** | 10.7 |

**구 `ρ = 10` 단일값이 3.74~11.21 범위로 갈린다.** 현행 값은 대략 중형~대형
사이였던 셈이다. GT/TEU 가 큰 배일수록 낮아지는 것도 실선과 맞는다.

### 무엇이 새로 생기나 — 우선순위 축

지금은 모든 본선이 동등해서 **"어느 배를 먼저 먹일까"라는 결정이 없다.**
대형선을 세우는 비용이 소형선의 **3배**가 되면 그 결정이 생긴다. 재배치 정책이
쓸 수 있는 **새 신호**이고, 규칙은 이걸 반영하지 않는다.

### 기항 물량과 척수는 02b 의 무대 계약을 따른다

이 값은 새로 정할 항목이 아니다. v3 는 다음 [02b 본선](02b-본선.md) 계약을 따른다.

```text
moves_v ~ TEU_v × U(0.15, 0.30)       # 시드에서 선추출
port_time_v = lookup(moves_v)          # 실측 Port Time 표 조회
```

평균 접안 시간은 소·중·대 **20.4 / 27.7 / 38.6시간**이다. 이는 순수 하역 작업시간이
아니며, 중·대형은 24h 창을 넘는다. 구성은 **소2 · 중1 · 대1은 30% 확률**이다.
긴 접안과 동시 처리율 때문에 기존 **12척 구성은 유지할 수 없다.**
현재 코드는 **12척·척당 120 moves**로 아직 이 계약을 구현하지 않았다 → [[YR-212]]

**⚠️ 무대가 바뀌므로 앞선 7,500 실측은 다시 재야 한다**(본선 1,440 기준 수치).

### ⚠️ `T_idle` 의 정의를 못박아야 한다

2.99원/GT·시간은 **선박 단위** 요율이다. 큰 배는 보통 STS 를 여러 대 붙이므로
"STS 1대가 멈춤"과 "배가 멈춤"이 다르다.

| 정의 | 뜻 |
|---|---|
| **선박 유휴** (권장) | 그 배에 붙은 STS 가 **전부** 멈춘 시간 — GT 요율과 단위가 맞는다 |
| STS 유휴 합 | 개별 STS 멈춤의 합 — 대수로 나눠야 하고 이중 계상 위험 |

현 엔진은 본선 1척 = 1 STS 스트림(`sts_move_interval_s`)이라 둘이 같다. 선급별로
STS 대수를 다르게 두면 그때 갈린다 → 착수 시 결정.

## 1-3. ★왜 대기항만 꺾인선인가

**선형이면 재배치의 이득이 정의상 0 에 가까워진다.**

```
선형:   10분 + 20분 = 30분      15분 + 15분 = 30분      ← 똑같다
꺾인선: 20분짜리가 문턱을 넘어 할증  →  펴면 싸진다
```

`sell_gain.py` 가 이미 그렇게 적어놨다 — *"비용이 선형이라면 시간 판매는 원리상
이득이 없다(미룬 만큼 기사가 밖에서 기다리므로) — **볼록성이 이 기준의 존재
이유**다."* 대기를 없애는 게 아니라 **남에게 넘기는 것**뿐이기 때문이다.

| | 선형에서 |
|---|---|
| 시간 이연 | 이득 **정확히 0** |
| 공간 재배치 | 목적지 크레인이 놀 때만 이득 — 크게 줄어듦 |

**꺾이는 지점이 고시와 일치한다**(1시간). 볼록성이 인위적 장치가 아니라 **법정
요금 구조 그 자체**라 방어하기 쉽다. 구 softplus 는 이 꺾은선을 매끄럽게 만든
것이므로 `max(0,·)` 로 단순화해도 된다(미분 가능성만 포기).

**⚠️ 무대의 트럭 SLA 는 1,800초**(`truck_sla_s`)로 별개 값이다. 꺾이는 지점을
1시간으로 두면 둘이 어긋난다 — [[YR-207]] 착수 시 하나로 정리한다.
