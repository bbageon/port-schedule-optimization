# 04 — 비용과 보상: 평가 잣대와 학습 잣대

> **확인일 2026-08-20** · 코드: `integrated/cost_curve_v2.py` ·
> `experiments/yr151_transfer_ppo.py`(Φ) · `experiments/yr174_txn_reward.py`(보상)

## 0. 잣대가 둘이고, **시야가 다르다**

| | 무엇 | 시야 |
|---|---|---|
| **Φ** | 평가 잣대 — 터미널 하루 총비용 | **24시간** |
| **`D_i`** | 학습 잣대 — 그 거래 하나의 공로 | **약 40분** |

**이 불일치가 현재 연구의 핵심 문제**다 → §4

## 1. Φ — 평가 잣대

```
Φ(t) = Σ블록 (트럭 비용 + 본선 비용)  +  주행/3600  +  기사 외부 대기/3600
```

### 트럭 (softplus 확률 지연 · YR-136 v2.1)

```
J_T(Ô) = (Ô − A)/3600  +  (κ_T/3600) · softplus((Ô − D_T)/κ_T)
          └ 체류 시간      └ SLA 초과 **확률** × 벌점
```

**계단이 아니라 softplus 인 이유**: 마감 직전인 작업은 이미 "넘길 위험"을 안고
있는데, `max(0, x)` 는 그걸 결정 시점에 안 보여준다. 그리고 **미분 가능**하다.

### 본선

```
J_V(F̂) = (10 · κ_V/3600) · softplus((F̂ − P)/κ_V)      ρ = 10
```

**본선 지연은 트럭의 10배**. κ 는 0단계에서 적합 후 `kappa_fit.json` 으로 동결 —
판정런 내 조정 금지.

### 단위

**비용시간(cost-hour)**. 원(KRW) 아님. `ρ=10` 은 사실상 임의 가중치이며, 원 단위
환산은 실데이터로 단가를 실측할 수 있을 때가 적기다.

## 2. `D_i` — 학습 잣대 (차분 신용)

```
공간:  D_i = R_src − B_dst − ΔC_route
시간:  D_i = relief − burden − defer_s/3600
```

| 항 | 계산 |
|---|---|
| `B_dst` 수신 부담 | 자기 비용 + **뒤차 지연**(그 시각 대기 수 × 점유시간) + **본선 압력**(ρ=10) |
| `R_src` 소스 절감 | 같은 형태로 src 에서 — "남았더라면"은 미관측이라 **실현 서비스 시간 대입**(가정) |
| `ΔC_route` | (게이트→dst) − (게이트→src) |

**대칭성**: 양쪽 모두 "점유시간 × 그때 대기 수 (+ 본선 몫)" 라는 **같은 근사**를
일부러 쓴다. 한쪽만 정밀하면 편향이 생긴다.

**학습 목표** = `−D_i / Q_SCALE` (Q_SCALE = 20.0). KEEP 은 표본이 아니라 **상수 0**.

## 4. ★40분 시야 — 무엇이 빠져 있나

`realized_credit` 이 세는 범위:

```python
occupy = job_done − service_start      # 크레인 점유
own    = gate_out − gate_in            # 그 트럭의 체류
blocked_dst = 그 순간 대기 트럭 수
```

**전부 "그 트럭 한 대의 방문"(약 40분) 안**이다. 에피소드는 24시간.

| 세는 것 | 안 세는 것 |
|---|---|
| 그 트럭의 체류 | 그 배치가 만들 **재취급** |
| 그 순간 뒤차 지연 | 이후 트럭들의 **추가 대기** |
| 그 순간 본선 압력 | 그 컨테이너를 **나중에 꺼낼 때**의 비용 |

**그리고 규칙(`sell_gain`)도 근시안이다** — "지금 순이득"만 본다. 따라서
**RL 에게 구조적 우위가 없다**: 같은 질문에 규칙은 공식, RL 은 근사로 답한다.
