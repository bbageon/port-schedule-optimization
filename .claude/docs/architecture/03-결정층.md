## 1. 두 층이 세계를 통해서만 만난다

```
① 크레인 층 ─── 블록 안에서 "지금 비는 크레인 2대로 어떤 작업을 할까"
     ↕  (직접 통신 없음. 야드 상태로만 상호작용)
② 재배치 층 ─── 블록 사이에서 "이 트럭을 다른 블록으로 보낼까 / 미룰까"
```

## 2. ① 크레인 층 — **동결**

| | |
|---|---|
| 망 | `JointPairNet(250)` · **97,410 파라미터** |
| 계보 | 규칙(`JointRolloutGreedy`) → **증류**(YR-073) → **PPO 학습**(YR-139) |
| 채택 | YR-143 confirm C0 체크포인트 |
| 상태 | `requires_grad=False` **동결** · 매 iteration 해시 검사 |

**한 대씩이 아니라 두 대를 함께 정한다:**

```python
rows.append(ctx_a + blk_a + ctx_b + blk_b)   # 한 행 = 두 크레인 조합
argmin(net(rows))                             # 가장 싼 조합
```

후보는 크레인별로 생성(`{crane: generate(sim, crane)}`)하지만 **결정은 조합
단위**다 — 같은 블록의 두 크레인이 서로 방해하기 때문.

**왜 안 배우나**: 오라클 상한이 **트럭 1대당 +0.18분**(2026-07-15·07-19 두 번
확증). 재배치 축은 −2.6분. **14배 차이라 여기 집중한다.**

**⚠️ 한계**: 구 2블록 무대에서 학습한 것을 21블록 무대에 얼려 쓴다. 이 무대에서는
규칙보다 비싸다(`A − R` = +59.97, 대당 +1.00분).

## 3. ② 재배치 층 — **학습 대상**

| | |
|---|---|
| 망 | `SellQNet` · **5,633 파라미터** (21 → 64 → 64 → 1) |
| 출력의 뜻 | **비용** (낮을수록 싸다) — 확률이 아니다 |
| 선택 | **argmin** (평가) · ε=0.15 + σ=0.20 (학습 탐색) |
| 공유 | 가중치 **1벌을 21블록이 각자 실행** (중앙학습·분산실행) |

### 행 = 21차원

```
블록 요약 7 + 후보 6 + 좌표 8 = 21
```

| 부분 | 내용 |
|---|---|
| 블록 7 | inside/10 · pipeline/10 · crane_backlog/3600 · occupancy · vessel_slack/3600 · announced_30/10 · n_cands/6 |
| 후보 6 | ETA 잔여 · is_out · size40 · gate 잔여 · 이송 이력 · 이연 이력 |
| 좌표 8 | is_space · is_time · dst_load · dst_free · route_delta · defer_s · src_load_after · **src_load** |

**`src_load` 만 두 축이 공유** — 배정기의 **가상 상태**가 망에 들어가는 유일한 통로다.

### ★행에 좌표가 들어간 것이 핵심

```
구(PPO): 블록 7 + KEEP플래그 1 + 후보 6 = 14   ← 목적지가 없다
신(Q)  : 블록 7 + 후보 6 + 좌표 8      = 21   ← 목적지가 있다
```

구판은 행에 목적지가 없어 **배정기가 좌표를 따로 계산**했고, 거기서 [[YR-175]]
(부호 오류)·[[YR-177]](기준 불일치)이 났다. 지금은 **정책과 배정기가 같은 망으로
같은 행**을 채점한다 — "다른 자로 잰다"가 성립 불가.

## 4. 두 관문

### 1관문 — 블록이 제안 (60초 격자)

각 블록이 자기 후보를 훑어 **한 건만** 내놓는다.

| 모드 | 동작 |
|---|---|
| `defer_decision=False` (구) | 최소 Q < 0 일 때만 제안 — **판단을 여기서** |
| `defer_decision=True` ([[YR-195]]~) | **무조건 최악 하나 지목** — 순위만, 판단 안 함 |

### 2관문 — 중앙 배정기가 좌표 결정

전 블록 제안을 모아 **동시에** 처리한다.

| `inOut` | 선택지 |
|---|---|
| `GATE_IN` | 다른 블록 20곳(공간) ∪ +15분 이연(시간) ∪ KEEP |
| `GATE_OUT` | +15분 이연(시간) ∪ KEEP — **공간 불가** (컨테이너 위치 고정) |

```python
while remaining:                       # 전역 한계비용 최소 쌍 반복 선택
    best = min over (offer × coord) of cost
    q[dst] += 1; q[src] -= 1           # 가상 대기열 갱신 (볼록 비용 재계산)
    vcap[dst] += 1                     # 용량 검사
```

**KEEP 의 값**: `0 − sell_margin` (구) 또는 좌표마다 `+margin_axis` ([[YR-200]]).
**순열 불변** — 동점은 `(cost, offer_key, coord)` 사전순.

## 6. 비용이 아니라 제약으로 다루는 것

**물리적으로 불가능한 것은 벌점이 아니라 후보에서 제거한다.**

| | 처리 |
|---|---|
| 블록 용량 초과 | `free_slots − vcap ≤ capacity_margin` → 좌표 미생성 |
| 크레인 물리 충돌 | `feasible_mask` — 열거 단계 선제거 |
| 재조작 용량 초과 | `rehandle_capacity_ok` |
| 대기·주행·지연·본선 | **비용함수** |

**벌점으로 때려 넣은 곳이 없다.**
