# 02 — 무대: 21블록 24시간 터미널

> **확인일 2026-08-20** · 코드: `integrated/profiles.py` · `yard_layout.py` ·
> `terminal_stream.py`

## 1. 물리

| | 값 | 근거 |
|---|---|---|
| 블록 | **21개** (`Y01`~`Y21`) | `terminal_layout().ids` |
| 블록당 크레인 | **2대** (`YC-L`, `YC-W`) | `profile.cranes` |
| 블록 규격 | 24 bay × 10 row × 6 tier = **1,440 슬롯** | `profile.block` |
| 배치 | **한 줄(단일 축)** — 게이트에서 거리순 | `layout.position_m()` |
| 게이트→블록 | **190 ~ 410초** | `gate_to_block_s()` = 거리 ÷ 속도 |

```
게이트 ─ Y01(190s) ─ Y02(201s) ─ … ─ Y21(410s)
        가까움 ←──────────────────────→ 멂
```

**⚠️ 실데이터와 다름**: DGT 는 **24종 이상**이고 **A열·E열 두 줄 + 검사장(`INS`)**
이다. 우리는 단일 축 21개. 거리표 재작성이 [[YR-196]] 대상.

## 2. 물량과 시간

| | 값 |
|---|---|
| 하루 트럭 | **3,600대** |
| 반출 비율 | **0.6** (실측 61.6%) — DGT 는 49% |
| 40피트 비율 | 0.7 |
| 관측 계약 | warmup **7,200초** + measure **79,200초** = **86,400초(24h)** |
| 도착 패턴 | **아침·저녁 이중 피크** |
| 트럭 SLA | **1,800초**(30분) 초과부터 벌점 |
| 본선 가중 | **ρ = 10** — 본선 지연은 트럭의 10배 |

**고정 재공량(WIP)** 무대다 — 도착 명단이 **사전 확정**되고 개방루프로 투입된다.
그래서 두 정책이 **같은 트럭·같은 시각**을 받는다(짝비교의 근거).

## 3. 난수는 전부 시드에서 미리 뽑힌다

```python
random.Random(f"h21d:arr:{seed}")     # 도착 시각
random.Random(f"h21:resid:{seed}")    # 주행 오차
random.Random(f"h21:mix:{seed}")      # 반입/반출·규격
random.Random(f"h21:exit:{seed}")     # 출문 주행
```

**정책이 결정할 시점에는 이미 다 확정돼 있다.** 즉 진짜 우연이 아니라
**가려놓은 것**이다 — 정책은 통지된 것만 볼 수 있을 뿐, 세계는 결정적이다.

이것이 [[YR-199]] 잡음 하한(신호의 77.6%)의 해석에 중요하다 — 그 잡음은
환경의 무작위성이 아니라 **우리가 준 특징으로 구분 안 되는 것**이다.

## 4. ★현 무대의 구조적 제약 (연구에 영향)

### ① 통지 리드타임이 30분 고정

```
ANNOUNCE_LEAD_S = 1800.0   # 모든 트럭이 정확히 30분 전 통지
```

**모든 트럭이 정보 측면에서 동일**하다. 그래서 **"어느 트럭을 언제 다룰까"라는
결정이 성립하지 않는다.** 규칙과 학습이 다를 이유가 줄어든다.

DGT 실측: 중앙 **1.27시간** · 사분위폭 **2.36시간** · **14.1%는 통지 전 도착**.

### ② 정책이 시각을 모른다

`block_features` 7개에 **시각이 없다**:

```
[inside/10, pipeline/10, crane_backlog/3600, occupancy,
 vessel_slack/3600, announced_30/10, n_cands/6]
```

무대에 이중 피크가 있는데 **"지금 06시라 곧 붐빈다"를 알 수 없다.**
`t/end` 는 구 critic 입력에만 있었고 [[YR-189]] Q 전환에서 critic 을 없애며 소멸.

### ③ 대기 대수를 정책이 다른 값으로 본다

| | 정의 |
|---|---|
| 정책이 보는 `inside` | 게이트인 ≤ t < 게이트아웃 — **블록 안 전부** |
| 보상이 쓰는 `_waiting_at` | 블록도착 ≤ t < 서비스시작 — **줄 선 것만** |

**채점은 "줄 선 대수"로 하는데 정책에는 "총 대수"를 준다.**

②③ 은 [[YR-198]] 후보이며, **잡음 하한 재측정으로 값어치를 선확인**할 수 있다.
