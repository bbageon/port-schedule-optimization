# 06 — 학습과 판정 (v3 설계 · 축 ③)

> **성격**: to-be 설계. 코드가 여기에 맞춰진다. → [index](README.md)
> **관련 코드**: `experiments/yr189_q_train.py` · `yr195_margin.py` ·
> `yr200_axis_margin.py` · `integrated/repro.py`

**★판정 규약은 v3 에서도 안 바꾼다.** 사전등록·하드가드·짝비교·대역 관리는
**세대와 무관한 심판 규칙**이다. 바꾸면 v1·v2 와 비교가 끊긴다.
바뀌는 것은 **학습 쪽**뿐이다 — 교사–학생 2단.

## 1. 학습 계약 (v2 현행 · Q 회귀)

| | 값 | 왜 |
|---|---|---|
| 방식 | **후버 회귀** (`smooth_l1`, β=1.0) | PPO 아님 — 문맥 밴딧 위 비용 회귀 |
| 목표 | `Q(고른 행) ← −D_i / Q_SCALE` | 부호 반전: 이득 → 비용 |
| `Q_SCALE` | **20.0** | 목표를 O(1) 로. **비판정 시드에서 실측** 후 동결 |
| 학습률 | 3e-4 | yr139 앵커 승계 |
| 회차 | 16 × 4 에피소드 | YR-183 실측: 곡선이 iter 11~13 에서 평평 |
| 재생 버퍼 | 150,000 (FIFO) | off-policy — 라벨이 직접 관측이라 편향 없음 |
| 갱신 | 회차당 600 step · 미니배치 256 · grad clip 1.0 | |
| 탐색 | 제안 ε=0.15 · 좌표 σ=0.20 | **학습 중에만**. 평가는 0 |
| critic | **없음** | 붕괴할 critic 이 없다 |

### ★정직한 명명

라벨 `−D_i` 가 **그 거래의 실현 손익**이므로 부트스트랩이 없다.
**시간차 학습이 아니라 문맥 밴딧 위의 비용 회귀**다.
논문에 "Q 학습"이라 쓰지 않고 **"차분 신용 라벨을 쓰는 조합 행동공간 비용 회귀"**.

문헌: difference rewards (Wolpert & Tumer 2002) · COMA (Foerster 2018) ·
조합 행동공간 후보 채점. **우리 발명이 아니다.**

### ⚠️ 알려진 설정 결함

| | 실측 |
|---|---|
| σ 를 **절대값**으로 고정 | 목표 눈금이 줄어 상대 강도 1.8배 → **8.7배** ([[YR-193]]) |
| 버퍼 FIFO 축출 | iter 10 부터 초기 넓은 탐색 데이터가 통째로 밀려남 |

**v3 에서 둘 다 고친다** — σ 를 목표 표준편차 대비 **상대값**으로, 버퍼는 초기
탐색분을 남기는 축출로. 다만 [[YR-193]] 의 근거였던 3시간 창 관측은 22시간에서
뒤집혔으므로(관측 7), **전제를 다시 재고 나서** 손댄다.

## 1-1. ★v3 학습 계약 — 교사–학생 2단

배포 시점에 반사실 rollout 을 돌릴 수 없으므로 **라벨 만드는 쪽과 결정하는 쪽을
분리**한다.

| | 교사 ([[YR-204]]) | 학생 ([[YR-205]]) |
|---|---|---|
| 하는 일 | 그 거래만 취소한 세계를 **H=1h 굴려** `D_i` 산출 | 그 라벨을 회귀로 배움 |
| 언제 | **학습 때만** | 학습 + **배포·판정** |
| 속도 | 느림 (후보 1건당 rollout 1회) | 즉시 추론 |
| 산출 | `R_src` · `B_dst` 두 조각 | Seller 망 · Buyer 망 |

**교사는 망이 아니다** — 시뮬레이터를 두 번 굴리는 절차다. 학습할 파라미터가 없다.

### 두 단계를 따로 판정한다

| 단계 | 무엇을 확인 | 판정 없이 넘어가면 |
|---|---|---|
| **4** 교사만 | 라벨 품질 — [[YR-199]] 잡음 하한이 내려가나 | 학생이 못 배운 건지 라벨이 나쁜 건지 못 가른다 |
| **5** 학생 | 규칙 대비 성능 | — |

**4단계는 학습 없이 끝낼 수 있다.** 교사 라벨로 잡음 하한을 재측정해서 v2 라벨보다
설명력이 높은지만 보면 된다. **낮으면 5단계를 안 한다.**

### 새 하드가드 — 교사 누출 금지

판정 실행에서 **교사가 한 번도 안 불려야** 한다.

```
rollout_calls_during_eval == 0
```

교사 라벨이 학생 **입력**에 섞이면 미래가 새어 들어온다
([05](05-정보경계.md) §3).

## 2. 판정 계약 (v3 에서도 동일)

| | |
|---|---|
| 모드 | **argmin 결정론** (ε=0·σ=0) — 배포 방식 |
| 팔 | `K`(안 팔기) · `greedy`(규칙) · 학습 팔 |
| 독립단위 | **날** (n=16) · 같은 날 짝지어 |
| 유의 | \|t\| ≥ 2.13 (df=15 양측 95%) |
| 방향 선언 | **CI 가 0 을 배제할 때만** — 포함하면 "구분 불가" |
| 가중치 | **마지막 회차 고정** (중간 지점 고르기 금지) |

### 하드가드 (위반 시 그 셀 실격)

1. 투입 = **전건** (`admitted == DIURNAL_DAY_TOTAL`, 2026-08-20 기준 **7,500**)
   — 리터럴 3600 을 박아두던 5개 판정 스크립트를 상수 참조로 고쳤다
2. `policy_exceptions == 0`
3. 실행 트리 **`code_dirty == False`**
4. 전 셀 존재 (팔 수 × 날 수)
5. 학습 중 표본 0 인 회차가 있으면 즉시 중단

**⚠️ `code_dirty` 함정**: WSL 에서 `GIT_DIR` 없이 돌리면 `None` 을 반환해
가드가 **조용히 무력화**된다. 실행 전 확인 필수.

**판정 대역을 쓰는 것은 2·8 뿐**(4는 통과 시). 3·4·7 은 학습 없이 라벨 품질만
재므로 대역을 안 쓴다 — **대역이 유한 자원이라 아끼는 설계**다.

**⚠️ 5~8 은 지금 착수 금지** — [[YR-203]]·[[YR-207]]·[[YR-204]]·[[YR-205]] 는
전부 "현재 performance 게이트 해소 전 착수 금지"로 등록돼 있다.

### [[YR-207]] 은 왜 판정이 아닌가

단위만 원화로 바꾸는 것이므로 **정책 순위가 안 바뀌어야 정상**이다. 순위가 바뀌면
그건 개선이 아니라 **환산이 틀렸다는 신호**다. 그래서 대역을 안 쓰고, 대신
**전환 전후 순위 일치**를 검사한다.
