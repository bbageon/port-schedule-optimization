# 06 — 학습과 판정 (v3 설계 · 축 ③)

> **성격**: to-be 설계. 코드가 여기에 맞춰진다. → [index](README.md)
> **관련 코드**: `experiments/yr189_q_train.py` · `yr195_margin.py` ·
> `yr200_axis_margin.py` · `integrated/repro.py`

**★판정 규약은 v3 에서도 안 바꾼다.** 사전등록·하드가드·짝비교·대역 관리는 **세대와
무관한 심판 규칙**이라 바꾸면 v1·v2 와 비교가 끊긴다. 바뀌는 것은 **학습 쪽**뿐이다.

## 1. 학습 계약 (v2 현행 · Q 회귀)

| | 값 | 왜 |
|---|---|---|
| 방식 | **후버 회귀** (`smooth_l1`, β=1.0) | PPO 아님 — 문맥 밴딧 위 비용 회귀 |
| 목표 | `Q(고른 행) ← −D_i / Q_SCALE` | 부호 반전: 이득 → 비용 |
| `Q_SCALE` | **20.0** | 목표를 O(1) 로. **비판정 시드에서 실측** 후 동결 |
| 학습률 | 3e-4 | yr139 앵커 승계 |
| 회차 | 16 × 4 에피소드 | YR-183 실측: 곡선이 iter 11~13 에서 평평 |
| 재생 버퍼 | 150,000 (FIFO) | off-policy — 라벨이 직접 관측이라 편향 없음 |
| 갱신 | 회차당 600 step · 미니배치 256 · grad clip 1.0 | |
| 탐색 | 제안 ε=0.15 · 좌표 σ=0.20 | **학습 중에만**. 평가는 0 |
| critic | **없음** | 붕괴할 critic 이 없다 |

### ★정직한 명명

라벨 `−D_i` 가 **그 거래의 실현 손익**이라 부트스트랩이 없다 — **시간차 학습이 아니라
문맥 밴딧 위의 비용 회귀**다. 논문에 "Q 학습"이라 쓰지 않는다. 문헌: difference
rewards(Wolpert & Tumer 2002) · COMA(Foerster 2018). **우리 발명이 아니다.**

### ⚠️ 알려진 설정 결함

σ 를 **절대값**으로 고정해 목표 눈금이 줄면 상대 강도가 1.8배→**8.7배**가 되고
([[YR-193]]), 버퍼 FIFO 축출은 iter 10 부터 초기 탐색 데이터를 통째로 밀어낸다.
**v3 에서 둘 다 고친다** — 다만 [[YR-193]] 의 근거였던 3시간 창 관측이 22시간에서
뒤집혔으므로(관측 7) **전제를 다시 재고 나서** 손댄다.

## 1-1. ★v3 학습 계약 — 교사 1 · **학생 2**

배포 때 rollout 을 못 돌리므로 **라벨 만드는 쪽과 결정하는 쪽을 분리**한다. v3 는
Seller·Buyer 가 **독립 행위자**라 학생이 **둘**이다([03](03-결정층.md) §3-1).

| | 교사 ([[YR-204]]) | 학생 ([[YR-205]]) |
|---|---|---|
| 하는 일 | 행위자가 **자기 행동을 바꾼** 세계를 H=3h 굴린다 | 그 라벨을 회귀로 배움 |
| 산출 | Seller `Φ_H(KEEP)`↔`Φ_H(SELL)` · Buyer `Φ_H(REJECT)`↔`Φ_H(BUY)` | **Seller 망 · Buyer 망** |
| 언제·속도 | **학습 때만** · 느림(선택지당 rollout 1회) | 학습 + **배포·판정** · 즉시 |

**교사는 망이 아니다**(시뮬레이터를 굴리는 절차). **선택지가 둘뿐이라 회귀로 끝난다**
— 각 세계 비용을 배우고 싼 쪽을 고른다. PPO 도 critic 도 안 들인다(v1 이 무너진 자리).

**★두 학생의 라벨을 더하지 않는다** — 각자 "내가 행동을 바꿨다면"을 재므로 겹치는
몫이 양쪽에 다 들어간다. Φ 에는 **일어난 일만 한 번** 기록한다(합치면 이중 계상).

**4단계(교사만)는 학습 없이 끝낼 수 있다** — 교사 라벨로 잡음 하한을 재측정해 v2
라벨보다 설명력이 높은지만 본다. **낮으면 5단계(학생)를 안 한다**(안 그러면 "학생이
못 배운 건지 라벨이 나쁜 건지"를 못 가른다).

### v3 신설 하드가드 둘

**① 교사 누출 금지** `rollout_calls_during_eval == 0` — 교사 라벨이 학생 **입력**에
섞이면 미래가 샌다([05](05-정보경계.md) §3).

**② 거래 0 감지** `traded_edges > 0` — 독립 행위자라 **Buyer 가 전량 거절하면
거래가 0** 이 되고 학습 신호가 사라진다. 그런 회차가 나오면 **즉시 중단**하고,
"학습이 안 된 것"과 "거래 자체가 없던 것"을 **구분해 보고**한다.

## 2. 판정 계약 (v3 에서도 동일)

| | |
|---|---|
| **부하** | **3,500 · 5,000 · 7,500 세 수준 전부** — 셋 다 실측이라 하나만 이기면 인정 안 된다 ([02](02-무대.md) §2-1 · [[YR-210]]) |
| 모드 | **argmin 결정론** (ε=0·σ=0) — 배포 방식 |
| 팔 | **재배치** 7종 (§2-1 · [[YR-211]]) × **배차** 3종 (§2-2 · [[YR-213]]) |
| 독립단위 | **날** (n=16) · **같은 날·같은 부하**끼리 짝지어 |
| 유의 | \|t\| ≥ 2.13 (df=15 양측 95%) |
| 방향 선언 | **CI 가 0 을 배제할 때만** — 포함하면 "구분 불가" |
| 가중치 | **마지막 회차 고정** (중간 지점 고르기 금지) |

### 하드가드 (위반 시 그 셀 실격)

1. 투입 = **전건** (`admitted == 그 부하의 물량`)
2. 전 셀 존재 (**부하 3 ×** 팔 수 × 날 수) — 한 부하라도 비면 판정 미성립
3. `policy_exceptions == 0` · 실행 트리 **`code_dirty == False`**
4. 학습 중 표본 0 인 회차가 있으면 즉시 중단
5. **`rollout_calls_during_eval == 0`** · **`traded_edges > 0`** — v3 신규 (§1-1)

**⚠️ `code_dirty` 함정**: WSL 에서 `GIT_DIR` 없이 돌리면 `None` 을 반환해 가드가
**조용히 무력화**된다. 실행 전 확인 필수.

### [[YR-207]] 은 왜 판정이 아닌가

단위만 원화로 바꾸는 것이므로 **정책 순위가 안 바뀌어야 정상**이다. 순위가 바뀌면
그건 개선이 아니라 **환산이 틀렸다는 신호**다. 그래서 대역을 안 쓰고, 대신
**전환 전후 순위 일치**를 검사한다.
