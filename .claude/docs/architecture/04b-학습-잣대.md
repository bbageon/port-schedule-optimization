**`D_i` 는 그 거래 하나의 공로**다. Φ 가 하루 전체(24시간)를 재는 반면 `D_i` 의
시야는 **약 40분**이다. v3 는 이 잣대를 **추정 공식에서 반사실로** 바꾼다.

```contract
counterfactual_h_s_target = 3600
```

## 1. `D_i` — v2 학습 잣대 (차분 신용)

```
공간:  D_i = R_src − B_dst − ΔC_route
시간:  D_i = relief − burden − defer_s/3600
```

| 항 | 계산 |
|---|---|
| `B_dst` 수신 부담 | 자기 비용 + **뒤차 지연**(그 시각 대기 수 × 점유시간) + **본선 압력**(ρ=10) |
| `R_src` 소스 절감 | 같은 형태로 src 에서 — "남았더라면"은 미관측이라 **실현 서비스 시간 대입**(가정) |
| `ΔC_route` | (게이트→dst) − (게이트→src) |

**대칭성**: 양쪽 모두 "점유시간 × 그때 대기 수 (+ 본선 몫)" 라는 **같은 근사**를
일부러 쓴다. 한쪽만 정밀하면 편향이 생긴다.
**학습 목표** = `−D_i / Q_SCALE` (Q_SCALE = 20.0). KEEP 은 표본이 아니라 **상수 0**.

**v3 에서 이 세 항의 뺄셈 구조는 유지**하고, 값을 만드는 방법만 바꾼다(§3).
그리고 세 항을 **망 둘로 쪼갠다** → [03](03-결정층.md) §3-1.

## 2. ★v2 의 `D_i` 는 독립 검증을 통과했다

| 방법 | 시간 판매 1건의 비용 |
|---|---|
| 비용식에서 **해석적 유도** ([[YR-171]]) | **14.28 분** |
| 차분 신용 **실측** (2026-08-19) | **13.75 분** |

**완전히 다른 두 경로가 4% 안에서 만난다.** 축 격차도 라벨 +0.2480 vs 모델
+0.2546 로 맞는다. 부수 정황: `Φ + 신용합` 이 회차마다 2,413~2,588 로 좁게 모인다
(엄밀 검증 [[YR-194]]).

**그래서 v3 반사실은 "틀린 것을 고치는" 게 아니다.** 지금 식은 자기 가정 안에서
정합적이다. 바꾸는 이유는 **가정 밖(연쇄·재조작·1시간)을 못 본다**는 것이다.

## 2-1. ★v2 의 벽 — 시야 40분 · 그리고 **추정**

`realized_credit` 이 세는 범위(`occupy`·`own`·`blocked_dst`)는 **전부 "그 트럭
한 대의 방문"(약 40분) 안**이다. 에피소드는 24시간. 그 배치가 만들 **재취급**,
이후 트럭들의 **추가 대기**, **나중에 꺼낼 때**의 비용은 아무것도 안 센다.

**그리고 값이 실측이 아니라 추정이다.** `blocked_dst × occupy` 는 *"내가 크레인을
잡은 동안 뒤차 N대가 그만큼 밀렸을 것이다"* 라는 **가정**이다. 실제로는 그 사이
크레인 하나가 비었을 수도, 다른 트럭이 먼저 갔을 수도 있다.

**게다가 규칙(`sell_gain`)도 근시안이다** — "지금 순이득"만 본다. 같은 질문에
규칙은 **공식**으로, RL 은 **근사**로 답한다. **RL 에게 구조적 우위가 없다.**

## 3. ★v3 변경 ② — 추정에서 반사실로

### 두 걸음이다 — 먼저 [[YR-201]], 그다음 [[YR-204]]

| | 무엇 | 시야 | 상태 |
|---|---|---|---|
| **[[YR-201]]** 진짜 반사실 신용 | `D_i = C(i 빼고 재매칭) − C(전체 매칭)` ← **재매칭**이 핵심 | 그 순간 | **코드가 이미 있다** — `sell_credit.py`, **import 0곳** |
| **[[YR-204]]** 장기 반사실 교사 | 그 거래만 취소한 세계를 **H=1h 굴림** | 1시간 | 미구현 |

**[[YR-201]] 이 먼저인 이유**: 지금 식은 *"i 가 없었으면 아무 일도 안 일어난다"*
고 본다. 실제로는 **그 자리를 다른 제안이 대신 쓴다.** 그래서 자기 공로를
과대평가한다. 재매칭 반사실은 그것만 고치며 **rollout 이 필요 없다** — 싸다.

**[[YR-204]] 는 거기에 시간을 더한다.** 아래가 그 설계다.

### 하는 일: 안 했을 때의 세계를 **실제로 굴린다**

```
결정 시점 t ─┬─ 그대로 진행 ───────────► Φ_H(했다)
             └─ 그 거래만 취소하고 진행 ► Φ_H(안 했다)

D_i = Φ_H(안 했다) − Φ_H(했다)        H = 1시간
```

**추측이 없다.** 두 세계를 같은 시드로 1시간씩 굴려 총비용을 재고 뺀다.
"밀렸을 것이다"가 "실제로 밀렸다"로 바뀐다.

| | v2 (추정) | v3 (반사실) |
|---|---|---|
| 뒤차 지연 | 대기 수 × 점유시간 **가정** | 실제로 굴려서 **측정** |
| `R_src` "남았더라면" | 실현 서비스 시간 **대입** | 그 세계를 **진짜 굴림** |
| 재취급·크레인 이동 | ❌ 안 셈 | ✅ **1시간 안이면 자동으로 잡힘** |
| 연쇄 효과 | ❌ | ✅ H 안에서 |

**§6 의 빠진 비용항 일부가 여기서 저절로 해결된다** — 재조작이 일어나면 크레인이
그만큼 오래 잡히고, 그 지연이 다음 트럭들의 대기로 **Φ 에 나타난다.** 비용항을
새로 만들 필요가 없다. (다만 **며칠 뒤 꺼낼 때**의 재취급은 H 밖이라 여전히 없다.)

### 값이 얼마나 드나 · 왜 1시간인가

반사실은 **거래 후보 1건당 rollout 1회**이므로 **H 가 곧 배수**다
(40분 ×1 · **1시간 ×1.5** · 3시간 ×4.5).

**사용자 결정 2026-08-20: H = 1시간.** 멀리 볼수록 좋지만 오더 1건마다 발생하므로
3시간은 감당이 안 된다. [03](03-결정층.md) §3-1 의 O(N²)→O(N) 이 이 예산을 만든다.

### 학습에서만 쓴다 — 교사–학생

배포 시점에 rollout 을 돌릴 수는 없다(1건 결정에 1시간 시뮬).
**교사**(반사실 rollout · 느림) → 라벨 → **학생**(Seller·Buyer 망 · 즉시 추론).
→ [[YR-204]](교사) · [[YR-205]](학생) · [06](06-학습과-판정.md) §1-1

### 남는 위험

| 위험 | 대응 |
|---|---|
| 1시간 절벽 (59분 100% / 61분 0%) | 경계 선형 감쇠 후보 → §4-1 |
| rollout 이 비결정적이면 차가 잡음 | 같은 시드·같은 분기점에서 두 세계를 굴린다 |
| 라벨 눈금이 커져 `Q_SCALE` 이 안 맞음 | 비판정 시드에서 **재실측 후 동결** |

## 3-1. ★지평(H)과 할인율(γ)은 다르다

| | 무엇 | 성격 |
|---|---|---|
| **H (지평)** | **얼마나 멀리 굴려볼까** — 1시간까지 100%, 넘으면 0 | **계산 예산** |
| **γ (할인율)** | **먼 미래를 얼마나 쳐줄까** — 매끄럽게 감쇠 | **가치관** |

`H` 는 굴리기를 멈추는 지점이라 **비용이 직접 걸린다**(3시간 굴리면 3시간치 계산).
`γ` 는 계산 비용과 무관하다.

**우리는 `γ` 를 쓰지 않는다** — 비용이 **실제로 발생한 시간**이기 때문이다. 트럭이
1시간 뒤에 10분 기다렸으면 진짜 10분 손해다. 깎을 근거가 없다. (`γ` 는 무한히
이어지는 문제에서 발산을 막으려고 쓴다. 우리는 하루짜리 유한 문제다. 크레인
정책도 `γ=1` — [[YR-139]] 계약 "유한 에피소드 총비용 정합".)

**대신 절벽이 생긴다**: 59분에 생긴 영향은 100%, 61분은 0%. 거의 같은 두 상황의
라벨이 크게 달라져 **학습이 어려워질 수 있다.** 절충 후보는 경계 근처 선형 감쇠
(예: 50~60분). 근거는 *"60분 절단이 임의적이라 절벽을 없앤다"* 이지 *"먼 미래가
덜 중요하다"* 가 아니다 → [[YR-204]] 착수 시 결정.

### v2 에는 `H` 가 암묵적이었다

**`H` 가 "그 트럭의 체류"로 자동 결정**됐다 — 트럭이 나가면 계산이 끝난다(약 40분).
v3 는 그것을 **명시적 1시간**으로 바꾼다.

## 4. 왜 시야를 못 늘렸나 — 신용 배분

[[YR-170]] 에서 **하루 총비용**을 보상으로 줬다가 실패했다. 21블록이 같은 60초에
동시에 결정하는데 결과가 하나로 뭉쳐 나와 귀속이 안 됐다 —
**행동 귀속 분산 = 0.0000038** (사실상 0).

| | 신용 배분 | 시야 |
|---|---|---|
| 하루 총비용 보상 ([[YR-170]]) | ❌ | ✅ |
| 거래별 추정 (v2 현행) | ✅ | ❌ 40분 |
| **v3 반사실 H=1h** | ✅ **그 거래만 취소** | ✅ **1시간** |

**반사실이 둘을 동시에 준다** — "그 거래 하나만 없앤 세계"와 비교하므로 귀속이
정의상 보장되고, 굴리는 길이는 `H` 로 따로 정할 수 있다. 근거 [[YR-206]].
