> `integrated/sell_credit.py`(진짜 반사실 — **import 0곳**)

**`D_i` 는 그 거래 하나의 공로**다. Φ 가 하루 전체(24시간)를 재는 반면 `D_i` 의
시야는 **약 40분**이다. v3 는 이 잣대를 **추정 공식에서 반사실로** 바꾼다.

```contract
counterfactual_h_s_target = 3600
```

## 1. `D_i` — v2 학습 잣대 (차분 신용)

```
공간:  D_i = R_src − B_dst − ΔC_route          시간:  relief − burden − defer_s/3600
```

`B_dst`(수신 부담) = 자기 비용 + 뒤차 지연(그 시각 대기 수 × 점유시간) + 본선 압력.
`R_src`(소스 절감)도 같은 형태인데 **"남았더라면"이 미관측**이라 실현 서비스 시간을
**대입**한다(가정). 양쪽에 **같은 근사**를 일부러 써서 한쪽만 정밀할 때 생기는 편향을
막는다. 학습 목표 = `−D_i / Q_SCALE`(20.0), KEEP 은 **상수 0**.

**v3 는 값을 만드는 방법만 바꾼다**(§3) — 세 항의 뺄셈 구조는 유지하고, 행위자
둘로 쪼갠다 → [03](03-결정층.md) §3-1.

## 2. ★v2 의 `D_i` 는 독립 검증을 통과했다

시간 판매 1건의 비용을 **해석적으로 유도**하면 14.28분([[YR-171]]), **차분 신용으로
실측**하면 13.75분이다 — **완전히 다른 두 경로가 4% 안에서 만난다**(축 격차도 라벨
+0.2480 vs 모델 +0.2546 로 일치 · `Φ + 신용합` 은 2,413~2,588 로 좁게 모인다).

**그래서 v3 반사실은 "틀린 것을 고치는" 게 아니다.** 지금 식은 자기 가정 안에서
정합적이고, 바꾸는 이유는 **가정 밖(연쇄·재조작·1시간)을 못 본다**는 것이다.

## 2-1. ★v2 의 벽 — 시야 40분 · 그리고 **추정**

`realized_credit` 이 세는 범위는 **전부 "그 트럭 한 대의 방문"(약 40분) 안**이다
(에피소드는 24시간). 그 배치가 만들 **재취급**, 이후 트럭들의 **추가 대기**,
**나중에 꺼낼 때**의 비용은 아무것도 안 센다.

**게다가 값이 실측이 아니라 추정이다** — `blocked_dst × occupy` 는 *"내가 크레인을
잡은 동안 뒤차 N대가 그만큼 밀렸을 것"* 이라는 **가정**이다. **규칙도 근시안**이라
같은 질문에 규칙은 **공식**, RL 은 **근사**로 답한다 — **구조적 우위가 없다.**

## 3. ★v3 변경 ② — 추정에서 반사실로

### 두 걸음이다 — 먼저 [[YR-201]], 그다음 [[YR-204]]

**[[YR-201]]** 진짜 반사실 신용 `D_i = C(i 빼고 **재매칭**) − C(전체 매칭)` — 지금
식은 *"i 가 없었으면 아무 일도 안 일어난다"* 고 보는데 실제로는 **그 자리를 다른
제안이 대신 쓴다**(자기 공로 과대평가). 코드가 이미 있고(`sell_credit.py` · import
0곳) rollout 이 필요 없어 싸다. **[[YR-204]]** 는 거기에 **시간**(H=1h)과 **행위자
분리**를 더한다 — 아래가 그 설계다.

### 하는 일: 안 했을 때의 세계를 **실제로 굴린다**

```
결정 시점 t ─┬─ 그대로 진행 ───────────► Φ_H(했다)
             └─ 그 행동만 바꾸고 진행 ─► Φ_H(안 했다)

이득 = Φ_H(안 했다) − Φ_H(했다)        H = 1시간
```

**추측이 없다.** 두 세계를 같은 시드로 1시간씩 굴려 총비용을 재고 뺀다.
"밀렸을 것이다"가 "실제로 밀렸다"로 바뀐다.

**⚠️ 창 밖 효과는 못 본다** — 2시간 뒤 칸으로 이연하면 Φ 가 factual 과 **정확히
같아** 라벨이 0 이 된다(2026-08-22 실측). 이연 칸을 H 안으로 묶든 H 를 늘리든
결정이 필요하다 → [[YR-216]].

### ★행위자마다 자기 이진 반사실을 갖는다 ([03](03-결정층.md) §3-1)

v3 는 Seller·Buyer 가 **독립 행위자**다. 그래서 하나의 `D_i` 를 두 조각으로
쪼개는 게 아니라, **행위자마다 자기 선택지 둘을 굴린다.**

| 행위자 | 굴리는 두 세계 | 라벨 |
|---|---|---|
| **Seller** | `Φ_H(KEEP)` vs `Φ_H(SELL)` | 내놓아서 번 것 |
| **Buyer** | `Φ_H(REJECT)` vs `Φ_H(BUY)` | 받아서 치른 것 |

같은 snapshot·같은 난수에서 갈라 굴린다. 선택지가 **둘뿐**이라 회귀로 각 세계의
비용을 배우고 **싼 쪽을 고르면** 끝이다 — PPO 도 critic 도 필요 없다.

**★두 라벨을 더하면 `D_i` 가 되지 않는다. 그게 정상이다.** 각자 "내가 행동을
바꿨다면"을 재는 것이라 **겹치는 몫이 양쪽에 다 들어간다.** 그래서 실제 목적함수
Φ 에는 **일어난 일(factual)만 한 번** 기록하고 **actor 비용은 합산하지 않는다**
([[YR-204]]·[[YR-205]] 계약). 합치면 이중 계상이다.

**`KEEP_Q = 0` 이라는 고정 기준점도 필요 없어진다** — v2 는 KEEP 을 상수 0 으로
두고 다른 좌표를 상대적으로 쟀지만, 이제 KEEP 세계도 **직접 굴려 값을 잰다**.

### ★독립 계산인데 실제 세계와 어긋나지 않으려면

행위자가 각자 굴리면 **일어날 수 없는 세계**로 라벨을 만들 위험이 있다. 셋을 못박는다.

**① 상대는 가정하지 않고 정책을 그대로 굴린다.** Seller 의 `SELL` 가지에서
"Buyer 가 받아준다"고 가정하면, 실제로 거절당한 경우 그 세계는 **도달 불가능**하다.
그래서 offer 를 내고 **Buyer 정책이 실제로 응답하게** 굴린다. Buyer 의 반사실은
**실제로 온 offer 를 조건으로** 한다. COMA(Foerster 2018)의 "남은 고정, 나만 바꾼다"를
순차 게임에 맞춘 형태다 — Buyer 행동이 Seller 선택에 의존하므로 **행동이 아니라
정책**을 고정한다.

**② factual 을 공유해 세계가 넷이 아니라 셋이다.**

| 실제로 일어난 일 | Seller 라벨 | Buyer 라벨 |
|---|---|---|
| `KEEP` | factual vs `SELL`→Buyer 응답 | **없음** (물어보지도 않았다) |
| `SELL ∧ BUY` | factual vs `KEEP` | factual vs `REJECT` |
| `SELL ∧ REJECT` | factual vs `KEEP` → **≈ 0** | factual vs `BUY` |

`SELL ∧ REJECT` 에서 Seller 라벨이 0 에 가까운 것은 **맞다**(제안했다 거절당하면
세상이 안 바뀐다). 그것도 배울 정보다 — "이 상황에서 내놓으면 거절당한다".

**③ 상대가 학습하면 내 라벨도 낡는다.** 라벨은 **그 시점 상대 정책 기준**이므로
**회차마다 다시 만든다** — v2 의 150,000 FIFO 버퍼는 라벨이 **직접 관측**이라 안
상했기에 가능했다. 반사실 라벨에는 **유효기간이 있다.**

### 기계로 검사한다 — 동일성 불변식 (★2026-08-22 정정)

**Φ 로는 못 잰다.** 분기 세계는 `t+H` 에서 세상이 끝나 경계 근처 서비스가 실제와
달라진다(실측 +0.05~15.7% · 창 안 Φ 가 작은 새벽일수록 큼). 대신 factual 가지가
**같은 결정**(판매 행동·좌표·구매 응답)을 내는지 본다. 절단분은 세 세계가 **공유
하는 상수**라 차이에서 상쇄된다 — 한쪽만 안 자른 값을 쓰면 그게 곧 편향이다.
이 검사가 실제로 결함 넷을 잡았다 → [[YR-215]].

| | v2 (추정) | v3 (반사실) |
|---|---|---|
| 뒤차 지연 | 대기 수 × 점유시간 **가정** | 실제로 굴려서 **측정** |
| `R_src` "남았더라면" | 실현 서비스 시간 **대입** | 그 세계를 **진짜 굴림** |
| 재취급·크레인 이동 · 연쇄 | ❌ 안 셈 | ✅ **1시간 안이면 자동으로 잡힘** |

**빠진 비용항 일부가 저절로 해결된다** — 재조작이 일어나면 크레인이 오래 잡히고 그 지연이 다음 트럭 대기로 **Φ 에 나타난다**(**며칠 뒤 꺼낼 때**는 H 밖이라 없다).

### 값이 얼마나 드나 · 왜 1시간인가

**H 가 곧 배수**다(40분 ×1 · **1시간 ×1.5** · 3시간 ×4.5). **사용자 결정: H = 1시간**
— 오더 1건마다 발생하는 데다 **거래당 세계가 셋**이라 여유가 없다. **실측(2026-08-22)**:
세계 1개 ≈ 4.8초(복제 0.6 + 재생 1.4~7.9)라 3,500건 전수는 **회차당 14시간** —
불가능하다. 회차마다 K건만 표본한다([[YR-215]]). **배포 때는 못 쓴다** — **교사**
(rollout·느림) → 라벨 → **학생 둘**(즉시) → [06](06-학습과-판정.md) §1-1

### 남는 위험

| 위험 | 대응 |
|---|---|
| 1시간 절벽 (59분 100% / 61분 0%) · 창 밖 이연 라벨 0 | 경계 선형 감쇠 후보 → §4-1 · [[YR-216]] |
| rollout 이 비결정적이면 차가 잡음 | 같은 시드·같은 분기점 · 동일성 불변식으로 검사 |
| 라벨 눈금이 커져 `Q_SCALE` 이 안 맞음 | 비판정 시드에서 **재실측 후 동결** |
| 두 행위자가 서로를 바꾸면 라벨도 바뀜(비정상성) | 반사실이 **그 시점 정책 기준**이라 회차마다 라벨을 다시 만든다 |

## 3-1. ★지평(H)과 할인율(γ)은 다르다

| | 무엇 | 성격 |
|---|---|---|
| **H (지평)** | 얼마나 멀리 굴려볼까 — 1시간까지 100%, 넘으면 0 | **계산 예산** |
| **γ (할인율)** | 먼 미래를 얼마나 쳐줄까 — 매끄럽게 감쇠 | **가치관** |

`H` 는 굴리기를 멈추는 지점이라 **비용이 직접 걸리고**, `γ` 는 계산 비용과 무관하다.

**우리는 `γ` 를 쓰지 않는다** — 비용이 **실제로 발생한 시간**이기 때문이다. 트럭이
1시간 뒤에 10분 기다렸으면 진짜 10분 손해라 깎을 근거가 없다(`γ` 는 무한 문제의
발산을 막는 장치이고, 우리는 하루짜리 유한 문제다. 크레인도 `γ=1` — [[YR-139]]).

**대신 절벽이 생긴다**: 59분 영향은 100%, 61분은 0%. 절충 후보는 경계 근처 선형
감쇠(50~60분)이고, 근거는 *"60분 절단이 임의적"* 이지 *"먼 미래가 덜 중요"* 가
아니다 → [[YR-204]] 착수 시 결정.

### v2 에는 `H` 가 암묵적이었다

**`H` 가 "그 트럭의 체류"로 자동 결정**됐다 — 트럭이 나가면 계산이 끝난다(약 40분).
v3 는 그것을 **명시적 1시간**으로 바꾼다.

## 4. 왜 시야를 못 늘렸나 — 신용 배분

[[YR-170]] 에서 **하루 총비용**을 보상으로 줬다가 실패했다 — 21블록이 같은 60초에
동시에 결정하는데 결과가 하나로 뭉쳐 나와 귀속이 안 됐다(**행동 귀속 분산 =
0.0000038**, 사실상 0).

| | 신용 배분 | 시야 |
|---|---|---|
| 하루 총비용 ([[YR-170]]) | ❌ | ✅ |
| 거래별 추정 (v2) | ✅ | ❌ 40분 |
| **v3 반사실 H=1h** | ✅ **내 행동만 바꿈** | ✅ **1시간** |

**반사실이 둘을 동시에 준다** — 귀속이 정의상 보장되고 길이는 `H` 로 따로 정한다.
