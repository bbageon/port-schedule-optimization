## 검증 방법

각 문서 끝에 **`검증`** 절이 있다. 거기 적힌 명령을 돌려 문서의 수치가 코드와
맞는지 확인한다. 전체 검증은:

```bash
PYTHONPATH=src python .claude/docs/architecture/verify_architecture.py
```

## 이 문서를 고쳐야 할 때

- 코드를 바꿔 구조가 달라졌을 때 — **같은 커밋에서** 이 문서도 고친다
- 교차검증에서 불일치가 나왔을 때 — 어느 쪽이 옳은지 판정하고 양쪽을 맞춘다
- **결과를 보고 고치지 않는다** — 판정 계약은 사전등록이 정본이다
