## 1. YR-317-a — 기록 정합과 독립성

정본 원고·제출 PDF·학습 코드·체크포인트·환경 설정·원자료를 해시로 연결한다.
YR-298의 제출 시점 확인은 같은 원고임이 입증된 뒤에만 태그로 남긴다.
학습 난수는 환경 생성, 신경망 초기화, 탐색, 미니배치 추출로 나눠 실제 값과 저장 상태를 기록한다.
예전 체크포인트 재평가는 가능하지만, 그 가중치를 seed 하나로 다시 학습할 수 있다는 주장과 구분한다.
공통 난수는 정책 실행 중 난수 호출 횟수와 분리한다. 같은 트럭·선박·서비스 난수를
고유 사건에 묶어, 정책이 달라도 외생 입력이 같다는 검사를 통과해야 한다.

표본 단위는 **독립적으로 만든 연속 실행 전체**다. 하루는 그 실행에 속한 반복 관측이다.
기존 28일 부호검정을 Wilcoxon(차이의 크기 순위도 쓰는 검정)으로 교체하는 것만으로 해결되지 않는다.
다른 시드로 만든 달끼리 초기 재고·서비스 난수까지 독립인지 검사한다.

## 2. YR-317-b — 시간 이동을 실제 예약으로 평가

코드에는 슬롯 정원 인자가 있지만 기본값은 빈 사전이다. 기존 월 실행에 정원을 넣은 증거가 없다.
따라서 정원 인자의 존재와 실험 중 제약의 작동을 구분한다.

**첫 축: 예약 장부·정원.** 기존 예약과 변경 예약을 함께 세고, 한 시간대에 여러 제안이
몰려도 합계가 정원을 넘지 않도록 확정 시점에 검사한다. 원래 슬롯 반환·대상 슬롯 점유를
함께 처리하고 날짜 경계와 취소에도 장부가 보존되는지 확인한다. 임의로 대기 차량을 삭제하지 않는다.
기준선도 같은 예약·대기·거절 규칙을 적용받아야 한다.

정원은 실측 처리능력이나 공개 자료의 범위로 먼저 보정한다. 제안 민감도는
기준 정원의 0.8배/1.0배/1.2배이며, 근거 없는 세 숫자 자체를 현실 검증으로 부르지 않는다.
처음부터 정원을 넘는 예약은 별도 명시한 대기·이월 규칙으로 처리하고 총수요를 보존한다.

**둘째 축: 변경 가능성.** 원래 예약과 변경 시각, 통지 시각, 운송사 가능 시간대를 저장한다.
최소 통지 여유와 최대 이동 폭은 각각 다른 변수다. 현행 30분 재검토 창·15분 격자·최대 2시간
이연은 모든 차량에 같은 통지 여유를 보장하지 않는다. 늦게 통지된 차량의 자격과 이동 가능성을 직접 검사한다.
취소·거절·변경 횟수, 변경한 대수, 대당 이동 시간과 불가능 제안 비율을 보고한다.

**셋째 축: 비용 누락.** 현행 비용은 게이트 진입 이후 대기·장비 이동·재취급·본선 유휴다.
게이트에 오기 전의 일정 이동을 공짜로 취급할 수 있으므로 원래 예약을 기준으로 다음 항을 분리한다.

`평가 비용 = 기존 터미널 비용 + 일정 변경 부담 + 기존 항에 없는 외부 대기 부담`.

일정 변경 부담은 변경 건당 고정비와 이동 시간당 단가로 구성하는 것을 제안한다.
운송사가 차량을 다른 일에 쓸 수 있는 시간과 실제 공회전 대기는 구별한다.
같은 시간을 기존 체류 비용과 두 번 청구하지 않는다. 실제 대기료와 기회비용을 같은 것으로 단정하지 않는다.
단가 자료가 없으면 0과 문헌·협의로 정한 범위를 민감도로 제시하고, **손익분기 단가**
(그보다 변경 부담이 크면 절감이 사라지는 금액)를 함께 제시한다.

고정 정책의 사후 비용 재계산은 강건성 진단이다. 새 비용을 최적화했다고 주장하려면
그 비용으로 라벨·학습·평가를 일치시킨 단일축 재학습이 필요하다.
최종 잠금평가 전에 정원→가능 시간→비용을 차례로 확인하고 같은 최종 계약으로 모든 비교군을 평가한다.

## 3. YR-317-c — 두 행동의 비교가 전체 선택으로 이어지는가

현행 `train/labels.py`는 사실·대안 비용의 평균을 두 라벨에서 뺀다.
비용이 C(a), C(b)라면 각각 `(C(a)-C(b))/2`, `(C(b)-C(a))/2`다(단위 눈금 제외).
한 쌍 내부에서는 차이가 보존된다. **쌍마다 평균이 다르면 다른 쌍의 점수까지 같은 기준이 되지는 않는다.**

예를 들어 실제 비용이 a=0, b=2, c=100일 때 a-b 비교에서 a의 라벨은 -1,
b-c 비교에서 b의 라벨은 -49다. 이 둘을 그대로 비교하면 b를 더 싸게 본다.
이는 학습된 망이 반드시 이렇게 오작동한다는 증명이 아니라, 쌍 내부의 상수 차감만으로
전체 순위를 보장하는 논증이 불충분하다는 반례다. 같은 b의 목표도 상대에 따라 달라진다.

**먼저 진단한다.** 별도 진단 시드에서 부하·행동 종류·후보 수를 층화해 결정 상태를 표집한다.
제안 규모는 300개 상태이며, 계산 예산을 재고 결과를 보기 전에 고정한다.
각 상태에서 KEEP(그대로 두기)을 포함한 모든 합법 후보를 같은 외생 난수와 같은 후속 정책으로
분기 실행한다. 비교 중 다른 망·다른 미래정보를 섞지 않는다. 후보를 일부만 재면 전역 최적을 재었다고 쓰지 않는다.
학습·검증은 상태와 시드 단위로 분리한다. 같은 상태의 후보 행을 양쪽 자료에 나누지 않는다.

보고 지표는 전체 순위 일치도, 최저비용 후보 선택률, KEEP보다 나쁜 선택 비율,
**선택 손실**(고른 후보의 실제 비용−검사한 후보 중 최저 비용)이다.
전체 평균과 혼잡 조건을 나눠, 비용 차이가 거의 없는 후보의 순서 오류도 구분한다.
Buyer(수락망)는 제안 하나에 BUY/REJECT만 비교하므로 Seller(제안망)의 다중 후보 문제와 구별한다.
다만 resolver가 서로 다른 제안의 점수를 다시 비교하는지까지 검사해야 한다.

오류가 재현될 때만 학습 목표 축 하나를 보정한다. 우선안은 모든 후보를 같은 상태의
KEEP 비용과 비교하는 공통 기준 목표다. 대안은 점수 차이를 실제 비용 차이에 맞추는 손실이다.
후보 수집·라벨 연결성이 부족하면 목표 식만 바꿔도 전체 순위는 보장되지 않으므로 이를 함께 진단한다.
입력 특징·수락망·정원·교사 길이를 동시에 바꾸지 않는다. 절대 비용 회귀 복귀는
과거 큰 공통비용에 행동 효과가 묻힌 실패 근거가 있어 첫 선택으로 삼지 않는다.

## 4. YR-317-d — 독립 반복과 구성요소 검증

고정 체크포인트 재평가는 **그 모형의 일반성**, 여러 번의 재학습은 **학습 절차의 안정성**을 묻는다.
두 질문을 구분한다. 예비 규모는 고정 모형 × 독립 20개월, 학습 주장에는 초기화·학습 시드
5개 × 독립 평가 월 시드 10개를 제안한다. 50칸을 독립 표본 50개로 세지 않는다.
학습 반복과 월 난수를 공유하는 교차 구조를 반영해 두 축을 재표집하고, 시드별 원값도 공개한다.
최종 개수는 진단 시드에서 변동과 최소 중요 개선량을 추정해 고정한다. 결과를 보며 늘리지 않는다.

주요 값은 동일한 월의 **후보 총비용−비교군 총비용**이다. 음수이면 이득이다.
월 단위 짝을 통째로 재표집하는 bootstrap(실행 묶음을 다시 뽑아 불확실성을 추정하는 방법)으로
평균 차이와 95% 신뢰구간을 제시한다. 학습 반복을 포함하면 위 교차 의존성도 반영한다.
중앙값·월 승률·각 실행 절감률·총액 가중 절감률도 보조 보고하며 서로 다른 집계임을 밝힌다.
일별 그림은 시간 흐름 진단으로 사용한다. 기존 한 달에 대한 블록 재표집만으로 독립 반복을 대신하지 않는다.
여러 우위 검정을 주장하면 주비교를 하나 고정하고 나머지는 Holm 보정 등 다중비교 규칙을 사전등록한다.
성능 통과는 신뢰구간 전체가 사전에 정한 최소 개선량을 넘고 운영 가드를 모두 통과하는 경우다.

| 비교 | 목적 | 통제 |
|---|---|---|
| 전체 vs 같은 행동 범위의 강한 규칙 | 선택 방법의 가치 | 공간·시간 행동, 관측정보, 용량, 비용 동일 |
| 전체 vs 시간만 | 공간 추가의 실익 | 먼저 같은 가중치에서 행동만 제한; 이어 별도 학습한 시간 전용과 구분 |
| 공간만 vs 재배치 없음 | 공간 단독의 조건별 역할 | 한산·혼잡을 독립 반복하고 장기 비용 포함 |
| 전체 vs 학습된 거절 제거 | 거부 기능의 기여 | 물리 정원·충돌 검사는 유지 |
| 전체 vs 단순 수락 규칙 | 학습된 수락의 추가 가치 | 같은 정보·가능 행동·물리 검사 |
| 전체 vs 같은 출발 가중치의 학습 전 모형 | 학습 기여 | 초기 가중치 저장, 체크포인트 선택은 별도 검증 자료 |

두 별도 망의 구조적 우위까지 주장하려면, 같은 정보·파라미터 예산의 단일 점수 모형과
별도 비교가 필요하다. 거절을 껐을 때 악화했다는 결과만으로 “두 망만 가능하다”는 주장은 하지 않는다.
이 추가 비교는 구조 우위를 주장하기로 할 때만 같은 YR-317-d 명세에 사전등록한다.
이는 비교용 제거 실험이며 운영 정책에 보조 레이어를 더하는 처방이 아니다.

## 5. 수요·비용·운영기간과 경계 효과

기존 혼잡 빈도 2/6/14일 자료는 재사용하되 같은 시드 한 벌임을 명시한다.
추가 축은 빈도를 고정한 혼잡일 연속 배치, 도착 시간대 집중, 선박·트럭 피크 겹침이다.
하나씩 바꾸고 동일한 정책들을 짝으로 돌린다. 임의로 잘 나오는 날만 뽑지 않는다.
처치 후 생긴 혼잡 수준만으로 그룹을 나누면 정책 효과와 섞이므로 외생 수요 조건으로 먼저 층화한다.
실현된 대기열·처리량·재고는 그 상황이 실제로 어떻게 굴렀는지 확인하는 별도 진단이다.

비용 가중치는 트럭/본선/장비/일정 변경을 각각 바꾸고 그 근거 범위를 공개한다.
기간은 30/60/90일을 제안하되 초기화 안정화 기간은 별도 진단 후 고정한다.
같은 긴 궤적의 앞 30/60/90일을 독립 실험 셋으로 세지 않는다.
평가창 끝까지 유입을 유지하고, 비용을 창 밖으로 미루는 효과를 추적한다.
고정 달력창 비용과 원래 예약시각으로 정한 대상 집단의 완료까지 비용을 나눠 보고한다.
후자의 추가 추적 구간은 달력창 주지표에 섞지 않는다. 시간 조정으로 대상 집단 자체가 바뀌지 않아야 한다.
기말 대기와 재고, 미투입·미완료·소실, 본선 보호·물리 유효성을 확인한다.
유입이 계속되는 창의 기말 대기 자체와, 대상 작업을 끝까지 추적한 뒤 미완료가 남는 실패는 구분한다.

혼잡일 상위 4일의 절감 기여율은 실행마다 보고하고 분포를 제시한다.
상위 4일을 제외한 합계는 의존성 진단으로만 쓰며, 혼잡 다음 날의 여파까지 따로 추적한다.
연속 혼잡에서 이득이 유지되고, 종료 직전 이연만으로 이득을 만들지 않아야 장기 효과를 주장한다.

## 6. 외부 타당성과 출처

다중 시드는 합성모형 안에서의 반복성을 높일 뿐 실항만 검증을 대체하지 않는다.
입력 보정 자료와 검증 자료를 분리하고, 도착 시간 분포·체류시간 분포·장치율·크레인 처리량·본선 작업량을
관측 범위와 대조한다. 자료가 없으면 출처별 가정과 민감도 범위를 공개하고 “문헌 보정 시뮬레이션”으로 한정한다.
특정 터미널 성능 주장은 저장소 research-gates가 요구하는 운영 이력 증거를 충족해야 한다.
