# v3 리뷰 대응 — 독립 반복·기여 분해·민감도 실행 설계

2026-09-14 · YR-317-a·d·e·g · [현행 전략](2026-09-14-v3-review-refined-strategy.md).
예약 정원·새 일정 변경 비용·새 제약층은 이번 실험에서 제외한다. 기존 네 비용 항과 환경을 기준으로 한다.

## 1. 평가 전에 통과할 기록 검사

각 실행 계약은 코드 커밋·가중치 해시·정책 종류·난수 목록·수요 일정·기간·비용·설정을 포함한다.
현재 `judge_month._load`는 폴더 안의 `arm_RL.json`만 있으면 재사용한다.
새 실행별 폴더를 분리하고 결과에 계약 해시를 넣어 일치할 때만 이어 돌린다.
자료 없는 과거 가드값을 0으로 채우지 않는다. legacy 자료의 미기록은 미확인으로 표시한다.

월 내부 날짜 시드는 `base + 1000*(day+1)`이다. 월 base만 다르다고 독립이 되지 않는다.
예를 들어 base를 1000 차이로 잡으면 30일 중 29개 날짜 시드가 겹친다.
학습·진단·평가의 **파생 시드 전체 목록**을 비교해 중복을 막고, 같은 달 정책끼리만 공통 난수를 쓴다.
학습 초기화와 탐색도 명시적으로 시딩한다. 재시작 때에는 난수 상태와 체크포인트를 함께 복원한다.
`eval.__main__`의 진단 대역 경고만으로 사용 대역 검사가 된다고 보지 않는다.

## 2. YR-317-g — 동일한 작업 명단이 보존되는지

기존 수락망 평가의 측정 28일에 `truck_skipped`가 전체 745대, 거절 제거 675대,
재배치 없음 1,919대다. 이는 신규 시뮬레이션 없이 기존 JSON에서 재합산했다.
수요별 환경에서도 미투입이 나타난다. 이 수치로 원인이나 비용 편향의 방향을 확정할 수는 없다.

진단 실행에는 모든 요청의 고유 ID와 원래 예약, 실제 투입, 완료, 미투입 사유·시각을 저장한다.
`ann.skips`의 TAIL/NO_TARGET/투입 예외를 각각 구분한다. 선박의 요청·실제 투입과 누락도 저장한다.
일별·월 전체에서 `요청 = 투입 + 미투입`이 맞고, 투입된 작업은 완료 또는 추적 중으로 남아야 한다.
현재 결과의 `n_censored=0`은 이미 들어온 트럭이 남지 않았다는 뜻일 뿐 미투입 0을 보장하지 않는다.
미투입은 비용 0으로 조용히 제외할 수 없다. 기존 하드가드대로 성능 판정을 보류하고 원인을 보정한다.
이는 새 예약 제한을 넣는 일이 아니라 원래 연구 계약을 확인하는 일이다.

날짜별 트럭 비용과 장비 비용의 측정 대상도 맞춘다. 현재 트럭은 `Dxx-` 주문 ID 접두어로 묶이고,
장비·선박은 날짜 경계 누적 차분이다. 주석의 “실제 gate-in 날”과 같은 집합인지 확인한다.
이 혼합 비용을 순수 달력창 적분이라고 설명하지 않는다. 기존 정의로 대표 수치를 재현하되
고정 대상·완료 추적·경계별 미완료를 보조로 보고하여 이연으로 비용을 창 밖에 숨겼는지 확인한다.

## 3. 핵심 반복평가 행렬

예산안: 독립 30일 실행 **20개×8정책=160개 정책-월 실행**. 모든 정책이 같은 20개 명단을 공유한다.
전부 새 코드를 만드는 계획은 아니다. 아래 여덟 중 마지막 비교만 신규 경로가 필요하다.
가중치는 논문 체크포인트로 고정하고 탐색 0, 교사 호출 0, 크레인 규칙 동일이다.
측정은 기존과 같은 가운데 28일로 시작하되 YR-317-g의 집합·경계 검사를 선행한다.

| 정책 | 기존 여부 | 직접 답하는 질문 |
|---|---|---|
| 재배치 없음 `NO_REALLOC` | 있음 | 재배치 자체의 가치 |
| 공간·시간 규칙 `SPACE_TIME_LL` | 있음 | 같은 행동 범위에서 학습된 선택이 나은가 |
| 시간 규칙 `SLOT_LL` | 있음 | 시간 행동을 주기만 해도 생기는 이득과 구분 |
| 전체 `RL` | 있음 | 논문 정책 |
| 시간만 `RL_TIME` | 있음 | 전체 대비 공간 후보 허용의 추가 이득 |
| 공간만 `RL_SPACE` | 있음 | 공간 단독의 이득·손실 조건 |
| 거절권 제거 `RL_NOVETO` | 있음 | 학습된 거절 기능의 가치, 수락망 정렬은 유지 |
| 수락망 완전 제거 | 신규 | 수락망의 거절+정렬 역할 전체의 가치 |

수락망 완전 제거는 망 호출 없이 합법 제안에 응답하고, 중앙 확정은 고정된 제안 키 순서로 처리한다.
블록 물리 용량·소유권·중복·실행 직전 검사는 그대로 둔다. 새 예약 정원을 추가하지 않는다.
거절권 제거와 완전 제거의 차이는 수락 점수에 의한 순서 선택의 효과다.
한 번에 두 기능을 없앤 완전 제거 하나만으로 거절·정렬 각각의 공로를 해석하지 않는다.
경합이 없어서 두 비교가 같으면 그 조건에서는 중앙 점수 역할이 작았다고 보고한다.

주비교는 전체−공간·시간 규칙의 월 비용 차이다. 직접 추가 기여는 전체−시간만,
전체−거절권 제거, 전체−수락망 완전 제거를 보조 확증으로 사전 고정한다.
공간 단독−재배치 없음은 기제 진단이다. `전체`와 `시간만`은 동일 가중치의 후보 제한 비교이며
시간 전용으로 재학습한 최적 정책을 이겼다는 주장은 하지 않는다.

단순 수락 규칙을 더 비교하려면 목표를 먼저 명시한다. 예: 수신 시점의 통지된 혼잡이 출발보다
낮으면 수락하는 기준을 양 축에서 동일하게 쓰고 고정 정렬을 적용한다. 문턱 조정은 진단 자료에서만 한다.
이는 “학습된 수락이 단순 규칙보다 낫다”를 주장할 경우의 추가 한 정책이며 필수 8종에 몰래 섞지 않는다.

## 4. 통계 계약과 표본 수

각 독립 월의 짝차이 `D_m = 전체 비용 − 비교 비용`를 계산한다. 음수이면 전체가 싸다.
같은 월의 모든 정책을 한 묶음으로 10,000번 재표집해 평균 차이와 95% 신뢰구간을 낸다.
원화 평균 차이·중앙·월 승패, 총액 가중 절감률과 월별 절감률 분포를 함께 보고한다.
이 집계들은 서로 다른 질문이므로 가장 좋아 보이는 것만 고르지 않는다.
동점은 승률 분모·동점 수를 명시하며 평균 차이에서는 제외하지 않는다.

여러 확증 비교는 Holm 보정으로 가족 단위 오류율을 관리한다. 효과크기 신뢰구간은
개별/동시 구간인지 표시하고, 단순 bootstrap 부호 비율을 p값으로 바꿔 쓰지 않는다.
필요한 검정은 독립 월 단위의 사전 명시한 검정으로 수행하고 가정과 평균/중앙 중 무엇을 검정하는지 적는다.
성능 게이트는 평균 총비용 차이의 반올림 전 구간과 운영 가드를 사용한다.

20개월은 정밀도 보장값이 아니다. 별도 진단 월 4~6개에서 월 차이의 변동과 실행시간을 추정하고
원하는 오차 폭·최소 중요 개선량으로 최종 표본 수를 정한다. 진단 월은 확증 표본에 넣지 않는다.
월 차이가 극단값에 좌우되면 정규근사 계산만 믿지 않고 bootstrap 구간의 안정성도 진단한다.
결과를 본 뒤 20→30→40으로 늘리는 방식은 쓰지 않는다. 부족하면 미확정으로 보고한다.

## 5. 학습 기여 — 초기 모형을 새로 정의해야 한다

`month-02/ckpt_000.pt`는 **첫날 학습 뒤** 저장됐다. 기존 비교는 초기 학습 단계 대비 추가 학습의 비교다.
기존 문장의 “학습 전”을 정정하고, 옛 무작위 초기값이 남아 있지 않으면 재구성했다고 주장하지 않는다.
현행 학습은 첫·마지막 연결 날에도 라벨이 있으면 fit하므로, 보고 회차 수 역시 실제 업데이트와 대조한다.

새 학습 묶음은 시작 전에 `init.pt`를 저장하고 마지막 모델 선택 규칙을 고정한다.
초기화·학습 수요를 달리한 5회, 각 모형의 초기/최종을 같은 독립 평가 월 10개에 적용하는 예산안이다.
**5회 학습 + 5×10×2=100개 정책-월 평가**다. 기본 160개와 별도이며 중복 실행은 해시 일치 시 재사용한다.
학습에 쓰는 환경·정책·목표·회차·라벨 예산은 고정한다. 성적을 보고 좋은 체크포인트를 고르지 않는다.
초기/최종 비용 차이 행렬에서 학습 반복과 평가 월을 각각 다시 뽑는다. 50칸을 독립 50회로 세지 않는다.
5회만으로 학습 분산을 정밀하게 알기는 어려워 각 학습 시드의 결과도 전부 보여 준다.
과거 학습 1회는 기록상 17.79시간이었다. 장비·혼잡 조건이 바뀌면 달라지므로 새 예산은 계측 후 고정한다.

## 6. 혼잡일 편중·수요·기간

우선 기본 반복에서 추가 시뮬레이션 없이 수요별 비용, 혼잡 뒤 1~3일 누적 차이, 상위 4일 집중도를 낸다.
상위 4일의 양의 절감 합/모든 양의 절감 합과 원 논문의 순절감 대비 비율을 구분한다.
순절감이 0에 가깝거나 음수이면 기여율이 폭증하므로 비율만 보고하지 않는다.
혼잡 나흘을 빼고 재계산한 결과는 강건성 진단이지 그날을 없앤 세계의 인과 효과가 아니다.

별도 수요 축은 **혼잡 빈도 고정·배치 순서 변경**을 우선한다. 같은 28일 수요 다중집합을
분산 배치/연속 배치로 만들고, 연속 파도의 월 위치를 시드에 따라 사전 균형 배정한다.
예산안: 6독립 명단×2배치×전체·시간만·재배치 없음 3종=36개 월 실행.
일일 선박·트럭 구성과 날짜 난수가 함께 바뀌면 순서 효과 외의 차이가 섞이므로
동일한 일일 외생 사건 묶음을 시간 이동해 배치하는 기능이 필요하다. 월 컨테이너 ID·시간 계약도 검증한다.
기존 혼잡 빈도 2/6/14일 자료는 별도 통제 실험으로 제시하며 독립 84일로 합치지 않는다.

기간 축은 우선 30일과 90일을 같은 계약으로 비교한다. 60일은 추세가 꼭 필요할 때 사전 포함한다.
예산안: 6독립 긴 명단×3정책의 90일 실행. 그 안의 30/60/90일 관측은 **서로 의존하는 부분창**이다.
기간별 1일 평균 비용·도착/완료·재고·대기열 기울기와 경계 뒤 잔여를 보고한다.
원래 30일 실행은 끝이 달라 사건 진행이 바뀔 수 있으므로 긴 실행의 앞 30일과 동일하다고 가정하지 않는다.
같은 초기화 안정화 길이를 고정하고, 앞뒤 제외의 수치도 실제 측정 일수로 보고한다.
교사의 3시간→6시간 변경과 운영기간 연장은 다른 질문이다. 철회된 v4 교사 실험은 v3 근거로 쓰지 않는다.

## 7. 기존 비용 가정의 민감도 — 새 일정 비용 제외

저장된 `c_wait, c_move, c_rehandle, c_vessel`를 이용해 기존 항의 가중치를 한 번에 하나씩
0.5/1/2배로 재합산한다. 1배는 공통이라 기본+4항×2변형=9개 비용 평가다.
고정 정책의 실행은 그대로이므로 신규 시뮬레이션이 필요 없고, 목적함수가 바뀌어도 최적으로 학습됐다는 주장은 하지 않는다.
네 항을 같은 비율로 바꾸는 것은 순위를 바꾸지 않으므로 별도 실험으로 세지 않는다.
이는 설계 단가에 대한 강건성 검사다. 단가 범위가 실측됐거나 실제 지출을 보장한다는 뜻은 아니다.
시간 문턱·비선형 비용 형태를 바꾸려면 트럭별 시간이 필요하다. 일일 평균·상위 분위수만으로 복원하지 않는다.

## 8. 표·재현성·처리시간 산출

주표: 독립 월 비교의 비용 차이·구간·승패와 실패 건수.
제거 비교표: 공간 후보·거절·수락망·초기/최종의 직접 차이.
보조 그림: 실행별 분포, 혼잡 파도 후 누적 비용, 기간별 대기열·처리량, 비용 가중치 민감도.
처리시간표: 입력 동기화 포함 전체 review와 후보·망·중앙 확정 구간, 부하·후보 수·거래 유무별 분포.
비어 있는 결정주기로 속도가 좋아 보이지 않게 비어 있음/제안 있음 결과를 별도로 보고한다.
실행시간 계측을 반복평가에 붙일 경우 값 비교에 사용되는 상태·가중치·동점 순서가 바뀌지 않는지 검사한다.
