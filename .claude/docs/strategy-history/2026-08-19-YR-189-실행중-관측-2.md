## 관측 4 — 두 번째 배포 점검(iter 7)이 첫 번째(iter 4)와 엇갈린다

같은 조건(대역 9,900,020~ · 3시간창 · 2일 · σ=0·ε=0)으로 iter 7 체크포인트를
다시 두드렸다. 체크포인트는 사본으로 고정해 학습이 덮어쓰지 않게 했다.

| | iter 4 | iter 7 |
|---|---|---|
| 공간 판매 | 336 | **145** |
| **시간 판매** | 142 | **258** |
| 제안 | 741 | 673 |
| `q − greedy` | −54.0 (−46.7, −61.3) | **−7.7** (−42.9, +27.6) |
| `q − K` | −13.9 (+14.9, −42.7) | **+32.4** (+18.7, +46.2) |
| 버퍼 RMSE | 0.0331 | 0.0272 |

**Φ 차이는 잡음일 수 있다** — 2일·3시간창이고 일별 편차가 ±40 이다.
**그러나 판매 구성 변화는 잡음이 아니다** — 약 3,800건의 결정 위에서 공간이
반으로 줄고 시간이 두 배가 됐다. **손해 축(시간)을 더 고르는 쪽으로 이동했다.**

### 이것이 뜻하는 것

같은 구간에 **학습 목표(버퍼 RMSE)는 계속 좋아졌다.** 즉 **학습이 개선되는데
배포 결정은 그렇지 않다.** 이는 [관측 2](#관측-2--학습-곡선으로는-배포-모드를-볼-수-없다-iter-13-정체) 에서
결과를 보기 **전에** 적어둔 위험 — 버퍼의 상태 분포가 "마구 파는 정책"의
것이라 argmin 이 만드는 한산한 상태를 모델이 못 본다 — 이 실제로 나타난
모습으로 보인다.

그리고 이것은 논문 `03-한계와-주장-범위.md` §4("최적화 대상과 배포 대상이
어긋나 있다")가 **형태를 바꿔 재등장**한 것이다.

| | 어긋남의 정체 |
|---|---|
| 구 PPO | **추첨 정책** 의 기대수익을 최적화하는데 배포는 **최선 고르기** |
| Q 전환 | 그 불일치는 사라졌다 — 목표가 곧 argmin 이 읽는 값이다 |
| **여기서 남은 것** | **상태 분포** — 버퍼는 탐색 정책의 세계, 배포는 argmin 의 세계 |

→ [[YR-193]](탐색 어닐링)이 이 축을 겨냥한다. **지금 바꾸지 않는다**(사전등록 §8).

### 판정 해석에 미리 못박아 둘 것

이 관측은 판정 결과가 어느 쪽으로 나오든 **그대로 보고한다**.

- 판정이 좋게 나오면: 3시간창 점검이 22시간 계약을 대표하지 못했다는 뜻이다.
- 판정이 나쁘게 나오면: **원인 후보가 이미 특정돼 있다**(상태 분포 어긋남).
  "더 학습하면 나아지는가"에 대한 답이 **"이 설정에서는 아니다"** 로 기울며,
  [[YR-183]] 이 물었던 질문이 회차 수가 아니라 **탐색 설계**의 문제로 옮겨간다.

## 관측 5 — iter 10 에서 버퍼가 상한에 닿았다 (설명력 급락은 고장이 아니다)

| | iter 9 | iter 10 |
|---|---|---|
| 표본 | 147,878 | **150,000 (상한)** |
| 목표 RMS | 0.0408 | **0.0233** |
| RMSE | 0.0258 | 0.0188 |
| RMSE / 목표RMS | 0.633 | **0.807** |
| 설명력 | 0.599 | **0.349** |

`BUFFER_MAX = 150_000` 에 닿아 **FIFO 로 가장 오래된 표본을 버리기 시작**했다.
버려진 것은 iter 0 의 극단 라벨(원단위 −45~+127)이다. 그래서 남은 표본의 분산이
절반으로 줄고, 같은 오차라도 "설명한 비율"이 낮게 나온다.

**설명력 0.60 → 0.35 는 학습 고장이 아니다** — RMSE 는 오히려 0.0258 → 0.0188 로
개선됐다. 지표의 분모가 바뀐 것이다.

**그러나 [관측 4](#관측-4--두-번째-배포-점검iter-7이-첫-번째iter-4와-엇갈린다) 의 우려를
강화한다**: 버퍼가 이제 **최근 정책 데이터만** 남게 되어 좌표 공간의 다양성이
줄어든다. iter 0 의 "아무것도 모르던 시절의 넓은 탐색"이 통째로 사라진다.

`BUFFER_MAX` 는 사전등록 §4 동결값이므로 **이번 판은 그대로 간다.**
"오래된 극단 표본을 남기는 표집"(우선순위 재생·계층 표집)은 [[YR-193]] 과 같은
축(탐색·데이터 다양성)이므로 그 spec 에 함께 검토 대상으로 적는다.

## 관측 6 — ★원인 규명: 축별 라벨 분포가 다르고 모델이 비용을 과대예측한다

[관측 4](#관측-4--두-번째-배포-점검iter-7이-첫-번째iter-4와-엇갈린다) 의 구성 변화
(공간 반토막·시간 두 배)가 **모델 문제인가 보상 정의 문제인가**를 갈랐다.
iter 7 체크포인트로 한 판 돌려 라벨을 좌표 종류별로 집계했다
(비판정 대역 9,900,031 · 3시간창 · 학습과 같은 탐색 강도).

### 결과 — 두 축이 완전히 다른 문제를 갖는다

| 축 | n | 라벨 **실제 이득** 비율 | 모델 **팔겠다** 비율 | 라벨 **정확히 0** | 편향 |
|---|---|---|---|---|---|
| 공간 | 1,447 | **48.1%** | **5.9%** | 2.6% | **+0.768** |
| 시간 | 991 | **9.3%** | **15.1%** | **38.6%** | +0.564 |

**모델이 좋은 축은 과소, 나쁜 축은 과대 판정한다.** 이것이 관측 4 의 구성 변화
(공간 336→145 · 시간 142→258)를 그대로 설명한다.

### 축 구분 자체는 학습됐다 (이건 문제가 아니다)

라벨 격차(시간−공간) **+1.4442**, 모델이 배운 격차 **+1.2401** — 방향·크기가 맞다.
**차분신용 라벨이 축 비대칭을 직접 측정한 것은 이번이 처음**이다. 지금까지는
해석적 유도값(+14.28분/건, [[YR-171]])뿐이었다. 실측: 시간 판매 1건 = 약
**+1.45 비용시간 손해**(본선 압력 10배 가중·뒤차 지연 포함이라 분 단위 유도값보다 크다).

### 기전 ① 공간 축 — 편향이 신호보다 크다

| | 원단위 |
|---|---|
| 공간 라벨 표준편차 (신호 폭) | 0.36 |
| 모델 편향 | **+0.768** |

**편향이 신호 폭의 2.1배다.** 결정 규칙이 `Q < 0` 이라는 **딱딱한 문턱**이므로,
모든 예측이 0.77 올라가면 KEEP 기준점이 사실상 −0.77 로 옮겨간 셈이고
**실제로 이득인 판매(48.1%)의 대부분을 거부**한다(통과 5.9%).

원인 가설: 시간 축의 큰 양수 꼬리(p90 **+4.72** · 표준편차가 공간의 6.8배)를
**같은 망이 공유 은닉층으로** 맞추려는 압력이 공간 예측까지 위로 민다.
후버 β=1 은 이 눈금에서 거의 전부 제곱 영역이라 큰 값에 강하게 끌린다.

### 기전 ② 시간 축 — **미측정을 0으로 가르쳤다**

시간 라벨의 **38.6%가 정확히 0**이다. 이는 "비용 0"이 아니라 **측정 실패**다
(`realized_credit` 은 `service_start`·`job_done`·`gate_in` 이 없으면 0 을 준다 —
"미완 — 채점하지 않는다(0 = KEEP 과 동일)"). 공간은 2.6% 뿐이다.

그런데 **0 은 KEEP 과 같은 값**이다. 모델은 "시간 판매의 40%는 공짜"로 배운다.
이 0 들이 예측을 아래로 끌어당겨 시간 좌표가 `Q<0` 이 되게 한다(통과 15.1%,
실제 이득은 9.3%).

**[[YR-174]] 가 물려준 "미완 = 0" 설계가, 이점 정규화로 흐려지던 PPO 와 달리
딱딱한 0 문턱을 쓰는 Q 채점에서는 직접 해를 끼친다.**

### 확인이 필요한 것 (돌리는 중)

이 진단은 **3시간창**이라 미측정률이 절단(censoring)으로 부풀려졌을 수 있다 —
창 끝에서 +15분 이연된 트럭은 당연히 미완이다. 판정은 22시간이므로 **같은
진단을 22시간 계약으로 재실행**했다. 결과는 관측 7 에 적는다.

### 조치 (이번 판은 그대로)

사전등록 §4 동결이므로 **아무것도 바꾸지 않는다.** 수정 방향은 별도 row 로:
①미측정 라벨을 표본에서 **제외**(0 으로 가르치지 않기) ②후버 β 를 라벨 눈금에
맞추기 ③축별 출력 헤드(자는 여전히 하나 — 정책·배정기가 공유하므로).

## 관측 7 — ★관측 6 을 정정한다: 3시간창이 만든 인공물이었다

같은 진단을 **22시간 판정 계약**으로 다시 돌렸다(비판정 대역 9,900,032 ·
iter 7 체크포인트 · 같은 탐색 강도).

| | 3시간창 (관측 6) | **22시간창 (판정 계약)** |
|---|---|---|
| 표본 | 2,438 (공간 1,447 · 시간 991) | 3,689 (공간 1,465 · 시간 2,224) |
| 공간 편향 | +0.768 | **+0.040** |
| 시간 편향 | +0.564 | **+0.047** |
| 시간 라벨 "정확히 0" | **38.6%** | **4.2%** |
| 공간 라벨 "정확히 0" | 2.6% | 5.9% |
| 시간 라벨 평균 | +1.4525 | **+0.2292** |
| 공간 라벨 평균 | +0.0083 | **−0.0188** |
| 공간 예측<0 / 라벨<0 | 5.9% / 48.1% | **42.0% / 48.1%** |
| 시간 예측<0 / 라벨<0 | 15.1% / 9.3% | **9.4% / 17.0%** |

### 정정 3건

1. **"모델이 비용을 +0.78 과대예측한다" — 틀렸다.** 판정 계약에서 편향은
   **+0.040** 이고 공간 라벨의 폭(표준편차)은 0.37 이다. **잘 보정돼 있다.**
2. **"미측정을 0 으로 가르쳤다(38.6%)" — 창 끝 절단(censoring) 인공물이었다.**
   22시간에서는 **4.2%** 다. 관측 6 에서 이 가능성을 명시하고 확인한 것이 맞았다.
3. **"좋은 축은 과소, 나쁜 축은 과대 판정" — 방향이 반대다.** 공간은 실제 이득
   48.1% 중 **42.0%** 를 잡아내고(잘 잡는다), 시간은 17.0% 중 **9.4%** 만
   팔겠다고 해서 **보수적**이다.

### 따라서 관측 3·4 도 신뢰할 수 없다

배포 점검 두 판(iter 4 · iter 7)은 **같은 3시간창**에서 나왔다. 구성 변화
(공간 반토막·시간 두 배)와 `q − greedy` 의 엇갈림은 **창 절단이 두 축을
비대칭하게 왜곡한 결과**일 수 있다. 판정(22시간 · 16일 · CI)이 유일한 근거다.

**교훈**: 짧은 관측창은 **비용의 크기만 줄이는 게 아니라 축 사이의 비율을
바꾼다.** 시간 이연은 트럭을 창 밖으로 밀어내므로 시간 축이 크게 절단된다.
배선 점검은 짧은 창으로 하되 **정량 비교는 하지 않는다.**

### ★강한 검증 하나 — 두 독립 방법이 같은 값에 도달했다

22시간 계약에서 **시간 판매 1건의 실측 비용 = +0.2292 비용시간 ≈ 13.8분**.
[[YR-171]] 이 비용식에서 **해석적으로 유도**한 값은 **+14.28분/건**이었다.

| 방법 | 값 |
|---|---|
| 비용식 유도 (YR-171 · 2026-08-13) | +14.28 분/건 |
| **차분신용 실측 (여기 · 2026-08-19)** | **+13.75 분/건** |

완전히 다른 두 경로가 4% 안에서 만난다. 축 격차도 라벨 **+0.2480** vs 모델이
배운 **+0.2546** 으로 맞는다. **[[YR-174]] 분해식의 첫 독립 검증**이다
(관측 1 의 정황과 함께 [[YR-194]] 가 엄밀화한다).

### YR-193 의 전제는 약해졌다 (그러나 σ 산술은 유효)

관측 4 가 흔들리므로 "상태 분포 어긋남이 **실제로 해를 끼쳤다**"는 증거는 사라졌다.
그러나 **σ 가 신호보다 훨씬 크다는 산술은 그대로다** — iter 13 에서 목표 RMS
0.0230 vs σ 0.20 = **8.7배**. [[YR-193]] 근거를 "성능 악화 관측"에서
**"탐색 강도 설계 오류"** 로 바꾼다.
