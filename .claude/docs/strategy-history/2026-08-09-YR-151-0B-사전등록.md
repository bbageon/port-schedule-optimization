# 2026-08-09 — YR-151 0B(판매 신호 예선) 사전등록 (결과 열람 전 동결)

사용자 확정(2026-08-09): "0B 예선 → GO 면 본 학습 → 최종 비교(K/Q30/S)" 순서 승인.
본 문서가 0B 의 동결 원본이다 — 실행 후 어떤 항목도 바꾸지 않는다.

## 질문

**"판매(블록 간 이송·재예약)로 얻을 이득 신호가 이 터미널에 존재하는가?"**
없다면 그것도 유효한 연구 결론이다(STOP 박제·완화 금지).

## 무대·시드 (동결)

- 셀: **w5-L100 · w5-L150** (YR-157 3시드 안정 BUSY 재현 셀 — 성능 주판정 무대)
- 개발 시드: 셀당 5개 — `cell_seed(w,L) + 10,000,000 + r×1,000,000` (r=0..4),
  배경 시드 동률 이동. **평가(잠금) 시드뱅크와 분리** — 잠금 밴드는 본 학습 후
  별도 등록하며 이 대역(+10M~+14M)을 제외한다.
- 실행: shadow dry-run(본 실행 불변 — `0808f45` 실측 검증 승계), 판매 정책 =
  미학습 TransferHead(초기화 시드 7,000,000 고정·sample=True), 실행 정책 = 채택
  PPO(C0+StateNorm+가드, 해시 봉인), 관측창 = 정본(워밍업 1h+측정 4h), 오차 0
  (무오차 조건 한정 — YR-162B 전까지 주장 한정 문구 의무).

## 판정 2축 (동결 — 둘 다 통과해야 GO)

1. **상금 존재**: 10런 **전부**에서 would-commit ≥ 1 **그리고** 시드별 상금
   Σ(−ΔJ) > 0. ΔJ = resolver 가 선택한 좌표의 계산 순비용(음수=이득 — KEEP=0 을
   이겨야 선택되므로 구성상 음수이나, 발화 자체가 0 인 시드가 있으면 실패).
2. **구분력**: 공개 정보가 "이득 큰 제안"을 구분하는가 — 전 런 합동(pooled)
   would-commit 에 대해 **소스 블록 혼잡 특징(내부/10 + 통근중/10, 결정 시점
   TransferHead 행 값)과 이득(−ΔJ)의 Spearman 순위상관 ρ ≥ 0.2**.
   근거: 판매 이득의 이론 원천이 볼록 비용의 블록 간 혼잡 격차이므로, 공개 혼잡
   신호와 이득이 무상관이면 학습이 잡을 손잡이가 없다. 임계 0.2 = "약하지만
   체계적인" 통상 하한(사전 동결 — 결과 보고 조정 금지).

## GO/STOP 규칙 (동결)

- **GO** = 축 1·2 모두 통과 → Q30 동결본 등록 → 본 학습(초기화 3개) → K/Q30/S.
- **STOP** = 하나라도 실패 → 그대로 박제. 후속은 "완화 재시도"가 아니라 원인 규명
  단일축(예: 무대 재설계 신규 등록)만 허용.
- 판정 산식·임계·시드는 merge 전에 코드로 고정(`yr151_0b_signal.py`)·본 문서가 원본.
