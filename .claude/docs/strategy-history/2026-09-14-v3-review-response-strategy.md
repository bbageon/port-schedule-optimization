# v3 리뷰 대응 전략 — 주장별 검증과 제출 범위

기록일: 2026-09-14 · 사용자 요청: 심사위원 1~3의 의견을 v3 기준으로 해결할 전략.
연결 작업: YR-317(리뷰 대응 묶음). **전략 작성 완료, 추가 실험과 원고 수정은 미착수**다.
실행 계약은 [실험 설계](2026-09-14-v3-review-experiment-protocol.md), 사용자 관점은
[HCI·재현성](2026-09-14-v3-review-hci-reproducibility.md)에 상세 보존한다.

## 1. 추천과 적용 범위

추천은 **v3의 제안·수락 구조를 유지하고, 각 구성요소가 필요한 조건을 검증하는 개정**이다.
14.72%를 반드시 유지할 목표로 삼지 않는다. 현실적 제약에서 남는 순편익과 불확실성이 목표다.
시간 조정, 공간 조정, 수락망, 학습 자체의 기여는 각각 다른 비교로 판단한다.
정책 정보를 한꺼번에 늘리거나 혼잡 전용 규칙을 덧대는 방식은 채택하지 않는다.

대상은 `docs/paper/v3/` 원고와 `src/yard_rl/v3/` 코드다. v4·v5의 성과를 증거로 승계하지 않는다.
실제 제출본과 `submissionv2`가 같은지는 아직 확정하지 않았다. 원고 정본 식별은 YR-298과 연결한다.
이번에는 원고·학습 코드·실행 중 프로세스를 변경하지 않는다. 신규 태그도 만들지 않는다.

## 2. 리뷰를 어떻게 받아들일 것인가

| 의견 | 현재 판단 | 필요한 답 |
|---|---|---|
| 1-① 연속 28일은 독립 실험이 아님 | 타당. 날짜별 부호·순위검정으로 독립 반복을 대체할 수 없음 | 독립된 연속 실행을 반복하고 월 단위 비용 차이와 구간 추정 |
| 1-② 예약 정원·재예약 비용 누락 | 가장 먼저 확인할 운영 가정 | 예약 장부와 정원을 연결하고 터미널 밖 지연·변경 부담을 비용에 포함 |
| 1-③ 두 행동 비교에서 전체 순위로 확장 | 설명만으로 닫을 수 없는 학습 목표 문제 | 같은 상태의 전체 후보를 실제 분기로 채점하여 선택 오류 검사 |
| 1-④ 공간·수락망의 추가 가치 불명확 | 일부 추가 자료가 있으나 확증 부족 | 시간만 대비 공간 추가, 거절 제거 대비 수락망, 학습 전후 비교 |
| 1-⑤ 혼잡 나흘 편중·민감도·속도 | 일부 민감도 자료 있음 | 혼잡 파도·비용·운영기간 반복과 전체 온라인 경로 시간 측정 |
| 2 합성환경·한 번의 30일 실험 | 내부 반복성과 실제 항만 타당성은 다른 문제 | 반복평가 + 실제 자료로 환경 보정·검증, 자료 없으면 주장 제한 |
| 3 HCI 연결·사용자·사용 맥락 | 알고리즘 설명과 별개로 보완 필요 | 누가 언제 무엇을 보고 어떤 권한으로 수정·거절하는지 명시 |

리뷰는 구조 자체를 부정하기보다, 효과의 일반성과 실제 사용 가능성을 요구한다.
다만 HCI 학술 기여까지 주장하려면 사용자 평가가 필요할 수 있으며 사용 시나리오만으로 보장되지 않는다.

## 3. 저장소에서 직접 확인한 근거 스냅샷

원자료 JSON의 날짜 index 1~28(첫날·마지막날 제외)을 다시 합산했다. 단위는 억 원이다.
이 금액은 시뮬레이터의 비용 환산값이며 실제 회계상 절감액을 뜻하지 않는다.

| 자료 | 조건 | 재배치 없음 | 전체 | 시간만 | 공간만 |
|---|---|---:|---:|---:|---:|
| `judge-30d` | 시드 9,900,950, 기존 대표 실행 | 99.9581 | 85.2438 | 86.5221 | 101.2645 |
| `env-quiet` | 시드 9,900,980, 혼잡 2일 | 63.8274 | 55.5995 | 58.3537 | 61.5668 |
| `env-mixed` | 같은 시드, 혼잡 6일 | 141.2506 | 115.7428 | 121.1982 | 165.2082 |
| `env-heavy` | 같은 시드, 혼잡 14일 | 296.3735 | 245.9015 | 255.2434 | 284.6927 |

대표 실행에서 전체는 14.7204%, 시간만은 13.4416% 절감했다. 차이는 **1.2788%포인트**다.
이 차이는 전체 정책에 공간 행동을 허용한 추가 이득의 관찰값이지, 독립적으로 증명된 공간 기여가 아니다.
공간만은 1.3070% 비용 증가였다. 그러나 다른 수요 구성에서는 공간만의 부호도 달라진다.
따라서 “공간은 항상 해롭다”, “시공간 결합은 항상 유리하다” 모두 현재 자료를 넘어선다.

수락망 비교 `judge-consent`(시드 9,500,000): 전체 99.2467억, 학습된 거절을 끈 정책
102.1958억, 재배치 없음 121.4688억. 거절을 유지한 쪽이 **2.9491억** 낮다.
이 실험은 이미 있어 재사용 가치가 있다. 하지만 21/28일과 기존 p값은 연속 날짜 기준이므로
독립 반복에서 수락망 이득이 확증됐다는 해석은 다시 검사해야 한다.

재검토 창 자료 `window-sweep`(시드 9,900,995): 30분/1시간/2시간에서 절감률은
**16.26% / 14.64% / 10.97%**다. 검토를 앞당긴 민감도 관찰이며, 모든 차량에
1~2시간 사전 통지가 보장되었다거나 정원·운송사 동의까지 충족했다는 증거는 아니다.
성능 감소를 전부 “막판 정보의 가치”라고 인과적으로 해석하지도 않는다.

기존 대표 실행의 나흘 집중 90.5%, 학습 전 모형 대비 18/28일·p=0.1849도 보존한다.
후자는 기존 검정으로도 확증되지 않았고, 날짜 의존성을 고친 결과가 새로 필요하다.

## 4. 선행 기록에서 바로잡아야 할 부분

- YR-254(수락망 제거 비교)의 세 환경은 **같은 시드**를 공유했다. 84일을 독립 표본처럼
  합치는 검정은 사용하지 않는다. 수요 조건을 달리한 통제 실험으로 보존한다.
- YR-296은 Dashboard에 완료지만 spec 첫 상태는 backlog다. 완료라는 이름과 기존 p값만으로
  현재 신뢰성 통과를 선언하지 않는다. row·spec·원자료·실행 커밋을 함께 대조한다.
- YR-299(기존 리비전 실험)의 B는 v4 실험으로 바뀌었고 결과가 철회됐다.
  “6시간 교사가 나쁘므로 3시간이 충분하다”를 v3 답변에 쓰지 않는다.
- YR-304는 학습 초기값 시딩 누락을 기록했다. 현재 v3 `train/month_loop.py`도 망 생성 전
  시딩이 없어, v4의 수정 완료를 v3 재학습 재현성 확보로 읽으면 안 된다.
- 저장된 공통 게이트는 2026-08-17 자료이며 현재 v3의 직접 판정이 아니다.
  저장값은 성능 미확정·신뢰성/현실성 통과지만, 이를 이번 작업 착수 허가로 승계하지 않는다.
- 별도 작업 두 개가 YR-315를 공유하는 기존 board 충돌도 관찰됐다. 전체 board 정합 통과를
  주장하지 않는다. 이번 기록은 새 YR-317 계열의 유일성과 증거 연결만 검사한다.

## 5. 작업 순서 — 등록된 row와 연결

| 순서 | row | 무엇 / 왜 지금 |
|---|---|---|
| 1 | YR-317-a | 원고·코드·원자료·통계 단위를 맞춘다. 이전 실험을 잘못된 확증으로 인용하는 일을 먼저 막는다. |
| 2 | YR-317-b | 예약 정원, 변경 가능한 시간, 외부 지연 비용을 한 축씩 검사한다. 가장 큰 이득의 운영 전제를 확인한다. |
| 3 | YR-317-c | 전체 후보 선택의 정확성을 검사한다. 쌍 비교 학습이 실제 선택으로 이어지는지 확인한다. |
| 4 | YR-317-d | 독립 반복에서 행동·수락·학습의 기여와 장기 효과를 확증한다. 일반화된 성능 문장의 근거를 만든다. |
| 보조 | YR-317-e | 전체 처리시간·실행 명세를 정리한다. 실시간·재현성 주장에 실제 측정치를 붙인다. |

보조 문서 작업은 실험과 별개로 준비 가능하다. 정책 실험은 신뢰성→현실성→성능 순으로
현재 증거에 근거한 착수 허가를 받아야 한다. 실패하면 해당 항목만 직접 보정한다.
미사용 시드 결과를 열기 전에 코드·비용·정원·비교군·표본 수·판정식을 고정한다.

## 6. 검토한 대안과 채택하지 않은 이유

| 대안 | 판단 |
|---|---|
| 문장만 완화하고 재제출 | HCI 맥락은 개선되지만 독립성·비용 누락·순위 문제를 해결하지 못함 |
| 현재 코드 그대로 시드만 늘림 | 반복성은 늘지만 정원 없는 이득과 잘못된 학습 목표도 그대로 반복할 수 있음 |
| v5 결과로 교체 | 다른 정책·학습 방법의 평가이므로 v3 구조에 대한 답이 되지 않음 |
| 공간 행동·수락망을 바로 삭제 | 현재는 단정할 근거 부족. 비교 결과가 필요성을 뒷받침하지 못하면 그때 주장 축소 |
| 혼잡 때 규칙을 덧붙여 성능 방어 | 추가 기제의 효과가 섞임. 관찰된 결함을 단일축으로 고치는 원칙과 맞지 않음 |
| 사용자 화면만 추가 | 사용 맥락 설명에는 도움. HCI 효과를 검증했다는 근거는 아님 |

## 7. 결과에 따라 바꿀 주장

- 현실적 정원·비용에서도 전체가 강한 동정보 규칙보다 낮으면, 그 조건에서의 순편익을 보고한다.
- 시간만과 전체의 차이가 불명확하면 공간 추가 이득은 미확정으로 둔다.
  시간만이 더 좋으면 시간 조정 중심 결과로 범위를 축소하고 결합 우위 주장을 철회한다.
- 수락망을 제거하거나 단순 수락 규칙으로 바꿔도 같으면 별도 학습망의 필요성은 주장하지 않는다.
- 학습 전과 구별되지 않으면 강화학습의 성능 기여는 미확정이다. 작동하는 구조와 학습 성공을 구분한다.
- 슬롯 제한·외부 비용 때문에 이득이 사라지면 원래 결과를 자유로운 시간 이동의 잠재 효과로 한정한다.
- 사용자 평가가 없다면 HCI는 제안한 사용 맥락으로 표시한다. 실증된 HCI 기여가 필요한
  제출처에서는 설명 보강만으로 부족할 수 있음을 개정 전략의 한계로 둔다.

## 8. 산출과 근거

개정 묶음의 목표 산출은 리뷰별 답변표, 월 단위 반복 결과표, 구성요소 비교표,
운영 제약·비용표, 전체 후보 선택 검증표, 처리시간표, 사용자 역할·흐름 그림이다.
아직 작성·실행하지 않은 산출은 완료로 표기하지 않는다.

로컬 근거: `outputs/v3/{judge-30d,judge-consent,env-quiet,env-mixed,env-heavy,window-sweep}/`,
YR-254·272·293·296·299·304 명세와 v3 `train/labels.py`, `actors/nets.py`, `reward/phi.py`.
기계 재계산·파일 해시는 [검증 증거](../../../outputs/reports/yr317_v3_review_strategy/README.md)에 둔다.
외부 연구는 전략의 방법론 참고이며 위 항만 실험의 성능 근거를 대신하지 않는다.
