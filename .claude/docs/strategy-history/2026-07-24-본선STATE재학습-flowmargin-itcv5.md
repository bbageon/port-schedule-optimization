# 본선 인지 STATE 재학습 결과 — flow_margin (itc-v5) (2026-07-24)

> 실험: 반응형 RL(yr088_joint_rl)에 **flow_margin 을 STATE에 추가**(SCHEMA itc-v4→itc-v5)하고
> **같은 리워드·seed·200 episode**로 재학습 → 본선(berth)이 개선되는가. 리워드는 안 바꿈
> (v6 리워드축은 이미 실패). 즉 **"더 나은 본선 STATE가 학습을 여는가"**의 단독 검정.

## 1. 배경 — 축이 갈렸다

- **리워드축(v6)**: sts_wait 지배 재조정 → **실패**(berth 전 셀 악화·건전깨짐·미완주). 대리신호 악용.
- **STATE축(이번)**: flow_margin(STS 굶/막힘 여유 요약)을 관측에 추가. 리워드 불변.

## 2. 결과 (test, RL vs SF, berth=선석초과 분)

| 셀 | itc-v4 RL/SF | **itc-v5 RL/SF** | Δberth(v4→v5) |
|---|---|---|---|
| mid-loose | 27.4 / 29.4 | **11.8 / 29.4** | **−15.6** |
| high-loose | 68.9 / 62.1 | 68.4 / 62.1 | −0.5 |
| mid-tight | 108.8 / 109.6 | **102.1 / 109.6** | −6.7 |
| high-tight | 145.2 / 161.4 | **148.8 / 161.4** | +3.6 |

- **평균 berth: RL 87.6 → 82.8분** (SF 90.6). itc-v5 RL 이 **SF 를 berth 에서 3/4 셀 + 평균으로 이김**.
- **트럭 유지**: 평균대기 RL 8.51 (SF 9.04) — 본선 개선이 트럭 희생 아님. 전 셀 **healthy·완주 True**.

## 3. 판정 — STATE축은 (모듈하게) 효과 있음

**flow_margin 을 STATE에 넣으니 본선(berth)이 개선됐다** — 리워드로는 못 하던 걸 **더 나은 관측**이
부분적으로 열었다. 리워드축(v6 실패) vs STATE축(이번 개선)의 대비가 **"본선은 보상이 아니라 관측/표현
문제"** 라는 이번 세션 가설을 지지한다.

## 3b. 확증 (신선 12 seed·paired CI, RL vs SF)

- **본선 berth: 개선 확증** — 전체 Δberth **−11.77분 [−17.92, −5.62] 유의**(48 seed pooled).
  셀별: high-loose −19.70[−34.14,−5.26]★·high-tight −13.82[−26.95,−0.69]★ 유의 / mid-loose·
  mid-tight 는 CI 0 포함(무의·경계). → 본선 개선은 **통계적으로 실재**(6 seed 방향값 확증).
- **★트럭 P95(꼬리): 유의 악화** — ΔP95 high-loose +9.56★·mid-tight +8.36★·high-tight +12.26★
  (3/4 셀 CI 상한>0). 트럭 **평균**은 비열등(CI 0 포함)이나 **꼬리를 희생**. 완주 전셀 1.0.
- **판정: 본선 얻고 트럭 꼬리 내준 Pareto 이동** — flow_margin STATE 는 본선을 실제로 열지만
  **공짜 아님**. 앞선 적대검토가 경고한 배↔트럭꼬리 상충이 실측으로 확증됨.

**정직한 한계**:
- **비균일**: berth 개선은 high 부하 셀에서 유의, mid 셀은 무의(경계). "전 조건 개선" 아님.
- **트럭 P95 게이트 실패**: 채택 게이트(트럭 P95 비열등)를 이 정책은 **통과 못 함** → P95 보호(YR-029
  필터/게이트)와 결합 선결.
- **조기 정체**: best_ep=20 (v4·v5 공통) — 추가 학습 개선 없음, RL 일찍 정체.
- **lookahead 잔여**: STATE 가 본선의 절반을 열고, 나머지(경합 미래)는 rollout/credit 축.

## 4. 함의·다음

- **확인된 것**: 본선 심화의 유효 레버 = **관측(STATE) 표현** > 리워드 shaping. flow_margin 채택
  가치 있음(berth −11.77 유의 확증). 단 **트럭 P95 대가** 동반.

## 5. ★트럭 P95 보호 가드 — 채택 게이트 통과 (재학습 없이)

itc-v5 net 을 결정시점 가드로 감쌈: **크레인에 SLA 임박(대기≥0.8·SLA=24분) mandatory SERVE 가
있으면 그 크레인은 mandatory 를 서비스하는 공동조합만 허용**(나머지는 net argmin). 재학습 불필요·
정책 무개조(결정시점 필터). 가드RL vs SF, 12 seed·paired CI:

| 지표 | 가드 없음 | **가드** | 판정 |
|---|---|---|---|
| Δberth (전체) | −11.77 [−17.92,−5.62]★ | **−7.73 [−13.67,−1.78]★** | 본선 개선 **유지·유의** |
| ΔP95 (전체) | +평균 (3/4셀 +8~12★ 악화) | **+1.03 [−1.44,+3.50]** | 트럭 꼬리 **비열등 회복** |
| Δwait·완주 | 비열등·1.0 | 비열등(high-loose −2.50★)·1.0 | 유지 |

**판정: 채택 게이트 통과** — 완주 1.0 · 트럭 평균/P95 비열등 · 본선 berth 유의 개선(−7.73). 즉
**flow_margin STATE(본선 학습) + mandatory 하드가드(꼬리 보호) = 배 이기고 트럭 꼬리 지키는 첫
채택가능 본선인지 정책**. 대가: berth 개선폭 −11.77→−7.73 (가드가 본선 이득 일부 양보해 꼬리 보호).
한계: 셀별 berth 는 pooled 만 유의(개별 CI 0 포함)·best_ep20 조기정체·문헌 보정 시뮬.
