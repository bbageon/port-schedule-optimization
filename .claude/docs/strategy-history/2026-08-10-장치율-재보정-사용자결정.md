# 2026-08-10 — 초기 장치율 재보정 사용자 결정 (0.30 → 0.65)

## 결정

H-21 지속유입 계약의 초기 야드 장치율을 **0.65** 로 재보정한다 (선택지: 0.65 권장 /
0.60 보수 / 0.30 유지 중 **0.65 채택**).

## 경위

- 미수집 앵커 조사(2026-08-09, 워크플로 3축+교차검증)에서 부산항 평시 장치율이
  **66~75%**(2019 평시 68.6%·3년 평균 66~75.13%·포화 기준 80%), 국제 peer-reviewed
  실측이 52.4~73.3%(평균 60.4)로 수렴 — 등록 대역 **[0.60, 0.75]**.
- 우리 가정 0.30 은 **문헌 최저 실측(52%)보다 낮은** assumed 값으로 판명 — 등록 순간
  현실성 게이트의 위반 사유가 됨. 유지 시 성능 주장이 "저장치율 합성환경" 한정으로
  영구 제약.

## 적용 범위 (골든 보존 원칙)

- **변경**: `TerminalStreamParams.fill_ratio` 기본값 0.65 — H-21 지속유입(고정 WIP)
  계약 전용. 블록당 초기 컨테이너 432 → **936개**(1,440 슬롯 × 0.65).
- **불변**: `scenario_gen.TerminalGenParams.fill_ratio = 0.30` — 구세대(2블록·유입량
  계약) 실험의 골든 바이트 보존. 새 값을 소급하지 않는다.

## 파급 (예상 — 재자격이 실측한다)

- 반출 재고 여유 2배+ (fallback 위험 ↓) · 반입 수용 여유 감소(블록당 빈 슬롯
  1,008 → 504 — 트럭 규모 대비 여전히 충분) · **재취급(rehandle) 증가** → 서비스
  시간 ↑ → 처리율 ↓ (게이트 처리율 상단 초과[~190 vs 등록 160대/h] 문제의 자연
  완화 가능성) · 상태 지도(BUSY 무대) 변동 가능 → **무대 재확정 필요**.
- 따라서 **전면 재자격 재실행이 정본**: YR-157 18런(6셀×3시드) → 상태 지도 재판정 →
  무대 재동결 → 크레인 서비스 계측 배선 → 현실성 재제출 → 인가 → 반사실 0B.
- 기존 0.30 환경의 자격·smoke 결과는 전부 "구 장치율 환경 이력"으로 강등 보존.
