# YR-195 사전등록 — 문턱: 눈금에 오차가 있는 자를 쓰는 법

- **작성 2026-08-19 · 실행 전 동결** (이 문서 커밋 이후 §1~8 수정 금지. 개정은 별도 문서)
- **답할 질문 하나**: **판매 문턱을 두면 규칙을 넘는가.**

## 1. 왜 지금 — [[YR-189]] 가 진 원인이 실측으로 특정됐다

`q − greedy` = **+211.41** [+167.79, +255.02] · **16일 전부 규칙 승**.
학습 정책이 규칙보다 **2.26배** 팔았다(일평균 2,167 vs 957).

판정 후 배포 모드 4시드 × 22시간(비판정 대역)으로 원인을 분해했다.

| 실측 | 값 |
|---|---|
| 고른 좌표의 편향 (예측 − 라벨) | **−0.1694** (낙관) |
| 대조 — 탐색 켠 상태(선택 무작위화) | **+0.04** (부호 반전) |
| 실제 이득 평균 | −0.0105 → **편향이 이득의 16배** |
| 판 것 중 실제 손해 | **43%** |
| 배정기가 **판단해서** 거부 | **0.9%** (95/10,141) |

**두 가지가 확정됐다.** ①"가장 싼 것을 고르는 행위" 자체가 낙관 편향을 만든다
(승자의 저주 — 모델이 아니라 선택 규칙의 문제다). ②문턱이 있어야 할 자리인
2관문이 **판단을 하지 않는다**(1관문이 같은 망으로 이미 같은 계산을 했다).

## 2. 무엇을 바꾸나 — 세 곳 (전부 opt-in · 기본값은 YR-189 보존)

| # | 무엇 | 코드 |
|---|---|---|
| ① | **1관문 문턱 제거** — 블록은 "내 후보 중 뭐가 제일 부담인가" 순위만 매긴다 | `QSellPolicy(defer_decision=True)` |
| ② | **2관문이 판단** — KEEP 값을 `0` → **`−m`**. 좌표가 KEEP 을 `m` 만큼 이겨야 판다 | `UnifiedSellOrchestrator(sell_margin=m/Q_SCALE)` |
| ~~③~~ | ~~채점 넘겨받기 + 더티 추적~~ — **폐기** (아래) | — |

**혼잡 갱신은 유지한다** — 배정이 확정될 때마다 목적지가 차오르는 것을 반영하지
않으면 21블록이 같은 빈 블록으로 몰린다. 그것이 배정기의 진짜 일이다.

### ③은 실행 전 검증에서 폐기했다 (2026-08-19)

더티 추적은 "배정은 목적지를 **더 붐비게만** 만드므로, 자기 최선 좌표가 안 바뀐
제안은 argmin 도 안 바뀐다"에 기댔다. 실행 전에 전량 재채점과 대조했다.

| | 실측 |
|---|---|
| 배정 기록 일치 | **2,477 / 3,797 불일치** — 가정이 성립하지 않는다 |
| 속도 이득 | **1.00배** (224초 vs 224초) |

**신경망은 목적지 부하에 단조가 아니다.** 그리고 속도 이득도 없었다 — 계산의
대부분은 1관문(블록이 후보×좌표 채점)에 있고 배정기 몫은 애초에 작다.
위험한 가정을 안고 갈 이유가 없어 **전량 재채점을 유지**한다.

(어제 "배정기 계산이 11배 준다"고 적었다가 전체로는 거의 안 준다고 정정했는데,
이번에 **정확히 0** 으로 실측됐다.)

### ★단위 함정 — 실행 전 검증에서 잡았다

`sell_margin` 은 **Q 망 출력과 같은 눈금**이다. 학습이 목표를 `Q_SCALE = 20` 으로
나눠 쓰므로, 비용시간 여유를 그대로 넣으면 **20배 과한 문턱**이 된다.

| m (원단위로 잘못 넣었을 때) | 공간 판매 | 시간 판매 |
|---|---|---|
| 0.000 | 634 | 315 |
| 0.085 | **0** | 182 |
| 0.170 | **0** | 147 |

공간 판매가 통째로 사라진다. 격자는 **비용시간**으로 적고
`margin_to_net_units()`(= ÷ `Q_SCALE`)로 변환해 넣는다.

## 3. 왜 학습은 한 번만 하나

문턱은 **학습 목표에 들어가지 않는다.** Q 망은 "이 좌표로 팔면 비용이 얼마"를
회귀할 뿐이고, `m` 은 그 예측을 **쓰는 규칙**이다. 그래서 **학습 1번 + 평가 4번**
이면 격자 전체를 덮는다. 학습 설정은 [[YR-189]] 와 **완전히 동일**하다
(16회차 × 4에피소드 · LR 3e-4 · ε 0.15 · σ 0.20 · 버퍼 150,000 · 600 step ·
Q_SCALE 20.0 · Huber β 1.0). 학습 시 `sell_margin = 0`.

## 4. 동결 — 평가

| | |
|---|---|
| **평가일** | **새 대역 9,700,000 + 1,000·i (i=0..15, 16일)** — 9,600,000~ 는 YR-189 가 썼다 |
| 팔 | `K`(안 팔기) · `greedy`(규칙) · `m0` · `m0.085` · **`m0.17`** · `m0.34` |
| **주판정** | **`m0.17 − greedy`** (총비용 Φ) — 0.17 은 실측 편향 0.1694 |
| 모드 | argmin 결정론 (ε=0·σ=0) · 문턱은 배정기 한 곳 |
| 비교 | 같은 날 짝지어, 독립단위 = **날**(n=16) · \|t\| ≥ 2.13 |
| 가중치 | 마지막 회차 고정 |

**격자를 여러 개 돌리는 것은 다중비교**다. 주판정은 **`m=0.17` 하나로 미리
고정**하고, 나머지 세 값은 **함께 보고**(판정 아님)로만 쓴다. 결과를 보고 다른
`m` 을 주판정으로 바꾸지 않는다.

## 5. 동결 — 판정

| 결과 | 뜻 |
|---|---|
| 95% CI 전체가 **0 미만** | **문턱을 넣으니 규칙을 넘었다** → 서사 A 재검토 |
| CI 가 0 을 포함 | **구분 불가** — 문턱이 +211.41 을 없앴다. 그것도 결과다 |
| CI 전체가 **0 초과** | **못 넘었다** → 문턱은 원인의 일부였을 뿐 |

**함께 보고(판정 아님)**: `m0 − greedy`(새 구조에서 문턱만 뺀 대조) ·
각 `m` 의 판매량·제안수 · `m* − K` · 체류 평균 · 격자의 단조성.

**`m0` 은 YR-189 의 정확한 재현이 아니다** — ①이 켜져 있어 전역 매칭 폭이
넓어졌다(제안 1,364 → 3,797, 실측). 그 차이도 함께 보고한다.

## 6. 동결 — 하드 가드 (위반 시 그 셀 실격)

1. 투입 = 3,600 전건 (`admitted == 3600`)
2. `policy_exceptions == 0`
3. 실행 트리 `code_dirty == False`
4. 6팔 × 16일 = **96셀 전부 존재**
5. 문턱 격자가 **망 출력 눈금으로 변환**되어 들어갔는지 (원단위 직접 투입 금지)
6. 학습 중 표본 0 인 회차가 있으면 즉시 중단

## 7. 하지 않는 것

- 결과를 보고 주판정 `m` 을 바꾸는 것.
- 격자에 없는 `m` 을 사후에 추가하는 것.
- 규칙의 `gain_margin` 을 건드려 기준선을 약화시키는 것.
- ①② 외의 축(학습률·회차·탐색·버퍼)을 함께 바꾸는 것.
- 폐기한 ③(더티 추적)을 검증 없이 되살리는 것.
- 이 판정으로 실제 항만 운영 대비 개선율을 주장하는 것.
