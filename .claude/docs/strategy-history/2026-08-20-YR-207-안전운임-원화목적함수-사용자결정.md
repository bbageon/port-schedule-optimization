# YR-207 결정 — 2026 안전운임을 기준으로 터미널 비용을 원화 환산한다

> 기록일: 2026-08-20 · 상태: 사용자 결정 반영, 구현·학습 전
> 현재 3대 게이트가 성능 `INCONCLUSIVE`이므로 backlog 명세만 등록한다.

## 1. 결정 경위

현행 `TERMINAL-COST-NUMERAIRE-V1`은 트럭 `B→C` 1시간을 1로 두고 본선·크레인·
재취급을 상대비율로 더한다. 사용자는 terminal objective의 트럭 시간을 블록 체류가 아니라
`gate-out−gate-in(A→O)` 턴타임으로 정하고, 2026년 안전운임제에서 트럭 기사 1시간의
원화 가치를 확인해 계수로 쓰기로 결정했다.

이 변경은 단순 표시단위 교체가 아니다. 트럭 비용의 시작·종료가 `B→C`에서 `A→O`로
바뀌므로 게이트 이후 내부 이동·블록 처리·출문까지 터미널 안에 머문 시간이 모두 들어간다.

## 2. 공식 근거 스냅샷

2026-08-20 확인 당시 현행 문서는 「2026년 적용 화물자동차 안전운임 고시」,
국토교통부고시 제2026-402호, 시행 2026-08-01이다.

별표 1 제24호의 수출입 컨테이너 항만부두 대기료는 다음 조건이다.

- 20FT·40FT 공통
- 1시간을 초과한 뒤 30분당 20,000원
- 대기시간: 화주 또는 부두운영사의 도착요청부터 상·하차와 송장 발급 완료까지
- 부대조항 금액은 부가가치세가 포함되지 않음

따라서 한계 시간가치는 `20,000 / 0.5 = 40,000원/트럭·시간`이다.

## 3. 채택한 해석

`40,000원/시간`은 법정 청구액 자체가 아니라 **정책의 시간가치 기준재**로 쓴다.
법정 대기료는 첫 1시간이 무료이고 시작·종료 시각도 우리 gate 기록과 다르다. 이를 그대로
reward로 쓰면 0~1시간 개선은 모두 0원이 되어 정책이 짧은 턴타임 차이를 배우지 못한다.

```text
TT_j(T) = max(0, min(O_j,T) - A_j)
C_truck(T) = 40,000 × Σ_j TT_j(T) / 3,600
```

완료차는 `O−A`, 미완료차는 평가 끝 `T−A`를 쓴다. 현재 `TimeLedger.terminal_area_s`가
이 적분을 이미 보유한다. `block_area_s(B→C)`와 `S−B`는 진단으로 남기고 보상에서 뺀다.

## 4. 전체 목적함수

비용 ID는 `TERMINAL-COST-KRW-EQ-2026-SAFE-FREIGHT-V1`이다. 현 상대비율을 유지한 채
40,000원을 곱해 본선 1,320,000원/시간, YC 40,000원/시간, 재취급 2,000원/회로
환산한다. `long_wait` 가산은 0으로 두어 A→O와 같은 시간을 두 번 부과하지 않는다.

이 중 트럭 시간계수만 고시에 직접 닿아 있다. 나머지는 현 가정 비율을 원화 눈금으로
바꾼 값이므로 결과 이름도 `KRW_EQ`로 고정하고 **실제 회계비용**이라 부르지 않는다.
금액 주장에는 본선 비율 `33×`의 기존 민감도 `1/3~3배`를 그대로 붙인다.

## 5. Seller·Buyer 보상과의 관계

terminal objective는 하나다. factual 비용은 거래당 한 번만 기록한다. YR-204는 같은
`J_KRW_EQ`에서 Seller `SELL−KEEP`, Buyer `BUY−REJECT` 반사실 비용을 각각 만들지만,
그 둘을 terminal total에 합치지 않는다. 따라서 양쪽이 같은 좋은 거래를 학습해도 실제
비용 감소가 두 번 세어지지 않는다.

## 6. 검토한 대안과 기각 사유

| 대안 | 결정 | 이유 |
|---|---|---|
| 법정식 그대로 첫 1시간 0원 | 기각 | 정상 턴타임 구간의 학습 신호가 사라짐 |
| 기존 B→C와 새 A→O를 함께 더함 | 기각 | 같은 트럭 시간을 구조적으로 이중계상 |
| 노선별 전체 안전운임을 시간가치로 나눔 | 기각 | 거리·연료·차량비가 섞여 터미널 지연만 분리 못함 |
| 월소득·근로시간으로 기사 임금 추정 | 기각 | 현 고시에서 바로 확인되는 항만 대기료보다 가정이 많음 |
| 40,000원만 곱하고 B→C 원료 유지 | 기각 | 사용자가 정한 terminal turntime 목적과 불일치 |

## 7. 적용 범위와 되돌릴 조건

순서는 `YR-203→YR-207→YR-204→YR-205`다. YR-207은 비용·시간 원료 한 축만 바꾸며
상태·후보·actor 구조를 함께 바꾸지 않는다. 기존 config와 결과는 이력으로 보존한다.

공식 고시가 다시 개정되거나 실제 터미널 회계 원가가 들어오면 새 `cost_id`로만 교체한다.
40,000원 계수를 과거 결과에 소급 적용해 실제 절감액으로 주장하지 않는다. 새 비용으로
양 정책을 같은 시드에서 다시 평가한 뒤에만 원화 환산 개선액을 보고한다.
