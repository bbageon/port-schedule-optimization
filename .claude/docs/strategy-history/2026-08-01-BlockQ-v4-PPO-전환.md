개선 ③D−B −6.7 유의(순위 능력의 실전 방향성) ④남은 결함 = **오프라인 궤적(DIFF1)과
실행 궤적의 분포 이동** + 재배치 재퇴화.

## BlockQ-v4 계약 — 중앙 공동후보 PPO

핵심 한 문장: **두 크레인의 공동후보를 중앙 Actor 가 직접 선택하고, 자신이 실제로 만든
운영 궤적의 전체 터미널 비용으로 PPO 학습한다.** 이 구조가 확인된 두 문제를 동시에
제거: 고정 DIFF1 궤적 학습(분포 이동)·600s 후보비용 정확 예측 요구.

- 블록 전체 = 단일 에이전트 (공동후보 조합 선택 — QMIX 식 크레인별 신용 분해 불필요).
- Actor = 공동후보별 logit → 물리·안전 mask 후 softmax (invalid action masking —
  불가능 행동은 벌점이 아니라 확률 계산 전 제거, 문헌 근거 有).
- Critic = V(s) (상태 공통 미래비용 — 행동 선택 안 함, Advantage 안정화 용).
- 학습비용 = 결정 구간의 **실제 발생비용** r_k = −ΔΦ. **핵심 등식(테스트 고정)**:
  −Σ r_k = 에피소드 최종 평가 총비용 (학습 비용 ≡ 평가 비용).
- γ=1 (유한 에피소드 총비용 정합) · 안정화 = Advantage 정규화 + PPO clipping ·
  GAE 는 Critic 잡음 감소 용도만 (표준 상수 앵커 — 튜닝 아님 문서화).
- 행동공간 유지: SERVE/PRE_REHANDLE/REPOSITION/구조적 WAIT (전략 WAIT 제외 — 현행
  증거 승계). REPO 장악 재발 시에만 v4-B 단일축: PREPOSITION(job, target_bay,
  expires_at) — PPO 효과와 행동정의 효과 분리를 위해 2단계 분할.
- 안전계층(비통과·안전거리·통로·중복·예약) 현행 유지.
- DAgger 는 보조 후보로만 (PPO 표본 부족 시 초기학습 보조 — 600s 교사 라벨 의존이라
  최종 정책의 핵심으로 두지 않음).

## v4-A 최소 검증 (동결)

학습방식만 변경(상태·후보·resolver·비용계약 그대로)·3 초기화·중간+고부하 혼합 학습·
평가군 = PPO vs SF-SPT 만. 판정: ①완주 100%·backlog 0 ②**3 초기화 중 ≥2 에서 SF 대비
비용 감소 방향** ③WAIT·REPO 장악 0. **신호 없으면 PPO 트랙도 중단.** 최종 확증(신규
시드·신뢰구간 잠금평가)은 방향 신호 확인 후에만.
