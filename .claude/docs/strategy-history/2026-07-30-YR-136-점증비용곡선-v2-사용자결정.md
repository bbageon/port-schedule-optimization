# YR-136 — 점증 지연비용 곡선 v2 사용자 결정

> 기록일: 2026-07-30 · 상태: 설계 확정, 구현 전
> 적용: YR-123 후속 비용계약, BlockQ-v3 라벨, YR-133 견적

## 1. 결정

사용자는 YR-123 v1의 계단형 트럭 비용과 본선 가중치 33을 앞으로의 정책계약으로
사용하지 않기로 결정했다.

1. 트럭은 SLA 직전까지 `1/h`였다가 갑자기 `2/h`가 되는 대신, SLA에 접근하는 동안
   `1/h → 2/h`로 부드럽게 증가한다.
2. 본선은 고정 가중치 33 대신 최대 `10/h`를 사용하고, 예상 완료시각이 계획
   완료시각에 가까워질수록 `0/h → 10/h`로 증가한다.
3. 비용은 끝점 비용률×지연시간으로 근사하지 않고 지연구간 전체를 적분한다.

## 2. 정확한 수식

공통 smoothstep:

```text
S(x)=0 (x≤0), 3x²-2x³ (0<x<1), 1 (x≥1)
```

트럭:

```text
L=30분, W_T=10분(assumed)
r_T(w)=1+S((w-(L-W_T))/W_T)
ΔC_T=(1/3600)∫ r_T
```

본선 적하:

```text
W_V=30분(assumed), 최대비용률=10/h
r_V(F)=10·S((F-(P-W_V))/W_V)
ΔC_V=(1/3600)∫ r_V
```

따라서 트럭은 `20분=1`, `25분=1.5`, `30분=2`, 본선은
`P-30분=0`, `P-15분=5`, `P=10`이 된다.

## 3. 선택 이유

- 계단형은 임계 전후 몇 초 차이에 비용률이 갑자기 달라져 후보 순위를 불안정하게 만든다.
- smoothstep은 경계에서 값과 기울기가 이어져 점진적 긴급도를 표현한다.
- 본선 33은 assumed 값이며 과거 실험에서 본선 신호가 트럭 채널을 압도했다. 10으로
  낮춰도 “본선이면 무조건 우선”이 아니라 실제 완료 위험에 따라 최대 10까지 올라간다.

## 4. 중요한 해석 제한

- `W_T=10분`, `W_V=30분`, 최대 10은 사용자 지정·연구 가정이지 부산항 실측 원가가 아니다.
- 정책용 점증비용은 후보 전후 차이를 비교하기 위한 값이다. 실제 운영 보고에는 평균
  `B→C`, 평균 `A→O`, SLA 초과, 실제 본선 계획완료 초과시간도 원형으로 함께 남긴다.
- 본선 양하는 현재 비용 인과가 완전하지 않아 이번 v2 최초 범위에 넣지 않는다.
- P95는 기존 결정처럼 보고용일 뿐 채택 게이트가 아니다.

## 5. 기존 결과의 지위

- YR-123 커밋 `322af31`은 계단형·본선 33의 **v1 재현 evidence**로 보존한다.
- 진행 중 YR-135는 v1 비용으로 생성된 절대 C600 라벨을 사용하므로 구조 진단 결과로는
  유효하지만, 새 비용계약의 채택 정책 근거로 승계하지 않는다.
- v2 구현 뒤 YR-135 구조가 유효한 경우에만 라벨을 새로 생성한다. 기존 라벨 재사용 금지.
- YR-133의 OutRelief·InBurden은 v2 공통 계산기가 연결된 뒤에만 정책 견적으로 사용한다.

## 6. 검증 순서

트럭 곡선과 본선 곡선을 한꺼번에 바꾸면 어느 변경의 효과인지 알 수 없다. 따라서
계약 테스트 후 `트럭만 → 본선만 → 결합` 순서로 각각 증거를 남긴다. 성능 검증 전
하드가드·예약·자동실행은 추가하지 않는다.

## 7. 되돌릴 조건

- 점증곡선이 후보 순위의 변별력을 낮추거나 완료율을 해치면 해당 단일축만 v1로 되돌린다.
- 정책비용과 엔진 평가비용의 합이 일치하지 않으면 성능 판정을 중단하고 계약부터 수정한다.
- 실제 SLA·선석비용 자료가 확보되면 `W_T/W_V/10`을 새 사전등록으로 재보정한다.
