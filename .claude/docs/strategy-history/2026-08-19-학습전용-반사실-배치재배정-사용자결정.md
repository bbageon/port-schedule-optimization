# 학습 전용 반사실 교사·일회성 배치 재배정 (사용자 결정 2026-08-19)

> 상태: 방향·Dashboard 작업 등록. 구현·사전등록·성능 판정 전이다. 현재 성능 게이트가
> `INCONCLUSIVE`이므로 YR-200~202 뒤의 후속 구조로만 등록한다.

## 1. 결정 경위

사용자는 블록 작업 재배치를 다음 계보로 정리했다.

1. 터미널 실제 목적함수는 하나만 계산한다.
2. Seller의 KEEP/SELL, Buyer의 REJECT/BUY는 각 행동을 제거한 반사실과 비교한다.
3. 긴 미래 비용은 시뮬레이터를 분기해 **학습 때만** 깨끗한 교사 라벨로 만든다.
4. 평가·운영에서는 분기 시뮬레이션을 하지 않고 학습된 Seller·Buyer 모델과 중앙
   Resolver가 즉시 최종 목적지를 정한다.
5. 한 작업은 최초 통지 창 진입 때 딱 한 번 판단하고, 같은 epoch 신규 작업은 batch로
   공동 배정해 재판매 순회와 독립 배정 과부하를 막는다.

핵심 연구 문장은 다음으로 고정한다.

> cooperative MARL의 counterfactual credit assignment를 container terminal의
> one-shot yard-block task reallocation에 적용해, 학습 때 얻은 장기 반사실 비용을
> 운영 시 빠른 Seller·Buyer 견적과 중앙 matching으로 근사한다.

## 2. 선행연구 대조 — 확인된 범위

- [Castellini et al., Difference Rewards Policy Gradients](https://arxiv.org/abs/2012.11258):
  공동 보상에서 개별 기여를 가르기 위해 reward 자체의 차이를 쓰며, 알려진 reward가
  없으면 reward network를 학습하는 변형도 제시한다.
- [Foerster et al., COMA](https://arxiv.org/abs/1705.08926): 중앙 critic이 다른 agent
  행동은 고정하고 한 agent의 대안 행동을 평균내 반사실 baseline을 만든다.
- [Mesnard et al., ICML 2021](https://proceedings.mlr.press/v139/mesnard21a.html): 행동이
  미래 reward에 미친 영향과 외부요인·후속행동의 영향을 분리하는 장기 credit assignment다.
- [Chang et al., ICML 2020](https://proceedings.mlr.press/v119/chang20b.html): agent가
  환경 상태를 조작할 권리를 사고파는 지역 경제 거래로 전역 목적을 맞춘다.
- [Hoppe et al., L4DC 2024](https://proceedings.mlr.press/v242/hoppe24a.html): 차량의
  고객요청 배정·거절 문제에서 지역 보상과 운영자 전역 이익의 충돌을 반사실 global
  reward로 보정한다.

이들은 우리 발상의 이론적 근거지만, **컨테이너 블록이 KEEP/SELL·BUY/REJECT로 작업을
재배치하는 동일 알고리즘은 아니다.** 이번 제한 검색에서 같은 형태를 찾지 못했다는
사실만 기록하며, 체계적 문헌검색 전에는 “최초”라고 주장하지 않는다.

## 3. 목적함수와 학습신호

거래 `k=(A,B,j)`의 실제 비용 변화는 한 번만 계산한다.

```text
ΔC_k^H = C_H(실제 거래 포함) − C_H(k만 KEEP/REJECT인 반사실)
D_k^H  = −ΔC_k^H
```

- 터미널 평가지표: 실제 trajectory의 total cost 한 번.
- Seller·Buyer 학습: 같은 `D_k^H`를 양측에 귀속 가능.
- 두 agent가 같은 신호를 받는 것은 실제 비용을 두 번 합산한다는 뜻이 아니다.
- 거래별 두 손실은 평균해 거래 표본의 가중치가 두 배가 되지 않게 한다.

Seller relief와 Buyer burden을 별도 수치로 해석하려면 추가 조건이 있다. pair-level
차이 하나만으로 두 내부 항은 유일하게 정해지지 않는다. 블록별 원장 component 합이
pair target과 맞는지 먼저 확인하고, 불일치하면 직접 joint-score만 정답으로 인정한다.

## 4. 학습과 운영 경계

### 학습

```text
동일 snapshot·외생 난수
├─ 실제 batch 배정 → H 지평 비용
└─ k만 KEEP/REJECT → H 지평 비용
                         ↓
                    장기 차이 라벨
                         ↓
              Seller/Buyer 또는 joint 모델
```

공통 난수·snapshot hash·동일 ExecutionHead를 강제한다. `H`·반사실 기본행동·다른
batch 작업의 처리·표본수는 결과 열람 전에 동결한다. 눈가림 파일럿에서는 분산과
벽시계만 열어 검정력·예산을 판정한다.

### 평가·운영

```text
공개 현재상태 → 학습된 모델 → 중앙 Resolver → 최종 배정
```

KEEP/SELL 두 세계를 운영 때 다시 굴리지 않는다. 운영 rollout을 허용하면 연구 대상은
학습정책이 아니라 온라인 시뮬레이션 최적화/MPC로 바뀌므로 금지한다.

## 5. 사건·행동 계약

- 판단 시점은 물리 블록 도착이 아니라 공개 ETA가 30분 창에 **최초 진입한 epoch**다.
- 같은 epoch에 새로 자격을 얻은 작업 전부를 `J_t`로 묶는다.
- 최종 행동은 `a_t=[dest(j_1),...,dest(j_m)]`; SELL/BUY는 제안·견적 의미다.
- KEEP을 포함해 결정 뒤 `allocation_decided=True`; 이후 재판매하지 않는다.
- 배정 실험에서는 ExecutionHead의 WORK/PREMOVE/WAIT 정책을 고정한다.
- 사건 간격이 다르면 할인은 실제 경과시간을 반영하거나 평균비용 계약을 쓴다.

## 6. 검토한 대안과 기각 사유

| 대안 | 판정 | 사유 |
|---|---|---|
| 매 60초 반복 SELL/BUY | 기각 | KEEP 재검토 중복·희소 신호·표본 귀속 악화 |
| 작업별 독립 목적지 선택 | 기각 | 동시 수신 과부하·용량 상호작용 누락 |
| 운영 중 H-rollout | 기각 | 계산 폭발·정책이 아니라 온라인 MPC가 됨 |
| Seller/Buyer 별도 지역 목적 | 기각 | 떠넘기기 재발; 터미널 목적 하나 원칙 위반 |
| 명시적 내부 가격 | 기각 | 외생 시장가가 아니며 전역 목적에 불필요 |
| 배정과 실행 동시 재학습 | 기각 | 어느 축이 효과를 냈는지 식별 불가 |

## 7. 작업 분해와 순서

현재 단일축 순서 `YR-200→201→202`를 바꾸지 않는다.

1. [[YR-203]]: 최초 통지 1회·동시유입 batch의 사건/장부/Resolver 계약만 구현.
2. [[YR-204]]: 정책을 바꾸지 않고 장기 반사실 교사 데이터의 계산가능성·잡음 판정.
3. [[YR-205]]: 자격을 통과한 동일 데이터로 joint 대 Seller/Buyer factorization 비교.

## 8. 적용 범위와 되돌릴 조건

- 주장 범위는 문헌 보정 시뮬레이션의 H-21 반입 one-shot 재배정이다.
- 장기 라벨의 필요 표본이 예산을 넘거나 신호가 잡음보다 작으면 YR-204에서 종료한다.
- factorized 모델이 joint 모델보다 최종비용·예측력에서 열세면 별도 Seller/Buyer 의미를
  버리고 joint-score+Resolver를 유지한다.
- 현재 performance 게이트가 열리기 전에는 세 신규 row를 ready/in-progress로 옮기지 않는다.
