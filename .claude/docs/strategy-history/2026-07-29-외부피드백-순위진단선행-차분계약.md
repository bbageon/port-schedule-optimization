# 2026-07-29 — 외부 피드백: YR-127 결론 하향·순위 진단 선행·차분 계약 3요건

YR-127(갱신 ×20 기각) 보고에 대한 외부 피드백을 사용자가 전달("해당 피드백 참고해서
다음사항 진행해줘"). 결정 경위·원문 요지를 상세 보존한다.

## 피드백 요지 (원문 구조 보존)

1. **절대 예측력 ≠ 행동 구분력.** N1 개선(오차 99%→69%, 설명력 ~31%)은 "전체 비용
   규모를 얼추 맞히는" 능력이고, 행동 선택에 필요한 것은 SERVE 100.0 vs WAIT 100.3
   같은 **미세한 차이의 부호·순위**다. 전체 미래비용에는 해당 행동과 무관한 공통비용
   (주변 트럭·본선·다른 크레인)이 대부분이라, 1,003 vs 1,008 을 각각 회귀로 맞혀서
   차이 5 를 얻는 구조는 잡음에 묻힌다. "전체 미래비용을 잘 맞힘 ≠ 좋은 행동을 잘
   구분함"이 이번 실험의 핵심.
2. **결론 하향 (정확한 문구).** "학습 목표가 WAIT 를 선호한다"는 서술은 "실제 터미널
   비용 목적함수에서 WAIT 가 정말 최적"까지 읽힐 수 있어 과함. 확정된 것은:
   **"현재 상태·후보·보상 귀속·TD 학습 방식의 조합에서 Q 망이 WAIT 를 더 낮은 비용으로
   평가한다"** 까지. 원인 후보는 복수: ①큰 공통 미래비용에 행동 차이가 묻힘 ②WAIT
   구간 비용이 WAIT 행동에 정확히 귀속되지 않음 ③부트스트랩 오차 누적 ④WAIT/SERVE
   표본 수·목표값 분포 차이 ⑤절대비용은 배우나 행동 간 순위는 못 배움. 따라서
   "목적함수 자체가 틀렸다"보다 **"현재의 총비용 회귀 방식이 행동별 책임을 제대로
   나누지 못한다"** 가 정확한 결론.
3. **차분 신용의 기대효과와 조건.** 기대: 공통 미래비용 상쇄·행동 간 차이 직접 학습·
   장기 전파 의존 감소·기여 행동 구분 용이. 단 자동 성공이 아니며 계약 3요건:
   - **기준행동 정의**: 무엇을 기준(반사실)으로 삼는지 명시.
   - **동일조건 반사실**: 같은 상태 사본·같은 창에서 반사실 비용을 계산.
   - **강제 WAIT 와 전략적 WAIT 분리**: 기준을 WAIT 로 쓸 경우 필수 (선택지가 없어서
     하는 WAIT 를 기준으로 쓰면 안 됨 — YR-121 경계 계약과 정합).
4. **순서**: YR-125(차분) 재학습 착수 전에, **기존 체크포인트에서 WAIT/SERVE/REPOSITION
   의 Q 순위 vs 실제 사후비용 순위 일치도를 먼저 측정**해 차분이 고칠 문제가 실제로
   "가치 순위 오류"인지 확인하라.

## 반영 결정

- **YR-127 결론 문구 하향 정정**: done.md row·report.md·spec 에 ★정정 표기로 반영
  (사후 서술 정정 — 판정 수치·기각 결론은 불변).
- **YR-128 신규 등록·즉시 착수**: 가치 순위 진단 (Q vs C600 순위 — R1 top-1 / R2
  Spearman / R3 WAIT 방향 혼동표 P(cw|qw), 해석 규칙 H-순위결함·H-실제선호 동결).
  반사실 척도는 YR-063 계보의 `_rollout_cost` 600s (오라클 — YR-107 진단 특권,
  YR-065 창 한계 고지). H-실제선호로 나오면 차분도 같은 창 함정을 공유하므로
  **목표 회계 재검이 차분에 선행**한다는 분기까지 동결.
- **YR-125 2단계 계약 갱신**: 위 3요건을 spec 에 명문화, YR-128 을 착수 게이트로 지정.
