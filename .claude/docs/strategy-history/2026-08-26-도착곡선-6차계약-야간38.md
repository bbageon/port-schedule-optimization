# 2026-08-26 — 도착 곡선 6차 계약: 야간 38% · 봉우리 셋 · 부하 5단

> 사용자 지시. 5차 계약([2026-08-11 이중피크](2026-08-11-24시간-이중피크-상수-유도-사전등록.md))을 대체한다.
> **이 문서는 요약하지 않는다** — 결정 경위·대안·설정·근거 수치를 그대로 보존한다.

## 1. 발단

사용자가 외부 피드백을 받아 곡선 수정을 요청했다. 확인 물음에 대한 답:

> *"야간에도 물량이 0이 아니라 **24시간 연속으로 진행**되기 때문이야"* (2026-08-26)

부산신항은 **게이트가 24시간 돈다**. 5차 계약의 야간 15% 는 야간 물량을
과소평가했다.

## 2. 바뀐 상수

|---|---|---|
| 야간 바닥 | 일평균의 **15%** | 일평균의 **38%** |
| 오전항 | N(11.0, σ=1.0) × 0.333 | **N(10.0, σ=1.5) × 0.317** |
| 오후항 | N(15.0, σ=2.0) × 0.667 | **N(15.0, σ=2.5) × 0.633** |
| 저녁항 | — | **N(21.0, σ=1.0) × 0.050** ★신규 |

가중은 **봉우리끼리의 상대값**이다 — 총량의 38% 를 야간 바닥이 먼저 가져가고,
남은 62% 를 셋이 0.317 : 0.633 : 0.050 으로 나눈다.

## 3. ★결과 — 곡선이 평평해져 **옛 혼잡이 사라졌다**

바꾸기 **전에** 계산해서 확인했다 (부하 7,500 기준):

| | 5차 | 6차 |
|---|---|---|
| 최대 도착률 | 961대/h | **581대/h** |
| 크레인 능력(840) 대비 | **114%** | **69%** |
| 능력 초과 시간대 | 3개 | **0개** |
| 야간(0~6시) | 47대/h | **119대/h** |

**우리 핵심 결과([[YR-232]] 고전 5종 전부 승)는 부하 7,500 이 능력을 넘었기 때문에
나왔다.** 6차 곡선에서는 7,500 이 더 이상 혼잡이 아니다.
