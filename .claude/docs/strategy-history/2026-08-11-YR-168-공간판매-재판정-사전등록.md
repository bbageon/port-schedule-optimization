# YR-168 공간 판매 재판정 — 사전등록 (2026-08-11 동결)

41차 감사 결정을 그대로 이행한다. **결과 열람 전 동결**이며, 실행 후 이 문서의
숫자·규칙을 바꾸지 않는다. 인가: `authorize-next allowed=true`(게이트 c113f12,
보정 대상 `performance` 단일축).

## A. 무엇을 묻는가 (두 질문을 분리한다)

- **Q1 이득 존재** — 판매 1건의 **평균 실현 이득이 0보다 큰가**. ← 본 판정
- **Q2 견적 구분력** — 견적이 이로운 판매를 골라내는가(순위상관). ← 본 판정
  0B 에서 STOP 을 낸 미해소 축이다(중앙 ρ = −0.204, 임계 0.3).
- **Q3 효과 크기** — 0.5 등가비용시간과 비교한 크기. ← **보고만 한다(합격선 아님)**

최종 운영 채택(안 팔기 vs 계산식 vs 학습 정책의 **하루 총비용** 비교)은 이 실험의
범위가 아니다 — 별건으로 backlog 에 둔다.

## B. 0.5 등가비용시간의 지위 (41차 감사)

**표본설계용 가정값이다. 운영 채택선이 아니다.** 비용 단위는 트럭 1대·1시간 = 1.
코드 확인(`cost_curve_v2.py`): 트럭 = 체류/3600 + max(0, 체류−2,580s)/3600,
본선 = **10.0** × 지연/3600. 따라서 0.5 는 대략 —

| 대상 | 0.5 등가비용시간 |
|---|---|
| 벌금 아래 트럭 대기 | 30분 |
| 벌금 위 트럭 대기(항 2개 적립) | 15분 |
| 본선 지연(ρ=10) | 3분 |

**정정 박제**: "0.5 ≈ 43분 벌금 1건 제거"는 **틀린 설명**이다. 벌금은 43분 자체가
아니라 43분을 **넘긴 초과분**에만 붙는다(임계에 딱 걸린 트럭의 벌금은 0).

**0.139(견적 중앙값)를 기준으로 쓰지 않는 이유**: 아직 정확성이 검증되지 않은
견적식이 스스로 매긴 값이라 그것으로 표본을 설계하면 순환 논리가 된다.

## C. 무대·정책 (동결)

- 무대: 5차 계약 24시간 이중 피크 — `build_diurnal` + `ScheduledAnnouncer`(개방
  루프). YR-167 재자격 12/12 통과본(`273ffc5`, 산출물 sha256 `61793868b905c688…`).
- **집행 정책 = SF(ServiceFirstSPT) 결정론** — 자격을 통과한 무대와 **같은 정책**을
  쓴다. 채택 PPO 집행 헤드로 바꾸면 다른 무대가 되므로 재자격이 필요하다.
  → **한계로 명시**: 이 결과는 SF 집행 조건부다.
- **판매 기준선 = `EstimatorBaseline`**(`yr168_pilot.py` 동결본). 정책의 역할은
  블록마다 후보 1건을 **지명**하는 것뿐이고(공개 ETA 최소·동순위 job_id 사전순),
  **판매 여부와 수신 블록은 전적으로 resolver 의 견적(NetGain)이 정한다.**
  압력 임계 같은 사전 필터를 두지 않는다 — 필터를 앞에 두면 "무엇이 골라낸 것인지"
  구분되지 않아 Q2 가 무의미해진다.
  · `UnifiedNetGain`(sell_gain.py)을 정책으로 쓰지 않는 이유: ①`a_gate_in`(실현
  게이트인)을 읽어 준수오차 도입 시 정보 누출이 되고 ②큐 추정기가 resolver 와 달라
  제안 기준과 좌표 견적이 서로 다른 잣대가 된다. 지명은 공개 ETA 만 쓰고 비용 계산은
  resolver 하나로 통일한다.
- 기저 세계 = 전건 KEEP(판매 0건).
- 시드: **8,300,000 대역**(자격 8,100,000~2·관찰과 교집합 0). 배경 시드도 분리.

## D. 표본 (동결)

- **독립 표본 1개 = 하루 시드 1개 = 판매 1건.** 같은 시드에서 여러 건을 뽑아
  표본 수를 부풀리지 않는다.
- **처치 판매 1건의 선택 규칙(결정론)**: 피크대 **[11,16)시**에서 견적 기준선이
  **처음 발행**하는 공간 판매 제안 1건. 동순위는 `(t, job_id, dst)` 사전순.
  피크대로 한정하는 근거는 관찰 실측이다 — 기회 격차가 피크 평균 15.1(격차≥5 인
  시각 100%) / 야간 평균 0.32(격차≥3 인 시각 0%). **사전 선언이므로 유리 표본
  선별이 아니다.**
- **기본 표본 = 100쌍 이상.** 정확한 N 은 눈가림 파일럿의 σ 로 산출한다:
  `N = max(100, ceil((z_.05 + z_.20)² σ² / 0.5²))` (단측 α=0.05·검정력 80%,
  z=1.645·0.842).
- **예산 상한 = 300쌍.** 산출 N 이 이를 넘으면 **임계를 바꾸지 않고
  `POWER_FAIL`(검정력 부족)로 종료**한다.

## E. 눈가림 파일럿 (동결)

- 시드 8,300,000~8,300,011 (12쌍). 각 쌍 = 기저(전 KEEP) vs 처치(위 규칙 1건).
- **개봉하는 것: 짝차이의 표본표준편차 σ 와 유효 쌍 수, 그것뿐.**
- **봉인하는 것: 평균·부호·중앙값·개별값·순위상관.** 원자료는 sha256 만 공개하고
  본 판정 사전등록이 동결될 때까지 열지 않는다.
- 파일럿 표본은 본 판정에 **재사용하지 않는다**(시드 대역 분리).

## F. 판정 규칙 (동결)

측정: 실현 이득 `G = Φ_terminal(기저, 창끝) − Φ_terminal(처치, 창끝)`.
Φ = Σ블록 비용 + 주행/3600 + 기사 외부대기/3600 (전역이므로 수신 블록 부담·주행이
전부 포함된다).

- **축1 (이득 존재)**: G 평균에 대한 단측 t 검정 p < 0.05 **그리고** 95% 신뢰구간
  하한 > 0. → 통과 시 "판매는 평균적으로 이득이다".
- **축2 (견적 구분력)**: Spearman(견적 −ΔJ, 실현 G) ≥ **0.3** (0B 계약 승계).
- **결과 라벨(배타)**: `GAIN_AND_DISCRIMINATES`(축1·축2 통과) /
  `GAIN_ONLY`(축1만 — 이득은 있으나 견적이 못 고름) /
  `NO_GAIN`(축1 미통과·CI 폭 ≤ 0.5 → "이득은 0.5보다 작다"는 결론) /
  `INCONCLUSIVE`(축1 미통과·CI 폭 > 0.5) / `POWER_FAIL` / `INVALID`.
- **Q3 보고**: G 평균과 95% CI 를 0.5 와 대조해 **서술만** 한다(합격 판정 아님).

## G. 하드 가드 (판정 조건 — 위반 시 그 쌍은 실격)

- 두 세계 모두 **26시간(관측 24h + 배수 2h) 종료 시점**에 트럭 **3,600 완주** ·
  본선 완주 · 누락 0 · 취소 0.
- 처치 직전 `_state_digest` 동일(짝 성립 증명). 불일치 = 실격.
- 장부 면적 항등식·재고 보존 항등식·불변식 위반 = 실격.
- 처리량 감소 쌍은 **비용 단독으로 이득 판정하지 않는다**(별도 계수·보고).
- 실격 + 집행 불가 합계가 **표본의 10%** 를 넘으면 `INVALID`.

## H. 야간의 용도 (동결)

야간 **[2,8)시**는 효과 판정에 쓰지 않는다. 관찰에서 기회 격차가 0.32(≥3 인 시각
0%)이므로, **"쓸데없이 팔지 않는가"** 확인용으로만 쓴다 — 기저 정책이 야간에
발행하는 제안 수를 세어 보고한다(임계 없음, 서술 보고).
야간 명세를 [1,6)시에서 [2,8)시로 정정한 근거: 측정창이 2시부터 시작해 1시는
관측 자체가 불가능하다(40차 감사).

## I. 금지 (동결)
