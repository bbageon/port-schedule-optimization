# 채택형(RL+가드) 총비용 반납 — SF/무가드/가드 3자 분해 + 적대검증

> 파생: [본선STATE재학습-flowmargin-itcv5](2026-07-24-본선STATE재학습-flowmargin-itcv5.md) §9-10.
> 질문: "채택형(RL+가드)이 무가드 −9.8% 중 얼마를 반납하나" + "가드없는 것 구체 분해".
> **전부 문헌보정 시뮬레이션(numeraire_v1, ρ_vessel=33) — 실 부산항 운영 개선 주장 아님(D5).**

## 1. 방법

동일 15 seed × 4 cell(seed=BASE+500+i) 3자: **SF / 무가드 RL(목적 최적화 그대로) / 가드 RL(채택형)**.
가드 = 의무처리 하드가드(대기≥0.8×SLA=24분 트럭이 있으면 그 크레인은 강제 SERVE, feasible 조합만,
없으면 전체 폴백). itc-v5 net(flow_margin STATE). 목적 = numeraire_v1(트럭대기 + 33×선석초과 +
rehandle + crane). 반납 = 가드총비용 − 무가드총비용(양수=가드가 더 비쌈).

## 4. 결과 C — 행동·물리 3자

## 6. 판정 (적대검증 반영·교정)

- **채택형 총비용 = 무가드와 구분 불가 수준 유지 + 트럭 P95 SF 수준 복구.** 단 "공짜"가 아니라 **주
  목적 차원(선석초과)에서 이득의 약 1/3 반납 → 트럭으로 되사오는 재구성.**
- **"반납 0 증명" 아님**: CI 0 포함 = 이 표본서 미탐지일 뿐, 상한 +1.83(절감의 ~30%) 반납 가능성 열림.
  등가검정(TOST) 미실시. "거의 공짜/그대로 유지"는 점추정 프레이밍 — 철회.
- **절감 크기는 견고한 효율 수치 아님**: ρ_vessel=33 가중 + seed 대역 조건부(−6~−10%), 본선 한 항의
  33배 증폭 산물. 가중치 낮추면 헤드라인 축소·트럭 P95 대가 부각.
- **운영 함의**: 무가드 = 목적 총비용 점추정 최소(트럭 꼬리 희생). 채택형 = 총비용 거의 동급 + 꼬리
  보호. 어느 쪽을 택하든 목적 밖 P95 라는 별개 축의 문제 — 값은 전부 시뮬 내부 동역학(D5).

## 7. 검증 (67줄 적대검증 워크플로우 3-agent)

  (make_cost total=Σcontrib 항등), 항목별 Δ합 −6.12 복원. 셀 pooling 은 CI 를 넓히는 **보수적** 방향
