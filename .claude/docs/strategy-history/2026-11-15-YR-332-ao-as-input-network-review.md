# YR-332-ao/as — 합성 입력 구현과 신경망 전략 검토의 결정 경위

2026-11-15. 사용자: 신경망 설계 전략을 검토하고 앞서 제안한 합성 데이터 구성을 진행한다.
이 기록은 이번 입력 선택의 전체 경위다. 이전 설계 기록을 덮어쓰지 않는다.

## 1. 시작 상태와 범위

시작 HEAD는 dfb330c8. aq 모델은 실제 자료로 보정한 합성 환경에서 3개를 재학습했으나
SF_SPT보다 평균 트럭 시간이 27.07% 길고 초기값별 결과가 흔들렸다.
현재 게이트는 신뢰성 PASS, 시드 현실성 FAIL, 성능 FAIL이다.
aq의 bfd096a5 게이트와 정확한 파일 해시로 ao `REMEDIATION/scenario_validity` 착수 허용을 재확인했다.
사용자는 합성 입력 구현을 승인했고, 신경망은 우선 검토를 요청했다. 두 축을 동시에 교체하지 않기로 했다.

변경 범위는 하루 시간대 도착 모양이다. 물량 3,500/7,500/15,000건, 반출 확률,
관측 분별 방문 형판, 다중 오더 방문, 정보 보정, 물리, 정책, 비용, 교사, 최적화기를 유지한다.
전역 기본 입력은 바꾸지 않고 선택 가능한 곡선 은행을 만든다.

## 2. 처음 시도한 곡선과 실패

이미 개발에 사용한 2026-10-28~11-09의 13일, 진입 오더 34,304건의 시간대 비중을 썼다.
방문 단위의 날짜 곡선과 혼동하지 않도록 `gate_in_time`별 오더 집계로 맞췄다.
원래 식의 24시간 균등 기저와 세 Gaussian(중심 10/15/21시, 폭 1.5/2.5/1시간)을 그대로 두고
합이 1이고 음수가 아닌 네 계수를 날짜별 제약 최소제곱으로 맞췄다.
0~24시간 안에서 각 성분의 적분을 정규화했다. 네 성분의 모든 활성 집합을 조사해 최소를 구했다.

실행 전 판정은 날짜별 적합 잔차가 그 적합 곡선에서 같은 N개를 1,000회 뽑은
다항 표본잡음 거리의 95% 값 이하인지다. 날짜별 잡음 seed=9934000+날짜 순번이다.
이 기준은 표현 가능성 진단이며 현실성·예측 검정이 아니라는 제한을 같이 적었다.
원래 가족은 **0/13일**, 잔차 0.043441~0.134933이었다.
평균 잔차가 가장 큰 시간은 12시(관측−적합 −0.012984), 그 뒤 11시(+0.007459), 19시(+0.006285)다.
따라서 계수의 임의 ±10% 흔들기를 채택하지 않았다.
첫 구현·사전등록은 5f1396e3에 저장했고 최초 결과 `calibration.json`/`bank.json`도 보존한다.

## 3. 입력만 본 곡선 가족 수정

로그 Fourier 1~8차를 입력 탐색했다. 통과 날짜는 차례대로 0/0/1/2/5/5/6/9일이었다.
이 탐색은 정책을 실행하지 않은 입력 적합이며, 높은 차수가 필요하고 설명이 간단하지 않아 최종 가족으로 쓰지 않았다.
주기적 선형 곡선의 삼각형 기저도 6/8/12/24개 시간 지점으로 비교했다.
통과 날짜는 0/0/3/13일, 잔차 범위는 각각 아래와 같다.

| 지점 수 | 최소 거리 | 최대 거리 |
|---:|---:|---:|
| 6 | 0.059014 | 0.103002 |
| 8 | 0.049599 | 0.101356 |
| 12 | 0.034718 | 0.079441 |
| 24 | 0.000000086 | 0.000437 |

시간 간격 1시간인 24개 지점 가족을 선택했다. 양수·합 1·자정 연속성은 기저와 제약으로 보장된다.
입력 자료를 본 뒤 한 수정임을 사전등록 아래 별도 절로 공개했다. 정책 성능으로 선택한 것이 아니다.
24개 시간대에 24계수를 맞추므로 작은 잔차는 표현의 유연성 근거일 뿐, 실제 날짜 분포 추정 성공을 뜻하지 않는다.
수정 구현과 가족별 최종 적합은 d74cbac5 코드에서 실행했다.

## 4. 새 합성 곡선의 추첨과 분할

하루마다 서로 다른 두 개발 날짜의 적합 계수 벡터를 균등 추첨한다.
U(0,1) 혼합비로 계수를 보간한다. 원본 오더/방문 시각은 복사하지 않는다.
이는 관측 범위 안의 조건을 만드는 가정이며 실제 날짜의 발생 확률을 추정한 것이 아니다.
보간이 산포를 줄인다는 점을 숨기지 않는다. 봉우리 위치·폭까지 추가로 독립 추첨하지 않는다.

- 곡선 bank seed=9934000; 이름공간 `ao:day-shape:<seed>:<split>`.
- 학습 24개, 선택 6개, 잠금 6개. 새로운 곡선 조합과 분리된 이름공간을 사용한다.
- 고정 곡선=학습 24개의 시간대 비중 평균. 선택·잠금은 평균 계산에 넣지 않는다.
- 초기 사건 시드=9934100+100×분할번호+곡선번호. 분할번호 0/1/2.
- 첫 입력 비교는 학습 첫 3개×3개 부하×고정/변동 18개, 동일 입력 추가 1회 재현.
- 전체 잠금 입력의 정책 결과는 열지 않았다. 입력 제약만 사전 확인했다.

## 5. 방문 규격 감사와 재고 문제

첫 입력 감사는 반출 오더의 `size_ft40`를 실제 반출 크기로 읽어 용량 위반이라고 잘못 판단했다.
반출의 크기는 대상 컨테이너가 정한다. 감사 코드를 그 기준으로 고쳤으며 물리/방문 생성기는 바꾸지 않았다.
다음 감사에서 seed=9934102·15,000건의 반출 44건이 반입으로 바뀌는 기존 동작을 실제 발견했다.
블록별 18(Y03)+25(Y05)+1(Y12)건이고 곡선 변경 전에도 발생했다.

선택지는 공급 생성기 변경 또는 조건부 입력 범위 제한이었다. 전자는 재고 배치까지 바꾸므로 at로 분리했다.
이번에는 모든 곡선은 유지하고, 작업 종류를 보존하는 배경만 구성한다. 정책 성능을 기준으로 고르지 않는다.
각 곡선의 배경 후보를 3개 부하 모두 확인하며 반출→반입 전환이 있을 때만
`요청 시드+1000×재시도 번호`로 다시 뽑는다. 최대 20회, 고정/변동 대조군은 같은 최종 시드다.
모든 거절 원장과 최종 시드를 저장하며 유효하지만 혼잡한 입력을 버리지 않는다.

41개 후보에서 5개를 거절하고 36개를 확정했다. 거절은 모두 15,000건에서 발생했다.
9934102:44건, 9934104:1건, 9934112:315건, 9934116:13건, 9934118:361건, 합 734건이다.
5개 모두 첫 재시도에 성립했다. 입력 도메인은 재고가 성립하는 조건부 상황이며 전역 생성기의 근본 해결이 아니다.
재시도 코드·계약은 609d1cf6에서 동결했다. 18개 짝 입력 감사·반복 동일성이 통과했다.

## 6. 신경망 검토에서 바로잡은 점

10→64→64→1 MLP는 이미 가변 후보 전체를 일괄 평가한다. 로그에 최대 657개 후보도 있다.
현재 목적함수는 두 점수 차이와 정규화된 반사실 비용 차이의 SmoothL1 회귀다. PPO·DQN 갱신은 없다.
최신 aq의 행동 정책은 초기값으로 고정하고, 학생은 매 회차 새 정답만 50회 학습한다.
모델별 총 수집 쌍 92/105/86, 총 학습 분할 76/87/72, 마지막 회차 학습 16/16/12쌍이다.
이전 회차 자료를 재사용하지 않아 망각 가능성을 323-d 진단 후보에 추가했다. 원인 확정이나 재학습 결과는 아니다.

143편 리뷰와 항만 논문 세 편은 확인했다. 여러 블록 연구는 CNN+MLP+공유 PPO이고,
쌍둥이 크레인은 자기 Attention+PPO, AGV/YC 적하는 관계별 그래프 합성곱이다. 모두 GAT인 것은 아니다.
MLP가 오래됐다는 이유만으로 교체하지 않는다. 같은 정보로 MLP/관계망을 비교하고 알고리즘은 별도로 비교한다.
PPO는 실제 실행 행동 확률과 공동 배정기의 정합을 먼저 설계해야 한다.

## 7. 적용 범위·재검토 조건

전체 현실성과 성능은 통과로 올리지 않는다. 운반·대기열, 전역 공급, 원본 분별 형판 문제가 남는다.
관측 집계를 썼으므로 통계 보정 합성이라고 기술한다. 통계 사용을 공개할 수 없는 연구에는 이 설정을 이식하지 않는다.
후속 ao 고정 정책 민감도, at 공급 보정, ar 수식 도착, 323-d 학습 진단을 각각 분리한다.
새 날짜에서 잔차·산포가 맞지 않거나 조건부 재고 선택이 비교를 좌우하면 곡선/배경 설정을 재검토한다.
새 망·PPO·새 학습은 이번에 실행하지 않았다. 근거와 모든 시드는 `outputs/reports/yr332_day_shapes/`에 보존한다.
