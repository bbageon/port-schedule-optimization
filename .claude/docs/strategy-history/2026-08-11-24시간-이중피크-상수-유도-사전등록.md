# 2026-08-11 — 24시간 이중 피크 환경: **상수 유도 사전등록** (자격 실행 전 동결)

5차 계약 전환([결정](2026-08-11-부하계약-도착률-24시간-이중피크-전환-사용자결정.md))의
파라미터를 **결과 열람 전에** 유도·동결한다. 모든 값은 이미 등록된 앵커·측정치에서
유도하며, 자격런 수치를 보고 조정하지 않는다.

## A. 도착 곡선 (일 총량 → 형상 → 저점)

**A1. 일 총량** = 일평균 **150대/h × 24h = 3,600대/일**
근거: 게이트 처리율 앵커 [60,225] 대/h 의 중심 부근이며, 부산신항 P터미널 4주 실측
일평균 3,790대(158/h)와 근접(박상국·김영두 2016). **앵커는 24시간 평균 지표**이므로
순간 피크가 225 를 넘는 것은 위반이 아니다(앵커 자체가 연/일 평균 환산값).

**A2. 피크 창** (국내 A급 실측 그대로): **오전 10~12시**, **오후 13~17시**
(박상국·김영두 2016 Fig.5 최혼잡 구간). 정규 형상의 ±1σ 가 그 창을 덮도록:
- 오전: 중심 **t₁ = 11.0시**, **σ₁ = 1.0h** (10~12시)
- 오후: 중심 **t₂ = 15.0시**, **σ₂ = 2.0h** (13~17시)

**A3. 형상식** (동결):
```
λ(t) = b + A₁·φ((t−t₁)/σ₁)/σ₁ + A₂·φ((t−t₂)/σ₂)/σ₂ ,  A₂ = 2·A₁
```
φ = 표준정규 밀도. A₂=2A₁ 는 오후 창(4h)이 오전 창(2h)의 2배라는 실측 폭 비율에서
유도(자유 선택 아님). 이 형상에서 두 봉우리 높이는 자동으로 같아진다
(A₁φ(0)/σ₁ = 2A₁φ(0)/σ₂).

**A4. 야간 저점 b 와 피크 배수 r 의 관계** (총량 제약 24b + 3A₁ = 3,600 에서):
```
r = peak/평균 = 3.192 − 2.192·f  ,  f = b / 평균
```
| f (야간/평균) | r (피크 배수) | 피크 λ | 비고 |
|---|---|---|---|
| 0.00 | 3.19 | 479/h | 야간 도착 0 — 비현실 |
| **0.15** | **2.86** | **429/h** | **채택** |
| 0.25 | 2.64 | 396/h | 피크가 능력과 동률 |
| 0.35 | 2.42 | 363/h | 과부하 미달 |

**A5. f 의 결정 근거(설계 요건)**: 피크에서 **터미널 트럭 처리능력을 5% 이상 초과**해야
줄이 쌓여 벌금 구간에 닿는다. 능력 = 400대/h(아래 B1) → 피크 ≥ 420/h → r ≥ 2.80 →
**f ≤ 0.18**. 문헌 대역([2.0, 3.2] — 업계 과밀 경계 2.0, 뉴욕항 환산 상한 3.2)과의
교집합에서 **f = 0.15(야간 22.5대/h), r = 2.86, 피크 429대/h** 를 채택한다.
(국내 야간 물량 숫자표는 공개 문헌·공공데이터에 없어 f 는 **설계 파라미터**이고,
그 사실을 한계로 박제한다.)

**A6. 도착 시각 생성**: λ(t) 의 정규화 CDF 역함수로 층화균등 분위를 사상(기존
`_peak_warp` 의 방식과 동일 원리, 단 이중 정규 형상). **결정론**(추가 난수 소비 0).

**★A7. 산술 정정 추록 (2026-08-11, 구현 검증 중 발견 — 형상·제약 불변)**
A4·A5 표의 "피크 λ" 열은 **두 봉우리의 겹침**(오후 정규가 오전 피크 위치에 더하는 몫)을
빠뜨린 계산이었다. A3 식을 그대로 수치 적분하면:

| 항목 | 문서 표기(오류) | **실제(A3 식)** |
|---|---|---|
| 순간 최대 λ | 429대/h | **488.7대/h @ 11.15시** |

**바뀐 것은 산술뿐이고 동결 입력(총량·피크 창·σ·A₂=2A₁·f=0.15)은 그대로다.** 설계
요건("피크가 능력 400대/h 를 5% 이상 초과")은 정정 후에도 충족하며 오히려 **22% 초과**
(이용률 1.02~1.22)가 된다 — 요건을 만족시키려고 값을 고친 것이 **아니다**.
W11 의 비교 기준은 A3 식에서 유도한 **계획 시간대별 최대 461.2대**(±10%)로 확정한다.

## B. 터미널 처리능력 (앵커 실측에서)

**B1.** 크레인 1회 146.5초(YR-158 런 실측) → 블록당 2기 = 49.1회/h.
트럭 1건 = 1.83회(재취급 포함, 268초/146.5초). 본선 스트림은 25회/h 선점.
- 본선 없는 블록: 49.1/1.83 = **26.8대/h**
- 본선 있는 블록: (49.1−25)/1.83 = **13.2대/h**
동시 활성 본선 6블록(아래 C1) 기준 터미널 능력 =
6×13.2 + 15×26.8 = **약 481대/h**. 보수적으로 재취급 변동을 감안해 **400~480대/h**
대역으로 보고, 설계 판정에는 하한 400 을 쓴다(피크 429 = 이용률 0.89~1.07).

## C. 본선 물량 재유도 (24시간)

**C1.** 목표 = 계획 작업률 앵커 [145,170] moves/h 유지.
스트림 1개 = 120 moves × 144초 = **4.8시간** 지속, 25 moves/h.
동시 활성 c 개면 작업률 = 25c → **c = 6** 이면 150 moves/h ✓
하루 총 스트림 = c × 24/4.8 = **30개/일**(시작 시각 24시간에 균등 분산·시드 추첨).
- 구판(5시간·12스트림 동시)의 야드 선점 부담이 **절반으로 줄어** 장치율 앵커와의

- 양하 15 × 120 = 1,800개 유입 / 적하 15 × 120 = 1,800개 유출 → **야드 균형**.
