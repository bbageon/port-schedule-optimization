# YR-332-az: 전역 대기 정보의 설명력을 먼저 확인하는 결정

## 결정 경위와 승인 범위

11월17일 ay에서는 Transformer와 PPO의 예측 목표 눈금만 PopArt로 바꿨다.
기존 대비 총비용−7.55%, 트럭시간−8.74%였으나 반출+1.98%, 본선지연비용+0.74%였다.
양하·적하 합산 평균도982.648→988.380분으로0.583% 늘었다. 기본 정책을 교체하지 않았다.
새 날짜의 예측 오차는 물량3500/7500/15000에서1.6995→2.2341,1.8075→2.0410,
3.9629→3.9357이었다. 목표 눈금 수정만으로 예측 오차 문제가 해소됐다는 근거가 없다.

11월17일 등록한 az는 지역 후보와 시각으로 터미널 전체 남은 비용을 예측하는 정보 범위 차이를 짚었다.
11월18일 사용자는 이 안을 제시하며 “이거 한번 검토해서 진행해볼래?”라고 실행을 요청했다.
이 새 요청을 예측 진단→조건부 정책 비교라는 두 단계 합성 실험의 승인으로 기록했다.
과거 ay의 승인 범위를 자동 승계하지 않았다. 현실성 게이트를 통과 처리하거나 현장 개선을 주장하지 않는다.
`authorize-next`의 실제 응답은 현실성 선결 미충족으로 종료코드2였다.
명령·원래 거절·새 사용자 요청은 `outputs/reports/yr332_global_value_context/authorization.json`에 보존했다.

## 가설의 범위와 대안

가설은 같은 지역 후보 상태에서 전역 외부 트럭 대기 규모가 남은 비용 예측에 추가 설명력을 갖는가다.
전역 정보 부족이 이미 확정된 원인이라는 주장은 아니다. 양수 학습 신호 비율을 성공 기준으로 쓰지 않는다.
검토한 대안은 비용망 눈금 추가 조절, 선택망에도 전역 입력 추가, 본선·트럭별 여러 상태 동시 추가,
개별 행동의 반사실 비용 분리, 그리고 보상창 축소였다. 이번에는 모두 제외했다.
그 이유는 기존 증거에서 남은 예측 문제를 직접 겨냥하는 한 축 비교를 지키고 원인을 분리하기 위해서다.
본선 상태를 추가하지 않았다는 한계는 남는다. 외부 트럭 대기 합계 하나가 터미널의 충분한 상태는 아니다.

문헌도 중앙 비용 예측이 언제나 좋다고 보장하지 않는다.
MAPPO의 전역 정보 활용 원리와 중앙 평가자 분석의 편향·분산 경고를 함께 확인했다.
따라서 새로운 정보를 넣자마자 강화학습 예산을 쓰지 않고 같은 경험의 예측 비교를 앞에 둔다.
공유 표현은 예측 진단에서는 고정한다. 정책 비교에서는 기존처럼 공유하여 비용 손실이 표현에 영향을 준다.
공유 표현까지 분리하는 별도 아키텍처 실험은 포함하지 않는다.

## 정보 시점·단위 계약과 구현 검토

각 블록은 `run_until_decision`까지 독립 전진한다. 결정 중 다른 객체의 대기를 합산하면 미래가 섞일 수 있다.
초기0과 기존review의 전 블록 동기화 지점에서만 읽기 전용 관측을 만든다.
관측은 공개 접수와 원장 갱신 후 저장하며 기존 사건·결정·접수 주기를 늘리지 않는다.
review가 같은 시각의 블록 사건보다 먼저 돌아올 수 있음을 엔진에서 확인했다.
이 동률은 실제 처리 순서를 따르며 나중에 처리될 도착·시작을 관측 당시 상태에 역으로 넣지 않는다.
활성 블록의 시각 일치, 모든 블록의 미래 시각 부재, 합계, 결정시각 이하 관측을 검사한다.
대기는 `kpis.waiting_count()`의 블록 도착 후 서비스 시작 전 외부 트럭 오더다.
이는 물리적 차량 줄 길이도, 방문 수·본선 작업 대기 합계도 아니다.
동일 프로파일을 블록들이 공유하므로 profile.block_id를 결정 블록 식별자로 쓰면 잘못될 수 있다.
실제 terminal의 simulator 객체→block key 대응을 사용하도록 구현했다.
24시간 뒤에는 기존 동기화review가 호출되지 않으므로 관측은24시간 값으로 남는다.
학습은24시간 전 결정만 사용한다. 배수 구간의 오래된 관측은 별도로 기록하며 미래 값으로 채우지 않는다.

입력은 `log1p(total_waiting_orders)/log1p(21*10)`이며 상한을 자르지 않는다.
상수는 기존21블록×블록 대기 눈금10에 따른 고정 단위다. 평가자료로 분모를 고르지 않는다.
두 군 모두 같은66→64→1 비용망이고 zero군은 마지막 입력을0으로 만든다.
기존65열을 그대로 복사하고 새 가중치 열을0으로 두므로 처음 예측과 작업 선택은 같아야 한다.
원자료에는 실제 관측을 양 군 모두 보존하고 신경망 입력0과 구분한다.
새 경험 저장 형식v2는 관측 근거·실제 신경망 입력을 명시한다. 구형 저장 함수가 이를 조용히 버리지 않게 한다.
과거 소스·해시는 그대로 과거 커밋에 보존한다. 현재 코드를 바꿔 과거 해시 검사 통과를 주장하지 않는다.

## 사전 고정한 실행 설정과 이유

전체 설정은 [실행 사전등록](../../../docs/research/v7-discharge/global-value-context-prereg.md)에 보존한다.
새 bank9964000, train13/selection3/holdout3이다. 이전36개와ay19개 곡선의 중복을 배제한다.
입력seed는train9964200+i,selection9964300+i,holdout9964400+i다.
같은 보정 가족의 새 합성 날짜이므로 새로운 실제 운영 기간을 검증한 것이 아니다.
train12는3500오더 동작 시험 전용이고 나머지12일은3500/7500/15000오더를 네 번 반복한다.
selection과holdout은 각각3곡선×3물량9입력이다. 초기재고 보존과 방문 연결은 유지한다.

고정 행동 정책은 ay PopArt 최종 모델 중 첫 번호9951101을 사용한다.
여러 행동 정책을 돌려 결과가 유리한 것을 고르는 절차는 없다. 그래도 이 한 정책의 경험 분포라는 한계가 있다.
비용망 비교는 ay PopArt9951101/9951102/9951103 가중치·통계를 각각 승계한 세 쌍이다.
새 Adam이므로 완전 이어학습이라고 부르지 않는다. 두 군의 출발값과 정규화는 각 쌍에서 동일하다.

예측용 경험은 학습일마다1024개, 검증입력마다2048개를 고정 난수로 중복 없이 뽑는다.
하루 안 결정의 무작위 train/test 분할은 사용하지 않는다. 날짜 단위로 분리한다.
비용망만Adam lr0.0003,묶음128,200회 반복 학습한다. Transformer 표현은 미리 계산해 재사용한다.
이200회는 비용망 설명력을 보는 지도 예측 예산이며 PPO 회차 확대를 의미하지 않는다.
0/20/50/100/200회 오차는 모두 공개하되 마지막200회로만 판정하고 최적 회차를 선택하지 않는다.
평가 단위는 날짜별 동일 가중 MSE를 평균한 제곱근, 모델 간도 같은 무게다.
전역 오차5% 이상 감소·세 쌍 각각 감소·물량별 악화2% 이하·6시간대별 악화5% 이하를 통과 조건으로 둔다.
이 임계는 정책 실험의 추가 계산량을 쓸 실용적 기준이며 외부 문헌의 유의수준이나 성능 보장이 아니다.
실패하면 표본·반복·기준을 바꾸지 않고 예측 진단으로 범위를 닫는다.

통과 시 PPO는 예측 진단의 가중치를 승계하지 않고 같은ay 출발모델을 복제한다.
모델마다12일·6갱신,2048표본·4반복·묶음64,lr0.0003·clip0.2·value0.5·entropy0.01·grad1이다.
원래24시간총비용·26시간실행·고정 보상 눈금368293633.7020551·음수 신호는 유지한다.
validation81회와holdout63회,최종정책 두 군 각1회 재실행을 사전에 고정한다.
평균 트럭만 보고 채택하지 않는다. 본선 합산·반입/반출/양하/적하·미완료와 본선비용을 함께 판단한다.
