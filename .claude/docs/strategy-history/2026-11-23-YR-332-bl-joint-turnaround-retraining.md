## 1. 결정 경위

- 2026-11-23 사용자가 트럭·본선 턴타임을 함께 줄이는 보상을 요청했다. 이전 세션이 `트럭 턴타임 합계(분) + 67 × 본선 턴타임 합계(분)`을 줄이는 값으로 정하고 기존 30일 원장에 적용했다. 순위는 짧은 작업 우선 27,926,124 → 기존 학습 모델 32,807,923 → 오래 기다린 작업 우선 36,057,211 가중 분이었다.
- 사용자가 "응 그러면 진행해봐"라고 답했다. 이전 세션은 학습 월 12,104,101(트럭 241,000건·본선 101척)과 시험 월 12,204,201(206,500건·97척)을 성적 확인 전에 지정했다. 각 월을 두 번 독립 생성해 지문이 일치했고, 고정 모델의 3일 재현에서 선택 8,105회에 새 학습 목표가 맞게 연결됨을 확인했다. 가중치 갱신은 0회였다.
- 공통 검사는 입력 재현 단계를 허용하고 성능 단계를 거절했다. 사유는 월간 연구의 현실성 선결 미통과다. 이전 세션은 "현장 검증 전에 합성 환경 탐색으로 먼저 재학습할지"를 물은 채 사용 한도로 끊겼다.
- 사용자가 그 기록을 붙여 "계속해서 작업 진행"을 요청했다. 에이전트는 이를 합성 환경 탐색의 선택으로 읽었다. 근거는 세 가지다. 현장 검증은 외부 자료 대기라 계속할 작업이 없다. 사용자가 2026-08-19에 "현 단계 목표는 강화학습 효과 검증이며 실데이터는 판정 전제가 아니다"라고 지시했다. bc에서 같은 방식의 제한된 탐색 선례가 있다. 거절 판정은 그대로 보존했고 해석임을 착수 기록에 적었다.

## 2. 검토한 대안과 기각 사유

1. **하루 단위 환경에서 보상만 바꿔 재학습.** 기존 모델과 학습 환경이 같아 한 축 비교로는 가장 깨끗하다. 기각했다. 보상이 "같은 입력 명단에서 전량 완료까지"로 정의돼 있고, 평가가 30일 연속 환경이며, 학습 월이 이미 등록·검증돼 있었다.
2. **기존 비용 예측부를 그대로 사용.** 기각했다. 기존 예측부는 하루 단위 원화 비용을 예측한다. 새 단위에서 설명력이 3일 시험 −16.9, 본 실행 첫 물결 −3.58이었다. 이대로면 첫 갱신의 신호가 예측 오차로 채워진다.
3. **비용 예측부와 공유 표현을 함께 먼저 학습.** 기각했다. 공유 표현이 바뀌면 작업 선택 확률이 달라져, 모아 둔 경험이 현재 정책의 것이 아니게 된다. 그래서 비용 예측부의 마지막 두 층만 고정된 표현 위에서 맞췄고, 맞춘 뒤 작업 선택 점수가 한 값도 바뀌지 않음을 검사했다.
4. **시계 입력을 하루=1로 유지.** 기각했다. 한 달이면 값이 35까지 커져 예측부의 입력 범위를 벗어난다. 작업 선택부는 시계를 입력으로 쓰지 않으므로 정책의 입력 계약은 그대로다. 기존 모델의 3일 재현이 30일=1 설정에서도 사건 단위로 보관본과 일치했다.
5. **갱신당 표본과 최적화 단계를 늘림.** 한 달을 굴려 얻는 결정 24만 개 중 512개만 쓰는 것은 낭비다. 기각했다. 학습량은 보상과 다른 축이다. 결과적으로 신호 대부분이 선택과 무관했으므로 표본을 늘렸어도 방향은 같았을 것으로 본다. 이는 측정이 아니라 추정이다.
6. **갱신 6회.** 이전 학습의 관례다. 4회로 정했다. 한 물결을 2~3시간으로 추정했기 때문이다. 실측은 88분이었다.
7. **학습 월의 앞 10일만 굴림.** 한 번이 4분의 1로 줄고 목표의 범위도 짧아진다. 기각했다. 등록·검증한 입력과 달라지고 화물 명단의 부분 사용을 새로 검증해야 한다.
8. **기준 방식 세 개의 시험 월 재현을 끝에 몰아서 실행.** 대신 학습 물결 옆에서 하나씩 돌렸다. 총 시간은 같고, 시험 월 고유의 오류를 첫 물결에서 미리 볼 수 있다.

## 5. 해석

- 보상 연결 자체는 맞다. 사건별 보상의 합이 최종 가중 턴타임과 일치하고, 결정별 목표가 원장에서 따로 계산한 값과 일치한다.
- 실패한 지점은 학습 목표의 범위다. 결정 하나의 목표에 한 달 치 터미널 전체 시간이 들어가, 비용 예측이 97.5% 이상 맞아도 남은 오차가 선택의 효과를 덮는다. 그 오차가 시각을 따라 움직이므로 갱신은 "언제 결정했나"를 따라갔다.
- 기존 모델은 선택 확률이 거의 평평하다. 그래서 작은 변화에도 최고 선택이 15% 안팎 뒤집혔고, 확률 선택 성적(+0.80%)과 고정 선택 성적(+23.07%)이 크게 갈렸다.
- 이전 하루 단위 학습도 "그날 터미널 전체 비용의 남은 합"을 목표로 썼다. 같은 현상이 있었을 가능성이 있으나 이번에 재지 않았다.

## 6. 적용 범위와 되돌릴 조건

- 이 결론은 "터미널 전체·월말까지" 합산하는 학습 목표에 미친다. 가중치 67, 모델 구조, 후보 구성에 대한 결론이 아니다.
- 모델 1개·학습 월 1개·시험 월 1개다. 다른 학습 난수에서 새 모델이 기존 모델보다 나아지는 결과가 반복되면 "악화"는 재검토한다. 신호 진단은 네 갱신에서 같았다.
- 학습 월(트럭 223분/작업)이 시험 월(94분)보다 훨씬 혼잡하다. 혼잡도가 비슷한 학습 월에서 신호의 시각 비율이 크게 낮아지면 원인 진단을 재검토한다.
- 후속은 합산 범위를 줄이는 [YR-332-bm](../dashboard-task-specs/YR-332-bm-local-return-scope.md)이다. 재학습 전에 저장된 학습 월 16개로 후보 목표의 시각 비율과 크기를 먼저 잰다.
