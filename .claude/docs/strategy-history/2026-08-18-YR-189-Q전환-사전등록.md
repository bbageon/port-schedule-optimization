# YR-189 사전등록 — 판매 축을 Q 채점으로 전환 (C안)

- **작성 2026-08-18 · 실행 전 동결** (이 문서 커밋 이후 §1~9 수정 금지. 개정은 별도 문서)
- **답할 질문 하나**: **학습 방식을 PPO 에서 Q 회귀로 바꾸면 규칙을 넘는가.**

## 1. 왜 지금 · 무엇이 바뀌나

[[YR-179]]·[[YR-180]] 이 처음으로 규칙 기준선을 재면서 드러난 것은
"학습이 규칙보다 못하다"였다. [[YR-185]] 가 그 원인 하나(보상 0 표본 91% →
critic 붕괴)를 특정하고 절반 고쳤다(격차 96.6 → 40.9). [[YR-183]]은 회차를
늘려 나머지를 메우려 했으나 **취소**했다 — 곡선이 iter 11~13 에서 이미
평평해졌고, 무엇보다 **구조를 바꾸므로 승계가 불가능**하다.

바뀌는 축은 **학습 방식 하나**다.

| | 구 (YR-185 까지) | 신 (이 판) |
|---|---|---|
| 망 | 정책망 + critic **둘** | **Q 하나** |
| 출력의 뜻 | "얼마나 선호하나"(확률) | **"비용이 얼마나 드나"** |
| 선택 | 추첨 / argmax | **argmin** |
| 손실 | PPO clip + 이점 정규화 | **후버 회귀** |
| KEEP | 학습되는 행 | **상수 0**(기준점) |
| 데이터 | on-policy (쓰고 버림) | **off-policy 재생** |
| 배정기 좌표 값매김 | 별도 계산식 `cost_given_queue` | **같은 Q 망** |

무대·보상 원료(`realized_credit`)·집행(크레인 동결)·행동 공간(`fixed15`
고정 +15분)·문턱은 **전부 그대로**다.

## 2. 왜 이 전환이 세 결함을 동시에 없애나 (설계 주장)

1. **critic 붕괴 재발 불가** — 붕괴할 critic 이 없다.
2. **0 보상 표본 91% 소멸** — KEEP 은 표본이 아니라 정의상 0 인 기준점이다.
   학습 표본은 "배정기가 실제로 고른 (작업, 좌표) 행"뿐이다.
3. **[[YR-175]](부호)·[[YR-177]](기준 불일치) 발생 지점 소멸** — 자가 하나뿐이라
   "공간은 자기 비용으로, 시간은 순비용으로" 같은 비대칭이 성립 불가다.

이것은 **설계 주장이지 결과가 아니다.** 아래 판정이 이를 검증한다.

## 2-1. ★정직한 명명 — 이것은 시간차 학습이 **아니다**

목표 `−D_i` 는 **그 거래의 실현 손익**이지 미래 가치의 부트스트랩이 아니다.
따라서 이 구조의 정확한 이름은 **Q-learning 이 아니라 문맥 밴딧(contextual
bandit) 위의 비용 회귀**다. 미래 파급은 `realized_credit` 의 분해식(수신 부담·
본선 압력·뒤차 지연) 안에 **근사로만** 들어 있다.

논문·보고에서 "Q 학습"이라고 쓰지 않는다. 쓰는 표현은
**"차분 신용 라벨을 쓰는 조합 행동공간 비용 회귀"** 다.

이 선택은 의도적이다 — TD 신용 희석([[YR-061]])이 이 문제의 실측 병목이었고,
직접 라벨은 그 경로를 아예 쓰지 않는다. 대가는 "먼 미래를 스스로 학습하지
못한다"이며, 그 한계를 여기 미리 적어둔다.

## 3. 문헌 정렬 (우리 발명이 아니다)

| 개념 | 원전 |
|---|---|
| 차분 신용(difference rewards) | Wolpert & Tumer (2002), Tumer & Agogino (2007) |
| 반사실 기준선의 신경망화 | COMA, Foerster et al. (AAAI 2018) |
| 조합 행동공간의 후보 채점 + argmin | 후보 채점 계열 |

문헌이 지적하는 위험 — **최고 후보 하나만 쓰면 채점 잡음에 민감** — 은 학습 중
ε 탐색으로 완화한다. 평가는 순수 argmin 이다.

| | |
|---|---|

| 집행 | `ADOPTED_C0_GUARD` (동결) · 크레인 가중치 불변 |
| 정보 계약 | `day_plan_public=True` — **학습·평가 전 팔 동일** |
| 회차 | **16** × 4 에피소드 (YR-183 실측: 곡선은 iter 11~13 에서 평평) |
| 시드 | **8,400,000** (1개) |
| 학습률 | 3e-4 (yr139 앵커 승계 — 구 PPO 와 동일) |
| 탐색 (제안) | ε = **0.15** — 어느 작업을 낼까 (학습 중에만) |
| 탐색 (좌표) | σ = **0.20** — 점수에 얹는 가법 잡음. 어디로/언제 팔까 (학습 중에만) |
| 재생 버퍼 | 150,000 표본 · 회차당 **600 step** · 미니배치 256 |
| **목표 눈금** | `Q_SCALE = 20.0` — 목표를 이 상수로 나눈다 (아래 §4-1) |
| 손실 | Huber(β=1.0) · grad clip 1.0 |
| 목표 | **Q(고른 행) ← −D_i** (`realized_credit`, 부호 반전) |

`realized_credit`·집행 설정은 [[YR-185]]·[[YR-183]] 과 **동일**하다.

### 4-1. ★목표 눈금을 왜 나누나 (실행 전 실측 근거)

배선 검증 스모크(**평가 대역과 무관한 시드 9,900,002**, 학습 안 한 망)에서 목표
`−D_i` 의 분포를 쟀다.

| | 값 |
|---|---|
| 평균 | **+10.78** |
| 범위 | **−45.4 ~ +126.6** |
| 라벨 붙은 표본 비율 | **95.6%** (1,509 / 1,579) ← 구 PPO 의 9% 와 대비 |

Adam 은 스텝 크기가 대략 학습률(3e-4)이라 4,800 스텝으로는 **10 단위 거리를 못
간다**. [[YR-170]] 에서 목표 −1,670 vs critic 출력 −0.06 으로 학습이 16시간 멈춘
것과 **같은 유형의 실패**다. 고정 상수 `Q_SCALE = 20.0` 으로 나눠 목표를 O(1) 로
만든다.

**판정에 영향이 없는 이유**: 결정 규칙이 `Q < KEEP_Q = 0` 이고 `0 / s = 0` 이므로
부호와 순서가 보존된다. 전역 매칭 비교도 같은 상수로 나뉘어 그대로다.

**정보 경계**: 이 상수는 **평가 대역(9,600,000~)이 아니라 스모크 시드**에서 왔다.
판정 데이터를 보고 정한 값이 아니다.

**자동 검사**: 회차마다 `pred_rms`·`pred_mean`·`target_mean`·`explained`
(=1−(RMSE/목표RMS)²)를 남긴다. 망이 목표에 못 닿으면 `explained ≈ 0` 으로 즉시
드러난다 — 조용한 무학습이 불가능하다.

## 5. 동결 — 평가

| | |
|---|---|
| **평가일** | **새 대역 9,600,000 + 1,000·i (i=0..15, 16일)** — 기존 전 대역과 무겹침 |
| 팔 | `K`(안 팔기) · `greedy`(규칙, [[YR-179]] `UnifiedNetGain` 문턱 기본값 동결) · `q`(학습된 Q) |
| **모드** | **argmin (결정론, ε=0·σ=0)** — 배포 방식. 추첨 모드는 존재하지 않는다 |
| 집행 | 세 팔 모두 `ADOPTED_C0_GUARD` |
| 비교 | 같은 날 짝지어, 독립단위 = **날**(n=16) |
| 가중치 | **마지막 회차 고정** (중간 지점 고르기 금지) |

**한계 (미리 적는다)**: 학습 시드는 **1개**다. 이 판정은 "이 초기화에서 나온
정책"에 대한 것이고 **시드 간 흩어짐은 재지 않는다** — [[YR-180]] 이 단일
체크포인트(`fixed15_s8400000`)로 판정한 것과 같은 관행이다. 결과가 유의하면
시드 확대가 다음 순서다.

### 5-1. ★이 대비가 무엇을 재는지 (오독 방지 — 실행 전에 못박는다)

`q` 팔은 **제안 정책과 배정기 값매김을 동시에** 바꾼다. `greedy` 팔은 규칙 제안 +
계산식 배정기다. 따라서 이 대비는 **부품 하나의 기여를 분리하지 않는다** —
**메커니즘 대 메커니즘**의 시스템 비교다.

[[YR-179]] 는 일부러 배정기를 고정해 "학습의 기여"만 분리했다. 여기는 반대로
**"학습된 판매 기구 전체가 규칙 기구 전체를 이기는가"** 를 묻는다. C안의 요지가
"자를 하나로 만든다"이므로 배정기를 떼어놓으면 그 요지 자체를 검증할 수 없다.

보고할 때 **"학습이 규칙보다 낫다"로 줄여 쓰지 않는다.** 쓰는 문장은
**"학습된 판매 기구가 규칙 판매 기구보다 낫다"** 다. 부품 분해가 필요하면
후속 단일축 실험(제안만 Q · 배정기만 Q)으로 따로 잰다.

## 6. 동결 — 판정

**주판정**: `q − greedy` (총비용 Φ, argmin)

| 결과 | 뜻 |
|---|---|
| 95% CI 전체가 **0 미만** | **학습이 규칙을 넘었다** → 서사 A 재검토 · A안(완전 통합) 값어치 재평가 |
| CI 가 0 을 포함 | **구분 불가** — "규칙 설계 없이 학습만으로 동등 도달". 이것도 결과다 |
| CI 전체가 **0 초과** | **못 넘었다** → 서사 B 확정 · 문제 성질 3차 확증 |

`|t| ≥ 2.13` (df=15, 양측 95%).

**함께 보고(판정 아님)**: `q − K` · `greedy − K` · A→O 평균·P95 ·
학습 곡선(RMSE·설명력) · 제안 수 · 공간/시간 판매 건수 · 좌표 분포.

## 8. 하지 않는 것

- 결과를 보고 판정축·모드·평가일·시드·회차를 바꾸는 것.
- 규칙 기준선을 약화시키는 것 — `gain_margin` 은 코드 기본값 동결.
- 중간 회차 가중치를 골라 쓰는 것.
- 이 판정으로 실제 항만 운영 대비 개선율을 주장하는 것.
- 차분 신용을 우리 발명으로 서술하는 것(§3 인용 필수).
