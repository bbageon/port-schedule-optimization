# 2026-07-30 — BlockQ-v3 전환: 공동 Advantage-Q (외부 7차 피드백, v2 마감)

## v2 마감 결정 (사용자 지시 "s123000 세부 원인 추적보다 세대 마감")

누적 근거 5: ①갱신×20 무효(YR-127) ②절대예측 개선에도 순위 불가(YR-128/130)
③WAIT 기준 차분 → REPO 풍선 이동(YR-125) ④순위손실만 → 비용 크기 상실(YR-131)
⑤미완 개수 잔여 → 시드별 효과 방향 반전(YR-132). 결함은 특정 파라미터·시드가 아니라
**정책 계약**: "하나의 신경망이 미래 총비용을 직접 예측하고 그 값의 미세 차이로 공동후보
순서를 결정한다". 단 절대 Q 를 버리고 SF-SPT 차이만 학습하는 것도 표준 해법이 아님 —
**표준 수정 = 절대 Q 유지 + V/A 분리(dueling)**.

## BlockQ-v3 계약 — 공동 Advantage-Q

    Q(s,a) = V(s) + A(s,a) − mean_{a'∈s} A(s,a')

- V(s): 어떤 후보를 골라도 공통으로 발생할 야드 비용 (상태 문맥 입력만).
- A(s,a): 공동후보 a 의 상대 가치 — 같은 상태에선 V 공통이라 **선택은 A 순서가 결정**,
  Q 전체는 절대 비용 크기를 보존 (YR-131 의 "순위는 순위로" 교훈과 비용 크기 보존 양립).
- 학습 신호 분리: (a) Q 절대비용 회귀 (b) [2단계, 필요시에만] 같은 상태 K 후보에서
  실제 비용 낮은 후보의 A 가 낮아지도록 순위 보조손실.

## 유지 / 중단

유지: 공동후보 생성 · 두 크레인 중앙 공동배정 · 물리·안전 resolver · 공식 비용계약 ·
같은 상태 K 후보 비교 구조.
중단: 단일 점수로 총비용+순위 동시 해결 · WAIT 기준 차분 · 미완 개수 보정 ·
λ/학습량/시드별 원인 미세조정 · 검증되지 않은 예약·가드·추가 상태정보.

## SF-SPT 의 올바른 역할 (학습표적 기준 아님)

①비교할 공동후보 중 하나(동등 경쟁 — 그 공동선택은 열거 조합에 자연 포함)
②rollout 후속 기준정책 ③성능 비교 기준선 ④성능 검증 후의 안전 fallback 후보.

## 검증 순서 (단일축 사다리)

1. **YR-135** 공동 V/A-Q 구조 — 상태·후보·비용표적 유지, 점수망 구조만 교체 (오프라인).
2. 순위 보조손실 — 1단계에서 순위 부족할 때만.
3. 오프라인 판정 — 순위상관·top-1·선택 후 손실 + 절대비용 오차 동시 측정.
4. 에피소드 판정 — 오프라인 두 능력 확인 후에만.
WAIT·새 상태정보·예약·가드·혼합 보정은 이 최소 정책 성능 확인 후 별도 단일축.
