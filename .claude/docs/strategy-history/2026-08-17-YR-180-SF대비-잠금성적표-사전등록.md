# YR-180 사전등록 — 현 무대 SF-SPT 대비 잠금 성적표

- **작성**: 2026-08-17 / **상태**: 실행 전 동결 (이 문서 커밋 이후 수정 금지)
- **목적**: 연구 최초로 **현 무대에서 현행 배차 규칙 대비** 비용을 잰다.
- **이 문서는 결과를 보기 전에 작성됐다.** 아래 항목은 실행 후 바꾸지 않는다.

## 왜 지금인가

지금까지 모든 성적은 **"안 팔기" 대비**였고, 크레인 집행은 `ADOPTED_C0_GUARD`
하나로 고정돼 있었다. 그 크레인 정책이 **이 무대에서 규칙을 이기는지는 한 번도
측정된 적이 없다**([[YR-184]]). 게다가 그 정책은 구 2블록 부하셀 무대에서
학습된 것을 얼려 쓰는 것이다.

밑바닥을 모르면 위층 숫자는 뜻이 없다 — 채택 정책이 규칙보다 5% 나쁘면
판매로 3% 를 벌어도 합계는 규칙보다 못하다.

## 동결 ① — 팔 (5개, 2×2 + 학습 변형)

| 팔 | 크레인 집행 | 판매 층 |
|---|---|---|
| `R` | **SF-SPT 규칙** | 없음 |
| `R_S` | SF-SPT 규칙 | **규칙 판매**(`UnifiedNetGain`) |
| `A` | 채택 정책(동결) | 없음 |
| `A_S` | 채택 정책(동결) | 규칙 판매 |
| `A_P` | 채택 정책(동결) | **학습 판매**(YR-171-C `fixed15`, 시드 8400000) |

판매 층은 전부 **고정 +15분 한 칸**(`time_slots=False`, `buy_net=None`).
48칸·견적망은 YR-177 미해소이므로 이 판에 올리지 않는다.

`A_P` 에 학습 팔을 넣는 이유는 YR-179 판정("규칙이 학습을 이김")을 새 시드
대역에서 **독립 확인**하기 위해서다. 학습 팔이 결론을 바꾸면 그것도 결과다.

## 동결 ② — 평가일 (새 시드 대역)

```
9_300_000 + i*1000,  i = 0..15   →  16 일
```

기존 사용 대역과 겹치지 않는다(학습 8.4~8.9M · YR-174 평가 9.0M · 정답지
9.1M · YR-171-C 평가 9.2M). **이 대역은 이번 판정에만 쓰고 재사용하지 않는다.**

## 동결 ③ — 판정 축

- **주판정 (공동)**: ①터미널 총비용 `Φ` ②평균 **실제 gate-in→gate-out (A→O)**
  — 2026-07-27 평가계약 그대로. 둘 다 봐야 "비용은 줄었는데 트럭은 더 오래
  머문다" 같은 뒤바뀜을 잡는다.
- **보고만**: P95 A→O · 판매 건수 · 완주율. **게이트로 쓰지 않는다.**

## 동결 ④ — 대비와 해석

| 대비 | 질문 |
|---|---|
| `A − R` | 얼린 크레인 정책이 이 무대에서 규칙을 이기나 (**최초 측정**) |
| `R_S − R` | 재배치 층이 **규칙 배차 위에서도** 이득인가 (일반성) |
| `A_S − A` | 재배치 층이 채택 배차 위에서 이득인가 (YR-179 재확인) |
| `A_P − A_S` | 학습 판매가 규칙 판매를 이기나 (YR-179 독립 확인) |
| **`A_S − R`** | **연구 목표: 전체가 현행 규칙을 이기나** |

## 동결 ⑤ — 통계

- 같은 날 **짝지어**(paired), 독립단위 = **날**(n=16).
- `mean ± se`, `se = pstdev/sqrt(n−1)`, `t = mean/se`.
- **방향 선언은 95% 신뢰구간이 0을 배제할 때만** 한다(|t| ≥ 2.13, df=15).
  아니면 `INCONCLUSIVE` 로 보고하고 그렇게 박제한다.
- **표본 확장 규칙(사전 지정)**: 어떤 대비든 신뢰구간 반폭이 **60 비용시간
  (대당 1분)** 을 넘으면 `9_400_000` 대역 16일을 추가해 32일로 간다.
  확장 여부는 **폭만 보고** 정한다 — 추정치의 부호·유의성은 보지 않는다.

## 동결 ⑥ — 하드 가드 (위반 시 그 셀 실격, 완화 금지)

1. 투입 = **3,600 전건**(`admitted == 3600`)
2. `policy_exceptions == 0`
3. 같은 날·같은 팔 재실행 시 `Φ` 완전 일치(결정론)
4. 실행 트리 `code_dirty == False`

## 동결 ⑦ — 하지 않는 것

- 결과를 보고 팔·평가일·판정 축·임계를 바꾸는 것.
- 규칙(`R`·판매 문턱)을 약화시켜 채택 정책을 이기게 만드는 것.
- 실제 부산항 운영 대비 개선율 주장 — 허용 범위는 **문헌 보정 시뮬레이션**까지다.
- `A − R` 이 양수(채택 정책 열세)로 나왔을 때 그것을 숨기거나 유보하는 것.
  **그 경우 연구 서사를 바꾸는 것이 옳은 대응이다.**

## 예상 결과가 아니라 대응 계획

| `A − R` | 뜻 | 다음 |
|---|---|---|
| 유의하게 음수 | 얼린 정책이 규칙보다 낫다 | 위층(판매) 논의가 성립. YR-183 재학습으로 진행 |
| 구분 불가 | 크레인 층 기여 없음 | 연구 주장을 **재배치 층 단독**으로 재구성 |
| 유의하게 양수 | 얼린 정책이 규칙보다 **나쁘다** | 크레인 재학습(YR-184 A안)이 선결로 승격. 현행 성적 전부 재해석 |

세 경우 모두 미리 적어둔다 — 결과를 보고 서사를 고르지 않기 위해서다.
