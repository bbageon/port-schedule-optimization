# WAIT-WAIT 정책 최적화 우선·배포 안전 분리 — 사용자 결정

## 1. 결정

YR-145의 `WAIT+WAIT` 실패를 곧바로 금지·강제대체하지 않는다. 연구 목표는 예외처리로
성공시키는 것이 아니라 **정책이 진행할 때와 기다릴 때를 스스로 구분하도록 최적화하는 것**이다.

순서는 다음으로 동결한다.

```text
정책 최적화(YR-147, 마스크 없음)
→ 단일블록 행동공간 검증(YR-143)
→ 배포 안전장치(YR-146)
→ 블록 간 판매·수용 견적(YR-133)
```

## 2. YR-145에서 실제로 일어난 일

high-loose/910017, PPO 초기화 123000에서 본선 적하 2건이 남았다. 두 크레인의 동시
SERVE는 물리적으로 불가능했지만 한 대씩 작업하는 두 공동행동은 가능했다.

| 공동행동 | PPO 예상비용(낮을수록 좋음) |
|---|---:|
| `SERVE+WAIT` | 14.2435 |
| `WAIT+SERVE` | 13.2208 |
| `WAIT+WAIT` | **12.5055** |

PPO가 전원 대기를 가장 싸다고 오평가했다. 실행 뒤 두 크레인이 모두 양보 상태가 됐고 미래
사건이 없어 재결정이 열리지 않았다. 따라서 “물리적으로 아무 행동도 불가능”이 아니라
**정책 순위 오류와 재개방 없는 WAIT 계약의 결합**이다.

## 3. 금지를 먼저 쓰지 않는 이유

- 하드 마스크가 있으면 완주해도 정책이 배운 것인지 안전층이 대신한 것인지 구분할 수 없다.
- 실제로는 구조적 대기와 전략적 대기가 모두 존재하므로 모든 WAIT에 고정 벌점을 주면
  유효한 기다림도 제거한다.
- PPO는 확률 정책이라 학습만으로 운영상 0건을 보장할 수 없다. 따라서 **최적화와 보장**을
  서로 다른 실험·주장으로 분리한다.

## 4. 정책 최적화 계약

원시 WAIT를 `DEFER_UNTIL(trigger, expiry)`로 바꿔 무엇을 언제까지 기다리는지 명시한다.
같은 상태·같은 난수에서 전원 대기와 안전한 진행 후보의 후속비용을 짝지어 비교한다.

```text
D_wait = C_H(WAIT+WAIT) - min C_H(안전한 진행 후보)
```

양수면 전원 대기가 손해이고 음수면 실제로 기다리는 편이 낫다. PPO는 이 부호·순위를
보조목표로 학습하되, DEFER 의미 교체와 순위손실은 같은 실험에서 동시에 바꾸지 않는다.
희귀 교착상태 추가도 앞 단계가 미달일 때만 별도 단일축으로 연다.

## 5. 판정과 허용 주장

연구 판정에서는 `WAIT+WAIT` 마스크를 사용하지 않는다. 회피 가능한 전원대기율, 정상 대기
선택 정확도, v2 비용, A→O, 본선 초과, 완주·backlog를 신규 시드로 함께 본다.

- 허용: “마스크 없이 정책의 회피 가능한 전원대기가 감소했고 운영비용이 개선/유지됐다.”
- 금지: 안전장치가 막은 결과를 “PPO가 학습했다”고 표현.
- 배포: YR-146에서만 진행 후보가 있는데도 전원 대기를 고르면 거부하고, 진행 후보가 전혀
  없을 때 최소 안전 escape를 확정한다.

## 6. 실제 환경과의 대응

같은 레일의 두 크레인 중 한 대가 일하고 한 대가 양보하는 것은 정상이다. 작업이 없거나
설비·하류가 막힌 구조적 대기도 정상이다. 반면 실행 가능한 작업이 남았는데 두 대가 영구
정지하는 것은 운영 교착이며, 실제 배포에서는 ECS/watchdog 성격의 YR-146이 최종 차단한다.

## 6-b. 재현 검증 (2026-08-03, 판정 체크포인트 재실행)

§2 의 수치를 B2:123000 체크포인트·high-loose/910017 재실행으로 독립 재현했다. **회피
가능한 전원 대기 결정은 1회가 아니라 3회**(t=17186.6 / 17366.6 / 17498.9)였고, 세 번
모두 같은 순위 오류(WAIT+WAIT 최저)였으며 마지막 결정의 예상비용이 §2 표와 소수 4자리
까지 일치(12.5055 / 13.2208 / 14.2435 순서 그대로). 결속 작업은
J-V-LOAD-1-05(YC-W 몫)·J-V-LOAD-1-09(YC-L 몫). 전략적 WAIT 금지(YR-052)가 못 막은
이유도 확인 — 그 규칙은 전원 실작업 조합이 존재할 때만 대기 조합을 제외하는데, 이
상태는 동시 SERVE 가 물리 불가(간섭)라 혼합·전원 대기 조합이 허용 목록에 남는다.
YR-147 1단계(기준 측정)의 회피 가능 전원대기율 분모·분자 정의는 이 계측 방식을 따른다.

## 7. Dashboard 영향

- 기존 YR-146 “엔진 강제 탈출 우선”은 배포 안전장치로 유지하되 YR-147·YR-143 뒤로
  순연한다.
- 마스크 없는 정책 최적화는 YR-147로 분리한다.
- YR-143의 선결을 YR-145에서 YR-147로 올리고, 연구 평가에서는 YR-146 guard를 끈다.
- YR-133은 YR-143과 YR-146 뒤에 연다.

## 8. YR-147 2단계 파일럿 결과

무기한 WAIT(A)를 최대 600초 뒤 재개방되는 유한 DEFER(B)로 바꿨고, 관측 trigger가 없는
DEFER를 전략 후보에서 제외하는 C도 분해군으로 구현했다. B·C는 3초기화씩 재학습했고,
개발셋 4셀×16판에서 계측했다. 이 단계는 판정이 아니라 3단계 설계용 파일럿이다.

| 초기화 | A 미완주·비용 | B 미완주·비용 | B−A 방향 |
|---|---:|---:|---|
| 88000 | 1판·40.57 | 0판·38.63 | 완주·비용 개선 |
| 99000 | 0판·38.37 | 4판·39.26 | 신규 미완주·비용 악화 |
| 123000 | 5판·39.96 | 0판·37.70 | 완주·비용 개선 |

DEFER wake는 B에서 64판당 1,825~2,209회 소비됐다. A의 기존 미완주 6판은 B의 같은
초기화에서 모두 사라졌지만 B:99000에서 새 미완주 4판이 생겼다. 따라서 유한화는 “다시
판단할 기회”를 복구했지만, 재개방 뒤의 진행/연기 선택까지 고치지는 못했다.

## 9. 22차 감사에서 뒤집힌 해석

1. **C군은 환경 발견이 아니다.** C의 무trigger DEFER 제외는 기존
   `FORBID_WAIT=True`의 전략적 WAIT 제외와 같은 조건으로 귀결돼 B와 중복됐다. B/C
   체크포인트 동일성은 ETA가 충분하다는 증거가 아니라 구현 별칭 증거다. C는 종료하고
   trigger 정의를 바꿔 차이를 인위적으로 만들지 않는다.
2. **C 원자료에 분모 결함이 남았다.** 커밋된 C JSON은 `multi=0`인데
   `ww_avoidable>0`이다. 현재 코드로 C 계측만 다시 실행해 교체하며 재학습은 하지 않는다.
3. **완주 우선 비교가 구현되지 않았다.** 짝지은 진행 후보를 총비용으로 먼저 골랐고
   backlog를 저장하지 않았다. B:99000 32짝 중 7짝은 한쪽 이상 미완주라 기존 D_wait를
   학습 라벨로 사용하지 않는다.
4. **75~81%의 범위를 낮춘다.** 충분한 표본은 88000의 31짝(80.6%)과 99000의
   32짝(75.0%)이고 123000은 1짝뿐이다. 이는 전 상태 오류율이 아니라 정책이 연기를
   선택한 층화 표본의 조건부 관찰이다.
5. **evidence 계약은 미완이다.** 로컬 B=C checkpoint SHA-256은 88000
   `CA1D601B55C4F9334251F124A919836E06D6D5DF05B4CDA42C73AC884C3C2C28`, 99000
   `3927D52562B49776C249BC8143C165298A4D2938483D7FF05D1844F74FE2ED35`, 123000
   `CBF69BE0CD8C112CCCA7ECD9F22FA168773F62157C45D09634435116DCD5114B`로 확인했지만,
   모델 파일은 untracked이고 재실행 명령 manifest가 없다.

## 10. 3단계 정정 계약

주 비교는 B(유한 DEFER)와 R(B+반사실 순위손실)이다. A와 SF-SPT는 참고군이며 C는
중복군으로 닫는다. B/R은 같은 신규 학습 대역·학습예산·초기화·체크포인트 선택기준으로
각각 재학습하고 유일한 차이는 반사실 순위 보조손실이다.

라벨은 같은 상태·같은 사건 난수·같은 후속정책에서 에피소드 종료까지 굴려 만든다. 공동행동은
`미완 비율→backlog→v2 비용` 순서로 비교한다. 가능한 안전 진행후보를 전부 평가하며, 계산상
K개만 가능하면 PPO의 현재 점수로 고르지 않고 SF-SPT·행동유형 층화·무작위 후보를 결과 열람
전에 고정한다. 동점폭·손실계수·표본수·판정상한은 사전등록하고 같은 실험 안에서 조정하지 않는다.

판정은 신규 시드의 R−B 실제 비용 신뢰구간이 1차다. 완주 100%·backlog 0·종단 정지 0,
유효한 연기 보존, 잘못된 연기 감소, PREPOSITION/REPOSITION 장악 미이동을 함께 요구한다.
자연분포와 교착 스트레스는 합치지 않고 별도 판정한다.

## 11. 적용 범위와 되돌릴 조건

- 지금 확정된 것은 “유한 DEFER가 무기한 WAIT의 재개방 문제를 고쳤다”까지다. 정책 성능
  개선·완주 해결·ETA 충분성은 확정하지 않는다.
- 3단계가 B보다 비용과 구분 정확도를 함께 개선하지 못하면 희귀상태 노출 4단계로 넘어가기
  전에 YR-147 정책학습 트랙의 중단 여부를 다시 결정한다.
- 연구 성능 arm에는 YR-146 강제 진행 guard를 넣지 않는다. 운영상 0건 보장은 YR-143 뒤
  YR-146에서만 별도로 검증한다.
