# YR-089 트럭 시간계약 v2 — 구현·계약테스트·새 목적 재판정

> [spec](../dashboard-task-specs/YR-089-truck-time-contract.md) 집행. 시간축:
> 예약 T_appt → 실제 진입 A → 블록도착 B → 작업시작 S → 완료 C → 출문 O.
> **문헌보정 시뮬레이션(D5) — 분포 전부 assumed(실측은 YR-082 Level3 운영로그 후).**

## 1. 구현 (opt-in `time_contract_v2` — 기본 off = v1 바이트 동일)

- **Job 필드**: `appointment_window_start/end`·`appointment_gate_time`(예약, 정책 가시)·
  `estimated_block_arrival`(예약 기반 예측 — `provided_eta` 는 deprecated alias)·
  `exit_travel_s`(외생)·`actual_gate_out`(런타임). 전부 None 기본.
- **생성 인과 재구성**: 예약이 1차 — A=예약+준수오차(±2σ 정규, adh 스트림), B=A+게이트·내부주행
  (gtx 스트림), O=C+출문주행(exit 스트림). **예측 = 예약 + 준수예측0 + 기대주행** — 실현 draw
  미참조(누출 0). v1 draw 열은 그대로 소비 → v2 예약시각 == v1 도착시각(같은 공식 재해석, 테스트 고정).
- **TimeLedger**(신규 [time_contract.py](../../src/yard_rl/integrated/time_contract.py)):
  블록 점유(B→C) 적분 = **v2 truck_wait/long_wait 원료(학습비용)** · 터미널 점유(A→O) 적분 =
  최종 KPI · 검열(end−A/end−B) 포함. **설계 결정: gate 사건을 이벤트 큐에 넣지 않음** — A·O 는
  외생이라 장부가 적분 중 경계 처리. event_log 골든 불변 + "gate 사건이 YC 결정시점을 열지
  않는다" 계약을 구조로 보장 (spec 의 TRUCK_GATE_* 명명은 이벤트 사용 시 규칙).
- **보고 분리**: `mean_wait/p95_wait`(S−B 진단) ↔ `block_turntime_*`(C−B 학습표적) ↔
  `terminal_turntime_*`(O−A 최종 KPI) — 혼용 금지 테스트 포함.
- 검증: 계약 tests **12 passed** (순서식·지식경계·예약이동 비용불변·적분등식 4·검열·결정론) ·
  전체 회귀 **431 passed·골든 불변** (잔여 1 = YR-058 기지 머신민감, stash 재실행으로 회귀 아님 확인).

  우위 성립**. ΔA−O ≡ ΔB−C(동일값) = 외생 구간(B−A·O−C)이 짝지음에서 정확 상쇄 — 분해 계약의
  수치 검증. Δberth 는 @3600 만 유의(−27.67 [−42.09,−13.26]) — "본선은 긴 창" 기왕 지식 정합.

- **체크포인트 판정(수용기준): 재평가 한정** — 기존 RL 체크포인트 트럭 성과는 구 S−B 증거로만
  승계·v2 채택 주장 금지. rollout 계열은 무학습·행동 불변 → 교사 재수집 불요(step5 판정).
