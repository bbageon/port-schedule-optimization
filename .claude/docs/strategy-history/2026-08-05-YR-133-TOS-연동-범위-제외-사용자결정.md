# YR-133 — 실제 TOS 연동을 연구 범위에서 제외한 사용자 결정

> 결정일: 2026-08-05
> 영향: YR-133 완료 주장, YR-149 후속 명세, 다중 블록 아키텍처의 주장 경계
> 이전 설계: [2026-08-02 실환경 계약](2026-08-02-YR-133-판매수용-실환경-설계와-YR-143-무재배치-채택계약.md)

## 1. 결정 경위

YR-133 1차는 `source OFFER → receiver InBurden → TransferResolver` 계산과 시뮬레이터 내부
원자 이송을 발화시켰다. 8개 에피소드 쌍에서 이송 14건, 완주 전판, KEEP군 이송 0을
확인했지만 비용효과는 `QUOTE−KEEP = −15.58~+19.11`로 미확증이었다.

코드 감사에서 실제 TOS(터미널 운영 시스템) 승인 없이 `try_transfer()`가 즉시 owner를
바꾸는다는 점을 “미구현”으로 분류했다. 사용자는 실제 TOS 연동은 연구자가 통제하거나
구현할 수 없는 작업이므로 연구 범위에서 제외하라고 결정했다.

## 2. 최종 결정

외부 TOS는 다음 한 가지 역할만 가진다.

- 작업의 최초 블록 배정이 연구 시작 전에 이미 끝났다는 **외생 배경·입력 스냅샷**.

다음 항목은 YR-133·YR-149 및 최종 채택 게이트에서 제외한다.

- 실제 TOS/ECS API 호출과 인증.
- ACK/NACK·timeout 처리와 운영 상태 동기화.
- TOS route/block instruction version 조회·잠금.
- 실제 장비 명령 발행과 현장 배포 가능성 증명.

## 3. 연구 안에서 유지하는 구조

```text
외부에서 이미 최초 배정된 작업 스냅샷
              ↓
원소유 Block Policy ── OFFER + OutRelief
              ↓
       TransferResolver ← receiver InBurden
              ↓
시뮬레이터 내부 KEEP 또는 A→B 원자 변경
```

- receiver 후보는 시나리오 설정의 `allowed_execution_blocks`로 제한한다.
- `TransferResolver`는 owner·queue·arrival event·전역 시간장부를 하나의 내부 transaction으로
  바꾸고 실패하면 원상복구한다.
- 이는 TOS를 모사하거나 대체하는 계층이 아니라 **재배정 정책의 비용효과를 측정하기 위한
  시뮬레이터 추상**이다.
- source가 발의하고 receiver가 부담을 답하며 resolver가 확정하는 권한 분리는 유지한다.
  BUY action·QMIX resolver·LLM 감독관은 추가하지 않는다.

## 4. 검토한 대안과 기각 사유

### 대안 A — 실제 TOS ACK 어댑터 구현

API·권한·상태계약을 연구자가 확보할 수 없어 재현 가능한 연구 작업이 아니다. 기각한다.

### 대안 B — 가짜 ACK 서버를 만들어 배포 경로를 모사

성공하더라도 실제 TOS 연동 가능성을 증명하지 못하고 연구 질문인 비용 최적화에 새 계층만
추가한다. 기각한다.

### 대안 C — TOS라는 배경 자체를 삭제

작업의 최초 배정과 연구가 다루는 재배정을 구분할 설명 경계가 사라진다. TOS는 외생 배경으로
남기되 실시간 연동만 제외한다.

## 5. 주장 경계

허용 가능한 주장은 다음까지다.

- 문헌 보정 다중 블록 시뮬레이션에서 견적 기반 재배정 기능이 작동하는가.
- 같은 시뮬레이션에서 KEEP·기존 규칙보다 총비용을 줄이는가.
- owner 유일성·완주·backlog·내부 rollback 계약을 지키는가.

다음 주장은 금지한다.

- 실제 TOS와 연결할 수 있다.
- 현장 장비에 자동 재배정 명령을 내릴 수 있다.
- 운영사 시스템에서 동일 성능이 재현된다.

## 6. 후속 작업 영향

- YR-133의 결론은 “시뮬레이터 기능 통과·비용효과 미확증”으로 유지한다.
- YR-149는 TOS 연동을 선결이나 비목표 목록의 미래 과제로 남기지 않는다.
- YR-149는 v2 실현비용 정렬, 결정시점 KEEP/TRANSFER 반사실 분해, 누락 파급 한 축 보정,
  신규 시드 효과 확증에만 집중한다.
- 실제 TOS 접근권한이 훗날 생기더라도 본 작업이 자동 재개되지는 않는다. 별도 연구범위와
  새 Dashboard ID를 사용자가 명시적으로 승인해야 한다.
