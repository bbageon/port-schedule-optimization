# 2026-08-23 · 반사실 지평 H = 3시간 · 학습 부하 2종 · 검토 창 3점

> 결정자: 사용자 · 제안: 실측 기반 ([[YR-217]])

> 검토 창 스윕 5점 → **3점**
> **사전등록 동결 대상 — 결과를 보고 바꾸지 않는다.**

## 1. 어쩌다 이 결정이 필요해졌나

[[YR-215]] 무대 결합 중, 성사된 이연 거래의 **라벨이 정확히 0** 인 것을 발견했다.
[[YR-216]] 이 이연 칸을 창 안으로 묶어 92.9% → 52.0% 로 줄였다. 남은 52% 를
확인하려고 포화 부하에서 재측정했더니(**[[YR-217]]**) 예상과 반대였다 —
라벨 0 이 줄기는커녕 늘었고(71.4%), **건드리지도 않은 대조군(공간 축)까지
0.0% → 66.7% 로 무너졌다.**

## 2. 진짜 원인 — 이연 문제가 아니었다

창 안에서 못 나간 트럭의 비용은 `T − A` 다(미완료 검열). **`A`(게이트인)는 재배치로
안 바뀐다** — 어느 블록으로 보내든, 언제로 미루든 문을 통과하는 시각은 그대로다.
그래서 **창 안 비용이 두 세계에서 정확히 같고**, 효과는 전부 창 밖에 남는다.

```
완료:   [A ...대기·작업... O]  →  비용 O−A   ← 재배치가 바꾼다 (라벨 생김)
미완료: [A ...아직 안 나감  ]T →  비용 T−A   ← A 는 안 바뀐다 (라벨 0)
```

**필요한 지평 = 검토 창 + 턴타임.** 결정은 도착 **전**에 하고 결과는 출문에**야** 난다.

## 4. 검토한 대안과 탈락 사유

| 안 | 내용 | 왜 안 골랐나 |
|---|---|---|
| H = 1시간 유지 | 현행 | 5,000 부터 못 덮는다. 7,500 은 라벨의 2/3 가 0 |
| **H = 2시간** | | 검토 창 30분만 겨우 덮는다(5,000 이 116분으로 걸침). **창 스윕이 무의미해진다** |
| **H = 3시간 (채택)** | | 학습 부하 2종을 **창 1시간 스윕점까지** 상위 10% 로 덮는다 |
| H = 5시간 | 7,500 상위 10% 를 덮음 | 회차당 5시간 넘는 계산 — 감당 불가 |
| 부하별 H | 3,500→1h · 7,500→3h | **부하마다 라벨 눈금이 갈려** 부하 간 비교가 어려워진다 |
| 창 안 완료분만 라벨로 | 미완료 제외 | 표본 1/3 · 오래 걸린 트럭이 체계적으로 빠져 **편향** |

## 6. ⚠️ 이 결정이 논문 주장에 미치는 영향

7,500 은 **학습하지 않고 판정만** 한다. 그러면 그 부하의 판정은 자동으로
**"배운 적 없는 조건에서도 되는가"** 라는 일반화 시험이 된다.

- **통과하면**: 원래 계획보다 **강한 주장**이다 — 학습 분포 밖 일반화.
- **실패하면**: *"정책이 나쁜가, 안 배운 조건이라 그런가"* 를 **못 가른다.**

이 한계는 판정 기록에 **반드시 명시**한다. 숨기면 결과 해석이 거짓이 된다.
