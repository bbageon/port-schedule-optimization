# YR-332-ba — 원본 사건 시각을 확인한 보정 표본 분리

## 결정 경위

2026-11-18 운반·대기 자료를 다시 조사하면서 원본600파일이 이전 수집본과 같음을 확인했다.
대기 값48,620건의 전달은 맞았으나 실제 사건 시각과 서버 로그 시각의 구분이 불완전했다.
대기 메시지600건의 원본 사건 시각이 비어 있었고, 그중2건만 다른 요청에서 명시 시각이 확인됐다.
대기 수가 없는3건까지 합쳐 게이트 진입 기록34,304건 중601건은 명시 시각의 근거가 없었다.
이601건에는 블록 진입·작업 완료·출차 후속 기록이 없었지만, 그것만으로 실제로 입장하지 않았다고 단정하지 않았다.
기존 예약·통지 보정20,936건에344건, 분포 확인8,349건에143건이 포함돼 있었다.
사용자는 이 근거 확인 후 보정 표본 분리를 진행하도록 지시했다.

현재 연구 판정 az(`04c7613f`)의 실제 `authorize-next` 결과는 현실성 보정 허용이었다.
정책 신경망·보상·선택 입력을 바꾸는 작업이 아니라 입력 근거 한 축을 고치는 범위로 ba를 실행했다.
착수·계약·코드·시험 결과를 `6f5a9366`으로 원격에 올린 뒤 원본 전체 변환과 합성 입력 검사를 돌렸다.
새 성능 판정과 PPO 재학습은 처음부터 범위에 넣지 않았다.

## 검토한 대안과 선택

1. **오류 표시만으로 제거**: 기각.601건 중 오류 참584건·거짓17건이며 표시만으로 진입 시각의 근거를 확인할 수 없다.
2. **로그 시각을 근사 실제 시각으로 유지**: 기각. 보정에서 사건과 메시지의 뜻을 혼동하게 된다. 가까운 시각이라는 가정도 검증되지 않았다.
3. **모든 관련 오더를 삭제**: 기각. 원본을 보존하고 보정의 포함 여부만 바꾼다. 이후 자료 제공처 정의가 오면 재검토할 수 있어야 한다.
4. **다른 메시지에 있는 같은 시각 인정**: 채택. 같은 컨테이너·차량·방향·시각이면 명시 시각 근거가 있으므로2건을 살린다.
   다른 시각에 일어난 나중 진입으로 앞선 로그를 덮어쓰는 것은 금지했다.
5. **시간 보정과 물리 도착곡선을 동시에 교체**: 기각. 어떤 차이가 예약 정보에서 발생했는지 분리하기 어렵다.
   시간 보정은 실제 입력 경로에 적용하고, 수요 의존 자료의 영향·후보 파일은 따로 계산해 bb로 연결한다.
6. **작은 중앙값 차이를 근거로 기존 결과를 그대로 새 성능으로 주장**: 기각. 분포 전체와 정책 선택 경로의 영향은 중앙값만으로 판단할 수 없다.

## 검증과 판정

관련 시험32개 통과. 입력18개156,000오더·반복2개7,000오더를 생성했고 실제 접수 변환까지 검사했다.
모든 쌍에서 물리 입력 hash가 같았고 예약·통지·예상시각 외 변경 필드는 없었다.
전체 원본에서 다시 만든 기존 정보 빈도표, 기존 시간대 수요·분별 템플릿·방문 패턴이 저장본과 일치했다.
새 보정 재실행은 profile·날짜별 비교·수요 영향·원본 manifest·분별 후보·방문 후보·입력 묶음7파일이 정확히 같았다.
다른 파서로 원본 명시 시각 집합을 다시 만든 뒤 기존 보정 함수에 필터를 연결해도 새 빈도표와4개 날짜/방향 표본 수가 같았다.
독립 검산21항목 모두 통과. 원본600파일·기존 정보 profile·모형 실행 코드 불변도 포함한다.

원본 행을 저장한 비공개 경로는 git에서 무시되고 추적 파일이 없음도 확인했다.
신뢰성은 결과·코드·보고 수치를 최종 원격 commit과 대조해 발행한다.
전체 현실성은 여전히 미통과이며 이번 입력 검사로 실행 중 사건/비용 장부 검사를 새로 통과했다고 주장하지 않는다.
새 학습·정책 성능은 측정하지 않았다. az의 예측 보호 조건 실패나 ay의 작업별 불균형 판정도 바꾸지 않는다.

## 적용 범위와 다시 판단할 조건

새 실험에서 정보 profile을 명시적으로 골라 사용할 수 있다. 과거 실험은 기존 경로로 그대로 재현한다.
새 예약 정보와 기존 물리 수요의 근거가 일부 다름을 `input-bundle.json`에 기록했다.
bb는 이 의존 보정을 같은 출처 기준으로 맞추는 직접 후속이다. f의 대기 수 정의와 i의 운반 단계·차량 흐름은 외부 자료 대기로 유지한다.
자료 제공처가 로그 대체 시각의 정확한 뜻과 매핑을 제시하거나 새 명시 사건이 확보되면 미확인 표본의 포함을 다시 검토한다.
보정 후 새 성능은 동일 조건의 정책 비교가 따로 있어야 말할 수 있다. 작은 수치 변화로 그 비교를 대신하지 않는다.
