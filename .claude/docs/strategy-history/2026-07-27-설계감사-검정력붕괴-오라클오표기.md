# 설계 감사 (2026-07-27) — 검정력 붕괴·오라클 오표기·대역 충돌

- **성격**: 6렌즈 병렬 감사 + 렌즈별 적대 재검증(12 에이전트). 전 발견은 코드 라인·재실행 실측 근거.
- **요청**: 사용자 "지금 설계의 빈 공간이 없는지 설계의 오류가 있는지 확인해줘"
- **결론 한 줄**: 개별 실험은 규약을 잘 지켰으나, **주지표 선택 하나가 전 판정의 검정력을
  무너뜨렸고**, 그 뿌리에 "물리적으로 달성 불가능한 본선 마감"이라는 시나리오 설정이 있다.
  지금까지의 전면 기각은 **"효과 없음"이 아니라 "이 지표·이 표본으로는 볼 수 없음"** 일 수 있다.


## B. 검정력 미계산 (critical)

전 사전등록·보고서·보드에 검정력/MDE 계산이 **하나도 없다**. 저장 원자료 재계산:

| 판정 | n | sd | MDE(80%) | 함의 |
|---|---|---|---|---|
| YR-099-G1 예측-quote | 8 | 10.28 | 11.85 | 오라클 상한(−22.4)의 53% 미만은 못 잡음 |
| YR-101 ensemble | 8 | 10.32 | 11.89 | 동일 |
| YR-103 Part A | 6 | 5.27 | 7.51 | 자기 "낙관 하한 −8.5" 는 겨우, −5 급은 못 잡음 |
| **YR-099-mid 확증런** | 8 | 19.27 | **22.22** | **판정런 −12 가 진짜여도 ~72% 확률로 "재현 실패"** |

→ **"선택→확증" 구조가 확증 대역을 같은 n=8 로 잡아 구조적으로 확증을 못 한다.**
보고서 산문은 "부재의 증명 아님"을 지켰으나, 보드 done 의 한 단어 "기각" 라벨과 다음 축
결정에는 그 구분이 반영되지 않았다.

## C. 타당성 오류 (major)

1. **JR1800 = 오라클인데 배포 후보로 잠금평가됨.** `baselines.py:163` 이 sim 을 deepcopy 해
   실제 엔진으로 진행 → 큐의 `actual_block_arrival`(진짜 미래 도착)을 소비. 프로젝트 자신이
   `predictive_rollout.py:3-4` 에서 이를 "오라클(상한)·배포 금지"로 규정했다. 그런데
   `yr100_candidate_eval.py:5` 는 "**공개정보** rollout 참고군"으로 표기했고 `yr041_locked` 는
   이를 **배포 후보 arm** 으로 집행했다. 게이트를 통과했다면 30분 앞 도착을 아는 정책을
   "채택"할 뻔했다. (기각된 결과라 판정 방향 자체는 유지.)
2. **시드 대역 충돌 — winner's curse 차단이 실질 부재.** 셀 BASE 간격(100) < 대역 offset
   간격(200) 이라 서로 다른 셀·실험이 같은 트럭 실현을 공유한다. `dmult` 는 난수를 소비하지
   않아(scenario_gen.py:329) 같은 seed·level 이면 트럭 실현이 **완전 동일**.
   - YR-041-a "신규 +900 대역": 24 표본 전부 YR-098 확증대역과 같은 실현, 18/24 는 후보를
     뽑은 YR-100-[3] 평가대역과 동일 (서로 다른 실현은 16개인데 df=23 으로 CI 계산 → 과소 폭).
   - YR-098 자신: 확증 40쌍 중 20쌍이 선택 대역과 같은 실현 — 하필 그 절반이 GO 를 떠받침.
3. **게이트가 자기 CI 보다 좁다.** YR-041-a 비열등 δ=5.0분 < CI 반폭 5.94분(시드 재사용
   반영 시 ≈7.45) → **후보가 SF 와 완전히 같아도 통과확률 25~37%**. "비열등 실패 → 기각"이
   검정력 실패와 구분되지 않는다.
4. **YR-104 의 YR-098 항목이 방향 반대.** "자체 CI 라 보수적이므로 재계산 불요"라고 적었으나
   실제 사용된 백분위 부트스트랩 구간이 정확 t 보다 **좁다**. 정확 t 로 재계산하면 유일한 GO
   판정의 여유가 −0.21 → **−0.08 (경계값)**.
5. **보드가 철회된 결론을 다음 우선순위의 근거로 사용** (본 세션의 자기 오류).
   in-progress/ready 가 YR-105 1차(오염판)의 "반대 방향 반증"·"볼륨 지배 확정"을 인용 —
   정본은 전부 **무의**이고 report 는 "방향 주장 안 함"을 명시했다. **무의를 원인 확정으로
   승격한 논증 오류.**

## D. 빈 공간 (major/minor 요약)

- **하드 guard 미강제**: 완주 1.0·backlog 0 이 최근 하네스에서 기록만 되고 게이트가 아님
  (YR-103 은 수집조차 안 함).
- **대조군 부재**: "혼잡을 관측해서 이득"과 "그냥 A→B 로 보내서 이득"을 가르는 대조군
  (같은 볼륨·신호 미사용 A→B)이 없다.
- **다중블록 물리**: 두 블록이 YT·도로·안벽·본선을 전혀 공유하지 않는 독립 sim 2개. 혼잡
  격차가 방향을 거의 안 바꿈(역방향 0~5%) — 규칙이 "A 가 더 붐빈다"는 상수만 검출.
  공유자원 stress 를 켜도 이송 fleet 이 포화되지 않아 결과가 자동 0.
- **죽은 계약**: `transfer_count≤1`(필드는 증가만·읽는 곳 0)·`allowed_execution_blocks`·
  `reassignable_until`·`TRANSFER_*` 이벤트 4종 미구현 → spec 의 운영량 분리 집계 불가.
- **양하 STORE 재배정 미구현** → spec 이 요구한 "반입/양하/혼합 셀 분리 보고" 불가.
- **재현성**: YR-099-mid 확증런(842k)이 커밋 코드로 재현 불가(대역 상수 하드코딩).
- **계약 정합 소품**: numeraire 이동 scale 7200m 이 gantry 2.0 m/s 유산인데 프로파일은
  4.0 → 선언 ρ_crane=1.0 이 실효 2.0 · yr041_locked 가 강등된 S−B P95 를 아직 하드 게이트로
  사용 · SLA 초과 건수/비율 미계산 · v2 플래그 누락 시 무경고 fallback.

## F. 집행 결과와 **감사 자체의 자기 정정** (2026-07-28)

### YR-106 (완료) — 감사 A 절 확인

채널 분해가 민감도 **4.01×** 개선을 실측. 필요 시드 총비용 24 → **트럭 채널 17**.
과거 "무의" 판정 다수가 실은 **"검출 실패"**(효과 없음이 아니라 볼 수 없었음)임을 라벨로 분리.

### YR-109 (완료) — ❌ **감사가 세운 인과의 절반이 반증됨**

감사는 dmult<1 의 구조적 최소초과를 "vessel_delay 를 총비용 70%로 밀어올린" 원인으로 지목하고,
YR-109 를 **검정력 회복의 근본 처방**으로 등재했다. 실측(선택대역 8시드 legacy vs achievable):

| | legacy | achievable |
|---|---|---|
| 구조적 최소초과 | >0 | **0** |
| 본선 비중 | 70.6% | **68.5%** |
| 필요 n (truck / total) | 17 / 24 | **21 / 22** |

**검정력은 개선되지 않았다.** 이유는 감사 문서 자신이 A 절에 이미 적어 둔 사실 —
"구조적 상수는 **짝지은 Δ 에서 상쇄**" — 이다. 상쇄되는 항은 **분산에도 기여하지 않는다**.
즉 "구조적 최소초과 제거 → 본선 분산 감소 → 필요 시드 감소"라는 연결은 처음부터 성립하지
않았고, 이를 YR-109 착수 근거로 제시한 것은 **내(에이전트) 확대해석**이다. 철회한다.
본선 분산의 실제 원천은 상수 마감이 아니라 **굶주림·대기의 확률적 변동**이다.

**YR-109 가 실제로 고친 것은 타당성이다** (이 부분은 유효):
`slack_s<0` 이 초기조건 → **창발 상태**가 되어 본선 신호가 정보량을 회복했고, 그 결과
본선 보호 필터의 vessel 채널 Δ 가 **+2.57 → −5.44** 로 **부호 반전**했다(유의하지 않음,
MDE 15.36 — 방향 주장 불가). 또한 과거 tight 셀(0.5·0.40·0.75, YR-041 포함) 판정은 전부
"물리적으로 지킬 수 없는 마감" 위에 있었음이 확정됐다.

**결론 정정**: 검정력 병목의 해법은 **오직 표본 수**(트럭 δ=3 에 n≈17~21)이며,
YR-109 는 대체재가 아니라 **해석 타당성의 병행 조건**이다.
