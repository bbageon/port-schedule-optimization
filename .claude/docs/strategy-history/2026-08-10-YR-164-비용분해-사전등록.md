# 2026-08-10 — YR-164 공간 판매 견적 진단: **비용 분해 사전등록** (결과 열람 전 동결)

0B STOP(`6e8a815`) 후속의 원인 규명 단일축. 37차 감사 권고 순서 이행:
①분해 방식 동결 → ②기존 40건 진단 재생(세부 장부만) → ③기계 규칙으로 지배 원인
선택 → ④가설까지만 → ⑤수정안은 새 시드 별도 검증. 본 문서는 ①의 동결 원본이다.

## 왜 필요한가

현 40개 짝 결과에는 **총비용 차와 처리량**만 있다. "견적의 어느 항이 틀렸나"를
답하려면 실현 비용을 견적식과 **같은 축**으로 쪼갠 값이 있어야 한다. 숫자를 본 뒤
쪼개는 방식을 고르면 결론을 만들 수 있으므로 여기서 미리 못박는다.

## 분해 정의 (동결 — Φ 구성과 1:1 대응)

`Φ = Σ_블록 phi_v2(트럭 대기 + 적하 지연) + route_cost/3600 + 기사 외부 대기/3600`
를 다음 **5개 항**으로 나눈다. 실현 이득 G = Φ_base − Φ_treat 이므로 각 항도
(기준−처치) 부호로 계산하고, **다섯 항의 합은 G 와 부동소수 오차 내에서 일치해야
한다**(항등 검사 — 어긋나면 그 표본은 진단 제외·건수 보고).

| 항 | 정의 (기준 − 처치) | 견적식 대응 |
|---|---|---|
| **T_src** | 소스 블록 트럭 대기비용 차 | `relief`(소스 경감) |
| **T_dst** | 수신 블록 트럭 대기비용 차 | `add`(수신 추가) |
| **T_other** | 나머지 19블록 트럭 대기비용 차 | **견적에 없음**(2차 파급) |
| **V_all** | 전 블록 적하(LOAD) 지연비용 차 | 견적에 없음(본선 경쟁) |
| **R_wait** | route 비용 + 기사 외부 대기 차 | `delta/3600`(주행) |

- 블록 귀속: 판매 **시점의 소스/수신** 블록 id 로 고정(이후 이동은 T_other 로).
- 트럭/적하 분리는 `phi_v2` 내부 계산과 동일 식(`j_truck_realized`/`j_vessel_realized`)
  을 블록·작업 단위로 재집계해 얻는다 — 새 비용 정의를 만들지 않는다.

## 견적 대응 잔차 (동결)

견적 ΔJ 는 `−(relief) + (add) + (delta/3600)` 구조이므로, 견적이 예상한 각 항과
실현 각 항의 **잔차**를 다음으로 정의한다(부호: 양수 = 견적이 이득을 과대평가):

- `res_src = 견적 relief − 실현 T_src`
- `res_dst = 실현 T_dst − 견적 add` … (실현이 더 나쁨이면 양수)
- `res_route = 실현 R_wait 의 route 성분 − 견적 delta/3600`
- `res_unmodeled = −(T_other + V_all)` … 견적에 아예 없는 항의 기여

## 지배 원인 선택 규칙 (기계 규칙 — 동결)

40건(진단 제외분 제외)에서 각 잔차의 **|중앙값|** 을 구해 가장 큰 항 하나를
"지배 원인"으로 선언한다. 동률(상위 두 항의 |중앙값| 차이가 10% 미만)이면
"복합"으로 기록하고 단일 원인을 주장하지 않는다. **눈으로 고르지 않는다.**

## 처리량 감소 축 (별도 — 동결)

처리량 감소 10건(그중 비용·처리량 동반 악화 7건)은 위 분해와 **분리해** 보고한다:
각 표본에서 처치 세계의 완료 감소가 어느 블록에서 났는지, 그 블록의 재취급 수·
본선 점유가 기준 세계와 어떻게 다른지 사건 단위로 집계한다(가설 생성용).

## 금지 (동결)

- 기존 40건으로 **수정식·조건을 검증**하는 것 — 원인 탐색 전용. 검증은 새 시드
  별도 사전등록.
- 분해 축·선택 규칙을 결과 보고 바꾸는 것.
- 이 진단을 근거로 Q30·SELL PPO 학습을 착수하는 것(0B GO 전 금지 유지).
