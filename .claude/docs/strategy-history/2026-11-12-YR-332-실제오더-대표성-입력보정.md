## 검토한 대안과 채택하지 않은 이유

1. 네 작업을 25%씩 만들기: 관측 작업 구성을 바꾸므로 채택하지 않는다.
2. 실제 일별 기록 수를 터미널 전체 부하로 쓰기: 자료 수집 범위가 확인되지 않아 채택하지 않는다.
3. 실제 게이트→완료 시간을 크레인 서비스시간으로 쓰기: 대기·주행을 포함하므로 채택하지 않는다.
4. atw→야드 간격을 운반차량 왕복 시간으로 쓰기: 사건 단계와 대기 포함 여부가 미확정이라 채택하지 않는다.
5. 여러 입력 축과 신경망을 동시에 수정하기: 원인을 분리할 수 없어 채택하지 않는다.
6. 실제 블록 이름만 수평 21블록에 대응하기: 지형·장비 근거가 없어 현장 재현이라고 할 수 없다.
7. 먼저 학습 반복을 늘리기: 기존 자료에도 나타나는 순위 어긋남의 원인이 표본 수인지 정보인지 최적화인지 아직 분리되지 않았다.
8. 이미 읽은 뒤 4일을 새 독립 평가로 부르기: 이미 분포 진단에 사용했으므로 채택하지 않는다.

본선 수치는 스트림 계획 시작부터 각 야드 작업 완료까지로, 선박 전체 체류시간이나 현장의 확인된 atw 기준이 아니다.
최종 입력에서 초기값별 전체 감소는 3.03%·3.33%·30.26%다. 전체 14.21% 감소는 세 초기값에서 고르게 나온 이득이 아니다.
짧은 실작업 우선 대비 트럭 평균 +17.93%, 모형 비용 +19.72%이므로 이 정책을 채택하지 않는다.

15,000건 조건에서 학습 후 미완료는 평균 2,705.67건, SF_SPT는 2,006건이었다.
24시간 미완료도 창 끝까지 누적하므로 완료된 오더만 고른 평균은 아니지만, 최종 완료까지의 총시간을 관측한 것은 아니다.

이번에 확정한 것은 입력 차이·두 축의 제한된 보정·반입 편중의 지속이다. 모델 성능 확증이나 현장 최적화가 아니다.
남은 현실성 보정은 ak의 방문/오더 단위와 도착 몰림, i/f의 본선 운반·대기열 의미 확인이다.
그 확인 뒤 323-d에서 저장된 자료를 못 맞추는 원인을 학습 자료 구성·표현·회차별 유지로 분리하고 단일 변경을 선택한다.
