# YR-332-ay — 남은 비용 예측의 학습 안정화 한 축 비교

기록일 2026-11-17. 이 문서는 결정 경위·대안·동결 설정을 보존한다. 결과는 뒤에 추가한다.

## 결정 경위와 허용 범위

AX 저장 경험 진단에서 Transformer의 혼잡일 오전 선택 5,838개 중 양수 행동 신호는 6개였다.
MLP는 5,930개 중 0개였다. 음수 자체가 잘못된 선택이라는 증거는 아니다.
Transformer의 원래 눈금 예측 오차는 갱신 전3.541→같은 학습자료에 대한 갱신 후1.648이었다.
같은 6시간 구간 안 날별 평균 차이가 잔차 변동에서 차지하는 비중의 중앙값은84.02%였다.
첫 묶음의 가치/행동 기울기 크기 비율 중앙값은116.1배였지만 Adam 이후 파라미터 이동량을 뜻하지 않았다.
이 관측은 비용 예측을 안정화할 필요를 제시하며, 정책 성능 악화의 인과 원인을 확정하지는 않는다.

사용자는 “응이거진행해봐 음수신호가 필요한지도 모르겟네”라고 비교 실행을 요청했다.
따라서 AY에 등록한 한 축 비교를 합성 환경의 진단으로 실행한다. 음수 삭제 지시로 해석하지 않았다.
검사 도구는 `scenario_validity` 선결로 거절했다. 그 응답·명령·사용자 요청을 `authorization.json`에 보존했다.
현장 운반·대기열(i/f)과 지속 운영 검증은 여전히 남고, 진단 요청을 현실성 통과로 바꾸지 않는다.

## 대안과 선택 이유

| 검토한 방향 | 이번 결정과 이유 |
|---|---|
| 음수 행동 신호 삭제 | 보류. 예상보다 나쁜 선택의 확률을 낮추는 PPO 항까지 바꾸므로 가치 학습 한 축 비교가 아니다. |
| 물량/날짜마다 보상을 다시 중심화 | 보류. 서로 다른 날의 상대 중요도나 평가 기준을 함께 바꿀 수 있다. |
| 짧은 보상 기간·대기시간 상한 해제·정보 추가 | 보류. 장기 본선 영향이나 관측 정보까지 동시에 달라진다. |
| 가치 손실 계수·학습률·반복 수 변경 | 보류. 정규화 효과와 다른 학습 조건의 효과가 섞인다. |
| 새 초기값에서 대조/변경군 재시작 | 채택. 이전 체크포인트에는 Adam 상태가 없어 가중치만 불러오면 완전한 이어학습이 아니다. |
| 지수 이동 통계 | 이번에는 선택하지 않았다. 새 갱신률 계수의 선택을 추가하지 않으려고 누적 통계를 쓴다. |
| Adam 상태 초기화/별도 재척도화 | 이번에는 하지 않았다. 모든 누적 상태를 유지하며 출력 보존과 최적화 궤적 불변성을 구별한다. |
| PopArt의 전역 목표 정규화 | 채택. 실제 비용 목표와 행동 신호를 유지하면서 가치 학습의 눈금만 바꾼다. |

## 동결한 설정 전수

- 구조: 기존 ReSched 참고 Transformer, 너비32·헤드4·층2. 원 논문 전체 재현은 아니다.
- 후보 특징10개, 작업·크레인 관계, 가치망의 시각 입력을 유지한다. 전체 합법 후보를 쓰고 개수 제한을 새로 두지 않는다.
- 기존 필수작업/실작업 우선 단계와 순차 합법 공동 배정의 실제 선택 확률을 유지한다.
- 보상: 24시간 총비용에서 직전 동기화 시점의 누적 비용을 뺀 남은 비용의 음수.
  기존 고정 눈금368293633.7020551을 유지한다. 원 단가·본선·이동·재취급 비용식은 변경하지 않는다.
- 관측24시간, 엔진26시간, 할인1, 종료 비용 기반 Monte Carlo 반환. TD/GAE로 바꾸지 않는다.
- 행동 신호는 원래 눈금의 반환−기존 가치 예측이고, 두 날짜의 선택 표본 전체에서 평균·표준편차로 조정한다.
- 모델 초기값9951101/9951102/9951103의 세 쌍. 모든 쌍의 초기 파라미터를 대조한다.
- 6갱신×2일, 갱신당2,048선택, 4회 반복, 묶음64, 총768최적화 단계/모델.
- Adam 학습률0.0003, 확률비 제한0.2, 가치 계수0.5, 엔트로피 계수0.01, 전체 기울기 상한1.
- 최종 모델은 항상 갱신5이다. 검증 성능이 좋은 중간 모델로 교체하지 않는다.
- 행동 난수는 `model_seed+1000+day_index`, 표본 선택은 `model_seed+2000+iteration`,
  학습 순서는 `model_seed+3000+iteration`으로 기존 식을 유지했다. 모델과 날짜를 모두 합친 난수의 독립성을 주장하지 않는다.
- 모델·정규화 통계·Adam·Torch 난수·갱신 번호를 저장한다. 복원 경계는 두 정책 갱신 사이이며,
  실행 중인 터미널의 중간 상태를 저장하는 연속 운영 체크포인트가 아니다.

## 정규화 산술

- 초기 평균μ=0, 표준편차σ=1, 누적수0. 선택한 새 표적을 갱신마다 한 번만 누적한다.
- float32 학습 표적의 누적 평균·모집단 분산을 float64로 계산한다. σ 바닥0.0001의 발동을 기록한다.
- 학습용 표적 `(Y−μ)/σ`, 복원한 예측 `V=σg+μ`. 행동 신호에는 복원한 V만 사용한다.
- 통계 변경 시 마지막 선형층은 `W'=σ_old/σ_new·W`, `b'=(σ_old·b+μ_old−μ_new)/σ_new`로 보정한다.
- 모든 선택 표본에서 예측 보존 최대오차0.00002 이하·작업 점수 차이0을 검사한다.
- 가치 손실은 정규화한 눈금의 제곱오차다. 고정 계수를 유지해도 행동/가치 기울기 비율까지 같아지는 것은 아니다.
- Adam의 누적값은 그대로 둔다. 이 선택은 함수 출력 보존과 별개이며 다른 Adam 처리 방식의 우열을 실험하지 않았다.
- 통계는 학습에서만 변한다. 검증·시험·단순 추론에서는 갱신하지 않는다.

## 입력과 평가 분리

- 기존24개 주기적 삼각 기저, 개발일 두 모수의 균등 보간, 같은 부모의 반출 비율 보간,
  분별 상관 도착, 다중 오더 방문 연결, 초기 재고 보존을 유지한다.
- bank seed9954000, 곡선19개: train13/selection3/holdout3. 이전36개 곡선과 중복0.
- 학습 train0~11, 입력 seed9954200~9954211, 물량3500/7500/15000을 네 번 순환한다.
- train12(seed9954212,3500건)는 동작시험 전용이며 학습/평가에 넣지 않는다.
- 검증 selection0/1/2: seed9954300/1/2, 각각3500/7500/15000건.
- 시험 holdout0/1/2: seed9954400/1/2, 각 곡선에 세 물량을 교차하여9입력을 만든다.
- 25입력에 대해 공급·방문·예약·작업 종류 보존을 정책 전에 검사했다. 거절한 입력0개다.
- 하루 사례마다 환경을 새로 만든다. 12일 연속 운영이나 독립 실측 날짜12개가 아니다.
- 검증 최고점 선택45회: 초기3모델×3입력 + 중간/최종6모델×3입력×2시점.
- 확률 정책의 비용 예측 검증18회: 최종6모델×3입력. 추첨 seed9956000+곡선번호+100×물량번호.
- 최종 시험63회: 최종6모델×9입력 + SF_SPT(실작업 중 짧게 끝나는 작업 우선)×9입력.
- 총126평가와 각 군 첫 초기값·첫 시험곡선3500건의 재실행2회. 검증에서 모델을 고르거나 조기 종료하지 않는다.
- 각 입력과 모델에 같은 무게를 준다. 과거의 오더 수 가중 평균도 보조값으로 남겨 혼동을 막는다.
- 트럭은 오더당 게이트 진입→야드 작업완료, 본선은 계획 묶음 시작→개별 야드 작업완료다.
  미완료도 관측 끝까지의 경과시간을 포함하며, 24/26시간 미완료를 별도 센다.
- 세 초기값 모두 평균 총비용이 감소하고, 전체 평균 트럭 시간·본선 지연·미완료가 악화하지 않아야 일관된 개선 후보다.
  규칙 우월·전건 완료·현실성은 별도 판정이며 3곡선·3초기값으로 통계적 확증을 주장하지 않는다.

## 구현·운영에서 확인한 사항

- 새 목표 정규화는 별도 모듈이다. 기존 학습기와 환경 소스는 바꾸지 않았다.
- 15계약 시험 통과: 기존 대조군의 파라미터/Adam 일치, 통계 변경의 출력 보존, 저장 복원 등을 포함한다.
- 입력 사전검사 첫 시도에서 시나리오 객체에 일반 JSON 해시 함수를 사용한 오류를 고쳤다.
  기존 객체 해시 함수를 쓰도록 연결했으며, 입력이나 판정 기준을 바꾼 것은 아니다.
- 구형 보정 JSON 하나가 Git과 실행 파일의 줄바꿈만 달랐다. 수치 동일성을 확인하고 원래 바이트 사본을 별도로 보존했다.
  고정 소스215개 중214개는 원격 commit의 바이트와 같고, 하나는 그 형식 차이다.
- 초기 평가9회가 끝나고 실행 중 평가가 없는 경계에서 실행 관리기만 재시작했다.
  불변 목록의 반복 생성을 없애고, 학습 중4개/학습 뒤10개의 평가 실행으로 관리한다.
  중단한 정책 실행0개, 바뀐 학습·평가 핵심 소스0개, 바뀐 평가 조건0개다.
- 학습 상태36갱신의 재계산에서 신경망과 Adam이 정확히 같음을 확인했다. 학습용 세계 전체를 다시 돌린 검사는 아니다.
- 같은 상태의 순위 진단은 크레인 하나의 선택을 별도로 센다. 여러 크레인 선택 순서 변화와 실작업 순위 변화를 구분한다.
