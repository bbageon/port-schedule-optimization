## 결정 경위와 범위

앞선 ao에서는 하루 시간대 곡선을 24지점 선형 보간 가족으로 바꾸고 54회 규칙 비교를 마쳤다.
하지만 반출 비율은 고정이고 분별 방문 수는 실제 날짜의 배열을 재사용했다.
사용자는 날짜마다 조금씩 다른 합성 자료로 학습하기를 요청했고, 네 단계 모두 실행을 승인했다.
따라서 하루 모양과 작업 비율을 함께 생성하는 축, 시간대 안 시각을 수식으로 생성하는 축을 분리했다.
실제 오더를 그대로 학습 입력에 넣는 것이 아니라 개발 자료의 집계 통계로 보정한 합성이다.
실측 통계를 사용한 사실과 부모 날짜에 대한 의존성은 논문에서 명시해야 한다.

## 날짜별 반출 비율: 대안과 동결 설정

기존 고정 비율은53.7517491%다. 개발13일의 날짜별 평균은55.4402735%, 표준편차6.7309222%p다.
날짜 범위는45.3818~69.3284%다. 오더 가중 평균과 날짜 평균은 다른 통계다.
새 비율은 곡선의 두 부모 날짜와 같은 보간계수로 계산한다.
`p_new=(1-f)*p_parent_a+f*p_parent_b`이며 곡선과 비율의 관측 연관성을 임의로 끊지 않는다.
서로 독립으로 비율을 흔드는 대안은 관측되지 않은 조합을 늘리므로 이번 단일축 비교에서 쓰지 않았다.
이 보간 가족은 실제 날짜의 확률분포를 추정한 생성기라는 주장이 아니다. 보간으로 산포가 줄 수 있다.

학습24·선택6·평가6개 곡선을 유지했다. 학습 비율의 평균54.4387673%, 표준편차4.9769331%p,
범위46.1320~64.5705%다. 대조 고정 비율은 학습24개의 평균으로 두었다.
전체36곡선×3물량×고정/변동=216개 입력에서 총량·흐름·공급·방문 용량·선후관계와 반복을 검사했다.
실행은 첫 학습 곡선0/1/2×3,500/7,500/15,000×두 비율×SF_SPT/FIFO/LWKR=54회다.
입력 시드9937100/101/102, 원래 분별 형판·물리·본선·규칙은 동일하다.
세 선택 비율51.1423/57.8574/59.8844%의 평균은 전체24개 평균과 같지 않다.
따라서 이 비교를 평균을 엄밀하게 통제한 분산만의 효과로 해석하지 않는다.

## 분별 도착: 실패한 대안과 변경 근거

시간대의 총 방문 수n은 그대로 두고 60분에 배분한다. 무조건부 Poisson이라고 부르지 않는다.
개발 자료312개 날짜×시간 구간(n≥2)의 1분 산포1.2656509670, 10분 산포1.1823228463,
인접 분 상관−0.10163131445를 목표로 삼았다. 산포는 각 시간의 분산/평균을 다시 평균한 값이다.
조건부 독립 배분의 기준 산포는1분59/60, 10분5/6이므로 정확히1이 아니다.
허용 절대 오차는1분≤0.10, 10분≤0.15, 인접 상관≤0.05로 먼저 고정했다.

AR(2)는 두 분 전까지의 강도 변동이 현재에 영향을 주는 정상 Gaussian 과정에 지수를 취한다.
로그 공분산C0=.2373945958,C1=−.0805392123,C2=.0567723095에서 Yule–Walker 식으로 추정했다.
고정 매개변수a1=−.34573485111282665,a2=.12294676387846318,sigma=.46152793712015955,
innovation=.9120520582510808,준비 구간128분이다. 반복 시드9936300~9936399에서 기준 하나를 놓쳤다.

## 수식 도착의 보존 조건과 적용 범위

최종 강도를60분 비중으로 정규화하고 고정 방문 수를 뽑는다. 분 안에서는 균등 시각을 쓰며 밀리초로 기록한다.

별도108쌍의 오더 속성 대조도 시각 필드 이외의 작업·컨테이너·방문 계획이 정확히 같았다.
게이트 시각을 목적 블록별로 나눈 통계는 실제 블록 도착시각의 통계라고 부르지 않는다.
규칙 비교는 비율변동의 첫3곡선·3물량×기존/수식 도착×SF_SPT/FIFO=36회다.
대조18회는 앞 단계 결과와 후보·선택·사건·작업·장부·결과 지문 및 원자료가 정확히 같아야 한다.
새 실행 설정은88a8d6b3의 깨끗한 코드 상태에서 고정했고, 모든 핵심 소스의 해시를 실행 전에 검사한다.

입력의 집계 적합 통과는 운반 장비·대기열·지속운영 현실성 통과와 다르다.

분별 생성 과정은 선택형 경로다. 통계·원자료 보존 실패가 발견되면 해당 결과의 채택을 중단하고 수정 축을 분리한다.
다음 단일축 학습 진단과 구조 비교는 사용자 요청 범위이며 기본 정책을 자동 교체하지 않는다.
