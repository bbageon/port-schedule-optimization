# 제안 정책의 진척과 타당성 (2026-07-28 기준)

사용자가 설계한 정책 구조가 지금 어디까지 실증됐는지, 각 주장을 어느 강도로 말할 수 있는지.

## 정책 구조 (사용자 설계)

| # | 구성 | 요지 |
|---|---|---|
| ① | **판매 창** | 재배정은 **[게이트 진입, 블록 도착)** 구간에서만 가능 |
| ② | **블록 Q** | 작업 유형(본선/트럭)을 **몰라도 되는** 총비용 최소화기 |
| ③ | **본선 긴급도** | 학습이 아니라 **계산**해서 비용으로 주입 |
| ④ | **중앙 resolver** | 여러 블록 상태를 보고 **어디로 보낼지** 결정 |
| ⑤ | **재배정 3종** | 장치위치 재배정 / 후보 컨테이너 선택 / 물리적 재배치 |

## 진척 — 축별

### ① 판매 창 (창중 재배정) — **여기가 유일하게 판정까지 간 축**

| 단계 | 작업 | 상태 |
|---|---|---|
| 기반 | YR-099-b 브리지 (공용 시계·전역 A→O 장부·canonical id·2단계 commit·수신 용량검사) | ✅ 구현·회귀 고정 |
| 1차 시도 | YR-099-mid 혼잡격차 0.10 단독 규칙 | ❌ 확증 실패(기각) |
| 단일축① | YR-105-a″ 본선 악화 방지 필터 | ❌ **기각** (2대역: 트럭 유의 악화 + 본선 동등성) |
| **근본 물음** | **YR-113 이송 자체에 값이 있는가** | ✅ **이롭다** — 트럭 2대역 재현 (+3.384 / +3.347) |
| 단일축② | YR-105-b 임계 최적화(0.05/0.10/0.20) | ⏸ 대기 (YR-116 선결) |

### ② 블록 Q 유형 무지 — 구조로 성립, 별도 판정 없음

블록 Q는 13항 비용만 보고 결정한다. 본선/트럭 구분은 비용계약이 흡수한다. 이 설계 자체는
전 실험의 전제로 깔려 있고 별도로 반증된 적 없다. 다만 **"유형을 알면 더 낫다"를 검증한
실험도 없다** — 즉 유리하다는 증거가 아니라 **불리하다는 증거가 없는** 상태다.

### ③ 본선 긴급도 계산 — 구현 완료, **채택 판정 없음**

`vessel_cost.py` 4개 비용계약 구현·적대검증 5건 정정 완료. 그러나 YR-100 판정은
"공식 검증 통과 / CALC 실행타이밍 시드 재현 실패"로 끝났고, 이후 YR-107 이 그 실험의
후보 선정 규칙이 **오라클을 자동 지명**했음을 밝혀 프레임 자체를 재서술했다.
**계산식은 있고, 그것이 정책을 개선한다는 판정은 없다.**

### ④ 중앙 resolver — **학습 부분 미착수**

지금 resolver 역할을 하는 것은 **규칙**(혼잡격차 ≥ 0.10)이다. 사용자 설계의 핵심인
"여러 블록 Q 상태를 실시간으로 보고 배정하는 학습형 resolver"는 **한 번도 시험되지 않았다**.
관련 시도: YR-101 ensemble quote 기각 · YR-102 분해 quote backlog.

### ⑤ 재배정 3종 — **1종만 구현**

구현: **반입 컨테이너의 블록 재배정(A→B)** 하나.
미구현: 양하 STORE 재배정 · 후보 컨테이너 선택(공컨/환적 그룹오더) · 물리적 재배치.

## 타당성 — 지금 말할 수 있는 강도

| 주장 | 강도 | 근거·단서 |
|---|---|---|
| **판매 창 재배정에 값이 있다** | **잠정 실증** | 트럭 채널 2대역 재현(+3.35). **단 YR-116 미해결 → 확정 아님** |
| 이송이 본선을 해치지 않는다 | 실증(확증 대역) | 막으면 본선이 +5.29 나빠짐 = 우려 반증 |
| 이송이 터미널 총비용을 줄인다 | **주장 불가** | 확증 대역 +8.06 유의지만 **탐색적 채널**(1차는 truck) → YR-115 필요 |
| 본선 보호 필터가 필요하다 | **반증** | 트럭만 나빠지고 본선은 동등 → 기각 |
| 최적 임계가 0.10 이다 | **미측정** | YR-105-b |
| 학습형 중앙 resolver 가 규칙보다 낫다 | **미착수** | 지금 이득은 전부 **규칙**의 것 |
| 본선 계산식이 정책을 개선한다 | **미확정** | 구현만 |

## ★ 지금 판정을 흔드는 것 — YR-116 (병렬 세션 발견, 진행 중)

1. **`0 < actual_gate_in` 조건이 t=0 반입을 재배정 검토에서 영구 제외했다.**
   YR-113 원자료에 **선택 40건·확증 77건**이 그렇게 빠졌다 → 판정에 쓰인 후보집합이
   실제보다 좁았다. YR-116 은 "방향 보존만 확인"을 목표로 두었으나, **재확인 전까지
   YR-113 은 잠정으로 취급해야 한다.**
2. **YR-112-b 의 "1 bay 탈출 후보 종단 검증"이 종단이 아니었다.** 중간 목표 집합까지만
   검사했고, 최종 후보 필터(≤1 bay 미세이동 제거)가 그 목표를 다시 지웠다.
   → 내가 "실제 생성되는지 검증했다"고 보고한 것은 **과장이었다.**

## 해석 — 한 문장

**정책의 1단계("재배정할 값이 있는가")는 규칙 기반으로 처음 긍정 답을 얻었고, 2단계
("얼마나·언제")와 3단계("학습형 resolver가 규칙을 넘는가")는 아직 시작도 안 했다.**
지금까지의 이득은 전부 **강화학습이 아니라 규칙**이 낸 것이다 — 다만 순서는 옳다.
규칙으로 이득의 존재를 못 박아야 학습이 그것을 넘는지 물을 수 있기 때문이다.
