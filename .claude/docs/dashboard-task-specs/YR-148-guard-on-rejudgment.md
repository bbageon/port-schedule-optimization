# YR-148 — 안전장치 ON 환경 C0/C1 재판정 (PREPOSITION 존재 가치 · 완주 교락 제거)

## 무엇을 왜
YR-143 확증은 양군 하드 가드 실격(미완주 C0 13/352·C1 10/352)으로 **미확정** —
비용 방향 신호(C0 우위 7/8 초기화·초기화 포함 상한 +0.113)는 미완주 검열로 오염
가능했다. YR-146 배포 안전장치(정책 무관 종단 정지 0)를 켠 환경에서 재판정하면 완주
교락 없이 PREPOSITION 순수 효과를 비교할 수 있다.

## 계약 (착수 시 동결 — 24차 반영)
- 비교: **C0+ON vs C1+ON** (배포 구성에서의 존재 가치 질문). 기존 체크포인트 재사용
  (YR-143 확증 8쌍 — 재학습 없음). guard OFF 결과는 학습 성과, ON 은 배포 구성 —
  합산 금지, ON 비교가 OFF 정책의 순수 성과를 소급 증명하지 않음을 명시.
- **통계 교체(24차)**: 초기화·시나리오 동시 반영 — 다중방향(초기화×시나리오)
  부트스트랩 또는 혼합효과. 시나리오 단순법 금지.
- 신규 시드뱅크 대역·δ 는 YR-143 가정값 승계(민감도 병행)·BOTH_GUARD_FAIL 분기 포함
  4분류·guard 개입률 허용치(YR-146 에서 동결한 값) 초과 시 "정책 미완" 태그.

## 선결
YR-146 (안전장치 구현·4군 OFF/ON 검증 통과).
