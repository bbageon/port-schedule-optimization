# YR-332-aq — 보정 환경 재학습·감소율 진단 (사용자 요청)

- **상태**: done
- 등록: 2026-11-14. 상위 [[YR-332]]. 선행 [[YR-332-an]]·[[YR-332-am]]·[[YR-332-al]].
- 사용자 지시(2026-11-14): “모든 사항 진행하고 학습 다시 해서 감소율 알려줘.”
- 게이트: ak 저장 판정은 신뢰성 PASS·현실성 FAIL·성능 INCONCLUSIVE이고, 하네스는 현실성 보정만 허용한다.
  새 학습은 그 범위 밖이다. ag와 같이 **사용자 실행 지시 진단**으로만 수행하며 성능 확증·채택·현실성 통과를 주장하지 않는다.

## 무엇과 왜

ag 학습 뒤 환경을 네 번 고쳤다: 작업 비율·시간대(aj), 시간대 안 방문 몰림(ak), 여러 컨테이너 방문 연결(al),
명단 보조 시각(an). 저장 모델은 보정 전 입력으로 학습했다. 학습 방법은 그대로 두고 **환경만 바꿔** 다시 학습해,
학습 전·짧은 실작업 우선 규칙·이전 모델 대비 트럭 시간 감소율을 잰다.

## 범위 (사전등록)

- 학습: ag와 동일(초기 시드 3개, 6회, 회당 최대 24쌍, 50회 갱신, 3시간 비용 창, 초기 정책 동결, 쌍 비교 손실).
- 환경: al의 `observed_visit_links` 입력(aj+ak ③+al). 물리·운반 가정은 그대로다.
- 평가: 새 입력 9개 × 정책 16개(규칙 7, 학습 전 3, 재학습 3, 이전 모델 3) + 반복 2회 = 146회.
- 보고: 감소율(학습 전·SF_SPT·이전 모델 대비), 유형·물량·모델별 값, 총비용 짝 재표집 구간, 성능 판정 기록.
- [사전등록](../../../docs/research/v7-discharge/linked-retraining-prereg.md)

## 완료 기준

- 저장 라벨로 가중치 18개 정확 재학습, 평가 146회 행 단위 재계산, 방문 정차·출차 엔진 검사, 반복 2회 비트 일치.
- 모델별·물량별 결과를 모두 공개하고 결과를 본 뒤 학습량·입력을 바꾸지 않는다.

## 착수 — 2026-11-14

- 하네스 `authorize-next`(NEW_HYPOTHESIS)는 미통과 게이트 때문에 거절했다(종료코드 2). 거절 기록을 남기고,
  사용자 명시 지시에 따라 ag와 같은 진단으로만 실행한다. [기록](../../../outputs/reports/yr332_linked_retraining/authorization.json).
- 환경은 al의 동결 입력 `observed_visit_links`다. al 고정 정책 결과를 보기 전에 이 사전등록과 실행 설정을 동결한다.
- 학습과 무관한 규칙·학습 전·이전 모델 평가 117회는 학습과 함께 돌리고, 재학습 평가는 학습 뒤에 돌린다.

## 재시작 — 2026-11-14

- 첫 동결 `071b1ce6` 학습은 al과 같은 엔진 기록 결함 수정 때문에 모델 9917101의 1회차(질문 8쌍) 뒤 중단·폐기했다.
  같은 설정으로 재동결해 처음부터 다시 학습한다. 학습·평가 결과는 보지 않았다.

## 완료 — 2026-11-14

- 학습 18회(모델 3개×6회, 학습 쌍 283개)와 평가 146회 완료·검산 PASS. 가중치 18개 정확 재학습, 트럭 1,263,000행 재계산,
  정차 도착 430,658건·단일 출차 175,294건 확인, 늦은 도착·출차 0, 반복 2회 비트 일치.
- **재학습 감소율**(양수 = 짧아짐, 세 물량 합산): 학습 전 대비 **+4.17%**(116.658→111.791분),
  SF_SPT 대비 −27.07%(87.975분), 이전 모델 대비 −8.29%(103.229분).
- 모델별 학습 전 대비 −21.42%·+8.22%·+21.12%로 크게 엇갈렸다. 물량별 학습 전 대비 3,500 −5.01%, 7,500 −0.33%, 15,000 +4.98%.
- 반입은 학습 전보다 16.77% 줄었지만 반출은 −0.32%로 그대로다. 총비용(재학습 − SF_SPT) 95% 구간 +58.1~+486.7백만 원.
  성능 FAIL(전건 완료·미완료 0·본선 보호 가드 미충족).
- 해석: 환경 보정만으로는 같은 학습 방법이 나아지지 않았고, 결과가 초기값에 좌우된다. 다음은 학습 진단
  [YR-323-d](YR-323-d-learning-budget-check.md)이며 이 결과를 그 명세에 근거로 추가했다.
