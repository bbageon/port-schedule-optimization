## 왜 필요한가

게이트가 6일째 같은 말을 하고 있다.

```
performance: INCONCLUSIVE
  known   : YR-148은 사전 이동 없음이 있음보다 우월함을 확인
  missing : 지속 유입·본선 포함·신규 시드에서 현재 최종 정책 대 SF-SPT 비교
```

현 무대(21블록·24시간 이중피크·고정 재공량)에서 평가한 모든 팔은 집행이
`ADOPTED_C0_GUARD` 하나로 고정돼 있다. 즉 지금 재고 있는 것은 **"같은 크레인
정책 위에서 판매를 켜고 끄고"** 의 차이뿐이고, **그 크레인 정책 자체가 규칙보다
나은지는 이 무대에서 확인된 적이 없다.**

이것이 왜 위험한지는 산수로 바로 보인다 — 채택 정책이 규칙보다 5% 나쁘다면,
그 위에 판매로 3.5% 를 벌어도 **합계는 여전히 규칙보다 나쁘다.** 지금 자료로는
이 경우를 배제할 수 없다.

**과거 규칙 초과 실적(YR-073-b)은 이 무대에 승계되지 않는다** — 2블록·214 입력·
2크레인 슬롯에 고정된 가치망이라 21블록에 그대로 쓸 수 없다는 것이 이미 박제돼
있다(Dashboard README 일반화 주장 경계, 2026-07-20).

## 무엇을 재나

같은 무대·같은 날·같은 배경에서 **집행 정책만** 바꾼 3팔.

| 팔 | 크레인 집행 | 판매 |
|---|---|---|
| R | **SF-SPT (규칙)** | 없음 |
| A | 채택 정책 | 없음 |
| A+S | 채택 정책 | 학습 판매 (그 시점 최선 팔) |

세 대비가 각각 다른 질문에 답한다.

| 대비 | 질문 |
|---|---|
| A − R | 크레인 정책이 규칙을 이기나 (**이 무대 최초 측정**) |
| A+S − A | 판매 층의 기여 (기존 −84.5 재현) |
| **A+S − R** | **연구 목표: 전체가 현행 규칙을 이기나** |

## 사전등록 필수

이 판은 **논문에 실릴 표**다. 잠금 규약을 따른다.

- **새 시드 대역**으로 평가일을 뽑고, 뽑은 뒤에는 바꾸지 않는다
  (열람한 대역 재사용 금지 — YR-115 선례).
- 표본 수·판정 축·최소검출효과·하드 가드를 **실행 전에** 동결하고 사전등록
  문서에 sha256 으로 박제한다.
- 판정은 터미널 총비용 + 평균 `실제 gate-in→gate-out` 공동 판정
  (P95 는 보고만 — 2026-07-27 평가계약).
- 결과가 규칙 열세여도 그대로 박제한다. 임계·팔 구성을 사후 조정하지 않는다.

## 선결

1. **[[YR-177]]** — 어느 팔을 A+S 로 올릴지가 여기서 정해진다. 지금 최고 성적
   (−175.9)이 값매김 실수의 산물이면 그 팔을 논문 표에 올릴 수 없다.
2. **[[YR-179]]** — 판매 층 기준선. 규칙 판매가 학습과 같으면 A+S 를
   "학습 판매"로 부를 수 없다.
3. 현 무대에 SF-SPT 집행 경로가 **실제로 배선돼 있는지 확인** — YR-167 자격은
   SF 집행으로 통과했으므로 경로는 있을 것이나, `run_episode_diurnal` 에서
   `exec_config` 로 선택 가능한지 코드에서 먼저 확인한다.
