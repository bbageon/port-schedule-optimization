# YR-128 — 가치 순위 진단: Q 순위 vs 반사실 rollout 비용 순위 (무학습)

> — "차분 신용이 고칠 문제가 실제로 가치 순위 오류인지, 재학습 전에 먼저 측정하라."

## 목적

행동 선택에 필요한 능력은 절대 비용 예측(YR-127 N1, 31%)이 아니라 **행동 간 차이의
부호·순위**다. 기존 체크포인트(BUDGET20 ×3 = 보정 최선 / WAITON ×3 = 대조)에서
매 결정의 Q 순위와 반사실 rollout 비용 C600 순위의 일치도를 직접 잰다.

## 방법 (하네스 docstring 이 정본 — [yr128_rank_diagnosis.py](../../../src/yard_rl/experiments/yr128_rank_diagnosis.py))

- YR-125 와 같은 8 에피소드를 argmin(Q) 로 실행, 매 결정에서 net 이 채점한 조합 목록
  그대로 각 조합의 `_rollout_cost(600s, RC_TRAIN, base=SF)` 를 계측 (YR-063 C_600s 계보).
- ⚠ C600 은 오라클(YR-107) — 진단 특권, 정책 입력·배포 불가. 600s 창 밖 효과는 못 봄
  (YR-065 창 비단조 이력 고지).

## 지표·해석 (결과 열람 전 동결)

- R1 top-1 일치율 · R2 결정별 Spearman ρ 평균 · R3 WAIT 방향 혼동표
  (핵심 = P(cw|qw): Q 가 "wait 이 더 싸다"고 본 결정 중 반사실도 동의한 비율).
- **H-순위결함** P(cw|qw) < 0.5 → WAIT 선호의 과반이 오평가 — 차분(부호·순위 표적) 직접 근거.
- **H-실제선호** P(cw|qw) ≥ 0.7 (+R1 대조 대비 높음) → 600s 창 기준 WAIT 이 실제 쌈 —
  결함은 목표 정의(창·할인·shaping vs 평가) → 차분도 같은 반사실 창을 쓰므로 목표 회계
  재검이 선행돼야 함.
- 중간(0.5~0.7): 혼재 — 차분 유지 + 목표 회계 재검 병행 조건.
- 진단이며 판정 아님. 표본 = 열람된 진단 대역 재사용 (YR-125 1단계와 같은 지위).
