## 3. 왜 이렇게 시끄러운가

짝비교(같은 시드에서 RL·안팔기 둘 다)라 무대는 같다. 남는 분산은 **"그 날 재배치가
얼마나 도움이 됐나" 의 진짜 날별 차이**다. 부하 5,000 에서 −1,158만 ~ +1,978만원까지
흔들린다 — Φ 1.9억원의 ±6% 다.

거기에 **정책이 회차마다 바뀌고 탐색 비율 ε 도 같이 줄어든다**. 날 차이·정책
차이·탐색 차이가 한 수치에 뒤섞여 있다.

### 필요한 표본 수 (100만원 효과 기준)

| | 필요한 날 수 |
|---|---|
| 부하 3,500 | **17 ~ 165일** |
| 부하 5,000 | **565 ~ 1,019일** |

**부하 5,000 은 사실상 판정 불가능**하다. 분산이 너무 크다.

## 4. ⚠️ 무엇은 살아남나 — 라벨 진단은 유효하다

[[YR-225]]·[[YR-227]] 의 결론은 **부호 검정**이라 판정력이 있다:

| | |
|---|---|
| t0=7.7시 라벨 부호 반대 | **8/8** → 부호검정 p = 0.008 |
| t0=14.3시 라벨 부호 맞음 | **8/8** → 〃 |

날별 크기가 흔들려도 **방향이 8일 내내 같으면** 우연이 아니다.
→ **라벨 진단은 그대로 두고, 성능 판정 설계만 고친다.**

## 5. 처방 후보 (착수 시 하나 골라 동결)

| 안 | 내용 | 대가 |
|---|---|---|
| **A. 판정을 정책 고정 + 다수 날로 분리** | 학습 회차 격차는 **진단용으로만** 쓰고, 성능은 체크포인트를 고정해 수십 날로 잰다 | 판정 비용이 따로 든다 |
| **B. 부하 3,500 에서만 판정** | 분산이 1/4~1/6 이라 17~39일이면 잡힌다 | 혼잡 부하 주장 포기 |
| C. 효과 크기를 키운다 | 라벨을 고쳐 정책이 실제로 더 좋아지게 | 이건 [[YR-227]] 축이지 판정 축이 아니다 |

**A+B 조합을 권한다** — 판정을 학습에서 떼어내고, 먼저 부하 3,500 에서 효과를
확증한다. 연구 목표가 *"RL 효과 검증"* 이므로 **효과를 잴 수 있는 조건에서 먼저
재는 것**이 맞다.
