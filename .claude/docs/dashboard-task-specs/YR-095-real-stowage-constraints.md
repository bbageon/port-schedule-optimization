# YR-095 — 현실 적재 제약 최종 도입

- **Epic**: Sim / **Priority**: ⚪ / **등록일**: 2026-07-26
- **상태**: 최종 실증·현실화 단계. 반입·양하 블록배치 PoC의 선결이 아니다.
- **사용자 범위 정정**: [2026-07-26 결정 기록](../strategy-history/2026-07-26-YR-081-반입-양하-우선-현실적재규칙-후순위.md)

## 목적

YR-081·099에서 반입과 본선 양하처럼 **아직 야드에 적재되지 않은 컨테이너**의 블록배치
메커니즘을 먼저 검증한다. 그 상금과 구조가 확인된 뒤, 실제 터미널 자료가 필요한 적재규칙을
마지막에 추가해 성능 유지 여부를 재검증한다.

현재 PoC는 공간·높이·규격·pile 일관성·슬롯 중복 금지 같은 최소 물리만 사용한다. 이 조건에서
개선이 생기면 “비용 기반 블록배치가 단순 환경에서 작동한다”는 방법론 증거다. 실제 운영
가능성 주장은 이 작업 완료 전까지 금지한다.

## 최종 도입 대상

- 중량·무거운 컨테이너 하단 적재와 슬롯 강도
- 냉동 컨테이너 전원구역·플러그 용량
- 위험물 등급별 격리거리·인접 금지
- 선사·목적항·항차·출항순서 그룹 적재
- 공컨·적컨 구역분리와 미지정 공컨 자격
- OOG·특수화물·전용블록
- 20ft×2와 40ft의 실제 bay 점유관계

## 개방 조건

1. YR-099에서 반입·양하 블록배치의 공개정보 상금이 확인된다.
2. YR-082 Level 2~3에서 터미널별 슬롯·구역·운영규칙 자료를 확보한다.
3. 규칙별 출처·적용 터미널·결측 처리·가정값을 사전등록한다.

공개자료만으로 분포나 상세 운영규칙을 임의 확정하지 않는다.

## 검증

- 규칙별 validator와 fail-closed 후보 mask
- 규칙 OFF일 때 기존 골든 불변
- 규칙 ON에서 위반 0, 완료율·backlog·결정론 검사
- 단순 PoC 대비 반입·양하 배치 이득의 유지·축소·역전을 구조군별 분리 보고

## 범위 밖

- YR-095를 이유로 현재 반입·양하 메커니즘 검증을 미루는 것
- 실측 자료 없이 특정 부산항 터미널의 운영규칙이라고 주장하는 것
- 본선 적하·지정 반출 대상 변경 또는 이미 적재된 컨테이너의 블록 간 물리이동
