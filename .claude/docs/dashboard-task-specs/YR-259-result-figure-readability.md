- **Epic**: Paper

- **선행**: [[YR-256]] (그림 양식 `figstyle.py` 확립) · [[YR-257]] (원고 문체 교정)

## 무엇을 하는 작업인가

논문 결과 그림 셋(학습곡선 · 수요수준별 분해 · 날짜별 짝비교)이 **읽히지 않아 본문에
넣을 수 없다**는 사용자 지적을 받아, 탑티어 논문의 그림 관례에 맞춰 다시 그렸다.
수치·자료·출력 경로는 그대로이고 **배치와 인코딩만** 바꿨다.

## 왜 안 읽혔나 — 진단 셋

세 그림 모두 **한 축에 서로 다른 것을 겹쳐** 그린 것이 원인이었다.

| 그림 | 겹친 것 | 증상 |
|---|---|---|
| 학습곡선 | 손실 4개 + 단위가 다른 탐험률 ε 을 쌍축으로 | 옅은 원자료 8줄이 화면을 가로지르고, ε 선이 그림을 대각선으로 자름. 선형축 상한을 넘긴 원자료 봉우리는 **잘려** 나감 |
| 분해막대 | 0.5억(원활)과 7.5억(초혼잡)을 한 축에 | 앞의 세 부하가 0선에 눌려 **부호조차** 안 보임. 게다가 넷째 막대만 기준선이 달랐다(`RL_EARLY` 대비) |
| 짝비교 | 확대 그림을 본 그림 **위에** 끼워넣음(inset) | 확대창이 그림 한가운데를 덮고, 자체 축·제목이 본 그림 축과 뒤섞임 |

## 무엇을 바꿨나

**규칙**: 세로축 단위가 다르거나 크기가 10배 이상 벌어지면 **축을 나눈다.** 나눈 뒤
(a)(b)(c) 로 표시하고, 범례는 그림 전체에 **하나만** 둔다.

### ① `fig-learning-curve` — 3단 분리 · 로그 축
- (a) 제안망 · (b) 수락망 · (c) 탐험률 ε — 가로축(회차) 공유
- **로그 세로축**: 손실이 0.002~1.06 으로 세 자릿수를 오간다. 선형이면 위를 자르거나 아래를 뭉갠다
- **혼잡 회차 음영**(수요 ≥ 12,500): 회차마다 부하를 새로 뽑으므로 손실의 오르내림
  상당수가 학습이 아니라 그날 수요에서 온다. 띠가 없으면 17~24회차 봉우리가 **과적합처럼 보인다**
- 범례는 회색 견본 4개(원자료 / 학습 / 검증 / 혼잡 회차) — 색은 패널이 이미 말한다

### ② `fig-decomposition` — 부하 구간 2패널
- (a) 원활~혼잡시작(3,500·5,000·7,500) · (b) 혼잡(12,500·15,000), 각자 세로축
- 가로축 눈금에 **관측 일수**를 함께 적었다(12·8·4·2·2일) — 합계 막대라 일수를 모르면
  "혼잡이 왜 이렇게 큰가"를 오해한다 (혼잡은 **일수가 적은데도** 크다)
- 기준선이 다른 넷째 막대(`RL_EARLY` 대비)를 **반 칸 띄우고 회색 계열**로 분리, 이름에 대비 상대 명기
- 해칭 선폭 0.5 로 낮춤 — 굵으면 막대 색을 덮는다

### ③ `fig-paired-daily` — 나란한 2패널
- (a) 28일 전부 · (b) 순위 1~24 확대 (inset 폐기)
- (a) 에 확대 구간을 옅은 띠로 표시하고 "shown in (b)" 를 적어 두 패널을 잇는다
- 개선/악화 범례 추가(파랑 원 · 붉은 사각)

## 검증

- 원자료에서 다시 읽은 값이 이전과 **동일**: 분해 합계 14.71억 · 시각 비중 **91.3%** ·
  짝비교 **26/28일** 개선 (표와 대조 가능하도록 스크립트가 실행 때마다 출력한다)
- PDF 3건 모두 벡터 + 글꼴 임베드(`TimesNewRomanPSMT` 서브셋 · 수식 STIX) · 폭 344~346 pt
  = **4.78~4.80 in** (LNCS 본문폭, 축소 없이 삽입되므로 8~10 pt 규칙이 인쇄물에서 유지됨)
- 600 dpi PNG 3건을 눈으로 확인 — 잘림·겹침·축 라벨 충돌 없음

## 곁다리가 남긴 것 — `fig-demand` 재렌더 필요

`figstyle` 에 `hatch.linewidth = 0.5` 를 넣었다(집 규칙은 한 곳에서 온다). `fig_demand.py`
가 `hatch="////"` 를 쓰므로 **다음에 그 그림을 다시 그리면 해칭이 조금 가늘어진다.**
지금 다시 그리지 않은 이유: 같은 시각 다른 세션이 `03-environment.tex`(그 그림을 싣는 절)을
고치고 있어 충돌을 만들지 않으려 했다. 그 작업이 끝난 뒤 재렌더하면 셋과 양식이 완전히 맞는다.
