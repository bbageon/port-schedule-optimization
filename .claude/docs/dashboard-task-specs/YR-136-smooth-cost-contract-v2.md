## 계약 — softplus 확률 비용 (v2.0 smoothstep 대체)

sp(x)=log(1+eˣ), σ(x)=1/(1+e⁻ˣ). 문헌: LSE-max 볼록근사(Boyd·Vandenberghe)·볼록
지연비용 스케줄링(Van Mieghem cμ 계열). 해석: **시간당 비용률 = 기본 체류 + 초과확률 ×
초과벌점** (로지스틱 오차 모형에서 정확).

- **트럭**: A=실제 게이트 진입, D_T=A+L_T(목표 턴타임), Ô=예측 게이트 진출.
  `J_T(Ô) = (Ô−A)/3600 + (κ_T/3600)·sp((Ô−D_T)/κ_T)` → `r_T = 1 + σ((Ô−D_T)/κ_T)`
  (1→2/h 연속, **D_T 에서 정확히 1.5/h** = 초과확률 50%). 후보 비교 = ΔC_T = J_T(Ô+Δt)−J_T(Ô).
- **본선 적하**: P=계획 완료, F̂=공개 공급경로 예상 완료(기존 projected_completion_s).
  `J_V = (10κ_V/3600)·sp((F̂−P)/κ_V)` → `r_V = 10·σ((F̂−P)/κ_V)` (0→10/h, **P 에서 5/h**).
  후보가 F̂ 를 안 바꾸면 비용 0 (공급 인과 유지). 양하 = 0 유지.
- **L_T 유도 앵커** (새 상수 발명 없음): L_T = 입문주행 평균 300s + 대기 SLA 1800s +
  표준 서비스 180s + 출문주행 평균 300s = **2,580s (43분)** — 기존 계약 구성요소 합.
- 고정 "마지막 10분/30분" 경계 폐지 — 전환 폭은 κ(예측오차)가 결정.

## Ô 예측기 (0단계 산출물 — 공개정보만, 동결)

- **도착 트럭**: Ô = now + (크레인 잔여실행초 + 표준서비스 180s × 선행 대기 트럭 수)/크레인
  수 + 표준서비스 + **출문주행 평균 300s** (작업별 exit_travel_s 는 외생 실현값이라 미열람).
- **미도착(공개 ETA)**: 같은 식에 도착시각 = provided_eta, 현재 큐를 proxy (고지) —
  라벨에서는 v1 규약(하한 0) 유지. **ETA 결측 = fail-closed** (v1 승계).
- **F̂**: vessel_cost 의 load_supply_state → projected_completion_s (기존 공개정보 fold).

## κ 적합 (0단계 — 프로토콜 사전 동결, 값은 적합 후 동결)

- 훈련 대역 4셀 × 시드 4 (BASE+0..3), **SF 정책** 에피소드. 예측 시점 = 트럭이 처음
  WAITING 으로 관측된 결정 / 본선은 개시 후 첫 결정. 오차 = 실현(게이트아웃·작업완료) − 예측.
- 위치-척도 적합: **b = 평균오차(중심 보정), κ = (√3/π)·SD(오차)** (로지스틱 근사 —
  피드백의 MLE 취지). 곡선은 (예측+b) 를 중심으로 사용. 미완료 검열 수 보고.
- 적합값은 kappa_fit.json 으로 동결 — **같은 판정런 안에서 κ·b 조정 금지**.

## 정책·평가 정렬 (이중 계약 금지 — softplus 판)

- 라벨·견적 = **예측값**(Ô, F̂) 의 J. 에피소드 평가 = **실현값**(O, F) 을 같은 J 형태에
  대입 (sp 항 = 실현 초과의 부드러운 벌점). 평가 KPI(평균 B→C·A→O·SLA 초과 건수)는
  원형 보고, 본선 환산 최대 가중 33→10, 계단형 long_wait 와 점증항 이중가산 금지 (v2.0 승계).
- 불확실성: κ 가 오차모형 그 자체 — 곡선에 내재. lo=cost=hi 로 반환 (별도 대역 없음).
- escalation_start 재정의: **초과확률 50% 도달까지의 예측 여유** = max(0, D_T−Ô) /
  max(0, P−F̂).

## 수용 기준 (v2.1)

- r_T: 단조증가·(1,2) 한계·**r_T(D_T)=1.5 정확**. r_V: 단조·(0,10)·**r_V(P)=5 정확**.
- ΔC 구간 가법성: J(x+d1+d2)−J(x) = [J(x+d1)−J(x)] + [J(x+d1+d2)−J(x+d1)].
- 지연 증가 시 비용 비감소. v1(cost_curve.py·NUMERAIRE-V1) 바이트 불변. 실현 미래
