## 고친 것 넷

1. **★그림 3에서 `(b) Acceptance network` 라벨이 사라져 있었다.** 2패널 판을 만들 때
   `set_xlabel` 을 `panel()` **뒤에** 불러 패널 이름을 덮어썼다([[YR-278]] 에서 축 이름
   아랫줄에 이름을 붙이도록 바꾼 뒤의 부작용). 축 이름을 먼저 걸도록 순서를 고쳤다.
2. **리드타임 근거가 없었다.** §3.1 이 "14.1% 는 자격을 못 얻는다", "중앙값 통지보다
   46분 늦게 결정된다" 고 적는데, 압축하며 리드타임 분포 설명이 빠져 근거가 공중에
   떴다. 설정표에 한 줄 추가 — `median 1.27 h (14.1% ≤0)`.
   (46분 = 중앙값 리드 1.27h(76분) − 검토창 30분. 코드
   `terminal_stream.LEAD_TIME_DIST` 의 실측 분위와 일치한다.)
3. **비용식이 $GT_v$ 를 쓰는데 표에 GT 값이 없었다** — 선박 등급 행에 50/100/150k 복원.
4. **"두 검정이 같은 양상" 이라는 오독 유발 문장.** 시간축 비교는 두 검정이 **갈리는**
   유일한 사례다(8/28 부호 p=0.036 규칙 우세 vs 부호순위 p=0.399, 총액은 학습 정책이
   10.0억원 낮다). "why both tests are needed" 로 바꾸고 "이것이 두 검정이 갈리는 유일한
   비교" 라고 명시했다.
