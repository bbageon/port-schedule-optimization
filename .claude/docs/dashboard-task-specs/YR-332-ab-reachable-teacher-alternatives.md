# YR-332-ab — 학습 교사의 대안을 실제 선택 계약에 맞추기

- **상태**: in-progress
- 등록: 2026-11-08. 상위 [[YR-332]], 근거 [[YR-332-w]].
- 3대 게이트 보정 대상: scenario_validity — 교사와 운영 정책의 행동·정보 계약 일치.
- 2026-11-09 사용자 지시: 환경 계산 확인 → 교사 수정 → 같은 구조 재학습까지 수행.
- w에서 실제 선택 불가능 판정이 확인됐다. 수정·재학습 실험은 아직 하지 않았다.

## 무엇과 왜

운영 정책은 실작업을 준비 작업보다 먼저 놓는다. 교사의 대안 강제는 이 순서를 우회한다.
저장된 두 자료에는 각각 52/198, 55/198개의 서로 다른 우선등급 쌍이 있다.
다른 크레인의 배정에 따라 선택 가능성이 달라지므로, 혼합이라는 사실만으로 버릴 수 없다.
w에서 실제 선택 불가를 확인했으므로 학습의 목표와 실행 행동을 맞출 필요가 있다.

## 확인된 근거 — 2026-11-08

w의 10회 정확 재생에서 기존 자료 40/198, 최신 자료 45/198쌍의 대안이
고정 우선순위·공동 배정 안에서 선택 불가능했다. 최신 자료의 16쌍은 교사가 그 대안을 선호했다.
최신 자료는 세 초기값에서 각각 12/66·16/65·17/67쌍으로 같은 경로가 재현됐다.
혼합 등급이지만 선택 가능한 쌍도 10개 있었으므로 종류만 보고 거르는 방식은 쓰지 않는다.
선택 가능 판정은 자유로운 후보 점수의 상한이다. 현재 신경망으로 모두 구현 가능하다는 보장은 아니다.
[감사 결과](../../../outputs/reports/yr332_action_contract/README.md).

## 단일축 수정안

1. 운영 정책의 필수 작업·실작업 우선·공동 안전·작업 중복 금지를 고정한다.
   후보 수를 임의로 줄이거나 신경망·입력·비용식을 함께 바꾸지 않는다.
2. 교사의 비교 대안은 같은 운영 제약 안에서 선택 가능한지 확인한다.
   물리적으로 강제 가능하다는 사실만으로 운영 선택 가능성을 대체하지 않는다.
3. 다른 크레인의 배정까지 필요한 대안은 실행 가능한 공동 선택과 그 증거를 남긴다.
   그 공동 선택으로 미래를 진행하며 나머지 정책·입력·평가창은 원래와 같게 유지한다.
4. 고정 예산에서 대안을 못 찾은 결정·거절 이유·실제 수집 쌍 수·계산 시간을 전부 보고한다.
   성공 표본만 더 모아 예산을 결과에 맞춰 늘리지 않는다.
5. 과거 라벨을 몰래 삭제·덮어쓰지 않는다. 기존 자료와 새 계약 자료를 분리하고,
   같은 초기 모델·학습 예산·평가 입력에서 새 교사 계약의 효과만 비교한다.
6. 비용 순서 정확도와 운영 성능을 구분한다. 체류·접수·완료·본선 보호를 함께 판정한다.

## 선행·완료 기준

w의 정확 재생·선택 가능성 증거가 먼저다. [[YR-332-aa]]와 [[YR-332-i]]의 환경 보정과
새 학습을 한 실험에 섞지 않는다. 미통과 게이트에 따라 환경 계약을 먼저 확정하고,
고정 예산·비교 대상·중단 조건·채택 기준을 별도로 사전등록한 뒤 수행한다.
이 작업은 현재 규칙 대비 성능 미달이 이 원인 하나 때문이라고 가정하지 않는다.

## 이번 실행 범위 — 2026-11-09

aa의 외생 주문 보존과 i의 양하 하한 수정을 공통 환경으로 고정한다.
운반차 3대·470초와 예약 정확성은 미보정 가정으로 남긴다. i/f 완료나 현실성 통과를 주장하지 않는다.
사용자의 3단계 실행 지시에 따라 합성 환경에서 교사 계약 수정의 재학습 효과까지 검증한다.
운영 정책의 10개 입력·64×64 신경망·실작업 우선·비용식은 두 군에서 동일하다.

대안 후보와 같은 float32 입력을 가진 모든 후보의 점수만 함께 앞당겨 실제 resolver로 확인한다.
필수 등급·실작업 우선·중복·공동 안전 조건을 우회하지 않는다. 전 후보 목록은 유지한다.
이는 단일 입력 점수 개입으로 찾은 대안이며, 가능한 모든 신경망 순서를 전수 탐색한 것은 아니다.
같은 표본 결정에서 차례로 대안을 확인하고, 없으면 해당 예산을 소모한 채 거절 사유를 저장한다.
실행할 공동 배정 전체를 기록하고 두 분기의 첫 배정과 대조한다. 이후에는 원래 정책으로 돌아간다.
기존 강제 교사 자료와 새 자료를 새 환경에서 각각 생성한다. 과거 자료는 덮어쓰지 않는다.
세 초기값·동일 행동 정책·고정 수집/최적화 예산, 독립 평가일의 최종 가중치로 비교한다.
