# YR-254 — 상호 동의 절제 (거부권을 없애면 얼마나 나빠지나)

## 왜 이 작업이 필요한가

논문이 새로움으로 내세우는 것은 **제안과 수락을 독립 정책으로 갈라 두고, 양쪽이
동의한 후보만 중앙이 확정한다**는 구조다. 그런데 지금까지 측정한 것은

- 한쪽 동의만으로 확정된 재배치가 **0건** — 즉 *장치가 설계대로 돌아갔다*

뿐이고, **동의를 요구하는 것이 이득인가**는 한 번도 재지 않았다. 작동 확인은
절제 실험이 아니다. 심사자가 가장 먼저 묻는 자리이기도 하다.

## 무엇을 하는가

팔 `RL_NOVETO` — 학습된 두 망은 그대로 두고 **수락 정책의 학습된 거절만** 없앤다.

```python
# actors/buyer.py
self.always_buy = False        # 켜면 값 판단 없이 BUY
...
if slot_capacity_left is not None and slot_capacity_left <= 0:
    return Response(offer=offer, action=REJECT)   # ★용량 = 물리, 강제보다 세다
...
elif self.always_buy:
    action = BUY                                  # ★절제 — 제안만으로 확정
```

용량 검사가 위에 그대로 남아 있으므로 **물리적으로 불가능한 거래는 여전히 거절**된다.
없애는 것은 오직 *값을 따져 거절하던 부분*이라, 이 팔은 제약 위반이 아니라
**"상호 동의 중 학습된 판단"만 덜어낸 대조군**이다.

`stage/episode.py` 는 `RL_SPACE`·`RL_TIME` 과 같은 방식으로 팔을 편다 — 시장 구성은
`RL` 과 동일하게 두고 플래그만 넘긴다.

## 선행 실측 (2026-08-30) — ⚠️ 결론 아님

시드 9,900,970 · 부하 3,500 과 12,500 **이틀** · `ckpt_029` · 반사실 호출 0회 통과.

| 팔 | Φ 합계 | 거래 | 공간 | 시간 |
|---|---|---|---|---|
| 재배치 없음 | 15.47억 | 0 | 0 | 0 |
| RL | 11.74억 | 10,279 | 1,698 | 8,581 |
| **RL_NOVETO** | **11.24억** | 12,657 | 1,822 | 10,835 |

거부권을 없앤 쪽이 **4.27% 쌌고** 거래는 23.1% 늘었다. 날짜별로는 하루가 무승부,
하루가 `RL_NOVETO` 우세였다.

**n=2 다. 결론이 아니다.** 다만 방향이 논문 주장에 **불리**하다는 점이 중요하다 —
그래서 이 수치를 근거로 *동의 구조가 이득이다* 라고 쓰지 않았고, 반대로 지어내지도
않았다. 현재 논문은 **작동 확인까지만** 주장하고, 한계 절에 다음을 명시했다:

> 동의 구조 자체의 기여는 분리되지 않았다 — 한쪽 동의만으로는 아무것도 확정되지
> 않음을 확인했으나 수락 정책의 거부권을 없애면 비용이 얼마나 달라지는지는 재지
> 않았다. 따라서 제안과 수락의 분리는 절제 실험이 아니라 작동 확인으로 뒷받침되는
> 설계 선택으로 남는다.

## 다음 단계

판정 대역 28일에서 `RL` vs `RL_NOVETO` 짝비교. 세 갈래로 해석이 갈린다.

1. **RL 이 유의하게 싸다** → 동의 구조가 이득이다. 논문의 주장이 절제로 뒷받침된다.
2. **차이 없음** → 구조는 비용이 아니라 *실행 가능성·설명 가능성* 으로 정당화된다.
   그렇게 다시 쓴다.
3. **RL_NOVETO 가 싸다**(선행과 같은 방향) → 지금 수락망이 **과하게 거절**하고 있다는
   뜻이다. 수락망의 라벨 품질을 먼저 본다 — 구조를 버릴 근거가 아니라 학습이 덜 됐다는
   신호일 수 있다([[YR-246]] 의 학습 몫 문제와 같은 뿌리).

## 실행 설계 (2026-09-03) — 위 "다음 단계" 를 두 군데 바꿨다

### 1. 판정 대역이 아니라 **진단 대역**이다

위에서 *"판정 대역 28일"* 이라 적었지만 **9,400,000 은 [[YR-233]] 에서 이미 썼고**,
같은 커밋에서 `eval/guards.py` 의 `USED_BANDS` 에 넣어 재사용을 코드가 막는다.
한 대역은 한 번만 쓴다 — 두 번째 판정은 그 대역에서 고를 여지를 만든다.

절제 실험은 **진단 대역이 제자리다.** 여기서 무엇이 참인지 알아내고, 논문 주장으로
쓸 값이면 그때 **새 판정 대역에서 확증**한다. 순서가 뒤집히면 안 된다.

### 2. 한 무대가 아니라 **세 환경**이다

[[YR-286]] 이 보인 것: **혼잡 빈도가 바뀌면 결론이 바뀐다.** 한 무대만 재면 그 함정에
그대로 빠진다. 그리고 셋을 **동시에** 돌리면 벽시계가 가장 느린 하나(혼잡)와 같으므로
**시간을 더 쓰지 않고 세 배로 안다.**
