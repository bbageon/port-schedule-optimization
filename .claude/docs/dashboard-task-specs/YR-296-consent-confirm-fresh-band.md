- **상태**: backlog · 2026-09-03

- **선행**: [[YR-254]] (진단 대역 절제 — 84일 60/84, p=0.0001 로 거부권 우세)

## 왜

[[YR-254]] 의 결과는 진단 대역(9,900,980)이다. 규약상 진단 수치는 논문 주장이 아니다.
논문이 *"동의 구조가 절제로 뒷받침된다"* 를 본문 주장으로 실으려면 **한 번도 안 쓴
판정 대역에서 한 번** 재야 한다 (9,400,000 은 [[YR-233]] 이 썼고 `USED_BANDS` 가 막는다).

## 무엇을

- 새 대역(예: 9,500,000 — `check_bands` 통과 확인 후 동결) 30일 × RL vs RL_NOVETO.
- 기준선 `NO_REALLOC` 포함 3팔. 부하는 설계 분포 추첨 그대로.
- 판정식: 날 단위 짝비교 · 부호검정 + 정확 부호순위 · [[YR-254]] 와 같은 처리.

## 조건

논문이 이 주장을 싣기로 결정했을 때만 돌린다 — 대역은 소모품이다.
