# YR-332-br · 1시간 할인 + 예측값으로 단기 학습 (bp 결과 뒤 판단)

- **상태**: backlog
- 상위 [[YR-332]]. 2026-11-24 등록. [YR-332-bq](YR-332-bq-value-horizon.md)에서 나온 후보다.
- 보정 대상: performance — bp와 같은 단기 학습을, 30분 창 대신 1시간 할인 + 다음 결정의 예측값으로 한다.
- 착수 조건: [YR-332-bp](YR-332-bp-short-window-large-batch.md) 결과를 본 뒤 판단한다. bp에서 단기 학습이 짧은 작업 우선 규칙에 다가가지 못하면 이 후보도 접는다. 현실성 미통과로 사용자 확인이 필요하다.

## 왜

- bq에서 1시간 할인은 흔들림 990, 남는 효과 트럭 13.2%·배 1.3%, 갱신당 필요한 결정 170,555개였다. bp의 30분 창(담긴 효과 대비 576배, 331,520개)보다 흔들림 대비 효과가 낫다.
- 배 효과는 거의 남지 않으므로 bp와 마찬가지로 1대67 공동 목표가 아니라 단기 트럭 대기 학습이다.

## 할 일

- bp와 같은 학습 월·시험 월·갱신 4회·평가로, 학습 목표만 1시간 할인 + 예측값으로 바꾼다. 세부는 착수 시 실행 전에 등록한다.
