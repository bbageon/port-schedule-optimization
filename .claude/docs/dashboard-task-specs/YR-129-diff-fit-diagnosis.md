## 4축 측정 ([하네스](../../../src/yard_rl/experiments/yr129_diff_fit.py) docstring 이 동결 정본)

- **A 훈련분포 적합**: 학습 대역(BASE+0/+1)에서 실행 후보의 D̂ vs 실측 D — Pearson r·
  부호 일치·MAE·보정 기울기. (정직 고지: 리플레이 표본의 문자적 재현이 아닌 분포 근사)
- **B 신규상태 적합**: 미학습 대역(BASE+700/+701)에서 같은 측정.
- **C 미선택 후보 적합**: 결정마다 **열거된 전 후보**에 D 라벨(결정당 baseline rollout
  1회 공유) — 실행/미선택 절단 적합 + 결정 내 Spearman·top-1. 전원-WAIT 항등 후보는
  제외하고 D̂ 만 "0-앵커" 검사.
- **D 종결 잔여 상관**: rollout 종료 시점 미완 작업 수와 |D−D̂| 오차의 상관 + 3분위 비교.
- 부수: 행동 유형별(REPO/부분 WAIT) MAE 분해. **부산물 = 고정 라벨 데이터셋 저장**
  (dataset_s*.pt — 오프라인 재학습 분기가 표본 재생성 없이 사용, train/novel 분리 내장).

## 판별 규칙·분기표 (동결)

| 결과 | 의미 | 다음 작업 |
|---|---|---|
| A 축 r < 0.5 | 회귀 미적합 | **고정 데이터셋 오프라인 epoch 학습** (생성·갱신 혼합 금지 — val 적합 정체 시 종료) |
| A ≥ 0.5, B < 0.3 (또는 A−0.2 초과 하락) | 일반화·상태표현 | YR-124 |
| 실행 부호 ≥ 0.7, 미선택 ρ < 0.3 | 후보 라벨 부족 | 상태당 K-후보 차분학습 (갱신 확대 아님) |
| A·B·C 양호 + 운영 실패(기지) | 표적 정의 문제 | 종결 잔여비용 추가 또는 시간창 재검 (D 축 상관 >0.3 이면 가중) |
| REPO MAE > 전체 ×2 | 유사 WAIT 신용 문제 | 행동 유형별 차분표적 검사 |

복수 발화 가능 — 전부 보고, 지배 원인은 효과 크기순. 진단이며 판정 아님.
