# YR-332-ap — 고물량 시간대의 도착 몰림 크기 판정 (외부 자료 대기)

- **상태**: backlog
- 등록: 2026-11-14. 상위 [[YR-332]], 발견 작업 [[YR-332-am]].
- **3대 게이트 보정 대상**: scenario_validity(고물량 입력의 몰림이 실제 근거 범위 안인가).
- ⏸ 외부 자료 대기. 터미널 전체 기록 또는 시간당 245번을 넘는 날짜 자료가 필요하다.

## 무엇과 왜

개발용 13일의 최대는 시간당 245번 방문이다. 60번 이상 시간대 174개에서 몰림 지수는 물량과 함께 뚜렷하게 커지지 않았다
(100번당 1분 −0.02, 10분 +0.10). 그런데 합성 7,500·15,000건은 이 범위를 넘는 시각대가 많고,
ak 조건 ③은 같은 시각대 날짜를 겹쳐 1분 지수를 1.67·2.36으로 키운다. 근거 범위 밖이다.

ak 결과로 본 민감도(학습 후 모델 vs 짧은 실작업 우선 규칙): 7,500건 무작위 간격 +7.62%, 실제처럼 몰림 +14.40%,
15,000건 +18.88%, +19.25%. 몰림 가정에 따라 7,500건 격차 크기가 달라진다.

## 범위

1. 새 자료가 오면 시간당 방문 수별 몰림 지수를 am과 같은 정의로 다시 잰다.
2. 고물량에서 몰림이 물량과 함께 커지는지 판정하고, 생성 방식(날짜 겹치기 또는 물량 무관 몰림 유지)을 사전등록으로 고른다.
3. 그 전에는 7,500·15,000건 결과를 무작위 간격과 실제처럼 몰림 두 조건의 범위로 함께 보고한다.
