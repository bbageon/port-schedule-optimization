# YR-247 — 논문 v2 최신 Dashboard·실험 이력·명세 동기화

- **상태**: done · 2026-08-28
- **분류**: Paper
- **근거**: YR-239·239b·242·243·245·246와 각 원자료

## 목적

2026-08-27 논문 초고 이후 확인된 반사실 라벨 결함과 크레인 배차 진단을 논문 v2에
반영한다. 구현 성공, 탐색 진단, 예비 성능, 미완료 평가를 섞지 않는다.

## 반영할 사실

1. 반사실 분기가 본 실행의 탐색률을 물려받지 않아 초기 4일 학습 라벨의 97%가 0이었다.
   수정 뒤 0 비율은 62%, 실질 신호는 1건에서 13건, 동일성 검사는 4건 모두 통과했다.
2. 현행 크레인 작업순서는 학습 신경망이 아니라 실작업 우선·최단 처리시간 규칙이다.
3. 재배치 없는 하루 진단에서 크레인 배차 규칙의 순위가 수요에 따라 뒤집혔다. 이는
   재배치 정책의 우세가 아니라 환경 민감도 진단이며, 규칙별 하루·한 시드라는 한계가 있다.
4. 7일 예비평가에서 학습 정책은 재배치 없음과 선착순 규칙을 7일 모두 이겼지만,
   학습 전 무작위 가중치 모형과는 4/7, p=1.000으로 구분되지 않았다. 학습 효과는 미확정이다.
5. 최근접 블록 규칙은 한 블록으로 후보가 집중되는 구조 결함 때문에 주 비교에서 제외했다.
   결과 확인 뒤 발견했으므로 제외 사유와 포함 수치는 함께 공개한다.

## 주장 경계

- 30일 연속 환경의 상태 연결과 오류 검출은 방법 검증으로 쓴다.
- 진행 중인 미사용 난수시드 30일 평가는 결과로 쓰지 않는다.
- 같은 크레인 규칙 아래 짝비교는 유효하지만, 다른 크레인 규칙으로의 일반성은 주장하지 않는다.
- 제출 본문 01~06에는 내부 시장 은유와 버전 번호 대신 일반 학술 용어를 쓴다.
