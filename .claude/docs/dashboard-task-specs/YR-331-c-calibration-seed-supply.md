# YR-331-c — 독립 보정 시드의 공급 부족 복구

- **상태**: backlog
- 파생: YR-331-a 초기 측정 중 생성 계약 실패(2026-09-27).
- 무엇: 시드 9921000, 부하 3,500·5,000·7,500의 Y08에서 원천 컨테이너 971개보다 반출 요구 976개가 많아진 경위를 찾고 입력 계획의 보존식을 바로잡는다.
- 왜: 상한을 독립 자료로 검증하는 단계가 시작조차 못 했다. 다른 시드로 교체하면 생성기의 적용 범위를 숨긴다.
- 증거: `outputs/reports/yr331_training/calibration-audit.json`, 원 실행 `yr331-runs/validation/failure.json` 및 `input-preflight.json`.

## 범위와 판정

1. `build_month → plan_month_vessels → build_fixed_seed` 단계별 원천/반출 장부를 복원한다.
2. 주문 삭제, 컨테이너 중복 반출, 없는 상자 생성, 알려지지 않은 미래 물리 완료 사용을 금지한다.
3. 입력 수량·흐름·초기 적재의 어느 계약을 바꾸는지 명시하고 실제 자료 또는 공개 범위에 대조한다.
4. 원 시드와 경계 사례를 검증한다. 실패 입력을 보존하고 보정 자료의 선택 편향을 보고한다.
5. 정책·보상은 고치지 않는다. 환경·입력 한 축을 고친 후 YR-331-a의 독립 상한 검증으로 돌아간다.

## 현재 결과

미착수. YR-331-b의 학습·평가는 완료했고 비교 입력 여섯 개는 별도의 사전 검사에 통과했다. 이 사실을 모든 시드의 현실성 통과로 일반화하지 않는다. [학습·평가 결과](../../../outputs/reports/yr331_training/report.md).
