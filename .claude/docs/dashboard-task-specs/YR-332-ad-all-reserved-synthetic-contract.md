# YR-332-ad — 전건 예약 합성 시드·예약/실제 진입 분리

- **상태**: in-progress
- **3대 게이트 보정 대상**: scenario_validity
- 상위: [[YR-332-f]]. 사용자 지시(2026-11-10): 24시간 합성곡선, 예약 없는 오더는 없다고 가정하고 진행.
- 목적: 실제 도착을 그대로 알려 주던 하루 연구 경로의 정보 계약을 고친다. 실측 보정 완료를 뜻하지 않는다.

## 고정하는 것

1. 24시간 트럭 실제 진입곡선: 10시·15시·21시 봉우리와 전 시간대 기본 물량.
2. 오더 수·반입반출·컨테이너·블록·주행·통지 리드·본선 계획·물리 용량·정책·보상.
3. 모든 트럭 오더에 예약이 존재한다. 미예약·예약 누락·노쇼는 이번 연구 조건에 없다.
4. 본선 적하/양하는 트럭 예약 대신 기존 본선 계획 시각을 따른다.

## 바꾸는 축: 공개 예약의 정확도

- 실제 진입 `A`는 기존 합성곡선으로 고정하고, 공개 예약 `R = A - ε`를 별도 생성한다.
- `ε`는 시드에 고정한 평균 0 정규 표본을 ±2σ에서 제한한 합성 오차다.
  기본 σ=600초는 기존 `TerminalStreamParams`의 설계값을 명시적으로 재사용한다.
  실제 항만에서 10분 오차라는 주장은 하지 않는다. 0초는 이전 완전 예측 조건 재현용이다.
- 예약이 관측 시작 전이나 끝 뒤일 수 있다. 자정에서 예약을 0/24시간으로 잘라
  실제 오더를 버리거나 진입 시각을 움직이지 않는다. 예약이 접수보다 앞선 과거 시각일 수도 있다.
  통지 시각은 기존 통지→실제 진입 표본을 유지한다. 이 결합분포도 실측 보정값은 아니다.
- 공개 예상 블록 도착은 `R + 블록까지의 기준 주행시간`; 실제 도착은 `A + 실제 주행시간`이다.
- 정책의 실행 기록은 해당 사건 이후에만 채운다. 신경망 입력 수·후보·보상 수식은 바꾸지 않는다.
- 하루 경로와 이를 이어 붙이는 월 경로에서 예약/실현 시각을 함께 보존한다.
  과거 저장 입력은 별도 계약으로 취급하고, 명시된 예약이 None/비정상 수치이면 실패시킨다.
  미지원 실행기가 실제 시각을 예약으로 몰래 대체하지 못하도록 검증 또는 명시적 거절한다.

## 결과 열람 전 검증 계획

- 부하 3,500/7,500/15,000 × 시드 9915101/9915102/9915103의 78,000건 생성.
- σ=0/600/1800초에서 전건 예약, 개수·실제 진입·물리 계획 불변, 반복 생성 동일성 확인.
  1800초는 합성 민감도 확인이며 최적 설정을 고르는 시험이 아니다.
- 통지 전 비가시, 진입 전 실현 기록 없음, 공개 예상값의 실현시각 독립성,
  이른/늦은 도착, 자정과 여러 날의 시간 이동, 분기 복제 계약 회귀 검사.
- 코드 변경 전 최단 실작업 우선 규칙으로 세 부하(시드 9915101) 하루 결과 보존.
  변경 후 σ=0에서 사건·선택·비용 재현, σ=600에서 투입 누락·시간 순서·비용 장부 확인.
  7,500건 σ=600 조건 한 번 반복. 총 변경 후 7회, 변경 전 3회.
- 관측 창 24시간, 엔진 26시간. 트럭 체류는 게이트 진입→출차로 계산한다.
  예약 오차를 체류시간에 더하거나 예약 시각부터 기다렸다고 계산하지 않는다.
- 실행 코드·설정·시드·입출력 해시·검사 결과를 `outputs/reports/yr332_reservation_contract/`에 저장.
