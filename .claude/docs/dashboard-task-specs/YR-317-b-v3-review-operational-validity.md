# YR-317-b — 예약 정원과 일정 변경 비용

- **상태**: backlog
- 분류: 현실성 직접 보정. 선행: YR-317-a의 신뢰성 통과와 착수 허가.
- 무엇: 정원 없는 시간 이동의 이득이 실행 가능한 예약·비용에서도 남는지 확인한다.
- 왜: 대표 이득 대부분이 시간 조정이며, 기존 비용에 게이트 진입 전 변경 부담이 없다.
- [실험 설계 §2·5·6](../strategy-history/2026-09-14-v3-review-experiment-protocol.md).
- 정원 → 통지 여유·이동 가능 범위 → 일정 변경·외부 대기 비용을 한 축씩 검증한다.
- 동시 제안의 정원 합계, 기존 예약 반환, 날짜 경계, 총수요 보존을 검사한다.
- 단가·정원 근거가 없으면 범위 민감도와 손익분기점을 보고하고 실항만 보정으로 부르지 않는다.
- 모든 비교군에 같은 운영 계약을 적용한다. 고정 정책 진단과 새 목적함수 재학습은 구별한다.
- 외부 보정 자료와 검증 자료를 분리하고 실제 운영 이력이 없는 주장 범위를 고정한다.
- 완료 기준: 예약 장부 보존, 불가능 변경·소실 없음, 비용 중복 없음, 현실성 판정과 최종 계약.
- 후속: 통과 후 YR-317-c. 실패 시 해당 환경·장부 축만 보정한다.
