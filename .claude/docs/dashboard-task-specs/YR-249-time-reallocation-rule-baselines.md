# YR-249 — 도착시각 조정을 사용하는 규칙 기반 대조군

- **상태**: in progress 🔴 · 2026-08-29
- **분류**: Exp
- **관련**: YR-250 재배치 유형 분해

## 문제

현재 규칙 기반 대조군은 블록만 바꾸지만 제안 방법은 블록과 도착시각을 모두 바꾼다.
따라서 현재 우세가 학습 품질인지 더 넓은 행동 범위 때문인지 공정하게 비교할 수 없다.

## 구현과 평가

- `SLOT_LL`: 블록은 유지하고 통지 물량이 가장 적은 시간대로 미룬다.
- `SPACE_TIME_LL`: 반입은 한산한 블록, 반출은 한산한 시간대로 조정한다.
- 두 규칙은 공개된 통지 물량과 제안 정책과 같은 시간 후보를 사용한다.
- 구현·연기시험은 `893a9bf`에서 완료했고, 같은 28일·시드 9,900,950 평가가 진행 중이다.

## 완료 조건

- 두 규칙이 실제로 도착시각을 조정하는 기능시험을 통과한다.
- 미래 실현값을 입력으로 사용하지 않는다.
- 28일 평가에서 비용·승패·수요수준별 결과를 함께 보고한다.

## 결과 (2026-09-03) — 28일 평가 완결 + ★시험 결함 발견

### 1. 두 팔 다 설계대로 동작한다

```
                진단 9,900,950              판정 9,400,000
                감소     공간·시간          감소     공간·시간
도착시각만      3.41%   0 · 44,131         4.93%   0 · 53,110
블록+도착시각    1.51%  18,549 · 25,441     4.51%  22,159 · 30,626
학습 정책      14.72%                     18.29%
```

`SLOT_LL` 의 공간 이동이 **정확히 0** 이다 — 이름대로 순수 시간 팔이다.
`SPACE_TIME_LL` 은 둘 다 쓴다. **행동 폭을 학습 정책에 맞춘다**는 목적이 충족됐다.

### 2. 같은 행동 폭에서도 학습이 낫다 — 다만 검정이 갈린다

```
RL vs 블록+도착시각 (같은 행동 폭)
  진단   20/28   부호 0.0357 ✓   정확 부호순위 0.0146 ✓
  판정   17/28   부호 0.3449 ✗   정확 부호순위 0.0037 ✓
```

판정 대역에서 **방향만 보는 검정은 못 가르고 크기를 보는 검정은 가른다.** 효과가
소수의 날에 몰려 있다는 이 연구의 주장과 일치하지만, **한 줄로 단정하지 않고 두
검정을 함께 싣는다** ([[YR-233]] §6.4 와 같은 처리).

### 3. ★남겨 둔 결함 — 시험이 이 팔들을 금지하고 있었다

`5716ccb`([[YR-211]])의 `test_rule_arms_never_defer_time` 은 `ARM_RULES` **전체**에
*시간을 미루면 안 된다* 를 걸었다. 그런데 `893a9bf`(이 row)가 거기에 **시간을 미루는
팔 둘을 넣고 시험을 안 고쳤다.** 그래서 그 뒤로 `tests/v3` 가 계속 실패했다.

코드는 의도가 분명했다 — `classical.py` 에 `TIME_ARMS = {"SLOT_LL", "SPACE_TIME_LL"}`
가 이미 있었다. **시험만 따라가지 않았다.**

고치면서 계약을 **양쪽으로** 만들었다.

| 시험 | 대상 | 단언 |
|---|---|---|
| `test_space_rules_never_defer_time` | `ARM_RULES − TIME_ARMS` (4종) | `n_time == 0` |
| `test_time_rules_do_defer_time` ★신설 | `TIME_ARMS` (2종) | `n_time > 0` |

**신설한 쪽이 더 중요하다.** 이 팔들의 존재 이유가 *같은 행동 폭의 대조군* 인데,
시간을 한 번도 안 미루면 이름만 시간 팔이고 **"같은 행동 폭에서도 학습이 낫다"는
비교가 성립하지 않는다.** 그 비교는 판정 대역 결과에 들어가 있는데, 지금까지
**아무것도 그것을 보증하지 않았다.**

검증: 6 passed (공간 4 · 시간 2) — 두 팔 다 실제로 시간을 미룬다.
