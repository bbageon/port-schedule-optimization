# YR-249 — 도착시각 조정을 사용하는 규칙 기반 대조군

- **상태**: in progress 🔴 · 2026-08-29
- **분류**: Exp
- **관련**: YR-250 재배치 유형 분해

## 문제

현재 규칙 기반 대조군은 블록만 바꾸지만 제안 방법은 블록과 도착시각을 모두 바꾼다.
따라서 현재 우세가 학습 품질인지 더 넓은 행동 범위 때문인지 공정하게 비교할 수 없다.

## 구현과 평가

- `SLOT_LL`: 블록은 유지하고 통지 물량이 가장 적은 시간대로 미룬다.
- `SPACE_TIME_LL`: 반입은 한산한 블록, 반출은 한산한 시간대로 조정한다.
- 두 규칙은 공개된 통지 물량과 제안 정책과 같은 시간 후보를 사용한다.
- 구현·연기시험은 `893a9bf`에서 완료했고, 같은 28일·시드 9,900,950 평가가 진행 중이다.

## 완료 조건

- 두 규칙이 실제로 도착시각을 조정하는 기능시험을 통과한다.
- 미래 실현값을 입력으로 사용하지 않는다.
- 28일 평가에서 비용·승패·수요수준별 결과를 함께 보고한다.
