# YR-220 · 라벨이 누적 Φ 라 행동 차이가 묻힌다 — 기준선을 걷어내야 한다

> Epic RL · 우선순위 🔴 · 상태 **backlog** (등록 2026-08-24)
> 선행 [[YR-218]] ✅(실패로 종료) · 이 row 가 학습 실패의 **단일 원인 축**이다

## 1. 무엇이 문제인가 — 한 줄

**학습 목표가 "그 세계의 누적 총비용"이라, 행동 하나가 만드는 차이(10만원)가
누적값(최대 1억원)에 묻힌다.** 망은 시각대별 기준선을 외우고 행동 차이는 못 배운다.

## 2. 숫자 (2026-08-24 · [[YR-218]] 24회차 이력)

| | 값 | 눈금(100만원) |
|---|---|---|
| 학습 목표 범위 | 265,537 ~ 100,958,215원 | **0.27 ~ 100.96** |
| **행동 1건의 효과** | 103,418원(3,500) · 112,367원(5,000) | **0.10 · 0.11** |
| **망의 잔차**(마지막 3회차) | 4,404,413원 · 10,537,488원 | **4.4 · 10.5** |
| **잔차 ÷ 신호** | | **43배 · 94배** |

**망의 오차가 분해해야 할 신호보다 43~94배 크다.** 이 상태로는 argmin 이 행동을
고르는 게 아니라 잡음을 고른다.

### 손실은 내려갔는데 정책은 나빠졌다 — 앞뒤가 맞는다

부하 3,500 손실 39.8 → 4.6 (**8.7배 감소**). 망이 **누적 Φ 예측**은 잘 배웠다.
그게 목표였으니 당연하다. 다만 그 목표가 **행동 선택에 필요한 양이 아니었다.**

## 3. 왜 이렇게 됐나 — 설계 문서의 결정이 수치를 못 견뎠다

[04b](../architecture/04b-학습-잣대.md) §3 은 v2 의 `KEEP_Q = 0` 기준점을 **없앴다**:

> **`KEEP_Q = 0` 이라는 고정 기준점도 필요 없어진다** — v2 는 KEEP 을 상수 0 으로
> 두고 다른 좌표를 상대적으로 쟀지만, 이제 KEEP 세계도 **직접 굴려 값을 잰다**.

굴려서 재는 것 자체는 옳다(추정이 아니라 실측이 된다). **틀린 것은 잰 값을 그대로
학습 목표로 쓴 것**이다. 두 세계의 Φ 는 **분기 전 과거를 공유**하므로 그 공통 부분이
목표의 99.9% 를 차지한다. 망에게 공통 부분을 외우게 하고 나머지 0.1% 에서 행동을
가르라는 요구가 된다.

## 4. 고치는 법 — 세 안

| 안 | 내용 | 신호 대비 |
|---|---|---|
| **A. 창 증분** | 목표 = `Φ(t+H) − Φ(t)` — 분기 전 누적을 뺀다 | 100.96 → **약 10** (10배 개선, 여전히 신호의 100배) |
| **B. 결정별 중심화 (권장)** | 손실을 그 결정의 **평균 기준으로 빼고** 계산. 예측·목표 둘 다 중심화 | 목표가 **±신호/2** — 신호가 곧 전부 |
| C. 기준선 망 분리 | `Q = V(상태) + A(행동)` 로 쪼개고 A 만 학습(dueling) | B 와 같은 효과 · 구조 변경 필요 |

**B 를 권한다.** 구조를 안 바꾸고 손실 계산만 바꾼다. argmin 은 결정 안에서만
비교하므로 **결정별 상수를 빼도 선택이 안 바뀐다** — 수학적으로 안전하다.
A 는 B 와 함께 써도 좋다(창 증분이 물리적으로도 더 읽기 쉽다).

## 5. 판정 기준 (착수 전 동결)

- **잔차 ÷ 신호 < 1** — 망 오차가 행동 효과보다 작아야 argmin 이 의미를 갖는다
- 24회차 재실행에서 **마지막 6회차 평균 격차 < 첫 6회차** ([[YR-218]] 과 같은 기준)
- 라벨0 비율은 [[YR-218]] 과 같은 수준을 유지(이 축과 무관해야 한다)
- 비판정 대역 · 사전등록 설정은 [[YR-218]] 과 **동일하게** (H·부하·ε·회차)

## 6. ⚠️ 이건 하이퍼파라미터 조정이 아니다

[[YR-218]] 사전등록은 *"실패해도 설정을 바꾸지 않는다"* 고 못 박았다. 이 row 는
그 약속을 어기는 게 아니다 — **학습률·회차 수 같은 조정이 아니라, 목표 정의의
수치적 결함**이다. 43~94배 잔차는 "덜 배웠다"가 아니라 "배울 수 없는 형태로 줬다"다.

그래도 **[[YR-218]] 의 실패 기록은 지우지 않는다.** 그 실행은 그 설정에서 실패했고,
이 row 는 별도 실행으로 다시 판정한다.
