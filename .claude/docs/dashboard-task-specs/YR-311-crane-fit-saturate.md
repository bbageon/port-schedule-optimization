# YR-311 — 덜 세게 가르친 조건을 **끝까지** 돌린다

## 무엇을 하는 작업인가

[[YR-310]] 의 조건(스텝 계수 1.0)을 **더 이상 안 늘 때까지** 돌려, 평탄부끼리
[[YR-309]](계수 4.0)와 견준다.

## 왜 지금 하나 — [[YR-310]] 이 반만 답했다

| | 계수 4.0 | 계수 1.0 | |
|---|---|---|---|
| 한 회차 널뛰기 | 5.92% | **4.12%** | ✅ 줄었다 |
| 평균 성적 | +3.86% | +4.68% | ❌ 나빠졌다 |

**널뛰기는 줄었는데 성적이 나빠졌다.** 그런데 두 번째는 **비교가 틀렸을 가능성이
크다** — 계수를 1/4 로 줄이고 회차를 12 로 고정하면 **훈련량도 1/4** 이다.
실제로 처음 규칙을 이긴 시점이 4.0 은 3회차, 1.0 은 5회차로 늦었다.

총 스텝을 맞춰 보면 (세 점뿐이라 참고):

| 총 스텝 | 계수 4.0 | 계수 1.0 |
|---|---|---|
| 408 | +20.69% | +21.91% |
| 816 | +29.41% | **+3.21%** |
| 1,224 | +13.20% | +12.64% |

**같은 스텝이면 못하지 않다.** 그래서 훈련량을 맞춰 다시 물어야 한다.

## 어떻게

계수 1.0 으로 **36회차** 돌린다 — 36 × 102 ≈ 3,672 스텝으로, [[YR-309]] 가
9회차까지 쌓은 양(9 × 408 = 3,672)과 같다. 나머지 조건은 [[YR-310]] 과 동일.

⚠️ **회차를 결과 보고 늘리지 않는다.** 36 은 위 계산으로 먼저 정한 값이다.

## 판정 기준 (사전등록 — 실행 전에 확정)

[[YR-309]] 궤적과 **평탄부끼리** 견준다. 평탄부 = *"처음 규칙을 이긴 회차 이후"*
(계수 4.0 은 3회차 이후 = 20점, 계수 1.0 은 5회차 이후 = 31점).

| | 기준 (계수 4.0 · 3회차 이후) | 이번 |
|---|---|---|
| ① **평탄부 평균** | **+3.61%** | 나아져야 한다 ← **주 기준** |
| ② **평탄부 표준편차** | **4.66%** | 줄어야 한다 ← **주 기준** |
| ③ 한 회차 변동 중앙 | 5.92% | ([[YR-310]] 에서 이미 4.12% 로 확인) |
| ④ 최저점 | −3.61% | (참고) |

**①②를 둘 다 봐야 한다.** 널뛰기만 줄고 성적이 그대로면 "덜 배우는 대신 덜
흔들린다" 는 것이고, 그것만으로는 채택할 이유가 없다.

## 예산

10코어 기준 [[YR-310]] 이 12회차에 1.45시간이었다 → 36회차 ≈ **4.4시간** +
궤적 진단 0.6시간 ≈ **5시간**.

## ★결과 — **①② 둘 다 통과 → 채택** (2026-09-12 · 36회차 · 4.92시간 · 10코어)

A = 계수 4.0([[YR-309]] · 23회차) · B = 계수 1.0(이 실행 · 36회차). 같은 날·같은
시드·같은 순서. 궤적은 부하 7,500 · 시드 9,900,917 · 평탄부 = 처음 규칙을 이긴
회차 이후 (A 3회차 → 20점 · B 5회차 → 31점).

| | A (계수 4.0) | B (계수 1.0) | 판정 |
|---|---|---|---|
| ① **평탄부 평균** | +3.61% | **+2.24%** | ✅ 나아졌다 |
| ② **평탄부 표준편차** | 4.66% | **4.20%** | ✅ 줄었다 |
| ③ 한 회차 변동 중앙 | 5.92% | **3.45%** | −42% |
| ④ 최저점 | −3.61% | **−5.63%** | |
| 이긴 회차 비율 | 5/20 (25%) | 10/31 (32%) | |

B 궤적 (36회차):

    +15.5 +22.0 +26.0 +21.9 +18.5 │ -3.6 +2.2 +3.2 +3.7 -0.7 +1.5 +12.6
    +3.8 +4.5 +6.5 +2.1 -4.4 +7.2 +5.9 +2.1 +2.4 +3.2 -0.7 +0.8
    +6.9 +7.0 +7.7 +6.9 +1.1 +4.0 -3.9 -5.6 -0.1 -0.3 -3.6 -3.0

[[YR-310]] 의 교란(회차 고정 → 훈련량 1/4)을 36회차로 풀자 **널뛰기와 성적이 둘 다**
나아졌다. `FIT_STEPS_PER_SAMPLE` 기본값을 **4.0 → 1.0** 으로 동결한다.

### ⚠️ 그러나 1단계 목표는 아직 아니다

평탄부 평균이 **+2.24% — 여전히 양수**다. 규칙 크레인보다 아직 조금 비싸다.
이 변경은 학습을 **안정**시킨 것이지 규칙을 **이기게** 한 것이 아니다.

평탄부 앞 절반 평균 +3.11% · 뒤 절반 +1.43% — 마지막 6회차가 전부 0 이하인
구간이 있으나, **꼬리를 보고 고르는 것**이라 주장으로 쓰지 않는다. *"36회차 뒤에도
계속 내려가나"* 는 별도 사전등록 실행([[YR-312]])으로 묻는다.

## 아직 하지 않는 것

- **실작업 우선 울타리 해제** — 효과가 실증된 뒤에 ([[YR-039]] 퇴화 방지)
- **학습률 조정** — 스텝 수와 같이 바꾸면 어느 쪽이 들었는지 못 가린다
- **라벨 버퍼** — 유효기간 규약(04b §3)을 깨는 것이라 이 축이 끝난 뒤 별도 논의
- **규칙 6종 대비 판정** — 수렴이 풀린 뒤
