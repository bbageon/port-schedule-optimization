# YR-311 — 덜 세게 가르친 조건을 **끝까지** 돌린다

## 무엇을 하는 작업인가

[[YR-310]] 의 조건(스텝 계수 1.0)을 **더 이상 안 늘 때까지** 돌려, 평탄부끼리
[[YR-309]](계수 4.0)와 견준다.

## 왜 지금 하나 — [[YR-310]] 이 반만 답했다

| | 계수 4.0 | 계수 1.0 | |
|---|---|---|---|
| 한 회차 널뛰기 | 5.92% | **4.12%** | ✅ 줄었다 |
| 평균 성적 | +3.86% | +4.68% | ❌ 나빠졌다 |

**널뛰기는 줄었는데 성적이 나빠졌다.** 그런데 두 번째는 **비교가 틀렸을 가능성이
크다** — 계수를 1/4 로 줄이고 회차를 12 로 고정하면 **훈련량도 1/4** 이다.
실제로 처음 규칙을 이긴 시점이 4.0 은 3회차, 1.0 은 5회차로 늦었다.

총 스텝을 맞춰 보면 (세 점뿐이라 참고):

| 총 스텝 | 계수 4.0 | 계수 1.0 |
|---|---|---|
| 408 | +20.69% | +21.91% |
| 816 | +29.41% | **+3.21%** |
| 1,224 | +13.20% | +12.64% |

**같은 스텝이면 못하지 않다.** 그래서 훈련량을 맞춰 다시 물어야 한다.

## 어떻게

계수 1.0 으로 **36회차** 돌린다 — 36 × 102 ≈ 3,672 스텝으로, [[YR-309]] 가
9회차까지 쌓은 양(9 × 408 = 3,672)과 같다. 나머지 조건은 [[YR-310]] 과 동일.

⚠️ **회차를 결과 보고 늘리지 않는다.** 36 은 위 계산으로 먼저 정한 값이다.

## 판정 기준 (사전등록 — 실행 전에 확정)

[[YR-309]] 궤적과 **평탄부끼리** 견준다. 평탄부 = *"처음 규칙을 이긴 회차 이후"*
(계수 4.0 은 3회차 이후 = 20점, 계수 1.0 은 5회차 이후 = 31점).

| | 기준 (계수 4.0 · 3회차 이후) | 이번 |
|---|---|---|
| ① **평탄부 평균** | **+3.61%** | 나아져야 한다 ← **주 기준** |
| ② **평탄부 표준편차** | **4.66%** | 줄어야 한다 ← **주 기준** |
| ③ 한 회차 변동 중앙 | 5.92% | ([[YR-310]] 에서 이미 4.12% 로 확인) |
| ④ 최저점 | −3.61% | (참고) |

**①②를 둘 다 봐야 한다.** 널뛰기만 줄고 성적이 그대로면 "덜 배우는 대신 덜
흔들린다" 는 것이고, 그것만으로는 채택할 이유가 없다.

## 예산

10코어 기준 [[YR-310]] 이 12회차에 1.45시간이었다 → 36회차 ≈ **4.4시간** +
궤적 진단 0.6시간 ≈ **5시간**.

## 아직 하지 않는 것

- **실작업 우선 울타리 해제** — 효과가 실증된 뒤에 ([[YR-039]] 퇴화 방지)
- **학습률 조정** — 스텝 수와 같이 바꾸면 어느 쪽이 들었는지 못 가린다
- **라벨 버퍼** — 유효기간 규약(04b §3)을 깨는 것이라 이 축이 끝난 뒤 별도 논의
- **규칙 6종 대비 판정** — 수렴이 풀린 뒤
