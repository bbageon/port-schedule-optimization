# YR-317-h4 — 합성 환경 실측 보정 (환경 현실성 게이트 직접 보정)

- **상태**: backlog
- 등록: 2026-09-20. parent: YR-317. 리뷰어 2 대응·3대 게이트 `scenario_validity` 미통과 항목.
- 무엇: 두 합성 환경(기존 공유형·수직 끝단형)의 기준정책 운영 지표를 실측·문헌 목표에 맞춘다. 목표를 **실행 전에 등록**한다.
- 목표(초안): 한가한 날(3,500대) 평균 트럭 턴타임 15~30분·상위 10% 60분 이내(부산신항 터미널 공개 실시간값 반입 9분·반출 19분과 [24] 대기시간 연구 참고), 붐비는 날 크레인 1대 시간당 20건 이상(ASC/RTG 문헌 20~40건), 하루 처리량이 평균 수요를 넘을 것.
- 현재값: 수평 한가한 날 25분/41분(대체로 범위 안), 수직 한가한 날 2시간 58분/10시간 17분·크레인 5.8건/시간(범위 밖).
- 조정 후보(수직): 배 작업이 없을 때 해측 크레인도 트럭을 받는 역할 완화, 내부 운반 차량 수, 인계 시간, 블록 길이. 수평: 필요 시 단가·리드타임 외 물리 값만.
- 두 환경을 같은 목표에 맞추는 "동등 서비스 수준 보정"을 기본으로 하고, 직각 자동화 터미널 실측이 확보되면 환경별 실측 보정으로 바꾼다.
- 왜: 보정 없이는 환경 간 비교가 혼잡 차이를 보는 것에 그치고, 정책 이득도 현실 국면과 다른 곳에서 측정된다. 리뷰어 2가 요구한 외적 타당성의 최소 조건이다.
- 완료 기준: 목표표·조정값·조정 전후 지표가 근거 파일과 함께 기록되고, 보정된 환경에서 기준정책 30일 1회가 기록 검사를 통과한다. 정책 성능 판정은 포함하지 않는다.
- **3대 게이트 보정 대상: `scenario_validity`** — 환경 현실성을 직접 보정하는 단일축 작업.
