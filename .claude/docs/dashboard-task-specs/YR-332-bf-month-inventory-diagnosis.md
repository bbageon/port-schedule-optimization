# YR-332-bf — 월 단위 재고 감소 원인 진단

- **상태**: backlog
- 상위: [[YR-332]]. 파생: [[YR-332-i]], 2026-11-21.
- **3대 게이트 보정 대상**: `scenario_validity` — 월 입력 수지와 검사의 전제 확인.
- 선행: [[YR-332-be]] 코드 기록 대조. 30일 성능 판정 [[YR-332-d]] 전에 확인한다.

## 무엇과 왜

기존 월 계획 시험에서 총재고가 첫날 말 20,148개에서 최저 9,544개로 내려간다.
첫날 말의 절반 이상을 유지한다는 기존 검사에 실패하며 적하 하한 수정 전후 동일하다.
이것이 의도된 순반출인지, 공급 부족인지, 오래된 검사 전제인지 구분해야 장기 결과를 해석할 수 있다.

## 범위와 완료 기준

1. 기존 시드 9,400,777과 설정을 고정해 날짜·블록별 초기재고, 반입·반출·양하·적하 수지를 독립 집계한다.
2. 외부 반출 비율, 본선 보충 규칙, 최초 재고가 기존 시험 설명과 맞는지 확인한다.
3. 계획 재고의 실제 슬롯 부족·음수 여부와 50% 유지 조건 위반을 구분한다.
4. 입력 결함이면 수요를 임의로 삭제하지 않는 단일축 보정을 먼저 명세화한다.
5. 검사 전제만 오래됐다면 연구 설계상 의도와 근거를 제시하고 고친다. 결과를 맞추기 위한 임계 완화 금지.
6. 진단 결과·원시 수지·재현 증거를 저장한다. 이번 row에서 학습과 30일 성능 주장은 하지 않는다.

배열 경로의 궤적 불일치 [[YR-332-ah]], 월 예약 계약 연결 [[YR-332-ai]]와 구분한다.
외부 실측 자료가 없이도 기존 입력의 수학적 수지는 확인할 수 있다.
