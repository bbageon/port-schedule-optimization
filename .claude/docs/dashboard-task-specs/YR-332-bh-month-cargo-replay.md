# YR-332-bh — 고정 월 입력의 실제 적치와 반출 대기 확인

- **상태**: in-progress
- 상위 [[YR-332]], 파생 [[YR-332-bg]], 2026-11-21.
- **3대 게이트 보정 대상**: `scenario_validity` — 같은 입력의 공급 대기와 물리적 공간 사용.

고정 월 입력에서 2,034개 반출이 지정 화물보다 먼저 도착하도록 계획돼 있다. 예정 시각의 최대 차이는 약 24시간이다.
기존 90% 혼잡 경보와 50% 재고 유지 경보도 남았다. 월말 총량과 계획 날짜 합계만으로는 실제로 언제 화물이 쌓이고 빠지는지 알 수 없다.

1. 시드 9,400,777의 고정 화물 문서 지문을 bg 증거와 대조한다. 시작 상태를 보존하고 기존 규칙 한 가지로 실제 사건을 추적한다.
2. 14개 자정과 2,034개 지연 반출에서 수요 공개, 블록 도착, 지정 화물 실제 적치, 반출 시작·완료 및 미완료를 연결한다.
3. 블록별 실제 점유와 빈자리 대기를 확인한다. 실제 공급 완료와 출고 완료의 차이가 물리 재고와 같은지 검산한다.
4. 계산 예산·중단 조건을 실행 전에 기록한다. 중단 시 관찰 구간과 남은 작업을 함께 보고한다.
5. 기존 두 경보의 물리적 결과와 합성 화물 연결의 한계를 기록한다. 실측 운반·인계 정의는 i/f의 외부 대기로 유지한다.

같은 입력으로 환경만 진단한다. 정책 학습과 새 시드의 30일 성능 판정은 별개다.

## 사용자 요청 2026-11-23 · 실행 전 비교 기준

같은 30일을 연속 실행하고 기존 학습 정책과 규칙을 비교한다. 이미 공급을 검사한 이 달은 합성 진단 입력이다.
학습하지 않고 직전 본선 작업시간 목적의 세 저장 모델 중 번호가 가장 작은 9951101을 미리 지정한다.
최고점 행동을 고정하고 같은 초기 야드·도착·본선·화물에 짧은 실작업 우선과 가장 오래 기다린 작업 우선을 각각 실행한다.
정책은 크레인만 제어한다. 입력은 위 지문, 동일 물리·정보 시각·장기대기 보호·후보 전체를 유지한다.
학습 횟수를 검사하는 구형 시장 학습 경로는 이 동결 비교에 사용하지 않는다.

- 하루끼리 초기화하지 않는다. 30일 모두 유입시키고 이후 최대 5일간 같은 정책으로 잔여 작업을 처리한다.
- 2~29일 게이트 진입 트럭과 하역 가능 본선을 주 비교로 하며, 1~30일 전체도 별도로 기록한다.
- 트럭은 게이트 진입부터 야드 작업 완료, 본선은 하역 가능부터 모든 안벽 작업 중 마지막 완료까지 한 척에 한 번 센다.
- 기존 트럭 시간·빈 이동·재조작 단가와 본선 총톤수 시간 단가를 유지한다. 장비 비용은 해당 달력 구간에 발생한 양이다.
- 잔여 트럭과 배는 수와 누적 비용 하한을 공개한다. 미완료를 완료로 계산하거나 다른 종료시각의 하한으로 우열을 확정하지 않는다.
- 비교 예산은 연속 30일 세 번과 소형 구동 검사다. 안전·작업 누락·물리 재고 보존 오류가 나면 기록하고 원인을 조사한다.
- 3배 중단 규칙과 독립 평가 월을 쓰는 정식 판정(d)은 별도로 유지한다. 이번 한 달 결과는 관측 범위 밖 물량을 포함하며 일반화하지 않는다.
