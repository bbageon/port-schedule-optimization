# YR-257 — 논문 v3 국·영문 문체와 논리 흐름 교정

- **Epic**: Exp / **Priority**: 🟠 / **등록·착수일**: 2026-08-30
- **상태**: 완료 (2026-08-30)

## 목적

국문 원고는 긴 문장을 나누고 문단의 핵심을 앞에 둔다. 영문 원고는 국문과 같은 의미를
유지하되 직역하지 않고, 영어 논문에서 자주 쓰는 쉽고 자연스러운 문장으로 고친다.

## 범위

- `docs/paper/v3/latex/` 국문 LaTeX 원고
- `docs/paper/v3/latex-en/` 영문 LaTeX 원고
- 두 조판 PDF와 원고 간 의미·수치·표·수식 일치 확인

## 편집 원칙

1. 한 문장에는 중심 주장 하나를 둔다.
2. 각 문단은 문제, 방법, 결과, 의미가 자연스럽게 이어지게 한다.
3. 영문은 수동태와 명사화를 줄이고, 익숙한 학술 동사를 사용한다.
4. 수치, 통계 판정, 연구 범위와 한계는 바꾸지 않는다.
5. 국문과 영문은 문장별 직역이 아니라 문단별 의미가 일치하게 한다.

## 완료 조건

- 국문과 영문 원고 전체의 문체·논리 교정 완료
- 두 PDF를 각각 두 번 빌드하고 미정의 참조와 치명 오류가 없음
- 두 PDF 전체 페이지 렌더링에서 잘림·겹침·깨진 글자가 없음
- 국·영문 핵심 수치와 표 값이 일치함
- Dashboard evidence, 범위가 명확한 commit, origin push 완료
