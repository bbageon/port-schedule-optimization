# YR-332-ao — 날짜별 24시간 모양·반출 비율 변동을 입력 축으로

- **상태**: backlog (2026-11-16 at 선행 보정 동안 대기; 사용자 진행 승인 유지)
- 등록: 2026-11-14. 상위 [[YR-332]], 발견 작업 [[YR-332-am]].
- **3대 게이트 보정 대상**: scenario_validity(만든 입력이 실제 날짜별 흐름의 다양성을 담는가).
- 입력 축 한 개. 정책·보상·학습은 바꾸지 않는다.

## 무엇과 왜

am 측정에서 실제 날짜는 우연보다 훨씬 크게 달랐다.

- 같은 시각대 방문 수의 날짜 간 변동계수는 포아송 기준의 약 3.0배(1.8~5.5배)다.
- 24시간 모양 차이는 날짜 중앙값이 우연 기대의 1.52배, 주말은 2.5~3.5배다.
- 날짜별 반출 비율은 45.4~69.3%(표준편차 6.7%p, 우연 기대 1.0%p)다.

합성 입력은 물량별로 한 가지 모양·반출 비율만 쓴다. 물량 수준은 3,500·7,500·15,000건 조건이 맡지만,
같은 물량 안의 모양 차이(예: 주말형)는 없다. 그래서 한 가지 모양으로 학습한 정책이 다른 날에도 같은지 알 수 없다.

## 범위 (실행 전 사전등록)

1. 터미널 전체 자료인지 확인되지 않았으므로 하루 총량이 아니라 **시간대 비중과 반출 비율**만 쓴다.
2. 날짜 유형(평일·주말 등) 또는 날짜별 모양을 입력 축으로 넣을지, 넣는다면 어떤 단위로 뽑을지 먼저 정한다.
   13일 중 주말은 4일뿐이라 주말 모양을 확정 값으로 쓰지 않는다.
3. 축 하나만 바꾸고 방문 연결(al)·시간대 안 몰림(ak)·물리·정책은 고정한다. 고정 정책 비교로 민감도를 먼저 본다.
4. 개발용 13일 안에서 만든 입력은 독립 검증이 아니다. 독립 평가는 323-e의 미열람 기간에서 한다.

## 문헌 검토·설계 — 2026-11-15

사용자 요청: 고정 곡선 대신 변화를 주는 합성 데이터로 의미 있는 학습을 하도록 기존 연구를 검토한다.
이번 산출물은 **설계**다. 숫자 범위 산정·생성기 적용·고정 정책 시험·재학습은 아직 실행하지 않았다.
따라서 ao 구현 상태는 backlog를 유지한다. 다음 세부 작업은 입력 자료만으로 변화 범위를 산정하는 것이다.

- [문헌 대조](../../../docs/research/v7-discharge/synthetic-demand-literature.md): 항만 흐름 생성,
  합성 작업장 학습, 조건 무작위화, 시뮬레이션 타당성·학습 결과 불확실성의 원문·공식 문서 확인.
- [설계](../../../docs/research/v7-discharge/synthetic-demand-design.md): 하루 조건→방문·컨테이너 연결→실제 도착→입력 저장.
  먼저 날짜별 모양만 바꾸고 반출 비율 변화는 뒤의 별도 비교로 분리한다.
- 고정 대조군은 변동 학습 곡선 집합의 평균을 사용한다. 평균 매개변수를 넣은 곡선과 평균 곡선을 혼동하지 않는다.
- 변화 폭은 일별 정규화 분포의 저차원 적합·산포·날짜 제외 진단으로 정한다. 관행적인 ±10%를 채택하지 않는다.
  물량 7,500·15,000건과 관측 범위 밖 조건은 부담 시험으로 표시한다.
- 입력 다양성의 효과와 표본·갱신량 증가 효과는 구분한다. 유효 비교 쌍·유형별 학습 가능성은 323-d에서 확인한다.
- 관측 분별 형판의 수식 대체는 [ar](YR-332-ar-parametric-within-hour-arrivals.md)로 등록했다.
  이 작업의 기존 ak 방식 고정 계약을 조용히 바꾸지 않는다.
- 최종 합성 평가의 새 시드·새 조건 조합과 미열람 실측 기간 평가를 구분한다(323-e).

## 구현 착수 — 2026-11-15

사용자: 합성 데이터 구성은 제안대로 진행, 신경망 전략은 별도 검토.
동일 aq 게이트로 `authorize-next` 재실행: scenario_validity 보정 허용.
[입력 사전등록](../../../docs/research/v7-discharge/day-shape-prereg.md)에 맞춰
기존 세 봉우리+기저의 일별 비중 적합·새 계수 보간·학습/선택/잠금 곡선 은행을 구현한다.
현재는 입력 표현·재현·제약 검사 단계다. 정책 실행·새 학습·모델 구조 변경은 포함하지 않는다.
적합 오차가 표본잡음 범위를 넘으면 ao에서 곡선 가족을 먼저 보정한다.

첫 입력 적합에서 기존 4성분은 0/13일 통과. 정책 실행 없이 곡선 가족을 입력만으로 비교한 뒤
1시간 간격 주기적 선형 곡선으로 수정했다. 수정 시점·버린 후보·표현과 타당성의 구분은 위 사전등록에 추가했다.
계수 24개는 생성기 설정이며 정책 입력 10개를 늘리지 않는다. 반출 크기 감사는 실제 대상 박스 기준으로 정정했다.

새 seed=9934102·15,000건의 반출 44건이 재고 부족으로 반입 전환되어 최초 입력 감사가 실패했다.
전역 공급 보정은 at로 등록. 이번 곡선 은행은 작업 종류가 보존되는 배경 시드만 입력 단계에서 생성하며
모든 거절·재시도·최종 시드를 남긴다. 조건부 도메인 제한이며 현실성 전체 통과가 아니다.
