# YR-332-ao — 날짜별 24시간 모양·반출 비율 변동을 입력 축으로

- **상태**: backlog
- 등록: 2026-11-14. 상위 [[YR-332]], 발견 작업 [[YR-332-am]].
- **3대 게이트 보정 대상**: scenario_validity(만든 입력이 실제 날짜별 흐름의 다양성을 담는가).
- 입력 축 한 개. 정책·보상·학습은 바꾸지 않는다.

## 무엇과 왜

am 측정에서 실제 날짜는 우연보다 훨씬 크게 달랐다.

- 같은 시각대 방문 수의 날짜 간 변동계수는 포아송 기준의 약 3.0배(1.8~5.5배)다.
- 24시간 모양 차이는 날짜 중앙값이 우연 기대의 1.52배, 주말은 2.5~3.5배다.
- 날짜별 반출 비율은 45.4~69.3%(표준편차 6.7%p, 우연 기대 1.0%p)다.

합성 입력은 물량별로 한 가지 모양·반출 비율만 쓴다. 물량 수준은 3,500·7,500·15,000건 조건이 맡지만,
같은 물량 안의 모양 차이(예: 주말형)는 없다. 그래서 한 가지 모양으로 학습한 정책이 다른 날에도 같은지 알 수 없다.

## 범위 (실행 전 사전등록)

1. 터미널 전체 자료인지 확인되지 않았으므로 하루 총량이 아니라 **시간대 비중과 반출 비율**만 쓴다.
2. 날짜 유형(평일·주말 등) 또는 날짜별 모양을 입력 축으로 넣을지, 넣는다면 어떤 단위로 뽑을지 먼저 정한다.
   13일 중 주말은 4일뿐이라 주말 모양을 확정 값으로 쓰지 않는다.
3. 축 하나만 바꾸고 방문 연결(al)·시간대 안 몰림(ak)·물리·정책은 고정한다. 고정 정책 비교로 민감도를 먼저 본다.
4. 개발용 13일 안에서 만든 입력은 독립 검증이 아니다. 독립 평가는 323-e의 미열람 기간에서 한다.
