# YR-323-c — 긴 비용 비교에 필요한 작업 정보의 기여 확인

**상태**: backlog

등록: 2026-11-10. 상위 진단 [YR-323-a](YR-323-a-horizon-cause-audit.md).
조건부 성능 진단이다. 운반·예약 보정과 기존 본선 긴급도 입력 점검(YR-332-x)이 선행한다.

## 무엇과 왜

현재 입력 10개는 후보 유형·현재 대기·본선 여유·작업 비용·현재 대기열 중심이다.
예약 기반 사전 준비 후보는 있지만 향후 시간대별 물량과 장비 가용 계획을 직접 요약하지는 않는다.
비슷한 현재 입력에 다른 장기 비용 차이가 붙는 원인이 빠진 작업 정보인지 확인한다.
정보가 부족하다는 추측만으로 입력을 늘리지는 않는다.

## 진단과 단일 변경

1. 결정 시점의 알려진 정보와 실제 나중에 실현된 정보를 분리한 목록을 만든다.
   예약·게이트 진입 후 이동 중·블록 도착 후 대기를 서로 다른 상태로 유지한다.
2. 비슷한 입력인데 비용 우열이 달라진 선택을 분석하고, 공개된 작업 정보로 차이를 설명할 수 있는지 본다.
   기존 입력의 상한 포화와 기록 오류를 먼저 제외한다. 미래 실현값을 이용한 분석은 운영 입력과 구분한다.
3. 진단에서 근거가 나온 정보 한 종류만 선정한다.
   후보는 게이트 진입 후 이동 중인 작업량 또는 보정된 예약 기반 예상 작업 부하다.
   모두 넣는 계획이 아니며 추가할 값·시간 범위·눈금은 학습 자료만으로 실행 전에 고정한다.
4. 기존 입력과 한 가지 추가 입력을 같은 학습 자료·후속 정책·K·학습량에서 비교한다.
   시험 시각의 실제 도착·완료·미래 장비 상태를 읽지 않는 검사를 포함한다.
5. 그 정보를 다시 뺐을 때 이득이 사라지는지 확인하고, 운영 가능한 최신 값으로 효과가 유지되는지 본다.

## 완료 기준

- 값이 변하는지, 이름대로 측정하는지, 실제 자료로 만들 수 있는지 모두 확인한다.
- 규칙과 학습 정책 사이의 정보 접근 차이를 기록하고 정보 추가 효과와 학습 효과를 구분한다.
- 전체·반입·반출·양하·적하 시간과 비용·미완료·본선 보호를 함께 판정한다.
- 재현된 효과가 없는 정보는 기본 정책에 추가하지 않는다. 별도 예측 계층·다중 정책 결합은 범위 밖이다.
- 실제 자료가 없으면 합성 정보의 효과로만 보고하며 현실 적용 효과로 확대하지 않는다.
