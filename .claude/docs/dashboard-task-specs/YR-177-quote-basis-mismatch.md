# YR-177 — 세 선택지의 값매김 기준이 서로 다르다 (견적 기준 불일치)

- **Epic**: Exp / **Priority**: 🔴 / **등록일**: 2026-08-17 / **상태**: backlog
- **3대 게이트 보정 대상**: `performance` (YR-171-C 판정의 해석이 걸려 있음)
- **1줄**: resolver 가 한 줄에 놓고 비교하는 세 값이 **서로 다른 자로 잰 값**이다 —
  시간 좌표만 남에게 끼친 피해까지 얹어 재고, 공간 좌표와 원래 자리는 자기 비용만 잰다.

## 무엇이 어긋났나 (`sell_review.py:345-399`)

resolver 는 매 결정마다 아래 셋 중 가장 싼 것을 고른다.

| 선택지 | 값 | 무엇을 재나 | 누가 재나 |
|---|---|---|---|
| 그대로(KEEP) | `0.0` | — | — |
| 공간 이동 | `add + 주행 − relief` | **자기 비용만** (`j_truck`) | 계산식 |
| 시간 이연 (견적망 ON) | `add_t + d/3600 − relief` | **자기 비용 + 뒤차 지연 + 본선 밀림** | 견적망 |

`relief`(원래 자리에서 아끼는 분)도 `cost_given_queue` → **자기 비용만**이다
(`sell_gain.py:59-71` — `j_truck` 한 항). 따라서 시간 좌표에서만 뺄셈의 양변이
다른 자로 재어진다.

## 규모 (실측)

| | 값 | 출처 |
|---|---|---|
| 견적망 라벨 평균 | **1.21 비용시간** | `dataset_meta.json` (n=28,530) |
| 라벨 구성 | 자기 **51%** · 뒤차 **30%** · 본선 **19%** | 같음 |
| 라벨 중 자기 몫 | ≈ **0.62** | 1.21 × 0.51 |
| 계산식이 재는 트럭 1대 비용 | ≈ **0.65** | Φ 2,346 ÷ 3,600대 |

자기 몫(0.62)은 계산식 눈금(0.65)과 사실상 같다 → **어긋난 것은 정확도가 아니라
기준이다.** 시간 좌표만 약 **1.9배**의 자로 재고 있고, 그 차이 ≈ +0.6 비용시간이
모든 시간 후보에 붙는 **고정 세금**처럼 작동한다.

## 왜 판정 해석이 걸리나

YR-171-C 에서 견적망 부착의 효과는 −135.5(짝지어 t=−12.7~−13.5)로 컸다.
그런데 같은 판에서 **선택 구성이 단조로 이동**했다:

| 팔 | 시간 좌표 비중 | 공간 판매/일 |
|---|---|---|
| fixed15 | **60.0%** | 240.8 |
| slots48 (계산식) | **42.0%** | 170.3 |
| slots48_buy (견적망) | **17.1%** | **901.3** |

그리고 시간 판매는 이미 **1건당 +14.28분 손해**로 확정된 축이다(YR-170 축 분리 진단).
즉 관측된 이득은 "**손해나는 축이 억제되고 이득나는 축이 늘어난 것**"으로 전부
설명될 수 있다. 두 해석이 아직 갈리지 않는다:

- **해석 A (정보 가치)**: 하루치 정보로 값을 정확히 매겨 좋은 칸을 골랐다.
- **해석 B (기준 불일치)**: 시간 좌표에만 외부효과 세금이 붙어 억제됐다.

B 라면 이득은 견적망의 정보가 아니라 **값매김 기준의 우연한 비대칭**에서 온다.
YR-171-C 의 −135.5 는 두 해석을 분리하지 않았으므로 "하루치 정보의 가치"로
단정할 수 없다.

## 판별 실험 (정책 고정 · 값매김만 교체)

학습된 정책을 그대로 두고 **resolver 의 값매김만** 바꿔 평가한다 — 학습 차이와
값매김 차이를 분리하는 유일한 방법이다.

| 평가 | 정책 | 시간 좌표 값매김 |
|---|---|---|
| E1 (기준) | slots48_buy | 견적망 (현행) |
| E2 | slots48_buy | 계산식 |
| E3 | slots48 | 견적망 |
| E4 | slots48_buy | 견적망 **− 외부효과 몫** (자기 비용만으로 환원) |

E1−E2 가 크고 E1−E4 가 작으면 **해석 B**(기준 비대칭이 원인)다.
E4 가 E1 만큼 좋으면 **해석 A**(정보 자체의 가치)다.

## 교정 후보 (하나씩)

1. **전부 외부효과 포함으로 올린다** — 공간 좌표의 `add` 와 `relief` 도 뒤차 지연·
   본선 몫을 포함하도록 확장. 외부효과는 실재하므로 **연구적으로 옳은 방향**이고,
   YR-174 의 실현 손익 분해식(`realized_credit`)과도 같은 기준이 된다.
2. **전부 자기 비용만으로 내린다** — 견적망 라벨을 `own` 만으로 다시 학습.
   구현은 싸지만 판매가 남에게 끼치는 피해를 못 본다(떠넘기기 재발).

권장은 **1번**이다. 단 공간 이득(−2.29분/건)이 외부효과 포함 후에도 남는지는
그 자체로 재판정 대상이다 — 지금의 공간 이득도 자기 비용만으로 잰 값이다.
