# YR-332-r — 작업 방향 입력 한 칸의 효과 검증

- **상태**: done — 입력 한 칸 진단·6단계 실행 완료, 운영 채택 미통과
- 사용자 승인: 2026-11-05, 6단계 순서대로 실험. 단계 6.
- 선행 진단: [[YR-332-q]]. 상위 [[YR-332]].

현재 본선 여부만으로 합쳐지는 반입/반출·적하/양하를 STORE 여부 한 칸으로 구분한다.
이는 공개된 작업 유형이며 미래 실현 정보를 읽지 않는다. 다른 상태 정보는 동시에 추가하지 않는다.
기존 9칸의 초기 가중치는 동일 복사하고 새 입력 가중치 0으로 시작해 초기 행동 차이를 제거한다.
같은 학습 조건에서 입력 1칸 유무만 비교한다. 원화 비용·후보 생성·표본 추출은 고정한다.
새 모델 형식과 이전 9입력 체크포인트의 구분을 명시하고 저장·복원과 분기 교사 상속을 검증한다.

사전등록: `docs/research/v7-discharge/six-step-prereg.md`.
추가 정보가 효과 없으면 채택하지 않는다. 실험 완료를 운영 효과 통과로 바꾸지 않는다.

## 6단계 착수 — 2026-11-05

5단계 표본 변경은 앞 단계보다 비용 +8.19%로 악화했다. 이 변경의 채택과 마지막 정보 진단은 구분한다.
같은 초기 모델·5단계 자료 198쌍·목표·눈금·갱신 예산을 유지해 STORE 한 칸의 효과만 비교한다.
새 입력 가중치는 0이며 기존 9칸의 초기 가중치는 복사한다. 반입·양하는 놓기, 반출·적하는 꺼내기다.
초기 모델 3개·각 3회 갱신 후 같은 별도 입력 3개에서 9회 평가한다. 새 미래 분기는 만들지 않는다.
모든 평가 종료 후 저장 자료로 전체 36개 갱신을 다시 학습해 가중치가 정확히 같은지 대조한다.

## 결과 — 2026-11-05

실행 코드 `816c68a9`. 초기 모델 3개·각 3회 갱신·평가 9회 완료. 5단계 198쌍을 재사용했고 새 분기는 0회다.
입력 한 칸을 더하면 앞 단계 대비 평균 비용 **-0.40%**, 체류 **-0.76%**다.
그러나 15,000건에서는 비용 **+3.66%**, 체류 **+3.16%**로 악화했다(세 학습 반복 평균).
전체 평균으로도 24시간 미완료가 37대 늘고 26시간 본선 완료가 10.56건 줄었다.
같은 전체 후보 규칙 대비 비용 **+20.21%**, 체류 **+16.99%**이며 본선 완료는 9/9회 감소했다.
원래 12개 선별 규칙 대비 비용 **+32.69%**다. 운영 채택은 미통과다.
모든 방법의 36개 갱신을 저장 자료로 다시 학습해 가중치가 정확히 같음을 확인했다.
파일·입력·수집 경로·표본 시각·체크포인트 대조 958건도 통과했다. 환경 재수집 전체 반복을 뜻하지 않는다.
이것으로 승인된 6단계 진단은 완료했다. 후보 보존·의미 수정·속도 개선과 정책 성능 채택을 구분한다.
후속은 [[YR-332-m]]의 투입·잔여 장부 대조, [[YR-332-f]]·[[YR-332-i]]의 현실 보정이다.
