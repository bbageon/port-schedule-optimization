# YR-332-bj — 본선 작업 턴타임과 재학습 성능

- **상태**: in-progress
- 상위 [[YR-332]]. 2026-11-22 사용자 요청.
- **3대 게이트 보정 대상**: `scenario_validity`. 본선 비용의 시작·끝과 자정 이후 장부를 맞춘다.

## 비교 계약

당일 같은 기항의 하역 가능 시각부터 안벽의 마지막 적하·양하까지 선박 한 척에 한 번 비용을 센다.
기존 톤수별 시간단가를 유지한다. 트럭·빈 이동·재조작은 종전 24시간 장부를 유지해 본선 한 축을 비교한다.
자정 이후 새 외생 입력 없이 같은 정책으로 마무리하며 당일 선택의 학습 목표에 본선의 남은 비용을 포함한다.
시뮬레이션 시작 전 입력된 작업만 대상으로 한다. 실제 연속운영 성능과 구분한다.
미완료 기항을 삭제하거나 시간 한도를 완료시각으로 대입하지 않는다. 미완료 시 선박·작업 잔량과 원인을 남긴다.

기존 전역 모델 최종 가중치에서 추가 학습한다. 기존 입력 묶음의 학습일과 시험일은 분리한다.
같은 시험일·물량의 기존 모델, 추가학습 모델, 짧은 작업 우선 규칙 모두 새 비용으로 평가한다.
최종 모델을 최고점 선택으로 평가한다. 총비용, 평균 본선 턴타임, 트럭 진입→완료, 미완료를 함께 보고한다.
전체 비교는 세 가지 물량과 날짜에 같은 비중을 둔다. 실측 밖의 두 높은 물량은 부담 시험이다.

## 실행 고정값

- 시작 모델 9951101·9951102·9951103. 학습 12일, 2일당 1회씩 6회 갱신, 표본 2048, 4회 반복.
- 최종 시험은 기존 묶음의 별도 3날 × 3500·7500·15000건. 입력별 모델 초기값 평균을 먼저 낸다.
- 선박별 최초 하역 가능 시각은 입력에서 정하고 가장 늦은 안벽 완료 사건을 쓴다. 배정 대수로 나눈 나머지 물량도 분배한다.
- 24시간 후 새 입력 없이 같은 배정 정책을 지속하고 기항 완료까지의 결정도 학습한다. 최장 120시간 추가 관측은 안전상한이다.
- 시험에 쓰지 않는 학습 묶음 13번째 날짜로 동작을 먼저 확인한다. 불완료는 개별 원장으로 조사한다.
- 운영 성능 채택은 별도다. 보정되지 않은 물량에서의 단기 비교와 실측 검증을 구분한다.

## 시험 성적 확인 전 보완

별도 동작확인 날짜의 4척 중 대형선에 양하 484개가 남았다. 입고를 전부 제외하고 반출을 전부 허용해도
일부 블록의 합산 최소 123개는 놓을 수 없다. 처음 정한 전체 기항의 마지막 시각이 항상 존재한다는 가정이 깨졌다.
원래 입력과 장비 제약을 유지한다. 학습 12일을 전부 실행·보존하고 실제 완료한 하루 경험에만 원화 목표를 붙인다.
두 날 모두 관측 불가능한 갱신은 생략 사실을 기록하며 유효 갱신 0회 모델을 재학습 성공으로 세지 않는다.
시험 9입력의 모든 정책·모델을 끝까지 집계한다. 미완료는 건수·잔량·비용 하한만 표시하고, 총비용과 시간은
모든 비교 정책의 모든 기항이 완료한 동일 입력에 한해 따로 비교한다. 전체 입력 순위로 일반화하지 않는다.
