# YR-323-d — 긴 창의 자료 부족과 학습 부족 구분

**상태**: backlog

등록: 2026-11-10. 상위 진단 [YR-323-a](YR-323-a-horizon-cause-audit.md).
조건부 성능 진단이다. 현실성 보정과 검사 대상 정책·후속 판단·입력의 고정이 선행한다.

## 무엇과 왜

기존 비교는 K마다 모델 3개×6회 갱신, 총 295개 비교 쌍이었다.
K를 늘렸을 때 학습할 관계가 달라졌지만 같은 표본·갱신 예산이 충분했는지는 별도로 검증하지 않았다.
더 오래 학습하면 좋아진다고 가정하지 않고, 자료 부족과 맞추기 부족을 먼저 구분한다.

## 한 축 비교

1. 학습용·진단용 선택을 결정 단위로 분리하고, 보지 않은 입력에서 학습 진행에 따른 성과를 측정한다.
   같은 결정의 실제 선택과 대안은 항상 같은 분할에 넣는다.
2. 학습 자료에는 잘 맞고 새 자료에서 실패하면 새 결정 표본 수만 늘리는 비교를 설계한다.
   모델 구조·후속 정책·K·정규화 규칙·갱신 횟수는 고정한다. 기존 표본 복제는 신규 자료로 세지 않는다.
3. 학습 자료에도 충분히 맞지 않는다면 동일 자료에서 최적화 반복 횟수만 바꾸는 비교를 먼저 선택한다.
   표본 수 증가와 반복 횟수 증가는 동시에 바꾸지 않는다. 정보 누락 문제를 반복 학습으로 덮지 않는다.
4. 비교 예산·모델 초기값·종료 조건을 실행 전에 정한다. 결과를 보며 임의로 학습을 연장하지 않는다.

## 완료 기준

- 단순 학습 손실과 실제 운영 비용·업무별 평균 시간 개선을 구분한다.
- 동일 예산에서 K끼리 비교한 결과와 추가 계산량으로 얻은 개선을 분리 보고한다.
- 자료·계산을 늘려도 재현되는 이득이 없으면 더 큰 모델·추가 계층으로 자동 확장하지 않는다.
- 확인된 한 가지 변경만 후속 평가에 반영하고 불리한 초기값과 실패 결과도 남긴다.
