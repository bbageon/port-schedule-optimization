# YR-321 — 공간을 빼고 시간 판매·구매만으로 처음부터 학습

- **상태**: backlog
- 출처: **사용자 제안 2026-09-22** — "공간은 제외하고 시간 판매 구매만 하면 어때?"
- 종류: 정책 학습. 판정은 별도 확증이 붙어야 가능.

## 무엇을 하나

공간 재배정 후보를 아예 만들지 않고(`Seller.no_space = True`) 30일을 처음부터
학습한다. 상대는 **크레인 정책과 운영 방식을 맞춘** 두 축 팔이다.

## 뒷받침

- v3 세대에서 순수 시간 규칙 팔이 공간+시간 규칙 팔보다 조금 나았다([[YR-249]]).
- [[YR-306]] 에서 최고점 선택으로 굳히자 공간 이동만 세 배로 튀었다.

## 반대 근거 (착수 전 반드시 읽을 것)

- **같은 실행 안에 반례가 있다.** [[YR-306]] 최고점 팔의 1일차는 판매 3,085건 중
  공간이 **13건**으로 사실상 시간 전용이었는데, 턴타임 35분으로 규칙 19분의 1.8배였다.
- 반대로 [[YR-319]] 추첨 팔은 1일차에 공간을 151건 쓰고 턴타임 27분이었다.
  **공간을 더 쓴 쪽이 더 빨랐다.**
- 과거 축 분해 증거는 전부 v3 세대(판매망·구매망 분리 + 반사실 교사)다.
  v5 는 망 하나가 판매·수락·크레인을 다 맡으므로 그대로 승계할 수 없다.
- v5 에서 시간 전용 팔은 **한 번도 실행된 적이 없다**.

## 선행 조건

[[YR-324]] → [[YR-320]] 순서 뒤다. 재학습은 **축과 가중치를 동시에 바꾸므로**
좋아져도 귀속이 안 된다. 축 효과를 절제로 먼저 재야 "한 번에 한 축" 을 지킨다.

## 판정

성과지표는 **턴타임**. 새 시드 대역 3개월 이상. 중단규칙은 [[YR-319]] 와 같다.
주판정은 크레인 정책과 운영 방식을 맞춘 짝이고, 규칙 대비는 참고로만 쓴다 —
규칙 팔은 판매를 0건 하므로 행동 폭이 다르다.

## 미해결

시간축 슬롯 용량이 v5 에서 한 번도 채워지지 않는다. 공간을 빼면 "상호 동의" 를
떠받치는 물리적 거절 근거가 미구현 축 하나만 남는다. 살릴지 한계로 적을지 결정 필요.
