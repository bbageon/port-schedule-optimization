## 무엇

## 사전등록 (실행 전 커밋)

- 주지표: 날짜별 턴타임(게이트 아웃 − 게이트 인), 측정창 2~29일.
- 중단: 어느 날이든 같은 날 규칙의 3배 초과면 즉시 중단.
- 하드 가드: 전건 투입 · 본선 완료 수 · 못 나간 트럭 · 물리 불변식.
- 학습 효과는 학습 후 대 학습 전으로만 말한다. 규칙 대비는 성능 판정.
- 한 달 이어 돌린 자료라 28일을 독립 표본으로 쓰는 검정은 하지 않는다. 시드 대역을 늘려 구간을 낸다.
