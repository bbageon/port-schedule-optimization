# YR-332-v — 고전 배차 규칙 7종 대비 학습 정책 재평가

- **상태**: done
- 등록: 2026-11-06. 사용자 승인: 제안한 비교군으로 학습 성능 재평가.
- 상위: [[YR-332]]. 비교 정의 감사 [[YR-332-t]]의 한 축을 구체화한다.
- 범위: 규칙 구현·오류 교정·저장 모델 평가. 재학습·보상·물리·입력 변경 없음.

## 무엇과 왜

실제 터미널의 작업 순서는 미확인이다. 도착순 하나를 현장 대표로 간주하지 않고
도착·처리시간·거리·본선 보호·대기 균형을 대표하는 규칙으로 학습 효과를 비교한다.
기존 NEAREST는 현재 위치가 포함된 점유구간 끝점을 골라 거리가 0이 되는 오류가 있다.
이를 실제 첫 취급 위치까지의 거리로 고치고, 이전 결과는 덮어쓰지 않는다.

## 고정 비교군

핵심: FCFS_ARRIVAL, SPT, NEAREST, VESSEL_FCFS, VESSEL_NEAREST.
보조: UNIDIRECTIONAL, DISTANCE_WAIT. 기존 SF_SPT도 별도 이력 기준으로 보존한다.
SPT의 동률은 작업 ID로, SF_SPT의 동률은 기존 본선·대기 규칙으로 해소한다.
동률 정의가 다르므로 둘을 실행 없이 동일하다고 하지 않는다.

- 관측된 대기열 진입 시각만 사용한다. 미실현 실제 도착을 읽지 않는다.
- 후보·공동 안전 제약·필수 작업·실작업 우선은 공통이다.
- 본선 우선은 양하/적하를 모두 포함한다. 종류 안에서 도착 또는 거리로 정한다.
- 단방향은 크레인별 실제 완료 위치의 변화로 방향을 기억한다. 후보 순회로 바꾸지 않는다.
- 거리·대기는 접근 이동 초에서 관측 대기 초를 뺀다. 새 원화 가중치를 만들지 않는다.
- 문헌의 외부 트럭/야드 차량 규칙을 네 흐름에 적용한 연구용 변형이며 현장 재현이 아니다.

## 평가와 완료 기준

- [사전등록](../../../docs/research/v7-discharge/classical-rules-prereg.md)을 코드와 함께 먼저 커밋한다.
- 같은 3일·3물량(3,500/7,500/15,000), 학습 전+4학습 방식×초기화 3개를 모두 새로 평가한다.
- 7규칙×3일 + 15모델×3일 + 기존 SF_SPT×3일 + 반복 2회 = 71회. 최대 6개 독립 프로세스.
- 기존 모델 45회·SF_SPT 3회·FCFS 3회의 궤적/결과가 저장 증거와 정확히 같아야 한다.
- 트럭 체류·상위 대기·미완료·미투입·본선 완료·관측 종료까지 본선 지연을 함께 보고한다.
- 시드별 및 학습 전후 차이를 보존한다. 결과를 보고 모델·규칙·입력을 고르지 않는다.
- 날짜 3개는 기존에 본 입력이다. 9쌍을 독립 9일로 해석하거나 통계적 확증을 주장하지 않는다.
- 관련 검증, 원자료 해시, 재현 정보, Dashboard 정합 판정 후 commit·push한다.
