# YR-317-f — 실제 사용자와 상호작용 맥락

- **상태**: done
- 무엇: 터미널 운영자·운송사 배차 담당자·운전자 역할과 검토·수정·거절 흐름을 원고에 명시한다.
- 왜: 소프트웨어 정책끼리의 동의는 인간의 의사결정 지원이나 HCI 검증을 대신하지 않는다.
- [사용자 설계 전체](../strategy-history/2026-09-14-v3-review-hci-reproducibility.md).
- 현재 구현, 제안한 사용 시나리오, 사용자 평가 결과를 구별한다. 외부 운영 시스템 연동은 범위 밖이다.
- 제안 화면은 기존·변경 배정, 알려진 혼잡·정원·통지 시간, 수정·거절 권한을 제시한다.
- 개별 후보의 미보정 점수를 정확한 원화 절감액·신뢰확률로 표시하지 않는다.
- 최소 개정은 사용자·권한·맥락 설명이다. HCI 효과 주장이 필요하면 실제 역할의 과업 평가를 설계한다.
- 역할별 2~3명 형성적 평가는 제안 규모일 뿐이며 정량 효과 확증을 보장하지 않는다.
- 완료 기준: 사용자 흐름·권한 표·사례와 평가 여부/한계 명시, 필요한 경우 사용자 평가 근거.
- 이번에는 사람에게 연락하거나 모집하지 않는다. 정책에 새 사람 승인 레이어를 구현하는 작업도 아니다.
- [현행 범위 §6](../strategy-history/2026-09-14-v3-review-refined-strategy.md): 이번 필수 대응은 사용자·권한·사용 맥락 서술이다.
- 사용자 과업 평가는 선택적 후속연구다. HCI 효과를 주장할 때만 필요 수준을 다시 정한다.
- 그림에서 현재 내부 정책 흐름과 향후 사람·제약층 연동을 구분한다. 사람의 동의·새 정원이 현재 구현됐다고 쓰지 않는다.
- 9/14 [영문 사용자·업무 맥락 문안](../../../outputs/reports/yr317_v3_reliability/manuscript-corrections.md) 작성. 원고 반영·사용자 평가는 미완료다.
- 9/15 [부산항·TOS·올컨e 전략](../../../docs/paper/v3/paper-revision/05-TOS-올컨e-사용맥락.md) 작성. 부산 신항 대기시간, 국내 TOS·인공지능 적용 연구와 올컨e 공식 자료를 직접 확인했다.
- 운영자·운송사 배차 담당자·운전자의 역할과 기존 배정→정책 권고→검토·협의→확정 안내 흐름을 제안했다.
- 올컨e 자료는 학술논문과 구별하고 TOS 연구를 모두 부산항 현장 실험으로 부르지 않는다. 실제 외부 연동·사람 모집·사용자 효과 검증은 없다.

## 9/15 진단 실험과 병행한 원고 반영

- 사용자 병행 작업 요청에 따라 [개정 원고](../../../docs/paper/v3/paper-revision/main-revised.tex)에 §3.5를 추가했다.
- 운영자·배차 담당자·운전자 역할을 설명하고 도착 지연 제안→운영자 검토→운송사 협의→운전자 확정 안내 사례를 반영했다.
- 내부 수락망과 사람의 승인을 구분하며, 알고리즘의 60초 주기와 사람의 응답 기한을 동일시하지 않는다.
- 부산 신항 대기시간·국내 TOS·BPA의 2022년 올컨e 소개를 인용했다. 실제 연동·권한 명세·사용자 효과를 확인한 것으로 쓰지 않았다.
- [답변 초안](../../../docs/paper/v3/paper-revision/11-리뷰1-2-리뷰3-답변초안.md)과 [반영·검증 기록](../../../docs/paper/v3/paper-revision/10-문헌-사용맥락-원고반영.md).
- 문안 반영은 완료했고, 다른 리뷰 수정과의 전체 통합·분량 조정은 남아 in-progress를 유지한다. 사용자 평가는 이번 작업의 필수 범위가 아니다.
- 최종 개정본의 참고문헌은 22건이며 최초 인용 순서·묶음 안 순서와 사용자 맥락 절 존재를 확인했다. [기계 검사](../../../docs/paper/v3/paper-revision/narrative-validation.json). 문서 검증이 사용자 효과의 검증을 의미하지 않는다.

## 9/18 서술 범위 완료

- [통합 결과·검증](../../../docs/paper/v3/paper-revision/24-전체리뷰-원고통합.md). 사용자 맥락 설명·분량 조정의 완료이며 외부 연동이나 HCI 효과 검증의 완료가 아니다.
