# YR-295 — 검증 스크립트가 수식 **기호**를 못 본다

**상태**: backlog
**Epic**: Paper

## 무엇이 문제인가

[[YR-294]] 에서 `C_move = 60{,}000\,m` 이 `60{,}000\,million` 으로 망가진 채
**여러 커밋을 통과했다**. `verify_submission.py` 는 원고의 **값**(60,000)을
원자료와 대조하는데, 그 값은 멀쩡했다. 바뀐 것은 **기호**($m$ → million)였고
아무 검사도 그것을 보지 않았다.

문자열 치환(정규식)으로 원고를 고칠 때마다 같은 사고가 날 수 있다.

## 어떻게 할까

- 수식 블록(`equation`·`aligned`) 안의 **기호 집합**을 스냅숏으로 떠 두고,
  바뀌면 알리는 검사를 `verify_submission.py` 에 추가한다.
- 또는 더 간단히, 본문에서 정의한 기호($h_i$·$m$·$R$·$T_v$·$GT_v$)가 수식에
  **그대로 등장하는지** 대조한다 — 이번 건은 그것만으로 잡혔다.
- 정규식 치환은 앞뒤 문맥을 확인하고, 수식 환경 안은 건드리지 않도록 한다.
