# YR-199 — 불확실성 분해: 예측 오차 중 못 줄이는 몫

- **Epic**: Exp / **Priority**: 🔴 / **등록일**: 2026-08-19 / **상태**: done
- **3대 게이트 보정 대상**: `performance` (해석 근거)
- **1줄**: 모델 오차의 **95%가 지금 특징으로는 원리적으로 못 줄이는 잡음**이다.
  더 학습해도 소용없고, **문턱이 정답 방향**임이 실측으로 확정됐다.

## 왜 쟀나

[[YR-189]] 에서 Q 망 오차가 신호의 82%(RMSE 0.019 / 목표RMS 0.023)였다.
이 중 **더 배우면 줄어드는 것**과 **원래 못 줄이는 것**의 비중을 몰랐다.
앞이 크면 정보 추가·재학습이 답이고, 뒤가 크면 **문턱밖에 없다.**

## 재는 법 — 1-최근접이웃 잔차 (Devroye–Györfi 계열)

행이 거의 같은 두 표본은 **어떤 모델도 같은 값을 예측할 수밖에 없다.**
라벨이 다르면 그 차이는 구조적으로 설명 불가다.

```
sigma_noise  ≈  sqrt( (1/2n) Σ (y_i − y_NN(i))^2 )
```

조건: 학습과 같은 분포(탐색 ε=0.15·σ=0.20) · 22시간 계약 · 6시드 ·
**비판정 대역 9,900,070~** · 차원별 표준화 후 최근접 탐색.

## 결과 (표본 22,158 — 공간 8,734 · 시간 13,424)

| 구분 | n | 신호 RMS | 모델 RMSE | **잡음 하한** | 남은 여지 | 잡음/신호 |
|---|---|---|---|---|---|---|
| **전체** | 22,158 | 0.02277 | 0.01859 | **0.01766** | **0.00579** | **77.6%** |
| 공간 | 8,734 | 0.01953 | 0.01587 | 0.01435 | 0.00678 | 73.4% |
| 시간 | 13,424 | 0.02465 | 0.02016 | 0.01911 | 0.00641 | 77.6% |

## 해석 — 셋이 확정된다

### ① 더 학습해도 소용없다

모델 오차 0.01859 중 **0.01766 이 하한**이다. 회차를 늘리거나 망을 키워
얻을 수 있는 최대치는 **0.0058**(신호의 25%)뿐이다.

→ [[YR-183]](회차 확대) 취소가 결과적으로 옳았다. 학습량은 병목이 아니다.

### ② 문턱이 정답 방향이다

오차가 이만큼 못 줄어드는데 `Q < 0` 이라는 **딱딱한 문턱**을 쓰면 승자의 저주가
**구조적으로 발생**한다. 예측이 정확해질 여지가 없으므로, **결정 규칙을 고치는
것 말고는 방법이 없다.** → [[YR-195]] 가 정확히 그 축이다.

### ③ 그러나 하한은 **특징 표현에 상대적**이다

"행이 같은데 결과가 다르다"는 **우리가 준 21개 특징으로는** 구분이 안 된다는
뜻이지, 세상이 근본적으로 무작위라는 뜻이 아니다.

가장 유력한 누락 정보: **크레인의 예상 서비스 시각**. 지금 판매 층은
"블록이 붐빈다"(`crane_backlog` 합계)만 알고 **"이 트럭이 얼마나 기다릴지"**
는 모른다. 그게 결과를 가르는 핵심 변수인데 특징에 없으므로, **같아 보이는 두
행이 실제로는 다른 상황**일 수 있다. → [[YR-198]] 후보

## ★부수 — 문턱 크기를 유도할 수 있다

| | 값 |
|---|---|
| 잡음 하한 (스케일) | 0.01766 |
| 잡음 하한 (원단위 = ×20) | **0.353** |
| 실측 선택 편향 ([[YR-189]] 관측 8) | **0.169** |
| 비율 | **0.48** |

좌표 21개 독립이면 이론상 최소값 편향은 잡음의 **약 1.9배**여야 한다. 실측이
**0.48배**로 훨씬 작은 것은 **좌표 간 오차가 독립이 아니기 때문**이다 — 같은
블록·같은 작업 특징을 공유하므로 오차가 함께 움직인다.

→ 문턱을 상수로 찍지 않고 **`m ≈ 0.48 × 잡음하한`** 으로 유도할 수 있다.
[[YR-195]] 결과가 좋으면 다음 단계에서 자동화한다(B안).

## 연구적 함의

이 측정은 negative result 의 성격을 바꾼다.

> "학습이 부족했다"가 아니라 **"이 문제는 예측 가능한 부분보다 예측 불가능한
> 부분이 3배 크다"** 가 실측됐다.

강화학습이 어떤 문제에 맞고 어떤 문제에 안 맞는지를 가르는 근거다. 문헌이
낙관 일변도인 상황에서 **잡음 하한을 직접 재서 보고한 사례**는 드물다.

## 하지 않는 것

- 이 하한을 "세상이 무작위다"로 읽는 것 — **특징 표현에 상대적**이다.
- 남은 여지 0.0058 을 "학습이 25% 더 좋아진다"로 읽는 것 — 그건 예측 오차이지
  성능이 아니다. 성능은 결정 규칙을 거쳐 나온다.
