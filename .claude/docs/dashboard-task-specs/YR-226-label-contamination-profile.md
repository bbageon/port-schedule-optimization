# YR-226 · 라벨 오염 비율 — 시각대별 부호 프로파일

> Epic RL · 우선순위 🔴 · 상태 ✅ **완료** 2026-08-25 (등록·착수·완료 같은 날)
> 선행 [[YR-225]] (시각 2점으로는 못 정한다) · 관련 [[YR-222]]

## 1. 물음 — 한 줄

**하루 중 어느 시각대의 라벨이 반대 부호이고, 그게 전체의 몇 %인가.**

## 2. 왜 별도 row 인가

[[YR-225]] 는 *"지평이 부호를 뒤집는가"* 를 물었고 **아침에는 그렇다 · 오후에는
아니다** 로 답했다. 그런데 시각을 **2점**(7.7시·14.3시)만 골랐다.

그 표본으로 나온 "부호 불일치 50%" 는 **내가 고른 두 점의 비율**이지 라벨의
실제 오염률이 아니다. 거래량이 시각대마다 3배 이상 다르므로
(7.7시 105건 vs 14.3시 336건) **거래량 가중 프로파일**이 필요하다.

이 숫자가 정해져야 답할 수 있는 것:

| 오염률 | 뜻 |
|---|---|
| 낮다 (~10%) | 라벨은 대체로 맞다 — [[YR-218]]~[[YR-222]] 실패의 주범이 아니다 |
| 중간 (~25%) | 아침 라벨만 손보면 된다 (시각대별 H) |
| 높다 (>40%) | **라벨 계약 자체를 다시 짜야 한다** |

## 3. 측정 (착수 전 동결)

```
시각 t0   1.0 · 4.0 · 7.7 · 11.0 · 14.3 · 17.5 시   (6점)
지평      3시간 (지금 라벨) · 12시간 · 하루끝        (3점 — 6시간은 뺀다)
부하      3,500 · 5,000
날        9,900,900 ~ 903 (4일)                     비판정 대역
정책      YR-220 ckpt_023 고정
= 48 스윕 · 144 행
```

**6시간을 뺀 이유**: [[YR-225]] 가 뒤집힘 구간을 3~12시간으로 이미 좁혔다.
여기서 필요한 건 뒤집힘 지점이 아니라 **3시간 라벨이 맞나 틀리나**다.

### 판정 지표 (동결)

| | 정의 |
|---|---|
| **부호 불일치율** | `sign(Y@3h) ≠ sign(Y@하루끝)` 인 스윕의 비율 |
| **★거래량 가중 오염률** | 위를 그 창의 H=3h 거래 수로 가중한 것 ← **이게 답이다** |
| 크기 왜곡 | `Y@3h ÷ Y@하루끝` 의 중앙값 (부호가 같을 때) |

⚠️ **결과를 보고 지표나 시각 격자를 바꾸지 않는다.**

## 4. 비용

[[YR-225]] 32 스윕(지평 4점)이 8코어 **2시간 45분**이었다. 여기는 48 스윕 ×
지평 3점이라 비슷하거나 조금 길다 — **약 3~4시간** 예상.
[[YR-222]] 가 16코어를 쓰는 중이므로 **8코어**로 돈다.

## 5. 하지 않는 것

- 라벨 계약 변경 — **측정만** 한다. 바꾸는 것은 [[YR-222]] 완주 뒤 별도 row 로.
- 정책 재학습 — 정책은 `ckpt_023` 으로 고정한다(움직이는 과녁을 쏘지 않는다).

## 6. ★결과 (2026-08-25 · 48 스윕 · 144행 · 8코어 3시간 11분)

### 시각대 프로파일

| t0 | 불일치 | H=3h 거래(중앙) | 3h `Y`(중앙) | 하루끝 `Y`(중앙) |
|---|---|---|---|---|
| 1.0시 | 3/8 | 17 | +2,122 | +4,392,092 |
| 4.0시 | 6/8 | 16 | −17,054 | +5,326,678 |
| **7.7시** | **8/8** | 105 | −202,934 | +6,722,930 |

### 사전등록 지표

| | 값 |
|---|---|
| 부호 불일치율 | 18/48 = **37.5%** |
| **★거래량 가중 오염률** | 935 / 5,644건 = **16.6%** |
| 크기 왜곡 (부호 맞는 것) | `Y@3h ÷ Y@하루끝` 중앙 **0.66배** (사분 0.20~0.93) |

### 판정 — **낮음과 중간 사이 · 오전에 국소화**

사전등록 구간표는 ~10% 낮음 / ~25% 중간 / >40% 높음 이었다. **16.6% 는 그 사이**다.
억지로 한 칸에 넣지 않고 실제 모양으로 읽는다:

```
라벨의 83.4% → 방향이 맞다 (다만 크기를 2/3 로 과소평가한다)
라벨의 16.6% → 방향이 반대 · 전부 오전
                그중 79% 가 7.7시 한 시각대에서 나온다 (739/935)
```

**오후(11·14.3시)는 0/16 이다** — 거래의 **73%** 가 여기서 나오고 부호가 완벽히 맞는다.

### 왜 오전만 틀리나 — 물리

오전에 이연한 트럭은 **정오 피크로 밀려간다.** 7.7시의 3시간 창은 10.7시까지라
피크가 창 밖이다. 오후에 이연한 트럭은 **저녁 한산한 시간대**로 가므로 실제로 이득이고,
그건 3시간 안에서도 보인다.

### ★크기 왜곡 0.66배 도 따로 봐야 한다

부호가 맞는 라벨도 **실제 이득의 2/3 만** 말한다. 방향은 맞지만 **재배치의 값을
체계적으로 깎아서** 가르치는 셈이다. 오후 시각대만 보면 0.92 로 좋다(11·14.3시).
왜곡은 거래가 적은 시각대에서 크다.
