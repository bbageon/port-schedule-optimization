# YR-323-e — 보정 후 K 선택과 독립 성능 검증

**상태**: backlog

등록: 2026-11-10. 상위 진단 [YR-323-a](YR-323-a-horizon-cause-audit.md).
선행: 환경 보정, 원인 진단, 근거가 확인된 단일 변경의 개별 검증과 기록 정합.
조건부 b/c/d를 전부 수행해야 한다는 뜻은 아니다.

## 무엇과 왜

기존 K 비교의 입력 9개는 이미 본 자료이고 K1의 이득은 혼잡 조건에 집중됐다.
개선한 환경·정책에서도 K의 순위와 업무별 손익이 유지되는지, 보지 않은 입력에서도 이득이 있는지 확인한다.
K1을 미리 최적값으로 고정하거나 부하별 K 선택기를 새로 추가하지 않는다.

## 선택용 비교

1. 환경·정책·후속 판단·학습 자료량·갱신 예산을 고정하고 K=1·2·3·6만 비교한다.
   이 단계는 아직 K 선택이 필요한 경우에만 수행하며 성능·기록·현실성 전부 통과한 후보가 있으면 확증으로 간다.
2. 학습·선택용 평가·최종 검증 입력을 미리 분리한다. 기존 9개 입력은 재현용으로만 보존한다.
3. 모델 초기값을 여러 개 사용하고 한산·혼잡 등 부하별 결과를 함께 본다.
   부하의 실제 처리 가능성과 잔여 작업 증가를 기록하며, 불리한 조건을 결과 확인 후 제외하지 않는다.
4. 원본 배정은 유지하고 같은 오더·정보·물리 조건의 학습 전 정책과 기존 고전 규칙을 비교한다.
   강한 기준은 실행 가능한 짧은 작업 우선이며, 도착순 등 기존 규칙 비교 계약도 유지한다.

## 보고와 최종 검증

- 전체 트럭·반입·반출·양하·적하의 평균 시간과 감소율을 보고한다. 시간 시작점과 미완료 처리도 고정한다.
- 평균 시간의 비율, 입력별 감소율 평균, 주문 수로 가중한 값은 서로 다른 지표로 표시한다.
- 관측창을 넘는 지연과 종료 때문에 짧아진 실제 K를 보고한다. 완주 주문만의 평균으로 바꾸지 않는다.
- 비용·본선 보호·미완료·물리 제약을 함께 판정한다. 단순 트럭 평균 최소로 채택하지 않는다.
- 표본 수·주 판정·최소 개선 기준·K 선택 규칙을 결과 열람 전에 고정한다.
- 선택한 K와 가중치는 동결한 뒤 미사용 입력에서 한 번 검증한다. 실패 후 같은 검증 자료로 재선택하지 않는다.
- 모두 통과한 뒤 기존 [YR-332-d](YR-332-d-v7-month-judgment.md)의 연속 30일 검증으로 연결한다.
  30일 안의 날짜들을 서로 독립인 30개 실험으로 취급하지 않는다.
- 실측 보정 범위를 넘는 실제 터미널 최적화·전역 최적성은 주장하지 않는다.

기존 10/28~11/09 자료는 이미 예약 보정과 분포 진단에 사용했다. 뒤 4일도 새 잠금평가 자료로 재명명하지 않는다.
새 미열람 기간은 날짜 단위로 분리하며 같은 차량 방문·연결 주문·항차가 양쪽에 새지 않는지 검사한다.
실제 외생 주문을 활용할 수 있는 범위와 합성으로 채운 배치·시간·자원을 함께 기록한다.
날짜별·유형별·부하별 결과와 미완료를 보고하고, 관측하지 않은 최종 완료시간을 짧게 확정하지 않는다.

이번 추가는 새 평가 또는 현실성 통과를 선언하는 것이 아니다.
