# YR-332-cb — 한 달 무대에서 규칙보다 나아질 여지(상한) 측정

- **상태**: backlog (사용자 확인 뒤 사전등록하고 착수)
- 상위 [[YR-332]], 2026-11-26 등록. 관련 [[YR-332-ca]](학습 데이터 점검) · [[YR-332-bi]](짧은 작업 우선 우위) · [[YR-332-br]](학습 목표만 바꾼 재학습) · [[YR-332-bt]].
- **3대 게이트 보정 대상**: `performance`. 강화학습이 규칙을 못 이긴 원인 가운데 '이길 여지 자체가 작은가'를 분리한다.
- 정책 학습은 하지 않는다. 진행 중인 bt·br 실행과 그 등록 파일은 건드리지 않는다.

## 발단

- 2026-11-26 사용자: "강화학습이 규칙을 이기지 못했다는 건, 보상 정책이 잘못되었다라고 보는 게 타당한가?"

## 왜

- 못 이긴 원인은 셋으로 나뉜다. ① 학습 점수(보상)가 평가 목표를 못 담는다. ② 학습량·신호가 부족하다. ③ 규칙이 이 환경에서 이미 거의 최선이다.
- ①은 [[YR-332-br]]이 학습 목표만 바꿔 시험한다. ②는 하루 무대 [[YR-323-d]]에서 반복 50→200회로 트럭 −23.78%였지만 규칙보다 3.10% 길었다.
- ③은 v7에서 잰 적이 없다. 예전 단일 블록 환경에서는 완벽정보 이득이 0으로 두 번 확인됐다
  ([단일 야드 트랙 종료](../strategy-history/2026-07-15-single-yard-track-closure.md), [YR-072 천장 재진단](../strategy-history/2026-07-19-YR-072-천장재진단-v2.md)).

## 근거 수치 (기존 결과, 2026-11-25 시험 월)

- 24분 승격 짧은 작업 우선: 트럭 94.19분·본선 37.49시간. bp 모델(같은 승격 공유): 102.00분·39.57시간. 승격 없는 고전 규칙: 101.88분·31.31시간.
- bp는 갱신 4회로 기존 모델보다 가중 합계 13.00% 나아졌고, 규칙 대비 격차가 +23.12%에서 +7.12%로 줄었다.
- bp의 학습 점수는 결정 뒤 30분의 블록 시간이라 본선 효과를 거의 담지 못한다([[YR-332-bq]]). 본선 시간이 셋 중 가장 나빴다.

## 할 일 (사전등록 후)

1. 규칙 기반 미리보기(rollout) 정책: 결정마다 후보별로 시뮬레이터를 정해 둔 시간만큼 굴려 비용이 가장 낮은 후보를 고르고, 이후는 규칙으로 잇는다.
   규칙 대비 개선폭이 개선 여지의 하한이다.
2. 공개 정보만 쓰는 판과 미래 도착을 아는 판을 나눠, 정보 부족과 정책 부족을 구분한다.
3. 계산량이 크므로 미리 정한 날(관측 범위 안 물량 날과 혼잡일)·블록 표본에서 시작한다. 결과는 물량별로 따로 보고한다([[YR-332-ca]]).

## 완료 조건

- 미리보기 정책과 규칙의 물량별 차이(트럭·본선)와 반복 간 흔들림을 낸다.
- 여지가 작으면 '규칙을 못 이김'을 학습 실패로 보지 않고, 여지가 생기는 조건을 연구 주장 범위로 정한다.
- 여지가 크면 학습 쪽(보상·학습량) 개선을 이어 간다. 결과를 보고 기준을 바꾸지 않는다.
