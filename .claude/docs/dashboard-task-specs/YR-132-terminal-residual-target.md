## 계약 ([하네스](../../../src/yard_rl/experiments/yr132_terminal_residual.py) docstring 이 동결 정본)

- 표적: `D_H(a) = D(a) + λ·(resid(a) − resid(기준))`, **λ = 1.0 동결**(가격 앵커:
  "창이 못 본 미완 1건 = 트럭 대기 1시간" — 기준재 정의 앵커, 튜닝 아님).
- **개수 잔여는 진단용 지위** (6차 피드백 ③): 성공 시 [YR-123](YR-123-common-cost-curve-api.md)
  비용곡선 기반 **비용가중 잔여**(남은 작업시간·트럭 대기·본선 마감)로 승계.
- 학습 = YR-131-b 프로토콜 그대로(순위손실·fresh init·선택 = 기존 novel 대역 ρ_H) —
  유일 차이 = 표적. 학습·선택 데이터는 신규 rollout 0.
- **판정 대역 = 새 대역 BASE+900/+901 (미열람)**: DIFF1 궤적 라벨 생성(resid 포함).
  - J1 (3/3): 결정 내 ρ(D̂, D_H) ≥ 0.30 ∧ top-1 ≥ 0.35.
  - J2 (3/3): 같은 결정 짝의 **선택 후 손실** mean regret_H(YR-132) < (YR-131-b).
  - 성공 = J1 ∧ J2. 부속: 혼잡 상위 40% ρ_H(131-b 병기)·D_H 신호 회복·plain D 지표.
- 성공 → 혼합손실(순위+보정) → 에피소드 검증. 실패 → 상태 별칭·비동기 정보 검사.
