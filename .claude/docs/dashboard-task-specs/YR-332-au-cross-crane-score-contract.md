# YR-332-au — 후보 점수 차이 학습과 공동 배정의 연결 확인

상태: backlog. 등록2026-11-16, as/323-d의 사후 구조 점검에서 파생했다.
3대 게이트 보정 대상: reliability(학습 목표와 실제 행동 결정의 연결을 확인).

## 무엇과 왜
현재 손실은 같은 크레인의 두 후보 점수 차이를 맞춘다. 실제 공동 배정기는 여러 크레인의 절대 점수를 비교한다.
실제 배정기와 모든 서로 다른 작업 조합이 가능한 장난감 조건에서, 크레인 하나의 모든 점수에100을 더하면
크레인 내 차이·학습 손실은 같지만 공동 배정은 바뀌었다.100은 반례의 임의 오프셋이며 비용 계수가 아니다.
[재현 반례](../../../outputs/reports/yr332_context_learning/score-offset-audit.json).
이는 구조상 가능성이다. 실제 학습 망이 이런 차이를 만들었다거나 이번 성능 악화 원인이라는 증거는 아니다.

## 범위
1. 저장 망·같은 후보 집합에서 크레인별 점수 기준과 공동 배정의 선택 순서를 읽기 전용으로 계산한다.
2. 점수 차이가 같은데 공동 배정이 달라지는 사례가 현행 후보·제약에서도 존재하는지 확인한다.
3. 순위 정답률·비용 차이 회귀오차·실행된 공동 행동을 구분해 연결되는 범위를 보고한다.
4. 점수를 임의로 중심화하거나 교사·배정기·손실을 자동 수정하지 않는다. 개선안은 확인된 원인에 한 축씩 대응한다.

## 완료 조건과 의존관계
저장 자료에서의 발생 여부·빈도와 반례의 적용 조건을 재현 가능한 원자료로 남긴다.
운영 시간의 인과 효과를 주장하려면 별도 고정 비교가 필요하다. 읽기 전용 결과로 개선율을 만들지 않는다.
본 작업은 구조 검산이며 i/f의 외부 현실성 근거를 대체하지 않는다.
새 학습·운영 비교는 해당 게이트·명세를 먼저 고정한다. 이번 네 단계의 고정 비교를 사후 변경하지 않는다.
