# YR-210 — 부하 세 수준에서 재배치의 가치 · 부호 전환점

- **Epic**: Exp / **Priority**: 🔴 / **등록일**: 2026-08-20
- **3대 게이트 보정 대상**: `performance` · `시드 현실타당성`
- **사용자 결정 2026-08-20**: *"3500 건도 실제로 발생할 수 있고 7500도 발생할 수 있다.
  실험할 때 3500·5000·7500 다 해서 통과해야 한다."*
- **아키텍처**: [02 무대](../architecture/02-무대.md) §2-1
- **1줄**: 하루 물량을 **3,500·5,000·7,500** 세 수준으로 두고, 각 수준에서
  재배치가 이득인지 손해인지를 재서 **부호가 뒤집히는 지점**을 찾는다.

## 왜 지금 이게 최우선인가

7,500 첫 실측에서 **논문 본 주장의 부호가 뒤집혔다.**

| 무대 | 안 팔기 Φ | 규칙 Φ | 규칙 − 안 팔기 |
|---|---|---|---|
| 3,600 (16일 사전등록) | — | — | **−158.13** (t=−11.90) — 재배치 이득 |
| **7,500** (1시드·비판정) | 25,034.69 | 25,536.54 | **+501.86** — **재배치 손해** |

7,500 런: `admitted = 7500` 전건 · 공간 907 · 시간 2,194 · 대당 Φ 0.63 → **3.34**.

논문 **서사 B 의 본 주장**이 *"블록 간 재배치 시장은 트럭 1대당 2.6분의 가치가
있다"* 인데, **실측 부하에서 그게 성립하지 않을 수 있다.** 확인 없이 다음 축으로
가면 안 된다.

## 세 부하의 성격

| 물량 | 평균 | 피크 | 피크 가동률 | 성격 |
|---|---|---|---|---|
| 3,500 | 146/h | 475/h | 57% | 한산 — 구 3,600 무대와 사실상 같다 |
| 5,000 | 208/h | 679/h | 81% | 빡빡하지만 능력 안 |
| **7,500** | 313/h | 1,018/h | **121%** | 피크 초과 — 쌓였다 밤에 빠진다 |

크레인 능력 = 21블록 × 2대 × (3600÷180초) = 840대/h.

**셋 다 실측 범위이므로 물량은 조정 대상이 아니다.** 결과가 나빠도 낮추지 않는다.

## 두 가설 — 이걸 가르는 게 이 작업의 핵심

| | 뜻 | 진단 신호 | RL 함의 |
|---|---|---|---|
| **(a) 과포화 무가치** | 전 블록이 막히면 옮겨도 주행비만 는다 | 문턱을 어떻게 걸어도 안 팔기를 못 넘는다 | **재배치 축 종료** |
| **(b) 규칙 오판** | 재배치는 가치 있는데 규칙의 기대대기 공식이 포화에서 깨진다 | **문턱을 걸면 안 팔기 아래로 내려간다** | **RL 헤드룸이 크게 생긴다** |

**(b)면 그동안 못 찾던 "학습이 규칙을 이기는 조건"이다** — 규칙이 틀리는 영역이
바로 학습이 이길 자리다. [[YR-195]]·[[YR-200]] 에서 문턱이 격차를 81% 줄였던 것도
같은 계열의 현상이다(규칙이 과하게 판다).

## 단계

### 1단계 — 부호 확증 (비판정 · 학습 없음)

세 물량 × {안 팔기, 규칙} × 3시드 = 18런. 물량마다 `규칙 − 안 팔기` 의 부호와 크기.

**산출**: 부하 대 재배치 이득 곡선. 부호가 뒤집히는 구간이 곧 답이다.

### 2단계 — (a)/(b) 진단 (비판정 · 학습 없음)

부호가 뒤집힌 물량에서 **규칙에 문턱을 걸어** 거래를 줄여 본다.

```
문턱 ∞  = 안 팔기          Φ 기준선
문턱 0  = 현 규칙          Φ +501.86
문턱 중간 값 몇 개   →  기준선 아래로 내려가는 지점이 있나?
```

내려가면 **(b)** — 재배치는 가치 있고 규칙이 과하게 판다.
단조 증가면 **(a)** — 재배치 자체가 무가치.

### 3단계 — 판정 계약 개정

세 물량 전부에서 판정하고 **전부 통과해야** 인정한다. 한 물량에서만 이기면
"그 부하에서만"이라고 명시한다.

```contract
load_levels_target = 3
```

## 판정

| | |
|---|---|
| 1·2단계 | **비판정** — 규칙 대 안 팔기 비교라 학습이 없다. 대역 소모 없음 |
| 3단계 이후 | 물량마다 새 대역. 세 물량 전부 보고 |
| 독립단위 | 날 · 같은 날·같은 물량끼리 짝지어 |
| 유의 | \|t\| ≥ 2.13 (df=15) |

## 선행·후속

- **선행**: 없음 — 지금 바로 할 수 있다(학습 불필요).
- **막는 것**: [[YR-190]] 리드타임 두 팔 실험은 **이게 끝나야** 의미가 있다.
  재배치 축이 죽어 있으면 리드타임을 바꿔도 잴 게 없다.
- **영향**: 결과에 따라 논문 **서사 B 본 주장**의 적용 범위를 다시 적어야 한다.

## 금지

- 결과가 나쁘다고 **물량을 낮추지 않는다** — 실측치다.
- 문턱 격자를 결과를 보고 바꾸지 않는다.
- 1·2단계에서 판정 대역을 쓰지 않는다(비판정 시드 9,900,0xx).

## 기록해 둘 것

7,500 의 출처(어느 터미널·어느 날짜)를 확인해 여기 적는다 — 지금은 "사용자 제공
실측치"로만 되어 있다. 3,500·5,000 도 같은 출처인지 확인 필요.
