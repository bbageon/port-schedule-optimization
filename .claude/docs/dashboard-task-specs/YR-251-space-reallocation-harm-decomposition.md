# YR-251 — 혼잡에서 블록 재배치가 손해인 원인 분해

- **상태**: backlog 🟢 · 2026-08-29
- **분류**: Exp
- **관련**: YR-250 재배치 유형 분해

## 연구질문

블록 재배치가 초혼잡에서 손해인 이유가 크레인 이동 증가인지, 목적 블록의 추가 대기인지
비용 항목별로 구분한다.

## 설계

- 수요 5,000대와 15,000대를 독립 하루로 실행한다.
- 재배치 없음, 블록만, 시간만, 두 유형 모두를 비교한다.
- 트럭 대기·크레인 이동·재취급·본선 유휴와 미완료·긴 대기·재배치 수를 보고한다.

## 한계와 완료 조건

독립 하루이므로 30일 안의 효과 크기로 일반화하지 않고 어느 비용 항목이 움직이는지만
진단한다. 같은 난수와 같은 비용 절단면에서 네 조건이 완주하면 완료한다.
