# YR-332-bm · 학습 목표를 선택이 바꿀 수 있는 범위로 좁히기

- **상태**: backlog
- 상위 [[YR-332]]. 2026-11-23 등록. [YR-332-bl](YR-332-bl-joint-turnaround-reward.md)에서 관측한 실패 기제를 직접 겨냥한다.
- 보정 대상: performance — 1대67 보상은 그대로 두고 학습 목표의 합산 범위 한 축만 바꾼다.
- 착수 조건: 현실성 판정이 미통과라 성능 단계는 공통 검사에서 거절된다. bl과 같은 합성 환경 탐색으로 진행할지 사용자 확인 뒤 착수한다.

## 왜 하는가

bl에서 새 모델은 기존 모델보다 시험 월 가중 합계가 23.07% 길어졌다. 원인은 보상 가중치가 아니라 합산 범위였다.

- 현행 학습 목표는 결정 시각부터 월말 진입분이 모두 끝날 때까지, 21개 블록과 모든 본선의 시간을 통째로 더한 값이다. 0에서 7,700만 가중 분까지 움직인다.
- 모델을 고치는 신호(`실제로 남은 시간 − 예상한 시간`)의 79~83%가 결정이 한 달 중 어느 6시간대였는지만으로 정해졌다. 선택과 무관한 값의 기대 비율은 6%다.
- 신호의 크기는 결정당 349만 가중 분이고, 선택 하나가 벌 수 있는 크기는 약 25 가중 분이다.
- 시각과 월 성분을 모두 빼도 126만 가중 분이 남는다. 그래서 비용 예측을 더 정밀하게 맞추는 것만으로는 부족하고, 합산 범위 자체를 줄여야 한다.

## 바꾸는 한 축

트럭 1분에 1, 본선 1분에 67이라는 보상 정의는 유지한다. 한 결정의 학습 목표에 더하는 범위만 줄인다.

- **대상**: 그 결정을 내린 블록에서 기다리거나 작업 중인 트럭, 그리고 그 블록이 작업하는 본선의 기항.
- **기간**: 결정 뒤 정해진 시간 안에 생긴 시간만 더한다. 기간 후보는 1단계에서 비교한다.
- 다른 블록의 트럭과 다른 본선, 그 기간 뒤의 시간은 이 결정의 목표에 넣지 않는다.

모델 구조·후보·물리·정보 시점·학습량은 bl과 같게 둔다. 예상값끼리의 차이로 배우는 방식 같은 다른 학습 방법은 이번 축이 아니다.

## 순서

1. **재학습 없이 먼저 잰다.** bl이 남긴 학습 월 16개의 원장과 저장 결정으로 후보 목표를 다시 계산한다. 기간 후보마다 세 가지를 잰다. 목표의 크기, 결정 시각만으로 정해지는 비율, 선택 하나의 기대 이득 대비 신호 크기다. 원장은 `build/yr332_joint_turnaround/training/rollouts/`에 있고 추적되지 않으므로 지우기 전에 계산한다.
2. **기준을 넘는 후보가 있을 때만 재학습을 등록한다.** 제안 기준은 시각 비율 20% 이하, 신호 크기가 선택당 기대 이득의 45배 이하다. 45배는 갱신 한 번의 2,048표본을 평균하면 신호와 같은 크기가 되는 수준이다. 기준값은 착수 시 실행 전 등록에서 확정한다.
3. 재학습은 bl과 같은 학습 월·시험 월·네 방식 비교를 쓴다. 한 번 굴리는 데 약 90분이다.

## 채택·중단 기준

- 1단계에서 어떤 후보도 기준을 넘지 못하면 재학습하지 않고 수치와 함께 닫는다.
- 범위를 줄이면 한 블록의 이득이 다른 블록의 손해를 못 볼 수 있다. 최종 판정은 줄인 목표가 아니라 시험 월 전체의 트럭 분·본선 시간·1대67 가중 합계로 한다.
- 현장 성능과 정책 채택은 주장하지 않는다.
