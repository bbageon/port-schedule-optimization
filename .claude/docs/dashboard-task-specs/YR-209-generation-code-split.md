## 규칙 (사용자 지시 2026-08-20)

> **"v1 은 v1 만, v2 는 v2 만, v3 는 v3 만 있어야 한다"**
> **"v3 코드를 작성할 때는 기존 코드를 수정하지 말고 v3 폴더에 작성한다"**

`shared/` 같은 중간 계층은 만들지 않는다 — 만들면 결국 거기로 다 모인다.
세대끼리 식이 같아도 **사본을 각자 갖는다**(의도된 중복). 그래야 v3 를 고쳐도
지난 판정이 흔들릴 수 없다.

**"세대가 바뀌면 이게 달라져야 하나"** 하나다.

| **판정에 쓰는 것** — 평가 잣대 Φ · 규칙 팔 · 에피소드 실행 · 시뮬레이터 | `integrated/` | **같아야 비교가 성립한다.** 판정이 짝비교라 세 세대가 같은 무대·같은 자를 받아야 한다 |
