# YR-168 — 5차 계약 무대에서 공간 판매 재판정 (YR-166 흡수)

- **Epic**: Exp / **Priority**: 🔴 / **등록일**: 2026-08-11 / **상태**: ready
- **3대 게이트 보정 대상**: `performance` 하나 — 착수 전 `authorize-next` 통과 필수
- **1줄**: 벌금 구간에 실제로 도달하고 **판매 기회가 실측으로 존재하는** 24시간 무대에서
  블록 간 공간 판매를 반사실 짝비교로 다시 판정한다.

## 왜 지금인가 (40차 감사 정정 반영)

0B 판정(YR-151)은 **STOP** 이었다. 기록된 STOP 사유는 두 기계 임계 미달이다 —
축1 런합 5런 중 2런 음수, 축2 순위상관 중앙값 **−0.204**(임계 0.3).
board 원문: "판매 자체가 무의미한 것이 아니라 **현재 견적식이 이로운 공간 판매를
안정적으로 구분하지 못해** 학습을 중단한다."

**과한 표현 정정**: "STOP 의 직접 원인은 벌금 구간 미도달"이라는 인과는 **어느
산출물에서도 검증된 적이 없다**(YR-164·YR-165 는 체류시간을 측정조차 안 했다).
정확한 진술은 이것이다 —

> 기존 실험은 저부하였고(평균 체류 ~20분 < 벌금 임계 43분) 판정의 정답 라벨이
> 투입기 인공물(T_other +16.52 > 총이득 +14.95)로 오염돼 있었으므로,
> **그 STOP 결과를 새 혼잡 환경에 그대로 이월할 수 없다.**

- 해소된 것: **무대 전제**(YR-167 재자격 12/12, 벌금 도달률 24.0%) 와
  **투입기 오염**(개방 루프 계약에 내장 — 구 YR-166 흡수).
- **해소되지 않은 것: 축2(견적 구분력).** 이 축은 새 사전등록에 그대로 승계한다.

## 판매 기회 실측 (YR-168 ① 관찰 모드 · 2026-08-11)

`yr168_observe` — 판매 미실행(전건 KEEP)으로 5분 격자마다 `iter_pre_gate_candidates`
로 **실제 후보**를 세고 블록 간 대기열 격차를 측정. 시드 3개 결과:

- 후보: 265 시각 중 257(97%)에 존재, 시각당 평균 26.8건, 후보 보유 블록 평균 10.5개.
- **기회 격차**(후보 보유 블록 최대 대기열 − 전체 최소 대기열): 평균 5.45~6.05, 최대 21.
- **피크 [11,16)시: 격차 ≥5 인 시각 100%**(평균 15.1) / **야간 [2,8)시: 0%**(평균 0.32).
- 부산물(현실성 게이트 재제출용): 크레인 사이클 139.3~140.0초, 게이트 처리율 161.6대/h.

→ **판매가 성립할 수 있는 무대다.** 단 기회는 피크대에 몰려 있고 야간엔 없다.

## 설계 (실행 전 동결 필요 — 아직 숫자 미동결)

1. **사전등록 동결** — 판정 임계·표본수·신뢰구간·무효 조항을 결과 열람 전에 sha256 박제.
2. **반사실 짝비교** — 같은 시드에서 기저 세계(전건 KEEP) vs 처치 세계(판매 1건).
   `_state_digest` 로 처치 직전 상태 동일성 증명. 실현 비용으로만 비교.
3. **시간대 정의(곡선 유도 · 미동결)** — 야간은 **[2,8)시**(측정창 시작과 일치).
   피크 [11,16)는 눈대중이었다(10~11시 402.8대가 빠지고 12~13시 349.1이 들어감) —
   λ(t) 적분에서 상위 시간대로 다시 유도해 동결한다.
4. **완주 하드 가드** — 두 세계 모두 26시간(관측 24h + 배수 2h) 종료 시점에
   트럭 3,600 완주·본선 완주·누락 0·취소 0 을 **판정 조건으로** 검사한다
   (YR-167 은 보고만 하고 검사하지 않았다 — 40차 감사 ③).
5. **표본 수** — 4차 σ 로 역산하면 효과 0.5h 검출에 63~98쌍, 견적 중앙값 0.139h
   검출에 814~1,497쌍이다. **과거 40쌍은 0.5h 급도 못 잡는다.** 5차 σ 는 다르므로
   **눈가림 파일럿**(평균·CI·원자료 봉인, 짝차이 표준편차만 개봉)으로 재측정한 뒤
   `N = max(하한, n(δ))` 로 동결한다. δ(검출 최소 효과)는 **사용자 결정 사항**.
6. **통계 단위** — 여러 판매 건이 아니라 **시드별(런 단위)** 결과를 통계 단위로 쓴다.
7. **시드 분리** — 새 트럭 시드 + 새 본선·초기배치 시드(자격 대역 8,100,000~2 와 교집합 0).

## 하지 않는 것

- 결과를 본 뒤 임계·표본수·판정 대역을 바꾸는 것.
- 4차 계약 결과와 직접 수치 비교하는 것(계약이 다르다 — 이력 분리).
- 이득이 안 나올 때 하이브리드·레이어 추가로 우회하는 것(전역 규칙: 단일 메커니즘
  최적화 우선).
- 검정력 부족 상태의 결과를 "이득 없음"으로 읽는 것 — POWER_FAIL 로 분류한다.
