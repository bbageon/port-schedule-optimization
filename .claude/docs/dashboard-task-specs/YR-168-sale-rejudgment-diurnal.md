# YR-168 — 5차 계약 무대에서 공간 판매 재판정 (YR-166 흡수)

- **Epic**: Exp / **Priority**: 🔴 / **등록일**: 2026-08-11 / **상태**: ready
- **3대 게이트**: 성능(미판정 — 이 작업이 판정) / 정합(YR-167 로 확보) / 시드 현실성(YR-167 PASS)
- **1줄**: 벌금 구간에 실제로 도달하는 24시간 무대에서 블록 간 공간 판매를
  반사실 짝비교로 다시 판정한다.

## 왜 지금인가

0B 판정(YR-151)은 **STOP** 이었다. 그러나 YR-164/YR-165 가 밝힌 원인은 "판매가
무용하다"가 아니라 **무대가 비용 벌금 구간에 도달하지 못했다**는 것이다:

- 실측 평균 체류 ~1,200초 vs 벌금 임계 2,580초 → 판매로 줄일 벌금이 애초에 없음.
- 전역 파급으로 보였던 `T_other` 는 **투입 통제기의 인공물**이었다(YR-165 판정 A,
  고정 투입에서 정확히 0).

YR-167 자격에서 **벌금 구간 도달률 24.0%**, 피크 시간대 평균 체류 40.8분이
확인돼 두 전제가 모두 해소됐다. 투입 고정(구 YR-166)은 개방 루프 스케줄러로
계약에 내장돼 별도 축이 필요 없다 → **YR-166 은 이 row 에 흡수**.

## 설계 (실행 전 동결 필요)

1. **사전등록 동결** — 판정 임계·표본수·중단 규칙을 결과 열람 전에 sha256 박제.
2. **반사실 짝비교** — 같은 시드에서 기저 세계(전건 KEEP) vs 처치 세계(판매 1건).
   `_state_digest` 로 처치 직전 상태 동일성 증명. 실현 비용으로만 비교.
3. **표본 배치** — 피크대(11~16시)와 야간대(1~6시)를 분리 집계해
   "혼잡에서 이득·한산에서 무해"를 각각 판정한다(사용자 요구의 두 국면).
4. **신호 대 잡음** — 4차에서 정책 결정 연쇄 변동(−3.95~+1.35h)이 단건 효과의
   약 30배였다. 짝 수를 잡음 표준편차로부터 역산해 사전 고정한다.

## 하지 않는 것

- 결과를 본 뒤 임계·표본수·판정 대역을 바꾸는 것.
- 4차 계약 결과와 직접 수치 비교하는 것(계약이 다르다 — 이력 분리).
- 이득이 안 나올 때 하이브리드·레이어 추가로 우회하는 것(전역 규칙: 단일 메커니즘
  최적화 우선).
