# YR-332-t — v7 비교 기준·비용 수치의 타당성 감사

- **상태**: backlog
- 상위: [[YR-332]]. 등록: 2026-11-06, 사용자 질문에 따른 우선순위 재검토.
- 대상: 현실성(scenario_validity)의 수치 근거 감사. 현재 정책·물리·비용을 고정한다.
- 이번 등록은 감사 계획과 코드·기존 결과의 예비 대조이며, 외부 근거 검증 완료가 아니다.

## 무엇과 왜

사용자는 “학습 효과가 없었다는 판단에 쓰인 비교 수치가 타당한가”를 물었다.
투입 누락(m)만 확인해서는 비용의 상대 비중이나 작업시간의 현실성을 판정할 수 없다.
현재 사용 중인 수치의 출처·단위·적용 범위를 먼저 정리하고, 근거 부족과 구현 오류를 구분한다.
과거 결과를 이유로 학습 정책에 유리하게 수치를 선택하지 않는다.

## 예비 확인 — 코드와 저장 결과에서 확인한 범위

- 기준 코드: `c59e66b12a41f3e8ec05f5c174b8dba5cfaeb121`.
- v7 교사 비용은 원화 네 항이다. v6의 정규화 비용 전환 결과를 v7에 적용된 것으로 읽지 않는다.
- 트럭 시간당 40,000원 + 1시간 초과분 시간당 40,000원, 빈 이동 시간당 60,000원,
  재취급 회당 2,000원, 본선 톤수·시간당 35.88원이 구현값이다. 이는 타당성 승인 목록이 아니다.
- 트럭의 고시 인용은 법정 청구액을 그대로 재현하지 않는다. 초과 할증은 설계 해석이다.
  이동·재취급은 설계 환산, 본선은 용선료의 대리값이라는 주석을 원출처와 대조해야 한다.
- 작업시간은 이동·인양 등의 합산 모델이고, 계산값을 실제 시뮬레이션 완료에 사용한다.
  실측 시간의 변동까지 검증됐다는 뜻은 아니다.
- 비교 규칙은 실작업 우선 후 가장 짧은 계획 시간을 고른다. 학습 정책도 계획 시간을 보지만,
  1시간으로 나눈 뒤 상한 1을 적용한다. 정보 접근과 표현의 차이를 구분해야 한다.
- 4단계 기존 학습은 학습 전 대비 비용 평균 -9.5772%, 체류 -8.4145%(같은 입력 9쌍)다.
  같은 후보 규칙 대비 비용은 +12.6808%이고 운영 채택 조건은 미통과다.
  따라서 “학습 전보다 개선 관측”과 “기존 규칙 우위 미달”을 함께 적는다.
  3개 초기 모델·각 3회 갱신의 진단이며 장기 수렴이나 통계적 확증은 아니다.

## 감사 범위와 완료 기준

1. 실행 설정·함수·결과 파일을 연결한 수치 목록을 만든다. 각 값에 단위, 원출처,
   변환식, 실측/문헌/설계/미확정 구분, 적용 가능한 작업·시간 범위를 기록한다.
2. 비용 네 항을 원래 시간·횟수로 분리한다. 트럭 체류·본선 지연/완료·미완료·미투입을
   총점과 함께 대조하고 중복 계상·관측 종료·분모 정의를 명시한다. 원인 복구는 m의 범위다.
3. 규칙과 학습 정책의 후보·정보 시점·작업시간 표현·안전 제약을 대조한다.
   규칙이 이겼다는 사실만으로 규칙의 최적성이나 시간 모델의 타당성을 승인하지 않는다.
4. 문헌·실자료에 근거한 범위가 있으면, 기존 궤적을 고정하고 계수 하나씩 재계산해 순위 변화를
   진단한다. 이는 고정 정책의 점수 민감도이며 바뀐 보상으로 재학습한 성능이 아니다.
   시간 모델 변경은 궤적도 바꾸므로 단순 재채점으로 검증하지 않는다.
5. 결과는 학습 전후 개선·규칙 대비 우열·운영 채택·현실 타당성으로 나눠 판정한다.
   근거가 없으면 수치를 임의 보충하지 않고 미확정 항목과 필요한 자료를 남긴다.
   오류나 보정이 필요하면 해당 한 축의 후속을 등록하고 새 실행 전에 조건을 고정한다.

- [[YR-332-m]]: 오더 투입 누락과 미완료의 원인·장부 대조. 본 감사가 그 수행을 대체하지 않는다.
- [[YR-332-f]]: 예약과 실제 도착 오차 보정. 원자료 경로가 선행이며 요약만으로 승인하지 않는다.
- [[YR-332-i]]: 양하 차량 수·이동/인계시간·마감 보정. 본 감사에서는 현재 값의 근거만 추적한다.
- 정책 개선 실험은 감사 결과와 기존 미통과 항목을 확인한 뒤 별도로 결정한다.
