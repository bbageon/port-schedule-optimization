## 무엇과 왜

사용자는 “학습 효과가 없었다는 판단에 쓰인 비교 수치가 타당한가”를 물었다.
투입 누락(m)만 확인해서는 비용의 상대 비중이나 작업시간의 현실성을 판정할 수 없다.
현재 사용 중인 수치의 출처·단위·적용 범위를 먼저 정리하고, 근거 부족과 구현 오류를 구분한다.
과거 결과를 이유로 학습 정책에 유리하게 수치를 선택하지 않는다.

  따라서 “학습 전보다 개선 관측”과 “기존 규칙 우위 미달”을 함께 적는다.

## 감사 범위와 완료 기준

1. 실행 설정·함수·결과 파일을 연결한 수치 목록을 만든다. 각 값에 단위, 원출처,
   변환식, 실측/문헌/설계/미확정 구분, 적용 가능한 작업·시간 범위를 기록한다.
2. 비용 네 항을 원래 시간·횟수로 분리한다. 트럭 체류·본선 지연/완료·미완료·미투입을
   총점과 함께 대조하고 중복 계상·관측 종료·분모 정의를 명시한다. 원인 복구는 m의 범위다.
3. 규칙과 학습 정책의 후보·정보 시점·작업시간 표현·안전 제약을 대조한다.
   규칙이 이겼다는 사실만으로 규칙의 최적성이나 시간 모델의 타당성을 승인하지 않는다.
4. 문헌·실자료에 근거한 범위가 있으면, 기존 궤적을 고정하고 계수 하나씩 재계산해 순위 변화를
   진단한다. 이는 고정 정책의 점수 민감도이며 바뀐 보상으로 재학습한 성능이 아니다.
   시간 모델 변경은 궤적도 바꾸므로 단순 재채점으로 검증하지 않는다.
5. 결과는 학습 전후 개선·규칙 대비 우열·운영 채택·현실 타당성으로 나눠 판정한다.
   근거가 없으면 수치를 임의 보충하지 않고 미확정 항목과 필요한 자료를 남긴다.
   오류나 보정이 필요하면 해당 한 축의 후속을 등록하고 새 실행 전에 조건을 고정한다.

## 도착순 비교에 대한 사용자 재질문 — 2026-11-06

사용자는 항만의 통상적인 크레인 작업이 들어온 순서대로 처리하는 방식인지 지적했다.
외부 트럭의 도착순(FCFS)은 문헌에 쓰이는 운영 규칙이자 대표 비교 기준이다.
그러나 근접 작업 우선·본선 연결 차량 우선 등의 규칙도 있으므로 모든 터미널의 단일 표준으로
단정하지 않는다. 부산항 특정 터미널의 실제 운영 규칙은 운영 자료 확인 전까지 미확정이다.

- 이번 6단계의 규칙 비교는 `six_step_learning.py:evaluate`에서 `SF_SPT`만 실행했다.
  따라서 최단작업 우선 대비 결과로 도착순 대비 성능을 결론내릴 수 없다.
- 비교 목적은 도착순 대비 작업 순서 개선과, 작업시간을 이용하는 규칙 대비 추가 개선으로 나눈다.
  도착순을 추가하더라도 기존 최단작업 우선 결과와 채택 미통과 판정은 보존한다.
- `v7/dispatch.py:FIFO`는 `release_time`(없으면 `provided_eta`)의 통지순이다.
  블록 도착순과 일치한다고 가정하지 않는다. 기존 `world/integrated/baselines.py:FIFOPreference`도
  미래 도착을 읽을 수 있는 별도 진단 코드이므로 이름만으로 도착순 기준에 재사용하지 않는다.
- 감사에서 게이트 진입·블록 도착·실제 작업 가능 시점 중 어느 시점을 뜻하는지 정하고,
  본선 작업의 선행관계·안전 제약을 공통으로 유지하는 비교 계약을 작성한다.
  후속 [[YR-332-u]]에서 조건을 고정해 구현·평가했다. 통지순 구현은 보존하고 실제 사건순 규칙을 추가했다.
  도착순 대비 평균 체류 감소는 확인했으나 투입·본선 보호 미통과와 수치 근거 검증은 여전히 남는다.
  [재평가 결과](../../../outputs/reports/yr332_arrival_eval/README.md).

근거: [Kim 등의 2003년 야드 작업 순서 연구](https://www.sciencedirect.com/science/article/pii/S0925527302004668)는
도착순 등 현장 규칙과 학습 규칙을 구분해 비교한다.
[2024년 외부 트럭·야드 크레인 연구 §3.1](https://www.mdpi.com/2071-1050/16/22/9743)은 도착순을 기본 규칙으로 설명한다.
[Yu 등의 2018년 연구 §3.1](https://onlinelibrary.wiley.com/doi/10.1155/2018/5401710)은
도착순·근접순·본선 연결 차량 우선의 변형을 함께 비교한다.
[Kaleris 공식 제품 설명](https://kaleris.com/advanced-optimization/)도 우선순위·근접성·부하를 이용한 배차를 설명한다.
문헌·제품 설명은 특정 부산항 터미널이 해당 방식을 사용한다는 증거와 구분한다.
