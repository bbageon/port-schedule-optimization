# YR-332-cc — 학습 정책의 선택이 거의 고르게 퍼져 있다 (같은 상황에서 규칙과 비교)

- **상태**: backlog (읽기 전용 진단 결과 기록, 후속 점검은 사용자 확인 뒤 사전등록)
- 상위 [[YR-332]], 2026-11-27 등록. 관련 [[YR-332-cb]](규칙보다 나아질 여지) · [[YR-332-bp]] · [[YR-332-bt]] · [[YR-325]](규칙에서 출발).
- **3대 게이트 보정 대상**: `performance`. 학습이 정책을 얼마나 움직이는지 확인한다.

## 발단

- 2026-11-27 사용자: "지금 규칙이랑 우리 정책이랑 한 결정의 차이가 뭐지..?" (bt 네 조건이 모두 규칙 미달이고 서로 비슷하게 나온 뒤)

## 사전 확인 (2026-11-27, 읽기 전용 · 판정 아님)

자료: bp 마지막 물결 첫 학습 달의 결정 상태 30,000개(선택지 2개 이상인 단계 30,449개).
두 정책은 같은 강제 순서(24분 넘게 기다린 트럭 먼저, 실작업 먼저) 안에서만 고른다. 규칙의 선택은 입력 6번째 칸(계획 소요 시간)이
가장 짧은 후보로 재구성했다(동률은 본선, 그다음 오래 기다린 순).

| 모델 | 규칙과 같은 선택(최고점) | 규칙 선택에 준 확률 | 자기 최고 후보 확률 | 퍼짐(무작위 = 1) |
|---|---:|---:|---:|---:|
| 출발 모델(bp 학습 전) | 32.9% | 25.9% | 29.4% | 0.97 |
| bp 최종 모델 | 47.7% | 27.2% | 29.4% | 0.97 |
| 무작위 | 24.4% | 24.4% | — | 1.00 |

- 선택지 수는 2개 29%, 8개 이상 41%다. 모든 후보가 24분 넘게 기다린 트럭인 단계가 40%다.
- 학습은 최고점 선택을 규칙 쪽으로 옮겼지만(32.9 → 47.7%) 확률 분포는 거의 고르게 남았다. 점수 차이가 아주 작아 최고점이 작은 차이로 갈린다.
- bp 갱신 4회의 평균 정책 변화(KL)는 0.0018~0.0022, 잘림 비율 1.2~1.6%, 퍼짐(엔트로피)은 1.874 → 1.846이다. 한 번의 갱신이 정책을 거의 바꾸지 않는다.
- bp 최종 모델이 규칙과 다르게 고른 15,937단계: 모델 선택이 중앙값 0.25분 더 긴 작업이다.
  규칙은 본선 작업·모델은 아닌 경우 26.4%(반대 0.6%), 모델만 내려놓기 작업 32.2%(반대 0.1%),
  모델이 덜 기다린 트럭 53.4%·더 기다린 트럭 28.6%.
- 시험 달 결과와 같은 방향이다: 모델 반입 18.4분(규칙 19.8), 반출 158.1분(144.1), 본선 39.57시간(37.49).
- 예정 시각 네 조건이 서로 비슷했던 것도 같은 맥락이다. 정책이 어떤 입력에도 강하게 반응하지 않는다.

## 할 일 (사전등록 후 한 축씩)

1. **갱신 크기**: 갱신마다 퍼짐·규칙 일치율·KL을 기록하고, 갱신 크기 한 축만 바꾼 비교를 설계한다.
2. **신호 대 잡음**: 결정별 이득 추정의 부호가 규칙 선택을 지지하는 비율을 잰다. 학습 신호가 어느 쪽을 가리키는지 본다.
3. **표현력**: 같은 망에 규칙 따라 하기만 학습시켜 일치율이 얼마까지 오르는지 본다. 진단용이며 배포 정책이 아니다.

## 완료 조건

- 퍼짐이 남는 원인(갱신 크기·신호 잡음·표현력)을 한 축씩 전후 수치로 분리한다. 결과를 보고 기준을 바꾸지 않는다.
- 진단 스크립트는 고정 사본에서 실행한 읽기 전용 계산이다. 진행 중인 실행의 등록 파일은 바꾸지 않는다.
