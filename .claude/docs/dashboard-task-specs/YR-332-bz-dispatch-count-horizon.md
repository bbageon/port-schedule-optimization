# YR-332-bz · 다음 배차 1·5·10건으로 첫 선택을 채점하는 방법 검토

- **상태**: backlog
- 2026-11-26 사용자 요청으로 [예정시각 실험의 첫 선택 대조](YR-332-by-port-decision-review.md) 뒤에 등록했다. 질문은 “트럭과 본선 중 하나를 먼저 고른 효과를, 같은 블록의 다음 몇 번의 배차까지 보면 구별할 수 있는가?”이다.
- 첫 단계는 저장 모델로 배차 기록을 읽는 성능 진단이다. 건수별 성적과 재학습 결과는 미측정이다.

## 한 건과 학습 점수

- 처음 비교할 배차는 0번이다. 그 뒤 같은 블록에서 트럭 또는 본선 실작업을 하나 이상 실제 배정한 결정을 센다. 한 결정에서 두 크레인에 함께 배정하면 1건이고, 선택지가 하나였어도 실작업을 배정했으면 센다. 대기·위치 이동·준비만 한 결정은 0건이며 그동안 발생한 체류비용은 누적한다.
- 후보는 다음 1건·5건·10건이다. 각 갈래에서 해당 번째 배차를 결정하기 직전까지 실제로 쌓인 비용을 세고, 그 시점의 상태에서 이후에 발생할 비용의 예측값을 잇는다. 예측 대상의 비용 범위와 단위를 모든 후보에 동일하게 적용한다. 끝까지 처리해도 지정 건수를 채우지 못하면 종료까지의 실제 비용을 쓰고 남은 비용은 0으로 둔다.
- 건수는 학습용 채점을 어디까지 실적에서 가져올지 정한다. 운영 시에는 크레인이 배차할 때마다 그때 보이는 정보로 가능한 작업을 고른다. 여러 건을 묶어서 미리 배정하지 않는다. [현재 배차 코드](../../../src/yard_rl/v7/crane/on_policy.py) · [현재 30분 채점](../../../scripts/v7/short_window_train.py)

## 어느 범위를 선택할지

1. 개발용 입력에서 같은 크레인이 트럭과 본선 실작업을 모두 선택할 수 있는 순간을 고정한다. 첫 선택만 바꾸고 이후 양쪽에 같은 정책과 외부 입력을 적용한다. 선행 과제의 시험 월 네 사례는 결과 해석에만 쓰며, 건수 선택은 별도 개발 자료에서 한다. 저장본에 후속 배차 시각이 없으면 고정 모델로 재생해 같은 블록의 실제 배정 이력을 복원한다.
2. 두 갈래에서 5번째 배차 시각은 서로 다를 수 있다. 후보별 실제 경과 분, 그때까지의 비용, 남은 비용 예측을 각각 남긴다. 예측에는 그 결정 당시 알 수 있던 상태만 쓴다. 두 갈래가 끝까지 처리한 실제 원장은 첫 선택 중 무엇이 유리했는지 확인하는 정답으로만 사용한다.
3. 30분과 1·5·10건을 같은 비용식·집계 범위·남은 비용 예측 방식으로도 비교한다. 기존 30분 모델은 실제 30분 비용만 사용했으므로 원래 점수도 별도 표시한다. 배차 건수 효과와 미래 비용 예측을 추가한 효과를 구별하기 위해서다.
4. 각 범위가 끝까지의 가중 시간 합계에서 유리했던 첫 선택을 얼마나 자주 맞히는지, 틀렸을 때 추가된 트럭 총분과 본선 총분이 얼마인지 본다. 동률·직접 비교 가능 건수와 후보 간 차이의 불확실성을 함께 기록한다. 짧은 범위도 같은 수준으로 판단하면 짧은 쪽을 우선 검토하고, 표본이나 차이가 부족하면 선택을 보류한다.
5. 건수 기준을 재학습에 적용할 근거가 생기면, 해당 비교에서는 상태 입력·작업 후보·비용 계수·승격 조건·모델 구조와 학습량을 맞춘다. 정책 적용 결과는 연속 30일에서 트럭 방문당 게이트 진입부터 마지막 작업 완료까지의 평균 분, 본선 척당 평균 작업시간으로 판정한다. 방문당 집계와 장기 체류 비용의 검증은 [별도 비용 실험](YR-332-bx-gate-age-curve.md)을 따른다.
