# YR-317-h — v3 기본 수평·수직 환경 정의와 검증

- **상태**: in-progress
- 등록: 2026-09-15 사용자 지시. parent: YR-317, 리뷰어 2와 리뷰 1-5 대응.
- 무엇: 기본 수평 공유형과 수직 역할분리형의 경로·작업 인계·자원 공유를 정의하고 시뮬레이터에서 검증한다.
- 왜: 기존 v3는 단일 축 합성 배치이며 실제 수직 환경에서 이미 검증한 것으로 볼 근거가 부족하다.
- [현재 전략·비교 계약](../../../docs/paper/v3/paper-revision/04-수평-수직환경-정의.md).
- [기존 두 구조 결정](../strategy-history/2026-08-06-H21-V21-두-합성구조-고정.md)을 참고하되 과거 정책·성능을 v3 근거로 승계하지 않는다.
- 수평은 안벽과 평행한 장축·측면 인계·크레인 공유, 수직은 직각 장축·육/해측 인계·크레인 역할을 구분한다.
- 공통 21블록·블록당 크레인 2대·1,440칸, 같은 외생 요청·재고·본선 계획·비용·학습 예산을 유지한다.
- 좌표·차로·속도·인계 시간·역할·버퍼를 출처와 함께 실행 전에 동결한다. 출처 없는 값은 합성 가정으로 표시한다.
- 이름이나 좌표 회전만 바꾸지 않는다. 구조 차이가 실제 경로·허용 작업·대기 사건에 반영되는 검증이 필요하다.
- 구조·인계·역할을 함께 바꾸므로 방향 하나의 인과효과로 해석하지 않는다. 혼합 배치·특정 실항만 재현·AGV 기술 성능 비교는 제외한다.
- 기존 정책에 추가 학습층·복합 제어 규칙을 덧붙이는 작업이 아니다. 새 구조는 먼저 환경 자격으로 검사한다.
- 구조별 같은 코드·학습 예산의 별도 가중치가 주비교다. 동결 기존 가중치 전이는 별도 진단으로 구별한다.
- 이후 d에서 구조별 독립 월 20개×4정책을 제안한다. 두 구조 원비용을 합쳐 한쪽 실패를 가리지 않는다.
- 선행: a·g의 관련 기록·처리량 정합 및 해당 연구 게이트. 미통과가 있으면 그 원인을 직접 고치는 작업을 우선한다.
- 완료 기준: 환경 명세·구현·경로/역할 변이 확인·요청/재고/본선 장부·완주·구조별 실행 계약의 일치.
- 이번 완료 범위는 문헌 검토와 정의 문서 작성이다. 환경 구현·추가학습·두 구조 평가를 실행한 상태가 아니다.

## 9/19 병렬 준비와 코드 연결 점검

- 사용자 병렬 진행 요청에 따라 실행 경로·프로파일·크레인 역할·인계 사건·기존 시험을 별도로 점검했다.
- [구체 준비 문서](../../../docs/paper/v3/paper-revision/25-HV-병렬준비.md)와 [소스 지문·줄 근거](../../../outputs/reports/yr317_v3_layout_readiness/source-audit.json)를 보존한다.
- 월 실행기는 공유형과 단일 축 배치를 고정한다. 육/해측 역할 제한과 측면/끝단 인계 사건을 전환하는 실행 설정은 없다.
- 구현 연결 지점과 작은 구조 검증 5단계를 정리했다. 정적 점검이며 환경 구현·단기 실행·학습·두 구조 비교 완료가 아니다.
- 환경 준비는 기존 독립 평가와 병행할 수 있다. 장기 실행은 실제 구조 차이·작업 보존의 검증과 해당 연구 게이트 이후 별도 계약으로 시작한다.
- 시간 정책 중심 범위에 맞춘 두 정책 비교안은 검토 후보이며 원래 160개 제안의 자동 실행·통계 계약 변경은 하지 않는다.

## 9/19 사용자 범위 축소·수직 환경 구현 지시

- 사용자는 시간 제약 때문에 두 구조의 대규모 독립 반복 대신 각 1시드 보완 비교를 요청하고, 수직형 구조 구현을 먼저 지시했다.
- 위의 20개월×4정책·구조별 별도 학습은 이전 제안으로 보존한다. 이번 구현은 장기 평가나 재학습을 시작하지 않는다.
- 후속 비교안은 같은 외생 입력 한 세트를 두 구조의 기준/시간 정책에 적용하는 4실행이며, 기존 모델을 고정하면 구조 변경에 대한 단일 사례 진단이다. 효과의 통계적 확증으로 보고하지 않는다.
- **3대 게이트 보정 대상: `scenario_validity`** — 현재 누락된 끝단 인계·경로·재고 접근을 구현하고 작은 물리 사례로 검증한다. 성능 판정·시드 선택·기존 평가 조건을 바꾸는 작업이 아니다.
- 사용자 병렬 진행 지시에 따라 기존 d의 고정 소스 평가와 별도로 구현한다. WSL 고정 체크아웃·가중치·입력·설정은 변경하지 않는다.
- 수직형의 기본 구현은 같은 레일의 비통과 크레인 2대, 육측/해측 끝단 인계, 외부/본선 작업 역할 분리로 둔다. 적재 영역은 분할하지 않는다.
- 양끝 인계점 바깥의 명시적인 주행 여유 구간으로 상대 크레인이 물러날 수 있게 한다. 이동시간·안전 간격을 보존하고 모든 적재 위치의 접근을 검사한다. 이는 합성 운영 가정이며 모든 수직 터미널의 공통 구조라는 주장이 아니다.
- 코드상 새 환경은 명시적으로 선택할 때만 사용한다. 기존 실행 경로의 결과 동일성과 새 경로의 물리 검증을 함께 확인한다.
- v3 선행 기록의 원격·지문과 저장된 신뢰성 검산 후 환경 현실성 보정 착수 허용을 확인했다. [실제 검사 응답](../../../outputs/reports/yr317_v3_vertical/authorization.json). 이것은 새 구조의 검증 완료나 성능 통과 판정이 아니다.

## 수직형 구현·진단

- [구현 명세와 한계](../../../docs/paper/v3/paper-revision/26-수직형-구현검증.md). 원본 world를 유지하고 opt-in 환경·도로·끝단 인계·비통과 역할·유한 양하 흐름을 연결했다.
- 실제 주행시간만 파생시키고 합성 요청·재고·본선 계획 지문을 보존한다. 본선 예정 마감은 원래 프로파일 기준으로 고정하고 새 물리 하한도 기록한다.
- 마지막 코드의 새 구조·마감·연결 55검사와 기존 환경 38검사를 통과했다(학습 분기 검사 1개 제외). 고정 모델 2일 진단 결과를 추가한다.
- [기존 환경 동일성](../../../outputs/reports/yr317_v3_vertical/legacy-equivalence.json): 1일·21대에서 기존 고정 소스와 새 기본 실행의 전체 결과·관측 289행이 일치했다. 새 빈 환경 명세 필드만 제외했다.
- 단기 자격 실행은 합성곡선의 모양을 유지한 60대/60대 입력을 쓴다. 저부하 기술 검사이며 정책 성능·학습 안정성·통계 일반화의 근거가 아니다.
- h는 계속 진행 중이다. 수평 대응 환경과 1시드×2구조×2정책 비교는 아직 미실행이며, 장기 평가나 새 학습을 착수하지 않았다.
