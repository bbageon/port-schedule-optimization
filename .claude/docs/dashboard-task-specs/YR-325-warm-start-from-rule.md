# YR-325 — 규칙에서 출발한다: rollout 알고리즘의 보장을 되찾기

## ★핵심 발견

우리가 쓰는 방법(한 결정에서 세계를 굴려 행동가치를 재고 그쪽으로 정책을 옮긴다)은
문헌에서 **rollout 알고리즘**이라 부른다. 그리고 이 알고리즘에는 **서명과도 같은 보장**이
있다 (Bertsekas·Castanon 1999):

> 기저 휴리스틱이 실행 가능한 해를 내면, rollout 정책이 내는 해의 비용은
> **그 휴리스틱보다 나쁘지 않다.**

**우리 목표가 정확히 "규칙보다 나은가" 인데, 그 보장을 스스로 버리고 있었다.**

### 왜 버렸나 — 기저정책이 규칙이 아니라 **학습 중인 망**이다

    run_episode(dispatcher="RL_CRANE", crane_net=net)
        → _Ctx(dispatcher="RL_CRANE", crane_net=net)
        → 분기 세계도 RL_CRANE 으로 3시간을 돈다

즉 우리가 재는 값은 **Q^(학습 중인 망)** 이지 **Q^(규칙)** 이 아니다. 그리고 망은
**무작위로 초기화**된다. 나쁜 정책 위에서 한 걸음 개선하면 **덜 나쁜 정책**이 나올 뿐,
규칙보다 낫다는 보장은 어디에도 없다.

실측이 이를 뒷받침한다 — 궤적 첫 다섯 회차가 **+15.6 / +22.0 / +26.0 / +21.9 / +18.5%**
로 규칙보다 한참 나쁘다. 이 구간은 순전히 *"무작위에서 기어 나오는"* 낭비다.

## 무엇을 바꾸나 — 두 자리

### ① 시작 망을 규칙 모방으로 (warm start) — **거의 공짜**

규칙이 무엇을 고를지는 **시뮬레이션 없이** 안다. 하루를 규칙으로 굴리며 결정마다
후보 순위를 적고, 그 순위를 망에게 흉내내게 가르친다. **반사실 세계가 0개** 든다.

문헌: *"전문가 안내는 학습 초기에 특히 유용하다 — 무작위 저품질 표본에 기대는 대신
의미 있는 영역으로 이끌어 헛된 탐색을 줄이고 수렴을 앞당긴다."* 택배 배차 사례는
첫 300회차를 휴리스틱 모방으로 채우고 1000회차까지 20% 확률로 섞었다.

### ② 분기 세계의 기저정책을 규칙으로 — 보장이 살아난다

지금은 `dispatcher` 하나가 **본 세계와 분기 세계를 같이** 정한다. 이를 갈라서
본 세계는 학습 망, **분기 세계는 규칙**으로 두면 Q^규칙 을 재게 되고,
그에 대해 탐욕적으로 행동하는 정책은 **규칙보다 나쁘지 않다**(위 정리).

⚠️ 대신 **한 걸음만** 좋아진다. 더 가려면 개선된 정책을 다음 기저로 삼아 반복한다
(정책반복) — 지금 하는 것과 같되 **출발점이 규칙**이라는 점이 다르다.

## 함께 찾은 방법 넷

| | 문헌이 말하는 것 | 우리 적합도 |
|---|---|---|
| **쉬운 것부터** (curriculum) | 작업장 일정 연구에서 난이도순 학습이 최적성 격차 **8.1%p** 개선 · **50시간** 절약 | ✅ 우리 자료와 정확히 맞는다 — 낮은 부하는 이기고 높은 부하는 지며, 3시간 창도 낮은 부하만 덮는다([[YR-323]]). 지금은 다섯 부하를 섞어 돌린다 |
| **굴릴 결정을 똑똑하게 고른다** (RSPI) | 상태 선택을 다중선택 문제로 보고 불확실한 곳에 자원 배분 → 균등 표본 대비 **10배** 절감 | ✅ 지금은 **등간격으로 기계적** 선택. 그런데 **라벨의 18%가 차이 0** — 배울 게 없는 결정에 계산을 쓴다. **계산을 실제로 줄이는 몇 안 되는 방법** |
| **조기 중단** (순차확률비검정) | 결론이 서면 표본을 멈춘다 | ⚠️ 원리는 맞다(차이가 0이면 일찍 포기, 벌어지면 일찍 확정). 구현이 까다롭다 |
| **병렬·벡터화** (EnvPool·JAX) | GPU 시뮬레이터가 10~100배 | ❌ 파이썬 이산사건 시뮬레이터라 GPU 로 못 옮긴다. 코드 주석도 *"병목이 신경망이 아니라 시뮬레이터"* · 망이 5,761 파라미터뿐이라 전송이 계산보다 비싸다. **다만 10코어 → 24코어는 그냥 이득** |

## 권하는 순서

1. **규칙 모방 warm start** — 거의 공짜, 즉시 가능, 첫 다섯 회차 낭비 제거
2. **분기 기저정책을 규칙으로** — 코드 한 군데를 가르면 된다(본 세계 / 분기 세계 분리).
   보장이 살아난다
3. **쉬운 부하부터** — [[YR-323]] 의 창 문제와 같은 방향
4. **굴릴 결정 고르기** — 계산을 실제로 줄이는 유일한 축(10배 보고)
5. 코어 10 → 24

⚠️ 1·2 는 **계산을 안 늘리고** 결과를 바꾼다. 먼저 한다.
