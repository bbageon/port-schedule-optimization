# YR-218 · 학습 루프 구동 — 정책을 한 번도 학습시킨 적이 없다

> Epic RL · 우선순위 🔴 · 상태 🟢 **진행 중** (등록·착수 2026-08-23)
> 선행 [[YR-215]]·[[YR-216]]·[[YR-217]] ✅ · 후행 [[YR-205]] → [[YR-210]]

## 1. 무엇을 하는 작업인가 — 한 줄

부품은 다 있는데 **돌리는 코드가 없다.** 에피소드 → 라벨 → 망 갱신 → 반복.

| 있는 것 | 없는 것 |
|---|---|
| 교사([[YR-204]]) — 라벨을 만든다 | **회차를 반복하는 루프** |
| `LabelCollector` — 라벨을 모은다 | 회차 간 상태 관리(체크포인트·탐색 어닐링) |
| `StudentTrainer` — 두 망을 민다 | 수렴 판단·중단 조건 |

## 2. 왜 지금인가

**지금까지 낸 모든 수치는 무작위 초기화 망이다.** 이게 없으면 [[YR-210]]·[[YR-211]]·
[[YR-213]] 판정이 전부 무의미하다 — 학습 안 된 정책을 대조군과 견주는 셈이다.

## 3. 범위

| | 무엇 | 주의 |
|---|---|---|
| ① | 회차 루프 — 학습 부하 3,500·5,000 교대 | 7,500 은 학습에서 뺀다([[YR-217]] 결정) |
| ② | 라벨은 **회차마다 새로** 만든다 | 반사실 라벨에는 **유효기간**이 있다(04b §3) — 상대가 학습하면 내 라벨이 낡는다. v2 의 150,000 FIFO 버퍼를 쓰면 안 된다 |
| ③ | 탐색 어닐링 | σ 는 **목표 표준편차 대비 상대값**([[YR-193]]) — v2 는 절대값이라 눈금이 줄자 8.7배가 됐다 |
| ④ | 회차별 진단 | 손실 · 라벨 수 · **라벨0 비율** · 거래 수 · 공간/시간 비 |
| ⑤ | **수렴 판단 기준을 회차 전에 동결** | 보고 나서 정하면 판정이 아니다 |
| ⑥ | 표본 0 회차면 즉시 중단 | 06 하드가드. "학습이 안 된 것" 과 "거래가 없던 것" 은 다른 실패다 |

## 4. ⚠️ 비용

라벨 64건 · H=3시간 기준 **회차당 45~75분**. 20회차면 **15~25시간**.
**비판정 대역(9,900,0xx)에서만** 돈다 — 판정 대역은 [[YR-210]] 이 처음 쓴다.

회차 수를 미리 못 정하겠으면 **시간 예산으로 끊는다**(예: 20시간) — 회차 수를
결과 보고 늘리면 사전등록이 무너진다.

## 4-1. ★사전등록 — **회차 시작 전에 동결한다** (2026-08-23)

실행 설정과 판단 기준을 **돌리기 전에** 못 박는다. 결과를 보고 바꾸면 판정이 아니다.

```
회차          24
라벨/회차     40           (전수 불가 — YR-215)
시간 예산     20시간        (넘으면 그 회차에서 종료)
학습 부하     3,500 · 5,000 교대   (7,500 은 학습 제외 — YR-217 결정)
시드          9,900,6xx    (비판정 대역)
탐색 ε        0.50 → 0.05  선형 감쇠
학습 스텝     max(50, min(600, 4 × 판매표본))
작업자        16 프로세스   (사용자 결정 2026-08-23 · [[YR-219]] — 결과 불변 검증됨)
```

**작업자 수는 결과를 안 바꾼다** — 반사실 세계가 서로 독립이고 탐색이 좌표 기반이라
순서에 안 의존한다(`tests/v3/test_branch_pool.py` 가 순차 = 병렬을 검사한다).
그래서 사전등록 대상이 아니라 **실행 자원 설정**이다.

### 판단 기준 (셋 다 본다)

| | 기준 |
|---|---|
| **개선 방향** | 마지막 6회차 평균 `gap_ratio` < 첫 6회차 평균 (Φ 격차가 음수 쪽으로) |
| **라벨 건전성** | 회차 평균 `zero_label_ratio` < 30% (넘으면 [[YR-217]] 재발) |
| **중단 없음** | 판매 표본 0 회차가 없다 (있으면 즉시 실패로 기록) |

**수치 주장은 하지 않는다** — 방향만 본다. 성능 판정은 [[YR-210]] 이 새 대역에서.

### 실패해도 설정을 바꾸지 않는다

수렴이 안 되면 그 사실을 그대로 기록하고, 원인 축을 **하나만** 골라 별도 row 로 판다.
회차 수·ε·H·부하를 결과 보고 조정하면 사전등록이 무너진다.

## 5. 완료 기준

- 규칙(안 팔기) 대비 Φ 격차가 **개선 방향으로 움직인다** — 수치 주장은 하지 않는다
  (판정은 [[YR-210]] 이 새 대역에서)
- 라벨0 비율이 회차 내내 낮게 유지된다(무너지면 [[YR-217]] 재발)
- 체크포인트에서 **같은 Φ 가 재현**된다(`tests/v3/test_episode_repro.py` 계약)
- 두 망의 손실이 **같은 눈금**에서 줄어든다(06 §1-1 — 따로 학습하면 편향이 안 맞는다)

## 6. 하지 않을 것

- **판정 대역 시드를 쓰지 않는다.** 학습 중 성능 수치를 논문 주장으로 쓰지 않는다.
- 수렴이 안 된다고 H·부하·탐색을 **결과를 보고 바꾸지 않는다** — 동결 대상이다.
  안 되면 그 사실을 그대로 기록하고 원인 축을 하나 골라 별도 row 로 판다.
