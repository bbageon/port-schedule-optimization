## 무엇과 왜

원본 GateIn 요청의 실제 진입 시각과 서버 로그 시각을 구분해 보정 표본을 만든다.
원본에 실제 시각 근거가 없는 601행 중 344행이 기존 예약·통지 보정에 포함돼 있었다.
미확인 시각을 실제 도착으로 취급한 채 신경망을 비교하면 환경 오차와 학습 효과가 섞인다.

## 확인된 근거

- 대기 값은 사건 표 48,620건 모두 원본에서 확인됐다. 값의 전달 결함과 사건 시각의 뜻을 구분한다.
- 대기 메시지의 사건 시각이 빈 600건 중 2건은 별도 요청의 실제 시각으로 확인, 598건은 미확인이다.
- 대기 수가 없는 3건까지 포함하면 GateIn 전체 34,304건 중 601건이 미확인이며 후속 블록 진입·완료·출차가 없다.
- 보정 20,936건 중 344, 분포 확인 8,349건 중 143건. 기존 방문 묶기의 최종 방문에는 23건 남는다.
- 해당 보정 표본 제외 시 예약 오차 중앙값은 반입 6,053→6,055초, 반출 3,999.5→4,027초다.
- 성능 변화는 측정하지 않았다. 작은 중앙값 차이를 성능 영향이 작다는 결론으로 승계하지 않는다.

## 범위와 완료 기준

1. 현재 `authorize-next`로 현실성 보정 착수 허가를 받은 뒤 시행한다.
2. 원본 명시 사건 시각·로그 대체·다른 메시지에서 확인되는 시각을 구분한 자료 계약을 만든다.
3. 원본 실제 시각이 확인되는 표본만 쓰는 별도 보정 산출물을 만든다. 미확인 행은 보존·분리하고 임의 시각을 넣지 않는다.
4. 기존 파일과 결과는 덮어쓰지 않는다. 같은 날짜 분할·반입반출·예약 유효성·문서 연결 규칙을 유지한다.
5. 예약·통지 보정, 날짜별 물량·분별 도착 및 방문 연결에서 영향받는 범위를 명시한다.
   각 반영은 한 축씩 검증하며 데이터 제외가 기존 물량·방문 단위를 바꾸는 효과를 별도로 기록한다.
6. 같은 입력·정책을 고정한 비교가 필요하면 실행 전에 기간·표본·지표를 고정한다. PPO 재학습은 이 작업에 포함하지 않는다.
7. 익명 집계·정확 재현·기존 자료 보존·Dashboard↔증거 확인 후 완료 처리한다.
