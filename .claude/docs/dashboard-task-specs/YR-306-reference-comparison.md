## 결과를 보기 전에 고정하는 비교

1. `final`: 원 실행의 `final.pt`를 고정한다.
2. `initial`: 같은 실행의 `initial.pt`를 고정한다. 임의로 다른 초기 모델을 뽑지 않는다.
3. `rule`: 재배정하지 않는 KEEP + 기존 SF-SPT(실작업 우선, 그중 짧은 작업 우선).
   규칙은 기존 구현을 그대로 호출한다. 오류를 WAIT로 대체한 경우 비교를 실패 처리한다.
- 학습 정책 두 개는 기존 평가 경로대로 **최고 점수 행동 선택(argmax)**, 갱신 0회다.
  원 학습의 확률 추첨 운영과 다르며 결과를 보고 모드를 바꾸지 않는다.
- 규칙과의 차이는 재배정+크레인의 전체 차이다. 학습 효과 자체는 final↔initial로 구분한다.
- 동일 고정 명단에서 **30일+정리 2시간**을 각각 처음부터 돌린다. 세계 상태를 공유하지 않는다.
- 주 비교: 첫날·마지막 날을 뺀 **2~29일 달력 시간의 총비용 증가분**.
  보조: 30일+2시간 전체 비용, 날짜별 비용, 전체 트럭 소요시간, 미완료 작업·마감 초과.
- 절감액 = 비교 상대 비용 − final 비용. 절감률 = 절감액 / 비교 상대 비용 × 100.
  음수면 비용 증가다. 다른 날짜·다른 창·부분 실패 결과를 섞지 않는다.
- 한 달을 이어 돌린 자료이므로 28일을 독립 표본으로 취급한 유의성 검정을 하지 않는다.
- **학습에 사용한 명단을 다시 쓰는 진단**이다. 새 주문에서의 일반화·실항만 성능은 주장하지 않는다.
