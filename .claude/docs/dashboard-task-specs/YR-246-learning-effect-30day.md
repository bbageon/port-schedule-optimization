# YR-246 — 학습 효과를 미학습 모형과 30일로 구분한다

- **상태**: backlog 🟡 · 2026-08-28
- **분류**: Exp
- **선행 관계**: YR-244보다 먼저 판정

## 발견

새 난수시드의 7일 예비평가에서 학습 정책은 재배치 없음과 선착순 재배치를 7일 모두
이겼다(양측 부호검정 p=0.0156). 그러나 학습 전 무작위 가중치 모형과는 4승 3패,
중앙 비용 차이 −148만원, p=1.0000으로 구분되지 않았다.

그래서 현재 증거는 “정책 출력이 두 운영 기준선보다 쌌다”까지다. 반사실 라벨을 학습한
효과라고 말하려면 학습 전 모형을 안정적으로 이겨야 한다.

## 30일 판정

- 학습과 겹치지 않는 새 난수시드 9,900,950을 사용한다.
- 첫날과 마지막날은 연결용으로 두고 가운데 28일을 날별 짝비교한다.
- 학습 정책, 학습 전 모형, 재배치 없음과 유효한 규칙 기반 비교 정책을 함께 평가한다.
- 전체와 수요수준별 비용 차이·승패·부호검정을 보고한다.
- 정책별 중간 저장으로 끝난 실행을 재사용한다.

## 무효 실행

앞선 30일 평가는 학습에 사용한 달과 같은 난수계획을 사용해 자료 누출이 있었다.
해당 값은 성능 근거에서 제외한다.

## 완료 조건

- 미사용 난수시드 30일 실행이 전 정책에서 완주한다.
- 학습 전 모형 대비 결과를 주 학습효과 판정으로 보고한다.
- 결과에 따라 YR-244를 실행하거나 불필요 판정한다.
