# YR-271 — 짝비교 검정 둘을 수치와 함께 (윌콕슨에 p 가 없었다)

- **Epic**: Paper / **Priority**: 🔴 / **등록·완료일**: 2026-08-30

## 발단 (다른 세션의 지적을 사용자가 전달)

① 윌콕슨은 이름만 있고 **p 값이 하나도 없었다** — 심사자가 검증할 수 없다.
② *"같은 결론을 준다"* 는 문장은 **아무도 계산해 본 적이 없는** 주장이었다.
③ 표에 부호검정 열만 있었다. ④ 왜 검정을 둘 쓰는지 근거가 없었다.
⑤ §5.6 의 "수요수준 안에서 다시 추출" 은 이름(층화 부트스트랩)과 되뽑기 횟수가 없었다.

## 한 일

- **`scripts/v3/paired_tests.py` 신설** — 판정 산출물(`outputs/v3/judge-*/arms/*.json`)
  에서 두 검정을 **함께** 계산하고 LaTeX 행까지 출력한다. 수치를 손으로 옮기지 않는다.
  - 부호검정: 정확 이항(양측) · 윌콕슨: **`method="exact"` 를 못박음**
    (28일·동점 0이라 정확검정이 가능하다. 정규근사를 쓰면 값이 달라진다 —
    판정 대역 순이득에서 정확 0.0017 vs 근사+연속성보정 0.0026. 결론은 같다.)
  - 층화 부트스트랩: 되뽑기 **20,000회** · 시드 20260830 · 백분위 구간.
- **검증**: 현행 원고의 부호검정 값(0.185·0.036·0.004·0.013·<0.001)을 **그대로 재현**했다.
  층화 구간 [-32,-17]·비층화 [-52,-3] 도 재현(재표본 음수 비율만 99.2%→99.3%).
- **원고**(국·영문 동일): §5.3 도입부에 두 검정을 쓰는 이유를 적고, 표에 **부호순위 p 열**을
  추가했으며, 근거 없던 *"같은 결론"* 문장을 실제 계산으로 대체했다. §5.6 은 층화
  부트스트랩이라는 이름과 되뽑기 횟수를 명시했다.

## 남은 것 (다른 세션과 겹침)

- 판정 대역(9,400,000)으로 §5 전체를 옮길 때 이 표의 두 열도 함께 바뀐다. 그 대역의
  값은 이미 계산해 뒀다 — 부호검정이 무승부인데 부호순위는 유의한 행이 둘 생긴다
  (한산한 블록+칸 0.345 vs 0.004 · 순이득 0.087 vs 0.002). 그때 §5.3 문장도 "두 검정이
  갈리는 곳" 서술로 바꿔야 한다.
