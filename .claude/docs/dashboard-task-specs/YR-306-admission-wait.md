## 변경 계약

1. 출처·번호·시각이 유효한 반입은 예약 잔여와 물리 잔여가 부족해도 한 번 등록한다.
2. 원래 상자 번호·게이트/블록 도착 시각과 장부를 유지한다. 임의 삭제·시각 지연·대체 컨테이너 금지.
3. 실제 적치 공간·규격·크레인 안전 제약은 그대로다. 자리가 없으면 미완료로 기다린다.
4. 기존 비용은 진입 이후 기다리는 동안 계속 누적한다. 아직 진입하지 않은 시간을 진입 후 대기로 소급하지 않는다.
5. 반출로 자리가 생기면 기존 크레인 정책이 해당 반입을 처리할 수 있다. 강제 우선순위나 별도 정책은 넣지 않는다.
6. 공간 재배정의 후보·확정 제약은 유지한다. 재배정이 불가능해도 원래 주문은 남는다.
7. 번호 중복·잘못된 출처·시간·장부 계약 오류는 계속 명시적으로 실패시킨다.
8. 고정 물리 엔진 사본과 v3/v4는 수정하지 않는다. 새 파일을 읽는 v5 실행 경로에서만 반입 등록을 변경한다.
