## 1단계 결과 (2026-07-29 — 진단 완료)

**H-A 확정, 단 예상보다 근본적**: 12 체크포인트 전부에서 보정 오차(G−Q̂)가 실현 수익
규모와 동일(+138~+215 vs G 140~218) — **Q 가 비용-투-고를 사실상 전혀 학습하지 못함**.
행동 간 격차(M1 −0.01~−0.13)는 그 위의 미세 편향. 원인 역산: 경사 갱신 총 ~1,000회
(에피소드당 2~3회 × 500) vs 지평 150+ 결정 — 부트스트랩 전파 예산 절대 부족.
세 기각(YR-119/121/122)은 "빈 Q 위의 개입"이라 통로가 없었던 것으로 재해석.

## 2단계 사전등록 (2026-07-29 동결 — [하네스](../../../src/yard_rl/experiments/yr125_diff_credit.py) docstring 이 정본)

외부 2차 피드백의 계약 7항을 그대로 동결: ①`D(a) = C600(a) − C600(기준)`, D<0 = 행동
유리, 망은 D 직접 예측·실행 argmin D̂ ②공동 기준행동 = **결정 참여 크레인만** 전략적
WAIT(비참여·진행 중 크레인은 원래 상태 — rollout 이 이어감) ③강제·구조적 WAIT 결정
(실행가능 실작업 조합 0)은 **학습 표본 제외** ④동일 반사실 조건(같은 deepcopy 상태·
결정적 이벤트·후속 정책 SF·종료 t0+600s) ⑤창 절단은 두 rollout 공통이라 차분에서
상쇄, 창 민감도(300/1200s)는 판정 외 후속 진단 ⑥C600 은 학습 교사정보만(CTDE, YR-107 —
실행망 입력은 현재 관측뿐) ⑦판정 P1~P5 (성공 = 전부·3/3 시드):
- P1 순위 회복: YR-128 동일 재진단에서 P(cw|qw) ≥ 0.5 ∧ top-1 ≥ 0.35 ∧ ρ ≥ 0.30
  (참조 최고 0.33/0.27/0.16).
- P2 WAIT 건전화: 전략적 WAIT 선택률 < 0.479 ∧ WAIT 점유 >0.60 에피소드 0.
- P3 운영 비악화: 짝 총비용(DIFF1−WAITON) upper95 < +10 ∧ A→O upper95 < +1.0분.
- P4 풍선 없음: REPO 비중 ≤ 0.15 ∧ REPO 점유 >0.60 에피소드 0 ("WAIT 감소 + REPO 재증가
  = 유휴의 개명"이므로 실패).
- P5 guard: 완주 1.0·backlog 0·미건전 ≤ WAITON.
표적 교체는 shaping·UNSERVED·γ 제거를 포함(표적 정의의 일부) — 부가 축 아님을 고지.
학습량 규칙은 base 와 동일(max(1, n//64)/ep — 단일축 순수성). 스모크: 162표본/ep·
