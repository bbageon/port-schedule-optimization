# YR-323-b — 첫 선택 이후 판단 기준의 영향 확인

**상태**: backlog

등록: 2026-11-10. 상위 진단 [YR-323-a](YR-323-a-horizon-cause-audit.md).
조건부 성능 진단이다. 운반·예약 보정과 기록 정합이 선행한다.

## 무엇과 왜

기존 K 비교는 처음 선택만 바꾸고 이후에는 초기 정책의 기준으로 작업을 계속 골랐다.
이후에도 상황에 따라 재판단하므로 고정 작업 순서를 그대로 재생하는 방식은 아니다.
긴 창의 결과가 초기 정책의 후속 판단에 크게 의존하는지, 배포할 정책과 달라지는지가 질문이다.
K1/K6의 우열 반전만으로 이 문제를 원인으로 확정하지 않는다.

## 한 축 비교

1. 같은 스냅샷·외부 도착·첫 선택 두 개·K·비용·물리를 고정한다.
2. 첫 결정의 공동 배정 전체가 원래 비교와 일치하는 것을 확인한 뒤 후속 판단 기준만 바꾼다.
   실행 가능성과 필수 작업 등급을 우회하는 강제 선택은 사용하지 않는다.
3. 초기 정책과 사전에 고정한 학습 정책의 후속 진행을 비교한다.
   학습 정책은 평가 성적 최고점이 아니라 미리 정한 갱신 회차의 가중치로 정한다.
4. 비용 차이의 부호·크기·후속 작업 순서와 업무별 성과가 어떻게 바뀌는지 검사한다.
   양쪽에 같은 외생 입력을 사용하며 반복 실행을 독립 표본으로 세지 않는다.
5. 새 진단용 입력에서도 손실 기제가 재현될 때만 후속 정책 갱신을 보정 후보로 삼는다.

## 조건부 수정과 완료 기준

- 진단이 지지되면 라벨 생성에 쓰는 후속 정책을 직전 학습 회차로 맞추는 단일 변경을 사전등록한다.
- 자료를 모으는 상태 분포까지 함께 바꾸면 다른 실험이 된다. 첫 비교에서는 상태·대안을 고정한다.
- 한 번의 비교 쌍 안에서는 가중치를 고정하고, 양쪽에 동일한 정책을 적용한다.
- 정보를 추가하거나 학습량을 늘리는 작업은 c/d로 분리한다. 규칙과 학습 정책의 혼합 운영을 만들지 않는다.
- 라벨 변화만으로 개선을 선언하지 않는다. 새 입력에서 기존 정책 대비 성능과 본선 보호를 함께 확인한다.
- 원인이 지지되지 않으면 후속 정책 갱신을 기본값으로 넣지 않고 기각·미확정으로 닫는다.
