# YR-216 · 반사실 지평(H)과 이연 칸 지평이 어긋난다

> Epic RL · 상태 ✅ **완료(안 A 적용·측정)** 2026-08-23
> 선행 [[YR-215]] ✅ (여기서 발견) · 관련 [[YR-204]] · [[YR-190]] · 후속 [[YR-217]]

## 1. 무엇이 문제였나 — 한 줄

**2시간 뒤로 미루는 결정을 1시간짜리 창으로 채점하면 "아무 일도 안 일어났다"** 가
나온다. 라벨이 0 이라 학습은 *"그 행동은 무의미"* 로 배운다.

## 2. 원인 — 두 지평이 따로 정해졌다

| 지평 | 값 | 정한 곳 |
|---|---|---|
| 반사실 창 `H` | **1시간** | 사용자 결정 2026-08-20 (연산량 근거) |
| 이연 칸 후보 | **15·30·60·120분** | [[YR-215]] 구현 |

**공간 축은 무사**하다(효과가 즉시 나타남) — **시간 축만** 걸린다.

## 3. 고침 — 안 A: 칸을 창 안으로

```
reserve + defer ≤ t + H          (t = 결정 시각, H = 반사실 창)
```

고정 목록이 아니라 **오더마다 다르다** — 도착이 임박할수록 미룰 수 있는 폭이 준다.
격자도 창에 맞춰 **15·30·45·60분**으로 바꿨다(옛 격자를 그대로 자르면 후보가 둘로
줄어 선택지가 빈약해진다). 자격 창이 30분이라 실제로는 **15·30분이 항상 열리고
45분은 도착이 15분 이내일 때**만 열린다 — H=1시간의 논리적 귀결이다.

구현: `v3/stage/bridge.py` `_time_slots` · `run_episode(slot_mode=…)`.
`"LEGACY"` 로 옛 동작을 재현할 수 있다(전후 비교 전용).

## 4. 측정 (2026-08-23 · 부하 3,500 · 시드 9,900,201 비판정 대역 · 탐색 0.5)

같은 시드·같은 무대로 두 팔. 라벨 104건씩, 반사실 세계 261/253개.

### 4-1. 전체 라벨 0 비율

| 축 | LEGACY | HORIZON |
|---|---|---|
| **TIME(이연)** | 43건 중 **95.3%** | 35건 중 **65.7%** |
| SPACE(공간) | 10건 중 30.0% | 10건 중 **30.0%** ← 대조군, 불변 |
| KEEP | 51건 중 35.3% | 59건 중 39.0% |

### 4-2. ★구매 응답으로 가른 뒤 — 여기가 본론

`SELL ∧ REJECT` 는 **거절당하면 세상이 안 바뀌므로 라벨 0 이 정상**이다(04b §3).
정상분을 빼고 **실제로 성사된 거래**만 본다.

| | LEGACY | HORIZON |
|---|---|---|
| **TIME ∧ BUY** (성사된 이연) | 28건 중 26 = **92.9%** | 25건 중 13 = **52.0%** |
| TIME ∧ REJECT | 15건 중 15 = 100% (정상) | 10건 중 10 = 100% (정상) |
| **SPACE ∧ BUY** (성사된 공간) | 7건 중 0 = **0.0%** (중앙 7,770원) | 7건 중 0 = **0.0%** (중앙 7,947원) |
| SPACE ∧ REJECT | 3건 중 3 = 100% (정상) | 3건 중 3 = 100% (정상) |

**대비가 선명하다** — 성사된 **공간** 재배치는 라벨이 **한 건도 0 이 아닌데**,
성사된 **이연**은 거의 다 0 이었다. 축이 문제였지 구현이 문제가 아니었다.

## 5. 판정

| 기준 (착수 전 등록) | 결과 |
|---|---|
| 이연 거래 라벨 0 비율이 유의하게 감소 | **92.9% → 52.0%** (−40.9%p) ✅ |
| 공간 축 라벨 분포 불변 | 0.0% → 0.0% · 중앙 7,770 → 7,947원 ✅ |
| 표본 ≥ 200 | ❌ **라벨 104×2 = 208** (거래 표본은 축별 25~28) |
| 비판정 대역 시드 | 9,900,201 ✅ |

표본 기준은 **전체 라벨로는 넘고 축별로는 못 넘는다**(TIME∧BUY 25~28건). 방향은
분명하지만 비율의 정밀도는 낮다 — 확증은 [[YR-217]] 이 맡는다.

## 6. ⚠️ 남은 52% — 결함이 아닐 수 있다

이연은 **방문 전체를 통째로 뒤로 민다.** 그 시각에 줄이 없으면 게이트인도 게이트
아웃도 같이 밀려 **턴타임(O−A)이 그대로**다 → Φ 차이가 **정확히 0** 이 된다.
이건 측정 결함이 아니라 *"그 이연은 실제로 아무 이득도 손해도 없었다"* 는 참말이다.

부하 3,500 은 한산해서(평균 턴타임 31.7분 · 1시간 초과 7.3%) 그런 경우가 많을 수
있다. **가르는 방법**: 포화 부하(7,500 · 평균 95.8분)에서 같은 측정을 하면
줄이 있으므로 이연이 실제 효과를 내야 한다 — 거기서도 52% 면 그때는 결함이다.
→ [[YR-217]].

## 7. 부수 산출 — 탐색을 좌표 기반으로 바꿨다

측정에 탐색이 필요한데(학습 전 망은 거의 KEEP 만 고른다), 기존 탐색은 순차 난수
(`random.Random`)라 **분기 세계에서 재현되지 않았다** — 복제한 세계는 난수를
0~t 만큼 소비하지 않아 factual 가지가 다른 탐색을 한다. 동일성 불변식이 깨진다.
(탐색을 끄면 안 터졌는데, 그건 문제가 없어서가 아니라 난수를 안 뽑아서였다.)

`v3/actors/explore.py` — `u = hash(시드, docKey, 시각, 태그)`. 같은 결정이면 언제
어디서 물어도 같은 값이라 분기 세계도 같은 탐색을 한다.
**결과: 탐색 0.5 에서도 동일성 불변식 3/3·2/2 통과.**

## 8. 하지 않은 것

`H` 는 안 건드렸다 — 사용자 결정이고 사전등록 동결 대상이다. 안 B(H=3시간·연산량
×4.5)와 안 C(축별 H·눈금 분리)는 채택하지 않았고, 필요하면 [[YR-217]] 결과를 보고
사용자 확인을 받아 재검토한다.
