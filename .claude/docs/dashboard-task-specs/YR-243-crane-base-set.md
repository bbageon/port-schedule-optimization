# YR-243 — 크레인 바닥 6종 + 바닥×부하 매트릭스

- **상태**: done · 2026-08-28 · **분류**: Sim
- **관련**: [[YR-242]] (설계-코드 불일치) · [[YR-213]] (바닥 비교군) · [[YR-244]] (바닥별 재학습)

## 1. 무엇을 만들었나

`src/yard_rl/v3/dispatch.py` — 고전 배차 규칙 6종. 전부 **공개 정보만** 쓴다
(`USES_FUTURE_INFORMATION = False`). `v3/world/` 는 사본이라 새 파일을 못 놓아
(`test_world_clone.py` 가 "원본 없는 사본"을 잡는다) 사본 **밖**에 두었다.

| 바닥 | 순서 기준 |
|---|---|
| `SF_SPT` | 소요시간 (현행) |
| `SPT` | 소요시간 — **`SF_SPT` 와 원 단위까지 같은 값**(실측) |
| `FIFO` · `LIFO` | 통지 시각 오름/내림 |
| `NEAREST` | 갠트리 이동거리 |
| `LWKR` | 누적 대기 |
| `RANDOM` | 해시 (기준 없음 — 하한) |

**공통 고정**: 여섯 다 **실작업(SERVE) 우선**. 고전 규칙은 *"어느 일감 먼저"* 만
답하고 *"일감을 할까·미리 파낼까·옮길까·쉴까"* 에는 대응물이 없다. 고정하지 않으면
60초 REPOSITION 이 300초 SERVE 를 이겨 퇴화한다([[YR-039]] 무효 사유 재현 방지).

## 2. 고친 버그 — 분기 세계가 옛 바닥을 쓸 뻔했다

`_Ctx.make_exec_policy()` 가 `SF_SPT` 로 **고정**돼 있었다. 바닥을 바꿔도 반사실
분기는 옛 바닥에서 굴러 **라벨이 다른 크레인 위에서** 만들어질 참이었다.
`_Ctx.dispatcher` 로 본 세계와 묶었다. 안 잡혔으면 바닥별 재학습이 전부 오염된다.

## 3. 매트릭스 — 순위가 부하에 따라 **완전히 뒤집힌다**

부하 5종 × 바닥 6종 · 하루씩 · `NO_REALLOC` · 시드 9,900,777.
`SPT` 는 `SF_SPT` 와 동일해 제외.

| 바닥 | 3천 | 5천 | 7천 | 12천 | 15천 |
|---|---:|---:|---:|---:|---:|
| **SF_SPT** | 1.217 | 1.246 | **1.000** | **1.000** | **1.000** |
| FIFO | 1.001 | **1.000** | 1.074 | 1.574 | 1.567 |
| LWKR | **1.000** | 1.006 | 1.038 | 1.586 | 1.575 |
| NEAREST | 1.010 | 1.021 | 1.107 | 1.558 | 1.567 |
| RANDOM | 1.113 | 1.120 | 1.105 | 1.550 | 1.524 |
| LIFO | 1.328 | 1.313 | 1.178 | 1.612 | 1.593 |

**달 기대값(30일 · 부하 추첨 가중)** — 혼잡일이 비용의 **69.5%** 를 차지한다:

```
SF_SPT 122.9억 (1.000) · RANDOM 169.3억 · FIFO 170.0억 · LWKR 170.0억 · LIFO 179.2억
```

### 왜 뒤집히나 — 미완료 대수가 답이다

```
부하 15,000 미완료:  SF_SPT 2,098  ·  FIFO 4,351  ·  LWKR 4,393
```

한산할 때는 줄이 없어 *"오래 기다린 것부터"* 가 대기를 줄인다. 혼잡할 때는 야드가
포화라 **처리량이 전부**이고, `SPT` 는 평균 체류시간을 최소화하는 고전 규칙이다.

### ⚠️ Φ 와 P90 이 어긋난다 — 논문에 적을 상충

```
부하 15,000 P90:  SF_SPT 509분  ·  FIFO 442분  ·  NEAREST 437분
```

`SF_SPT` 는 Φ(대기의 **합**)를 이기고 **꼬리는 진다** — 긴 작업이 굶는 SPT 의 대가다.

## 4. 검열 인공효과 점검 — 기각

Φ 는 창 끝에서 검열되므로(완료차 `O−A` · 미완료차 `T−A`) 일을 덜 끝낸 바닥이
싸 보일 수 있다. 부하 3,500 에서 확인한 결과 **방향이 반대**였다:

| 바닥 | Φ | 미완료 | P90 | 1h 초과 |
|---|---:|---:|---:|---:|
| LWKR | 6,022만 | 21 | 32.4분 | 1.1% |
| FIFO | 6,029만 | 20 | 32.4분 | 1.0% |
| SF_SPT | 7,330만 | 27 | 47.0분 | 3.2% |
| LIFO | 7,996만 | 33 | 49.3분 | 4.6% |

Φ · 미완료 · P90 이 **같은 순서**다. 검열 덕이면 싼 바닥의 미완료가 많아야 한다.

## 5. 판정

- **바닥을 갈지 않는다** — 달 기준으로 `SF_SPT` 가 최선이다.
- **[[YR-213]] 의 "바닥이 샌다" 우려는 기각**된다(v3 실측).
- **일반성 축이 더 중요해졌다** — 바닥에 따라 Φ 가 **1.46배**까지 벌어지고 순위까지
  뒤집힌다. 그 위에서 재배치 이득이 유지되는지가 논문의 핵심 방어선이다 → [[YR-244]].

  **취소**한다. 한산할 때만 그렇다.
