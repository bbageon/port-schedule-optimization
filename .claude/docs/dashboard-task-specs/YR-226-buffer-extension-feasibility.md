# YR-226 — 공용 외부 장치장 확장 연구의 성립조건 검토

- **Epic**: Exp / **Priority**: ⚪ / **등록일**: 2026-09-26 / **상태**: backlog
- **성격**: 조건부 후속 제안. 이번 사용자 요청은 설계 문서 개정이며 이 작업의 실행을 포함하지 않는다.
- **선행**: [YR-225 문서 개정](YR-225-buffer-design-rewrite.md).

## 무엇을 검토하는가

- 외부 장치장에서 컨테이너를 내려놓고 운송차량이 떠나는 운영 방식이 성립하는지 확인한다.
- 장치장 위치·취급 화물·장비·셔틀 차량·게이트 접수시간·수출 반입 마감·운송사 참여 조건을 확인한다.
- 터미널 밖 대기와 추가 운송을 포함한 동일 비용 경계 및 물량·차량·예약 용량 보존을 정의한다.
- 자료의 관측값·추정값·가정값을 나누고 소규모 시뮬레이션에서 검증 가능한 주장 범위를 정한다.

## 왜 필요한가

기존 블록 간 배정 변경은 외부 장치장의 추가 하역·보관·운송을 포함하지 않았다.
기존 개선율을 확장 연구의 기대 성과로 옮기기 전에 물류 흐름과 비용 경계의 타당성을 확인해야 한다.

## 착수 조건

- 기존 연구의 성능·증거 정합·현실성 판정 및 [연구 진행 규칙](../../skills/research-gates.md)에 따른 착수 가능 여부를 먼저 확인한다.
- 게이트 미통과 항목이 있으면 본 확장 제안을 우선순위로 올려 우회하지 않는다.
- 새 정책·예측모형·다중 에이전트 구조는 이 검토에 포함하지 않는다. 후속 구현은 별도 row·명세·사전등록으로 관리한다.

## 완료 기준

검증 대상·자료 충족도·공통 비용 경계·필수 제약을 문서로 확정하고, 가능한 실험과 아직 불가능한 주장을 구분한다.
현 상태는 **미착수**이며 실행 결과가 없다.
