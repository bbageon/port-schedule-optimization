# YR-325 — 배를 한 척도 못 댔는데 비용은 0.18%만 움직인다

- **상태**: backlog
- 파생: [[YR-306]] 30일 비교 분석 (2026-09-22).
- 종류: 비용식 점검. 정책을 바꾸지 않는다.

## 무엇이 문제인가

[[YR-306]] 의 학습 후 고정 팔은 **30일 동안 본선 작업을 한 건도 완료하지 못했다.**
양하 72,556건·적하 44,670건이 전부 미완으로 쌓였다. 같은 기간 규칙은 양하 71,760·
적하 44,400건을 끝냈다.

그런데 **비용에는 2,849,268,514원(전체의 0.18%)** 만 잡혔다. 비용의 99.8%는 트럭
대기비다. 즉 **정책이 배를 통째로 버려도 거의 벌을 안 받는다.**

## 왜 중요한가

강화학습은 비용이 가르쳐 주는 것만 배운다. 본선 실패가 비용에 안 보이면 정책은
본선을 포기하는 쪽으로 가도 손해를 못 느낀다. **보상이 목표를 대변하지 못하는
구조**이고, 이건 정책을 아무리 잘 최적화해도 안 고쳐진다.

## 확인할 것

1. 본선 유휴비(`vessel_idle_krw`)가 **무엇을 세고 무엇을 안 세는가.**
   미완료 본선 작업은 유휴로 잡히나, 아니면 배가 안 붙은 것으로 처리되나?
2. 30일 내내 완료 0건인데 유휴비가 28.5억에 그친 계산 경로를 따라가라.
3. 연구 설계안·구현계획서가 본선 비용을 어떻게 정의했나. 지금 구현과 어긋나나?
4. v5 서론이 "구현된 본선 유휴 집계" 라고 범위를 좁혀 적었다 — 그 한계가 이것인가?
5. 고친다면 **무대·비용식만** 고친다(연구 게이트: 시나리오 FAIL 은 정책을 안 건드린다).

## 주의

비용식을 바꾸면 **과거 판정과 비교가 끊긴다.** 바꾸기 전에 어느 판정이 승계
불가가 되는지 먼저 적어야 한다. [[YR-135]] 의 사후 비용계약 변경이 선례다.
