# YR-332-by · 실험 후 트럭과 본선 중 무엇을 먼저 할지 검토

- **상태**: backlog
- 2026-11-26 사용자 요청. [예정시각 4조건 실험](YR-332-bt-planned-times.md)이 끝난 뒤 저장 결과를 읽는 진단이다. 현재 정책으로 상황별 선택이 의미 있었는지 확인한다. 연구 게이트의 성능·현실성 판정은 선행 실험에 귀속된다.
- 네 조건의 시험 월 평가와 네 날짜의 첫 선택 대조를 모두 마친 `queue-status.json`의 `complete`를 시작 조건으로 한다. 사후 검토는 고정 실행 사본의 모델·시뮬레이터를 읽는다.

## 먼저 볼 질문

| 주장 | 대조할 기록과 판정 |
|---|---|
| 안벽에 어떤 상자가 준비됐는지에 따라 배차 이득이 달라진다 | 모형에서 결정 당시 적하·양하, 안벽 보관량, 안벽 멈춤 여부를 복원한다. 상자 필요 예정시각 추가 전후의 시험 월 성적을 나란히 적는다. 현장 선적 위치별 대체 가능 상자와 작업순서 자료가 있어야 실제 적재 제약의 효과를 판정할 수 있다. |
| 이 블록이 선박의 완료를 좌우하는 시점에 본선을 먼저 하면 배가 일찍 끝난다 | 같은 크레인이 트럭과 본선 실작업 사이에서 바뀐 사례만 직접 대조한다. 본선부터 했을 때 해당 안벽 작업 줄과 해당 배의 완료가 얼마나 당겨졌는지 본다. 작업 줄만 빨라진 사례, 같거나 오히려 늦어진 사례도 기록한다. 마지막에 끝난 줄은 사후 해석용이다. |
| 트럭의 게이트 체류시간을 알면 우선순위가 달라진다 | 선택 시점까지의 게이트·블록 경과시간과 해당 트럭의 최종 완료 차이를 남긴다. 장기 체류 곡선의 효과는 [방문당 집계·승격 해제 30일 비교](YR-332-bx-gate-age-curve.md)의 몫이다. |
| 내부 운반차의 투입·인계가 선택의 효과를 바꾼다 | 안벽 멈춤은 단서다. 운반차 배정·인계·빈차 복귀 및 시간대별 실제 투입 원장이 있어야 원인을 가를 수 있다. [자료 대조](YR-332-i-discharge-calibration.md) |
| 트럭이 몰릴 때는 지금 트럭을 먼저 처리할 가치가 커진다 | 트럭 도착 예정시각 유무의 월 결과를 비교한다. 가장 이른 도착시각 하나는 도착 대수를 담지 않는다. 시간대·블록별 통지와 실제 도착 자료가 필요하다. |
| 규칙이 작업시간을 실제 현장보다 정확하게 알아서 유리하다 | 각 작업의 배차 당시 예상시간, 장비 시작·완료 시각을 같은 건으로 연결할 때 검토한다. 이번 시험 월에서 규칙이 이겼거나 졌다는 사실로 원인을 정하지 않는다. [최단 작업 규칙 진단](YR-332-bi-short-job-rule-advantage-audit.md) |

## 수치와 해석

1. 네 조건·기존 모델·두 규칙이 받은 입력, 미완료 건수, 작업·선박 명단, 완료 원장을 대조한다. 주 비교에는 승격 없는 고전 최단을 표시한다. 기존 월과 첫 선택 실험이 사용하는 24분 승격 규칙도 실제 이름으로 표시한다.
2. 지정한 3·10·17·24일의 첫 불일치만 사용한다. 모델과 규칙의 선택 번호를 모델의 고정 재생에서 작업 종류와 연결한다. 블록·시각·양쪽 공동 배정·그때까지의 선택 지문이 같아야 한다. 불일치 없음·동일 종류 선택·복수 크레인 변경도 보존한다.
3. 두 갈래의 기존 완료 원장에서 결정 뒤 30분까지와 끝까지 누적한 트럭 총분·본선 총분을 계산한다. 같은 입력에서 규칙을 한 번 따른 갈래에서 모델을 계속 따른 갈래를 뺀다. 월 실험의 트럭 단위는 작업당이고, 본선은 한 척당이다. 30분 값은 터미널 전체에서 나타난 효과이며 학습기가 쓰는 블록별 보상과 집계 범위가 다르다.
4. 같은 크레인이 트럭과 본선 사이에서 직접 바뀐 사례에서 트럭 총분 + 67 × 본선 총분이 어느 쪽에서 줄었는지 센다. 두 방향이 모두 나오면 해당 사례에서 전환을 관찰한 것이다. 한 방향·동률·직접 사례 없음도 기록한다. 네 날짜를 전체 한 달의 효과로 확대하지 않는다.
