# YR-105-b — 상대 혼잡격차 임계 정책 최적화

## 상태

- **실행 금지 — YR-116 선결**.
- 이 문서는 사전등록 초안이다. YR-116 완료 후 코드 커밋·실현지문·표본수를 동결한 다음
  결과를 보기 전에 실행본으로 승격한다.

## 질문

현행 창중 재배정 규칙의 상대 혼잡격차 임계 `0.10`보다 트럭 비용을 더 낮추는 임계가
`0.05/0.20` 중에 있는가?

## 선결 조건

YR-116이 다음 두 계약을 코드와 종단 테스트로 닫아야 한다.

1. `actual_gate_in == 0`인 반입도 gate-in review 대상에 포함된다.
2. 간섭 교착 탈출용 1 bay `REPOSITION`이 중간 목표 집합뿐 아니라 최종 후보까지 살아남는다.

YR-116 수정 후 현행 `0.10`의 YR-113 방향성이 뒤집히면 이 사전등록을 재검토하고 실행하지
않는다. 선결 evidence 커밋을 이 문서에 박제하기 전에는 pilot도 열지 않는다.

## 단일 변경축

다음 식의 `τ_gap` 하나만 바꾼다.

```text
gap = C_zero(source) - C_zero(destination)
TRANSFER iff gap >= τ_gap
```

| arm | `τ_gap` | 뜻 |
|---|---:|---|
| AGGRESSIVE | 0.05 | 작은 상대 혼잡격차에도 이송 |
| BASE | 0.10 | 현행 YR-113 규칙 |
| CONSERVATIVE | 0.20 | 큰 상대 혼잡격차에서만 이송 |

`C_source >= C_HIGH` 같은 절대혼잡 AND 조건, 지속시간, 본선 필터, quote, 학습망은 넣지 않는다.
임계는 이송 건수뿐 아니라 시점·대상을 함께 바꾸므로 “순수 볼륨 효과”가 아니라
**상대 혼잡격차 임계 정책 효과**로 부른다.

## 공통 계약

- 동일 실현 안에서 세 arm 모두 같은 블록 A/B 시나리오·review epoch·정책·resolver를 쓴다.
- 정보등급은 `PRE_ADVICE`; 미래 실제값을 읽지 않는다.
- `time_contract_v2=True`, `gate_block_contract=True`.
- `vessel_deadline_achievable=True`.
- YR-112-b의 확정된 즉시 탈출 계약을 공통 적용하고 arm별 발화 수를 저장한다.
- 추가 이송주행은 `move` 채널에 계상한다.
- 실현지문으로 pilot·선택·확증·기열람 대역의 교집합 0을 강제한다.

## 추정량과 부호

기준은 항상 `τ=0.10`이다.

```text
B(τ, channel) = Cost(0.10, channel) - Cost(τ, channel)
```

`B>0`이면 후보 임계가 기준보다 비용을 줄였다는 뜻이다.

- **1차 채널**: `truck` 정규화 비용.
- **부지표**: `total`, `vessel`, `move`, A→O, B→C, berth minutes.
- **조작 확인**: 이송 수·방향·시점. 성공 지표로 쓰지 않는다.
- 관심효과: truck `δ=3`, vessel·total `δ=10`, move `δ=1`.
- 모든 δ는 실자료 SLA가 아닌 assumed 연구 기준이라고 표시한다.

## 신규 pilot과 표본수

1. 임계 격자와 코드를 먼저 동결한다.
2. 신규 pilot `n=16`을 세 arm 모두에서 실행한다.
3. pilot 평균은 arm 선택에 쓰지 않고, 다음 세 truck 차이의 표준편차만 쓴다.
   - `0.05 vs 0.10`
   - `0.20 vs 0.10`
   - `0.05 vs 0.20`
4. 각 차이에 대해 정확한 t 분포와 pilot 표준편차의 80% 상측한계를 사용해
   `δ=3`, power 0.80의 필요 표본수를 계산한다.
5. `N_select = max(24, 세 필요 표본수)`.
6. `N_confirm = 2 × N_select`.
7. 계획 표본에서 세 차이 모두 `MDE80 <= 3`인지 검사한다.

pilot 실현지문은 이후 대역에서 제외한다. 결과 평균을 본 뒤 표본을 추가하는 post-hoc
top-up은 금지한다. 선택 전 누출을 막기 위해 pilot 산출물·콘솔에는 arm별 평균·CI·raw row를
남기지 않고 세 쌍의 표준편차·상측한계·필요 표본수·guard·지문만 봉인해 저장한다.

## 선택 대역

- 세 arm을 모두 실행하지만 **순위 선정만** 한다. 선택 p-value는 연구 결론으로 쓰지 않는다.
- 평균 truck 비용이 가장 낮은 arm을 `τ*`로 선택한다.
- 후보 `0.05/0.20`의 평균 편익이 0 이하이거나 `0.10`이 최저이면 `NO_CANDIDATE`로 종료한다.
- 동률은 현행 `0.10`을 유지한다.
- `τ*`, `N_confirm`, 정확한 seed 목록·실현지문 digest, 판정식을 별도 커밋으로 동결한 뒤에만
  확증 대역을 연다.

## 독립 확증

- 확증에서는 동결한 `τ*`와 현행 `0.10` 두 arm만 실행하며, 승자를 바꾸지 않는다.
- 다른 후보로 갈아타기, 선택·확증 pooling, 실패 후 임계 재조정은 금지한다.
- 1차 확증 비교는 동결된 `τ* vs 0.10` 한 건이므로 다중비교 보정을 하지 않는다.
- “검사한 격자에서 최고”라고 주장하려면 1차 통과 후 남은 arm을 별도 고정순서로 추가 검정한다.
  이 추가 검정을 통과하지 않으면 “현행 0.10보다 우수”까지만 주장한다.

## 채택·라벨 규칙

편익 `B_truck`의 확증 신뢰구간을 기준으로 판정한다.

| 라벨 | 조건 |
|---|---|
| `INVALID` | guard·지문·재현·후보계약 중 하나라도 실패 |
| `NO_CANDIDATE` | 선택 대역에서 현행 0.10을 이길 후보가 없음 |
| `PRACTICAL_IMPROVEMENT` | 95% CI 하한 `>3`이고 본선·총비용 비열등 통과 |
| `SMALL_CONFIRMED` | 95% CI 하한 `>0`이나 `>3`은 아님 |
| `EQUIVALENT` | 0 포함, 90% CI가 `±3` 안에 들어감 |
| `INCONCLUSIVE` | 0 포함, TOST도 실패 |
| `HARMFUL` | 95% CI 상한 `<0` |
| `TRADEOFF_FAIL` | truck은 통과했으나 본선 또는 총비용 비열등 실패 |

본선·총비용 비열등은 동일 부호의 편익 하한이 각각 `>-10`이어야 한다. 두 guard를 모두
통과해야 하므로 교집합-합집합 판정으로 운용한다. 총비용 **개선** 주장은 YR-115의 몫이며,
여기서는 비열등 보호만 한다.

## 하드 guard와 산출물

- 전 arm 완주율 1.0, backlog 0, 정책 예외 0, 물리 위반 0.
- `NOTRANSFER`가 아니라 각 임계 arm의 실제 이송 수와 reject 수를 저장한다.
- arm별 채널 합이 terminal total과 일치해야 한다.
- 실행 코드는 clean commit이어야 하며 결과에 정확한 commit SHA를 기록한다.
- 결과 파일: pilot power note, 선택 rows/verdict, 승자 동결문, 확증 rows/verdict.

## 주장 범위

통과해도 문헌 보정 비대칭 2블록 조건에서 검사한 세 임계 중 현행보다 나은 임계를 찾았다는
뜻이다. 연속 임계의 전역최적, 순수 이송량 인과효과, 다른 터미널 일반화는 주장하지 않는다.
