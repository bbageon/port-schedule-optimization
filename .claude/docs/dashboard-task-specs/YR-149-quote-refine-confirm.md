# YR-149 — 견적 정밀화(수신 파급) → 이송 효과 확증

## 무엇을 왜
YR-133 1차는 블록 간 견적·원자 확정 배선을 실증(기능 가드 6종 통과·이송 14건)했으나,
확정 이송의 예측 순이득(전부 +0.005~0.31)과 실현 쌍 차이(−15.6~+19.1·sd 9.4)의 괴리가
커서 **"이송이 이득" 주장은 미확증**이다. 원인 후보 = 작업 1건 국소 견적이 수신 블록
기존 작업 지연·후속 상호작용 파급을 보지 못함(1차 명시 한계).

## 단계 (각각 단일축·착수 시 동결)
1. **원장 사후 대조**: 1차 확정 14건의 예측 vs 실현 기여 분해(원자료 pilot.json 보존) —
   괴리의 소재(수신 파급 vs 예측 편향 vs 잡음) 특정.
2. **InBurden 정밀화**: 수신 블록 기존 대기 트럭들의 지연 증가 예측 항 추가(공개 정보
   큐 proxy — 실현 미열람 유지). 보정 파일럿 재실행(기능 가드 + 분산 봉인).
3. **효과 확증**: 정밀화판 분산으로 표본 산정(δ 사전 동결·초기화 개념 없음 — 쌍 단위)·
   신규 대역·혼합/부트스트랩 통계·top-up 금지.
