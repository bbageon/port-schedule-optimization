# YR-266 — 패널 이름을 그림 아래로, 위는 범례 자리

- **Epic**: Paper / **Priority**: 🟠 / **등록·완료일**: 2026-08-30

## 발단

사용자 지적: *"표 제목이 범례 아래에 있는데 표 제목은 표 아래에 두고 표 위에 범례가
표현되게 해줘"* — 그림 머리에 범례와 패널 이름이 두 줄로 쌓여 무거웠다.

## 편집 계약

- `figstyle.panel()` **한 곳만** 고친다 — 네 그림이 같이 따라오게 (집 규칙의 목적).
- 자리는 subfigure 규약과 같다: 눈금 → 축 이름 → **패널 이름** → LaTeX 캡션.
- `ax.text` 로 얹지 않는다 — 배치기(constrained layout)가 자리를 예약하지 않아
  아래 그림·캡션과 겹칠 수 있다. **축 이름에 줄을 덧붙여** 자리를 예약시킨다.
- 그 결과 `panel()` 은 `set_xlabel` **뒤에** 불러야 한다 (먼저 부르면 덮인다).
- 아랫줄이 늘어난 만큼 그림 키를 준다: 수요 2.35→2.52 · 분해 2.70→2.86 ·
  짝비교 2.45→2.62 · 학습곡선 3.95→4.30(패널 셋이라 `hspace` 0.06→0.10).
- 그리는 자료·수치는 건드리지 않는다.

## 완료 조건

- 네 그림 모두 범례가 위, 패널 이름이 각 패널 **아래**.
- 국·영문 각 2회 빌드 — Overfull hbox 0 · 오류 0.
- 그림 일곱 건이 모두 캡션과 같은 쪽 (자동 대조).
