# YR-189 — 판매 축을 Q 채점으로 전환 (C안)

- **Epic**: RL / **Priority**: 🔴 / **등록일**: 2026-08-18 / **상태**: done — **판정 WORSE**
- **3대 게이트 보정 대상**: `performance`
- **1줄**: 확률을 배우던 것을 **비용을 배우게** 바꾸고, **배정기의 공식을 그 망으로**
  대체한다. 크레인은 손대지 않는다.

## 0. 왜 이 안인가 (A안·B안 대비)

| 안 | 무엇 | 비용 | 결함 소멸 | 넘을 확률 |
|---|---|---|---|---|
| A 완전 통합 | 크레인+판매 한 망 | 큼 (동결 해제·행 형식 통일·조합 폭발) | ✅ | 30~40% |
| **C 판매 축만 Q** | 판매+배정기만 | **중간** | ✅ | **35~45%** |
| B 미세 수정 | "왜 절반만 파나"만 | 작음 | ❌ | 15~20% |

**A 가 추가로 사는 것은 "크레인이 판매를 아는 협조"인데 크레인 축은 여유가
없다** — 오라클 상한 +0.18분/대(2026-07-15·07-19 두 번 확증) vs 판매 축 실측
−2.6분/대. A 의 실측 근거 있는 이득은 전부 C 에 들어 있다.

## 1. 무엇을 바꾸나 — 네 곳

### ① 출력의 뜻 (표면)

```python
# 지금
logits = actor(rows);  a = argmax(logits)      # "얼마나 선호하나"
# 바꾼 뒤
q = Q(rows);           a = argmin(q)           # "비용이 얼마나 드나"
```

망 구조(`Linear→ReLU→Linear→ReLU→점수`)와 입력 행 형식은 **그대로**다.
바뀌는 것은 **숫자의 뜻**과 **KEEP 행의 지위**다 — KEEP = **0 고정 기준점**.

### ② 학습 목표 (본체)

```python
# 지금 (PPO)
pi_loss = −min(ratio·adv, clip(ratio)·adv);  v_loss = (critic(ci) − ret)²
# 바꾼 뒤 (Q 회귀)
q_loss  = (Q(선택한 행) − (−차분신용))²
```

**`TransferCritic` 이 사라진다.** actor+critic 두 망 → **Q 하나**.
→ [[YR-185]] 가 진단한 **critic 붕괴가 구조적으로 재발 불가**(붕괴할 critic 없음).

### ③ 배정기 채점 (결함 제거)

```python
# 지금 (sell_review._coord_costs)
add = cost_given_queue(mbt.blocks[dst], …)      # 공식
# 바꾼 뒤
q(행(src, jid, dst, 가상상태))                   # 같은 Q망
```

**[[YR-175]](부호 오류)·[[YR-177]](기준 불일치)의 발생 지점이 사라진다.**
자가 하나뿐이므로 "다른 자로 잰다"가 성립 불가.

### ④ 데이터 재사용

on-policy(쓰고 버림) → **off-policy 재생 버퍼**. 40 에피소드 = 10시간인
실행 비용 구조에서 실질적으로 가장 큰 이득.

## 2. 안 바꾸는 것

망 구조 · 입력 행 형식 · **크레인 정책(동결 유지)** · 배정기의 매칭·용량·
원자 확정 · 장부·소유권 · `realized_credit` 계산.

## 3. 최종 아키텍처

```
[크레인 Q망] ← 동결(옛 무대)
   블록 안 두 크레인 조합 채점 → argmin → 실행
        ↕ (세계를 통해서만 상호작용)
[판매 Q망] ← 학습
   60초마다: 블록이 후보 채점 → 가장 싼 1건 제안
        ↓
   [배정기] 같은 Q망으로 재채점(가상 상태) · 탐욕 매칭 · 용량 · 원자 확정

목표: Q(행) ← −(차분 신용)     선택: argmin     "아무것도 안 함" = 0
```

## 4. 사라지는 것

`TransferCritic` · PPO 손실·이점 정규화 · **BUY 견적망** · 배정기 비용 공식 ·
확률 추첨 · **보상 0 이 91%**(KEEP 은 기준점이지 데이터가 아님).

## 5. 문헌 정렬 (반드시 인용 — 우리가 만든 것이 아니다)

차분 신용 = **Wolpert & Tumer (2002)**, Tumer & Agogino (2007) ·
반사실 기준선 신경망화 = **COMA** (Foerster et al., AAAI 2018) ·
조합 행동공간 = 후보 채점 + argmin 계열.

기여점은 "**기본 행동(KEEP/WAIT)이 문제 구조상 자연히 정해지는 사례**" —
문헌이 지적하는 두 한계(시뮬레이터 필요·기본 행동 선택의 모호함)를 이 문제가
자연히 피한다. **문헌이 지적하는 위험**(최고 후보 하나만 쓰면 채점 잡음에
민감)은 판정에서 **실제로 실현됐다** → §11.

## 6. 오더 데이터 정합 — [[YR-187]] 을 따른다

입력 행의 후보 특징은 **[[YR-187]] A단계 스키마**에 맞춘다. 특히:

| 지금 행 특징 | YR-187 이후 |

| `arrival_s` 기반 잔여시간 | **`reserved_s`(공개) 기반** — `gate_in_s`(실현)는 정책 비가시 |
| `size_ft40` 불리언 | **`size_class` 범주형** |
| — | **예약 준수 이력**(트럭·`dispatchGroup` 단위) ← [[YR-188]] D-1, 별도 축 |

**정보 경계 유지**: 실현 시각(`gate_in_s`·`blockInTime`·`jobDoneTime`)은
**결정 시점에 존재하지 않는다**. 학습 목표(차분 신용)에는 쓰되 **입력에는
넣지 않는다** — 지금 계약과 동일.

### ★행이 좌표까지 포함한다 — 결함 소멸의 기전

행 `14 → 21`차원: 블록요약 7 + 후보 6 + **좌표 8**(구판엔 목적지가 없었다).

### ★정직한 명명 (사전등록 §2-1)

시간차 학습이 **아니다**. 라벨 `−D_i` 가 실현 손익이므로 정확히는 **문맥 밴딧
위의 비용 회귀**다. 논문에서 "Q 학습"이라 쓰지 않고 **"차분 신용 라벨을 쓰는
조합 행동공간 비용 회귀"** 로 쓴다. 대가 = 먼 미래를 스스로 학습하지 못한다.

### ★논문 §4(최적화 대상 ≠ 배포 대상)가 구조적으로 닫힌다

PPO 는 **추첨 정책**의 기대수익을 최적화하는데 배포는 **최선 고르기**였다
(교정 후 −129.15 vs +39.47로 부호까지 달랐다). Q 전환에는 추첨 정책이 없다 —
학습 목표가 곧 배포 시 argmin 이 읽는 값이다. **판정 결과와 무관한 설계 사실.**

### 탐색 두 축 (학습 중에만 · 평가는 ε=0·σ=0)

제안 ε=0.15(어느 **작업**을 낼까) · 좌표 σ=0.20(**어디로/언제** 팔까).
σ 를 **절대값으로 고정**한 것이 설계 오류였다 — 목표 눈금이 줄어 상대 강도가
1.8배 → **8.7배**가 됐다(→ [[YR-193]]).

## 11. 판정 결과 (2026-08-19) — **WORSE**

**주판정 `q − greedy` = +211.41** · 95% CI [+167.79, +255.02] · t=+10.32.
**16일 중 q 가 이긴 날 0.** 학습은 규칙을 넘지 못했고, `q − K` = +86.32 로
**안 팔기보다도 나쁘다**. 하드가드 4종 전부 통과.

원인은 **문턱 부재** — 학습 정책이 규칙보다 2.26배 많이 판다(2,167 vs 957건).
`Q < 0` 은 예측 오차만큼 과잉 판매를 만든다. 규칙의 `gain_margin` 에 해당하는
안전 여유가 Q 설계에 없다. 후속 [[YR-195]].

설계 주장 §2(세 결함 소멸)는 **성립했다** — 라벨 99.3% · 축 격차 정확 학습 ·
critic 없음. **결함은 사라졌는데 성능이 안 따라왔다.**
