## 설계 ([하네스](../../../src/yard_rl/experiments/yr131_k_candidates.py) docstring 이 동결 정본)

- **131-a**: 변경 = 상태당 **전 후보 라벨** 사용(YR-129 데이터셋 live 2.1만~4.1만/시드,
  신규 rollout 0). 유지 = Huber 회귀·fresh init·하이퍼·선택지표 val Pearson r (YR-130
  프로토콜 그대로 — 유일 차이 = 표본 구성). 질문: 후보를 여러 개 보여주는 것만으로
  일반화·순위가 사는가?
- **131-b** (a 가 J1 실패 시에만): 데이터·망 동일, 변경 = Huber → 결정 내 pairwise
  margin 순위손실(margin 0.01·잡음쌍 제외 0.01, 동결). 선택지표 = val 결정 내 ρ
  (손실 교체에 수반되는 프로토콜 정의로 고지). 질문: 순서를 직접 가르쳐야 하는가?
- **J1 (동결, 3/3 시드 held-out=신규 대역)**: Pearson r ≥ 0.5 ∧ 결정 내 ρ ≥ 0.30 ∧
  top-1 ≥ 0.35 (참조 YR-130: r 0.29~0.39·ρ ≈0·top-1 0.16~0.18). 실행-후보-한정 r 을
  비교 다리로 병기.
- **관찰 부속**: 혼잡도(창 종료 미완 수) 5분위 × {평균|D|·표준편차·결정 내 범위·최대
  개선량} — "혼잡 시 600s 변별 신호 소멸" 가설(YR-129 사후)의 직접 검증. 저장 라벨만.
- a 통과 → b 생략, 사다리 5단(종결 잔여 축). a·b 모두 실패 → 사다리 4단(동시/비동기
