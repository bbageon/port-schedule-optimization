## 무엇과 왜

작업 후보의 개수 제한은 없애도, 신경망의 8번째 입력은 `min(작업 수/18, 1)`이다.
15,000건 조건에서 수정 입력의 59.51%가 상한에 도달했다. 18개와 200개를 구별하지 못한다.
근거: `outputs/reports/yr332_six_steps/stage3/campaign.json`, `stage3/report.md`.

## 단일축 범위

원래 개수도 보존하고, 기존 눈금과 상한 없이 개수 차이를 전달하는 눈금을 비교한다.
새 상태 칸·작업 종류·비용·후보·교사 지평을 함께 바꾸지 않는다.
눈금을 정할 때 평가 입력을 사용하지 않는다. 같은 초기 모델·자료·갱신 예산으로 재학습한다.
목표는 입력 변화 자체가 아니라 체류·미완료·본선 완료의 개선이다.
현재 6단계 결과와 현실 보정 선결 항목을 먼저 정리한 뒤 착수 여부를 판단한다.

## 사용자 지시와 실행 범위 — 2026-11-07

개선 기법·A/B 비교의 의미를 설명한 뒤 사용자가 “응 진행해줘”라고 지시했다.
확인된 입력 상한을 첫 단일축 진단으로 진행한다. 기존 현실성 미통과는 해소된 것으로 바꾸지 않는다.
