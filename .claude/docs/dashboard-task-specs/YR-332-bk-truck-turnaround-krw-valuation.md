# 트럭 턴타임을 원화로 평가하는 기준 검증

- YR-332-bk는 트럭 비용 검증 과제다. 상위 [[YR-332]]. 2026-11-23 설계 등록, 검증은 backlog.
- 하루를 넘기는 [기존 30일 비교](../../../outputs/reports/yr332_month_cranes/README.md)에서 학습 정책과 규칙이 부담시키는 트럭 비용의 의미를 확인한다.
- 후속 사용자 결정으로 안전운임은 정책이 줄인 트럭 시간의 경제적 해석에 쓴다. 현재 학습·선택 기준은 [트럭·본선 공동 보상](YR-332-bl-joint-turnaround-reward.md)이다. 3·4절의 총비용 최소화안은 이전 설계 경위로 보존한다.

## 1. 안전운임으로 설명할 수 있는 금액

트럭 턴타임은 게이트에 들어와 그 방문의 마지막 야드 작업이 끝날 때까지다. 이동·대기·작업을 모두 포함하고 자정을 지나도 이어 잰다.
고시상 부두 대기는 화주 또는 부두 운영사가 요청한 도착시각부터 상·하차와 송장 발급이 모두 끝난 시각까지다.
수출입 컨테이너의 항만 부두 대기 발생 시 20·40피트 공통으로 1시간 초과분 30분당 20,000원이다.
운수사업자가 차주에게 먼저 지급하고 원인제공자에게 청구한다. 증빙은 대기시간 확인서나 부두 입·출입 카드 내역 등이다.
고시 기준으로 정확히 60·90·120분이면 각각 0·20,000·40,000원이다. 30분 미만 잔여분의 정산 관행은 청구 자료에서 확인한다. [국토교통부 고시 제2026-595호 별표 1 제24호, 2026-11-01 시행](https://www.law.go.kr/LSW/flDownload.do?flSeq=171123011#page=25)

방문별로 도착요청·게이트 진입·최종 야드 작업 완료·송장 포함 완료의 네 시각을 대조한다. 예약·통지 시각을 도착요청으로 쓰려면 두 사건이 같다는 근거가 필요하다.
방문에 작업이 여러 건이면 대기료는 해당 부두 대기 건을 한 번 센다. 청구·지급 금액, 부담 주체, 자료 누락률을 따로 집계한다.
두 기준의 시각 차이가 확인된 표본에서 턴타임별 예상 대기료와 그중 터미널 귀책 금액을 각각 추정한다. 별도 날짜의 실제 청구 건수·금액과 대조한다.
정산 시각이 없는 합성 기록에서 처음 쓸 근사식은 `20,000원 × max(턴타임(분) − 60, 0) / 30`이다.
이는 게이트·완료 시각을 대신 쓰고 초과분을 분 단위로 나눈 비교 지표다. 실제 지급액과 터미널 귀책액은 각각 증빙이 있는 범위만 보고한다.

## 2. 지연이 늘 때 차주가 겪는 부담

한국해양수산개발원(2022)은 주로 부산항에서 일하는 외부트럭 기사 111명에게 설문해 유효 응답 74개를 얻었다.
추가 대기 30·60·120분에 원한 최소 보상액은 2022년 금액으로 각각 6,243·12,878·25,811원이다.
첫 추가 1시간 12,878원과 그다음 1시간 12,933원이 비슷하다. 장시간일수록 누적 부담이 커진다는 근거이며, 한 시간마다 단가를 두 배로 높일 근거는 약하다. [한국해양수산개발원 연구, 104쪽 및 112쪽 표 4-12](https://www.nkis.re.kr/subject_view1.do?otpId=OTP_0000000000011141&otpSeq=0&popup=P)

반입·반출과 방문 작업 구성별로 평소 정상 소요시간을 별도 운영 자료에서 정한다. 시험 전에 고정하고 지연이 실제 대기였는지 작업 기록으로 확인한다.
그 기준을 넘긴 추가 대기 0~120분에서 설문의 10분 간격 누적 보상액을 직선으로 연결해 정책 순위가 달라지는지 확인한다. 추가 대기 0분은 0원으로 둔다.
120분을 벗어난 방문 수와 시간을 따로 보고한다. 마지막 구간의 기울기를 연장한 결과는 외삽 가정으로 표시한다. 2026년 원화 수준을 비교할 때에는 가격 기준과 환산 근거를 표시한다.
더 가파른 곡선은 다음 배차 취소·재배정, 초과근무, 추가 연료 기록으로 검증한다. 유사한 일정·혼잡도에서 지연으로 증가한 배차 상실 확률에 그 운송의 순수익(운임에서 피한 비용을 뺀 금액)을 곱한다.
증빙된 추가 지출을 합칠 때 같은 시간·연료가 두 번 잡히는지 확인한다. 설문 보상과 대기료는 같은 방문을 다른 관점에서 평가하므로 두 금액을 더하지 않는다.

## 3. 기존 제안의 비교 절차

1. 입력 기록에서 복원 가능한 방문, 네 시각과 실제 청구의 연결률을 확인한다. 방문을 복원할 수 없는 자료는 작업당 근사액으로 표시하고 청구액 추정에서 제외한다.
2. 산식·가격 기준·자료 누락 처리와 비교 기간을 정책 성적을 보기 전에 고정한다. 같은 30일의 저장된 작업 기록에 적용하고 월말 진입 방문의 마지막 완료까지 추적한다.
3. 안전운임 기준 트럭 비용, 본선 작업 기간 비용, 장비 비용과 합계를 제시한다. 합계의 단위는 모형 환산원이다. 터미널의 실제 지출은 귀책과 청구가 확인된 금액으로 별도 제시한다.
4. 평균 턴타임과 오래 걸린 쪽 상위 10%의 경계 시간, 60분 초과 방문 비율, 미완료 수도 비교한다. 비용이 줄어도 평균이 악화되면 두 목표를 모두 달성했다고 판정할 수 없다.
5. 비용 정의만 바꾼 효과를 보도록 같은 장비·배정 조건과 같은 모델을 쓴다. 블록 대기 24분 우선 조건은 비용 기준에서 제외한다. 한 달의 순위는 해당 입력에 한해 해석한다.
6. 이후 학습에 반영할 때는 현장 자료로 선택한 방문당 누적 비용을 쓴다. 결정 사이에 터미널 안의 각 트럭에 새로 생긴 비용만 합산해, 한 방문의 전체 누계가 평가 원장과 일치하는지 확인한다.

## 4. 기존 제안의 총비용 선택 기준

- 트럭 한 방문의 턴타임이 60분 이하면 시간 환산비용은 0원이다. 그 뒤 30분마다 20,000원에 해당하는 기울기로 누적한다. 예를 들어 60·90·120분의 환산액은 0·20,000·40,000원이다. 방문별로 계산한 뒤 월 합계를 낸다.
- 월 총비용은 트럭별 환산액 합계, 기항별 본선 작업시간 비용(하역 가능 시각에서 마지막 하역 완료까지), 크레인 빈 이동 비용, 재조작 비용의 합이다. 이번 비교에서는 기존 본선·장비 단가를 사용한다. 실제 청구액은 이 합계에 더하지 않는다.
- 평균 턴타임은 분 단위로 정책 선택에 직접 넣는다. 동일 입력·동일 진입 방문에서 기존에 저장한 모델의 평균 턴타임을 상한으로 삼고, 이를 충족하는 정책 중 월 총비용이 가장 낮은 정책을 고른다. 총비용이 같으면 평균 턴타임이 더 짧은 쪽을 고른다.
- 90분에서 60분으로 줄면 방문당 환산비용이 20,000원 줄고, 60분에서 30분으로 줄면 비용은 같아도 월평균 턴타임은 개선된다. 규칙별 비용 차이와 시간 차이를 원자료 단위로 병기한다. 한 달에서 기존 모델의 평균을 지켰다는 이유만으로 규칙보다 빠르다고 판정하지 않는다.
- 미완료·방문 연결 누락으로 같은 방문 집단의 최종 시간을 비교할 수 없으면 포함 건수와 잔여를 밝히고 전체 순위는 보류한다. 향후 재학습 시점에는 각 결정부터 이후 완료까지의 누적 비용을 학습 목표에 포함하고, 평가용 달은 모델 선택에 사용하지 않는다.
