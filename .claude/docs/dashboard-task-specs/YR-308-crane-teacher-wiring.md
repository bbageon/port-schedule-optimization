# YR-308 — 크레인 교사 **배선** (부품 → 작동)

## 무엇을 하는 작업인가

[[YR-305]] 가 만든 크레인 학습 부품(특징·망·정책·교사·학습기)을 **실제로 돌아가게**
연결했다. 그전까지는 부품 시험이 전부 통과하는데도 **라벨이 한 건도 안 나왔다.**

## 무엇을 연결했나

| | 무엇 | 어디 |
|---|---|---|
| ① | 크레인 결정 **훅** — 결정 직후·반영 직전에 불린다 | `stage/episode.py::_rule_policy(on_crane=)` |
| ② | 결정 하나에서 **세계 둘** 굴리기 (사실 · 차점자 강제) | `crane/rollout.py` |
| ③ | 예산으로 표본하고 라벨 조립 | `crane/collect.py` |
| ④ | 하루 끝 학습 + 회차 반복 | `crane/train.py` |
| ⑤ | 실행 진입점 | `crane/__main__.py` |

    PYTHONPATH=src python -m yard_rl.v4.crane --iters 20 --workers 20

## ★ 배선하며 찾은 결함 셋 — 전부 "부품 시험" 으로는 안 잡힌다

### ① 분기 세계가 **딴 정책**으로 굴렀다 (치명)

`run_episode` 가 `dispatcher` 를 `_Ctx` 에 **안 넘기고 있었다.** `_Ctx` 머리말은
*"분기 세계도 같은 크레인 바닥을 써야 라벨이 정직하다"* 고 적어 두었는데, 그 계약이
코드에서 빠져 있어 분기 세계가 늘 기본값 `SF_SPT` 로 돌았다.

실측(부하 300): 사실 가지가 본 세계와 다른 일감을 골라 **표본 6건 전부 폐기**.
순위 튜플의 길이가 달라(3칸 vs 5칸) 두 정책이 섞였음이 드러났다.

> ⚠️ **v3(논문)에도 같은 구멍이 있지만 결과에는 영향이 없다.** 판정 경로는 배차를
> 넘기되 교사(`budget`)를 안 붙여 분기 세계가 **아예 안 뜨고**, 학습 경로는 배차를
> 기본값 `SF_SPT` 로 쓴다. 둘이 겹친 실행이 없어 이 값이 읽힌 적이 없다.

### ② 크레인 망이 **시드에 안 묶였다** ([[YR-304]] 재발)

본 세계와 분기 세계가 각자 `CraneNet()` 을 새로 만들어 **서로 다른 무작위 정책**이
됐다. `run_episode` 가 `seed+2` 로 망을 만들어 양쪽에 같은 것을 넘기게 고쳤다.

### ③ 예산이 **못 쓰는 결정**에 다 나갔다

크레인 결정은 셋 중 둘이 라벨이 안 된다 — 실측(부하 300 · 하루 3,920 결정×크레인):

    WAIT 33.0%   실행가능 일감 하나뿐 37.0%   ← 합쳐서 70%
    쓸 수 있음 29.5%   필수등급 불일치 0.5%

*"모든 결정을 세고 stride 마다 하나"* 를 그대로 쓰니 예산 4건이 전부 못 쓰는 결정에
나갔다. **먼저 쓸 수 있는지 보고 그 다음에 예산을 쓴다** 로 고쳤다(판정은 후보 목록을
훑는 것뿐이라 싸다 — 복제·특징 계산은 뽑힌 뒤에만 한다).

## 재배정층과 무엇이 다른가

| | 재배정층 | 크레인층 |
|---|---|---|
| 분기점 | review epoch (60초 격자 · 전 블록 park) | **크레인 결정 시각** (한 블록만 결정 중) |
| 세계 수 | 셋 (사실·판매대안·구매대안) | **둘** (고른 것·차점자) |
| 분기 절차 | epoch 을 손으로 연다 | **열린 결정을 손으로 한 번 돌린다** |

분기 절차가 다른 이유: 스냅샷을 뜰 때 그 블록은 이미 `_pending`(결정을 열어 둔 상태)
이라 복제본을 그냥 `run()` 하면 *"직전 결정 미해소"* 로 엔진이 거절한다.

## 회계 — 버린 것까지 남긴다

`seen / usable / sampled / no_alt / no_pick / factual_mismatch / force_failed / labeled`.
라벨 수만 보고하면 *"64건 뽑았다"* 가 실제로 12건이어도 안 보인다.

`force_failed` 는 강제가 안 먹은 경우다 — resolver 가 `mandatory` 를 어떤 선호보다
앞에 두므로(엔진 계약) 필수 작업이 걸리면 차점자를 강제해도 필수가 이긴다.
그런 세계는 **버린다** — 안 버리면 Φ_alt 가 Φ_factual 과 같아져
*"이 선택은 무의미"* 를 배운다.

## 실증 — 연기시험 (부하 300 · 창 30분 · 예산 6)

    고침 전:  표본 6 → 사실불일치 4 · 강제실패 2 · **라벨 0건**
    고침 후:  표본 6 → 사실불일치 0 · 강제실패 0 · **라벨 6건(표본 12개)**

## 남은 것

- `CRANE_ADV_SCALE` **재실측** — 지금은 재배정층에서 빌려온 잠정 100,000원이다.
  연기시험의 목표 격차가 3,100원 수준이라 눈금이 30배쯤 클 가능성이 있다.
  학습기가 `median_gap_krw` 를 기록하므로 회차를 돌리면 실측치가 나온다.
- 규칙 바닥 6종 대비 판정 (SF_SPT + 고전 5종 · 날 단위 짝비교)
