### 원인 — **문턱이 없다**

학습 정책은 규칙보다 **2.26배 많이 판다** (일평균 2,167 vs 957건).

`Q < 0` 은 "기대 비용이 0보다 작으면 판다"인데, 예측에 오차가 있으면
**오차 때문에 0 아래로 내려간 건들이 전부 팔린다.** 모델 오차는 신호의 **82%**
(RMSE 0.019 / 목표RMS 0.023)였다. 이 문턱은 사실상 동전 던지기에 가깝고,
잘못 판 건의 손해가 잘 판 건의 이득보다 크다.

규칙의 `gain_margin`(κ_T 1σ)은 **정확히 이 문제를 막는 안전 여유**다.
**Q 설계에는 그에 해당하는 것이 없다.**

→ "자를 하나로 만든다"는 성공했으나, **그 자에 눈금 오차가 있을 때 쓰는 법**을
넣지 않았다. 후속: [[YR-195]]

**편향이 진짜 이득의 16배**이고, 판 것의 **43%가 손해**였다.

**확정 실패**다. 1관문이 이미 같은 망으로 같은 계산을 했으니 되돌릴 이유가 없다.
