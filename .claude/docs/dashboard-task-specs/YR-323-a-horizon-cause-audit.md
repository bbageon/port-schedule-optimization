# YR-323-a — K가 길어질 때 학습 판단이 달라지는 원인 분해

**상태**: backlog

등록: 2026-11-10. 사용자 요청: K 비교 결과에 근거해 해야 할 작업을 정리한다.
상위 결과는 완료된 YR-323이다. 이번 등록은 실험 착수나 정책 변경을 뜻하지 않는다.

2026-11-10 후속 “확인하고 알려줘” 요청에 따라 기존 파일 점검을 수행했다.
새 실행·정책 변경은 없으며, 보정 환경의 원인 진단은 미착수라 상태는 backlog를 유지한다.

## 확인된 사실과 아직 모르는 것

- 같은 295개 선택을 K=1·2·3·6시간으로 평가했다. 전체 트럭 평균은 K1이 가장 짧았다.
- 대화 중 원자료의 결정 키·실제 작업·대안 작업을 맞춘 추가 집계에서 K1/K6 우열 반전은 87/295개다.
  두 비용 차이의 절댓값을 각각 1원보다 큰 경우로 제한해도 87개였다. 정규화 전 비교다.
- 이 반전은 긴 관측창에서 판단이 달라졌다는 증거이며, 그 판단이 틀렸다는 증거는 아니다.
- 3,500·7,500건에서는 K3, 15,000건에서는 K1의 트럭 평균이 짧았다. 전 부하 단조 악화는 아니다.
- 모델 입력·학습량은 동일하고, 자료 수집과 분기 후속 판단은 초기 정책으로 고정했다.
- 비용은 트럭·본선·이동·재취급 합계다. 트럭 평균 개선과 목적함수 개선을 구분한다.
- K6의 295쌍 중 53쌍은 환경 종료 때문에 6시간보다 짧았다. 미완료 작업도 많았다.

성능·기록 정합·현실성이 모두 통과하면 추가 가설 탐색을 멈추고 독립 확증으로 간다.
연속 30일 검증은 기존 [YR-332-d](YR-332-d-v7-month-judgment.md)의 선행 조건 통과 후에만 연다.

## 분석 범위

1. 기존 원자료에서 87개 반전과 동률 변화, 부하·업무별 반전, 비용 차이·정규화 눈금을 재계산한다.
   295개 결정을 서로 독립인 295일로 취급하지 않는다. 모델·입력별 결과를 보존한다.
2. 비용 차이를 선택 후 0~1·1~2·2~3·3~6시간 구간과 트럭·본선·이동·재취급으로 분해한다.
   저장되지 않은 구간별 비용은 추정해 채우지 않는다. 필요하면 측정기만 추가한 재생을 별도로 등록·고정한다.
   K별 종료 비용의 차이를 구간 기여로 해석하려면 공통 구간의 사건이 같은지도 먼저 확인한다.
3. 처음 선택의 직접 효과, 후속 작업 순서 변화, 시간 경계, 본선 운반 병목을 구분해 추적한다.
   판단이 바뀌었다는 이유만으로 잘못된 학습 신호 또는 미래 예측 오류라고 부르지 않는다.
4. 완전한 K를 관측한 선택과 끝에서 잘린 선택을 분리한다. 미완료·미도착을 제외해 개선을 만들지 않는다.
5. 모델이 보지 못하는 정보와 결과 사이의 관계는 분석용으로만 검사한다.
   결정 당시 알려지지 않은 실제 미래는 정책 입력으로 쓰지 않는다.

## 실행 경계와 완료 기준

- 기존 파일 읽기·집계와 새 시뮬레이션을 구분한다. 추가 실행 전 사전등록과 현재 게이트를 확인한다.
- 현실성 미통과 중에는 정책·보상·후보를 변경하지 않는다. i/f를 먼저 고친다.
- 기존 가정을 재생한 분석과 보정된 환경의 분석은 별도 출처로 남기며 수치를 섞지 않는다.
- 새 진단용 입력에서도 같은 손실 기제가 나타나는지 확인한 뒤 조건부 개선을 연다.
- 각 후보를 지지·반박·미확정으로 구분하고, 기존 비용·완료·본선 보호 기준은 임의로 완화하지 않는다.

## 기존 자료 점검 결과 — 2026-11-10

- 기록 72개·1,180 비교 쌍과 기존 평가 144개를 대조했다. 87개 반전 중 완전한 6시간 비교는 78개다.
- 반전 48개는 같은 업무 종류 사이의 선택이다. 정규화 전후 부호와 동일 종료점 비교 64개가 일치한다.
- K6−K1의 하루 평균 추가 비용 중 96.70%는 트럭 체류 항이다. 개별 학습 선택의 원인 분해와는 다르다.
- 본선 학습 후보 153개 중 142개가 마감 여유 입력 상한에 있다. 상한의 성능 영향은 미확정이다.
- 실제 하루 경로도 예약=실제 게이트 진입이다. 기존 f의 “하루 약 10분 오차” 설명을 정정했다.
- 저장소 실자료 100건 중 예약은 1건만 채워졌다. 운반 배치·편도·귀환·인계 원자료는 찾지 못했다.
- 분기별 비용 네 항·후속 결정이 저장되지 않아 인과 분해는 미완료다.
  필요한 측정을 [YR-323-f](YR-323-f-branch-cost-trace.md)로 등록했다. i/f 및 착수 게이트 이후 진행한다.
- 재현된 원인 없이 b/c/d를 시작하거나 K1을 채택하지 않는다.
