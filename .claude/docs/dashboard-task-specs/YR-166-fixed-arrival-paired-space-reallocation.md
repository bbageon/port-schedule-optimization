# YR-166 — 투입 고정 짝비교와 블록 재배치 재판정

- **상태**: backlog 🔴
- **분류**: Exp
- **선행**: YR-165

## 문제

기존 짝비교는 두 시뮬레이션에 서로 다른 트럭이 투입돼 재배치 효과와 수요 구성 차이가
섞였다. 기준 실행의 투입 계획을 비교 실행에 그대로 재생해야 한다.

## 범위

1. 투입 고정 계약과 난수시드를 실행 전에 동결한다.
2. 기존 판정의 표본 수·비용축·안전 검사를 유지한다.
3. 고정 투입 아래에서 블록 재배치 40쌍을 새 시드로 다시 평가한다.
4. 기존 결과는 투입 미고정 환경의 이력으로 보존한다.

## 완료 조건

- 두 실행의 투입 작업 식별자와 시각이 일치한다.
- 40쌍이 완주하고 기존 판정식으로 결과를 보고한다.
- 불리하거나 중단 방향이어도 기준을 바꾸지 않는다.
