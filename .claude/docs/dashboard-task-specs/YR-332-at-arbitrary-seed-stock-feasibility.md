## 무엇과 왜

원하는 반출 요청을 보존하면서 초기 재고·본선 공급·기간 밖 재고 연결을 맞춘다.
시드 다양화가 특정 우연한 재고 구성에 의존하지 않게 하기 위해 필요하다.
부하·블록별 요청/공급 회계와 미리 정한 시드 전체에서 작업 종류 보존을 검사한다.
제약을 충족하지 못하는 요청은 명시적으로 실패시킨다. 반입으로 바꾸어 통과시키지 않는다.

ao는 우선 작업 종류가 보존되는 배경만 조건부로 생성하고 모든 거절 시드를 남긴다.
이는 근본 수정이 아니다. 완전한 임의 시드 지원이나 실제 고물량 대표성으로 보고하지 않는다.
재고 배치를 바꿀 때 정책·보상·시간대 곡선·학습도 동시에 바꾸지 않는다.
