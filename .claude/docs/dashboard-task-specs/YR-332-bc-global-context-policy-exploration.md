# YR-332-bc — 예측 악화로 중단하지 않고 전역 정보의 정책 성능 비교

**상태**: backlog
등록: 2026-11-19. 이번에는 진행 기준 변경과 후속 실험 설계를 등록했으며 새 학습은 실행하지 않았다.
사용자: “일단 악화 허용치를 뺴고 성능을 계속 보는게 맞지않아?”
관련: az 전역 대기 예측 진단, ay 비용 예측 정규화 비교, bb 수요 보정.
보정 대상: performance — 예측 오차만으로 닫았던 동일 가설의 실제 정책 효과를 측정한다.

## 결정과 근거

- 이번 탐색에서는 비용 예측 오차의 악화율을 정책 실험 진입·조기 중단 조건으로 쓰지 않는다.
  전체·물량·시간대별 예측 오차는 계속 기록하고 실제 터미널 비용·작업시간과 함께 해석한다.
- az에서 전체 예측 오차는 1.412691→1.307982로 7.41% 감소했다.
  세 시작 모델은 −7.48/−6.92/−7.82%, 세 물량은 −5.95/−6.01/−7.78%였다.
  18~24시만 0.376207→0.396584로 5.42% 증가해 사전 허용치5%를 0.42%p 넘었다.
- 이 기준은 추가 계산을 결정하기 위한 실용적 기준이며 정책 성능 악화를 입증한 임계값이 아니다.
  az는 작업 선택을 고정했으므로 전역 정보가 정책 학습에 미치는 실제 효과는 아직 측정하지 않았다.
- ay에서는 3,500/7,500건의 검증 예측 오차가 1.6995→2.2341 / 1.8075→2.0410로 커졌지만,
  해당 물량의 트럭 작업시간은 12.95% / 10.70% 줄었고 전체 비용도7.55% 줄었다.
  서로 다른 정책의 방문 상태 차이가 있어 인과 입증은 아니지만, 예측 오차와 정책 결과를 구분할 근거다.
- 사용자의 제안을 이 후속 탐색의 진행 기준 변경으로 반영한다. az의 사전 기준·미통과 결과는 보존한다.
  예전 결과를 사후 통과로 바꾸거나 이미 정책 성능이 좋아졌다고 보고하지 않는다.

## 검토한 대안

1. 기존5% 중단 유지: 실제 정책 효과를 관측하지 못한 채 같은 가설을 닫으므로 이번 탐색에는 쓰지 않는다.
2. 허용치를6% 또는10%로 올림: 본 결과를 통과시킬 숫자 선택이 되며 근본 질문을 해결하지 못한다.
3. 예측 지표를 보고용으로 전환하고 정해 둔 정책 비교를 완주: 이번에 선택한다.
   전체 오차5% 개선·세 모델 동시 개선·물량2%·시간대5% 조건 모두 새 정책 실행의 필수 조건에서 제외한다.

## 유지할 실험 한 축

- Transformer 작업 선택 입력10칸·너비32·헤드4·층2, 후보·제약·비용·24시간 측정/26시간 실행을 유지한다.
- 두 군 모두 같은 확장 비용망을 쓴다. 추가 한 칸은 대조군0, 변경군은21블록 외부 트럭 대기 오더 합계다.
  변환은 `log1p(total_waiting_orders) / log1p(21 * 10)`이며 상한 절단은 없다.
- 동기화 경계의 관측·미래 정보 금지·결정시점 이전 스냅샷 계약은 기존 구현대로 유지한다.
- 같은 ay 최종 모델9951101/9951102/9951103을 각각 복제한다. 새 입력 열은0, 새 Adam으로 시작한다.
  az의 비용망만 따로 맞춘 가중치를 정책 실험 시작점으로 사용하지 않는다.
- 양 군에 같은 PopArt(예측 단위를 보존하는 비용 목표 정규화)를 적용한다.
  공유 Transformer 표현과 작업 선택망도 PPO(경험에 따라 선택 확률을 갱신하는 강화학습)로 학습한다.
  전역값은 선택망에 직접 들어가지 않지만 비용 손실이 공유 표현을 바꿀 수 있다.

## 입력·예산·평가

- 진행 중인 bb의 입력 검증 완료본을 한 버전으로 고정하고 양 군과 규칙에 공통 적용한다.
  bb의 자료 보정 효과를 전역 정보의 효과와 섞지 않도록 모든 비교를 같은 입력에서 새로 실행한다.
- 학습/개발/최종시험 곡선과 절대 난수·파일 해시를 실행 전에 새 명세로 고정한다.
  기존 az 검증 결과를 새 정책 최종시험으로 재사용하지 않는다. 이 문서는 실행 설정 동결 완료를 뜻하지 않는다.
- 정책 학습은 기존 제안 예산을 유지한다: 같은 초기값3쌍, 모델당12합성일·6갱신,
  갱신당2048표본·4반복·묶음64, Adam 학습률0.0003, PPO 범위0.2,
  비용망 손실계수0.5, 엔트로피계수0.01, 기울기 상한1.
- 시작·2·4·6번째 갱신에서 고정 개발 입력의 성능을 기록한다. 악화한 회차도 모두 남긴다.
  마지막6번째 모델을 최종시험에 사용한다. 유리한 중간 모델을 사후 선택하지 않는다.
- 최종시험은 새 곡선3개×물량3수준의9입력에 두 군6모델과 SF_SPT(짧은 실작업 우선 규칙)를 적용한다.
  같은 곡선을 물량만 바꾼 입력을 서로 독립적인 실제 운영일이라고 부르지 않는다.
- 1차 지표는 날짜·모델 동일 가중 터미널 총비용이다. 두 군 짝 차이·각 초기값·물량별 결과를 공개한다.
- 트럭 시간, 반입·반출·양하·적하 시간, 본선 지연비용, 24/26시간 미완료 건수를 함께 보고한다.
  미완료 작업의 시간은 관측 종료까지 포함하며 실제 최종 완료시간과 구별한다.
- 예측 오차나 운영 성능이 나쁘다는 이유로 정해진 비교를 도중에 끊거나 성공할 때까지 예산을 늘리지 않는다.
  물리 제약·정보 시점·장부 오류 또는 수치 계산 불능은 유효한 성능 결과가 아니므로 별도로 실패 처리한다.

## 코드와 기록 변경 범위

- 기존 `global_value_experiment.py`의 `train_policy`와 `evaluate`는
  `prediction-summary.json['passed']`를 요구한다. az 재현 경로의 이 검사를 지워 옛 계약을 바꾸지 않는다.
- bc 전용 설정·출력·진입점을 만들고, 예측 오차의 통과 여부가 정책 실행을 막지 않게 한다.
  공통 학습·관측 구현을 재사용하며 비용·학습식·다른 물리 검사까지 해제하는 강제 실행 옵션은 만들지 않는다.
- 관측 계약·표본 저장 복원·동일 초기값·후보/선택 확률·가중치와 원장 재현을 확인한다.
- 이전 정책·보고서·모델은 보존하고 신규 실행 증거는 별도 경로로 저장한다.

## 판정 범위와 현재 상태

- 이번 변경은 합성환경 탐색의 진행 기준이다. 기본 정책 채택 조건이나 공통 게이트를 일괄 삭제하지 않는다.
- 운반 흐름i·대기열 정의f의 미확인 상태는 사실대로 기록한다. 현장 효과·현실성 통과를 주장하지 않는다.
- 전체 비용 감소와 특정 작업 지연 증가가 함께 나오면 둘 다 보고한다. 최종 채택 여부와 탐색 완주를 구분한다.
- 새 자료에서 효과가 없거나 악화해도 결과를 보존한다. 추가 실험·학습량은 관측 뒤 자동 확대하지 않는다.
- 현재는 기준 변경·설계 등록만 완료했다. 실행 코드 변경·정책 학습·새 성능 평가는 아직 하지 않았다.
