# YR-204 — 학습 전용 장기 반사실 rollout 교사

- **Epic**: RL / **Priority**: 🟠 / **등록일**: 2026-08-19 / **상태**: backlog
- **3대 게이트 보정 대상**: `performance`
- **선행**: [[YR-202]] 라벨 잡음 판정 + [[YR-203]] 일회성 배치 계약
- **1줄**: 같은 상태에서 실제 배정과 KEEP/REJECT 반사실을 미래 `H`까지 함께 굴려
  장기 터미널 비용 차이를 만들되, 이 rollout은 **학습자료 생성 때만** 사용한다.

## YR-201·202와의 경계

| 작업 | 반사실 범위 |
|---|---|
| [[YR-201]] | 한 epoch의 동결 좌표 비용표에서 offer를 빼고 재매칭 |
| [[YR-202]] | 재취급 등 국소 미래비용 항을 라벨에 한 축씩 추가 |
| **YR-204** | 같은 난수·상태에서 전체 시뮬레이터를 `H`만큼 분기 실행 |

따라서 이 작업은 YR-201의 이름만 바꾸는 것이 아니라 더 비싼 **장기 교사 라벨**이다.

## 교사 라벨

배치에서 성립한 거래 `k=(A,B,j)`에 대해 비용 기준으로 정의한다.

```text
ΔC_k^H = C_H(실제 batch 배정) − C_H(k만 KEEP/REJECT로 바꾼 반사실)
D_k^H  = −ΔC_k^H       # 양수 = 거래가 장기 터미널 비용을 줄임
```

두 분기는 동일한 상태 snapshot, 외생 도착, 서비스시간, 고장, 정책 난수열을 쓴다
(공통 난수). `k` 외 다른 작업의 행동은 먼저 고정하며, 불가능해지면 사전등록한
재매칭 규칙을 적용하고 그 사실을 별도 표시한다.

Seller와 Buyer는 같은 `D_k^H`를 학습 신호로 받을 수 있지만, 실제 터미널 비용은
한 번만 센다. 두 손실은 거래 단위로 평균해 거래 하나를 두 배 가중하지 않는다.

## 먼저 고정할 것

- 지평 `H`와 종료 경계: 결과를 보기 전 물리 근거로 동결.
- 비용: 동일한 터미널 v2 비용과 같은 평가창; 별도 SELL/BUY 사적 목적 금지.
- 반사실 기본행동: Seller=KEEP, Buyer=REJECT, 나머지 batch 행동 처리 규칙.
- 난수 결합·snapshot hash·정보시점·미완주 처리.
- 표본수: 눈가림 파일럿에서는 짝차이 표준편차와 벽시계만 개봉한다.

## 단계와 수용 기준

1. 작은 N=3·작은 batch에서 snapshot 복원·결정론 재생·장부 보존을 검증한다.
2. `H`별 1라벨 벽시계와 짝차이 표준편차를 재고 예산 안의 표본수를 동결한다.
3. 동일 입력 재실행 라벨 오차 0, 소유권·물리 가드 위반 0을 확인한다.
4. 현 근사신용·YR-201 신용과 `D_k^H`의 부호 일치율·오차를 보고한다.
5. 신호가 잡음보다 작거나 필요 표본이 예산 상한을 넘으면 `POWER_FAIL`로 종료한다.

## 운영 경계

실제 평가·운영에서는 반사실 분기를 한 번도 실행하지 않는다. 이 산출물은
[[YR-205]]가 미래 비용 예측기를 학습할 때 쓰는 **교사 데이터셋**일 뿐이다.

## 하지 않는 것

- 결과를 본 뒤 `H`·반사실 규칙·표본수를 바꾸는 것.
- 운영 시 KEEP/SELL 두 세계를 굴리는 온라인 MPC.
- 이 작업에서 정책 가중치·Resolver·ExecutionHead를 함께 바꾸는 것.
