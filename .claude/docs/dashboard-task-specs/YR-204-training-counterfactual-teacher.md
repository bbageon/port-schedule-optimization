## ★사용자 결정 2026-08-20 — 지평 `H = 1시간`

spec 이 "`H` 는 결과를 보기 전 물리 근거로 동결"이라 열어둔 값을 여기서 정한다.

**근거는 연산량**이다. 반사실은 **오더 1건당** 발생하므로 `H` 가 곧 배수가 된다.

**`H`(지평)는 할인율 `γ` 가 아니다** — `H` 는 "얼마나 굴릴까"(계산 예산),
`γ` 는 "먼 미래를 얼마나 쳐줄까"(가치관)다. 우리는 **`γ` 를 쓰지 않는다**
(비용이 실제 발생 시간이라 깎을 근거가 없고, 유한 에피소드라 발산도 없다).
구분과 경계 절벽 문제 → [아키텍처 04 §4-1](../architecture/04-비용과-보상.md)

| H | 1건당 | 전수 2,000건 | 표본 100건 | 에피소드 1판 총계 |
|---|---|---|---|---|
| 0.5h | 20s | 11h | 33분 | 49분 |
| **1h** | **40s** | 22h | **67분** | **83분 (5배)** |
| 2h | 80s | 44h | 133분 | 149분 |
| 3h | 120s | 67h | 200분 | 216분 (14배) |

(모의 1시간 = 실측 40초. 에피소드 1판 = 24시간 = 960초.)

**전수는 어느 H 에서도 불가능**하다 — 표본 추출이 전제다. 그 위에서 학습
16회차 × 4판이면 **H=1 은 약 9시간, H=3 은 23시간**이다.

### 정직 고지 — H=1시간이 못 잡는 것

지금 보상의 시야가 트럭 한 대의 방문(**약 40분**)이다. 1시간은 그보다 조금 넓다.

| | H=1h |
|---|---|
| 즉각 혼잡 연쇄 — 뒤에 온 트럭이 **실제로** 얼마나 밀렸나 | ✅ |
| 크레인이 묶여서 생긴 파급 | ✅ |
| 몇 시간 뒤 **재취급** | ❌ |
| 반입 컨테이너의 **나중 반출** 비용 | ❌ |

→ **주된 이득은 "추정 → 실측"이고, 시야 확장은 40분→60분으로 제한적**이다.
지금 `occupy × 대기수` 라는 추측이 **실제로 밀린 시간**으로 바뀐다.

### 착수 전 확인 (값싸다)

`H = 0.5 / 1 / 2` 로 **같은 거래 20건**의 라벨을 재본다.
**H=1 과 H=2 가 비슷하면 1시간으로 충분**하다는 근거가 생긴다. 몇 분이면 된다.

## YR-201·202와의 경계

| 작업 | 반사실 범위 |
|---|---|
| [[YR-201]] | 한 epoch의 동결 좌표 비용표에서 offer를 빼고 재매칭 |
| [[YR-202]] | 재취급 등 국소 미래비용 항을 라벨에 한 축씩 추가 |
| **YR-204** | 같은 난수·상태에서 전체 시뮬레이터를 `H`만큼 분기 실행 |

따라서 이 작업은 YR-201의 이름만 바꾸는 것이 아니라 더 비싼 **장기 교사 라벨**이다.

## 비용 정본 — 하나만 둔다

새 SELL 보너스나 BUY 사적 비용을 만들지 않는다. 두 세계 모두 [[YR-207]]에서 잠근
`TERMINAL-COST-KRW-EQ-2026-SAFE-FREIGHT-V1`과 구간 `terminal total cost`를 사용한다.

```text
J_H(W) = Σ_[t,t+H] C_terminal(interval | W)
```

`cost_id`, 13개 항의 scale·weight, 설정 hash는 YR-207 산출물을 그대로 재사용한다.
트럭 항은 `A→O` 턴타임이고 `B→C`는 진단만 하며 두 항을 더하지 않는다. 크레인 주행·공차,
재취급, 본선지연과 이송 때문에 같은 장부에 생긴 비용을 세고, 별도 `SELL/BUY/WAIT` 상수
벌점은 더하지 않는다. 이송비를 terminal 장부와 actor 식에 동시에 넣는 것도 금지한다.
기다리는 동안 턴타임·지연이 늘면 그 구간 비용으로 자동 청구된다.

## actor별 반사실 비용

눈가림 파일럿에서 정한 decision epoch의 actor 행동좌표를 짝으로 비교한다.

```text
W_S^1: A가 SELL(j), 그 offer에 대한 Buyer 응답 후 Resolver 실행
W_S^0: A가 KEEP(j), j의 판매 edge 없이 Resolver 실행

W_B^1: A의 offer는 고정하고 B가 BUY(A,j), Resolver 재매칭
W_B^0: A의 offer는 고정하고 B가 REJECT(A,j), Resolver 재매칭

c_S^H(A,j)   = J_H(W_S^1) − J_H(W_S^0)
c_B^H(A,B,j) = J_H(W_B^1) − J_H(W_B^0)
```

작은 비용을 선호하는 Q 기준이므로 `c<0`이면 실제 SELL 또는 BUY가 좋은 행동이다.
보상 최대화 구현만 `r_S=−c_S`, `r_B=−c_B`로 부호를 바꾸며 두 표현을 섞지 않는다.

Seller가 KEEP하면 작업 `j`의 모든 판매 edge가 사라지고, Buyer가 REJECT하면 `(B,j)`
edge만 사라진다. 다른 Buyer가 대신 선택될 수 있으므로 두 라벨은 일반적으로 같지 않다.
대안 Buyer가 없으면 두 반사실 효과가 같아질 수 있다.

각 짝은 동일한 상태 snapshot, 외생 도착, 서비스시간, 고장, 정책 난수열을 쓴다
(공통 난수). Seller 짝에서는 `j` 외 작업의 요청을 고정하고 SELL 세계에서 Buyer 정책
응답을 한 번만 만든다. Buyer 짝에서는 Seller offer와 다른 Buyer 응답을 고정한다.
Resolver만 같은 동점규칙으로 다시 풀며 재매칭·대체 Buyer를 원장에 남긴다.

터미널 성능은 `J_H(W)` 한 번으로만 평가한다. `c_S+c_B`를 실제 비용이나 Resolver
점수로 사용하지 않는다. 두 actor 손실은 거래 단위 `(L_S+L_B)/2`로 평균해 한 거래가
두 배 가중되지 않게 한다. 소스 절감·수신 부담 분해는 진단용이며 주 보상이 아니다.

실행된 거래만 골라 라벨을 만들면 REJECT와 미선택 요청을 배우기 어렵다. 따라서 일부
decision epoch에서 실제 행동 여부와 무관하게 위 두 행동을 모두 굴린다. 토글해도 최종
배정이 같으면 비용 0이 정답이며 임의 상금을 만들지 않는다. 강제 행동은 교사 생성에서만
허용하고 실제 평가·운영에는 들어가지 않는다.

## 먼저 고정할 것

- 지평 `H`와 종료 경계: 결과를 보기 전 물리 근거로 동결.
- 비용 설정: 활성 `cost_id`·13항·설정 hash; 두 actor와 모든 세계에서 동일.
- 반사실 행동: Seller=KEEP, Buyer=REJECT, 나머지 request·Resolver 동점규칙 동결.
- 난수 결합·snapshot hash·정보시점·미완주 처리.
- 표본수: 눈가림 파일럿에서는 짝차이 표준편차와 벽시계만 개봉한다.
- 경계 밀어내기 방지: 영향 작업 완료와 마지막 구간 비용차 안정 기준을 사전 고정한다.

## 단계와 수용 기준

1. 작은 N=3·작은 batch에서 snapshot 복원·결정론 재생·장부 보존을 검증한다.
2. `H`별 1라벨 벽시계와 짝차이 표준편차를 재고 예산 안의 표본수를 동결한다.
3. 동일 입력 재실행 라벨 오차 0, 소유권·물리 가드 위반 0을 확인한다.
4. Seller·Buyer 토글 외 joint request가 같은지, 비용 원장 합이 `J_H`와 맞는지 검사한다.
5. 현 근사신용·YR-201과 `c_S^H`, `c_B^H`의 부호 일치율·오차를 각각 보고한다.
6. 영향이 `H` 밖으로 남거나 신호가 잡음보다 작거나 표본이 예산을 넘으면
   `POWER_FAIL`로 종료한다. 사후 tail model을 붙여 통과시키지 않는다.

## 운영 경계

실제 평가·운영에서는 반사실 분기를 한 번도 실행하지 않는다. 이 산출물은
[[YR-205]]의 Seller actor·Buyer actor와 중앙 critic을 학습할 **교사 데이터셋**일 뿐이다.

## 하지 않는 것

- 결과를 본 뒤 `H`·반사실 규칙·표본수를 바꾸는 것.
- 운영 시 KEEP/SELL 두 세계를 굴리는 온라인 MPC.
- Seller 비용과 Buyer 비용을 더해 터미널 비용이라고 부르는 것.
- 지역 블록 비용만으로 Buyer가 무조건 REJECT하게 만드는 사적 목적함수.
- 이 작업에서 정책 가중치·Resolver·ExecutionHead를 함께 바꾸는 것.
