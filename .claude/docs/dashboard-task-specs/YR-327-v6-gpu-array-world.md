## 무엇을 하는 작업인가

사용자 지시(2026-09-25): *"v5 를 기준으로 v6 를 만들어서 GPU 로 적용하고 전체 오더를

### ★손익분기 — 교차점이 **존재하지 않는다**

전 보고(굴리기 전용 경로, 4.34 s)는 **연구가 학습에 쓰지 않는 경로**였다. 실제 학습 경로로 다시 재면:

    30일 학습 한 판 (43,201 경계)      세계·하루당
      v5 단독            7.5분          15.0 s      ← 가장 빠름
      배열판 GPU         2.7시간       325 s        (21.7배 느림)
      배열판 CPU        14.1시간     1,697 s
      v5 ×24 프로세스                   5.94 s (병렬효율 보정 ≈1.3 → 약 250배)

**"세계를 쌓으면 된다" 가 학습 경로에서는 불가능하다** — 60초 경계마다 호스트 동기화 3회 + `np.asarray` +
파이썬 사전 루프가 있어 **B 축이 아예 없다**. 굴리기 경로(B=128 까지 쌓음)도 교차점이 없다:
포화 구간의 한계비용 **2.57~3.84 s/세계·하루** > v5×24 의 **1.294** → B→∞ 에서도 점근선이 v5 위다.
막히는 순서: ①경계 호스트 왕복 ②처리량 포화(64→128 에 10%) ③메모리(192세계) ④컴파일 ⑤래기드 낭비.
