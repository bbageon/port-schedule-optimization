# YR-327 — v6: 배열 세계 · GPU · 전체 오더를 한 번에

## 무엇을 하는 작업인가

사용자 지시(2026-09-25): *"v5 를 기준으로 v6 를 만들어서 GPU 로 적용하고 전체 오더를
신경망으로 할 수 있게 조치."*

v5 를 독립 복사(`7745dbc2`)한 뒤 **가속기에서 도는 배열 세계**를 더한다.

## 왜 — 세 갈래가 각자 막혀 있다

| | v4 | v5 | 막힌 곳 |
|---|---|---|---|
| 세계 복제 | 결정마다 | 없음 | v4: 계산의 **94%** |
| 쓰는 결정 | **0.43%** | 100% | v4: 99.6% 를 버린다 |
| 신용 배분 | 반사실(정확) | **공유 팀 보상** | v5: 누구 덕인지 모른다 |

v6 는 **반사실을 망 안에서** 만들어 셋을 한꺼번에 푼다([[YR-326]] 의 제안 구조).

## 무엇을 만들었나

### 환경

    RTX 5090 (32GB) · 드라이버 595.95 · 연산능력 12.0 (블랙웰)
    JAX 0.11.2 + cuda12  ← 새로 설치 (venv 는 uv 로 관리된다, pip 없음)

⚠️ GPU 에 다른 프로세스가 8.5GB 쓰고 있어 JAX 기본 선점(75%)이 실패한다 —
`XLA_PYTHON_CLIENT_PREALLOCATE=false` 가 필요하다.

### 코드 (`src/yard_rl/v6/gpu/`)

| 파일 | 무엇 |
|---|---|
| `events.py` | 사건 큐를 배열로. **힙과 같은 순서**(시각순·동시각은 넣은 순서)를 `(시각 + 순번×1e-9)` 단일 키로 낸다. 넘치면 **표시**(`overflow`) — 조용히 안 버린다 |
| `state.py` | 오더·크레인 배열, 비용 네 항, **턴타임 검열**(못 나간 트럭을 표본에서 빼면 정책이 이득 본다) |
| `policy.py` | **전 오더를 한 번의 순전파로** · 가치/우위 분해(`Q = V + A`, `A` 평균 0) · 반사실 기준선 |

### ★전체 오더를 한 번에

    v4·v5 :  for 후보 in 후보들:  점수 = 망(후보)     ← 20~28회
    v6    :  점수들 = 망(전 오더 행렬)                 ← **1회**

점수가 전부 나와 있으므로 **반사실 기준선이 공짜로 따라온다** — *"고른 것 − 후보 평균"*
을 시뮬레이션 없이. v4 가 세계 둘을 굴려 하던 일이다.

## 실측

    후보 64개 결정을 세계 N 개에서 동시에 (RTX 5090)

      세계      1회 시간     초당 결정수     한 결정당
         1      0.092ms         10,853       92.14µs
       128      0.066ms      1,949,898        0.51µs
     1,024      0.067ms     15,287,790        0.07µs
     8,192      0.474ms     17,267,126        0.06µs

**세계 1,024개까지 1개와 시간이 같다** — 가속기가 노는 구간이라 공짜로 늘어난다.

### ★부동소수점 — 값은 다르고 순서는 같다

GPU 와 CPU 는 더하는 순서가 달라 결과가 어긋난다: **상대 오차 5.8e-4**.
우리 신호가 비용의 0.003% 임을 생각하면 그냥 넘길 수 없는 크기다.

그런데 **정책은 점수로 줄을 세워 고른다.** 값이 달라도 순서가 같으면 같은 정책이다 —
실측 **1등 100% · 상위 3등 100% 일치**.

→ **규약**: 학습은 GPU(빠름), **판정은 CPU**(정확)로 다시 잰다. 학습이 진행돼 후보 간
격차가 좁아지면 이 잡음이 순서를 뒤집을 수 있다. 시험
(`test_ranking_is_what_must_match_not_raw_values`)이 그 경계를 지킨다.

## 시험 12건 (`tests/v6/test_gpu_core.py`)

힙과 같은 순서 · 빈 큐 · **넘침 표시** · 칸 재사용 · 한 번의 순전파 · 우위 평균 0 ·
빈 칸은 안 뽑힘 · **빈 칸이 기준선을 오염 안 시킴** · 반사실이 시뮬 없이 · **배치가
하나씩과 같은 답** · 턴타임 검열 · **순서 안정성**.

## ⚠️ 어디까지 왔나 — 정직하게

옮기며 **조각마다 v5 와 같은 답을 내는지** 붙든다. 전부 옮기기 전까지 v5 가 정본이다.
