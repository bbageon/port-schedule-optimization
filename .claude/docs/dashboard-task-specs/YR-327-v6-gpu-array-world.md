# YR-327 — v6: 배열 세계 · GPU · 전체 오더를 한 번에

## 무엇을 하는 작업인가

사용자 지시(2026-09-25): *"v5 를 기준으로 v6 를 만들어서 GPU 로 적용하고 전체 오더를
신경망으로 할 수 있게 조치"* → 이어서 *"v6 진행해봐"*.

v5 를 독립 복사(`7745dbc2`)한 뒤 **가속기에서 도는 배열 세계**를 더한다. 원본 v5 는 수정하지 않는다.

## 왜 — 세 갈래가 각자 막혀 있다

| | v4 | v5 | 막힌 곳 |
|---|---|---|---|
| 세계 복제 | 결정마다 | 없음 | v4: 계산의 **94%** |
| 쓰는 결정 | **0.43%** | 100% | v4: 99.6% 를 버린다 |
| 신용 배분 | 반사실(정확) | **공유 팀 보상** | v5: 누구 덕인지 모른다 |

v6 는 **반사실을 망 안에서** 만들어 셋을 한꺼번에 푼다([[YR-326]] 의 제안 구조).

## 1단계 — 핵심 골격 (`c06baafb`)

    RTX 5090 (32GB) · 드라이버 595.95 · 연산능력 12.0 · JAX 0.11.2+cuda12 (uv 로 설치)
    ⚠️ 다른 프로세스가 8.5GB 써서 XLA_PYTHON_CLIENT_PREALLOCATE=false 필요

`gpu/events.py`(사건 큐) · `gpu/state.py`(오더·크레인 배열) · `gpu/policy.py`(전 오더를 한 번의
순전파로, `Q = V + A`, 반사실 기준선). 후보 64개 결정을 세계 8,192개에서 0.474ms = **초당 1,727만**.
GPU·CPU 상대오차 5.8e-4 이나 **순서 100% 일치** → **규약: 학습은 GPU, 판정은 CPU**.
