# YR-332-ar — 관측 분별 형판을 수식 기반 방문 도착으로 대체

- **상태**: backlog
- 등록: 2026-11-15. 상위 [[YR-332]], 선행 설계 [[YR-332-ao]].
- **3대 게이트 보정 대상**: scenario_validity(하루 안 방문 도착의 변동을 설명 가능한 합성 과정으로 만드는가).

## 무엇과 왜

현재 ak의 `observed_visit_minutes`는 실제 날짜의 분당 방문 건수 배열을 뽑아 재사용한다.
사용자가 요청한 수식·설정으로 공개 가능한 합성 입력 경로를 만들려면 이 부분을 따로 검토해야 한다.
날짜별 평균 곡선이 달라지는 효과와 시간대 안 도착 과정이 달라지는 효과를 구분한다.

## 범위

1. ao에서 정한 하루 곡선·시간대 건수·작업 비율·방문 연결·정보·물리·정책은 고정한다.
2. 고정된 건수에서 독립 시각을 뽑는 조건부 과정과, 분 단위 강도 변동을 포함하는 수식 후보를 입력 통계로 비교한다.
   독립 도착만으로 충분한지 먼저 확인하며 복잡한 생성 신경망을 선행 채택하지 않는다.
3. 방문 단위에서 분별 산포·연속 구간의 상관·간격을 검사하고, 오더 확장과 블록 도착 뒤 통계를 별도로 검사한다.
   실제 관측 분별 배열을 숨겨 내장하거나 게이트 시각을 블록 도착으로 대신 쓰지 않는다.
4. 변화 폭·시간 척도·분포와 허용 오차는 정책 성능을 보기 전에 고정한다. 자료에서 추정한 값은 출처를 명시한다.
5. 같은 입력의 재현, 시간대 건수·방문 용량·작업 선후관계 보존, 고정 정책 민감도를 확인한다.
6. 7,500·15,000건에서 관측 몰림을 외삽했다면 그 가정과 민감도를 보고한다. 고물량 근거는 ap와 연결한다.

## 완료 기준

수식·매개변수 근거·재현용 설정으로 관측 날짜의 분별 배열 없이 방문 도착을 생성할 수 있어야 한다.
통계 적합과 고정 정책 결과를 각각 남기고, 통계 보정 합성인지 공개 근거 합성인지 구분한다.
기존 ak/al 결과를 보존하며 새 경로를 선택형으로 비교한다. 채택과 재학습은 별도 판정이다.

## 2026-11-16 입력 모형 검사
사용자가 네 단계 모두 실행하도록 요청했다. ao의 104121cb 게이트로 현실성 보정 허용을 확인했다.
최초 허가 명령은 선언 문구에 `3대`가 빠져 거절되어, 선언 형식만 바로잡은 뒤 같은 기준으로 허용됐다.
독립 균등·Dirichlet 분별 비중은 인접 분 상관을 못 맞춰 실패했다. AR(2) 수정도 10분 산포 오차0.1599로 기준0.15 미달.
10분 구간 로그 강도의 분산 하나를 입력 잔차로 보정한 모형은 세 기준을 모두 통과했다.
실제 Python 난수 생성 구현도 별도100회로 통과(1분/10분 산포 오차0.0727/0.00224, 인접 상관 오차0.0190).
기준은 완화하지 않았다. 입력을 본 뒤 수정했으며 최초 사전등록처럼 쓰지 않는다.
