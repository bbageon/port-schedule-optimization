# YR-310 — 회차당 학습 강도를 낮춘다 (크레인층 thrash)

## 무엇을 하는 작업인가

회차마다 망을 그날 데이터에 **408번 가까이 다시 맞추는** 것을 줄인다.

## 왜 지금 하나 — [[YR-309]] 가 원인을 좁혔다

[[YR-308]] 4시간 학습이 요동쳤다. [[YR-309]] 가 *"목표 눈금이 13배 벌어져서"* 를
시험했고 **기각**됐다(요동 표준편차 5.31% → 5.24%, 사실상 동일).

그다음 **23개 체크포인트 전부**를 한 날에 굴려 요동의 성질을 갈랐다:

    한 회차 변동 중앙 5.92%  /  전체 표준편차 7.70%  =  비율 0.77

**느린 표류가 아니라 매 회차 크게 흔들리는 것**이다. 그리고 학습은 **첫 4회차에
거의 끝난다** (+20.69% → −1.20%). 이후 19회차는 평균 +3.86% · 표준편차 4.65% 로
**추세가 없다**(전 회차보다 나빠진 횟수 10/18 — 동전 던지기).

### 왜 그런가

    라벨 64건/회차 → 표본 128개 → 학습분 약 102개
    스텝 수 = max(50, min(600, 4 × 102)) = 408
    미니배치 256 > 102  →  매 스텝이 사실상 **전체 배치**

라벨은 유효기간이 있어 회차마다 버린다(버퍼 없음 — 04b §3). 그래서 매 회차
**한 날의 표본 100개에 408번 가까이 맞춘다.** 망이 그날로 다시 그려진다.

## 무엇을 바꾸나

`crane/fit.py` 의 `steps = max(50, min(600, 4 * len(tr_idx)))` 계수를 낮춘다.
후보는 **4 → 1** (약 102 스텝) 과 **4 → 0.5** (약 51 스텝, 하한에 걸림).

⚠️ **학습률은 건드리지 않는다.** 스텝 수와 학습률을 같이 바꾸면 어느 쪽이
들었는지 못 가린다 (연구 원칙 2 — 한 번에 한 축).

## 판정 기준 (사전등록 — 실행 전에 확정한다)

같은 시드 바닥·같은 부하·같은 라벨 예산으로 돌리고, **전 체크포인트 궤적**
(`scripts/v4/probe_crane_trajectory.py` · 부하 7,500 · 시드 9,900,917)으로 잰다.

| 기준 | 지금 (계수 4 · [[YR-309]]) |
|---|---|
| ① **한 회차 변동 중앙** | **5.92%** ← 이게 줄어야 한다 |
| ② 후반 평균 (4회차 이후) | +3.86% |
| ③ 후반 표준편차 | 4.65% |
| ④ 최저점 | −3.61% |

**①이 주 기준이다** — thrash 가설을 직접 시험한다. ②가 나빠지면(학습이 덜 되면)
스텝을 너무 줄인 것이다.

## ★실험 예산 — 4시간이 필요 없다

[[YR-309]] 진단이 **학습이 첫 4회차에 saturate** 함을 보였다. 다만 스텝을 줄이면
saturate 가 늦어지므로 **12회차**(약 1.2시간) 로 잡고, 궤적 진단(+0.6시간)을 더해
**회차당 약 2시간**이면 한 조건이 비교된다.

## ★실행 사전등록 (2026-09-12 · 사용자 지시 "10코어만 써서" · 실행 **전에** 커밋)

[[YR-309]] 실행과 **한 곳만** 다르다 — 학습 강도. 나머지는 전부 같다.

| | 값 | [[YR-309]] 와 |
|---|---|---|
| **학습 강도** | **계수 1.0** (표본 102개 → 약 102스텝) | ★여기만 다름 (4.0 → 408스텝) |
| 회차 | 12 | (23 — 아래 "예산" 참조) |
| 작업자 | **10** | (20 — 사용자 지시) |
| 부하 | 3,500 / 5,000 / 7,500 / 12,500 / 15,000 | 같음 |
| 라벨 | 64건/회차 · 반사실 창 3시간 | 같음 |
| 눈금 | 그날 라벨의 중앙 격차 (하한 1,000원) | 같음 |
| **시드 바닥** | **9,900,700** | **같음 — 같은 날을 같은 순서로** |
| 학습률 | 3e-4 (안 건드림) | 같음 |
| 고정 평가일 | **안 함** (`--eval-every 0`) | 궤적 진단이 대신한다 |
| 결과 | `outputs/v4/crane-fit-gentle/` | — |

`--eval-every 0` 인 이유: 판정 기준이 **궤적 진단**이라 고정 평가일이 안 쓰인다.
평가 한 번이 15분이라 3회면 45분인데, 10코어에서는 그 시간이 더 아깝다.

### 판정 (기준값은 [[YR-309]] 궤적 · 부하 7,500 · 시드 9,900,917)

| | 기준 ([[YR-309]] · 계수 4.0) | 이번 (계수 1.0) |
|---|---|---|
| ① **한 회차 변동 중앙** | **5.92%** | 줄어야 한다 ← **주 기준** |
| ② 후반 평균 (4회차 이후) | +3.86% | 안 나빠져야 한다 |
| ③ 후반 표준편차 | 4.65% | (참고) |
| ④ 최저점 | −3.61% | (참고) |

②가 나빠지면 **학습이 덜 된 것**이다 — 스텝을 너무 줄였다는 뜻이라 계수 0.5 는
시험하지 않고 반대로 올려야 한다.

⚠️ **회차 수가 달라 ②③의 표본이 적다** ([[YR-309]] 19점 vs 이번 8점). ①은 회차 간
변동이라 영향이 작지만, ②③은 그만큼 느슨하게 읽는다.

### 예산

10코어라 반사실 세계가 20코어의 약 2배 걸린다. 12회차 ≈ **2.5~3시간** + 궤적 진단
(13개 체크포인트 × 한 날) ≈ 0.6시간.

회차를 12 로 잡은 근거: [[YR-309]] 궤적에서 **학습이 첫 4회차에 saturate** 했다.
계수를 낮추면 늦어지므로 3배인 12 로 둔다.

## ★결과 — ①통과 ②미통과 (2026-09-12 · 12회차 · 1.45시간 · 10코어)

A = [[YR-309]] 실행(계수 4.0) · B = 이 실행(계수 1.0). 같은 날·같은 시드·같은 순서.

### 궤적 (부하 7,500 · 시드 9,900,917)

    A  [ 0] +20.69  [ 1] +29.41  [ 2] +13.20  [ 3]  -1.20  [ 4]  +4.62 ...
    B  [ 0] +15.55  [ 1] +21.97  [ 2] +26.03  [ 3] +21.91  [ 4] +18.46
       [ 5]  -3.57  [ 6]  +2.24  [ 7]  +3.21  [ 8]  +3.67  [ 9]  -0.66
       [10]  +1.46  [11] +12.64

### 사전 등록한 판정

| | 기준 (A · 23회차) | A 앞 12회차 | B (12회차) | 판정 |
|---|---|---|---|---|
| ① **한 회차 변동 중앙** | 5.92% | 5.82% | **4.12%** | ✅ **통과** (−30%) |
| ② 후반 평균 (4회차 이후) | +3.86% | +2.35% | +4.68% | ❌ **미통과** |
| ③ 후반 표준편차 | 4.65% | 3.19% | 6.80% | (나빠짐) |
| ④ 최저점 | −3.61% | −3.61% | −3.57% | (동일) |

**①은 thrash 가설을 지지한다** — 스텝을 1/4 로 줄이니 회차 간 널뛰기가 30% 줄었다.

### ⚠️ 그러나 ②는 **결론이 아니라 교란이다**

B 는 12회차 동안 **총 스텝이 A 의 1/4** 이다 (12×102 = 1,224 vs 12×408 = 4,896).
*"같은 회차"* 로 견주면 B 는 아직 학습 중이다 — 실제로 처음으로 규칙을 이긴 시점이
A 는 3회차, B 는 **5회차**로 늦다. ②의 악화는 **학습이 덜 된 것**이지 나빠진 것이
아닐 수 있다.

**총 스텝을 맞춰 보면** (A 1회차 ≈ B 4회차):

| 총 스텝 | A | B |
|---|---|---|
| 408 | +20.69% (0회차) | +21.91% (3회차) |
| 816 | +29.41% (1회차) | **+3.21%** (7회차) |
| 1,224 | +13.20% (2회차) | +12.64% (11회차) |

세 점뿐이라 결론은 못 내지만, **같은 스텝이면 B 가 못하지 않다.**

> ⚠️ 사전등록이 *"같은 회차"* 로 견주게 짜여 있었다. **총 스텝을 맞추는 축이
> 빠졌다** — 스텝 수를 바꾸면서 회차를 고정하면 훈련량이 따라 바뀐다.
> 다음 실행은 **saturate 할 때까지** 돌려 평탄부끼리 견준다.

### 사전등록한 후속 규칙은 적용하지 않는다

*"②가 나빠지면 스텝을 너무 줄인 것이니 반대로 올린다"* 고 적었는데, 위 교란 때문에
②를 그대로 읽을 수 없다. **규칙을 어기는 것이 아니라, 그 규칙이 전제한 비교가
성립하지 않았음을 기록하고 다음 실행에서 다시 판정한다.**
