# YR-077-2 — 장부·실제 위치 불일치와 노쇼 강건성

- **상태**: backlog ⚪
- **분류**: Sim
- **재개 조건**: 정책 구조 확정과 현장 배치 검토 단계

## 목적

컨테이너의 장부 위치와 실제 위치가 다른 운영 오류, 그리고 통지 뒤 도착하지 않는
작업을 함께 넣어 정책과 반사실 시뮬레이션의 강건성을 평가한다.

## 연기 이유

이 작업은 원리 증명보다 채택 단계의 현실성 검증에 가깝고, 기록과 실제 상태를 따로
보관하는 새 엔진 모형이 필요하다. 정책 구조가 바뀌는 동안 먼저 구현하면 같은 시험을
다시 해야 하므로 후속 단계로 연기했다.

## 완료 조건

- 장부 위치와 실제 위치를 분리한 상태 계약을 정의한다.
- 노쇼와 위치 불일치 강도를 사전등록한다.
- 정상 조건 대비 비용·제약 위반·정책 성능 저하를 함께 보고한다.
