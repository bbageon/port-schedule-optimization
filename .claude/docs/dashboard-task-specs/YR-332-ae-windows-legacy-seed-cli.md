# YR-332-ae — Windows에서 구형 시드 생성 명령의 환경 기록 수정

- **상태**: backlog
- 분류: Infra. 연구 정책·환경을 바꾸지 않는 실행 환경 호환성 작업.
- 파생: YR-332-ad 관련 검사 중 `test_fixed_seed.py`의 구형 v5 명령 연결 검사에서 발견.

## 확인한 문제

`scripts/v5/generate_fixed_seed.py:31`이 환경 기록에 `os.sched_getaffinity(0)`을 호출한다.
Windows Python 3.13.9에는 이 함수가 없어 실제 생성 전에 `AttributeError`가 발생한다.
현재 v7의 직접 생성·저장·복원 검사는 통과했으며 신규 예약 계약과 별개다.

## 범위와 완료 조건

- 실제 사용 가능한 CPU 집합을 지원 플랫폼에서 기록하고, 미지원 플랫폼은 알 수 없는 값 또는
  구분된 CPU 개수 기록으로 처리한다. 제한된 CPU 집합을 임의로 추정하지 않는다.
- 연구 시드·오더·초기 재고·예약·학습·물리 설정은 바꾸지 않는다.
- 해당 연결 검사 및 생성 산출물의 코드·설정 기록을 확인한다.
- 원본 v5 명령의 호환성 변경으로 별도 commit에 보존한다.

## 우선순위

현재 CPU 연구의 하루 평가를 막지 않는다. 구형 명령을 Windows에서 다시 사용할 때 처리한다.
