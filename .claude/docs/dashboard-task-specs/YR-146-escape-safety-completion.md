## 무엇을 왜

YR-145의 유일한 미완주 판은 “두 크레인 모두 아무 일도 할 수 없음”이 아니었다. 같은
시점에 `SERVE+WAIT`와 `WAIT+SERVE`가 안전하게 가능했지만, PPO가 예상비용을
`WAIT+WAIT=12.5055 < WAIT+SERVE=13.2208 < SERVE+WAIT=14.2435`로 잘못 매겨
전원 대기를 골랐다. 이후 두 크레인이 모두 양보 상태가 되고 미래 wake가 없어 본선 적하
2건이 남았다.

즉 직접 원인은 **정책의 공동행동 순위 오평가**, 확대 원인은 **엔진이 이후 진행을 보장하지
못한 것**이다. 안전층만 먼저 고치면 정책이 배웠는지 알 수 없으므로, YR-147의 마스크 없는
정책 최적화와 YR-143의 행동공간 검증 뒤 배포 경로에만 적용한다.

## 최소 계약 (★24차 협소화 2026-08-03 — "진행 가능하면 전원 대기 거부"는 과광범위:
정상적 기다림까지 차단 위험. 발동은 아래 3 경우 한정)

1. **재개방 부재 대기**: 전원 대기를 선택했는데 미래 재검토 사건(defer 만료·wake·이벤트)
   이 전혀 없음 → 정책이 평가한 진행 후보 중 최선으로 대체 (종단 정지 직행 차단).
2. **무진전 반복 대기**: DEFER 만료로 재개방됐는데 상태 변화·작업 진전 없이 다시 전원
   대기를 선택함 → 동일 대체.
3. **간섭 교착 탈출**: 크레인 간섭 때문에 진행 후보가 전혀 없음 → 최소 안전 escape 확정.
4. 진행 행동 = 실작업 시작 또는 교착 통로를 여는 행동 한정 (목적 없는 위치조정 제외).
5. 안전거리·비통과·예약·동일시각 재결정·원자 rollback 계약 불변.
6. **개입률 허용치 사전 정의(착수 동결)**: guard 개입이 공동결정의 허용치를 넘으면
   "정책 미완" 판정 태그 — 안전장치 이득을 학습 성과로 합산 금지.

## 분리 평가

- YR-147·YR-143에서 확정한 동일 정책 체크포인트로 guard OFF/ON을 짝지어 실행한다.
- OFF 결과가 정책 성능, ON 결과가 배포 안전성이다. 두 결과를 합쳐 학습 성과라 부르지 않는다.
- 필수: 완주 100%, backlog 0, 미해결 교착 0, 무한 재결정 0, 정상 시나리오 불필요 escape 0.
- 함께 보고: guard 개입 횟수·상태·대체행동·비용 변화. 개입률이 높으면 정책 미완으로 판정한다.
- 알려진 high-loose/910017은 개발 회귀에만 쓰고, 판정은 신규 시드뱅크로 한다.
