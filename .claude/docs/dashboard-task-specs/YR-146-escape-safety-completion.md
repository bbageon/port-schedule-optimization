# YR-146 — 교착 탈출 안전층 완결: 정책 무관 종단 정지 0 보장

## 무엇을 왜 (YR-145 기각 원인의 안전층 수리)
YR-145 는 J2~J7 전부 통과(J7 은 사슬 최초 완전 통과 — 만료 후 실행 0·차단 실발생
4,812~4,992건)하고 **J1 완주 1판 실패**로 기각. 재현 계측: high-loose/910017 에서
본선 적하 2건이 RELEASED 인 채 종료 — 두 크레인 bay 22/24 유휴+양보 잠금, 엔진 술어
`interference_deadlock_corridors()` 종료 시점 참((18,24)·(22,24)) = **간섭 교착 종단
정지**. 같은 판을 9/10 정책이 완주 — 정책 궤적 특이 사례지만, 안전층은 정책과 무관하게
정지를 막아야 하는 계층이다 (16차 피드백: "교착 탈출은 성능 옵션이 아니라 물리적으로
필요한 엔진 기능").

## 조사 (수리 전 원인 확정 — 후보 가설)
1. 탈출 결정 개방이 yielded 크레인을 제외하는가 (`_decision_cranes` 의 yielded 필터
   vs `_try_escape` 개방 경로의 상호작용).
2. 같은 시각 재개방 금지(_escape_at) + 미래 이벤트 부재 조합에서 재개방 기회 소멸
   (YR-141 검증에서 이미 "미래 이벤트가 전혀 없으면 종료까지 교착 유지" 위험 식별됨).
3. 탈출 후보의 plan/예약이 상대 크레인 장벽에 다시 거부되어 공동 조합이 전무.
4. 전략 WAIT 금지 하에서도 조합 부재 시 전 크레인 WAIT fallback(yr088:182-183)이
   yielded 를 재설정하는 순환.

## 수리 방향 (조사 결과에 따라 단일축 확정)
YR-143 spec 의 안전층 계약을 선행 구현: "정책이 WAIT 로 탈출을 회피하지 못하도록
안전층이 **최소 실행 가능한 escape 를 확정**한다. 동일시각 재결정·무한루프·비통과·
최소간격·예약 계약은 기존과 동일." — 엔진 계층(정책 선택 불요)에서 교착 술어 참 +
탈출 실행가능 시 강제 실행 또는 결정 재개방 보장. 골든 영향 전수 회귀 필수.
