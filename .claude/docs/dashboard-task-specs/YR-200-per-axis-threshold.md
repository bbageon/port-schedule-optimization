## 왜 같은 문턱이 다르게 먹나

문턱의 크기는 **"몇 개 중에서 골랐나"** 에 달려 있다(승자의 저주).

| 축 | 비교 폭 | 선택 편향 |
|---|---|---|
| 반입(공간) | 목적지 20곳 + 시간 1 = **21개 중 최소** | 크다 |
| 반출(시간) | 시간 **1개뿐** | **선택 편향 없음** |

반출은 고를 게 하나뿐이라 승자의 저주가 **원리적으로 발생하지 않는다.**
그런데 같은 문턱을 걸었다. 시간축은 문턱이 아니라 **다른 이유로**(축 자체가
손해라서) 막혔어야 했고, 공간축은 편향만큼만 막혔어야 했다.

[[YR-189]] 실측이 이를 뒷받침한다 — 편향이 공간 −0.1752 · 시간 −0.1617 로
비슷해 보이지만, **시간축의 그 값은 선택 편향이 아니라 축 자체의 손해**다.

## 설계 (단일축 · 값싸다)

`sell_margin` 을 **좌표 종류별로** 나눈다.

```python
UnifiedSellOrchestrator(sell_margin_space=ms, sell_margin_time=mt)
```

**격자는 실측에서 유도한다** (손으로 찍지 않는다):

| | 근거 |
|---|---|
| `ms` | 공간축 선택 편향. [[YR-199]] 잡음하한 × 0.48 계수 |
| `mt` | 선택 편향 **0** (후보 1개) + 축 자체 손해분 |

`ms = mt = 0.17` 이 [[YR-195]] 재현이므로 **대조군이 공짜**다.

## 판정 (사전등록 시 동결)

`(ms*, mt*) − greedy` 짝비교. **격자와 주판정을 실행 전 동결**한다.
**학습은 [[YR-195]] 체크포인트를 재사용**한다 — 문턱은 학습에 안 들어간다.
평가 대역은 **새로 연다**(9,700,000~ 는 YR-195 가 썼다).

## 왜 이게 다음 순서인가

남은 격차 +39.92 의 후보 셋 중 **가장 값싸고 근거가 직접적**이다.

| 후보 | 비용 | 근거 |
|---|---|---|
| **축별 문턱 (이 row)** | **평가만** (학습 재사용) | YR-195 실측이 직접 지목 |
| 정보 추가 ([[YR-198]]) | 학습 + 평가 | YR-199 가 여지 있음을 보임 |
| 환경 다양화 ([[YR-190]]) | 무대 변경 + 전면 재판정 | 실데이터가 근거 |

## 하지 않는 것

- 결과를 보고 `(ms, mt)` 를 고르는 것.
- 축별 문턱과 다른 축(정보·환경)을 같이 바꾸는 것.
- 규칙의 `gain_margin` 을 건드리는 것.
