# YR-314 — 크레인 정책 **규칙 6종 대비 판정** (판정 대역 · 28일 짝비교 · 한 번)

## 무엇을 하는 작업인가

학습 크레인이 **현실에 있는 규칙들**보다 비용을 얼마나 줄이는지 — 한 번만, 미리 정한
방식으로 잰다. 재배정 논문([[YR-233]])과 같은 격이다: 같은 날들을 모든 정책으로 굴려
날 단위로 짝짓고, 부호검정·윌콕슨으로 판정한다.

## 왜 이 방식인가 (사용자 지시 2026-09-14)

*"미래를 다 아는 크레인은 현실에 존재할 수 없으니, 저 규칙들보다 얼마나 개선됐는지
봐야 한다."* — 천장(오라클) 비교는 접고, **규칙 대비 개선**을 주장의 단위로 삼는다.

## 언제 하나 — [[YR-313]] 결과가 나온 뒤

판정 대역은 **한 번만** 쓴다(`USED_BANDS`). 아직 성적이 움직이는 망으로 쓰면 아깝고,
반대로 "이길 때까지 학습하고 판정" 은 결과를 좇는 것이다. 기준은 **"안정됐나"** 다:
- [[YR-313]] 에서 15,000 격차가 **더 안 줄면**(평탄) → 그 망으로 바로 판정
- 아직 줄고 있으면 → 한 번 더 이어 돌린 뒤(사전등록) 판정
- **어느 쪽이든 판정은 한다** — 붐비는 날에 져도 그것이 결과다

## 어떻게

| | 값 |
|---|---|
| 날 | 28일 — 달 계획기(`plan_month`)로 부하를 뽑는다(실제 달처럼 섞임) |
| 시드 | **새 판정 대역** 하나 — 착수 시 고르고, 판정 후 `USED_BANDS` 에 박는다 |
| 정책 | 학습 크레인 + 규칙 6종 (FIFO · LIFO · SPT · NEAREST · LWKR · RANDOM) + `SF_SPT` |
| 재배정 | **끈다** (`NO_REALLOC`) — 1단계는 크레인 축만 |
| 비교 | 날마다 학습 − 규칙 (짝) · 규칙마다 따로 |
| 검정 | 부호검정(양측) + 정확 윌콕슨 · 층화 부트스트랩 신뢰구간 |
| 보고 | 규칙별 감소율 · 부하별(한가/붐빔) · **본선/트럭 분리** |

⚠️ **판정 전에 코드를 동결한다** — 망 체크포인트 해시와 코드 커밋을 spec 에 박고,
그 뒤로 바꾸지 않는다. 판정 대역 시드는 로그에도 미리 노출하지 않는다.

## 판정 기준 (사전등록 — 착수 시 확정)

주 기준은 **`SF_SPT` 대비**(가장 강한 규칙)다. 나머지 5종은 부수 결과.
- 28일 중 이긴 날 수 · 부호검정 p
- 감소율 중앙값과 신뢰구간
- 부하별로 갈라 *"어디서 이기고 어디서 지나"* 를 숨기지 않는다

## 예산

28일 × 7정책 ≈ 196 에피소드. 날 단위로 병렬(20코어) → 약 1.5~2시간.

## 아직 하지 않는 것

- **2단계** — 새 크레인 위에서 재배정을 다시 학습 ([[YR-248]] 의 다음 단계). 크레인이
  달라지면 재배정의 좋은 답도 달라진다.
- **울타리 해제·특징 추가** — 판정 결과를 보고 다음 축을 정한다
