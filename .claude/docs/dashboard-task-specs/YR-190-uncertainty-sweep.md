# YR-190 — 불확실성 축 스윕: 학습이 규칙을 이기는 조건

- **Epic**: Exp / **Priority**: 🟠 / **등록일**: 2026-08-18 / **상태**: ⏸ PENDING
- **아키텍처 분류**: 이전 v1/v2 정책 무대 실험 — v3 정책 본선 판정 뒤 재검토
- **3대 게이트 보정 대상**: `performance`
- **1줄**: 지금 무대는 **거의 결정론**이라 공식이 정확하다. 공식이 정확하면 학습이
  이길 수 없다. **불확실성을 축으로 돌려 교차점을 찾는다.**

## 1. 발단 (2026-08-18 사용자 관찰)

> "실제로 통지 시각과 실현 게이트인이 차이가 나면, 더 Q 가 다채로워지겠지"

이 관찰이 오늘 결과의 **가장 단순한 설명**일 수 있다.

## 2. 현 무대의 불확실성 — 거의 없다 (실측)

| 잡음원 | 값 | 24시간 무대 |
|---|---|---|
| 예약 준수 오차 | σ=600초 **정의는 있음** | ❌ `ScheduledAnnouncer` 는 안 씀 (`adherence` 0건) |
| 주행 잔차 | **σ = 5초** | ✅ |
| 출문 소요 | 변동계수 0.12 | ✅ |
| 크레인 서비스 | **결정론** (기준 180초) | — |

주행이 4~7분인데 편차가 **5초**다. **통지 = 실현**이고, 사실상 결정론이다.

## 3. 왜 이것이 결과를 설명하나

배정기 공식은 **전부 기댓값**이다.

```python
wait_pred = 대기열 × 평균서비스시간 / 크레인수
o_hat = eta + wait_pred + 서비스 + 게이트주행
```

**세상이 결정론이면 기댓값 = 실제값이다.** 공식이 정확하면 학습이 배울 것은
"공식이 틀리는 부분"인데, 안 틀리면 **배울 게 없다.**

→ [[YR-179]]·[[YR-180]] 의 "규칙이 학습을 이김"이 **정책 문제가 아니라 환경
성질**일 수 있다. 이 프로젝트가 단일 야드에서 두 번 내린 결론("헤드룸 부재는
문제 성질")과 같은 계열이다.

## 4. 무엇을 하나

`ScheduledAnnouncer` 에 준수 오차를 주입하고 **σ 를 축으로** 돌린다.

```
σ = 0(현행) · 300 · 600 · 1200 초
```

각 σ 에서 **규칙 대비 학습**을 재고, σ 에 대해 그린다.

| 결과 | 뜻 |
|---|---|
| 교차점 존재 | **"σ 가 X 를 넘으면 학습이 낫다"** — 정량적 조건 |
| 전 구간 규칙 우세 | **"이 범위에서는 해석적 공식이 최적에 가깝다"** — 이것도 결과 |
| σ 무관하게 격차 일정 | 불확실성 가설 기각 — 다른 원인 |

## 5. 왜 이 순서인가 (YR-189 뒤)

**σ 를 먼저 넣으면 안 된다.** 결과가 나빴을 때 "구조가 나쁜가 σ 가 나쁜가"를
가릴 수 없다. [[YR-189]] 로 Q 전환이 작동하는지 먼저 본 뒤, 그 구조 위에서
σ 를 돌린다. **한 번에 한 축**(AGENTS.md 설계 원칙 2).

```
YR-187 A단계(스키마) → YR-189(Q 전환) → YR-190(σ 스윕)
```

## 6. 논문에서의 위치

지금 서사는 *"RL 을 해봤는데 규칙에 졌다"* 다. 이 실험이 통과하면:

> **"이 문제에서 학습이 규칙을 이기는 조건은 불확실성이다. 결정론에 가까운
> 환경에서는 해석적 공식이 최적에 가깝고 학습이 더할 것이 없다."**

**"언제 RL 을 써야 하는가"에 대한 정량적 답**이 된다. 실패담이 아니라 조건을
밝힌 결과다.

## 7. 주의

- **σ 값은 측정이 아니라 가정**이다(YR-162 의 600초는 "저장소 선례"). 하나로
  정하지 말고 **범위로** 돌려야 하는 이유다. 실데이터가 오면([[YR-187]] B단계)
  실제 σ 를 이 곡선 위에 **찍기만** 하면 된다 — 재실행 불필요.
- 준수 오차는 **공개값(통지·예약)은 그대로 두고 실현만 어긋나게** 한다.
  정보 경계 계약 유지 — `realized_gate_in_s` 경로가 이미 그 계약이다.
- σ 를 올리면 규칙도 나빠진다. 판정은 **격차**이지 절대값이 아니다.

## 8. 하지 않는 것

- 결과를 보고 σ 격자를 바꾸는 것.
- σ 를 올려 학습이 이기는 지점만 골라 보고하는 것 — **전 구간을 보고**한다.
- 실데이터 없이 "실제 σ 는 이만큼"이라 주장하는 것.
