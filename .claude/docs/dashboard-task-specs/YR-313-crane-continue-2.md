# YR-313 — 이어서 36회차 더: 붐비는 날(15,000)도 내려가나

## 무엇을 하는 작업인가

[[YR-312]] 의 72회차 체크포인트에서 **이어서** 36회차(72~107). 조건은 그대로.

## 왜 지금 하나

[[YR-312]] 가 *"아직 내려가는 중"* 으로 답했다 — 궤적 평균이 +2.24% → −0.48%,
뒤 절반 −1.56%. 고정 평가일 3개에서도 3,500(−0.24%)·7,500(−0.75%)은 이기는데
**15,000 만 +3.31% 로 진다.** 규칙(최단작업 우선)이 붐빌수록 강해서 마지막 벽이다.

두 가지 중 하나다:
- **15,000 도 내려가는 중** — 82.88% → 3.31% 까지 왔으니 더 돌리면 넘는다
- **15,000 이 바닥** — 8칸 특징으로는 붐비는 날의 규칙을 못 넘는다 → 정보 축으로

## 어떻게

`--resume outputs/v4/crane-continue/crane_071.pt --iters 36`. 나머지는 [[YR-312]] 와
같다 (계수 1.0 · 라벨 64 · 창 3시간 · 10코어 · 시드 바닥 9,900,700). 회차 72~107 →
새 날들.

끝나면 **108회차 망**을 고정 평가일 3개에 넣는다 (`evaluate`, 학습과 같은 시드).

## 판정 기준 (사전등록 — 실행 전에 확정)

| | [[YR-312]] (72회차 망) | 이번 (108회차 망) |
|---|---|---|
| ① **15,000 격차** | +3.31% | **더 작아져야 한다** ← 주 기준 |
| ② 3부하 중앙 | −0.24% | 0 이하 유지 |
| ③ 이긴 날 | 2/3 | 2/3 이상 유지 |

- ①이 **0 이하**면 → 3부하 전부 이긴다. **판정 대역 진입 준비**로 넘어간다
  (규칙 6종 · 28일 짝비교 · 사전등록).
- ①이 줄었지만 양수면 → 한 번 더 이어 돌린다 (같은 규칙으로).
- ①이 **안 줄거나 커지면** → 15,000 이 바닥. 회차가 아니라 정책의 **정보**로
  축을 옮긴다 (연구 원칙 2 — 한 축씩, 첫 후보는 "이 블록에 밀린 대수").

⚠️ 3,500·7,500 이 다시 양수로 돌아서면 ①이 통과해도 채택하지 않는다 — 붐비는 날을
배우느라 한가한 날을 잊은 것이라 균형이 깨진 것이다.

## 예산

10코어 36회차 ≈ 5시간 + 3부하 평가 0.25시간 ≈ **5.3시간**.

## 아직 하지 않는 것

- **특징 추가·울타리 해제** — ①이 "바닥" 으로 나온 뒤에만
- **규칙 6종 대비 판정** — 3부하 전부 이긴 뒤에. 판정 대역은 한 번뿐이다
