### 어떻게 가르치나

크레인이 *"A트럭 먼저? B트럭 먼저?"* 를 고르는 순간마다 **두 세계를 굴린다**:

```
세계 A   실제로 고른 일감을 한다      → H시간 뒤 비용 Φ_A
세계 B   대신 차점자를 했다면          → H시간 뒤 비용 Φ_B
정답     (그 세계 비용 − 두 평균) ÷ 눈금
```

재배정층([[YR-205]])과 **같은 규약**이다 — 부트스트랩 없이 시뮬레이터가 실제로 재서
가르친다. 평균을 빼는 이유도 같다(안 빼면 *"이 상황은 원래 비싸다"* 를 배운다).

### ★대안은 **차점자**를 쓴다

무작위로 고르면 뻔한 나쁜 후보와 비교해 배울 게 없다. 망이 **두 번째로 좋다고 본 것**과
견줘야 *"1등과 2등 중 진짜 1등은 누구였나"* 를 배운다.

### ★눈금 계측을 넣었다 — [[YR-299]] B 의 교훈

`CraneFitReport.median_gap_krw` 가 **매 회차 목표 중앙격차를 기록**한다.
[[YR-299]] B 는 이 계측이 없어 *"눈금이 안 맞아서 나빠진 건가"* 를 **검증조차 못 했다**
(원값이 어디에도 안 남았다). `scale_health()` 가 한 줄로 판정한다:

```
목표 중앙 0.3~3.0   적정
       < 0.3        눈금이 크다 — 신호가 묻힌다
       > 3.0        눈금이 작다 — 학습이 튄다
```

⚠️ `CRANE_ADV_SCALE = 100,000` 은 재배정층 값을 빌린 **잠정치**다. 첫 실학습에서
실제 격차를 재서 다시 못박아야 한다.

### 검증 — 배울 수 있는 문제로 실증

*"오래 기다린 트럭을 먼저 하면 싸다"* 는 가짜 문제를 만들어 학습기가 **실제로 배우는지**
확인했다:

```
표본 480 학습 / 120 검증 · 600 스텝
학습 손실 0.1723 · 검증 손실 0.1894
목표 중앙격차 111,921원 → 적정 (목표 중앙 1.12)
대기 0.2h 점수 +0.758  ·  대기 1.8h 점수 -0.826   → 배웠다
```

**이 시험이 없으면 학습기가 도는지, 손실 숫자만 찍는지 구분 못 한다.**

### 검증분은 **결정 단위**로 가른다

한 결정이 표본 둘(고른 것·대안)을 만드는데 그 둘이 학습·검증으로 갈리면 **같은 결정을
보고 채점**하는 셈이라 검증이 낙관적으로 나온다. `test_val_split_is_by_decision` 이 지킨다.

### 아직 안 한 것 — 실제 무대 배선

지금은 **부품이 다 있고 연결이 안 됐다.** `crane/teacher.py` 를 부르려면 엔진이
결정마다 훅을 쏴 줘야 하는데, 재배정층은 `bridge.on_decision` 이 그 자리다.
크레인층에는 아직 그런 자리가 없다.

```
남은 배선   ① 크레인 결정마다 후보 점수·특징을 남긴다 (CranePolicy.record 는 있으나 안 불림)
           ② 그 결정에서 분기 세계 둘을 굴린다 (BranchPool 재사용)
           ③ 하루 끝에 CraneTrainer.fit 을 부른다
           ④ --dispatcher RL_CRANE 로 학습을 거는 CLI
```

**②가 가장 무겁다** — 크레인 결정은 하루 수만 건이라 전부 굴릴 수 없다. 재배정층처럼
**하루 K건만 뽑는 예산**이 필요하다(재배정층은 64건/일).
