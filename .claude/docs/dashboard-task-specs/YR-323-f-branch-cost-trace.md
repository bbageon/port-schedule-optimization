# YR-323-f — 분기별 비용 항목·후속 작업 기록

**상태**: backlog

등록: 2026-11-10. [YR-323-a 기존 자료 점검](../../../outputs/reports/yr323_horizon_cause_audit/README.md)에서 파생.
현재 등록은 측정 설계이며 새 시뮬레이션 착수가 아니다.

## 무엇과 왜

K1/K6 판단 반전 87건 중 78건은 6시간을 온전히 관측한 선택이다.
기존 분기 비교 1,180건은 합계 비용만 남겨 시간별·업무별 반전 원인을 식별할 수 없다.
같은 첫 선택의 이후 진행과 비용 네 항을 기록해 직접 효과·후속 순서·관찰 끝의 영향을 구분한다.
“긴 창이라 잡음이 많다”, “본선을 위해 트럭을 희생한다”를 원인으로 미리 확정하지 않는다.

## 선행과 실행 경계

- 기존 운반·예약 현실성 보정(i/f)과 현재 게이트의 선행 순서를 따른다.
- 새 실행 전 대상 입력·시드·K·첫 공동 배정·측정 시각·허용 오차를 별도 계약으로 고정한다.
- 기존 합성 조건을 복원한 진단과 실측 보정 환경의 진단은 별도 결과로 남긴다.
- 측정기 외 정책·보상·후보·후속 정책·운반 설정·학습량을 이 작업에서 함께 바꾸지 않는다.

## 기록할 값

1. 실제 선택과 대안 각각의 트럭 체류·본선 유휴·빈 이동·재취급 비용 및 합계.
2. 결정 시각과 1·2·3·6시간 뒤의 비용 계수기, 실제 종료 시각, 미완료·미도착 건수.
3. 첫 공동 배정 전체와 이후 결정·작업 시작·완료 기록, 외부 도착의 수락·보류·거절.
4. 입력에 보인 마감·대기 상한 값과 기록 가능한 원래 값. 미래 실현값은 분석용으로만 보존한다.

## 검증과 완료 기준

- 측정 추가 전후 첫 공동 배정·이벤트·완료·합계 비용이 일치해야 한다. 기록으로 정책이 달라지면 실패다.
- 비용 네 항의 합계와 기존 합계 비용, 기록된 시각과 실제 진행 범위를 대조한다.
- K별 공통 구간의 사건 일치 여부를 먼저 검사한다. 불일치하면 종료점 차이를 순수 구간 기여로 해석하지 않는다.
- 종료 때문에 짧아진 비교와 완전한 비교를 분리하고, 처음 선택의 직접 영향과 이후 선택 변화를 구분한다.
- 독립 진단용 입력에서도 같은 손실 기제가 재현될 때만 a의 조건부 개선 작업을 연다.
- 차이가 설명되지 않으면 미확정으로 남긴다. 이 작업 자체가 성능 개선이나 현실성 통과를 뜻하지 않는다.
