# YR-143 — 무-재배치 대조군: PREPOSITION 존재 가치의 가장 깨끗한 검증

## 무엇을 왜 (16차 피드백 2026-08-02)
16차 피드백의 핵심 제안: "가장 깨끗한 실험은 **작업 처리(SERVE)+선재조작(PRE_REHANDLE)만
하는 정책**과 여기에 **작업 연계 PREPOSITION만 추가한 정책**을 비교하는 것. 개선이
없다면 PREPOSITION도 제거할 수 있다." 저장소 전수 확인 결과 이런 무-재배치 대조군은
과거에 없었다 — 행동공간 소거는 전부 WAIT 축(YR-052·YR-119)이었고, 후보 생성기에
REPOSITION 차단 스위치 자체가 없다.

## 설계 (착수 시 판정 동결)
- **비교군 2 (동일 학습 예산·동일 PPO 계약)**:
  - C0 = SERVE + PRE_REHANDLE (재배치 후보 생성 완전 차단 — 교착 탈출은 안전기능이라
    비교 대상이 아니므로 유지, 구조적 WAIT 유지)
  - C1 = C0 + 결속 PREPOSITION (YR-142 v4-B-2 형태: 결속·근접 소멸·만료 내재·재발행 금지)
- **구현**: `candidates.py` 에 REPOSITION 차단 스위치 신설(탈출 bay 는 예외), 학습·평가
  공용. 단일축 원칙 — C0/C1 차이는 PREPOSITION 유무뿐.
- **판정(스케치 — 착수 시 동결)**: 짝지은 신규 미열람 대역에서 (C1−C0) v2 실현
  지연비용·본선 초과·v1 전체비용 방향. C1 이 개선 없으면 PREPOSITION 도 행동공간에서
  제거하는 근거가 된다.
- **선결**: YR-142 판정 종료(그 결과와 무관하게 수행 가능 — C1 정의만 YR-142 판정판을
  따름).

## 배포 전제 노트 (피드백 지적)
실제 PoC 터미널의 TOS/ECS(터미널 운영 시스템/장비 제어 시스템)가 "컨테이너 작업 시작 전
빈 크레인 이동명령"을 지원하는지 별도 확인 필요 — 미지원이면 PREPOSITION 은 배포
행동에서 제외(연구 결론과 배포 행동공간은 분리 기록). YR-082 자료등급 확인 시 함께.
