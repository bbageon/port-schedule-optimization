# YR-230 · 정책이 "미룬 곳이 붐빌지"를 못 본다 — 도착 압력 1칸

> Epic RL · 우선순위 🔴 · 상태 🟢 **진행 중** (등록 2026-08-25 · 착수 사용자 지시 "230 진행해줘")
> 근거 [[YR-227]]·[[YR-231]] · 대조군 [[YR-222]] · 판정 방식 [[YR-229]]

## 1. 문제 — 실측으로 확인한 것

[[YR-231]] 이 확인한 것: **라벨은 여전히 오전을 "이득" 이라 말한다**(6/8 · 실제와
28배 반대). 그런데 정책은 오전 거래를 줄였다 — 망이 **다른 특징으로 우회**한 것이고,
그 우회는 부하 3,500 에서만 통했다(5,000 은 오전 손해 +5,546만원이 그대로).

코드를 열어 보니 **볼 칸 자체가 없었다.** Seller 행동 8칸:

```
[KEEP, SPACE, TIME, 목적블록부하, 목적블록여유, 경로차이, ★몇 분 미루나, 안벽거리]
```

**"미룬 그 시각이 붐빌지" 를 나타내는 칸이 하나도 없다.**

| 막힌 곳 | |
|---|---|
| `announced_soon` | **지금부터 30분**만 센다(`_ANNOUNCE_HORIZON_S=1800`) — 2시간 뒤로 미루면 그 시각을 못 본다 |
| `slot_load` | Seller 함수가 인자로 받지만 **출력에 안 넣는다 — 죽은 인자** |
| `slot_capacity` | 실측 `{}` → `_slot_left(3)` = `None` ([[YR-176]] 미구현) |

## 2. 처방 — **한 칸만** 넣는다 (설계 원칙 2)

`announced_around(mbt, bid, center_s, orders, half_w=1800)`
= `center_s ± 30분` 에 그 블록으로 **통지된** 물량 수.

세 행동 모두에 값을 준다 — 그래야 서로 견줄 수 있다:

| 행동 | 도착 압력을 어디서 재나 |
|---|---|
| `KEEP` | `in_out_reserve_s` 시각 · **현재 블록** |
| `SPACE` | `in_out_reserve_s` 시각 · **목적 블록** |
| `TIME` | `in_out_reserve_s + defer_s` 시각 · 현재 블록 ← **급소** |

**정보 경계를 지킨다** — `in_out_reserve_s` 는 **통지된 예정**이지 실현 게이트인이
아니다. `announced_soon` 과 **같은 출처**라 새로 열리는 정보가 없다.

`SELLER_ACTION_DIM` 8→9 · `SELLER_ROW_DIM` 23→24 · 파라미터 5,761→5,825.
⚠️ 이전 체크포인트(`ckpt_023`·`ckpt_015`)는 23칸 계약이라 **새 코드로 못 읽는다.**
[[YR-229]] 의 대조군 수치는 이미 박제돼 있으므로 재실행이 필요 없다.

## 5. 하지 않는 것

- Buyer 특징은 **안 건드린다** (한 번에 한 축). `slot_load` 죽은 인자·`slot_capacity`
  미구현([[YR-176]])도 그대로 둔다.
- 라벨 지평([[YR-227]])은 **안 건드린다** — 이 축이 끝나야 무엇이 효과였는지 안다.

### ★부수 측정 — 재배치는 **트럭 대기**만 움직인다 (2026-08-25)

같은 질문이 나와 쟀다: *"판매 비용과 크레인 비용은 무슨 관계인가."*
학습 전 초기망 · 4일 중앙값 · `NO_REALLOC` 대비.

| 항 | 부하 5,000 Φ 비중 | **재배치가 움직인 몫** |
|---|---|---|
| ① 트럭 대기 | **91.6%** | **99.5%** (−11,406,269원) |
| ③ 재조작 | 7.3% | 0.3% (−36,000원) |
| ④ 본선 유휴 | 1.6% | 0.1% (−15,674원) |
| ② 크레인 빈 주행 | **0.35%** | 0.1% (−10,224원) |

**Φ 는 사실상 트럭 대기 비용이고, 재배치는 그것만 움직인다.**
크레인 직접 비용(②+③)은 Φ 의 7.6% 인데 재배치가 건드리는 몫은 **0.4%** 다.
→ 판매 결정은 *"트럭 대기 시간을 사고파는 것"* 이다. 크레인은 무대의 물리이지
거래 대상이 아니다.

부하 3,500 은 트럭 대기 변화 자체가 작아(−99,778원) 본선(45.2%)·재조작(14.7%)이
상대적으로 커 보이지만 **절대액은 전부 십만원 안팎**이다.

⚠️ **관찰 하나** — 이 초기망(24칸)은 부하 5,000 에서 거래 3,111건에 **−9,468,456원
이득**이 났다. [[YR-229]] 의 초기망(23칸)은 같은 부하에서 거래 675건에 **+10,713,750원
손해**였다. 입력 차원이 바뀌어 **완전히 다른 무작위 망**이고 날도 4일뿐이라
