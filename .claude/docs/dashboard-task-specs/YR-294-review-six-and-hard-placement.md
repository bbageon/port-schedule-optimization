## 1. 시각자료가 문장을 끊는 문제 (사용자 스크린샷 3장)

### 원인

**부동체(float)이기 때문이다.** `figure`/`table` 환경은 LaTeX 이 자리를 고르고,
본문은 그와 무관하게 흐르다 쪽이 끊긴다. 그 자리가 문장 중간이면 방법이 없다.

**통제되지 않는 것을 하나씩 실측했다.**

| 시도 | 결과 |
|---|---|
| 캡션 축약 2,193 → 1,940자 | 문장 경계 변화 **0** |
| 캡션 채움 27조합 (+0~2줄 × 3) | 변화 **0** |
| 배치 지정자 8조합 | "쪽 위"는 3→0 으로 고쳤지만 문장 경계는 그대로 |
| `[H]` (float 패키지) | **유일하게 통한다** |

## 2. 전달받은 검토 6건 — 여섯 다 타당했다

### ① 🔴 `C_move = 60,000 million` — **내가 낸 오류다**

`1a1e405`(bn/m 풀어쓰기)에서 정규식 `\,m(?![a-z])` 가 **수식의** `\,m`(크레인
추가 작업시간)까지 `million` 으로 바꿨다. `C_move = 60{,}000\,m` 으로 되돌렸고,
나머지 `million` 넷은 정상 통화 표기임을 전수 확인했다.

**왜 못 잡았나**: `verify_submission.py` 는 **값**을 대조하지 클 기호를 안 본다.
숫자는 60,000 그대로였으므로 통과했다. → 후속 [[YR-295]].

### ② 🔴 식 (1) 과 $w_i$

코드는 `0.0 < dt <= w` 로 막는데(`market.py:112`) 논문 식에는 그 조건이 없어
리드가 음수면 $w$ 도 음수가 된다. 식에 $\tau_i>t$ 를 넣고 *"has $w_i=0$"* →
*"has $w_i\le0$"* 로 고쳤다.

### ③ 🔴 중앙 확정의 정렬

`resolver.py:70` 이 `predicted_phi`(짝중심 점수)로 **서로 다른 job** 을 정렬한다.
코드 주석도 *"결정론"* 목적이라 적혀 있다. 짝 안에서 평균을 뺀 값이 짝 사이에
비교 가능하다는 보장이 없으므로 그 사실을 원고에 적었다 — *"…they are not
calibrated across jobs, so this order fixes a deterministic sequence rather
than a priority."*

### ④ 🔴 날의 독립성

상태가 날 경계를 넘으므로 28일은 독립 표본이 아니다. *"Days are treated as
independent comparison units"* 를 고쳐, **공통 궤적 위의 짝비교**이지 독립
반복이 아님을 밝혔다.
