# YR-332-ac — 교사 세계와 비용 계산의 종료 시각 일치

- **상태**: in-progress
- 3대 게이트 보정 대상: scenario_validity — 진행하지 않은 시간의 비용을 계산하는 장부 계약 보정.
- 등록 2026-11-09. ab 재학습 도중 독립 검산에서 확인. 사용자 지시 1~3단계의 환경 계산 확인에 해당.

## 관측

현재 분기는 t+10800초로 비용을 계산하지만 블록은 min(기존 종료,t+10800)에서 멈춘다.
26시간 환경에서 일부 수집 창의 요청 끝이 약 26.9시간이었다. 이후 사건은 진행하지 않으면서
미완료 비용을 더 쌓는 경로다. ab 첫 실행은 8개 수집 자료를 보존하고 최종 평가 전에 중단했다.

## 수정·검증

- 분기 비용 종료를 요청 끝과 모든 블록의 기존 종료 중 최솟값으로 통일한다.
- 단축된 창의 실제 길이와 건수를 자료에 남긴다. 이는 최대 3시간의 유한 에피소드 교사다.
- 첫 결정은 기존/수정 교사 각각의 계약을 지키고 두 분기의 관측 종료는 동일해야 한다.
- 짧은 실제 환경에서 요청 창이 환경을 넘는 경우를 재현하고, 비용·동기화·본선 계산의 끝을 검사한다.
- 환경 끝을 넘지 않는 경우와 직렬/병렬 일치도 함께 확인한다.
- 운반차·비용 단가·행동 후보·신경망은 변경하지 않는다. 이 보정 후 ab 두 군을 처음부터 재수집한다.
