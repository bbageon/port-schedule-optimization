## 연구질문

크레인 작업순서가 달라도 재배치 정책의 비용 절감 방향이 유지되는가?

## 왜 별도 재학습이 필요한가

재배치 정책 입력의 크레인 대기 작업량은 작업순서가 만든 상태다. 반사실 라벨도 그
작업순서 아래에서 만들어진다. 한 규칙에서 학습한 정책을 다른 규칙에 그대로 적용하면
일반성이 아니라 전이 성능을 측정하게 된다.

## 동결 설계

- 서로 성격이 다른 세 규칙: 최단 처리시간, 선착순, 무작위 순서
- 같은 9일 학습 시나리오와 같은 학습 난수시드를 사용하고 규칙만 바꾼다.
- 각 규칙에서 별도 정책을 학습한다.
- 새 30일 난수시드에서 규칙별로 재배치 없음과 학습 정책을 짝비교한다.
- 전체 가중 결과와 다섯 수요수준별 결과를 함께 보고한다.

## 완료 조건

- YR-246에서 학습 효과가 먼저 확인된다.
- 규칙별 체크포인트와 평가 원자료가 분리 저장된다.
- 각 규칙 안의 날별 비용 차이·승패·부호검정을 보고한다.
- 불리한 규칙과 수요수준도 함께 공개한다.
