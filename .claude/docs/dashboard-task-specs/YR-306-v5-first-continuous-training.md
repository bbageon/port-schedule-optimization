# YR-306 — v5 최초 연속 학습 시작

- **상태**: backlog
- 사용자 요청: 2026-09-10, "시작하고, 지금 구성이 어떻게 되어있는지 설명해줘".
- 대상은 v5 통합 블록 PPO다. 별도 진행 중인 v4 크레인 교사 작업과 섞지 않는다.
- 3대 게이트 보정 대상: `reliability` — 30일 연속 학습 연결·기록·실행을 검증한다.
- 현재는 시작 전 조건 확인 단계이며 학습 프로세스는 아직 실행하지 않았다.

## 확인된 현재 상태

- v5는 21블록의 판매·구매·크레인에 하나의 정책망을 공유한다.
- 실제 60초 구간의 비용 증가분을 보상으로 기록하고 PPO로 갱신한다.
- 반사실 세계 복제는 새 PPO 경로에서 사용하지 않는다.
- 현재 기본값: 60구간 수집, 2회 반복 갱신, 묶음 크기 64, 학습률 0.0003.
- 명령행 진입점은 최대 하루인 디버깅용이다. 두 날짜를 만들고 중간에 멈춘다.
- 장기 학습의 준비일·정리일 제외, 날짜별 저장·보고·중단 복구 계약은 별도 연결이 필요하다.
- 연구 시작 점검의 공용 최신 파일은 이전 정책에 대한 기록이다.
  이를 v5의 성능·현실타당성 통과 증거로 승계하지 않는다.

## 시작 조건

1. 연구 시작 점검을 실행하고 결과를 원자료로 남긴다. 거부되면 착수하지 않는다.
2. v5에 맞는 시작 조건과 연속 학습 실행 범위를 확정한다.
3. 실행기·설정·시드·관측/비용 계약을 고정한 커밋에서 짧은 배선 검사 후 시작한다.
4. 다른 무거운 학습이 실행 중인지 확인한다. CPU를 임의로 중복 점유하지 않는다.
5. 기존 모델·결과는 덮어쓰지 않는다. 비선형 본선 비용·6시간 통지창을 함께 추가하지 않는다.
