# YR-332-bb — 확인된 진입 시각을 수요 보정에도 적용

- **상태**: backlog
- 파생: YR-332-ba, 2026-11-18.
- **3대 게이트 보정 대상**: `scenario_validity` — 사건 시각 근거를 수요 보정의 의존 자료까지 연결한다.

## 무엇과 왜

ba는 실제 진입 시각 근거가 확인되는 표본으로 예약·통지 보정을 분리했다.
날짜별 곡선·분별 도착·여러 컨테이너 방문 연결의 물리 입력은 전후 비교를 위해 고정했다.
의존 보정에도 미확인 기록이 일부 들어갔으므로 같은 출처 기준으로 맞추는 작업이 남는다.

확인된 영향은 전체 진입 기록34,304→33,703건, 반출 비율−0.09777%p,
시간대 구성비 최대0.06523%p 변화, 재집계 방문27,415→27,395번, 분별 칸22개 변화다.
기존 허용 방문 패턴26,501→26,502개이며 단독 반출1개 증가 외 패턴 횟수는 같다.
이 작은 차이를 성능 무영향의 증거로 삼지 않는다.

## 범위와 순서

1. 현재 공통 판정으로 현실성 직접 보정 착수 허가를 받는다.
2. ba의 원본 시각 확인 기준·원본600파일 해시·제외 표본을 그대로 쓴다.
3. 적용 전 비교할 물량·곡선·시드·변경 허용 필드·통과 기준을 고정한다.
4. 같은 곡선 가족·같은 수식·같은 날짜 구분을 유지하고 보정 표본만 바꾼다.
   날짜별 물량/시간대·반출 비율, 분별 강도, 방문 패턴을 순서대로 따로 검산한 뒤 연결한다.
5. 기존 생성기·기존 profile·과거 성능 결과를 덮어쓰지 않는다. 새 보정과 전후 입력 근거를 별도 파일로 만든다.
6. 주문 보존·방문 연결·예약/통지 계약·정확 재현·기존 자료 불변·보고 수치를 검사한다.

## 제외 범위와 완료 조건

신경망 구조·보상·PPO·정책 성능 비교는 하지 않는다. 고물량 외삽을 실측으로 바꾸는 작업도 아니다.
모든 의존 보정에 확인된 시각 기준이 연결되고 전후 변화가 분리 집계되면 이 범위를 완료한다.
대기 수 정의 f, 내부 운반 흐름 i, 고물량 근거 ap는 그대로 남으며 전체 현실성 통과를 주장하지 않는다.
