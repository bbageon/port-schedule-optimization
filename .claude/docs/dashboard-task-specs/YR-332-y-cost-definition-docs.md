# YR-332-y — 비용 정의 문서와 코드의 불일치 정리

- **상태**: backlog
- 등록: 2026-11-07. 상위 [[YR-332]], 발견 작업 [[YR-332-t]].
- 신뢰성(기록이 서로 맞는가) 보정 한 축. 비용 값·궤적·학습은 바꾸지 않는다.

## 무엇과 왜

비교 기준 감사(t)에서 v7 비용의 문서 설명과 실제 코드가 다른 곳을 찾았다.
값을 바꾸자는 것이 아니라, 지금 무엇을 재고 있는지 문서가 정확히 말하게 하려는 작업이다.
문서가 틀리면 다음 실험의 해석(예: “빈 이동 비용이 줄었다”)이 잘못 읽힌다.

## 확인된 불일치

1. 크레인 빈 이동 항: `reward/phi.py`·`stage/episode.py:yc_empty_travel_s` 설명은
   “재배치·재조작 때문에 생긴 추가 이동”이지만, 엔진(`engine.py` 계획·완료 시 `add_travel`)은
   모든 작업의 빈 갠트리 접근 이동을 센다. 파내기 중 빈 귀환도 포함된다.
2. `.claude/docs/architecture/04-비용과-보상.md` §1-1 단가표는 본선 2.99원/GT·시간이다.
   v7 코드는 35.88원이다(코드 주석에 세대 차이 설명은 있음).
3. YR-207 결정 기록의 목적식은 할증 없는 선형·YC 40,000원/시간이다. v7은 1시간 초과 할증
   (+40,000원)·YC 60,000원/시간이다. 변경 경위를 결정 이력으로 연결해야 한다.
4. 용선료 환산표의 대형선 32.25원/GT·시간은 같은 표의 세 시장값으로 재현되지 않는다
   (4,300~8,000TEU 구간 선형 외삽 29.85원). 구현은 중앙값 35.88원 하나라 실행 영향은 없다.
5. 문서↔코드 자동 대조(`verify_architecture.py`)는 v3 경로와 트럭 단가·항 수·선급 수만 본다.
   v7의 본선·빈 이동·재조작 단가와 v7 경로를 검사하지 않는다.

## 완료 기준

- 문서를 코드의 실제 측정량에 맞춘다. 측정량 자체를 바꾸려면 별도 사전등록·재평가 row로 분리한다.
- 결정 이력(strategy-history)에 단가·할증 변경 경위를 연결한다. 과거 결과는 수정하지 않는다.
- 자동 대조에 v7 단가 계약을 추가하고 통과를 확인한다.
