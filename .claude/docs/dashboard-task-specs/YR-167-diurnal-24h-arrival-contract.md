## 환경 구현 (2026-08-11)

- `diurnal_rate`/`diurnal_arrivals` — 야간 상수 + 이중 정규(11h σ1 / 15h σ2·질량
  1:2)의 역CDF 층화균등 사상. 3,600대·평균 150/h·야간 22.5/h·순간 최대 488.7/h.
- `vessel_schedule_24h` — 30 스트림을 창 전체에 등간격 배치, 시작 순서로 블록 회전.
- `_retime_vessels` — 본선 이동 시 **연계 야드 작업 release_time 까지** 이동.
- `build_diurnal` — 배경 + 트럭 명단 사전 확정. 초기 채움(fill) 개념 없음.
- `ScheduledAnnouncer` — 개방 루프(전역 계수 미참조) → 투입기 오염 경로 소멸.
- `OBS_24H` — 워밍업 2h + 측정 22h. **`DIURNAL_DRAIN_S` 배수 2h**(39차 감사):
  엔진이 `블록도착 > sim.end` 투입을 거부하므로 지평이 도착일보다 길어야 하루 끝
  게이트인까지 전건 투입된다. 배수 구간은 측정 대상이 아니다.
- `ensure_time_ledger` — 초기 트럭 0 인 sim 에 v2 장부를 런너에서 활성.
- `_sim_from(scn, profile)` — **시나리오 생성 프로파일을 엔진에 주입**(기본값 유지로
  기존 호출부 바이트 불변).
