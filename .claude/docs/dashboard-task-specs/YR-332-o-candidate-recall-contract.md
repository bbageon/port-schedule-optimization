# YR-332-o — 후보 누락률·전체 후보 기준 비교 계약

- **상태**: backlog
- 실행 승인: 2026-11-05 사용자 6단계 실험의 2단계. `docs/research/v7-discharge/six-step-prereg.md`.
- 등록: 2026-11-05. 사용자 요청: 후보 생성·학습 개선을 문헌·상용 시스템과 대조, 재현율 우선.
- 상위: [[YR-332]], 연계: [[YR-332-n]]·[[YR-332-p]]. 연구 검토 결과이며 구현·효과 검증 전이다.

## 무엇과 왜

현재 `world/integrated/candidates.py`는 `_serve`·사전 준비·이동의 계획을 만든 뒤
`_prune`에서 기본 12칸(WAIT 포함)까지 줄인다. 필수 후보가 많으면 초과 보존한다.
따라서 이전 9쌍의 결과 일치는 **같은 제한에서 계산을 보존했다**는 증거다.
가능한 작업 전체 또는 좋은 작업을 놓치지 않았다는 증거는 아니다.

## 재현율의 정의를 분리

사용자에게 의미 확인을 요청했으며, 답변 전에는 아래를 모두 구분해 기록한다.

1. **후보 재현율**: 그 순간 알려진 정보와 물리 조건상 선택 가능한 작업 중 포함한 비율.
2. **좋은 후보 보존**: 전체 후보 기준에서 가장 좋은 것으로 평가된 작업이 남는 비율.
3. **실험 재현성**: 코드·입력·모델·난수·사건 순서를 고정하면 같은 선택·결과가 나오는가.
4. **현실 재현성**: 예약 오차·장치율·장비 용량·처리시간이 근거 자료와 맞는가.
   이는 후보 재현율 수치로 대신하지 않으며 [[YR-332-f]]·[[YR-332-i]]·[[YR-332-m]]에 연결한다.

## 비교 기준

- 기준 집합은 미래 실현 정보를 보지 않는 **개수 제한 전 실행 가능 행동**이다.
  아직 도착하지 않은 오더의 실제 하역은 실행 후보에 넣지 않는다.
  그 오더를 위한 지금 가능한 사전 준비는 별도 행동으로 포함할 수 있다.
- 작은 결정에서는 독립 전수 검사로 기준 생성기 자체도 점검한다.
  같은 생성기의 잘린 목록끼리 대조해 재현율 100%라 보고하지 않는다.
- 비율의 분모가 0인 결정은 별도 계수한다. 반입·반출·적하·양하와 혼잡도별로 나눈다.
- 같은 모델의 전체 후보 최고점 보존과, 같은 미래 입력을 쓴 시뮬레이션 비용 우위는 다르다.
  일부 후보만 시뮬레이션하면 그 집합 내 최선이며 전역 최적이라고 부르지 않는다.
- 선택 손실은 `선택한 작업 이후 비용 − 비교 집합 내 최저 비용`으로 잰다.
  좋은 후보를 많이 남겨도 실제 선택이 나쁘면 운영 효과가 없다.
- 개별 실행 가능 후보의 보존은 여러 크레인의 공동 배정 최적성을 보장하지 않는다.
  중복 작업·안전거리·예약 충돌 검사와 기존 배정 순서는 별도 대조한다.

## 후보 생성 설계 후보

예정 → 게이트 진입 후 이동 중 → 블록 도착/실행 준비 상태의 전체 목록을 관리한다.
목록 크기와 한 번에 처리하는 신경망 묶음 크기를 구분한다.
현재 실행 가능한 후보는 개수로 자르지 않고 묶음으로 나눠 모두 평가하는 경로를 기준으로 둔다.
가변 길이 입력 처리는 현재 후보별 공유 신경망으로도 가능하다. 큰 신경망이 선행 조건은 아니다.
취소·완료는 활성 목록에서 제거하되 이력은 평가 장부에 남긴다.
개수 제한 해제는 정책이 고르는 범위도 바꾸므로, [[YR-332-n]]의 계산 동등성 실험과 섞지 않는다.
모든 오더를 보존하더라도 실제 계산시간·메모리는 유한하다. 과부하 시 지연과 잔여를 보고한다.

## 완료 기준

1. 동일 후보 범위에서 계산 최적화의 누락·잘못된 실행 가능 판정·오래된 계획 사용 0건.
2. 제한 전 기준과 제한 후 후보 재현율·최선 행동 보존·선택 손실을 독립 표본에서 기록.
3. 필수 작업·동점·정보 공개 시각·예약 변경·취소·크레인 이동·시간 경계·복제 사례 포함.
4. 전체 평가시간, 후보 생성시간, 느린 5%와 1% 경계, 최대 지연·메모리를 따로 보고.
5. 같은 시드 반복은 구현 결정론만 검증. 다른 입력·초기값에서 효과의 반복 여부도 따로 평가.
6. 통과 수치는 관측한 조건 범위로 한정하고 보편적인 누락 0 증명으로 과장하지 않는다.

## 조사한 1차 자료와 적용 범위

- [Invalid Action Masking, FLAIRS 2022](https://arxiv.org/abs/2006.14171): 불가능한 행동 제외의
  이론·실험 근거. 가능하지만 낮게 평가한 행동을 삭제해도 된다는 근거가 아니다.
- [Learning to Dispatch, NeurIPS 2020](https://proceedings.neurips.cc/paper/2020/hash/11958dfee29b6709f48a9ba0387a2431-Abstract.html):
  작업 규모에 묶이지 않는 정책. [공식 코드](https://github.com/zcaicaros/L2D) 공개.
  제조 작업 순서 문제의 결과를 항만 성능 수치로 전용하지 않는다.
- [Deep Sets, NeurIPS 2017](https://proceedings.neurips.cc/paper/2017/hash/f22e4747da1aa27e363d86d40ff442fe-Abstract.html):
  순서와 크기가 달라지는 작업 집합을 표현하는 근거. 후보별 독립 점수와 집합 문맥은 별도 축이다.
- [통계적 평가, NeurIPS 2021](https://arxiv.org/abs/2108.13264): 소수 실행 평균만으로 판정하지
  않고 개선 구간과 변동을 보고한다. 표본 수는 예상 변동·최소 개선량·예산으로 사전 고정한다.
