# YR-256 — 논문 핵심 그림 출판 품질 재설계

- **Epic**: Exp / **Priority**: 🟠 / **등록·착수일**: 2026-08-30
- **배경**: 영문 원고의 시스템 구조 그림은 정보가 지나치게 많거나 축소 시 글자가 작고,
  MLP 참고 이미지는 구현의 ReLU와 다른 GELU를 표시한다. 그림과 코드가 다르면 방법론
  재현성이 깨지므로 실제 구현을 기준으로 다시 그린다.

## 목표와 수용 기준

1. 운영 경로와 학습 전용 반사실 경로를 한 그림에서 구분한다.
2. 제안망 21차원·수락망 16차원, `64-ReLU-64-ReLU-1`을 코드와 일치시킨다.
3. PDF/SVG 벡터 원본과 PNG 미리보기를 같은 생성 스크립트에서 만든다.
4. 그림 안 제목을 제거하고 캡션은 LaTeX가 담당한다.
5. LNCS 본문 폭에서 6pt 미만 글자가 없고, 흑백에서도 선 모양과 라벨로 구분된다.
6. 영문·국문 PDF를 다시 빌드하고 그림이 잘리거나 겹치지 않는지 렌더링으로 확인한다.

## 범위 밖

- 실험 결과 수치 변경과 새 성능 주장
- 정책 구조·학습 설정 변경
- 원자료로부터 생성되는 결과 그래프의 값 변경

## 완료 근거

- 구현 계약 대조: `nets.py`의 ReLU, `labels.py`의 정책별 짝 중심화를 그림에 반영했다.
- 조판: 영문 15쪽과 국문 13쪽을 각각 두 번 빌드했고 치명 오류·미정의 참조가 없다.
- 실물 확인: 영문 3·7쪽과 국문 2·6쪽에서 잘림·겹침이 없고 6pt 미만 글자가 없다.
- 형식 확인: SVG에 포함된 래스터 이미지가 없고 PDF에서 글자를 추출할 수 있다.
