# YR-317-m — 블록 변경 시 대상 컨테이너 미결 원인 진단 (읽기 전용)

- **상태**: backlog
- 등록: 2026-09-21. parent: YR-317. 근거: [발견사항](../strategy-history/2026-09-21-전략수립-발견사항.md).
- 무엇: 블록을 바꾸는 정책(전체 15/20 시드, 블록전용 18/20 시드)에서 종료 시점 "대상 미결(unbound)" 트럭이 대량 발생하는 원인이 정책 행동인지 PRESERVE 접수계약의 대상 재연결 규칙인지 가른다.
- 왜: 공간 조정의 부정 결론(R1-4a)이 정책의 성질인지 환경 계약의 부작용인지 확정되지 않으면 "공간 조정은 해롭다"를 발견으로 쓸 수 없다.
- 방법: 저장된 `requests.jsonl.gz`·`container-links.jsonl.gz`에서 미결 트럭의 요청일·블록·변경 시각·대상 종류 분포를 집계하고, `make_retarget` 재연결 경로를 코드로 대조한다. 필요하면 짧은 재생 1회.
- 완료 기준: 미결 발생 경로가 근거 파일과 함께 기록되고, 공간 부정 결론에 붙일 한 문장이 정해진다.
- **3대 게이트 보정 대상: `scenario_validity`**.
