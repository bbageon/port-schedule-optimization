# YR-165 — 공간 판매 "전역 효과" 분리검증 (투입 고정 대조)

- **Epic**: Exp / **Priority**: 🔴 / **등록일**: 2026-08-10 / **상태**: in-progress
- **1줄**: YR-164 가 찾은 **T_other(+16.52)** 가 실제 터미널 현상인지, 아니면 **고정
  재공량 투입기가 만든 실험장치 효과**인지 가른다. 이 답에 따라 다음 방향이 갈린다.

## 왜 필요한가 (38차 감사 지적 — 수용)

엔진에는 **21블록이 공유하는 YT·크레인이 없다**. 블록 간 유일한 연결은 ①판매 이송
자체 ②**중앙 투입 컨트롤러**다. 컨트롤러는 `deficit = L − (전 블록 내부+확약)` 을
**전역으로** 계산하고 **단일 pool 순서열**에서 트럭을 꺼낸다 — 판매로 트럭 1대의
진출 시각이 바뀌면 그 epoch 의 전역 계수가 달라지고, pool 커서가 어긋나 **이후 전
블록의 트럭 명단·시각이 통째로 바뀐다**. 즉 T_other 는 "도미노 파급"이 아니라
**"다른 트럭이 왔다"** 일 수 있다. 이 구분 없이 전역 학습(2안)으로 가면 장치
인공물을 학습 목표로 삼게 된다.

## 방법 (동결 — 실행 전)

1. **새 시드 대역**(0B 개발 대역과 분리) w3-L100 무대에서 shadow smoke 2런 →
   would-commit 에서 **런당 4건**(계산 이득 4분위 각 1건·job_id 사전순) = **8표본**.
2. 표본마다 짝 실행:
   - **기준 세계**: 정상 투입 컨트롤러. 이때 발생한 **투입 계획**(epoch, job_id 순서)
     을 그대로 기록한다.
   - **처치 세계**: **기준의 투입 계획을 그대로 재생**하는 고정 투입기(전역 계수를
     보지 않음) + 그 판매 1건만 집행.
   두 세계의 미래 트럭 명단·투입 시각이 **완전히 동일**해진다.
3. YR-164 와 같은 5항 분해(T_src·T_dst·T_other·V_all·R_wait)·항등 검사.

## 판정 (동결 — 결과 열람 전)

- **A. 장치 효과 확정**: 8표본 전부 `|T_other| < 1e-9` → 기존 +16.52 는 **투입기
  인공물**. 조치 = 환경 계약 정정(짝 비교 시 투입 고정) 후 **공간 판매 0B 재판정**.
  AI 에 전역 정보를 더할 이유가 없어진다.
- **B. 숨은 결합 존재**: 하나라도 비영 → 투입기 외의 블록 간 결합·장부 문제.
  원인을 먼저 규명(코드 결함 여부)하고, 그 전에는 어떤 방향도 선택하지 않는다.
- 부수 관측(판정 아님): 고정 투입 하의 실현 이득 `G_frozen = T_src+T_dst+V_all+R_wait`
  의 부호·크기 — "환경 정정 후에도 공간 판매 이득이 남는가"의 **예비 신호**.
  (정식 판정은 재판정 0B 에서만.)

## ★결과 = **A. 장치 효과 확정** (2026-08-10 · 8/8 · 클린 트리)

- **T_other = 0.000000000 (8표본 전부·max |T_other| = 0.0)** — 투입 계획을 고정하자
  나머지 19블록의 비용 차이가 **완전히 사라졌다**. 두 세계의 투입 건수도 전부 동일
  (`admission_identical_all=true`), 항등 오차 0.0.
- **결론**: YR-164 의 T_other(+16.52)는 **물리적 파급이 아니라 중앙 투입 컨트롤러
  인공물**이다 — 판매로 진출 시각이 바뀌면 전역 계수·pool 커서가 어긋나 이후 전
  블록이 **다른 트럭**을 받았을 뿐이다. 21블록은 물리적으로 연결돼 있지 않다.
- **부수 관측(예비 신호·판정 아님)**: 고정 투입 하 실현 이득 = 8건 중 **양수 3건**
  (−5.23 ~ +1.21). 이제 이득은 사실상 T_src+T_dst 로만 결정되며, 표본에서 소스
  경감이 수신 부담을 못 넘긴 경우가 다수다. **판매 이득 자체가 이전 추정보다
  훨씬 작거나 없을 수 있다** — 정식 판정은 환경 정정 후 재판정 0B 에서만.
- **파급**: ①YR-164 의 "전역 파급" 가설과 그로부터 나온 3안(전역 특징 추가·중앙
  PPO·축 종료)의 전제가 **무효** ②짝 비교 계약에 **투입 고정**을 넣어야 한다
  (안 그러면 판매 효과와 트럭 교체 효과가 섞인다) ③그 환경에서 **공간 판매 0B 재판정**.
