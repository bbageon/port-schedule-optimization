## 실행 계약

1. 출처가 확인된 반출은 상자가 아직 없어도 주문·트럭 시각을 등록한다.
   실제 스택에 적치되기 전에는 크레인 후보가 될 수 없다. 기다린 시간도 기존 비용에 포함한다.
2. 초기·반입·양하 상자의 현재 또는 확정 배정 블록을 추적한다. 정책에는 전체 미래 명단을 추가하지 않는다.
3. 반입 재배정이 확정되면 그 상자의 후속 작업이 새 블록을 따라간다. 상자를 순간 이동시키지 않는다.
   아직 오지 않은 반출은 목적지 주행을 다시 계산한다. 이미 도착했다면 블록 간 주행을 기다린 후 작업한다.
   후자의 최초 게이트·블록 도착 기록은 보존하고 추가 경로·준비 시각을 내부 이력으로 따로 남긴다.
4. 선적 크레인 작업은 상자 블록에서 처리하지만 본선·안벽 처리기는 원래 계획 블록에 한 번만 존재한다.
   다른 블록의 반출 완료는 정확한 시각에 동기화하여 원래 본선의 운반 자원에 전달한다.
   기존 운반 자원·편도 시간 가정을 유지한다. 무제한 운반이나 즉시 선적·본선 비용 중복 계상 금지.
5. 추가 동기화는 물리 사건 연결만 담당한다. PPO 수집·갱신은 기존 60초 경계를 유지한다.
6. 원래 선적 물량·계획 시작·마감 배수는 유지한다. 아직 없는 상자의 미래 적재 위치를 읽어 마감을 계산하지 않는다.
7. 누락·번호 변경·실행 중 준비 전 처리·중복 생성/출고는 기록하고 즉시 실패한다.
   완료 상자 이력은 일일 작업 정리 후에도 유지한다. 실행 종료와 전체 작업 완료는 구분한다.
