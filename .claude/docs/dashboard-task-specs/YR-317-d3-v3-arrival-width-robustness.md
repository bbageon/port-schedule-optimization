# YR-317-d3 — 도착 피크 폭과 비용의 강건성 설계

- **상태**: backlog
- 요청: 2026-09-16 사용자. 하루 물량·구성 성분 시각/비중을 유지하면서 피크 폭만 바꾸고 일별 비용을 비교할 필요 검토.
- 무엇: 독립 월 입력의 도착 분포 폭을 세 수준으로 바꾸고 같은 조건의 기준/전체/시간만 정책을 비교한다.
- 왜: 같은 하루 물량에서도 집중 도착이 대기열·잔여 작업·시간 조정의 이득을 바꾸는지 확인해 Reviewer #1의 수요 패턴 강건성 지적에 대응한다.
- 선행: g의 공급·반출 연결 판정과 d의 공통 평가 계약. 현재는 설계와 곡선 계산만 했으며 시뮬레이션은 미착수다.
- 하루를 매번 초기화하는 별도 실험은 기본안에 넣지 않는다. 30일 연속 실행의 일별 비용·혼잡과 월 단위 통계를 함께 사용한다.
- 제안 세 수준: 폭 배수 1.5/1.0/0.6. 최종 배수와 표본은 입력 검증·계산 예산 확인 뒤 성능 관측 전에 고정한다.
- 주의: 현재 생성기에서 1.5배는 세 구성 성분이 겹쳐 눈에 보이는 봉우리가 1개다. 구성 성분 개수 유지와 합성곡선 피크 개수 유지를 구별한다.
- 24시간 바깥으로 잘리는 꼬리 때문에 폭만 바꿔도 실제 성분 비중이 약간 달라진다. 실제 비중까지 고정하려면 기간 내 성분별 질량 보존과 원래 1.0배 재현을 함께 검증해야 한다.
- 유지: 일별 물량과 순서, 트럭 ID/반출입/블록/규격, 통지 여유·주행 표본, 선박 계획, 초기 상태, 정책 가중치·크레인·비용. 도착 변화에 종속된 통지/예약 시각은 일관되게 다시 계산한다.
- 동일 날짜·시드의 도착 난수 분위와 트럭 속성을 대응시킨다. 단순 시드 숫자만 같다는 이유로 공통 입력이라고 보지 않는다.
- 출력: 절대 일별 비용, 트럭당 비용, 같은 폭에서의 정책 절감액/절감률, 전체 대 시간만 차이, d2의 대기열·잔여·턴타임·행동 비율.
- 같은 시드·같은 폭의 정책 비교와 같은 시드·같은 정책의 폭 비교를 구분한다. 독립 표본은 월 전체이며 날을 독립 표본으로 세지 않는다.
- 사전 학습한 가중치를 고정한 폭 변화 평가가 우선이다. 폭별 재학습은 다른 연구 질문으로 분리한다.
- 예약 정원·외부 대기/변경 비용 미반영 조건은 그대로 한계다. 피크 실험이 현실 제약 검증을 대신하지 않는다.
