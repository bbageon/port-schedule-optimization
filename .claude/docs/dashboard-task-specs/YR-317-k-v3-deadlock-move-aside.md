# YR-317-k — 교착 시 비켜서기 후보 추가 (시뮬레이터 결함 수정)

- **상태**: backlog
- 등록: 2026-09-21. parent: YR-317. 근거: [[YR-317-j]] 진단 — 같은 블록의 크레인 두 대가 서로의 안전 간격 안에서 유휴일 때 모든 일감이 그 사이에 있으면 둘 다 간섭 거절되고, 비켜서기 행동이 없어 영구 정지한다.
- 무엇: 교착 통로가 검출될 때(`interference_deadlock_corridors` 비어 있지 않음) 유휴 크레인에게 통로 밖으로 물러나는 위치 이동(파킹) 후보를 발행한다. 기존 위치 이동 후보(트럭 도착 예상 기준)와 구분하고, 기본 경로 결과 동일성 검사를 유지한다(옵트인).
- 왜: 정지 달이 80건 통계의 평균을 지배한다. 결함을 고쳐야 정책 비교가 환경 결함에 오염되지 않는다.
- 범위 결정(사용자): ①수정만 하고 기존 80건은 그대로 두고 보조 표로 보고 ②수정 후 정지 시드 9실행만 재실행 ③80건 전체 재실행. 비용: 실행당 30일 2~7시간.
- 검증: 탐침 스냅샷(Y17)에서 수정 후 1시간 재생 시 완료 0건→양수, 정책 예외·물리 위반 0. 수직형 후보 보존 수정과의 상호작용 확인.
- **3대 게이트 보정 대상: `scenario_validity`**.
