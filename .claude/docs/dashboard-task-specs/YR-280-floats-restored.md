# YR-280 — 부동체 복원으로 쪽 여백 회수 + 표 2 열 간격

- **Epic**: Paper / **Priority**: 🟠 / **등록·완료일**: 2026-08-30

## 진단 (실측)

`scripts/v3/pdf_whitespace.py` 로 쪽마다 아래 여백을 쟀다. 정상 범위(16%)를 넘는 쪽:

| | 초과 쪽 | 초과분 합계 | 가장 심한 곳 |
|---|---|---|---|
| 영문 | 4개 | 0.81쪽 | 5쪽 46% · 2쪽 39% |
| 국문 | 5개 | 1.47쪽 | 19쪽 80% · 4쪽 55% · 15쪽 52% |

심한 쪽은 모두 **큰 그림 바로 앞**이었다 — 비부동체 블록이 통째로 다음 쪽으로 밀리며
앞 쪽 아래를 통째로 비운 것이다.

## 왜 비부동체였나 (그리고 왜 이제 되돌리나)

[[YR-259]] 에서 *"그림과 캡션이 쪽 경계에서 갈라진다"* 를 `center`+`minipage`+`\captionof`
로 막았다. 갈라짐은 막혔지만 **쪽을 채우는 능력**을 잃었다. 진짜 해법은 부동체다 —
`figure`/`table` 는 애초에 쪼개지지 않으므로 갈라짐이 없고, 동시에 LaTeX 이 본문으로
쪽을 채운다.

## 한 일

- 비부동체 블록 **20개**(국·영문 각 10개)를 `\begin{figure}[tbp]` / `\begin{table}[tbp]`
  로 되돌렸다. 캡션 위치는 원고 그대로 — 표는 위, 그림은 아래.
- `\usepackage{flafter}` 로 **부동체가 정의 지점보다 앞서 나오지 못하게** 했다.
- 부동체 비율 5줄: `topfraction .9` · `bottomfraction .8` · **`textfraction .07`**
  (기본 .2) · `floatpagefraction .75` · `topnumber 3`.
- 이미 부동체였던 표 둘의 위치지정도 `[t]`/`[tb]` → `[tbp]` 로 통일.
- 표 2 열 간격: `{@{}llr@{}}` → `{@{}l l@{\hspace{2em}} r@{}}` (머리글이 붙어 있었다).

## 결과

| | 쪽수 | 16% 초과 쪽 | 초과분 |
|---|---|---|---|
| 영문 | 21 → **20** | 4 → **1**(마지막 쪽) | 0.81 → **0.26** |
| 국문 | 19 → **17** | 5 → **0** | 1.47 → **0.00** |

**부동체가 멀리 날아가지 않았다** — `scripts/v3/pdf_float_placement.py` 로 캡션 쪽과
본문 첫 참조 쪽의 차이를 쟀다: 영문 0~2쪽(대부분 1), 국문 0~1쪽. 참조보다 **앞서 나온
부동체는 0개**다.

## 검증

- 국·영문 각 2회 빌드 — Overfull **0** · Underfull **0** · 오류 **0** · 미정의 참조 **0**.
- 그림 7건·표 4건 모두 번호와 순서 유지.
- escape 전수검사(`tex_escape_scan.py`) 이상 없음.
