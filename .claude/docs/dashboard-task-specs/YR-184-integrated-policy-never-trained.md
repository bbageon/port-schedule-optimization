# YR-184 — 최종 목표인 "단일 통합정책"을 한 번도 학습·평가한 적이 없다

- **Epic**: RL / **Priority**: 🔴 / **등록일**: 2026-08-17 / **상태**: backlog
- **3대 게이트 보정 대상**: `performance`
- **1줄**: 크레인 정책은 **옛 무대에서 학습된 것을 얼려서** 쓰고, 그 위에 판매만
  얹어 배웠다. 둘을 함께 학습한 적도, 함께 평가한 적도 없다.

## 사용자 지적 (2026-08-17)

> "PPO + 판매를 포함한 전체 환경을 학습 돌려서 비용을 평가한 건 아니지 않아?"

**맞다.** 코드에서 확인했다.

## 실측

### 1. 크레인 정책은 학습 대상이 아니다 (`yr151_transfer_ppo.py`)

```
:151  actor.eval()
:153  p.requires_grad_(False)      # 동결 — TransferHead 만 학습
:464  opt_a = torch.optim.Adam(actor.parameters(), lr=LR)   # ← TransferHead
:466  # 채택 실행 정책 — 동결 로딩 1회, 매 iteration 뒤 구성 전체 해시 불변 검사
```

옵티마이저에 들어가는 것은 **판매 머리(TransferHead) 뿐**이다. 크레인 정책은
매 회차 해시로 "안 변했는지" 검사까지 하며 고정된다.

### 2. 그 크레인 정책은 **다른 무대**에서 학습됐다

체크포인트 메타(`yr143_no_repo/confirm/c0/ppo_s221000/train_meta.json`):

```
train_band : "BASE+16..31"
by_cell    : mid-loose 162 · high-loose 48 · mid-tight 27 · high-tight 3
```

이 `mid/high × loose/tight` 4셀은 **구 2블록 부하셀 체계**(`yr090_dense_vessel`)다.
현 무대는 `terminal_stream` 의 **21블록 · 24시간 이중 피크 · 고정 재공량**이다.

즉 **옛 세계에서 배운 두뇌를 새 세계에 그대로 옮겨** 쓰고 있다.

## 최종 목표와의 거리

Dashboard README 가 기록한 최종 목표(2026-07-15 사용자 결정):

> 별도 Exp 정책이 아니라 차량·본선·이송장비·레인·다중 YC를 **처음부터 같은
> State·Action·Total Cost 계약으로 다루는 단일 통합정책**

현재 구조(YR-174 가 명시적으로 채택한 역할 분리):

| 구성 | 상태 |
|---|---|
| BUY 견적 | 지도학습 후 **동결** |
| SELL 판매 머리 | **학습** ← 이것만 |
| Resolver | 결정론 |
| 크레인 집행 | **동결** (그것도 옛 무대 산출) |

**역할 분리 자체는 정당한 설계 결정이었다** — AGENTS.md 연구 설계 원칙 2("한
번에 한 축씩, 각 추가는 자기 실증을 동반")를 따른 것이고, 한꺼번에 다 학습시키면
어디서 문제가 생겼는지 못 찾는다. 문제는 **분리한 채로 최종 목표를 향해
전진했다고 보고해 온 것**이다. 통합은 아직 시작도 안 했다.

## 그래서 지금까지 잰 것의 정확한 이름

"우리 통합정책의 비용 개선"이 **아니다**. 정확히는:

> **옛 무대에서 학습된 고정 크레인 정책 위에, 판매 층 하나를 얹었을 때의 차이**

그리고 그 판매 층조차 규칙에 졌다([[YR-179]]).

## 세 갈래 (사용자 결정 요청)

| 안 | 내용 | 비용 | 위험 |
|---|---|---|---|
| **A. 현 무대에서 크레인부터 재학습** | 21블록·24시간에서 크레인 정책을 다시 배우고, 그 위에 판매를 얹는다 | 큼 | 크레인 학습이 이 무대에서 될지 미검증 |
| **B. 크레인+판매 동시 학습** | 최종 목표 그대로. 하나의 정책이 둘 다 결정 | 가장 큼 | 신용 배분이 어려움 — 판매 단독도 아직 규칙을 못 넘음 |
| **C. 범위를 정직하게 좁힌다** | "고정 배차 정책 위의 재배치 층" 을 본 주장으로 삼고, 통합정책은 향후 과제로 명시 | 없음 | 연구 기여가 작아짐 |

**선결(어느 안이든)**: [[YR-180]] — 현 무대에서 **고정 크레인 정책이 규칙(SF-SPT)을
이기는지**부터 재야 한다. 옛 무대에서 배운 두뇌가 새 무대에서 규칙보다 나쁘다면
A·B 는 그 위에 무엇을 얹어도 의미가 없고, C 의 "고정 배차 정책"도 정당화되지
않는다. **이것이 현재 전체 연구의 최우선 미측정 항목이다.**

## 하지 않는 것

- 지금까지의 성적을 "통합정책 성능"으로 부르는 것.
- YR-180 없이 A·B 에 착수하는 것 (밑바닥을 모르는 채 위층을 쌓는 일).
