## 범위

1. Dashboard 257개 row를 상태와 무관하게 검색한다.
2. 논문에 직접 연결되는 축만 묶는다: 트럭 예약·시간 이연, 야드 크레인 배차,

4. 본문에는 저자-연도 인용을 넣고 별도 문서에 짧은 원문 인용과 전체 참고문헌을 둔다.

- 외부 문헌은 **연구 문제와 방법 선택의 타당성**을 뒷받침한다.

- 외부 사례의 개선율을 우리 결과처럼 쓰지 않는다.
- PEMA·HJNC 규모 자료를 `840 move/h`의 실측 증거로 쓰지 않는다.
- Transformer·GNN·RUDDER의 일반 장점을 현재 정책의 우월성 증거로 쓰지 않는다.
- 원문은 출처당 25단어를 넘지 않게 짧게 쓰고 바로 쉬운 해석을 붙인다.
