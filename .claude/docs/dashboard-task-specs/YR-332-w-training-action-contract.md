# YR-332-w — 학습 비교 대안과 실제 선택 제약의 정합 감사

- **상태**: done
- 등록: 2026-11-07. 상위 [[YR-332]], 발견 작업 [[YR-332-s]].
- 정책·자료를 바꾸기 전의 신뢰성 감사다. 대안이 잘못됐다는 판정이나 성능 원인 확정이 아니다.
- **3대 게이트 보정 대상**: `scenario_validity` — 학습 환경의 강제 대안과 운영 선택 계약을 대조하는 관측 한 축. 정책·보상·물리는 고정한다.

## 무엇과 왜

현재 실행 정책에는 실작업(SERVE)을 준비 작업보다 앞에 놓는 제약이 있다.
교사의 대안 추출은 같은 필수 등급을 요구하지만, 실작업/준비 작업 등급 일치까지 요구하지 않는다.
저장 자료에서 두 등급이 다른 쌍은 기존 표본 52/198, 범위를 넓힌 표본 55/198이다.
최신 flow 모델은 후자의 같은 자료를 사용한다. 어느 쪽도 새 입력 상한 실험의 변경으로 생긴 것이 아니다.

등급이 다르다는 사실만으로 실행 불가능이라고 할 수는 없다. 다른 크레인의 배정·안전 충돌 때문에
개별 순위와 실제 선택은 달라질 수 있다. 당시 공동 배정 상태에서 선택 가능한 대안인지 확인해야 한다.
효과가 없는 비교에 학습 예산이 쓰이는지, 제약으로 표현할 수 없는 선호를 학습하는지 가리는 것이 목적이다.

## 감사 범위

1. 저장된 결정 시점과 공통 행동 모델을 재생하고 후보·필수 등급·실작업 우선·공동 안전 제약을 기록한다.
2. 강제 선택 시 제약 중 무엇이 그대로 유지되고 무엇이 우회되는지 코드와 실행으로 대조한다.
3. 같은 제약에서 점수만 바꿔 선택 가능한 대안과, 제약 자체를 바꿔야 하는 대안을 구분한다.
4. 학습 표본·비용 차이·검증 정확도에서 각 부류의 비중을 보고한다. 수만으로 성능 저하의 원인이라 하지 않는다.
5. 계약 불일치가 확인되면 그 한 축의 수정 실험을 별도 사전등록한다. 이번 감사에서 후보를 임의로 지우지 않는다.

같은 입력에 같은 점수를 주는 증인도 따로 남기며, 특정 신경망의 실현 가능성 증명으로 과장하지 않는다.

## 결과 — 2026-11-08

9개 기존 학습일+반복 1회에서 입력·후보·실제 선택·하루 결과를 정확히 재현했다.
반복을 포함한 선택 가능성 증거 444건과 저장 모델 36개의 원래 검증 점수를 대조했다.
사전 판정 검사 8건, 본 실행 10회, 주 결과 표의 독립 집계 8값이 통과했다.
실행 커밋은 `d7407c45`다. 새 학습이나 교사 미래 비용 재계산은 하지 않았다.

| 자료 | 비교 쌍 | 우선등급 혼합 | 점수로 대안 선택 불가 | 그중 교사가 대안 선호 |

최신 자료의 45/198(22.7%)은 고정 제약 안에서 점수만 바꿔도 선택할 수 없다.
세 모델 초기값별로 12/66·16/65·17/67쌍에서 재현됐다. 독립 198개 날짜라는 뜻은 아니다.
교사의 강제 선택은 실작업 우선순위를 우회하지만, 필수 작업과 공동 안전 검사는 유지했다.
혼합 쌍 전부가 문제는 아니다. 기존 12쌍·최신 10쌍은 다른 크레인의 배정에 따라 선택 가능했다.

선택 불가 쌍은 최신 자료의 절대 비용 차이 14.83%, 정규화 목표 차이 15.75%를 차지한다.
이는 기울기 기여나 성능 저하 원인의 비율이 아니다. 최신 모델의 원래 검증 자료에서 비용
순서 정확도는 전체 56.25%(차이가 있는 32쌍), 선택 가능 상한 부류는 50%(22쌍)다.
고정된 작은 과거 표본이므로 새 데이터 일반화·장기 운영 효과로 해석하지 않는다.

나머지 3쌍은 그 점수표 구성으로 실패했을 뿐 불가능이 증명된 것은 아니다.
점수표를 현재 크기의 신경망이 실제로 구현할 수 있는지도 이번 감사 범위 밖이다.
