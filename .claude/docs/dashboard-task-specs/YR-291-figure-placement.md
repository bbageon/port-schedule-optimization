## ★ "문단 바로 뒤"(h 배치)는 쓸 수 없다 — 실측으로 확인

`\begin{figure}[!ht]` 로 바꿔도 그림이 **전부 쪽 맨 위로** 갔다. 원인은
**본문이 쪽을 끝까지 채우고 있다**는 것이다.

| 측정 | 값 |
|---|---|
| 본문 영역 아래 경계 | y = 665 |
| 9쪽 마지막 글줄 아래끝 | y = **666.4** |
| 10쪽 마지막 글줄 아래끝 | y = **666.4** |

빈 자리가 없으니 `h` 가 실패하고 `t`(다음 쪽 위)로 넘어간다. 확인한 조건:

- 배치 지정자 `!ht` · `ht` · `!h` × 그림2·3 조합 **16가지** (`figflow.py`)
- 그림 폭 **1.0 / 0.85 / 0.75 / 0.65 / 0.55** (`figfit.py`) — 0.55 에서도 쪽 맨 위
- `flafter` 패키지를 **꺼 보아도** 동일 (원인이 flafter 가 아님을 확인)

따라서 선택지는 **쪽 위**냐 **쪽 아래**냐 둘뿐이다.
