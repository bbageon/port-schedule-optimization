# YR-245 — 최근접 블록 비교 규칙 제외

- **상태**: backlog 🟢 · 2026-08-28
- **분류**: Exp
- **사용자 결정**: 재배치 층의 비교 규칙에서 제외

## 제외 이유

목적 블록을 주행거리 증가량만으로 고르면 게이트에서 가장 가까운 블록이 항상 유리하다.
현재 배치에서는 21개 원래 블록 중 20개가 같은 목적 블록을 골라, 혼잡을 분산하려는
재배치 비교 규칙으로 기능하지 않는다. 이 판정은 비용 결과가 아니라 배치와 목적지
선택식만으로 재현된다.

## 사후 제외에 대한 공개 규약

구조 결함은 성능 결과를 확인한 뒤 발견했다. 따라서 다음을 논문에 함께 남긴다.

1. 주 비교에서 제외한 이유와 목적지 집중 증거
2. 포함했을 때 9일 평가의 비용 차이
3. 이 규칙을 포함해 얻었던 유리한 승패를 주 근거에서 제거했다는 사실
4. 코드는 폐기 목록에 보존해 결과를 재현할 수 있다는 사실

## 완료 조건

- 주 비교 정책 목록에서 제외하고 실행 시 조용히 다시 포함되지 않게 한다.
- 기존 사전등록 문서에 사후 제외와 소급 영향을 기록한다.
- 논문에는 제외 사유와 포함 결과를 모두 적는다.
