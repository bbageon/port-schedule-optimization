# YR-332-ag — 작업 완료 기준으로 학습·고전 규칙 비교 재설정

- **상태**: backlog
- 선행: af의 비용·장부 계약 검증. 착수 직전 현재 연구 게이트 재판정.
- 목적: 출차 지연을 제외한 목적함수에서 학습 정책이 작업 순서를 더 잘 정하는지 검증한다.

## 필요한 이유

사용자 지시로 트럭 비용 종료점이 출차에서 작업 완료로 바뀌었다.
기존 K 비교와 4%대 결과는 과거 목적함수의 학습 결과다. 숫자를 그대로 승계하지 않는다.

## 범위

1. 같은 입력·물리·규칙·관측 창에서 새 비용으로 교사의 라벨을 다시 생성한다.
2. 새 계약을 기록한 모델을 학습하고 학습 전·학습 후·고전 규칙을 같은 조건에서 비교한다.
3. 트럭 전체·반입·반출의 진입→완료 시간과 미완료 수를 주 지표로 보고한다.
4. 완료→출차·전체 체류는 별도 진단, 본선 양하/적하와 본선 보호는 기존 계약으로 보고한다.
5. 학습량·시드·검증 입력은 결과 열람 전에 사전등록한다. 과거 모델의 동결 진단과 새 학습을 구분한다.

실측 운반(i)·예약/통지(f)의 잔여 문제와 정규화 참조가 출차 기준이라는 한계를 함께 표기한다.
이번 row는 등록이며 실행·성능 개선을 뜻하지 않는다.
