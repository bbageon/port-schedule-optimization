# YR-332-ag — 작업 완료 기준으로 학습·고전 규칙 비교 재설정

- **상태**: done
- 선행: af의 비용·장부 계약 검증. 착수 직전 현재 연구 게이트 재판정.
- 목적: 출차 지연을 제외한 목적함수에서 학습 정책이 작업 순서를 더 잘 정하는지 검증한다.

## 필요한 이유

사용자 지시로 트럭 비용 종료점이 출차에서 작업 완료로 바뀌었다.
기존 K 비교와 4%대 결과는 과거 목적함수의 학습 결과다. 숫자를 그대로 승계하지 않는다.

## 범위

1. 같은 입력·물리·규칙·관측 창에서 새 비용으로 교사의 라벨을 다시 생성한다.
2. 새 계약을 기록한 모델을 학습하고 학습 전·학습 후·고전 규칙을 같은 조건에서 비교한다.
3. 트럭 전체·반입·반출의 진입→완료 시간과 미완료 수를 주 지표로 보고한다.
4. 완료→출차·전체 체류는 별도 진단, 본선 양하/적하와 본선 보호는 기존 계약으로 보고한다.
5. 학습량·시드·검증 입력은 결과 열람 전에 사전등록한다. 과거 모델의 동결 진단과 새 학습을 구분한다.

실측 운반(i)·예약/통지(f)의 잔여 문제와 정규화 참조가 출차 기준이라는 한계를 함께 표기한다.
## 사용자 실행 지시·사전등록 — 2026-11-10

사용자가 접수 시각 수정과 `오더데이터/` 확인 후 **3번 새 학습 비교 실행**을 명시했다.
현실성 미확정 운반 조건은 유지한 진단으로 실행하며 실제 터미널 성능 확증은 하지 않는다.
이는 기존 게이트의 현실성 통과를 선언하거나 정책 구조 변경을 허용한 것이 아니다.
정책·해결기·후보 전체 일괄평가·표본 방식은 고정하고 목적함수와 정보 계약을 정정한다.

- 보정 파일: `outputs/reports/yr332_real_order_information/profile.json`.
  10/28~11/05의 진입 전 최초 예약 20,936건, 11/06~09의 8,349건은 분포 확인만.
  반입/반출별 예약 오차·접수 리드의 짝을 함께 뽑는다. 실제 도착은 기존 24시간 곡선.
  오래된 신고 예약도 분포에 보존하며 2000년 이전 자리표시 날짜는 제외한다.
  예상 도착 = 예약 + 보정 자료의 유형별 중앙 오차 + 기존 주행 추정. 실현 진입은 비공개.
- 신경망 초기 시드: 9917101·9917102·9917103. 각 6회, 회당 최대 24쌍, 갱신 50회.
- 학습 입력: `9917200 + 100×모델번호(0~2) + 10×회차(0~5)`.
  부하 3,500·7,500·15,000을 두 번 순회. 초기 정책 동결로 질문 생성, 마지막 가중치만 평가.
- 미래 비용 관측 K=3시간 유지. 이번에 K나 정책 정보를 추가 탐색하지 않는다.
- 평가 입력: `9917600 + 100×날짜번호(0~2) + 10×부하번호(0~2)`의 9개 신규 합성 입력.
  학습·분포 확인용 날짜와 합성 시드를 혼동하지 않는다. 실자료 운영 이력 재생은 아니다.
- 비교: 학습 전·후 3모델, SF_SPT·FIFO·LIFO·SPT·NEAREST·LWKR·RANDOM 7규칙.
  117개 고유 평가 + 중간 부하 규칙/학습 각 1회 반복 = 119회. 모든 팔 같은 입력·실행 가능 후보.
- 관측 24시간, 엔진 26시간. 미완료도 24시간까지 누적 시간을 포함한다.
- 보고: 트럭 전체·반입·반출의 진입→완료 평균/미완료, 양하·적하의 계획 시작→야드 완료,
  본선 비용, 완료→출차 별도. 양하·적하 수치는 선박 전체 체류시간이 아니다.
- 주 비교: 학습 후 대 SF_SPT의 총비용, 최소 1% 감소와 완주·미완료·본선 보호 조건.
  별도로 학습 전 대비와 각 규칙 대비를 모두 공개. 입력일을 단위로 짝 부트스트랩 10,000회,
  난수 9917899, 95% 구간. 모델 평균을 입력일 단위로 묶어 독립 표본 수를 부풀리지 않는다.
- 실행: CPU 하루 경로, 학습 3프로세스×분기 2개, 평가 4프로세스, torch 스레드 1.
  소규모 별도 시드 9917999로 배선 확인 후 코드·사전등록 커밋에서 실행한다.
- 새 라벨 계약은 `gate-in-to-job-done-v1`. 교사 정규화는 새 비용 차이의 중앙값 기반 기존 방식.
  PPO 고정 기준값을 새로 추정하는 실험은 아니며 PPO 갱신도 수행하지 않는다.

### 판정 한계

운반 3대·470초, 수평 배치, 24시간 합성 도착곡선은 실측으로 확정하지 않았다.
예약 필드의 오래된 값과 최초 예약 연결이 안 된 표본 제외에 따른 선택 편향도 남는다.
어떤 규칙보다 좋아도 이번 진단만으로 실터미널 효과·연속 운영 효과를 확정하지 않는다.

## 실행·검증 결과 — 2026-11-10

동결 소스 e72f7fe4에서 3모델×6회, 297쌍 학습, 117개 고유 평가와 2개 정확 반복을 완료했다.

반입은 학습 전보다 69.056% 감소, 반출은 6.301% 증가했다. 양하·적하는 1.364%·4.985% 감소했다.
