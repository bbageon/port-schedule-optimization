# YR-142 — v4-B-2: PREPOSITION 재발행 금지 강제 (실행 이력 기반)

## 무엇을 왜
YR-141(v4-B 구속적 PREPOSITION)은 7항 중 5항을 통과했고, 실패 2항(J2 장악·J7 반복)의
단일 원인은 **같은 작업을 위한 위치조정(PREPOSITION)이 반복 발행되는 것을 규칙으로
막지 않은 것**이었다 (근접 ≤1bay 소멸만으로는 미차단 — 스펙에 사전 고지한 단순화).
YR-142는 이미 동결된 J7 계약("같은 작업 반복 이동 = 0")을 **계수(사후 측정)에서
강제(사전 차단)로 승격**하는 구현 완결이다. YR-137 ①과 같은 "성립 조건 수리" 성격 —
튜닝이 아니다.

## 유일 변경 (단일축)
실행 이력 기반 재발행 금지:
1. **기록**: 결정이 실행될 때 결속 작업 id 를 `sim._prepo_history`(set)에 기록.
   - 학습 경로: `yr139_blockq_v4_ppo.run_episode` — 선택된 assign 적용 직전 기록.
   - 평가 경로: `yr141_bound_prepo._PrepoRecorder.decide` — 실행 계수와 같은 지점.
2. **차단**: `candidates._reposition` 의 BOUND_REPO 분기에서
   `jid in sim._prepo_history` 이면 후보 발행 스킵 (교착 탈출 REPO 는 불변 분리).

그 외 전부 YR-141 과 동일 (PPO 단위 정정판·표준 앵커·최종 정책·계약 물리·κ 동결).
