# YR-317-c — 전체 후보 선택의 정확성

- **상태**: backlog
- 분류: 성능/방법 타당성 직접 진단·보정. 선행: YR-317-a·g의 관련 근거와 연구 게이트 판정.
- 무엇: 두 행동씩 배운 점수가 같은 상태의 모든 후보를 잘 고르는지 실제 분기로 검사한다.
- 왜: 변경 후보는 공통 KEEP과의 차이로 설명할 수 있지만 KEEP 목표의 상대 의존성과 실제 근사 오차가 남는다.
- [정밀 선택 설계](../strategy-history/2026-09-14-v3-review-ranking-detail.md). 초기 a-b/b-c 반례를 v3 실제 라벨 구조로 해석하지 않는다.
- 부하·행동·후보 수를 나눠 미사용 진단 상태를 고정 표집한다. 300상태는 예산 검토용 제안이다.
- KEEP을 포함한 전체 합법 후보, 같은 외생 난수·후속 정책·계산창으로 실제 비용을 비교한다.
- 선택 손실·최선 선택률·순위 일치도·KEEP보다 나쁜 선택률을 비용 크기와 함께 보고한다.
- Seller와 Buyer의 비교 범위, resolver가 서로 다른 제안 점수를 비교하는지도 감사한다.
- 현재 SELL 강제는 원하는 좌표를 지정하지 못한다. 분기 전용 정확한 좌표 강제와 사실 재현 검사가 필요하다.
- 자정의 본선 투입·날 경계·분기 종료 절단이 교사 측정을 바꾸는지도 먼저 감사한다.
- KEEP 포함/제외 선택 손실과 수락 오류·중앙 경합을 분리한다. NOVETO는 거절만 끄고 수락망 정렬은 유지한다.
- 오류가 독립 상태에서 재현될 때만 공통 KEEP 기준 또는 비용차 손실 중 한 축을 사전등록한다.
- 입력·다른 망·교사 길이를 동시에 바꾸지 않는다. 같은 상태의 행을 학습·검증 양쪽에 나누지 않는다.
- 완료 기준: 선택 정확성 결과와 원자료, 필요하면 단일축 보정 전후 검증 및 게이트 판정.
- 후속: YR-317-d. 문제가 없으면 새 학습 가설을 만들지 않고 확증한다.

- 9/15 [개정 폴더의 구체 전략](../../../docs/paper/v3/paper-revision/03-후보순위-검증전략.md) 작성. 공통 KEEP일 때 변경 후보의 순위 보존 조건과 KEEP 상대 의존성을 수식·예제로 설명했다.
- 예산안 3실행×5부하×반입/반출×10상태=300상태, 먼저 10상태로 분기 재현·계산량 확인. 300개를 독립 실행 수로 세지 않는다.
- 원고 §3.3의 전체 순위 보장과 §3.2의 정렬 설명을 조건부로 수정한다. 경합 시 정렬이 실제 확정 집합에 미치는 영향도 검사한다.
- 문서 검토만 완료했으며 전체 후보 분기·추가학습은 이번 전략 작성에서 실행하지 않았다.
