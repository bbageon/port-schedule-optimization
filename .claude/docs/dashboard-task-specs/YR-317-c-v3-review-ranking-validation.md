# YR-317-c — 전체 후보 선택의 정확성

- **상태**: backlog
- 분류: 성능/방법 타당성 직접 진단·보정. 선행: YR-317-a·b와 착수 허가.
- 무엇: 두 행동씩 배운 점수가 같은 상태의 모든 후보를 잘 고르는지 실제 분기로 검사한다.
- 왜: 쌍마다 다른 평균을 빼는 학습 목표는 쌍 사이 점수 비교의 정당성을 자동 보장하지 않는다.
- [실험 설계 §3](../strategy-history/2026-09-14-v3-review-experiment-protocol.md).
- 부하·행동·후보 수를 나눠 미사용 진단 상태를 고정 표집한다. 300상태는 예산 검토용 제안이다.
- KEEP을 포함한 전체 합법 후보, 같은 외생 난수·후속 정책·계산창으로 실제 비용을 비교한다.
- 선택 손실·최선 선택률·순위 일치도·KEEP보다 나쁜 선택률을 비용 크기와 함께 보고한다.
- Seller와 Buyer의 비교 범위, resolver가 서로 다른 제안 점수를 비교하는지도 감사한다.
- 오류가 독립 상태에서 재현될 때만 공통 KEEP 기준 또는 비용차 손실 중 한 축을 사전등록한다.
- 입력·다른 망·교사 길이를 동시에 바꾸지 않는다. 같은 상태의 행을 학습·검증 양쪽에 나누지 않는다.
- 완료 기준: 선택 정확성 결과와 원자료, 필요하면 단일축 보정 전후 검증 및 게이트 판정.
- 후속: YR-317-d. 문제가 없으면 새 학습 가설을 만들지 않고 확증한다.
