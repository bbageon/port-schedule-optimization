# YR-127 — 학습 예산 단일축: 경사 갱신 횟수 ×20 (YR-125 1단계의 최소 수정 검증)
> 상태: **done (2026-07-29 — ★기각)** · 2세대 계측 위 학습 진단 · spec 등록 2026-07-29
> 근거: [YR-125 1단계](../../../outputs/reports/yr125_qvalue_diagnosis/report.md) — 12 체크포인트
> 전부 보정오차(G−Q̂) ≈ 실현수익 전체. 원인 역산 = **총 경사 갱신 ~1,000회**(에피소드당
> `max(1, len(trans)//64)` ≈ 2~3회 × 500) vs 전파 지평 150+ 결정.

## 목적
"부족한 건 메커니즘이 아니라 학습량"이라는 **가장 인색한 설명**을 직접 검증한다.
문헌 정합: 통상 DQN 관행은 수집 전이당 경사 표본 ≥4~8회(replay ratio) — 현행은 **~0.9회**.

## 설계 (착수 시 사전등록 동결에서 수치 확정)
- 유일한 차이 = **에피소드당 갱신 루프 횟수 ×20** (그 외 recipe·보상·γ·시드·후보 전부 동일).
- base arm = WAITON recipe(WAIT 허용) — 유휴 병리가 보이는 조건에서 보정 회복과 행동
  변화를 함께 본다. 시드 {88000, 99000, 123000}.
- **판정 (착수 시 동결 — [하네스](../../../src/yard_rl/experiments/yr127_training_budget.py)
  docstring 이 정본)**: 성공 = N1 ∧ N2 ∧ N3.
  - N1 보정 회복: YR-125 동일 진단(4셀×2 에피소드·같은 보상·γ 0.99)에서
    bias_ratio = |mean(G−Q̂)|/mean(|G|) 이 **3/3 시드 모두 ≤ 0.5** (참조 WAITON ≈ 0.99).
  - N2 전략적 WAIT 감소: 평가대역(4셀×6)에서 SERVE 가능인데 WAIT 선택률 전체 평균이
    같은 프로세스 재평가 WAITON 의 **절반 이하** AND WAIT 행동점유 >0.60 에피소드 없음.
  - N3 비용 비악화: 같은 (학습시드, 평가에피소드) 짝 총비용 차 upper95 < **+10** AND
    미건전 수 비증가.
  실패 시 → YR-125 2단계(차분 1-step)로. 고지: 갱신 수 증가는 rng 소비 경로를 바꿈 —
  축에 내재한 차이로 고지.
- 후속 옵션(이 실험에 혼입 금지): n-step 수익(Rainbow n=3 관행) · replay ratio 사다리.

## 결과 (2026-07-29 — ★기각, 성공 기준 N1·N2·N3 전부 미달)

- 축 실증: 실수행 갱신 21,960~22,200회/시드 (기존 ~1,100 의 20배, train_meta.json).
- N1 실패(방향 확증): bias_ratio 0.685/0.692/0.696 — 참조 WAITON 0.991 대비 3/3 일관
  개선(예측 설명력 1~3%→~31%)이나 동결 임계 0.5 미달.
- N2 실패: 전략적 WAIT 0.479(WAITON 재평가, YR-119 값과 일치)→0.535 증가, 60% 장악 13.
- N3 실패(guard): 짝 총비용 +1.46 [−4.74,+7.66] TOST 동등이나 미건전 13 vs 3.
- 수확: "Q 를 채우면 쏠림이 풀린다" 기각 — 재배치 붕괴(→0.005~0.015)·WAIT 수렴.
  **★결론 하향(외부 피드백 2026-07-29)**: 확정은 "현 조합(상태·후보·귀속·TD)에서
  Q 가 WAIT 를 더 싸게 평가"까지 — 원인 후보 다수·"목적함수상 WAIT 최적" 미확정.
  절대예측≠행동 구분력(순위·부호). 상세: [정정 기록](../strategy-history/2026-07-29-외부피드백-순위진단선행-차분계약.md)
- 분기 발동 + 선행 게이트: **YR-128 순위 진단** → YR-125 2단계 차분 1-step.
