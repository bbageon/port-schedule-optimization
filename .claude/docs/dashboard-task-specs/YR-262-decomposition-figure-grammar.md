## 진단 — 문법이 뜻을 배신하고 있었다

`Both actions` · `Timing only` · `Block only` 은 **어떤 행동을 허용했나** 의 결과다.
`Due to training` 은 `RL_EARLY − RL`, 즉 **효과의 분해값**이다. 성격이 다른데 넷 다
같은 막대로 그려 놓으니 독자가 순간적으로

> "Training 이라는 네 번째 행동이 있는 건가?"

로 읽는다. 색·해칭을 아무리 다듬어도 **문법이 같으면 뜻이 같아 보인다.**

## 고친 것 셋 (사용자가 꼽은 우선순위 그대로)

### ① 이름 — `Due to training` → `Training contribution`

문장처럼 읽히는 이름은 범례에 어울리지 않는다.

### ② ★문법을 갈랐다 — 막대가 아니라 ◆ + 세로선

사용자 제안 중 **방법 B** 를 택했다. 막대 셋만 막대로 두고, 학습 기여는 회색 마름모에
0에서 뻗은 가는 세로선으로 그린다. 그러면 한눈에

    막대 = 정책 실험 (재배치 없음 대비)
    ◆    = 학습 자체의 기여 (학습 전 모형 대비)

가 된다. 범례에서도 ◆ 라는 다른 기호가 스스로 갈라 준다 — 억지 빈칸은 넣지 않았다.
빈칸을 끼우면 범례가 그림 폭 전체로 벌어져 맨 오른쪽 항목이 (b) 패널 머리말처럼 읽힌다.

### ③ 눈금과 단위

- `3,500 (12 d)` → **`3,500` / `n = 12`** 두 줄. `d` 는 day 인지 demand 인지 한 번
  생각하게 만든다
- 축 이름에서 `(days observed)` 를 뺐다 → **`Daily external-truck demand (jobs/day)`**
- 세로축 **십억원 → 백만원**. 십억원이면 (a)가 0.02·0.04·0.06 이라 소수점만 읽게
  된다. 백만원이면 (a)는 20·40·60, (b)는 200·400·600 이라 두 패널 다 바로 읽힌다

## 함께 정리한 것

- **해칭은 하나에만.** 파랑+사선 · 흰색+X · 회색+사선이 섞이면 작은 PDF 에서 오히려
  안 갈린다. 이제 `Both`(진한 청색 solid) · `Timing`(연한 청색 solid) ·
  `Block`(흰색 + 얇은 사선) · `Training`(중간 회색 ◆ solid)
- **0선을 살렸다.** 이 그림에서 음수는 핵심이다(7,500의 학습 기여 −49, 15,000의
  블록만 −241). 격자 투명도 0.18 → **0.13**, 0선 굵기 0.9 → **1.1**, 아래 테두리 제거,
  x 눈금 표시 길이 0
- **패널 이름** `(a) Light to moderate demand` → **`(a) Non-congested regime`** ·
  `(b) Congested demand` → **`(b) Congested regime`**. 이 그림의 메시지가 바로 그
  **전환**이므로 이름이 먼저 말하게 했다
- **눈금 위치**는 가운데 막대 아래. 막대+◆ 전체의 한가운데로 잡으면 라벨이 막대와
  ◆ 사이 빈 곳에 떠서 어느 무리에 붙는지 흐려진다
- 캡션 마지막 문장이 메시지를 말한다 — *"비혼잡에서 혼잡으로 넘어가면 도착시각
  조정과 학습의 몫이 함께 급격히 커지는 반면, 블록만 쓰는 재배치는 음수로 돌아선다."*
  그리고 *"마름모는 넷째 행동이 아니다"* 를 캡션에도 못 박았다
