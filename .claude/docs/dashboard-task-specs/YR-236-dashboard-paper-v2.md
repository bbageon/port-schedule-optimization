## 왜 새 버전인가

`docs/paper/v1/`은 2026-08-18의 3,600대 무대 결과를 정확히 보존한다. 이후 v3에는
원화 네 항 비용, 독립 Seller·Buyer, 학습 전용 반사실 교사, 선급 3종, 부하 축,
고전 규칙 대조군이 생겼다. 동시에 도착곡선이 5차에서 6차로 바뀌어, YR-229~232의
성능 수치는 현재 무대의 결론으로 승계할 수 없게 됐다.

따라서 v1을 덮어쓰지 않고 `docs/paper/v2/`에 현재 상태를 다시 쓴다.
