# YR-332-ax — 저장 PPO 경험의 물량·작업별 학습 신호 확인

**상태**: backlog
등록: 2026-11-17. av의 고정 예산 진단에서 확인한 성능 손실의 읽기 전용 후속 점검.

## 무엇·왜

- av에서 Transformer+PPO는 학습 전보다 트럭 시간이14.79% 줄었지만 규칙보다26.54% 길었다.
  3,500/7,500건 입력에서는 규칙보다2.39/10.55% 짧고15,000건에서는31.00% 길었다.
- 개선은 주로 반입이며 반출은 학습 전보다1.56% 길어졌다. 같은 PPO 예산의 MLP는 세 초기값 모두 악화됐다.
- 저장된 실제 행동·비용 목표·초기/회차별 가중치에서 어느 종류의 결정이 어떻게 바뀌었는지 확인한다.
  하루 비용 귀속, 가치 예측 오차, 충분한 반복 여부 중 하나를 미리 원인으로 확정하지 않는다.

## 범위

1. 모델별6회 갱신의 저장 표본을 물량·작업 종류·시각으로 나누고 표본 수와 반환·가치 오차를 재계산한다.
2. 같은 저장 상태·실행 가능 마스크에서 갱신 전후 행동 확률과 선택 방향을 비교한다.
   최종 정책이 실제로 방문한 모든 상태의 원인 분석이라고 과장하지 않는다.
3. 가치 예측과 행동 선택의 손실·기울기를 분리해서 읽는다. 기존12개 첫 배치 측정은 일부 표본일 뿐이다.
   Adam이 신호를 재조절하므로 전체 기울기 제한 배율을 실제 가중치 이동 배율로 읽지 않는다.
4. 학습 전후·물량별 손실이 세 초기값에서 함께 나타나는지 확인하고 확인 못 한 원인도 기록한다.

## 제약·완료 조건

- 새 시뮬레이션·학습·보상 변경·추가 정보·모델 교체를 하지 않는다. 저장 파일 읽기만 수행한다.
- 환경 현실성 i/f의 외부 근거 대기는 유지한다. 본 작업 결과만으로 현장 효과나 다음 학습을 허용하지 않는다.
- 새 학습 비교가 필요하면 관측 근거로 한 축을 정하고 별도 사전등록·착수 판정을 받는다.
- 원자료 해시·재계산 표·반례와 한계·Dashboard 정합 확인 뒤 commit/push한다.
