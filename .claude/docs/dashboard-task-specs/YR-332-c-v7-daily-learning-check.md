# YR-332-c — v7 하루 무대에서 학습이 되는가

- **상태**: done
- 상위: [[YR-332]]. 선행: [[YR-332-a]]·[[YR-332-b]].
- 2026-11-09: 사용자 지시로 ab의 교사 계약 보정 효과 검증에 이 작업의 고정 평가를 연결한다.

## 무엇

학습에 쓰지 않는 **고정 평가일**을 정하고, 학습 전·중간·후 망을 같은 날 같은 시드로 굴려 짝비교한다.
성과지표는 턴타임. 크레인 초기값 셋.

## 사전 해석

- 학습 후가 학습 전보다 고정 평가일에서 턴타임이 낮으면 **학습이 된다** → [[YR-332-d]] 로.
- 같거나 나쁘면 **학습이 안 된다** — 연속 판정으로 가지 않는다. 그 자체를 결과로 기록한다.
- 이번에는 가중치를 평가 성적으로 고르지 않고 사전 고정한 6회 후 가중치를 판정한다.
  초기·3회·6회 모델을 독립 3일×3부하에서 평가하고 중간 모델은 추세만 보고한다.
- 운반차·예약 실측 보정은 미확정이다. 합성 환경 진단과 실제 터미널 성능을 구분한다.
- 고정 계획: [교사 수정 재학습](../../../docs/research/v7-discharge/reachable-teacher-prereg.md).

## 완료 결과 — 2026-11-09

ab의 보정 환경에서 초기값 셋·교사 두 종류·각 6회 학습을 완료했다.
초기·3회·6회 가중치와 고전 규칙 8종을 같은 학습 밖 9개 입력에서 평가했다.
208회 평가, 주문 장부 1,809,000건 대조, 가중치 36개 재학습 재현, 회귀 165건을 통과했다.
판정 모델은 사전 지정한 6회 후 가중치이며, 시험 성적으로 모델을 고르지 않았다.

수정 교사의 평균 체류시간은 학습 전보다 4.549% 짧지만, 기존 교사보다 3.572% 길다.
SF-SPT(실작업 우선·그중 짧은 작업 우선)보다 평균 체류 10.090%·비용 14.540%가 더 크다.
하루 15,000건에서는 체류 200.252분 대 153.602분, 26시간 미출차 2,702.111대 대 1,465.667대다.
횟수는 실행 평균이며, 규칙에도 잔여가 있어 환경의 용량 가정 문제를 학습만의 실패로 단정하지 않는다.
초기값별 학습 전 대비 체류 변화는 -1.131%, +3.698%, -14.701%다. 평균 개선과 안정적 개선은 다르다.

따라서 평균 학습 효과는 관측했으나, 교사 수정의 성능 우위·완주·본선 보호는 채택 조건을 못 넘었다.
전역 3대 게이트에 따라 [[YR-332-d]]의 30일 확증으로 진행하지 않는다.
[[YR-332-i]] 운반 자원·시간·달성 가능한 마감과 [[YR-332-f]] 예약 현실화는 실측 보정이 남아 있다.
이번 결과는 고정 가정의 합성 환경 진단이다. 6회·공통 행동 자료이며 온라인 정책 반복 개선 실험은 아니다.
현재 신경망이 모든 교사 목표를 동시에 표현할 수 있다는 증명도 아니다.
