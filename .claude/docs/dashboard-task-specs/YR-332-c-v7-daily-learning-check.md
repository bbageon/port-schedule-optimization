- 학습 후가 학습 전보다 고정 평가일에서 턴타임이 낮으면 **학습이 된다** → [[YR-332-d]] 로.

- 이번에는 가중치를 평가 성적으로 고르지 않고 사전 고정한 6회 후 가중치를 판정한다.
