# YR-332-c — v7 하루 무대에서 학습이 되는가

- **상태**: ready
- 상위: [[YR-332]]. 선행: [[YR-332-a]]·[[YR-332-b]].

## 무엇

학습에 쓰지 않는 **고정 평가일**을 정하고, 학습 전·중간·후 망을 같은 날 같은 시드로 굴려 짝비교한다.
성과지표는 턴타임. 크레인 초기값 셋.

## 사전 해석

- 학습 후가 학습 전보다 고정 평가일에서 턴타임이 낮으면 **학습이 된다** → [[YR-332-d]] 로.
- 같거나 나쁘면 **학습이 안 된다** — 연속 판정으로 가지 않는다. 그 자체를 결과로 기록한다.
- 저장할 가중치는 고정 평가일 성적으로 고른다. 그 평가일 성적을 판정 근거로 다시 쓰지 않는다.
