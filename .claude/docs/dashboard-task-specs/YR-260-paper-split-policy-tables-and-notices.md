# YR-260 — 결과표 분리와 정부 고시 참고문헌 통일

- **Epic**: Paper / **Priority**: 🟠 / **등록·착수일**: 2026-08-30

## 목적

정책별 전체 비용 감소와 제안 정책의 날짜별 짝비교를 서로 다른 표로 제시한다. 독자가
효과의 크기와 통계 비교를 섞어 읽지 않게 하고, 정부 고시 참고문헌은 국·영문에서 같은
영문 표기로 맞춘다.

## 범위

- 국문·영문 `sections/05-results.tex`
- 국문·영문 `main.tex`의 참고문헌 15·16
- 국문·영문 조판 PDF

## 편집 계약

- 첫 표는 정책, 사용 행동과 재배치 없음 대비 감소율만 제시한다.
- 둘째 표는 비교 목적, 비교 정책, 제안 정책이 더 저렴한 날과 양측 부호검정 값을 제시한다.
- 짝비교 값이 없는 정책은 둘째 표에서 제외한다.
- 14.72%, 13.44%, 18/28과 모든 p값은 바꾸지 않는다.
- 참고문헌 15·16은 사용자가 지정한 기관명, 문서명, 고시번호와 연도로 통일한다.

## 완료 조건

- 국문과 영문에 별도 표 두 개가 같은 구조와 값으로 들어간다.
- 표 설명에서 양수·음수와 `제안 정책이 더 저렴한 날`의 뜻을 바로 설명한다.
- 참고문헌 15·16이 두 PDF에서 같은 영문 표기로 출력된다.
