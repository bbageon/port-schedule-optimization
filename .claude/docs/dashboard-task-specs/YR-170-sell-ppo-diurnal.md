# YR-170 — 5차 계약 무대에서 판매 PPO 학습 (먼저 돌리고 본다)

- **Epic**: Exp / **Priority**: 🔴 / **등록일**: 2026-08-11 / **상태**: in-progress
- **3대 게이트 보정 대상**: `performance` 하나 — 인가 `allowed=true`(게이트 c113f12)
- **1줄**: 견적을 더 고치지 말고 **판매 정책을 학습시켜 보고**, 안 되면 그때 디버깅한다.

## 왜 이 작업인가 (사용자 결정 2026-08-11)

> *"학습부터 해서 학습이 안 됐다가 나와야 디버깅을 하는 거 아냐?"*

그동안 0B 의 논리를 따라왔다 — **"손으로 만든 견적이 좋은 판매를 못 고르면
학습해도 안 될 테니 학습하지 말자."** 그런데 코드를 확인하니 그 전제가 틀렸다:

```
보상 = −(Φ_final − Φ(결정 시점)) + V(s_end)      # yr151_transfer_ppo.build_batch
Φ    = Σ블록 실현 v2 비용 + 주행/3600 + 기사 외부대기/3600
```

**학습기는 견적(`delta_j`)을 보상으로 쓰지 않는다** — 실현 터미널 총비용에서 배운다.
`delta_j` 는 복기용으로 전이에 join 될 뿐이다. 따라서 견적의 부정확은 학습을 막을
이유가 아니라 **학습이 할 일이 남았다는 뜻**이다.

게다가 현재 게이트가 허가한 축이 정확히 `performance` 하나이고, "판매 정책이
기준선보다 비용을 줄이는가"가 바로 그 축이다 — 학습이 인가된 다음 단계였다.

## 구현 (2026-08-11)

**무대만 바꾸고 학습 루프는 공유한다.** `train_one(episode_fn=...)` 주입 배선을
추가했다(기본값 유지 — 4차 호출부 바이트 불변).

| | 4차(고정 WIP) | **5차(24h 이중 피크)** |
|---|---|---|
| 환경 | `build_fixed_wip` + hotspot | `build_diurnal`(명단 사전 확정) |
| 투입 | `WipAdmissionController`(피드백) | `ScheduledAnnouncer`(개방 루프) |
| 관측창 | 5h | `OBS_24H` 워밍업 2h + 측정 22h + 배수 2h |
| 프로파일 | AGV 보정본(39차 감사 결함) | H-21 YT 주입 |
| 장부 가드 | 등록 = 채움 + 투입 | 등록 = 투입 = 계획 3,600 · 누락 0 |

- 집행 정책 = **채택 PPO 헤드**(C0 + 대기 허가증, 동결). 연구 질문이 "채택 실행
  위에 판매를 얹으면 비용이 더 주는가"이므로 SF 로 돌리면 다른 질문이 된다.
- **한계 명시**: YR-167 자격은 SF 집행으로 통과시켰다. 채택 헤드는 같은 환경
  계약(도착·본선·재고)을 쓰지만 실현 비용 곡선은 다르다.
- 학습 시드 8,400,000 / 8,500,000 / 8,600,000 (자격·관찰·파일럿 대역과 교집합 0).

## 지위 — 성능 주장 없음

이 작업은 **"학습이 되는가"를 보는 실행**이다. 판정(기준선 대비 개선)은 별도
사전등록으로 동결한 뒤에만 한다. 학습 곡선·판매 건수·Φ 추이는 **관측**으로 보고한다.

## 실패해도 되는 작업이다

안 되면 그 결과가 디버깅의 출발점이다. 미리 짐작해서 고치지 않는다.
관측할 것: ①구간 보상이 학습 신호가 되는가(critic 손실·advantage 분포)
②판매 건수가 학습에 따라 변하는가(전부 KEEP 로 수렴하는지 포함) ③Φ 추이.

## 결과 — 학습되지 않음. 원인 3중 확증 (2026-08-11~12)

**관측**: 3시드 × 20 iteration 동안 세 지표 전부 미동.
Φ 2,914 → 2,903/2,996/2,998 (기준선 2,286 대비 +27%) · 판매 3,628 → 3,632~3,645 ·
v_loss 422만 → 425만. **학습 곡선이 아니라 날마다의 무작위 변동만 보인다.**

원인 후보 5종을 독립 진단(5 에이전트)한 결과 **지배 원인 3개가 겹쳐 있다**:

### ① 갱신 횟수 — `ppo_update` 에 미니배치가 없다 (CONFIRMED·지배)

`yr151_transfer_ppo.py:397-413` 의 `opt_a.step()`/`opt_c.step()` 이 **표본 루프
밖**에 있다. 60,879 표본을 전부 더해 **epoch 당 1회**, iteration 당 **4회**만
파라미터를 움직인다. 20 iteration = **80 step**, 40 iteration = **160 step**.
동일 구조 재현 실험에서 의미 있는 하강에 **약 1,000 step(≈250 iteration ≈ 5일)**
필요. → **40회를 다 돌려도 결과는 바뀔 수 없다.**
미니배치 256~1024 를 도입하면 iteration 당 갱신이 4 → 240~950 회가 된다.

### ② 보상 규모 — 수익 정규화가 없다 (CONFIRMED·지배)

`r2go = −(Φ_final − Φ_pre)` 가 원 단위라 목표가 **−1,670 평균 / [−2,914, 0]**.
critic 초기 출력은 −0.06, 20 iteration 뒤에도 **−0.70~−1.18**(목표의 0.06%).
**v_loss 는 학습 상태가 아니라 Φ 규모를 되말한 값이다** — 57개 기록 전부에서
`v_loss / Φ_final² = 0.5045 ± 0.0038`(변동계수 0.75%), corr = **0.984**.

### ③ 공로 배분 — 같은 epoch 의 21블록이 **전부 같은 보상**을 받는다 (지배)

`yr151:347·383` 에서 `phi_pre` 는 **터미널 전역 스칼라 1개**다. 블록별로 다른 건
`boot`(critic 출력 ≈ −1)뿐이라, "같은 시각에 A블록은 팔고 B블록은 안 팔았다"를
advantage 가 **원리적으로 구분하지 못한다**. 행동에 귀속 가능한 분산 비율
**3.8 × 10⁻⁶** — 표준화하면 advantage 는 사실상 "**표준화된 시계**"가 된다.
대조: 판매 1건의 실측 인과효과 **0.845**(YR-168 pair000) vs advantage 시각 잡음
표준편차 **1,180** → 표본당 신호대잡음 **7.2 × 10⁻⁴**.

### 기여 원인

- **행동 구조(PARTIAL)**: 행동은 [KEEP + 후보 K] 위 단일 Categorical 이고 정책은
  아직 **완전 균등**이라 판매 확률이 K/(K+1) 로 고정 — "판매 건수가 1건도 안
  줄었다"가 완벽히 설명된다. 단 **K ≈ 2** 라 KEEP 은 33~50% 로 뽑힌다
  (초기 보고의 "K=20·KEEP 5%" 는 **오류 — 정정**). 균등을 붙잡는 범인은
  엔트로피(0.01)가 아니라 ①②③ 이다.
- **무대(PARTIAL)**: "고칠 몫이 잡음보다 작다"는 **지금 상태에선 틀렸다** —
  전건 KEEP 으로만 돌려도 657점(에피소드 잡음의 5.9배) 개선이 눈앞에 있는데
  20 iteration 동안 하나도 못 먹었다. 다만 **시간 판매 축은 이 무대에서 평균
  이득이 수학적으로 0** 이라는 별도 지적이 있다.

### ★ 근본 경위 — 이미 고쳤던 결함이 되살아났다

`yr151:85` 는 "**yr139 앵커 승계**(clip/lr/ent/γ)"라고 적혀 있으나, 실제 yr139 는
정규화를 **갖고 있었다**. YR-140 이 "원 단위 보상과 1/20 단위 가치의 혼합 =
**확정 결함**"으로 판정하고 고친 것인데, 승계하면서 숫자 4개만 가져오고 아래를
전부 떨어뜨렸다:

| yr139 (있음) | yr151/yr170 (없음) |
|---|---|
| 보상 `/SCALE`(20.0) | 원 단위 그대로 |
| GAE λ=0.95 | λ=1 (MC 전액) |
| 미니배치 64 + 셔플 | 전배치 1 step (951배 차) |
| grad clip | 없음 |

**4차 계약에서 안 드러난 이유**: 4차에서는 **학습을 한 번도 돌린 적이 없다**
(`yr151:29` "이 파일은 실행하지 않았다(빌드 우선)", `outputs/reports/yr151_transfer_ppo/`
디렉터리 부재). 사용자의 "학습부터 돌려라"가 아니었으면 계속 안 드러났을 결함이다.
