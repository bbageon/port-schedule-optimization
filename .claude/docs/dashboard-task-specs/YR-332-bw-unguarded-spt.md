# YR-332-bw · BP 시험 월에서 보호 없는 최단 작업 우선과 비교

- **상태**: in-progress
- 상위 [[YR-332]], 관련 [[YR-332-bi]], [[YR-332-bp]]. 2026-11-25 사용자 요청. 종전 보고의 ‘짧은 작업 우선’에는 블록에서 24분 이상 기다린 트럭을 승격하는 조건이 있었다.
- 기존 규칙과 BP 모델에는 그 조건이 공통이다. BP의 학습 점수는 결정 뒤 30분 동안 해당 블록에 귀속된 트럭·본선 턴타임으로 산출된다. 순위 승격과 경과시간의 분당 가중치는 별개다.
- 새 규칙은 물리적으로 배정 가능한 실작업 중 계획 소요시간이 짧은 것을 먼저 고른다. 동률은 기존 SPT의 작업 ID 순이다. 기존 SF_SPT는 동률에서 본선, 누적 대기시간도 사용하므로 두 규칙 차이 전체를 24분 조건의 단독 효과로 해석하지 않는다.
- 시험 입력은 BP와 같은 시드 12204201, 연속 30일 및 마지막 물량 처리 기간 5일, 후보 수 제한 없음. 고정 모델과 기존 규칙은 저장된 건별 원장으로 다시 집계한다.
- 미완료 수가 있으면 완주한 방식과 순위를 매기지 않는다. 완주 시 개별 트럭·선박의 식별자 및 시작시각이 같음을 검증한다. 트럭은 게이트 진입부터 작업 완료까지, 본선은 작업 시작부터 마지막 작업 완료까지다.
- 평균 두 개, 트럭 턴타임 상위 5% 경계, 블록 도착부터 작업 시작까지 대기의 상위 5% 경계·최대, 월 가중합(트럭 총분 + 67 × 본선 총분)을 보고한다. 단일 합성 시험 월의 비교 기준 정정이다.
- 재현은 프로젝트 루트에서 `PYTHONPATH=src;scripts/v7`로 `python scripts/v7/unguarded_spt_month.py replay`를 실행한다. 이미 저장된 원장을 다시 비교하는 명령은 `python scripts/v7/unguarded_spt_month.py compare`다.
