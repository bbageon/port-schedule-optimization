- **상태**: done
- 사용자 요청 2026-11-25. 현재 BP 모델의 신경망 구조를 확인하고 GPU(그래픽 연산 장치)로 실행 시간을 줄인다.
- BP 세 번째 갱신 모델 및 바로 다음 물결의 실제 결정 1,024개로 CPU 1스레드, CPU 16스레드, RTX 5090을 비교한다. 같은 64건씩 4반복, 세 번의 중앙값이다. 추론은 시뮬레이터가 한 번에 보내는 한 상태의 점수와 선택을 재현한다.
- 수치 검사 항목은 마스크가 있는 선택의 확률·기울기, 점수 보존, 체크포인트 재개, 고정 선택과 반복 학습 차이다. 완료된 BP 기록과 예정시각 실험의 최초 등록 기록을 보존한다.
- 장치 선택은 `scripts/v7/short_window_train.py`의 `--train-device cpu|cuda`, `--inference-device cpu|cuda`이다. CUDA를 요청한 경로는 GPU를 쓸 수 있는 PyTorch가 필요하다.

## 실제 적용

- 측정 코드 버전 `9afa8b70`. BP 모델의 학습 파라미터는 43,874개다. 작업·크레인 후보 특징 10개를 32차원으로 바꾸고 4헤드, 2층 트랜스포머로 처리한다. 선택부는 96→32→1로 후보 점수, 비용 예측부는 66→64→1로 상태별 값을 낸다.
- 1,024개를 64개씩 4회 반복한 학습 갱신 중앙값은 CPU 1스레드 15.53초, CPU 16스레드 4.04초, GPU 3.36초다. GPU 경로는 조건부 작업 선택의 확률도 묶어서 계산한다. 한 건씩 추론 시 CPU 1.12ms, GPU 9.41ms다. 한 달 전체 실행 시간은 후속 실행에서 확인한다.
- 고정 모델에서 저장된 256개 상태의 허용된 후보별 최고 점수 선택이 CPU·GPU에서 일치했다. 각 장치에서 반복한 갱신의 가중치는 동일했다. 같은 표본으로 갱신한 뒤 CPU 1스레드 대비 GPU 가중치의 최대 절댓값 차이는 0.00152였다.
- BP의 최종 평가는 기존 CPU 프로세스에서 진행한다. BT 대기기는 11월 25일 09:18 기존 학습 시작 전에 GPU 전용 환경과 고정된 코드로 전환했다. 네 조건에서 학습은 CUDA, 추론은 CPU를 사용한다. BP의 기존 장치와 양쪽 실행 차이를 기록했다.
