# YR-318 — 확증 캠페인: 수정 엔진·새 시드 대역·6팔 (규칙 대조군 포함)

- **상태**: backlog
- 등록: 2026-09-21. parent: YR-317. 선행: [[YR-317-k]](교착 수정)·[[YR-317-n]](학습 3판).
- 무엇: 결함을 고친 엔진에서 **새 평가 대역** 20시드 × 6팔 = 120실행을 사전등록 표본으로 한 번만 돌린다.
- 팔: `NO_REALLOC` · **`SLOT_LL`(규칙, 시간만 — 행동 폭이 시간정책과 동일)** · **`SPACE_TIME_LL`(규칙, 블록+시간)** · `RL_TIME` · `RL` · `RL_NOVETO`. 블록전용은 이미 −150%로 결론나 제외한다.
- 왜: ①이 저장소의 동결 규약이 *"주판정 축 = 규칙 대비, 안 팔기 대비는 판별력 0"*(`.claude/docs/architecture/06-학습과-판정.md:103`)인데 현재 80건에 규칙 팔이 0개다 → 지금 논문에는 "학습이 규칙보다 낫다"는 증거가 없다. ②`RL_NOVETO`가 R1-4b(수락망 기여)를 닫는다. ③기존 20시드는 판정에 이미 썼으므로 새 대역이 필요하다.
- 고정(실행 전): 주판정 = 기준 대비가 아니라 **규칙(SLOT_LL) 대비 시간정책**. 재표집 20,000회·97.5% 구간. 결과별 대응 문장을 사전등록에 미리 적는다(전략 §5).
- 비용: 120실행 × 6.49시간(정지 수정 후 실측) = 779 CPU-시간 → 동시성 9.2 기준 **약 3.5일**. 16코어 사용, 4코어는 v4/v5에 남긴다. 새 시드 대역의 seed bank 생성 시간을 별도 계상한다.
- 완료 기준: 120건 완료·기록 검사 통과·짝 통계 산출, 그리고 결과가 어느 방향이든 사전등록 문장대로 보고.
- **3대 게이트 보정 대상: `performance`** — 규칙 대비 성능을 사전 고정 표본으로 한 번 확증한다.
