# YR-318 — 확증 캠페인: 수정 엔진·새 시드 대역·규칙 대조군

- **상태**: backlog (실행기·통계 배선 완료 2026-09-22 · 선행 대기)
- 등록: 2026-09-21. parent: YR-317. 선행: [[YR-317-k]](교착 수정 ✅)·[[YR-317-n]](학습 3판).
- **사전등록**: `outputs/reports/yr318_confirmatory/prereg.md` (2026-09-22 작성, 결과 보기 전 고정).
- **3대 게이트 보정 대상: `performance`** — 규칙 대비 성능을 사전 고정 표본으로 한 번 확증한다.

## 왜

1. 이 저장소의 동결 규약은 **주판정 축 = 규칙 대비**이고 *안 팔기 대비는 판별력 0* 이다
   (`.claude/docs/architecture/06-학습과-판정.md:103`). 기존 80건에 규칙 팔이 **0개**라,
   지금 원고에는 "학습이 규칙보다 낫다"는 증거가 없다.
2. 후보 가지치기 수정은 **예산이 찬 모든 순간**에 후보 집합을 바꾼다 → 기존 80건과
   직접 비교 불가, 새 사전등록 필수.
3. 80건 전부가 체크포인트 하나에서 나왔고 그 모델은 LEGACY 에서 배워 PRESERVE 에서
   평가됐다. 학습 3판으로 학습 축과 계약 불일치를 같이 막는다.
4. 기존 20시드는 이미 판정에 썼다.

## 설계 (사전등록에서 고정)

- **대역**: 22,000,000 ~ 23,900,000, 간격 100,000, **20개월**. 기존·진단 대역과 겹치지 않음을
  실행기가 기계로 확인한다(`campaign_specs`).
- **엔진**: `candidate_pruning="feasible_first"` · `measure_latency=true`.
- **열 8개**: `NO_REALLOC` · `SLOT_LL`(규칙·시간만, **주 대조군**) · `SPACE_TIME_LL`(규칙·블록+시간)
  · `RL_TIME_n1|n2|n3`(학습 3판) · `RL_n1` · `RL_NOVETO_n1`. 블록전용은 제외(이미 −150% 결론).
- **주판정 하나**: 월마다 학습 3판의 비용을 평균한 파생 열 `RL_TIME_mean` 을 만들고
  `28d:SLOT_LL-RL_TIME_mean` 95% 구간 **하나만** 확증한다. 규약의 *주판정 하나만 고정* 을
  지키면서 "잘 나온 판만 고르기"를 구조적으로 막는다.
- **확증 조건**: 구간이 0을 넘고 **동시에** 세 판의 점추정 부호가 같아야 한다.
- 재표집 20,000회, 통계 난수 **9,900,727**.
- 결과 네 경우(A~D)의 보고 문장을 사전등록에 미리 적었다.

## 배선 (2026-09-22 완료)

- `independent_eval_checks.campaign_specs` — 설정이 (시드, 열 사양)을 선언한다. 열 하나가
  `label`+`arm`+`checkpoint` 라서 **한 팔을 학습 판마다 여러 열**로 둘 수 있다.
  기존 `yr317.independent-evaluation.v1` 설정은 동결값과 정확히 같아야 통과한다.
- `campaign_checks.campaign_summary` / `write_campaign_report` — 선언된 비교쌍·확증 가족·
  파생 열을 받는 짝 재표집. 동결 `paired_summary` 는 **손대지 않았다**.
- `run_independent_evaluation.py` — 시드·팔·가중치를 설정에서 읽고, 열마다 제 가중치를 싣고,
  동결 schema 가 아니면 공급 사전검사 대신 **월별 입력 지문 전수 대조**를 한다
  (공급 사전검사는 체크포인트 하나에 묶여 있어 다중 가중치 캠페인이 재사용할 수 없다).
- `build_independent_seed_bank.py --base/--count/--created-date` — 새 대역 생성.
- `make_campaign_config.py` — 은행·공급 입력·학습 3판에서 설정을 **생성**한다. 손으로 쓰면
  지문 오타 하나가 1,000 CPU-시간을 버린다. 미완성 학습·계약 불일치 학습·누락 입력을 거절한다.
- 열 이름은 파일명 안전 문자만 허용한다(`RL_TIME_n1`) — 콜론은 Windows 폴더 생성에서 깨진다.
- 시험 `tests/v3/test_campaign_contract.py` 17건 + `test_campaign_config.py` 6건.
