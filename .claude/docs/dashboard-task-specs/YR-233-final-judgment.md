## 1. 왜 다시 돌리나

지금까지 판정은 전부 **비판정 대역**(9,900,920~935)에서 나왔다. 거기서 나는:

| 한 일 | 왜 오염인가 |
|---|---|
| 트리거 `k` 4종을 돌려 **팔마다 최선 `k`** 를 골랐다 | 같은 16일 위에서 고른 값이다 |
| [[YR-222]]·[[YR-230]] 중 어느 정책을 쓸지 봤다 | 결과를 보고 골랐다 |
| *"부하가 오를수록 강해진다"* 서사를 만들었다 | **결과를 본 뒤에** 만들었다 |

06 §3 동결 규약: **평가 대역은 새 대역 · 재사용 금지.**

## 2. ★사전등록 — 아래를 동결한다. 실행 뒤 하나도 안 고친다.

```
대역     9,910,000 ~ 9,910,015  (16일 · ★한 번도 안 쓴 새 대역)
부하     3,500 · 5,000 · 7,500        (EVAL_LOADS 동결값 전부)

진단 팔  RL_SPACE(공간만) · RL_TIME(시간만)
```

| 부하 | FCFS | SPT | LEAST_SLACK | NEAREST | NETGAIN |

**새 대역에서는 아무것도 고르지 않는다.** `k` 스윕도 정책 선택도 다시 하지 않는다.

## 3. 판정식 (실행 전 확정)

```
독립단위   날 (같은 날·같은 부하끼리 짝지어)
검정       부호검정 · 양측 · p < 0.05
주판정     부하별로 "RL 이 고전 5종 중 몇 종을 유의하게 넘는가"
부판정     RL 이 NO_REALLOC 을 넘는가
진단       RL / RL_SPACE / RL_TIME 의 안 팔기 대비 격차
```

### 세 결과에 대한 대응을 **미리 적는다** (결과 보고 서사 고르지 않기 위해)

| 새 대역 결과 | 그때 쓸 문장 |
|---|---|
| 부하 7,500 에서 **5/5** | *"과포화에서 학습 정책이 고전 규칙 5종을 전부 이겼다"* — 비판정 재현 |
| 부하 7,500 에서 **3~4/5** | *"과포화에서 5종 중 N종을 이겼다"* — 넘지 못한 팔을 이름과 함께 적는다 |
| 부하 7,500 에서 **0~2/5** | *"비판정에서 보인 우세가 새 대역에서 재현되지 않았다"* — 그대로 적고 원인을 별도 축으로 |

**어느 경우든 부하 3,500·5,000 결과를 함께 적는다.** 이긴 부하만 고르지 않는다.

## 4. 금지

- 결과를 보고 `k`·정책·부하·팔을 바꾸지 않는다.
- 이 대역을 **두 번 쓰지 않는다** — 실행 후 06 §3 의 "사용한 대역" 에 박제한다.
- 진단 팔(`RL_SPACE`·`RL_TIME`)은 주판정에 넣지 않는다. **분해 보고용**이다.

## 6. 실행 결과 (2026-08-30) — **사전등록을 그대로 쓰지 않았다**

### 6.1 왜 사전등록대로 못 했나

§2 의 동결값은 **v2 무대**를 전제한다 — `ckpt_015`, 16일, 부하 3수준, 팔별 트리거 `k`,
셀 432. 그 사이 정책이 **v3 통합 아키텍처**(독립 제안·수락 + 상호 동의 + 반사실 비용
학습, [[YR-203]]·[[YR-205]]·[[YR-207]])로 바뀌었고, 무대도 **30일 연속**([[YR-239]])이
되면서 트리거 `k` 라는 개념 자체가 사라졌다. 그래서 사전등록은 **폐기하고 재설계**했다.

바뀌지 않은 것은 이 row 의 목적이다 — **한 번도 안 쓴 대역에서 딱 한 번 판정한다.**

### 6.4 남는 한계 — 정직하게 적는다

- **분해 팔(`RL_SPACE`·`RL_TIME`)은 주판정이 아니다.** §4 금지 조항대로 분해 보고용이며,

- **같은 행동범위 규칙과의 비교가 검정에 따라 갈린다.** 방향만 보는 부호검정은 못 가르고,

  일치하지만, **한 줄로 단정하지 않고 두 검정을 함께 싣는다.**
