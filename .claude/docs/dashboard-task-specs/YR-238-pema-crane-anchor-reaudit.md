# YR-238 — PEMA 크레인 서비스시간 앵커 재감사

- **Epic**: Infra / **Priority**: 🔴 / **등록일**: 2026-08-27 / **상태**: backlog
- **3대 게이트 보정 대상**: `scenario_validity`와 Dashboard↔증거 정합
- **1줄**: 항만장비제조사협회(PEMA)의 장비 사이클과 시뮬레이션에서 잰 작업의 단위를 대조해 크레인 시간에 대한 현실성 판정을 다시 계산한다.

## 발견

2026-11-25 발행처 PDF 파일의 인쇄면 19쪽(파일 10쪽)을 렌더링해 §7.4를 확인했다. 자동 적재 크레인 한 대의 상·하차를 포함한 전형적 평균 사이클은 **2~3분**으로 명시돼 있다. 이 절은 외부·내부 대기를 제외하고 육측·해측·야드 정리 작업을 각각 정의한다. §7.6은 외부 트럭 서비스시간을 별도로 다룬다. 8월 YR-237의 ‘직접 수치가 없다’는 기록을 정정한다. 이 숫자를 개별 트럭 오더의 허용범위로 사용하려면 작업 단위가 대응하는지를 입증해야 한다. [PEMA 공식 원문 §7.4 및 §7.6](https://www.pema.org/wp-content/uploads/2022/09/PEMA-IP15-ASC-Performance.pdf#page=10)

확인한 PDF의 SHA-256은 `3a98aab8515e819d52faf7898d053b05aa10ba0b13c2d5c1ad122f1fe4bb4959`이다. [30일 시험 월 대조](YR-332-bx-gate-age-curve.md)

한편 Farashahi, Wu, Tatham(2015)은 야드 크레인 취급시간에 삼각분포
`(1.2, 2.0, 3.4)분`을 **가정**한다. 이는 `180초`가 학술모형의 범위 안이라는 보조
근거이지, 부산항 또는 PEMA의 실측 능력 증거는 아니다.

## 할 일

1. PEMA PDF의 §7.4와 §7.6 대조는 위와 같이 완료했다.
2. 등록부의 모든 크레인 시간 출처를 원문·정의·단위별로 분리한다.
3. 시뮬 런 실측 `146.7~147.3초`가 검증된 외부 범위 안인지 다시 판정한다.
4. YR-158 spec·done row·등록부·게이트 산출물에 정정 이력과 새 판정을 같은 커밋으로 남긴다.

## 완료 조건

- PEMA의 전형적인 평균 사이클과 국내 터미널의 트럭 작업 실측을 구분한다.
- 외부 범위의 각 숫자에 원문 위치와 `실측/가정/유도` 등급이 있다.
- `scenario_validity`를 같은 코드로 재계산하고 PASS 또는 FAIL을 결과대로 보존한다.
- 정책 성능은 실행하지 않는다.
