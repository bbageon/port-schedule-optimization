# YR-317-h3 — 구조별 학습·평가 반복 (시드 3개·14일)

- **상태**: backlog
- 등록: 2026-09-20. parent: YR-317. 선행: [[YR-317-h2]](1시드·7일 사례 완료).
- 무엇: h2와 같은 설계(환경별 시간정책 학습 → 자기 환경 평가)를 학습 시드 3개·평가 시드 3개·14일로 반복해 방향의 일관성을 본다.
- 왜: h2는 시드 하나·측정 5일이라 서술 사례다. 리뷰어 2의 "다른 배치에서도 되는가"에 통계로 답하려면 반복이 필요하다. 7일 학습이 30일보다 이득이 작았으므로 학습 일수도 늘린다.
- 고정 원칙: h2 사전등록 그대로(요청 보존·공급 보정·시간정책·마지막 날 체크포인트·시드 선택 규칙). 시드는 결과를 보기 전에 규칙으로 고른다.
- 비용: h2 기준 학습 수평 3.4h·수직 6.3h(7일) → 14일·3시드면 수직 학습만 약 38시간. 코어 배정과 일정을 먼저 정한다.
- 완료 기준: 환경별 시드 3개 짝 요약과 부호 일치 여부, 처리량 변화 공개.
