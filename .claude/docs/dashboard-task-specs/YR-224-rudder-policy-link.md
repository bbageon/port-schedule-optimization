# YR-224 · RUDDER 기여도를 정책 학습에 연결 (자격시험 통과 시에만)

> Epic RL · 우선순위 ⚪ · 상태 **backlog · 조건부** (등록 2026-08-24)
> 선행 [[YR-223]] 관문 A·B·D·F 통과 — **통과 전에는 착수 금지**

## 1. 왜 별도 row 인가

[[YR-223]] 은 *"시간대별 기여도가 의미를 갖는가"* 만 본다. 이 row 는 *"그 기여도로
정책을 가르칠 수 있는가"* 다. **둘을 한 row 로 묶으면 실패 원인을 못 가린다** —
RUDDER 가 틀린 건지, 기여도를 정책에 연결하는 방식이 틀린 건지.

## 2. 핵심 난관 — epoch 기여도 ≠ 개별 행동

```
RUDDER 가 주는 것:  10:00 시장 batch 전체의 기여도 = −12만원
그 안에 오더 10건:  D-001 의 공로는? D-002 의 잘못은? Seller 몫? Buyer 몫?
```

**RUDDER 만으로는 알 수 없다.** 같은 시점 안의 책임 배분은 다른 문제다.

## 3. 두 갈래 — 하나는 연구 질문을 바꾼다

| 안 | 내용 | 대가 |
|---|---|---|
| **A. epoch 공동행동으로 학습** | 기여도를 그 epoch 의 공동 보상으로 | ⚠️ **v3 의 연구 주장을 포기**한다 — "독립 행위자 + 거부권 시장" 이 학습에서 사라진다 |
| **B. 분업 (권장)** | 시간 축은 RUDDER · epoch 안 행위자 신용은 **지금 반사실 그대로** | 반사실 비용이 그대로 남는다 |

**B 를 권한다.** A 는 축을 바꾸는 게 아니라 **연구 질문을 바꾸는 것**이다.
v3 가 v2 와 다른 점이 바로 거부권 있는 독립 행위자인데, 공동 보상으로 학습하면
그 구조가 학습 신호에서 사라진다.

## 4. 판정 기준 (착수 시 동결 · [[YR-218]] 계열과 비교 가능하게)

- 마지막 4회차 평균 격차 < 첫 4회차 평균
- 검증 손실이 라벨 차이의 절반 미만 ([[YR-222]] 와 같은 기준)
- 시드·부하·ε·H 는 [[YR-218]]·[[YR-220]]·[[YR-222]] 와 **동일**

## 5. 하지 않을 것

- [[YR-223]] 관문 미통과 상태에서 착수하지 않는다.
- A 안(공동행동)으로 갈 경우 **연구 주장이 바뀐다는 사실을 먼저 사용자에게 확인**받는다.
