# YR-272 — 망이 내는 값의 이름을 코드와 맞춘다 (짝 중심 상대 비용)

- **Epic**: Paper / **Priority**: 🔴 / **등록·완료일**: 2026-08-30

## 발단

논문 세 곳이 망 출력을 *"예상 운영비(expected operating cost)"* 라고 적었다. 실제
학습 목표는 절대 Φ 가 아니라 **짝 중심 상대 비용**이다.

## 코드로 확인한 사실 (문서만 읽고 고치지 않았다)

- `train/labels.py:74` `base = 0.5*(Φ_factual + Φ_alt)` — 기준선은 **그 짝의 평균**.
- `actors/nets.py:79` `to_advantage = (Φ − base)/ADV_SCALE`, `ADV_SCALE = 100,000`.
  → 목표값은 짝 비용 차이의 **±절반** (원고 수식 `(φ_F − φ̄)/10^5` 은 이미 옳다).
- `reward/counterfactual.py:148` `seller_alt = "KEEP" if seller_action != "KEEP" else "SELL"`
  → 대안은 **실제 행동의 반대**다. 유지했으면 대안이 SELL 이므로
  "$\Delta\Phi^P = E[\Phi(a) - \Phi(KEEP)]$" 로 쓰면 **절반의 경우에 거짓**이다.
- `actors/seller.py:118` 강제 SELL 은 KEEP 행을 빼고 **가장 싼 후보**를 고른다.

## 원고 수정 (국·영문 동일)

- `main.tex` §2.2 · `04-policy.tex` §3.3 · MLP 그림 캡션의 "예상 비용" → **짝 중심 상대
  비용(pair-centred cost score)**. 공통 상수를 빼는 것이라 `argmin` 순서는 불변임을 명시.
- §3.5 에 **대안이 무엇인지** 적었다 — 제안했으면 대안은 유지, 유지했으면 대안은 가장 싼
  후보, 수락은 수락↔거절. 기준점이 고정 행동이 아니라 **짝 자체**임을 밝혔다.
- §3.6 에 *"라벨은 고정된 자료가 아니다"* 문단 추가 — 짝이 그때의 정책 행동에서
  갈라지고 회차마다 버려지므로 **온폴리시 몬테카를로 이점 추정**에 해당하며,
  부트스트랩도 정책경사도 쓰지 않는다. DQN 비유는 "목표 만드는 방식이 다르다"로 한정.

## 왜 이렇게 적는가

심사자의 *"이건 그냥 지도학습 아닌가"* 를 명칭 변경이 아니라 **사실**로 막는다.
자료가 정책을 따라 움직이고 매 회차 폐기된다는 점이 지도학습과 갈리는 지점이다.
