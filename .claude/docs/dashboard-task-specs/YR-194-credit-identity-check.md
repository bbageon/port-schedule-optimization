# YR-194 — 차분신용 합 ≟ 터미널 비용 변화 (엄밀 검증)

- **Epic**: Exp / **Priority**: 🟠 / **등록일**: 2026-08-19 / **상태**: backlog
- **3대 게이트 보정 대상**: `dashboard-code-evidence`
- **1줄**: [[YR-174]] 의 차분신용 분해식이 **실제 비용 변화와 같은지** 한 번도
  직접 대조된 적이 없다. [[YR-189]] 실행 중 우연히 강한 정황이 나왔다.

## 왜 지금 (실측 정황 · YR-189 실행 중 관측 1)

| iter | Φ | 차분신용 합 | Φ + 신용합 |
|---|---|---|---|
| 0 | 4,263 | −1,849 | **2,413** |
| 1 | 3,012 | −510 | **2,502** |
| 2 | 3,080 | −524 | **2,557** |
| 3 | 3,101 | −514 | **2,588** |

행동이 크게 달라진 네 회차인데 `Φ + 신용합` 이 좁게 모인다. 이 값이 "그 날
안 팔았을 때의 비용"이라면 다음 항등식이 성립한다는 뜻이다.

```
Φ(판매 정책) = Φ(안 팔기) − Σ D_i
```

**이것이 성립하면 짝비교 대조군 없이 한 판만으로 판매의 순효과를 읽을 수 있다.**
평가 비용이 절반으로 줄고, 학습 중에도 "지금 정책이 도움이 되는가"를 실시간으로
볼 수 있다.

## 왜 아직 증명이 아닌가

회차마다 **에피소드 시드가 다르다**(`ts + it*4 + e`). 즉 위 표의 2,413~2,588
차이가 "항등식 오차"인지 "다른 날이라서"인지 갈리지 않는다.

## 설계 (단일축 · 값싸다)

**같은 시드로 두 팔을 돌리고 직접 뺀다.**

| | |
|---|---|
| 팔 | `K`(안 팔기) · `q`(판매) — 같은 날·같은 집행 |
| 대상 | ΔΦ = Φ(q) − Φ(K) 와 −Σ D_i 를 **날마다** 대조 |
| 표본 | 12일 (새 대역) |
| 판정 | 짝별 잔차 `ΔΦ + ΣD_i` 의 평균·95% CI · 상대오차 분포 |

**기대**: 완전 일치하지는 않는다. `realized_credit` 은 근사다(소스 절감의
"남았더라면"은 미관측이고 본선 압력도 근사). **얼마나 어긋나는지를 재는 것**이
목적이다.

| 잔차 | 뜻 |
|---|---|
| CI 가 0 포함 · 상대오차 작음 | **항등식을 실용적으로 쓸 수 있다** — 대조군 생략 가능 |
| 계통 편향 존재 | 어느 항이 빠졌는지 분해(수신 부담·본선·주행·기사) |
| 크게 어긋남 | 차분신용을 **보상으로만** 쓰고 성과 지표로는 쓰지 않는다 |

## 하지 않는 것

- 결과를 보고 `realized_credit` 을 항등식에 맞게 고치는 것 — 그러면 보상이
  성과 지표를 정의하게 되어 순환이다. 어긋남은 **어긋남으로 보고**한다.
- 이 검증으로 [[YR-189]] 판정을 대체하는 것.
