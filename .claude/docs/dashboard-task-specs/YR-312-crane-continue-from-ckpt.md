# YR-312 — 안정된 조건을 **이어서** 돌려 평탄부가 아직 움직이는지 본다

## 무엇을 하는 작업인가

[[YR-311]] 의 마지막 체크포인트(36회차)에서 **이어서** 36회차를 더 돌린다.
새로 시작하지 않는다.

## 왜 지금 하나 — 1단계 목표(규칙 이기기)가 아직 아니다

[[YR-311]] 로 학습이 안정됐다(널뛰기 −42%). 그런데 평탄부 평균이 **+2.24%** 로
규칙보다 아직 조금 비싸다. 두 가지 중 하나다:

- **아직 내려가는 중** — 평탄부 앞 절반 +3.11% · 뒤 절반 +1.43%, 마지막 6회차가
  전부 0 이하. 그러면 더 돌리면 이긴다.
- **여기가 바닥** — 8칸 특징·차점자 비교만으로는 규칙을 못 넘는다. 그러면 정책의
  **정보**나 **비교 방식**을 바꿔야 하고, 회차를 더 돌려도 소용없다.

**이 둘을 가르는 것이 먼저다.** 정보를 추가하는 것은 연구 원칙 2 에 따라 *"효과가
실증된 뒤 한 축씩"* 인데, 지금은 회차 부족인지 정보 부족인지조차 모른다.

## 어떻게

`--resume outputs/v4/crane-fit-saturate/crane_035.pt` 로 망과 옵티마이저를 이어받아
36회차. 시드는 이어지는 번호(37회차부터)라 **새 날**들을 본다. 나머지 조건은
[[YR-311]] 과 동일 (계수 1.0 · 라벨 64 · 창 3시간 · 10코어 · 고정 평가일 없음).

⚠️ 옵티마이저 상태(Adam 모멘트)도 저장·복원해야 한다 — 망만 이어받으면 첫 몇 회차가
새 시작과 같아진다. 지금 체크포인트는 망만 저장하므로 **저장 형식을 먼저 고친다.**

## 판정 기준 (사전등록 — 실행 전에 확정)

이어 돌린 36회차의 궤적(부하 7,500 · 시드 9,900,917)을 [[YR-311]] 평탄부와 견준다.

| | [[YR-311]] 평탄부 (31점) | 이번 (36점) |
|---|---|---|
| ① **평균** | +2.24% | **0 이하**로 내려가야 "아직 움직인다" |
| ② 표준편차 | 4.20% | 안 커져야 한다 |
| ③ 이긴 회차 비율 | 32% | 참고 |

①이 0 이하면 → 계속 돌린다(다음 단계로 판정 대역 진입 준비).
①이 여전히 양수고 [[YR-311]] 과 비슷하면 → **바닥**이다. 회차가 아니라 정책의
정보·비교 방식으로 축을 옮긴다([[YR-248]] 2단계 재설계).

## 예산

10코어 36회차 ≈ 4.9시간 + 궤적 0.6시간 ≈ **5.5시간**.
