# YR-248 — 다음 연구: 크레인 학습과 본선·트럭 비용 분리

- **상태**: backlog 🟡 · 2026-08-28
- **분류**: RL
- **원래 등록 ID 정정**: 닫힌 논문 작업 YR-240과 중복돼 YR-248로 이동
- **선행**: YR-239 현행 연구 판정 완료

## 범위 결정

현행 연구에서 본선은 터미널 부하를 만드는 작업으로만 사용하고, 재배치 정책과 크레인
작업순서가 본선·트럭 비용을 구분해 최적화하는 문제는 다음 연구로 이관한다.

## 관측된 출발점

- 현행 크레인 작업순서는 비용을 읽는 학습 정책이 아니라 최단 처리시간 규칙이다.
- 본선 일정 여유 입력은 15,000대에서도 97.5%가 상한에 붙어 대부분 같은 값이다.
- 본선 유휴는 관측되지만 정책은 직접 원인을 구분하지 못하고 혼잡도만 간접적으로 본다.

## 후보 연구축

1. 본선 계획 완료시각과 일정 여유 범위를 실제 기항시간 범위로 다시 보정한다.
2. 막힌 본선 작업, 버퍼 수준, 대기 작업 중 본선 비율 같은 즉시 신호를 비교한다.
3. 본선과 트럭 비용 가중치를 구분해 비용을 인식하는 크레인 정책을 학습한다.

각 정보와 비용축은 한 번에 하나씩 추가하고, 수요수준별 개선과 긴 대기 악화를 따로
검증한다.

## 착수 (2026-09-06) — v4 에서 시작

**세대**: v4 ([[YR-297]] 경계 — 아키텍처를 바꾸는 축이라 논문 코드 v3 에 손대지 않는다)

### 코드를 읽고 확인한 출발점 — 재료는 이미 있다

| 있는 것 | 위치 |
|---|---|
| **본선/트럭 구분이 후보 특징에 이미 있다** | `adapter.py` — `is_vessel` · `is_external` |
| 본선 신호도 이미 관측된다 | `deadline_slack_s` · `vessel_risk_delta` · `backlog_vessel` · `sts_wait_s` |
| RL 이 꽂힐 자리가 규약으로 열려 있다 | `Preference.rank(sim, crane_id, gc) -> tuple` |
| 정보경계가 이미 지켜진다 | 다섯 바닥 전부 `USES_FUTURE_INFORMATION = False` |

**즉 없는 것은 "그 재료를 읽고 비용으로 고르는 정책" 하나뿐이다.** 후보 특징을 새로
만들 필요가 없다 — [[YR-242]] 가 말한 *설계-코드 불일치* 의 실체가 이것이다.

### 왜 지금 값을 하나 — 규칙의 실체

현행 `SF_SPT` 는 정렬키가 다섯 자리지만 실제 승부는 **소요시간 61.6% · 이름순 33.6%**
로 갈린다(실측 [[YR-242]] §2). 즉 **사실상 최단작업 우선이고 이름순이 3분의 1을 정한다.**
비용을 한 줄도 안 읽는다. 본선 유휴가 30일 내내 발생(하루도 0인 날 없음 · 최악 53시간/일
· 합계 1.96억원 = Φ의 1.21%)하는데 크레인은 그것을 모른다.

### 단계 (연구원칙: 한 번에 한 축)

```
1단계  비용 인식 크레인 정책의 최소형
       상태 = 이미 있는 후보 특징 중 핵심만 (is_vessel · cum_wait · reach ·
              expected_service_time · deadline_slack)
       라벨 = v3 과 같은 방식 — 반사실 비용 차이 (자기 추정 부트스트랩 안 함)
       판정 = 다섯 규칙 바닥 대비 · 날 단위 짝비교
2단계  본선/트럭 가중치 분리 (사용자 결정 2026-08-28 의 핵심)
       Φ 의 본선 항과 트럭 항을 **다른 가중치**로 크레인에 준다.
       그래야 "어느 배를 먼저 먹일까" 가 비로소 결정이 된다.
3단계  재배정층(v3 정책)과 함께 굴렸을 때의 상호작용
       ⚠️ 두 층이 동시에 학습하면 귀속이 무너진다 — 재배정층은 **동결**하고 시작.
```

### 먼저 확인해야 할 것 (1단계 전)

- **`slack_s` 상한 문제**: 본선 일정 여유가 15,000대에서도 97.5%가 상한에 붙는다
  ([[YR-239]] A11 정정 — 원인은 창 밖 결측이 아니라 **여유 배수 `dmult=2.0`**).
  이 칸이 죽어 있으면 본선 축 학습이 시작부터 장님이다. **후보축 1번(기항시간 범위
  재보정)이 1단계보다 먼저**일 수 있다 — 실측으로 판정한다.
- **비교 바닥 확정**: [[YR-213]](크레인층 비교군을 문헌 표준으로)이 열려 있다.
