# YR-332-ay — 남은 비용 예측 학습 안정화 한 축 비교

**상태**: done (합성 진단 완료; 기본 정책 채택 없음)
등록: 2026-11-17. ax 저장 경험 진단에서 파생. 사용자가 비교 실행을 명시 요청하여 합성 진단에 착수한다.
3대 게이트 보정 대상: performance. 현실성 i/f 선결은 유지한다.

## 무엇·왜

- ax에서 두 구조·초기값 셋 모두 혼잡일 오전 선택이 거의 전부 음수 학습 신호를 받았다.
  Transformer 5,838선택 중 양수6개, MLP 5,930개 중0개다. 음수 자체를 잘못된 선택으로 해석하지 않는다.
- Transformer 비용 예측 오차는 갱신 직전3.541→같은 자료 학습 직후1.648이지만,
  물량·시각별 기준 예측 차이가 크게 남았다. 첫 배치의 가치 기울기는 행동의 중앙값116.1배다.
- 다음 비교는 **가치망 내부의 목표 정규화** 한 축으로 좁힌다. 후보는 PopArt(목표 눈금은 조정하되
  원래 단위의 예측은 보존하는 방식)다. 가치망 오차가 실제 정책 손실의 원인인지는 검증 대상이다.

## 설계할 비교

1. 현행 가치 학습 vs 출력 보존 목표 정규화. 보상·고정 비용 눈금368293633.7020551·기간·10개 입력·
   정책 구조·행동 확률·가치 손실 계수·표본 수·반복 횟수·기울기 제한은 같은 값으로 고정한다.
2. 원래 단위로 복구한 가치 예측으로 행동 학습 신호를 계산한다. 물량별 보상 가중치나
   날별 임의 평균 빼기, 짧은 보상창, 대기 상한 해제, 새 상태 정보를 함께 추가하지 않는다.
3. 정규화 통계는 학습 자료에서만 갱신하며, 통계만 바꾼 순간의 복구된 가치 예측이 보존되는지 시험한다.
   Adam 상태·출력층 보정 계약과 통계 갱신 속도를 실제 실행 전에 문헌·코드와 대조해 동결한다.
4. 같은 시작값의 Transformer 초기값 셋을 대응시킨다. 기존 가중치 파일에 Adam 상태가 없으므로
   완전한 이어학습이라고 부르지 않는다. 동일 초기화 재시작 또는 저장 경험으로 상태 복원 중
   하나를 사전등록하며, 두 방법을 섞지 않는다. 실제 seed·입력·예산은 별도 실행 명세에서 동결한다.
5. 새 경험을 사용하는 학습과 고정 검증 입력을 분리한다. 이미 본6개 holdout을 새 독립 시험으로
   재사용하지 않는다. 환경 생성기는 유지하고 데이터 분리·통계 추정·체크포인트 선택 규칙을 먼저 고정한다.

## 확인할 효과와 제한

- 학습 자료 적합도와 미사용 날짜의 가치 예측 오차를 구별한다. 물량·시각별 신호 쏠림도 다시 잰다.
- 같은 상태에서 확률 분포와 최고점 순위를 함께 기록한다. ax에서 약4%p 확률 변화가
  두 초기값의 최고점 반입 비중을 거의 전부로 바꿨으므로 작은 확률 변화를 작은 행동 변화로 읽지 않는다.
- 평가는 기존 최고점 선택으로 고정해 비교한다. 학습의 확률 추첨과 같다고 서술하지 않는다.
- 최종 효과는 총비용·게이트진입→작업완료 평균·반입/반출/양하/적하·미완료·본선 보호로 판정한다.
  가치 오차만 줄거나 한 초기값만 좋아지면 정책 개선으로 채택하지 않는다.
- 이번 등록은 성능 개선이나 새 실행 허가가 아니다. i/f 현실성 확인과 착수 판정을 선행한다.
  사용자가 별도의 합성 진단을 명시 요청하면 그 범위와 원래 게이트 거절을 그대로 기록한다.
