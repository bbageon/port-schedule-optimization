# YR-302 — 학습 망 초기값이 시딩되지 않았다

- **상태**: ✅ 완료 · 2026-09-10
- **분류**: Infra
- **발단**: [[YR-299]] B 를 무효로 만든 결함. 사용자 지적(*"더 보는데 악화가 이해 안 된다"*)에서 감사로 찾았다.

## 무엇이 문제였나

```python
train/month_loop.py:71    s_net, b_net = SellerNet(), BuyerNet()    # 시딩 없음
```

`torch.manual_seed` 는 `stage/month_run.py` 와 `stage/episode.py` 두 곳에 있는데
**둘 다 `seller_net is None` 일 때만** 탄다. 학습 경로는 망을 여기서 만들어 넘기므로
**한 번도 시딩되지 않았다.**

## 왜 심각한가 — 실험 하나를 무효로 만들었다

[[YR-299]] B 가 반사실 창 3h vs 6h 를 견줬는데 **0일차부터 거래가 갈렸다**:

| 0일차 | h3 | h6 |
|---|---|---|
| 부하·트럭·결정 수 | 동일 | 동일 |
| 거래 | 4,400 (공간 **33.5%**) | 3,759 (공간 **17.3%**) |

0일차는 **창이 개입할 경로가 없다**(창은 하루 끝 적합에만 쓰인다). 원인은 초기값뿐이고,
그래서 "3.7배 차이" 를 창 탓으로 돌릴 수 없게 됐다. 초기값만으로 공간 비중이 이만큼
흔들리는데, 그 방향은 최종 결과(2.4% vs 38.1%)와 **반대**였다.

## 고침

```python
import torch
torch.manual_seed(int(seed) + 1)          # ← 망을 만들기 직전
s_net, b_net = SellerNet(), BuyerNet()
```

**`seed + 1` 인 이유**: `run_month` 안에서 `torch.manual_seed(seed)` 가 또 불릴 수 있다
(탐색 잡음용). 같은 값을 쓰면 초기값과 탐색이 같은 흐름을 공유해 둘이 얽힌다.

**검증**: 같은 시드 두 번 → 첫 가중치 `0.038676` 동일 · 다른 시드 → `-0.024357` 로 다름.

## 남는 일

- [[YR-299]] B 재실험은 이 고침 **위에서** 해야 한다. 다만 시딩만으로는 부족하고
  **팔당 3시드**가 필요하다 — 시드 하나로는 초기값 운을 못 걷어낸다.
- 라벨 중앙 격차를 `history.json` 에 기록하는 계측은 **아직 안 했다.** 그게 없으면
  `ADV_SCALE` 눈금 문제를 검증조차 못 한다 → 후속으로 남긴다.
