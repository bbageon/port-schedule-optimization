# YR-332-aj — 실제 오더 대표성·유입 분포 대조와 단일축 보정

- **상태**: backlog
- 등록: 2026-11-12, 사용자 질문 “학습·평가 편향이 있는가 / 그러면 무엇을 하면 되는가”.
- **3대 게이트 보정 대상**: scenario_validity(만든 상황이 관측 자료와 맞는가).
- 이 명세는 진행 순서 등록이다. 새 생성기 수정·학습·평가 착수를 뜻하지 않는다.
- 착수 전 현재 저장 판정으로 현실성 보정 허가를 재확인한다.

## 무엇과 왜

ag는 실제 예약·접수 분포만 보정한 합성 하루 실험이다. 작업 구성 전체를 재현한 실험이 아니다.
반입 우선 성향의 원인을 학습망으로만 돌리기 전에 입력과 처리 구조의 차이를 확인한다.
관측 자료의 반입 46.25%·반출 53.75%와 평가 입력 40.19%·59.81%가 다르다.
이 차이 자체가 반입 우선의 원인이라는 뜻은 아니며, 가정과 관측을 구분할 근거다.

## 1. 자료 범위와 분할을 먼저 확정

1. 원본 파일 해시·수집 기간·중복·누락·취소·최초 통지 연결 여부를 기록한다.
2. 제공 자료가 터미널 전체 물량인지 일부 차량·수집 경로의 표본인지 확인한다.
   확인되지 않은 일별 건수를 터미널 전체 도착률로 확대하거나 확정하지 않는다.
3. 날짜·시간대·반입/반출·관측 가능한 블록별 건수, 도착 간격과 몰림을 비교한다.
   본선은 양하·적하·항차·시각의 정의를 구분하며 291,499행을 관측 13일 처리량으로 보지 않는다.
4. 예약 보정에 제외된 5,019건(진입 자료의 약 14.6%)의 관측 가능한 특성을 포함군과 비교한다.
   사용자 전건 예약 가정을 유지하되, 예약 정보의 선택 조건 때문에 물리 주문까지 삭제하지 않는다.
5. 이미 살펴본 10/28~11/09 자료는 개발·진단용이다. 뒤 4일을 새 잠금평가 자료로 부르지 않는다.
   최종 검증 기간은 새로운 미열람 자료에서 미리 정한다. 신규 합성 시드는 실자료 독립 검증과 구분한다.

## 2. 실제 자료와 합성 입력의 차이를 표로 확정

- 물량 비율, 시간대별 유입, 블록 집중, 유형 간 동시 유입, 본선 작업 겹침을 같은 단위로 대조한다.
- 적용 가능·필드 의미 미확정·자료 없음으로 나누고, 확인된 차이의 크기와 표본 수를 함께 기록한다.
- 예약 오차·통지 리드의 관계는 유지하며 시간대·날짜별 차이가 큰지 검사한다.
- 게이트→작업 완료는 대기·주행을 포함하므로 순수 크레인 작업시간으로 대입하지 않는다.
- 본선 atw의 단계 정의·운반 자원은 기존 i, 블록 대기 수의 정의는 기존 f에서 확인한다.
- 실제 완료 시각은 검증 대상이다. 이를 변경 정책의 강제 완료 시각이나 공개 미래 정보로 쓰지 않는다.
- 실제 블록 정보를 기존 수평 배치에 옮길 때 대응 근거를 남긴다. 이름만 대응해 현장 재현으로 부르지 않는다.

## 3. 확인된 유입 차이를 한 축씩 보정하고 고정 정책으로 진단

1. 한 번에 작업 비율 또는 시간대별 유입 등 확인된 입력 축 하나만 바꾼다.
   24시간 입력 틀과 전건 예약 조건을 유지하며, 네 유형을 억지로 25%씩 만들지 않는다.
2. 입력 계약·비교 날짜/시드·물량·관측 창·평균의 가중 방식·판정 범위를 실행 전에 고정한다.
   모든 규칙과 모델에 같은 신규 입력을 주고, 가능한 부분은 변경 전후의 난수를 맞춘다.
3. 저장된 학습 전/후 모델과 기존 7규칙을 고정한 채 비교한다. 보상·신경망·운반 설정을 함께 바꾸지 않는다.
4. 주문 보존·컨테이너 공급·적재 용량·정보 공개 시점·시각 순서를 먼저 검사한다.
   같은 입력의 반복 결과가 일치해야 비교 수치를 해석한다.
5. 트럭 진입→완료, 본선의 확인된 시작→야드 완료, 미완료 수와 대기 분해를 유형별·부하별로 보고한다.
   주문 수 가중 평균과 날짜별 결과를 구분하고, 혼잡한 조건이 평균을 지배하는 정도를 명시한다.
6. 완료 시각을 모형에 강제 입력하거나 작업시간을 정책 성능에 맞춰 조정하지 않는다.
   처리 조건 미확정이 남으면 그 범위의 진단으로 보고하고 전체 현실성 통과로 승계하지 않는다.

## 완료 기준과 연결

- 관측/합성 분포 비교, 포함·제외·미확정 목록, 보정 파라미터의 출처와 재현 자료를 남긴다.
- 확인 가능한 유입 보정과 고정 정책 비교를 완료한다. i/f의 별도 미확정을 이 작업 완료로 닫지 않는다.
- 그 뒤에도 반입 우선이 남으면 기존 323-d에서 표본 구성과 주어진 자료를 맞추는 능력을 구분한다.
- 정책의 성능 변경은 현실성 조건을 확인한 뒤 표본 수 또는 학습 반복 중 한 축만 검증한다.
- 최종 선택과 미사용 기간 검증은 323-e, 연속 운영 판단은 기존 332-d로 이어진다.
