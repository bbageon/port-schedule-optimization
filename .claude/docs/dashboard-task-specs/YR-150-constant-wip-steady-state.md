# YR-150 — 지속 유입 정상상태 시험 (도착률 고정 · 재공량 자유 변동)

- **Epic**: Exp / **Priority**: 🔴 / **등록일**: 2026-08-05 / **재정의**: 2026-08-05
- **상태**: backlog
- **★재정의(사용자 결정 2026-08-05)**: 구판 제목·설계였던 **"보정 고정 재공량(WIP-CAL)"
  의 핵심 메커니즘(목표 밴드 입문 제어)은 채택하지 않는다.** 터미널 안 트럭 수를 항상
  일정하게 유지하면 **정책이 빨리 처리할수록 새 트럭을 더 받게 되어 정책별 입력량이
  달라진다**(공정 비교 파괴). 대신 **외부 도착률을 고정**하고 **재공량은 정책 성능에 따라
  변하는 결과 지표**로 둔다. [결정 문서](../strategy-history/2026-08-05-지속유입-정상상태-시험-전환-사용자결정.md)

## 질문과 지위

- 질문: "트럭이 **계속 도착하는** 정상상태에서 Block Policy 와 TransferResolver 가 규칙보다
  시간당 더 많이 처리하면서 완료 1대당 비용도 낮추는가?"
- **본 성능시험**이다. YR-149 5셀(4h 유입→2h 비우기)은 **유한 물량 처리·회복 시험**으로
  분리 보존한다 — 그 구조는 지속 운영 성능이 아니라 "쌓인 물량을 얼마나 빨리 비우는가"를
  잰다(A150 의 과부하도 그 뜻으로 한정).
- 실제 TOS 연동은 제외. 작업저장소는 TOS 가 최초 배정·예약·ETA 를 전달한 합성 입력이며
  실제 도착·주행·완료는 발생 전 비가시 실현값이다.

## 지속 유입 계약 (동결 대상 — 착수 시)

1. **트럭은 평가 종료까지 계속 도착**한다(현재는 4h 뒤 유입 중단 — 생성 계약 변경 필요).
2. **50·75·100·125·150 은 총량이 아니라 4시간당 도착 강도**로 재정의한다
   (시간당 약 12.5 · 18.75 · 25 · 31.25 · 37.5 대).
3. **모든 정책군이 동일한 도착 흐름**(같은 master stream)을 쓴다.
4. **warm-up → 측정창(4h) → 비우기창** 3구간으로 나눈다. 비용·대기·처리량은 **측정창에서만**
   집계하고, 비우기창은 **완주·잔여 확인 전용**(성능비용에 섞지 않음)이다.
5. **본선 작업도 평가창 전체에 분산**한다 — 후반부가 트럭 전용 실험이 되지 않게 한다.
6. 재공량(A≤t<O)은 **제어하지 않고 측정**한다. 목표 밴드·즉시 재충전·입문 보류 없음.

## 엔진 선결

1. 유입이 평가창 전체에 걸쳐 발생하도록 시나리오 생성 계약 변경(현 `horizon` 내 도착 +
   `drain_window` 구조를 3구간 계약으로 확장).
2. 본선 process 를 평가창 전체에 분산 배치(현재는 앞쪽 집중).
3. 구간별 장부: 측정창 비용 적분·검열 규칙, 구간 경계에서의 진행 중 작업 처리.
4. 동일 master job stream 을 정책군이 공유하고, owner/version/rollback·TransferResolver
   원자성은 현 계약을 유지한다.
5. 결정론·사건 순서·미래정보 누출 0·구간 경계 장부 항등을 테스트로 고정한다.

## 평가계약

- **주지표**: 측정창의 시간당 완료 트럭 수, 완료 트럭 1대당 v2 비용.
- **공동 보호지표**: 평균 A→O, 시간당 본선 지연비용, YC 가동률, 이송/route 비용,
  안전장치 개입률, 측정창 재공량(결과 지표).
- raw 에피소드 총비용은 판정에 쓰지 않는다(정책별 노출 차이).
- 미완·검열 표본을 제외하지 않는다. 측정창 종료 시 진행 중 작업은 전부 장부에 남긴다.
- 처리량이 늘고 비용/완료가 줄며 보호지표·물리·원자성 가드를 통과할 때만 우월이다.

## 실험 사다리

0. **엔진 계약 파일럿**: 정책 없이(SF) 도착 흐름·3구간 장부·정상상태 도달 여부만 확인.
   warm-up 길이와 측정창을 결과 열람 전 동결한다.
1. **정책 비교**: `SF-SPT / PPO C0 / PPO C0 + 계산견적 TransferResolver` 분리 —
   블록 내부 정책 이득과 블록 간 이송의 추가 이득을 구분한다. learned SELL 은 YR-151
   통과 뒤 별도 군으로만 추가한다. 안전장치 ON/OFF 는 섞지 않고 별도 열로 보고한다.
2. **독립 확증**: 파일럿과 겹치지 않는 시드뱅크·정책 간 동일 master stream·계층형 짝지은
   신뢰구간. 표본 수는 파일럿 MDE 로 사전 동결·top-up 금지.

## 되돌릴 조건

- 정상상태에 도달하지 못하면(측정창 안에서 재공량·대기가 계속 발산) 그 부하 셀은
  **용량 초과**로 분류하고 비용 판정 대신 처리량·잔여만 본다.
- 지속 유입 구조에서 이송 효과가 없으면 TransferResolver 군은 닫고 SF/PPO 의 정상상태
  처리능력 진단으로 범위를 축소한다.
