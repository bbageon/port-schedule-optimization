# YR-150 — 보정 고정 재공량(WIP-CAL) 정상상태 스트레스

- **Epic**: Exp / **Priority**: 🟠 / **등록일**: 2026-08-05
- **상태**: backlog — YR-149 열린 흐름 5셀·견적축 확정 뒤
- **사용자 결정**: 유입 총량 실험과 별도로, 터미널 안 트럭 수를 꾸준히 유지한 상태에서
  정책의 지속 처리능력과 비용효율을 측정한다.

## 질문과 범위

- 질문: “트럭이 계속 공급되는 정상상태에서 Block Policy와 TransferResolver가 규칙보다
  시간당 더 많이 처리하면서 완료 1대당 비용도 낮추는가?”
- 실제 TOS 연동은 제외한다. 작업저장소는 TOS가 최초 배정·예약·ETA를 이미 전달했다는
  **합성 입력 스냅샷**이며, 실제 도착·주행·완료는 발생 전 비가시 실현값이다.
- 본 실험은 스트레스·용량 검증이다. 실제 터미널 동시대수나 DGT 성능을 주장하지 않는다.

## 고정 재공량 계약

- 활성 트럭은 `actual_gate_in(A) <= now < actual_gate_out(O)`로 정의한다.
- 제어 대상은 **터미널 전체 활성 트럭 수**다. 블록별 수를 강제하면 이송 직후 자동 보충이
  이송 효과를 지우므로 블록별 목표·즉시 재충전은 금지한다.
- 목표는 정확히 한 점이 아니라 `target ±max(1대, 5%)` 밴드다. 하한 아래로 내려가면 합성 TOS
  작업저장소에서 다음 사전발행 작업을 gate-in시키고, 상한에서는 입문을 보류한다.
- 50/75/100/125/150은 4시간 **유입 총량**이므로 동시대수로 그대로 재사용하지 않는다.
  YR-149 각 열린 흐름 셀에서 측정한 시간가중 활성대수·A→O로 목표 밴드를 결과 열람 전에
  `WIP-CAL-*`로 별도 동결한다(`L = 유입률 × 체류시간` 계약).

## 엔진 선결

1. 현재 `O=C+exit_travel` 장부 계산을 명시적 `GATE_OUT` 사건으로 승격한다.
2. `GATE_OUT`에서 전역 활성대수를 갱신하고 admission controller를 깨운다.
3. 작업저장소는 job/예약/ETA/최초 블록만 공개하고 actual A/B/O·실현 travel을 분리한다.
4. 예상 gate→block/이송시간과 실제 실현시간은 다른 난수열로 생성한다.
5. 동일 master job stream·초기 블록 비율을 정책군이 공유하며, owner/version/rollback과
   TransferResolver의 원자성은 현 계약을 유지한다.
6. 결정론·사건 순서·중복 gate-out 0·활성대수 장부 항등·미래정보 누출 0을 테스트한다.

## 실험 사다리

### 0. 목표 동시대수 보정

- YR-149 열린 흐름 5셀을 SF-SPT로 실행해 시간가중 활성대수·최대대수·A→O를 측정한다.
- 각 셀에 대응하는 목표 밴드와 warm-up·측정창을 결과 열람 전 별도 동결한다.

### 1. 엔진 계약 파일럿

- 정책 없이 입문/출문 장부, 목표 밴드 유지율, 저장소 고갈 0, 정보시점만 확인한다.
- 한 정책이 느려서 출문이 적을 때 새 작업도 적게 받는 내생 노출을 원자료에 기록한다.

### 2. 정책 비교

- `SF-SPT / 현재 PPO C0 / PPO C0+계산견적 TransferResolver`를 분리해 블록 내부 정책 이득과
  블록 간 이송의 추가 이득을 구분한다.
- learned SELL은 YR-151이 통과한 뒤에만 별도 군으로 추가하며 계산견적 군을 암묵 대체하지 않는다.
- 배포 안전장치 ON/OFF를 섞지 않고 별도 열로 보고해 가드 이득을 학습 성과에 합산하지 않는다.

### 3. 독립 확증

- 파일럿과 겹치지 않는 seedbank, 정책 간 동일 master stream, 학습 초기화×시나리오의
  계층형 짝지은 신뢰구간을 사용한다. 표본 수는 파일럿 MDE로 사전 동결한다.

## 평가계약

- **주지표**: 시간당 완료 트럭 수, 완료 트럭 1대당 v2 비용.
- **공동 보호지표**: 평균 A→O, 시간당 본선 지연비용, YC 가동률, 이송/route 비용,
  안전장치 개입률, 목표 밴드 유지율.
- raw 에피소드 총비용은 더 빠른 정책이 더 많은 작업을 받는 노출 차이 때문에 판정에 쓰지 않는다.
- 미완·검열 표본을 제외하지 않는다. 종료시 활성 WIP와 진행 중 작업은 전부 장부에 남긴다.
- 처리량이 늘고 비용/완료가 줄며 본선 허용손실·물리·원자성 가드를 통과할 때만 우월이다.

## 되돌릴 조건

- 목표 밴드 제어가 정책별 입문 패턴을 지나치게 다르게 만들어 공정 비교가 불가능하면,
  고정 WIP를 채택평가에서 제외하고 열린 흐름의 용량 스트레스 참고군으로만 보존한다.
- 열린 흐름 YR-149에서 견적 효과가 없으면 TransferResolver 군은 열지 않고
  SF-SPT/PPO의 정상상태 처리능력 진단으로 범위를 축소한다.

## 현재 환경과의 차이

- 현재는 첫 4시간에 유한 작업을 생성하고 2시간 배출한 뒤 종료한다.
- `GATE_OUT`은 사건이 아니라 완료 때 계산한 장부시각이고, 새 작업을 동적으로 추가하지 않는다.
- 따라서 본 row는 단순 파라미터 변경이 아니라 사건·입문 계약을 추가하는 별도 실험이다.
