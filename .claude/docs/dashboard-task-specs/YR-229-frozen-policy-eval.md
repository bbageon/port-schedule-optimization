# YR-229 · 정책을 얼려서 16일로 잰다 — ★RL 이 처음으로 기준선을 이겼다

> Epic Exp · 우선순위 🔴 · 상태 ✅ **완료** 2026-08-25
> 처방 출처 [[YR-228]] 안 A · 사용자 물음 *"지금 정책적으로 이득을 본거야?"*

## 1. 왜 이 측정인가

[[YR-228]] 이 확인한 것 — 지금까지 성능이라 부른 **학습 회차 격차**는 정책·탐색·
날이 한 수치에 뒤섞여 **판정력이 없었다**(세 실행 모두 |t|<2).

→ 정책을 **얼리고**(탐색 0) 같은 날에 팔만 바꿔 **16일 부호검정**을 한다.
그러면 남는 분산이 날 차이뿐이라 판정력이 생긴다.

## 2. 사전등록 (착수 전 동결 · 결과 보고 안 바꿈)

```
정책 3종   ① 학습 전(초기망·시드고정) ② [[YR-220]] 최종 ckpt_023 ③ [[YR-222]] 최종 ckpt_015
기준선     NO_REALLOC (처음부터 끝까지 한 번도 안 판다) — 공통
부하       3,500 · 5,000        날 9,900,920~935 (16일 · 비판정 대역)
탐색       0                    판정  부호검정 p<0.05
가드       모든 셀에서 rollout_calls == 0 (교사 누출 없음) — assert 로 강제
```

셀 128개 · 8코어 **72분**.

### ★부하 3,500 에서 RL 이 기준선을 이겼다 — 이 연구의 첫 긍정 결과

**16일 중 14일**에서 재배치가 더 쌌다. 중앙 **−1,551,913원 (−1.81%)** · p=0.0042.
거래 1,185건 기준 **1건당 −1,310원**.

### 학습이 만든 변화 (부하 3,500 · 학습 전 대비)

| | |
|---|---|
| [[YR-220]] | +2,484,724 → +2,589,936 = **+105,212원 악화** |
| **[[YR-222]]** | +2,484,724 → **−1,551,913** = **−4,036,638원 개선** |

**표본을 5배로 늘린 것이 실제로 정책을 바꿨다.** [[YR-220]] 은 학습 전과 같거나
조금 나빴는데, [[YR-222]] 는 400만원을 되돌렸다.

### 부하 5,000 은 아직 손해 — 그러나 개선 중

+11,045,606 → **+6,273,522** (약 480만원 개선). 방향은 맞지만 아직 기준선 아래로
못 내려왔다. 거래 1건당 +5,885 → +3,973원.

## 4. ★[[YR-222]] 판정을 정정한다

[[YR-222]] 를 *"실패(①③ 미달)"* 로 기록했는데, **기준 ③ 은 판정력이 없는
지표 위에 세워져 있었다**([[YR-228]]). 제대로 재니 **[[YR-222]] 는 부하 3,500 에서
성공**이다.

| | 그때 판정 | 지금 |
|---|---|---|
| ① 검증 잔차 < 신호 절반 | ❌ 미달 (0.87배) | **그대로 미달** — 라벨 학습 가능성 문제는 남는다 |
| ③ 마지막 4회차 < 첫 4회차 | ❌ 미달 | **판정 무효** — 표본 4개·표준편차 800만원 |
| **성능 (정정 측정)** | — | **✅ 부하 3,500 이득 (p=0.0042)** |

**①은 여전히 사실이다** — 망 오차가 신호의 0.87배다. 그런데도 정책이 좋아졌다는
것은, **오차가 커도 argmin 이 평균적으로는 옳은 쪽을 고른다**는 뜻이다.
