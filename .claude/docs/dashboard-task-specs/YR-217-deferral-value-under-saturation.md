# YR-217 · 이연 라벨 0 이 남는 이유 — **답이 예상과 달랐다**

> Epic RL · 상태 ✅ **측정 완료 · 사용자 결정 대기** 2026-08-23
> 선행 [[YR-216]] ✅ · 후속 결정 필요 → §5

## 1. 물었던 것

[[YR-216]] 이 성사된 이연의 라벨 0 을 92.9% → 52.0% 로 줄였다. **남은 52% 가
측정 결함인지, "그 이연이 실제로 무의미했다" 는 참말인지** 가르려 했다.

가설: *"3,500 은 한산해서 줄이 없고, 줄이 없으면 방문이 통째로 밀려 턴타임이 그대로다.
포화 부하(7,500)에서는 줄이 있으니 라벨 0 이 줄 것이다."*

## 2. 측정 (2026-08-23 · 시드 9,900,202 비판정 · 탐색 0.5 · `slot_mode=HORIZON`)

| 부하 | 평균 턴타임 | `TIME ∧ BUY` 라벨0 | `SPACE ∧ BUY` 라벨0 |
|---|---|---|---|
| 3,500 | 31.7분 | 52.0% (13/25) | **0.0%** (0/7) |
| **7,500** | **102.2분** | **71.4%** (5/7) | **66.7%** (2/3) |

**가설이 틀렸다.** 포화에서 라벨 0 이 줄기는커녕 늘었고, 무엇보다 **건드리지도 않은
대조군(공간 축)까지 0% → 66.7% 로 무너졌다.**

## 3. ★진짜 원인 — 창이 턴타임보다 짧다

문제는 이연이 아니었다. **반사실 창(H=1시간)이 트럭의 체류시간보다 짧으면 어떤
재배치도 창 안에서 안 보인다.**

창 안에서 못 나간 트럭의 비용은 `T − A` 다(미완료 검열). `A`(게이트인)는 재배치로
**안 바뀐다** — 어느 블록으로 보내든, 언제로 미루든 게이트 진입 시각은 그대로다.
그래서 **창 안 비용이 두 세계에서 정확히 같고**, 효과는 전부 창 밖에 남는다.

```
완료:   [A ...대기·작업... O]  →  비용 O−A   ← 재배치가 바꾼다 (라벨 생김)
미완료: [A ...아직 안 나감  ]T →  비용 T−A   ← A 는 안 바뀐다 (라벨 0)
```

### 뒷받침 — 1시간을 넘는 트럭의 비율

| 부하 | 평균 턴타임 | **1시간 초과 비율** |
|---|---|---|
| 3,500 | 31.7분 | **7.7%** |
| 5,000 | 48.6분 | **18.8%** |
| 7,500 | 95.8분 | **33.1%** |

이건 하루 전체 기준이다. **창 안 기준은 훨씬 나쁘다** — 창 [t, t+H] 안에 게이트인한
트럭이 창 끝까지 나가려면 `턴타임 ≤ t+H−A` 여야 하는데, A 가 창 안에 고루 퍼지므로
평균적으로 **H 의 절반** 안에 끝나야 한다. 7,500 은 평균이 95.8분이라 **H=60분의
절반(30분) 안에 끝나는 트럭이 거의 없다.**

## 4. 그래서 무엇이 참인가

| 질문 | 답 |
|---|---|
| [[YR-216]] 의 이연 칸 정합이 옳았나 | **옳다.** 3,500 에서 92.9% → 52.0% 는 실재하는 개선이다 |
| 남은 52% 가 이연 고유의 문제인가 | **아니다.** 같은 무대에서 공간 축은 0.0% 였다 — 이연만의 문제는 아니다 |
| 그럼 남은 52% 는 무엇인가 | 창 안에서 못 나간 트럭 몫 + 진짜로 효과가 없던 이연이 섞여 있다. **분리 못 했다** |
| 7,500 에서 학습이 되나 | **지금 설정으로는 안 된다.** 라벨의 3분의 2가 0 이다 |

## 5. ⚠️ 사용자 결정이 필요하다 — `H` 는 내가 못 바꾼다

`H = 1시간`은 **사용자 결정(2026-08-20)**이고 사전등록 동결 대상이라 임의로 못 바꾼다.
그런데 부하 7,500 은 **세 판정 부하 중 하나**이고(사용자 결정: "3500 5000 7500 다
해서 통과해야해"), 거기서 라벨이 안 만들어진다. 선택지를 그대로 올린다.

| 안 | 내용 | 대가 |
|---|---|---|
| **A. H 를 부하에 맞춰 키운다** | 3,500→1h · 5,000→1.5h · 7,500→**3h** | 연산량 7,500 에서 ×4.5. 세계 1개 ≈ 4.8초 → 20초대. **부하별로 라벨 눈금이 달라져** 부하 간 비교가 어려워진다 |
| **B. H 를 일괄 3시간** | 전 부하 동일 | 눈금 통일 ✅ · 연산량 ×4.5 (회차당 14시간 → 63시간) — **사실상 불가** |
| **C. 창 안 완료분만 라벨로** | 미완료 트럭을 라벨에서 제외 | 연산량 그대로 ✅ · 7,500 에서 **표본이 3분의 1로** 줄고, 오래 걸린 트럭이 체계적으로 빠져 **편향**이 생긴다 |
| **D. 7,500 을 학습 부하에서 뺀다** | 학습은 3,500·5,000 · **판정만 7,500 포함** | 연산량 그대로 ✅ · 학습이 못 본 부하에서 판정하는 셈 — **일반화 주장**이 되지만 약해진다 |

**권장 없음** — 넷 다 연구 주장의 성격을 바꾸므로 사용자가 정할 문제다.
다만 **D 가 현행 계약과 가장 덜 부딪힌다**(H 동결 유지 · 연산량 유지 · 판정 부하 3종 유지).

## 6. ⚠️ 표본 한계 — 이 결론의 신뢰도

7,500 표본이 **`TIME∧BUY` 7건 · `SPACE∧BUY` 3건**뿐이다(43분 소요). 비율의 정밀도는
낮다. **그러나 방향은 메커니즘으로 뒷받침된다** — 미완료 트럭의 창 안 비용이
`T−A` 로 재배치와 무관하다는 것은 계산상 자명하고, 1시간 초과 비율 7.7→18.8→33.1%
가 그 규모를 준다.

**결정 전에 확증이 필요하면**: 부하 5,000·7,500 에서 `SPACE∧BUY` 표본 ≥60건.
비용은 7,500 기준 라벨 60건 ≈ **6시간**이다.
