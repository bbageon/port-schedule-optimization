# YR-217 · 이연 라벨 0 이 남는 이유 — 결함인가, 참말인가

> Epic RL · 우선순위 🔴 · 상태 **backlog** (등록 2026-08-23)
> 선행 [[YR-216]] ✅ (여기서 발견) · 관련 [[YR-210]]

## 1. 무엇을 가리나 — 한 줄

[[YR-216]] 이 이연 라벨 0 을 92.9% → 52.0% 로 줄였다. **남은 52% 가 측정 결함인지,
"그 이연이 실제로 무의미했다" 는 참말인지** 가른다.

## 2. 왜 애매한가

이연은 **방문 전체를 통째로 뒤로 민다.** 그 시각에 줄이 없으면 게이트인도 게이트
아웃도 같이 밀려 **턴타임(O−A)이 그대로**다 → Φ 차이가 정확히 0.

```
줄 없음:   [A ...작업... O]  →  30분 뒤   [A' ...작업... O']    O−A = O'−A'  (차 0)
줄 있음:   [A ..대기..작업.. O] → 30분 뒤 [A' .작업. O']        O−A > O'−A'  (차 발생)
```

측정한 부하 3,500 은 **한산하다** — 평균 턴타임 31.7분, 1시간 초과 7.3%. 줄이
거의 없으니 라벨 0 이 참말일 수 있다.

## 3. 가르는 방법

**포화 부하에서 같은 측정을 반복한다.** 7,500 은 평균 턴타임 **95.8분** · 초과
비율이 훨씬 높아 줄이 실재한다 — 거기서는 이연이 실제 효과를 내야 한다.

| 부하 | 평균 턴타임 | 기대 |
|---|---|---|
| 3,500 | 31.7분 | 라벨 0 많음 (참말일 수 있음) |
| 5,000 | 48.6분 | 중간 |
| **7,500** | **95.8분** | **라벨 0 이 크게 줄어야 한다** |

## 4. 판정 기준

- **줄면 참말**: 7,500 의 `TIME ∧ BUY` 라벨 0 비율이 3,500 대비 유의하게 낮다
  → 남은 0 은 결함이 아니라 "그 상황에서 이연이 무의미했다" 는 정보다. 종료.
- **안 줄면 결함**: 포화인데도 50% 안팎이면 창이 여전히 짧거나 Φ 가 이연 효과를
  못 잡는 것이다 → `H` 재검토(안 B/C)를 **사용자 확인 후** 올린다.

**표본**: `TIME ∧ BUY` 축별 **≥ 60건**([[YR-216]] 은 25~28건이라 정밀도가 낮았다).
비판정 대역 시드. 탐색 0.5(좌표 기반이라 분기 안정).

## 5. ⚠️ 비용

7,500 은 하루 에피소드가 340초, 반사실 재생도 3,500 보다 비싸다. 라벨 60건 ×
3세계면 **1시간 이상**을 잡아야 한다. 먼저 라벨 20건으로 소요를 재고 늘린다.

## 6. 곁가지 — [[YR-210]] 과 겹치는 부분

*"부하가 오르면 재배치의 가치가 어떻게 변하나"* 는 [[YR-210]] 의 질문이기도 하다.
여기서는 **정책 성능이 아니라 라벨의 유효성**만 본다 — 판정 대역을 쓰지 않는다.
