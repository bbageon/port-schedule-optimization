# YR-286 — §5.2 "블록만 재배치하면 비용이 오른다" 는 대역 특정 주장이다

**상태**: backlog
**Epic**: Paper

## 무엇이 문제인가

제출본 §5.2 는 이렇게 말한다 — *블록만 재배치하는 팔은 가장 수요가 높은 날 오히려
비용을 올린다*. 근거는 진단 대역(시드 9,900,950) 값 **−0.131 bn** 하나다.

혼잡 민감도 실험을 돌려 보니 **부호가 뒤집힌다**.

| 환경 | 블록만 재배치의 효과 |
|---|---|
| env-quiet (한산) | **+0.226 bn** (비용이 내려간다) |
| 판정 대역 | **+0.394 bn** (내려간다) |
| 진단 대역 | **−0.131 bn** (올라간다 — 원고가 쓴 값) |

즉 원고의 문장은 *한 대역에서만 성립하는 관찰*을 일반 성질처럼 적은 것이다.
같은 이유로 초록의 **91.3%**(도착시각 조정이 감소분에서 차지하는 비율)도
{66.5%, 91.3%, 53.8%} 중 **가장 높은 값**이다.

## 무엇을 해야 하나

1. §5.2 에서 *"raises cost at the highest demand"* 문장을 **제거**하거나, 대역을
   명시한 문장으로 바꾼다.
2. env-mixed·env-heavy 실행이 끝나면 **수요 구성 민감도** 소절을 추가한다.
3. 판정 대역으로 옮긴다면 **그림의 두 선과 본문 수치를 같은 commit 에서** 바꾼다
   (따로 바꾸면 [[YR-282]] 가 잡은 종류의 그림↔본문 불일치가 생긴다).
4. 바꾼 뒤 `scripts/v3/verify_submission.py` 재실행 — 41건 대조가 새 값으로 통과해야 한다.

## 왜 지금 안 했나

사용자에게 제거를 제안했고 결정을 기다리는 중이다. env-mixed·env-heavy 가 아직
실행 중이라, 지금 지우기만 하면 대체할 근거 없이 서술이 비게 된다.
