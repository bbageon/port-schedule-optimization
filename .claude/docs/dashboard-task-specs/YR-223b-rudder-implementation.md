# YR-223b · RUDDER 구현과 사전등록

## 1. 구현 (2026-08-24) — `src/yard_rl/rudder/`

### ★v3 를 복제하지 않는다 (사용자 지시 "새 코드로" 에 대한 해석)

| | 왜 |
|---|---|
| v3 가 v1·v2 를 복제한 이유 | **비교 대상**이라 빌려 쓰면 비교가 오염된다 |
| rudder 가 v3 를 복제 **안 하는** 이유 | **측정 대상**이라 복제하면 사본을 재게 된다 — v3 가 바뀌어도 옛 v3 를 계속 재는 셈이라 **측정이 틀린다** |

**꾸러미는 전부 새 코드**(v3 에 한 줄도 안 더했다). v3 는 **읽기 전용 재료**로 쓴다.
계약은 시험이 지킨다 — `tests/rudder/test_no_v3_mutation.py`(정적·실행중·전역상태),
`test_runner_identity.py`(v3 `run_episode` 와 Φ·거래·결정 일치).

| | |
|---|---|

### ★비용 재측정 — 등록 시 견적이 틀렸다

등록 시 *"궤적 200개 ≈ 11분"* 이라고 적었는데 **하루 굴리는 비용을 빼먹었다.**

| 실측 (2026-08-24) | |
|---|---|
| 하루 1회 | **169초** — 순차 (review epoch 1,441회 × 21블록) |
| 창 짝 1개 (H=3시간) | 약 54초 |
| 날 16 × 창 13 = **208 궤적** | 작업자당 871초 · **8코어면 약 29분** |

11분이 아니라 **약 30분**이다. 그래도 싸다.
