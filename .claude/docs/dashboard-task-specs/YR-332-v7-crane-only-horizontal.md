## 확정한 결정 (2026-11-04)

1. **배치는 수평형이다.** 현 엔진의 HJNC 기반 21블록·크레인 42기를 유지한다.
   DGT 는 수직형(육측·해측 완전 분리)이므로 배치는 가져오지 않는다.
   사용자 지시 "수평터미널을 기준으로 개발" 과 "DGT 표본에 맞춘다" 를 이렇게 맞췄다.
2. **DGT 표본에서는 트럭 시간 정보만 가져온다** — 배치와 무관한 운송사 쪽 행동이라는 가정.
   `docs/data-handover/2026-08-19-DGT-1차표본-대조.md` 기준:
   - 반입 리드타임 중앙 0.95시간, 반출 중앙 2.45시간에 긴 꼬리(p75 91시간). **둘을 따로 뽑는다.**
   - 14%는 통지보다 먼저 도착한다. 수명주기 불변식(통지 ≤ 게이트 진입)을 지키기 위해
     이런 트럭은 **통지 시각 = 도착 시각**, 즉 사전 정보 없이 나타나는 트럭으로 모델링한다.
   - ⚠️ 표본은 **100건·1시간**(통지 있는 71건)뿐이다. 분포 모양을 빌리는 것이지
     DGT 실측 재현을 주장하지 않는다.
3. **결정 주체는 크레인뿐이다.** 판매·구매 재배정을 끄고 트럭은 원래 블록·시각으로 온다.
4. **학습은 v4 반사실 교사다.** 이 프로젝트에서 학습이 된다는 걸 보인 유일한 방법이다
   ([[YR-308]] 고정 평가일 짝비교). v5 PPO 는 학습할수록 무작위보다 나빠졌다.
5. **비용은 원화, 본선 단가 35.88원.** 교사 눈금(10,000원)이 원화로 보정돼 있어 연속성을 지킨다.
6. **행동은 실작업·파내기·쉬기 + 교착 탈출 빈 이동.** 미리 자리 잡는 빈 이동은 뺀다
   ([[YR-148]] 채택 결정). 쉬기는 할 일이 없을 때의 안전판이라 못 뺀다.
7. **성과지표는 턴타임(게이트 아웃 − 게이트 인).** 재배정이 없어 공정하다.
   확인용으로 최초 예약~출차 시간도 함께 기록한다 — 규칙과 학습의 차이가 같아야 정상이다.

## 정책이 보는 정보

실현된 미래는 보지 않는다. 통지된 예정·현재 상태·지도 거리·이력만 본다.

- 트럭: 사전 반출입정보의 예약 시각과 제공 도착 예정(통지된 경우만), 블록에서 기다린 시간.
- 본선: 계획 작업 시작·완료 예정·출항 예정(ETW·ETC·ETD). 입항·접안 예정(ETA·ETB)은 없다([[YR-322]]).
- 크레인: 후보 작업의 예상 소요시간(지도·적재 위치로 계산), 빈 주행 거리, 필요한 재취급 수.
