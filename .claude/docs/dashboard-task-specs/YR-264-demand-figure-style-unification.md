- **Epic**: Paper / **Priority**: 🟠 / **등록·완료일**: 2026-08-30

## 발단

사용자 지적: *"해당 이미지의 표를 다른 표와 같이 디자인을 일관성하게 하고 싶은데,
그리고 각 표의 가독성이 조금 안좋은거 같은데"* — 3장 수요 그림(`fig-demand`)만
흑백 해칭·안쪽 범례로 그려져 결과 그림 셋([[YR-259]]·[[YR-262]])과 문법이 달랐다.

## 편집 계약

- 그리는 **내용·수치는 바꾸지 않는다** — 인코딩(색·범례·이름·여백)만 손댄다.
- 수치는 계속 구현 상수에서 든다. 범례의 균등 기저 38%도 `DIURNAL_NIGHT_FRAC` 에서
  만들어 하드코딩을 없앤다.
- (a) 확률 단위를 **퍼센트 하나로** 통일한다 (앞판은 축 0.0~0.2 소수 + 막대 위 30%).
- (b) 균등 기저 아래를 `BAND` 로 옅게 채워 "하루 어느 시각에나 깔린 물량"이 보이게 한다.
- 캡션·본문 문장은 건드리지 않는다. 다른 세션이 만지는 5장 결과 파일도 건드리지 않는다.
