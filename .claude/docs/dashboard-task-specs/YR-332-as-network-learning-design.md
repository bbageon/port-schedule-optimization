# YR-332-as — 신경망 표현과 학습 알고리즘을 분리한 설계 검토

- **상태**: backlog. 2026-11-15 문헌·코드 검토 완료, 정책 교체·학습 미실행.
- 사용자 요청: MLP→GAT+기존 비교학습→GAT+PPO 제안의 타당성을 검토한다.
- 관련: ao(합성 날짜 다양성), 323-d(학습 표본·최적화 진단), 326(이전 버전 학습 구조 논의).

현재 구현은 10→64→64→1 후보별 공유망이며 가변 후보 전체를 묶어 평가한다.
최신 aq 실험은 두 반사실 실행의 정규화 비용 **차이**를 맞추는 회귀다. PPO·DQN 갱신이 아니다.
GAT의 연구 이유는 후보 수가 아니라 방문·선후관계·자원 경쟁 표현이다.
aq는 회차별 새 자료만 학습한다. 마지막 회차의 학습 쌍은 16/16/12개로, 이전 조건을 잊는지는 323-d에서 분리 진단한다.

## 설계와 실행 조건

1. 323-d에서 현재 자료 맞추기·학습량·새 상태 진단을 분리한다. 정보가 다른 비교를 망 효과라고 하지 않는다.
2. 같은 입력 정보와 같은 비교 정답으로 MLP와 관계 표현망을 비교한다. 관계 입력을 추가하면 그 축부터 분리한다.
3. PPO는 데이터 수집·실행 행동 확률·가치 추정·보상 귀속을 별도로 설계하고 작은 환경에서 검증한다.
   현재 점수→공동 배정기를 그대로 둔 채 후보별 softmax 확률을 실행 행동 확률로 쓰지 않는다.
4. 후보 전체 보존, 알려진 정보만 사용, 전체 결정 지연을 확인한다. 복잡한 Transformer·다중 에이전트는 자동 후속 아님.

새 망 채택·PPO 전환은 이번 검토의 완료 조건이 아니다. 현재 입력 보정과 동시에 하지 않는다.
실행 시 연구 게이트와 구체적 비교 명세를 먼저 고정한다.
