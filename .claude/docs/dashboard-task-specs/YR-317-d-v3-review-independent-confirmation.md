# YR-317-d — 독립 반복과 구성요소 확증

- **상태**: backlog
- 분류: 잠금평가. 선행: 관련 신뢰성·현실성·성능 게이트 통과 후 착수 허가.
- 성능이 미확정이면 게이트 절차에 따라 사전 고정 표본의 성능 직접 보정으로 먼저 등록한다.
- 무엇: 전체·시간만·공간만·거절 제거·규칙 수락·학습 전·동정보 규칙의 비용을 같은 월끼리 비교한다.
- 왜: 공간 추가 1.28%포인트, 수락망 차이와 학습 기여가 독립 실행에서 남는지 아직 모른다.
- [실험 설계 §4·5](../strategy-history/2026-09-14-v3-review-experiment-protocol.md).
- 고정 모형 20개월 또는 학습 5시드×평가 10개월은 예산용 제안이다. 진단 분산·최소 개선량으로 최종 표본을 동결한다.
- 월 단위 비용 차이·신뢰구간과 시드별 결과를 보고한다. 학습×평가 50칸을 독립 표본으로 세지 않는다.
- 같은 가중치의 행동 제한과 그 제한으로 별도 학습한 최적화 비교를 구별한다.
- 혼잡 빈도·연속성·비용·운영기간을 한 축씩 검증하고 평가창 밖으로 미룬 비용도 추적한다.
- 여러 우위 주장은 주비교·다중비교 규칙을 고정한다. 결과를 보고 시드를 추가하지 않는다.
- 완료 기준: 실패 포함 원자료, 운영 가드, 독립 반복 구간 추정, 구성요소별 지지/미확정/반대 판정.
- 결과가 약하면 주장을 축소한다. 전체 구조의 우위를 입증하기 위해 결과를 선별하지 않는다.
