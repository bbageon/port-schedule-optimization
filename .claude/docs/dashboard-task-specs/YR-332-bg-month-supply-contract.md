## 무엇과 왜

월말 재고가 모두 양수여도 중간 계획에서5블록·14블록일의 공급 부족이 남았다(최대209개).
또한 기존 검사는 실제 생성 초기재고 대신 블록마다648개로 계산해 혼잡 가능성도 낮게 표시했다.
월말 총량을 맞추는 것만으로는 각 오더가 필요한 시점에 화물이 있는지 보장하지 못한다.

## 범위와 완료 기준

1. 기존 시드9,400,777을 고정하고 실제 초기 컨테이너 목록으로 재고 검사를 시작한다.
2. bf의14개 부족 구간을 개별 화물 공급·작업 공개 시각·본선 날짜 경계와 연결한다.
   계획 날짜 수지 부족과 실행에서 허용한 대기·이월을 구분해 무엇이 잘못된 입력인지 먼저 정의한다.
3. 그 계약에 맞춰 월말 검사에 빠진 중간 공급·공간 조건을 검증한다. 잘못된 입력을 조용히 통과시키지 않는다.
4. 생성 보정이 필요하면 물량·작업 종류를 보존하는 가능한 구성과 실패 조건을 먼저 명세화하고 한 축씩 비교한다.
   오더 삭제·반출입 유형 전환·무제한 용량 증설·결과를 본 시드 교체로 해결하지 않는다.
5. 원래50% 재고 유지·90% 혼잡 기준의 목적과 근거를 확인하고 실제 물리·정보 검증과 분리한다.
   단순 임계 완화 금지. 기존 실패는 보존하고 전후 입력·오더·본선·시각 변화 범위를 보고한다.
6. 같은 원인에 대한 작고 명확한 반례, 고정 월 입력, 기존 정상 입력의 회귀와 독립 수지 검산을 수행한다.

정책·보상·학습은 범위 밖이다. 월/배열 정보 연결ai·배열 궤적ah·운반 실측i/f/ap를 대신하지 않는다.
