# YR-179 — 규칙 기반 판매 기준선: 학습이 기여한 몫을 분리한다

- **Epic**: Baseline / **Priority**: 🔴 / **등록일**: 2026-08-17 / **상태**: in-progress
- **3대 게이트 보정 대상**: `performance`
- **1줄**: "학습한 판매 정책이 −3.5%" 는 **학습 없이 규칙으로 팔면 얼마인지**를
  모르는 채로 나온 숫자다.

## 발견 (2026-08-17)

`sell_gain.py:85` 에 **규칙 기반 판매 정책**이 이미 있다.

```python
class UnifiedNetGain:
    """SellPolicy 구현 — 두 축 모두 순이득 > 0 인 후보 중 최대 1건을 고른다."""
```

순이득이 양수인 후보를 고르는 탐욕 규칙이고, 문턱(`gain_margin`)도 상수 튜닝이
아니라 `κ_T` 1σ 에서 유도돼 있다. **그런데 어떤 실험도 이것을 import 하지 않는다**
(`grep -rl UnifiedNetGain src/yard_rl/experiments/` → 0건).

즉 지금까지의 모든 판매 성적은 **학습 정책 대 안 팔기**만 비교했고,
**학습 정책 대 규칙 판매**는 한 번도 재지 않았다.

## 왜 이것이 판정을 가르나

현재 주장의 구조는 이렇다.

> 채택 크레인 정책 위에 **학습한 판매 층**을 얹으면 −3.5% (대당 1.4분).

여기서 "학습한" 이 기여한 몫은 분리되지 않았다. 가능한 세 결과:

| 규칙 판매 결과 | 학습의 기여 | 함의 |
|---|---|---|
| 규칙도 −3.5% 근처 | **없음** | 기여는 판매 **메커니즘**이지 RL 이 아니다 — 연구 주장을 메커니즘 쪽으로 다시 써야 한다 |
| 규칙이 −1% 수준 | 있음 (−2.5%p) | RL 기여를 정량으로 말할 수 있다 — **현재 주장이 성립** |
| 규칙이 손해 | 큼 | "규칙으로는 오히려 손해인 판을 학습이 이득으로 돌렸다" — 가장 강한 주장 |

**세 번째가 실제로 가능성이 있다.** 학습 전 정책(P0)이 +507.4 로 크게 손해였고,
축 분리 진단상 시간 판매는 1건당 +14.28분 손해다. 순이득 계산식이 시간 축을
과대평가하면 규칙 판매도 같은 함정에 빠진다 — 그렇다면 "학습이 손해 축을
스스로 줄였다"(시간 판매 −59%)가 곧 기여의 정체다.

어느 쪽이든 **이 한 판을 돌리기 전에는 RL 의 기여를 말할 수 없다.**

## 실행

- 무대·집행설정·평가일을 **YR-171-C 와 완전히 동일**하게: `ADOPTED_C0_GUARD`,
  `day_plan_public=True`, 평가일 9200000~9205000, 같은 날 짝지어, 결정론 실행.
- 팔 추가: `greedy` = `UnifiedNetGain`(기본 `gain_margin`, 고정 +15분 시간 축 —
  학습 팔 `fixed15` 와 **행동 공간을 맞춘다**).
- 기준선 `K` 는 기존 결과 재사용.
- 판정 축은 기존과 동일(Φ, 같은 날 짝지어, 날 단위 통계).

**학습이 없으므로 시드가 없다** — 결정론 규칙이라 6일 6건이면 끝난다.
YR-171-C 평가 실측(42 실행 33분) 기준 **10분 이내**.

## 사전 동결 (결과 보고 바꾸지 않는다)

- 문턱 `gain_margin` 은 코드 기본값(`κ_T` 1σ 유도)을 쓰고 **조정하지 않는다**.
  규칙을 약하게 만들어 학습을 이기게 하는 것은 기준선 조작이다.
- 규칙이 학습을 이기면 그대로 박제한다. 그 경우 후속은 "왜 학습이 규칙보다
  못한가"이지 규칙을 깎는 것이 아니다.
- 48칸 규칙 판매(`slots48` 대응)는 **이번 범위 밖**이다 — 견적 기준이 YR-177 에서
  정해진 뒤에 별도 축으로 붙인다.
