# YR-332-ai — 실측 예약·정밀 접수의 월/배열 경로 연결

- **상태**: backlog
- 선행: 연구 게이트 재판정과 현재 하루 정보 계약 검증.
- 목적: 하루 실험에서 명시적으로 전달한 정보 보정 파일을 다른 실행 경로에서도 같은 뜻으로 사용한다.

## 현재 범위와 필요한 이유

f/ag는 실측 예약 오차·접수 리드를 CPU 하루 학습·평가에 명시적으로 전달한다.
새 CPU 하루/월 입력의 정확한 접수 사건은 연결했지만 월 실행에 실측 분포를 자동 적용한 것은 아니다.
배열 경로는 기존의 분 단위 접수·예약=도착 가정을 요구하므로 새 계약을 조용히 근사하지 않고 거절한다.
월/배열 실행을 새 연구 근거로 사용하기 전에 이 의미 차이를 해소해야 한다.

## 범위

1. 월 입력의 예약/통지 분포 전달과 원본 파일의 보정 메타데이터 보존.
2. 다음 날 예약의 전날 통지, 전체 관측 시작 전 통지, 일 경계에서 중복·누락 없는 가시성 검사.
3. 배열 경로의 예약·실현 도착 분리 및 정확한 접수 사건 지원.
4. 같은 입력의 공개 시각·작업 목록·사건·비용을 CPU 하루 경로와 대조한다.

정책 정보·학습 손실·운반 용량을 함께 변경하지 않는다.
기존 배열 월 궤적 불일치 ah는 별도 결함이며 이 row의 정보 계약 대조로 통과를 대신하지 않는다.
이번 등록은 구현·성능 개선 또는 월 실행 검증 완료를 뜻하지 않는다.
