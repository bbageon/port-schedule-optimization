# YR-332-i — 양하 운반 용량·시간·본선 마감 보정

- **상태**: in-progress
- 상위: [[YR-332]]. 파생: [[YR-332-h]], 2026-11-05.
- **3대 게이트 보정 대상**: `scenario_validity` — 정책·보상을 바꾸지 않는 운반 시간·인계·마감 환경 보정.

## 무엇과 왜

실행 프로파일의 운반차 3대·왕복 환산 470초와 문서의 가정을 대조하고,
차량이 야드에서 풀려나는 시점과 본선의 달성 가능한 마감을 맞춘다.
양하 연결은 복구했지만 이 값이 틀리면 정책이 비현실적인 병목에 맞춰 학습한다.

## 범위와 완료 기준

1. 실제 사용되는 차량 대수·주행시간·인계시간의 출처와 단위, 적용 블록을 확정한다.
2. 문헌·실자료의 관측 범위와 현재 집계 모형의 범위를 대조한다. 없는 근거는 미확정으로 남긴다.
3. 상자 인수와 야드 최종 적재, 차량 귀환을 구분할 필요를 검토하고 한 축씩 보정한다.
4. 달성 가능한 본선 마감 계산이 새 병목과 일치하는지 검사한다.
5. 복수 선박의 공유 용량·장부 보존·결정론 재현과 현실성 게이트를 재검사한다.

현재 3대를 최적 대수라고 주장하거나, 학습 성능에 맞춰 용량을 선택하지 않는다.
필요 자료가 없으면 외부타당성 미확정 판정과 누락 자료를 남긴다.

## 비교 기준 감사(t)에서 추가 확인 — 2026-11-07

[[YR-332-t]]의 69회 재실행에서 안벽 크레인이 기다린 시간 비율(접안~24시)을 스트림별로 쟀다.
적하는 최소 29.5%·중앙 72.6%, 양하는 최소 40.6%·중앙 73.1%였다. 설계상 바닥은 적하 16.4%
(운반 3대·왕복 470초, 문서화된 보정 목표)이고, 양하는 인계 상한 3박스 때문에 코드 산술로 약 26~31%다.
한가한 날(3,500건)에는 이 본선 유휴가 공식 비용의 약 44%다. 따라서 운반 대수·시간·인계 상한의
현실성은 본선 비용 수준 자체를 좌우한다. 붐비는 날에는 필수 작업 규칙(24분 이상 대기 트럭 우선)도
함께 작용하므로, 원인 분리는 이 row에서 한 축씩 수행한다.
[감사 보고서 §3](../../../outputs/reports/yr332_comparison_audit/README.md).

[출처 검토](../../../docs/research/v7-discharge/transport-calibration-review.md).
실제 투입 대수·편도/귀환 시간·인계 조건은 아직 자료가 없어 비동기로 파일 경로를 요청했다.

자료 없이 확인할 수 있는 현재 시간 계약을 먼저 재현한다. 기존 단일 블록 시험 무대에
H-21의 3대·470초와 안벽 간격 3600/27.5초를 넣고, 1·2·3박스 및 1/2척×8박스,
야드 정지 0/1,200초를 검사한다(7조건+1반복). 입력 시드는 기존 결정론 시험값 0이다.
이는 시간 관계 진단이며 해당 조건이 실제 터미널을 대표하거나 최적 대수임을 주장하지 않는다.
정책·보상·운영 기본 설정은 고정하고, 도착·자원 해제·완료·하한 계산의 원자료를 남긴다.
현실성 전체 판정은 실제 관측 근거를 확보하기 전까지 미확정이다.
