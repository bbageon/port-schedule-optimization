# YR-332-i — 양하 운반 용량·시간·본선 마감 보정

- **상태**: backlog
- 상위: [[YR-332]]. 파생: [[YR-332-h]], 2026-11-05.
- 미통과 축: 현실성(scenario_validity). 정책·보상을 바꾸지 않는 환경 보정.

## 무엇과 왜

실행 프로파일의 운반차 3대·왕복 환산 470초와 문서의 가정을 대조하고,
차량이 야드에서 풀려나는 시점과 본선의 달성 가능한 마감을 맞춘다.
양하 연결은 복구했지만 이 값이 틀리면 정책이 비현실적인 병목에 맞춰 학습한다.

## 범위와 완료 기준

1. 실제 사용되는 차량 대수·주행시간·인계시간의 출처와 단위, 적용 블록을 확정한다.
2. 문헌·실자료의 관측 범위와 현재 집계 모형의 범위를 대조한다. 없는 근거는 미확정으로 남긴다.
3. 상자 인수와 야드 최종 적재, 차량 귀환을 구분할 필요를 검토하고 한 축씩 보정한다.
4. 달성 가능한 본선 마감 계산이 새 병목과 일치하는지 검사한다.
5. 복수 선박의 공유 용량·장부 보존·결정론 재현과 현실성 게이트를 재검사한다.

현재 3대를 최적 대수라고 주장하거나, 학습 성능에 맞춰 용량을 선택하지 않는다.
필요 자료가 없으면 외부타당성 미확정 판정과 누락 자료를 남긴다.
