## 범위와 근거

- [ReSched 논문](https://proceedings.iclr.cc/paper_files/paper/2026/file/467e109270678b3e2b3c2e7fa6b3d575-Paper-Conference.pdf), [공식 구현](https://github.com/XiangjieXiao/ReSched).
- 본편 학습은 REINFORCE, PPO는 부록·공식 코드다. 제조 makespan 최소화와 항만 비용 최소화는 다르다.
- 작업 간 self-attention, 작업–장비 edge 정보와 장비 self-loop를 쓰는 두 갈래 표현을 참고한다.
- 기존 10개 후보 정보·실행 가능성·필수/실작업 우선 등급·24시간 비용·26시간 배수를 유지한다.
- 후보 상한 없이 현재 블록의 실행 가능 후보를 평가한다. 미래 실현 도착·완료를 입력으로 쓰지 않는다.
- 작업 순서 RoPE, 미도착 전체 공정, 블록 간 그래프는 이번 범위 밖이다. 논문 전체 재현으로 부르지 않는다.

## 사용자 요청과 게이트

- 앞 작업 성능 FAIL·현실성 FAIL은 유지한다. 운반·대기열 실측 근거(i/f)가 없다.
- 이번 명시적 적용 요청에 따른 진단이며 기본 정책 채택·실항만 개선·독립 확증을 주장하지 않는다.
- 착수 검사 결과를 그대로 보존한다. 자동 승인 거절을 PASS로 바꾸지 않는다.
- 착수 검사: 현실성부터 해결해야 한다는 사유로 allowed=false. 이번 사용자 명시적 적용 요청의 진단 범위만 실행한다.
- 기존 as의 자동 PPO 확장 금지는 이번 명시적 요청과 구분한다.

## 비교와 검증

1. 기존 안전 검사로 조건부 실행 가능 집합을 만든 뒤 그 안에서 직접 행동을 표본한다.
   공동 배정의 순차 구성 전체를 행동으로 정의하고 실제 선택과 같은 확률을 PPO에 전달한다.
2. 같은 정보·행동·보상·예산의 MLP+PPO와 작은 두 갈래 Transformer+PPO를 비교한다.
   저장된 누적자료200회 학습 모델·SF_SPT·FIFO·LWKR도 같은 새 평가 입력으로 비교한다.
3. 학습은 현재 정책으로 새 궤적을 모은다. 두 세계 미래비교 정답을 사용하지 않는다.
   기본60초 격자와 추가 접수 시각 중 직전 동기화 누적 비용을 뺀24시간 Monte Carlo 반환을 사용한다.
   감가율1, 미래 예측 부트스트랩 없음. 미래 비용 누적량을 예측하는 critic을 함께 학습한다.
4. 반환 눈금은 기존 학습용 입력의 SF_SPT 비용 중앙값으로 사전 고정한다. 평가 결과로 맞추지 않는다.
5. 작은 비측정 smoke 뒤 계산 예산·시드·입력·최종 체크포인트 사용을 campaign에 고정하고 본실행한다.
6. 오더 장부에서 반입·반출·양하·적하·미완료를 재계산하고 같은 실행을 반복한다.
   고정 입력의 작업 순서 그림과 실제 결정 지연도 보고한다.
