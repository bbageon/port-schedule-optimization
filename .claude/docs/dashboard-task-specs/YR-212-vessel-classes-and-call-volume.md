## 1. 무엇이 문제였나

정의는 [[YR-214]] 때 만들어 뒀는데 **무대가 안 쓰고 있었다.** 실측으로 확인:

| | v3 설계 | 무대가 실제로 만들던 것 |
|---|---|---|
| 선급 | 소 50k / 중 100k / 대 150k GT | **구분 없음 — 전부 동등** |
| 기항 물량 | 450~4,200 moves | **전부 정확히 120** (최대 26배 차이) |

| STS 스트림 | 2 / 4 / 6 | **척당 1** (30스트림) |

120 moves 라 **전부 소형선으로 판정**되고 있었다.

### ★스트림 유휴를 그대로 더하면 안 된다

대형선은 STS 6대라 스트림이 여섯이다. 각 스트림이 1시간씩 막히면 합은 6시간이지만
**배가 6시간 논 게 아니다** — 처리 능력을 6 스트림·시간 잃은 것이고 그만큼 접안이
길어진다. 선박 비용이 **배 1척·1시간** 단위(2.99원/GT·시간)라 나눠서 환산해야 맞는다.

## 3. ⚠️ 정상상태로 뽑아봤다가 되돌렸다 (기록)

접안이 20~47시간이라 *"어제 온 배가 오늘도 붙어 있다"* 를 반영하면 물리적으로는
더 맞는다. 실제로 그렇게 뽑아보니 **창에 걸치는 배 6~7척 · 스트림 20개 · 대형선이
80% 의 날에 보였다.** 설계 정본(02b §3: 스트림 8 또는 14 · 대형 30%)과 어긋나
**문서를 따랐다.** 설계가 정한 것은 *"그날 처리하는 물량"* 이지 입항률이 아니다.

## 5. ★Φ 항4 결정 — 구조적 유휴는 안 넣는다

Port Time 에는 정박 대기·조선·접이안·검역이 들어 있어 작업 시간보다 6.9~21시간 길다.
**그 차이(구조적 유휴)는 Φ 에 안 넣는다** — 정책이 못 바꾸는 상수라 개선 비율만
희석되고, 반사실 차이에서는 어차피 상쇄되어 **학습에는 영향이 없다.**
`c_vessel_structural` 진단 열로 따로 낸다: 하루 **5.1M원** · 대형 오는 날 **9.9M원**.

02b §2 의 *"나머지 유휴"* 문구와 다르므로 **문서에 인용으로 명시**했다.
