# YR-332-m — 기본 하루 환경의 투입 누락·작업 잔여 원인 대조

- **상태**: done
- 상위: [[YR-332]], 파생: [[YR-332-l]], 2026-11-05.
- 환경·장부 진단 한 축. 정책·보상이나 임의 재배정으로 누락을 숨기지 않는다.

## 무엇과 왜

기본 하루 속도 비교의 첫 입력(시드 9,913,320, 트럭 3,500건)에서 3,299건만 투입됐다.
본선 미완료도 남았고 두 계산 방식의 결과는 같았다. 속도 최적화가 만든 차이는 아니지만,
명목 오더 수와 실제 처리 부하를 구분해야 기본 환경의 성능을 해석할 수 있다.

## 완료 기준

1. 기존 안내자의 `skips` 원자료를 수집해 창 끝 제외·용량·대상 컨테이너 등 사유를 구분한다.
2. 예약/통지·게이트·블록·작업 완료 기록과 대조해 입력 수 = 투입 수 + 사유별 누락 수를 맞춘다.
3. 의도된 부하 초과와 입력/물리 설정 오류를 구분한다. 고쳐야 할 항목만 별도 단일축으로 특정한다.
4. 미완료 트럭·양하·적하 작업을 각각 기록한다. 두 구현의 동등성을 전건 처리 성공으로 해석하지 않는다.
5. 같은 평가창·같은 오더·모델을 유지한다. 성적에 맞춰 물량/용량/마감을 조절하지 않는다.

## 고전 규칙 비교에서 추가 확인 — 2026-11-06

[[YR-332-v]]의 같은 15,000건 입력에서 도착순 14,439건, 최단 작업 14,406건,
최근접 14,284건, 최신 학습 정책 평균 14,426.67건이 투입됐다. 같은 입력과 같은 처리 집합을 구분한다.
`run_episode`는 엔진을 26시간까지 진행하지만 마지막 `bridge._sync`는 24시간으로 호출한다.

사용하지 않고, 엔진 최종 상태로 26시간 야드 작업 미완료를 따로 집계했다(71회 투입 수 보존 확인).
이 감사에서 24시간 출차·26시간 출차·26시간 야드 작업 완료를 구분하고, 누락 사유와 함께 대조한다.

## 비교 기준 감사(t)에서 넘어온 단서 — 2026-11-07

[[YR-332-t]] 코드 대조 중 확인한 투입 조건이다. 실행으로 원인을 판정하지는 않았다.
반입(GATE_IN) 트럭은 블록의 빈 칸이 여유 2칸 이하이면 투입되지 않는다
(`multiblock.py:admit_external_job`, `free_slots`). 빈 칸에서 아직 도착하지 않은 반입과
**양하 예정 작업**을 미리 뺀다. 초기 적재율 0.65면 블록당 빈 칸이 약 504칸이라, 양하 예정이
많은 블록은 시작부터 반입 투입이 막힐 수 있다. 크레인이 상자를 얼마나 빨리 치우느냐에 따라
빈 칸이 달라지므로 정책마다 투입 수가 달라질 수 있다는 가설이다. m에서 사유별 장부로 검증한다.
t는 투입·미투입 수를 비용 총점과 나란히만 정리했다(원인 복구는 m).

사용자는 t·m·w를 모두 진행하고 개별 보고하라고 지시했고 중단 후 재개를 요청했다.

## 결과 — 2026-11-08

42회 모두 기존 결과·후보·선택·사건·작업·장부 해시를 정확히 재현했다.
오더별 수지 확인 720,000건, 24시간 원장 보존, 26시간 별도 장부의 엔진 사건 일치,
같은 실행 반복의 전건 장부 일치를 확인했다. 실행 커밋은 `d69c160d`다.

최초 3,500건 입력의 201건 미투입은 모두 공간 예약 한도였다. 두 계산 방식이 같았고,
24시간의 미출차 21대는 26시간까지 모두 출차했다. 미투입 201건은 여전히 처리되지 않았다.
15,000건 입력에서 최신 학습 3모델은 평균 573.33건, 상한 제거 모델은 615.67건,
최단 작업 규칙은 594건을 접수하지 않았다. 실제 빈 칸은 있었고 양하 예정 예약분을
뺀 계산 때문에 막혔다. 해당 예약을 삭제해도 안전하다는 검증은 아니다.

안내자가 오더를 한 번만 검토하고 실패한 주문은 다시 시도하지 않는 경로를 확정했다.
따라서 명목 입력은 같아도 실제 투입 집합이 달라진다. 공통 투입 ID의 체류도 따로 계산했으나,
정책 실행 뒤 정해진 집합이므로 공정한 인과 효과로 부르지 않는다.
학습 3모델의 26시간 미출차 평균은 2,381.67대, 야드 작업 미완료는 2,351.33대다.
두 숫자의 차이는 작업을 마쳤지만 게이트로 이동 중인 트럭이다.
