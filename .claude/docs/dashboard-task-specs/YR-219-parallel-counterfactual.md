## 1. 물음 — "GPU 를 쓸 수 있어?"

**쓸 수 있지만 안 빨라진다.** 병목이 신경망이 아니라 시뮬레이터다.

| | 크기 | 성격 |
|---|---|---|
| `SellerNet` | **5,761** 파라미터 | GPU 로 보내는 전송 비용이 계산보다 크다 |
| `BuyerNet` | **5,505** 파라미터 | 〃 |
| 시뮬레이터 | 이산사건 · 순수 파이썬 | **GPU 로 못 옮긴다** |

환경: RTX 5090 · torch 2.13.0 **+cpu 빌드**(CUDA 없음) · CPU 24코어 · RAM 62GB.
CUDA 빌드를 깔 수는 있으나 이 작업에서는 효과가 없어 권하지 않는다.

## 2. ★진짜 지렛대 — 코어

반사실 세계들은 **완전히 독립**이다. 각자 스냅샷을 복제해 따로 굴리고 서로의
결과를 안 본다. 공유 상태가 없으니 프로세스로 쪼개도 결과가 안 바뀐다.

**탐색을 좌표 기반으로 바꿔둔 것이 여기서 값을 한다**([[YR-216]] 부수 산출) —
순차 난수였다면 프로세스로 나누는 순간 결과가 갈렸다.

## 3. 무엇이 안 나뉘나 (Amdahl)

에피소드 자체는 **순차**다 — 하루를 시간순으로 굴려야 하고 결정이 그 안에서 난다.

```
회차 = 에피소드(순차) + 반사실 세계들(병렬) + 학습(짧음)
```

### 실측 분해 (2026-08-23 · 부하 3,500 · 라벨 40건)

| | 값 |
|---|---|
| 에피소드 1회 | **149초** — 순차 (RL + 안 팔기 = 5.0분) |
| 반사실 세계 1개 | **27.1초** — 병렬 대상 (H=3시간이라 구 1시간보다 비싸다) |
| 세계 100개 | 45.1분 |
| **회차 총합 (1코어)** | **50.0분** |

| 코어 | 회차당 | 가속 |
|---|---|---|
| 8 | 10.6분 | 4.7배 |
| **16** | **7.8분** | **6.4배** |
| 20 | 7.2분 | 6.9배 |

**20 을 넘겨도 크게 안 빨라진다** — 순차 5분이 벽이다. 사용자 결정: **16 프로세스**
(나머지 코어를 다른 작업에 남긴다 · 20 대비 4% 느림).

## 4. 구현

`src/yard_rl/v3/stage/branchpool.py` — `BranchPool` · `BranchJob`

| | 내용 |
|---|---|
| 단위 | **결정 하나 = 세계 셋**을 한 작업으로 (스냅샷을 세 번 안 보낸다) |
| 시점 | 에피소드가 **도는 중에** 맡긴다 — 굴리기와 에피소드가 겹친다 |
| `ctx` | 망·레이아웃·공고기는 작업자마다 **한 번만**(initializer) |
| 메모리 | 진행 중 작업 수에 뚜껑(`max_inflight`) — 스냅샷이 무한정 안 쌓이게 |
| 스레드 | 작업자마다 `torch.set_num_threads(1)` — 16프로세스 × N스레드는 서로 방해만 |
| 순서 | 결과를 **(t, docKey) 순으로 정렬** — 작업자가 끝나는 순서는 매번 다르다 |
| `workers=1` | 같은 프로세스에서 순차로 — **순차 = 병렬 대조용으로 남겨 둔다** |

### ★계수기가 부모로 돌아와야 한다

작업자의 `rollout_calls` 는 그 프로세스 안에만 남는다. 판정 하드가드
(`rollout_calls_during_eval == 0`)는 **부모에서** 검사되므로, 되받아 더하지 않으면
*"다른 프로세스에서 굴렸다"* 는 이유로 **교사 누출을 통과시킨다.**
`add_rollout_calls(n)` 로 부모가 되받는다. 시험이 이걸 직접 검사한다.

## 5. 검증 — `tests/v3/test_branch_pool.py` (4건 통과)

| | 무엇 |
|---|---|
| 순차 = 병렬 | 라벨 값(Φ·좌표·행동)이 **전부 일치** |
| 계수기 복귀 | `rollout_calls` == 굴린 세계 수 (순차·병렬 동일) |
| 판정 경로 | 작업자 수와 무관하게 교사 호출 **0** (팔 2종) |

**결과가 안 바뀌므로 작업자 수는 사전등록 대상이 아니다** — 실행 자원 설정이다.
