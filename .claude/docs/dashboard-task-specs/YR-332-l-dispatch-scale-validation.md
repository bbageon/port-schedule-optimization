- **상태**: done
- 완료: 2026-11-05. 기본 환경 적용·9쌍 동등성/속도 비교와 관련 44검사 통과.
- 착수: 2026-11-05. 사용자 직접 요청: 기본 연구 환경에서 평가 속도 개선 적용·시험.
- 상위: [[YR-332]]. 파생: [[YR-332-j]], 2026-11-05.
- 기존 계산 최적화의 적용 범위 검증. 새 정책·보상 가설은 추가하지 않는다.

## 무엇과 왜

큰 적재 재고·다양한 작업·여러 크레인이 겹쳐 판단할 때의 시간과 메모리를 잰다.
착수 전 증거는 한 크레인의 많은 반입 후보와 두 크레인의 작은 67작업 환경이었다.
실제 운영 규모에서는 적재 상태 대조·재계산·근접 점수 재평가 비용이 달라질 수 있다.

## 완료 기준

1. 기본 야드 점유율·크레인 수·오더 수와 측정 범위를 사전에 고정한다.
   현장 허용 응답시간이 없으므로 상대 비교로 한정하고 절대 실시간 보증은 하지 않는다.
2. 기존 단일 경로와 최적화 경로의 후보·계획·선택·완료·비용을 같은 조건에서 대조한다.
3. 최초/반복 계산, 무효화율, 메모리, 느린 쪽 처리시간을 함께 기록한다.
4. 고정 모델 3개와 기존 동점 회귀 검사를 포함한다. 호환되는 v7 학습 체크포인트는 아직 없어
   학습 모델 일반성은 주장하지 않는다. 동일 세계의 동시 수정은 허용하지 않는다.
5. 실제 통신을 측정하지 않았다면 그 시간은 제외했다고 표시한다. 현장 적용 가능성과 구분한다.
