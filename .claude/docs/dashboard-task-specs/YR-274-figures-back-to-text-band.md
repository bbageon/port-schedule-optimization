# YR-274 — 그림을 본문과 같은 대역으로 되돌림 (자기모순 제거)

- **Epic**: Paper / **Priority**: 🔴 / **등록·완료일**: 2026-08-30

## 무엇이 문제였나

다른 세션이 결과 그림을 **판정 대역**(9,400,000)으로 먼저 옮겼는데 본문·표는 아직
**진단 대역**(9,900,950) 값이었다. 그래서 한 논문 안에서 같은 사실이 두 값으로 나왔다:

| | 그림 5 | 본문·캡션 |
|---|---|---|
| 제안 정책이 더 싼 날 | **28 / 28** | **26 / 28** |

심사자가 그림과 본문을 나란히 보면 바로 걸리는 모순이다. 수치가 좋아지는 쪽이라도
**절반만 옮긴 상태**가 가장 나쁘다.

## 한 일 (두 줄 + 재생성)

`fig_results.py` 의 `ARMS`·`JUDGE_SEED` 를 진단 대역으로 되돌리고 그림 셋을 다시 그렸다.
그림은 원자료를 직접 읽으므로 두 줄이면 전체가 따라온다.

**대조 확인** (PDF 본문에서 기계로 확인):

- 영문 15쪽 · 국문 13쪽에서 그림 안의 `26 / 28 days improved` 와 본문의 `26 of the 28`
  (국문 `26일`)이 **같은 쪽에서 일치**한다.
- `28 / 28` 흔적은 국·영문 어디에도 없다.
- 표 4 합계 `1.471`(국문 `14.71억`)과 시각 비중 `91.3%` 가 초록·본문·표에서 일치한다.

## 다음 — 205개 수치를 한 번에 옮긴다

`RL_TIME`·`RL_SPACE` 판정 실행이 끝나 `judge-locked` 에 여덟 팔이 모두 들어오면:

1. 원자료에서 값을 뽑는 스크립트로 대상 수치를 전부 출력한다
   (짝비교 §5.3 은 [[YR-271]] 의 `scripts/v3/paired_tests.py` 가 이미 그 역할을 한다).
2. 본문·표·초록에 갈아 넣는다 (§5.1 5개 · §5.3 71개 · §5.4 58개 · §5.5 9개 ·
   §5.6 56개 · 초록 6개 = 약 205개).
3. **그림의 두 줄도 같은 커밋에서** judge-locked·9,400,000 으로 바꾼다.
4. 스크립트를 다시 돌려 논문과 기계로 대조한다 — 사람 눈으로 205개를 검산하지 않는다.

⚠️ §3·§4 와 학습곡선 수치는 학습 달에서 나온 값이라 **바뀌지 않는다** (블록 21개,
슬롯 1,440, 도착곡선, 비용계수, 손실 0.079→0.029, 반사실 세계 4,671개, 망 크기 등).
