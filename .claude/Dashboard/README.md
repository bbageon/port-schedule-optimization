- **주장 게이트 (2026-07-20 갱신)**: 현재 접근 가능한 공개자료만으로는 `실운영 대비 개선율`·CURRENT_RULE 재현·운영사 실측 validation을 주장할 수 없다. 가능한 주장은 `문헌·공개자료 보정 시뮬레이션`의 방법론 결과다. 향후 실제 PoC는 YR-082의 Level 2 구조자료와 Level 3 운영로그를 확보하고, 별도 Level 4 Shadow Mode 범위를 승인받은 뒤에만 연다. 이는 과거 협약 폐기 결정을 자동으로 뒤집는 것이 아니다.
